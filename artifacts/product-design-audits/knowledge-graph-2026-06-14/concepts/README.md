# Knowledge Graph Concept References

Date: 2026-06-14
Surface: `/knowledge`

These images are Product Design concept references for the next knowledge graph workspace proposal series. They are not pixel-perfect implementation targets.

## Concepts

- `night-bridge-semantic-map.png`: dark premium reference. Adopt restrained dark-mode depth, fine semantic edges, and a stable right inspector feeling. Do not adopt the mock role switch or any standalone shell that diverges from the shared AppShell.
- `daylight-engineering-atlas.png`: light clarity reference. Adopt white-mode readability, compact tool groups, and clearer right-panel hierarchy. Do not adopt the fully expanded left navigation as the default.
- `layered-research-atlas.png`: graph organization reference. Adopt semantic cluster territories, compact left local graph tools, fine relation lines, stable right inspector, and persistent graph workspace framing. Do not treat the generated labels, icons, or exact node positions as requirements.

## Accepted Direction

The approved direction combines layered graph organization from `layered-research-atlas.png`, the premium dark atmosphere from `night-bridge-semantic-map.png`, and the light-mode clarity from `daylight-engineering-atlas.png`.

Global platform navigation, theme switching, user center, and the right-bottom Konling assistant remain owned by the shared platform shell. Knowledge-specific directory, filters, legend, layout, focus, and inspector controls remain local workspace tools.
