## 1. 本批审计顺序

本批沿教师课后到学生回查的真实顺序展开：

1. 教师进入上课历史，查找已结束课堂。
2. 通过搜索定位 5-3 课堂，打开归档编辑。
3. 触发删除课堂并取消，记录确认方式和影响说明。
4. 进入有效课堂复盘，查看能力追踪、补强路径、学生摘要和雷达图。
5. 从复盘页跳转到评审聚合入口，再从复盘页返回班级详情。
6. 访问未归档课堂复盘阻断页。
7. 学生进入学习证据，使用默认列表、课堂作答筛选、复盘课堂作答动作、课次过滤和空态恢复。

## 2. 教师上课历史与归档编辑

证据：

- `01-teacher-history-mobile.png`
- `02-teacher-history-search-53-mobile.png`
- `03-teacher-history-archive-edit-mobile.png`
- `04-teacher-history-delete-dismissed-mobile.png`

观察：

- 上课历史移动端能展示已结束课堂清单，每条课堂包含教案标题、班级归档、日期、时长、参与人数和课堂码。
- 搜索 `5-3` 后能缩小列表，便于定位目标课堂。
- “编辑”展开后可以选择归档班级，并提供“保存归档”和“删除课堂”。
- 点击“删除课堂”触发浏览器原生确认，文案是“确定删除这条课堂历史吗？课堂记录会一并删除。”；本批已取消确认，没有删除数据。
- 全部结构化快照的 `alerts` 为空。

问题：

- P1：课堂删除仍依赖原生 confirm。删除影响涉及课堂记录、学生状态、提交、报告和证据来源，但确认文案只说“课堂记录会一并删除”，没有显示影响数量、是否可恢复、是否影响学生证据或教师报告。
- P1：归档编辑缺少保存前影响说明。教师能把历史课堂改归档到班级，但 UI 没有说明这会如何影响班级复盘、学生证据归属、统计口径或历史报告入口。
- P2：移动端历史清单功能密度高。默认历史页结构化快照记录 133 个按钮/链接候选和 249 个图形元素，虽然多数来自整页导航与图标，但教师在移动端仍需要从很长列表中定位“课堂统计、编辑、删除”的风险动作。
- P2：搜索结果没有结果数变化播报。搜索能缩小列表，但没有 `role=status`/`aria-live` 提示当前命中多少节课。

建议：

- 删除课堂改为系统内确认模态，展示课堂名、班级、学生状态数、提交数、报告数、证据影响和恢复策略。
- 归档编辑保存前展示“变更后此课堂会进入哪个班级复盘/统计”的确认摘要。
- 移动端把高风险删除动作放到二级菜单或确认面板，避免与课堂统计、编辑并列暴露。

## 3. 有效课堂复盘页

证据：

- `05-teacher-valid-review-mobile.png`
- `07-teacher-valid-review-desktop.png`
- `08-teacher-review-return-class-detail-desktop.png`
- `09-teacher-unbound-review-blocked-desktop.png`

观察：

- 有效课堂复盘页展示 5-3 课堂：`2024自动化（ZXVBP6）`，状态 `FINISHED`。
- 顶部能展示课堂记录 81 人、有互动日志 72 人、有提交 56 人、形成学习事实 56 人、同步错误 0 人。
- 能力追踪显示五个维度，均为课前 89 到课后 50，变化 `-39`。
- 课后个性化补强路径区域能定位到刘中天、肖毅等学生，但两个重点学生均显示“暂无补强路径记录”和“暂无个性化题单”。
- 学生摘要能列出前 4 名学生和追踪短板。
- 页面包含两张雷达图，结构化快照中 `unnamedGraphics` 为 2。
- 复盘页只有“返回班级详情”和“前往评审聚合入口”两个主要后续链接；没有导出、下载、打印、发送学生、生成补强路径、创建题单或同步到班级报告的动作。
- 未归档课堂复盘阻断页能阻断访问，但结构化快照没有可用链接，缺少直接修复路径。

问题：

- P1：有效复盘有数据，但没有把数据转成教师后续动作。页面能发现能力下降、重点学生和同步状态，但无法一键生成补强路径、题单、班级报告、学生通知或导出材料。
- P1：补强路径区域处于“识别学生但无方案”的半成品状态。教师能看到重点学生短板，却只能看到“暂无补强路径记录/暂无个性化题单”，没有“生成/补录/查看原因”。
- P1：复盘页缺少报告输出能力。桌面和移动都没有导出、下载、打印或分享入口，无法把课堂复盘带入教研、班级沟通或学生反馈。
- P1：复盘页跳转到 `/review/extracurricular-showcase` 会离开教师课后工作流。该入口是内部评审聚合页，里面混合知识图谱、BOPPPS 入口、控制奥德赛等展示链接，不像教师继续处理本课堂报告。
- P1：未归档阻断页缺少修复入口。阻断是合理的，但页面应提供“去上课历史归档此课堂”或“返回上课历史并定位该记录”，不能只停在无链接空态。
- P2：雷达图缺少可访问名称或等价表格摘要。结构化快照记录 2 个未命名图形，读屏用户难以获得课前/课后雷达图结论。

建议：

- 在复盘页顶部增加“导出报告、生成补强路径、创建题单、发送学生、返回历史”主动作。
- 对“暂无补强路径/题单”给出原因和生成动作，至少区分数据不足、规则未配置、AI 不可用和待同步。
- 把内部评审聚合入口从教师正式复盘页移除，或改成教师可理解的“查看设计评审样例”，不作为主工作流出口。
- 未归档阻断页直接链接到 `/teacher/history` 并携带 sessionId 或搜索条件。

## 4. 学生证据回查

证据：

- `10-student-evidence-default-mobile.png`
- `11-student-evidence-default-question-filter-mobile.png`
- `12-student-evidence-default-next-action-mobile.png`
- `13-student-evidence-lesson-filter-mobile.png`
- `14-student-evidence-refresh-mobile.png`
- `15-student-evidence-question-filter-mobile.png`
- `16-student-evidence-next-action-mobile.png`
- `17-student-evidence-empty-filter-mobile.png`

观察：

- 学生默认证据页能展示多条课堂作答证据，包含 4-1 前测、课堂作答 step-03、课堂作答 step-10 等记录。
- 事实类型筛选为“课堂作答”后，证据仍可见。
- 证据卡上的“复盘课堂作答”会跳到 `/profile/evidence?lessonId=unit-4-1-design-task-expression-v1`，仍停留在证据列表内。
- 直接用课程路由 slug `unit-4-1-design-task-expression` 过滤时，页面显示“当前筛选下暂无证据”。
- 空态提供“重置筛选条件”和“返回成长中心”。
- 嵌入式 `/profile/evidence` 顶部可见一个只有图标的刷新按钮，但 Playwright 通过可访问名称 `刷新` 无法定位；结构化快照的 `alerts` 均为空。

问题：

- P1：课程路由 slug 与证据 lessonId 不一致。学生默认列表中 4-1 证据使用 `unit-4-1-design-task-expression-v1`，而课程路由使用 `unit-4-1-design-task-expression`；从课程或报告按路由 slug 回查会得到空态。
- P1：“复盘课堂作答”没有进入真正的复盘或补救路径。它只是带 lessonId 再次过滤证据列表，学生仍停留在证据浏览页，没有题目复盘、正确答案、补练建议或回到原课堂步骤。
- P1：证据刷新在嵌入页缺少可访问名称和状态播报。顶部刷新图标可见，但没有可通过名称定位的 `刷新` 按钮；点击或筛选变化后也没有 live/status 说明。
- P1：空态没有解释筛选条件为什么无结果。页面显示“当前筛选下暂无证据”，但不提示当前 lessonId、可用 lessonId、是否存在 `-v1` 版本或如何从课程记录进入。
- P2：移动端证据卡信息密度偏高。证据卡同时展示标题、标签、lessonId、stepId、评分、来源范围、新鲜度、置信度、缺失来源和下一步按钮，学生很难先理解“这条证据说明我哪里需要复盘”。

建议：

- 统一课程路由 slug 与证据 lessonId，或在证据 API 中兼容别名映射。
- “复盘课堂作答”应进入题目级复盘页，展示原题、作答、参考答案、错误原因和补练任务。
- 给刷新图标添加可访问名称，并在刷新、筛选、加载更多、空态恢复时提供 `role=status` 或 live 区域。
- 空态展示当前筛选条件，并建议可点击的相邻课次或“查看全部 4-1 证据”。

## 5. 本批新增优先问题

1. P1：教师课堂删除仍使用原生 confirm，影响范围不透明。
2. P1：有效课堂复盘有数据但缺少导出、发送、生成补强路径和创建题单等后续动作。
3. P1：复盘页跳到内部评审聚合入口，离开教师课后工作流。
4. P1：未归档课堂复盘阻断页没有返回历史并定位归档的修复入口。
5. P1：学生证据 lessonId 与课程路由 slug 不一致，导致按课程 slug 回查为空。
6. P1：“复盘课堂作答”只重新过滤证据列表，没有进入题目复盘或补救路径。
7. P1：证据刷新和筛选结果缺少可访问名称与 live/status 播报。
