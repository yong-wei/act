## 1. 本批审计顺序

观察：

- 班级详情页能显示 `2024自动化`、班级码、学生清单、课堂历史和 batch24 结束课堂；课堂历史 API 也能用 `status=FINISHED&search=4-1` 查到课堂 `cmqm6s1s1001f1wyf4ggkifs5`。
- 班级详情页的已结束课堂入口主要是“课堂统计”，没有在历史列表中暴露导出、发送报告、补强路径发布或同步状态。
- 复盘页能显示真实班级、课堂记录 2 人、有互动日志 2 人、有提交 2 人、形成学习事实 2 人、同步错误 0 人。
- 复盘页展示课前/课后能力追踪、个性化补强路径、学生摘要和雷达图，但补强路径区块仍是“暂无补强路径记录/暂无个性化题单”。
- 桌面和移动复盘页均只有“返回班级详情”和“前往评审聚合入口”这类导航动作，没有导出、发送、复制摘要、生成补强或标记已交付。

问题：

- P1：班级历史只把已结束课堂暴露为统计入口，不承接报告交付。教师完成课堂后仍需要在别处寻找导出或发送能力。
- P1：复盘页缺少报告交付主动作。页面有真实数据，但没有把“给学生/班主任/教师自己交付什么”变成可执行任务。
- P1：补强路径区块是结果占位，不是生成或发布入口。教师看到学生短板后无法从同页创建补强路径或题单。
- P2：移动端复盘页长页面末尾才出现评审聚合入口，报告交付动作缺失时移动端更难发现下一步。

建议：

- 已结束课堂历史行增加“查看复盘”“导出报告”“发送给学生”“发布补强”四类状态化动作。
- 复盘页顶部在状态 chips 后加入报告交付操作区：导出、发送、复制摘要、生成补强路径、同步异常详情。
- 补强路径区块应提供“为未掌握短板生成补强路径”和“发送题单”动作，并显示交付状态。

## 3. 评审聚合入口与教师报告账本

证据：

- `03-review-aggregation-entry-result-desktop.png`
- `04-teacher-dashboard-report-ledger-desktop.png`
- `09-teacher-dashboard-report-ledger-mobile.png`

观察：

- 复盘页的“前往评审聚合入口”跳转到 `/review/extracurricular-showcase`，页面标题为“课外展示聚合入口/课外教学展示聚合入口”。
- 该页面不是从 `2024自动化`、课堂 `113718` 或本次复盘生成的报告交付面；它更像内部 review 或课外展示汇聚页。
- 教师首页包含“学习分析槽位”和“助手效果报告槽位”，能看到导出语义标签，例如“导出：仅确定性报告”。
- 助手效果报告槽位写明“等待确定性种子、重置和效果指标接入”，说明它是占位或 feature-flag 状态，不是真实课堂报告闭环。
- 教师首页能展示当前课堂、班级、教案和历史报告摘要，但没有从 batch24 复盘直接回流到报告账本的交付记录。

问题：

- P1：复盘页出口跳到内部评审/展示聚合页，语义不符合教师课后报告交付。教师会从“课堂复盘”跳到一个不带本课堂上下文的页面。
- P1：教师首页报告槽位是语义占位，不是可执行的报告账本。页面展示导出策略，但没有可点击的真实课堂报告条目。
- P2：报告槽位与课堂历史分离。教师难以确认某节课堂是否已导出、已发送、是否有异常或是否等待补强路径生成。

建议：

- 将复盘页“评审聚合入口”降级为内部入口，另设教师主路径按钮：`生成课堂报告`、`发送给学生`、`发布补强路径`。
- 教师首页报告槽位应显示真实报告条目、来源课堂、生成时间、交付状态、导出按钮和失败重试。
- 内部 review 页面如果保留入口，应明确标注“内部审查/展示聚合”，避免被误认为学生报告交付路径。

## 4. 报告 API 与评分工作台

证据：

- `05-teacher-grading-workbench-empty-desktop.png`
- `06-teacher-grading-workbench-demo-desktop.png`
- `10-teacher-grading-workbench-empty-mobile.png`
- `function-state-flows-batch25-manifest.json`

API 证据：

- `/api/teacher/classes/cmma7g0590004g9q2nl2jyzdf/control-correction-report?export=true` 返回 200，包含 `report` 和 `export`，`export` 下有 `tables`、`chartData`、`methodologyNotes`、`redactionPolicyNotes`。
- `/api/teacher/classes/cmma7g0590004g9q2nl2jyzdf/assistant-effect-report?export=true` 返回 404，错误为“演示效果报告不存在”。
- `/api/teacher/classes/cmma7g0590004g9q2nl2jyzdf/sessions?status=FINISHED&search=4-1` 返回 200，并包含本批复用课堂 `cmqm6s1s1001f1wyf4ggkifs5`。

观察：

- 控制纠偏报告真实班级导出 API 已存在，但当前班级详情、复盘页和教师首页没有把它作为显式可用动作呈现。
- 助手效果报告真实班级 API 仍是 demo-only/404，与教师首页“助手效果报告槽位”的可见标签存在落差。
- 报告评分工作台空态显示“请选择已转换的学生提交，或通过评分草稿标识进入审批工作台”，没有说明从真实课堂复盘、班级历史或报告账本如何进入。
- demo 态评分工作台可展示样例数据，但与真实课堂 `2024自动化` 无绑定，页面也没有明显避免教师误解为正式报告。

问题：

- P1：真实导出 API 与教师 UI 断开。后端已经能生成控制纠偏报告 export，但教师主流程不可发现。
- P1：助手效果报告槽位和真实 API 状态不一致。教师首页展示“导出：仅确定性报告”，但真实班级 API 返回 demo-only 404。
- P1：报告评分工作台缺少真实来源路径。空态没有“从某节课堂复盘生成评分草稿”或“返回报告账本”的动作。
- P2：demo 工作台与正式工作台边界不够强。教师进入 demo 后能看到报告评分界面，但缺少“演示数据，不会写入真实班级”的醒目标识。

建议：

- 把控制纠偏报告导出能力接入班级详情、课堂复盘页和教师首页报告账本。
- 助手效果报告在真实班级不可用时，UI 应显示“尚未接入真实闭环数据”，不应表现成可导出的报告槽位。
- 报告评分工作台空态提供来源说明和回流动作：选择课堂、查看报告账本、创建评分草稿。
- demo 工作台加演示标识和数据隔离说明，并避免从教师主流程误跳。

    班级详情页能找到课堂统计，但没有导出、发送、生成补强或交付状态。

    “前往评审聚合入口”落到 `/review/extracurricular-showcase`，不携带本课堂上下文。

     `/control-correction-report?export=true` 返回 `report` 和 `export`，但教师班级、复盘和首页都没有显式入口。

     `?demo=1` 能看到样例评分界面，但缺少明显演示数据隔离和不会写入真实班级的说明。

104. P2：移动端课后复盘缺少固定交付动作区。
     移动复盘页长页面主要呈现分析内容，缺少顶部或底部的导出、发送和补强路径快捷动作。
