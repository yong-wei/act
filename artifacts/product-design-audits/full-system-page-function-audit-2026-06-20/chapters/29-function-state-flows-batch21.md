## 1. 本批审计顺序

本批沿教师管理班级成员的真实顺序展开：

1. 教师进入班级详情，查看班级码、学情总览、课堂历史和学生清单。
2. 打开“添加学生”，查看默认候选、单字符校验、候选搜索。
3. 切换到 Excel 导入，选择无效学号文件并触发导入结果。
4. 关闭添加学生弹窗，触发学生删除并取消原生确认。
5. 进入学生个体学情页，查看风险、证据治理和推荐动作。
6. 进入教师侧学生证据页，检查筛选、刷新和移动端证据卡。

证据：

- `02-teacher-add-students-modal-default-desktop.png`
- `03-teacher-add-students-one-char-error-desktop.png`
- `04-teacher-add-students-search-demo-desktop.png`
- `05-teacher-add-students-import-default-desktop.png`
- `06-teacher-add-students-import-file-selected-desktop.png`
- `07-teacher-add-students-import-invalid-result-desktop.png`
- `11-teacher-add-students-modal-mobile.png`
- `12-teacher-add-students-import-mobile.png`

观察：

- 添加学生弹窗覆盖在班级详情长表格之上，默认标签为“搜索添加”，另一个标签为“Excel导入”。
- 搜索输入的可访问名称与 placeholder 均为“搜索姓名、账号或学号...”。输入 1 个字符后能出现“请输入至少2个字符”，但结构化快照 `alerts` 为空。
- 搜索 `demo` 能展示候选学生和“添加”按钮；本批没有点击添加，避免污染班级数据。
- Excel 导入说明写明第一行为标题行、第一列为学号、支持 `.xlsx`、仅导入系统中已存在的学生账号。
- 文件选择后页面展示文件名，但没有行数、预校验摘要或替换文件入口；隐藏 file input 没有 `aria-label`。
- 无效学号导入后能显示“导入结果”：总计 1、成功 0、失败 1，并展示失败表格“学号/原因”。结构化快照中新增一个 1 行失败表。
- 移动端添加学生弹窗出现在长表格页面中段，全页截图下弹窗很容易被背景长列表稀释。

问题：

- P1：添加学生弹窗缺少可访问对话框语义。截图可见遮罩和弹窗，但 DOM 快照仍把背景长表格、背景按钮和弹窗输入混在一起；没有明显 `dialog`、焦点陷阱和背景不可达证据。
- P1：搜索校验和搜索结果缺少 live/status 播报。单字符错误、候选列表刷新和“未找到匹配学生”都应有可感知状态，而不是只靠静态文本。
- P1：候选添加前缺少影响确认。候选卡能显示当前班级信息，但点击“添加”前没有说明是否会从原班级迁移、是否影响历史报告和学生证据归属。
- P1：Excel 导入缺少预览和批次治理。无效导入能显示失败行，但没有下载模板、失败行导出、批次编号、文件名、撤销、通知学生、导入前预检和导入后筛选本批学生。
- P2：隐藏 file input 没有任务语义名称。读屏或自动化工具无法通过可访问名称理解这是“导入班级学生 Excel”。

建议：

- 将添加学生弹窗声明为 `role=dialog` 或等价语义，打开后聚焦标题/输入框，背景内容不可 Tab 到。
- 搜索、校验、导入中、导入完成和失败结果都接入 `role=status`/`role=alert`。
- Excel 导入加入预览步骤：文件名、行数、将新增/迁移/失败的学生数、影响班级、可撤销范围。

## 4. 教师侧个体学情与证据页

证据：

- `13-teacher-student-insights-desktop.png`
- `14-teacher-student-evidence-desktop.png`
- `15-teacher-student-insights-mobile.png`
- `16-teacher-student-evidence-mobile.png`

观察：

- 个体学情页显示左乔生为中风险，综合指数 0，学习事实 0，画像摘要为“需关注”。
- 页面能展示风险标记：近一周学习活跃度极低、近两周无成功学习记录；推荐动作包括恢复学习节奏、突破学习瓶颈、提升控制建模与分析能力、工程决策训练和探索知识图谱。
- 证据治理显示“缺少证据”“无置信 · 0 条”，近期会话质量中 4-4 课堂为“待判定”。
- 个体学情页有“刷新数据”“查看干预建议”“查看完整证据”，但推荐动作本身没有分派、发送、创建补练、记录已处理等执行入口。
- 教师侧学生证据页提供能力维度、课次、事实类型和结果筛选；默认能看到一条课堂作答证据，来源范围为互动课提交，新鲜度待刷新，置信度低，缺失来源显示来源完整。
- 教师侧证据页的刷新按钮有可访问名称“刷新”，但刷新、筛选和重置后的结构化快照 `alerts` 为空。
- 移动端证据页第一视口主要是筛选面板，证据卡在其后；证据卡底部动作是“留在学生证据审核”，属于自链接，不能把证据转化为教师干预。

问题：

- P1：个体学情页把风险识别出来了，但推荐动作不可执行。教师看到“恢复学习节奏/突破学习瓶颈”等建议后，不能直接生成补练、发消息、分派任务、记录干预或关闭风险。
- P1：证据不足与推荐动作之间缺少因果解释。学生学习事实为 0、证据缓存缺少证据，但页面仍给出多个推荐动作；教师无法判断建议来自真实证据、规则兜底还是冷启动模板。
- P1：教师侧证据审核没有输出/处置链路。证据页能筛选和刷新，但没有导出证据、添加教师备注、标记已核验、创建补救任务或回写课堂复盘。
- P1：移动端证据页筛选占据首屏，证据和下一步动作被推到后面。教师在手机上优先看到筛选表单，而不是“这个学生当前最需要处理什么证据”。
- P2：证据页刷新和筛选没有状态播报。刷新按钮命名比学生端更好，但没有 live/status 说明刷新中、完成、失败或筛选结果数量。

建议：

- 把推荐动作改成可执行任务：分派补练、发送学生、加入课堂提醒、记录线下干预、标记已处理。
- 对冷启动/低证据学生，明确提示建议来源和置信度，避免把模板建议误读为证据充分诊断。
- 教师侧证据页增加“导出、备注、核验、生成补救任务、返回个体学情”的明确工作流。

## 5. 本批新增优先问题

68. P1：教师班级学生清单缺少搜索、筛选、批量治理和移动端重构。
    143 人学生清单在桌面和移动端都以长表格呈现，教师无法按风险、证据状态、待刷新或学生姓名快速定位。

69. P1：班级移除学生仍使用原生 confirm，影响范围不透明。
    确认文案只显示学生姓名，没有说明历史课堂、报告统计、学习事实、证据回流和恢复策略。

70. P1：添加学生弹窗缺少稳定 dialog/focus/live 语义。
    弹窗可见，但结构化快照仍混入背景长表格；搜索校验、候选刷新和空结果没有 `role=status` 或 `role=alert`。

71. P1：班级学生 Excel 导入缺少预览和批次治理。
    无效导入能显示失败表格，但导入前没有行数/影响预览，导入后没有批次编号、失败行导出、撤销、通知学生或筛选本批。

72. P1：教师个体学情推荐动作不可执行。
    页面能识别风险和推荐动作，但无法直接生成补练、发消息、分派任务、记录干预或关闭风险。

73. P1：教师侧学生证据页停留在筛选浏览，缺少核验与处置闭环。
    证据页能筛选刷新，但没有导出、备注、核验、生成补救任务或回写课堂复盘；移动端首屏主要被筛选占据。
