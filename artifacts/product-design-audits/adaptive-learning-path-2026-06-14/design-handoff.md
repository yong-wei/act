# 自适应学习路径中心重构设计 Handoff

状态: accepted for OpenSpec proposal input  
日期: 2026-06-14  
范围: `/assessment/adaptive-practice` 及其衍生的学习路径生成、选择、执行、历史与证据视图  

## 设计目标

将当前“自适应练习 / 控制校正中心”重构为通用的“自适应学习路径中心”。页面不再以固定控制校正目标和工程状态为主，而是围绕学生可执行的学习路径组织：

- 任何用户、任何证据状态下都能生成可用路径。
- 冷启动用户先获得入门路径，随后随学习证据自动调整。
- 路径可覆盖全站资源：互动课程、知识卡、自适应练习、控制工作台、虚拟仿真、Arena、外部资源、反思复盘和控灵辅导。
- 路径必须包含检查节点，不能只是资源浏览清单。
- 学生能选择、执行、跳过、回顾和继续互动；这些行为进入数据治理链路。
- 控灵是路径生成和调整的主要入口，但保持平台统一的右下浮动助手形态。

## 页面类型

### 1. 路径生成主界面

目标: 让学生明确当前可以生成学习路径，并能通过控灵表达目标和约束。

必须包含：

- 页面标题: `自适应学习路径中心`
- 主操作: `生成学习路径`
- 冷启动文案: `证据还少，先从入门路径开始，系统会随学习过程调整。`
- 学习概况: 当前目标、当前节点、已学习时间、预计总时长、本周完成情况。
- 控灵生成面板:
  - 学习目标
  - 可用时间
  - 难度节奏
  - 资源偏好
  - 检查节点
  - 站外资源
  - 自然语言输入: `告诉控灵你想达成什么`
- 生成结果预览: 2-3 条路径的简要预览。

不允许：

- 将路径生成按钮固定为“生成控制校正学习路径”。
- 把无路径、低证据、上下文缺失呈现为失败状态。
- 在首屏显示内部调试词。

### 2. 路径选择与比较

目标: 让学生比较多条路径，理解差异，并作出选择或请求控灵调整。

必须包含：

- 页面标题: `选择你的学习路径`
- 至少 2 条、推荐 3 条可比较路径。
- 默认路径类别:
  - 基础补弱路径
  - 实践冲刺路径
  - 课程同步路径或偏好匹配路径
- 对比字段:
  - 预计时长
  - 已匹配资源
  - 检查节点
  - 适合场景
  - 当前建议理由
  - 预期结果
- 操作:
  - `选择路径`
  - `请控灵调整`
  - `暂不采用`
- 选择历史: 已选择、拒绝、切换和有用性反馈。

路径选项应使用列表或表格式比较，不应做成三个孤立大卡片。资源组合必须使用稳定图标表达。

### 3. 当前路径执行与完整路径图

目标: 让学生清楚看到完整路径、当前节点和执行状态。

必须包含：

- 页面标题: `当前学习路径`
- 完整路径图，而不是只显示下一步。
- 当前节点必须有明确标记: `当前节点`
- 学习统计:
  - 已耗时
  - 预计剩余
  - 预计总时长
  - 完成节点
  - 检查点通过
  - 本周学习
- 节点详情:
  - 节点标题
  - 推荐理由
  - 启动操作
  - 预计时长
  - 将收集的学习证据
  - 检查标准
- 已完成节点操作:
  - `回顾`
  - `继续互动`
  - `查看证据`
- 未完成节点操作:
  - `开始学习`
  - `跳过`

跳过未完成资源前必须显式提醒：

> 跳过后该资源不会计入完成进度，但会记录为路径偏离，可稍后返回。

跳过是允许行为，但必须写入路径偏离记录，并可在之后返回。

### 4. 学习历史与证据记录

目标: 让学生看到路径完成、回顾、继续互动、跳过和控灵干预如何影响后续推荐。

必须包含：

- 页面标题: `学习路径记录` 或 `路径完成与证据`
- 汇总统计:
  - 已完成节点
  - 已耗时
  - 预计节省或超出时间
  - 检查点通过率
  - 回顾次数
  - 新增证据
- 时间线:
  - 完成节点
  - 已完成节点继续互动
  - 重试
  - 跳过未完成资源
  - 检查点通过或未通过
  - 控灵干预
  - 外部资源引用
- 已完成节点详情:
  - `回顾内容`
  - `继续互动`
  - `查看证据`
- 学生可见解释:
  - `新的互动会纳入学习证据，用于更新后续路径。`
- 证据来源标签:
  - 互动课程
  - 自适应练习
  - 控制工作台
  - 虚拟仿真
  - Arena
  - 外部资源
  - 控灵建议
- 证据状态只使用用户语言:
  - 已记录
  - 待复核
  - 可用于推荐
  - 仅作参考

## 资源类型图标合同

路径上的不同资源必须使用不同图标或视觉形态表达。图标语义应稳定，不随页面变化：

| 类型 | 显示名称 | 用途 |
|---|---|---|
| interactive_lesson | 互动课程 | 课程内容和课堂互动 |
| knowledge_card | 知识卡 | 概念补强和知识点复习 |
| adaptive_quiz | 自适应练习 | 检查理解和动态估计能力 |
| control_workbench | 控制工作台 | 参数实验、控制设计和分析 |
| simulation | 虚拟仿真 | 场景化验证 |
| arena_task | Arena | 挑战与综合验证 |
| external_resource | 外部资源 | 受治理的站外学习材料 |
| reflection | 反思复盘 | 总结、归因和复盘 |
| checkpoint | 检查点 | 阶段性判断，不等同普通资源 |
| konling | 控灵辅导 | 生成、解释、调整和干预 |

检查点必须与普通资源节点视觉上区分开。它可以是菱形、标尺、旗标或其他稳定形态，但不能仅靠文字说明。

## 导航与壳层

页面必须使用统一平台壳层：

- 左侧导航默认收起为图标栏。
- 用户展开或收起导航的选择跨页面保持。
- 顶部保留面包屑、主题切换、用户中心。
- 控灵统一为右下浮动 dock，不嵌入右侧栏。
- 移动端使用堆叠布局、底部面板、分段标签或纵向时间线，不复制桌面密集布局。

## 用户状态表达

学生界面必须使用产品语言，不显示工程状态。

禁止直接出现：

- `Readiness Gate`
- `missing-rules-graph-path-payload`
- `missing-konling-context`
- `terminal-validation-unavailable`
- `policyFamily`
- `stage`
- `no-path`
- `low-evidence`
- 任何 `missing-*` 或内部 reason code

推荐表达：

- `证据还少，先从入门路径开始，系统会随学习过程调整。`
- `这条路径更适合先补概念，再进入练习。`
- `当前检查点建议完成后再进入仿真。`
- `该资源可以跳过，但系统会记录为路径偏离，稍后仍可返回。`

内部状态可以保留在日志、管理员诊断或教师治理视图中，但不得默认出现在学生路径中心。

## 数据治理与交互回写

路径中心不是静态导航页。以下行为必须进入数据治理链路：

- 生成路径
- 选择路径
- 拒绝路径
- 切换路径
- 请求控灵调整路径
- 开始节点
- 完成节点
- 回顾已完成节点
- 在已完成节点中继续互动
- 跳过未完成资源
- 稍后返回跳过资源
- 检查点通过或未通过
- 控灵干预被采纳、忽略或拒绝
- 外部资源访问与引用

已完成节点再次互动产生的新数据，应作为新的学习证据进入后续推荐，但不应重复计算为原节点初次完成。

跳过未完成资源应记录为路径偏离，而不是静默删除节点。系统应允许学生稍后返回。

## 外部资源

外部资源可进入学习路径，但必须被治理：

- 有标题、来源、URL、预计时长、知识覆盖、适用目标。
- 标注是否可用于推荐证据。
- 学生可见状态应为 `仅作参考`、`可用于推荐` 等产品语言。
- 不允许把外部链接当作已完成学习证据，除非有明确访问或互动记录。

## 后续 OpenSpec 验收建议

后续提案应设置以下硬闸门：

1. 视觉对照: 实现截图必须对照本文档和 4 张概念图，通过 design-qa。
2. 文案闸门: 学生页面不得出现禁止词。
3. 冷启动闸门: 无学习证据账号仍能生成并选择可执行路径。
4. 通用目标闸门: 路径生成不得固定为 `control-correction`。
5. 资源覆盖闸门: 路径节点至少覆盖课程资源、练习、检查点和一个可选验证节点。
6. 图标语义闸门: 不同资源类型必须有稳定图标或视觉形态。
7. 路径全貌闸门: 执行页必须显示完整路径和当前节点。
8. 跳过提醒闸门: 未完成资源跳过前必须出现确认和后果说明。
9. 数据治理闸门: 选择、跳过、回顾、继续互动和控灵干预都必须写入对应事件或证据链路。
10. 移动端闸门: 每类页面必须有可用移动端布局，不得只压缩桌面布局。
