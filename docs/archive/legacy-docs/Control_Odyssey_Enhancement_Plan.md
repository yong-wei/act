# Control Odyssey (控制奥德赛) - 进阶物理与关卡体系规划 (Revised)

## 1. 核心设计理念：从开环到闭环

**本游戏的核心教学逻辑**：
玩家面临的对象始终是**开环被控对象 (Open-Loop Plant)**。游戏过程通过“手动控制（人脑作为控制器）”或“自动控制（PID 算法）”来闭合回路。

**教学目标**在于让学生体验：**不同特性的开环对象，在闭环后会表现出怎样截然不同的动态特性。**

*   *例*：开环是积分环节 ($1/s$)，闭环后表现为一阶惯性 ($1/(s+K)$)。
*   *例*：开环是双重积分 ($1/s^2$)，闭环后（仅用P）表现为无阻尼震荡 ($1/(s^2+K)$)，必须引入微分 ($D$) 才能稳定。

## 2. 物理引擎升级方案：通用传递函数

为了支持任意形式的线性定常系统 (LTI)，物理引擎将摒弃硬编码的差分方程，转而采用**通用的离散化传递函数求解器**。

### 2.1 核心算法
对于任意连续传递函数 $G(s) = \frac{B(s)}{A(s)}$，采用 **双线性变换 (Tustin Transform)** 或 **零极点匹配法 (Matched Z-transform)** 将其转换为离散差分方程：

$$ y[k] = \frac{1}{a_0} \left( \sum_{i=0}^{M} b_i u[k-i] - \sum_{j=1}^{N} a_j y[k-j] \right) $$

### 2.2 数据结构定义
关卡配置 (`level-data.ts`) 将直接定义 $G(s)$ 的 s 域系数（即开环模型），引擎在加载关卡时自动计算对应的差分系数。

```typescript
// 物理引擎支持的通用配置接口
interface TransferFunctionConfig {
    // 形式 1: 传递函数系数 G(s) = num(s) / den(s)
    num: number[]; // e.g. [1] -> 1; [1, 2] -> s + 2
    den: number[]; // e.g. [1, 0] -> s; [1, 1, 1] -> s^2 + s + 1
    
    // 形式 2: 零极点增益 G(s) = K * (s-z1)... / (s-p1)...
    zeros?: number[];
    poles?: number[];
    gain?: number;

    // 纯延时 (秒)
    delay?: number; 
}
```

## 3. 关卡体系详表 (10关)

以下所有模型均为**开环传递函数 $G(s)$**，输入 $u$ 通常代表推力/舵角，输出 $y$ 代表位置/深度。

### L01: 速度控制 (积分环节)
*   **对象模型**: $G(s) = \frac{K}{s}$
*   **物理意义**: 理想的无惯性速度响应（$v \propto u$）。
*   **闭环特性**: 一阶惯性系统。
*   **教学点**: 最简单的对象，P 控制即可稳定，无静差（对于速度型输入），无超调。
*   **参数建议**: $K=1$。

### L02: 惯性航行 (积分 + 小惯性)
*   **对象模型**: $G(s) = \frac{K}{s(Ts+1)}$
*   **物理意义**: 有质量的实体，速度不能突变。
*   **闭环特性**: 二阶系统。P 增益过大时会出现欠阻尼震荡。
*   **教学点**: 引入“超调”概念。体验 $K_p$ 增大带来的响应加快与震荡加剧的权衡。
*   **参数建议**: $K=1, T=0.5s$。

### L03: 迟缓巨轮 (积分 + 大惯性)
*   **对象模型**: $G(s) = \frac{K}{s(Ts+1)}$
*   **物理意义**: 巨大的轮船，起步慢，停下更慢。
*   **闭环特性**: 同 L02，但时间常数大，带宽低。
*   **教学点**: 必须要有耐心。若强行追求快速（大 $K_p$），极易震荡失稳。
*   **参数建议**: $K=1, T=2.0s$。

### L04: 延时危机 (积分 + 纯延时)
*   **对象模型**: $G(s) = \frac{K}{s} e^{-\tau s}$
*   **物理意义**: 舵令传输延迟或执行机构死区。
*   **闭环特性**: 延时环节引入的相位滞后 $\omega \tau$ 会迅速消耗相位裕度。
*   **教学点**: “明明操作了却没反应”，通过 Smith 预估或降低增益来应对。
*   **参数建议**: $K=1, \tau=0.5s$。

### L05: 太空漫步 (双重积分)
*   **对象模型**: $G(s) = \frac{K}{s^2}$
*   **物理意义**: 真空中的推力控制（加速度控制 $a \propto u$），无摩擦阻尼。
*   **闭环特性**: 若仅用 P 控制，闭环极点在虚轴上 ($s = \pm j\sqrt{K}$)，为等幅震荡（临界稳定）。
*   **教学点**: **必须引入 D (微分) 作用**来提供阻尼，否则永远停不下来。
*   **参数建议**: $K=1$。

### L06: 弹性链接 (积分 + 欠阻尼二阶)
*   **对象模型**: $G(s) = \frac{K}{s(s^2 + 2\zeta\omega_n s + \omega_n^2)}$
*   **物理意义**: 柔性机械臂或带弹性的传动系统。
*   **闭环特性**: 本身开环就有震荡极点，闭环后控制不当会激发剧烈共振。
*   **教学点**: 陷波滤波器（Notch Filter）或极点配置。
*   **参数建议**: $\zeta=0.2, \omega_n=2$。

### L07: 逆风而行 (非最小相位 - RHP Zero)
*   **对象模型**: $G(s) = \frac{K(1 - T_z s)}{s(T_p s + 1)}$
*   **物理意义**: 船舶舵效反转效应（操作舵角初期，侧推力会先使船向反方向平移）。
*   **闭环特性**: “反调”现象（Undershoot）。右半平面零点限制了系统的最大带宽。
*   **教学点**: 不能调得太快，否则反调幅度过大直接撞墙。
*   **参数建议**: $T_z=1.0s, T_p=2.0s$。

### L08: 刀尖起舞 (开环不稳定 - RHP Pole)
*   **对象模型**: $G(s) = \frac{K}{s(Ts - 1)}$
*   **物理意义**: 倒立摆或静不稳定战机。
*   **闭环特性**: 开环极点在右半平面 ($1/T$)。若不控制，系统指数发散。
*   **教学点**: **必须有最小控制量**。P 增益太小会失稳，太大也会震荡，稳定裕度极窄。
*   **参数建议**: $T=2.0s$ (极点 $s=0.5$)。

### L09: 抗扰大师 (强扰动环境)
*   **对象模型**: $G(s) = \frac{K}{s(Ts+1)}$
*   **关卡特征**: 黄金等级叠加高频噪声与低频漂移。
*   **教学点**: 积分项 $I$ 对低频干扰的抑制，微分项 $D$ 对高频噪声的敏感性（需要低通滤波）。
*   **参数建议**: 模型同 L02，但环境恶劣。

### L10: 综合挑战 (高阶 + 延时 + 不稳定零点)
*   **对象模型**: $G(s) = \frac{K(1-s)}{s^2(s+1)} e^{-0.2s}$
*   **教学点**: 终极 Boss。

## 4. 难度等级与挑战设计

每个关卡分为三个挑战等级，逐级解锁。

### 4.1 青铜 (Bronze): 稳态与建立
*   **信号**: 单一阶跃信号 (Step)。
*   **目标**: 无论快慢，只要能活着从起点走到终点，并最终停在目标带内。
*   **评分权重**: 生存 (50%) + 稳态误差 (30%) + 调节时间 (20%)。
*   **包络线 (Margin)**: 宽 ($ \pm 30\% $)。

### 4.2 白银 (Silver): 跟踪与适应
*   **信号**: 连续随机阶跃组合 (Sequence)。每隔一段距离高度变化一次。
*   **目标**: 快速响应变化的设定值。
*   **评分权重**: IAE (积分绝对误差) (50%) + 超调量 (30%) + 调节时间 (20%)。
*   **包络线**: 中 ($ \pm 20\% $)。

### 4.3 黄金 (Gold): 抗扰与鲁棒
*   **信号**: 白银信号 + **有色噪声 (Colored Noise)**。
    *   噪声模型: $N(s) = \frac{A}{s/\omega_c + 1}$ (低通滤波后的随机信号)。
*   **目标**: 在颠簸中保持航向。
*   **评分权重**: IAE (60%) + 输入平滑度 (20%) + 鲁棒性 (20%)。
*   **包络线**: 窄 ($ \pm 15\% $)。

### 4.4 难度系数 (Difficulty Scaling)
玩家可以在设置中调节难度系数 (0.5x ~ 2.0x)：
*   **影响参数**: 误差包络宽度 ($Margin / Difficulty$)。
*   **影响得分**: 最终结算分 $\times Difficulty$。
*   **高难奖励**: 只有在 Difficulty $\ge 1.0$ 时才能记录排行榜成绩。

## 5. UI 与可视化调整需求

为了配合上述模型，UI 层需提供更多信息：

1.  **开环/闭环伯德图预览 (Bode Plot)**: 在“调参实验室”中，根据当前 PID 参数，实时画出 $L(s) = C(s)P(s)$ 的开环伯德图，展示相位裕度 (PM) 和幅值裕度 (GM)。这对于理解 L04 (延时) 和 L08 (不稳定) 至关重要。
2.  **极点分布图 (Pole-Zero Map)**: 展示闭环极点是否跑到了右半平面。
3.  **反调提示**: 对于 L07，当检测到反向运动时，UI 给出提示“非最小相位特性：反向响应中...”。
