## 总体设计原则

### 页面布局模式

平台有两种页面布局模式：

| 模式 | 教师端布局 | 学生端布局 | 适用步骤 |
|------|-----------|-----------|---------|
| **文案页** | 全屏文案卡片（无工作区 iframe） | 全屏文案 + 引导内容 | bridge, objective, neural-ode, pause-reflection, summary |
| **工作区页** | 上方文案卡片 + 下方工作区 iframe | 上方环节任务条 + 下方工作区 iframe | engineering-target, first-exploration, ai-analysis, prompt-refine, adjustment, consistency, group-compare |

### 教师端（投影演示文稿风格）

- 标题：3xl–4xl（~36–48px），加粗
- BOPPPS 阶段标签 + 递进层标签：固定左上角，小号
- 时长标记：固定右上角，小号
- 学生任务框：xl–2xl 字体，醒目边框（2px），浅色背景
- 教师口令（🎯）：xl–2xl 字体，可朗读的提词器
- 巡视关注（🔍）：lg 字体，底部或侧边，次要层级
- 金句：2xl–3xl，居中，大量留白
- 信息密度：每屏 ≤ 3 个核心信息块

### 学生端（个人设备网页风格）

- 环节任务条：页面顶部固定，bg-slate-800/50，2xl 标题 + lg 正文
- 任务描述：lg–xl 字体，要点列表
- 关键问题（🔑）、提示（⚡）、检查项（✅）：前缀图标区分
- 公式引用：括号引用，如"（公式 4.5）"
- 工作区 iframe：占页面下方 ~60–70%
- 非工作区页面（文案页）：字体可更大（2xl–3xl）

### 配色方案（与现有平台深色主题一致）

| 色调 | 用途 | 色值 |
|------|------|------|
| 珊瑚红 | 安全红线、伦理边界、约束违反、伦理熔断 | RGB(228,72,96) / red-500 |
| 科技蓝 | 信息提示、系统参数、频域元素 | RGB(40,128,185) / sky-500 |
| 琥珀橙 | 警告、约束接近边界 | amber-500 |
| 翠绿 | 达标、安全余量、保留项 | emerald-500 |
| 紫色 | 策略、提示词 | violet-500 |
| 青色 | 布鲁姆动词高亮、关键术语 | cyan-300 |

AI 分析流程（2xl，四步纵向流程，箭头连接）：
```
AI 通过 Function Calling 读取仿真状态

  ① 读取参数 → 当前 Kp, Kd 值
         ↓
  ② 读取结果 → 实际 σ%, ts, alat 值
         ↓
  ③ 诊断失败 → 哪个约束被违反？差距多大？
         ↓
  ④ 提示方向 → 调整建议（不给最优值！）
```
