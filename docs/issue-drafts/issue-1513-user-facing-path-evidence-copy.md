# Issue：将学习路径候选说明改为用户可理解的中文

## 背景

学习路径候选卡片当前直接展示 `low-confidence-learner-state`、`adaptive-learner-state` 等内部证据标识。它们属于服务端和数据治理使用的技术术语，普通用户无法据此理解路径为什么这样生成。

## 问题

候选路径的场景说明把后台证据字段原样拼接到页面文案中，例如：

> 依据 low-confidence-learner-state、adaptive-learner-state 生成。

这会暴露实现细节，降低可读性，也让用户误以为需要理解系统内部状态才能选择学习路径。

## 目标

在不改变服务端证据字段、路径生成逻辑、推荐依据或已保存路径数据的前提下，将候选卡片中的场景说明转换为直接、易懂的中文。

## 预期行为

- 当学习记录较少时，显示“当前学习记录较少，这条路径会先从基础内容开始。”
- 当候选路径结合已有学习记录生成时，显示“这条路径结合你的学习记录生成。”
- 对无法识别的证据组合，显示“这条路径根据当前学习记录生成。”
- 页面不得显示 `low-confidence-learner-state`、`adaptive-learner-state`、`LearningFact` 等后台标识。
- 服务端仍保留原始证据字段，后台审计和推荐逻辑不受影响。

## 验收标准

- [ ] 候选路径卡片不再显示后台证据标识。
- [ ] 低置信度证据有明确的中文解释。
- [ ] 有学习记录的候选路径有明确的中文解释。
- [ ] 未识别证据组合使用中文兜底文案。
- [ ] 现有路径生成、保存、执行和比较流程无行为变化。
- [ ] 相关单元测试覆盖上述文案映射和技术术语不泄漏。
- [ ] `npm run typecheck` 通过。

## 非目标

- 不修改候选路径的生成算法或排序规则。
- 不修改服务端证据模型和数据治理字段。
- 不新增系统排名、最佳路径或推荐结论。
- 不改变用户已保存的学习路径和执行状态。
