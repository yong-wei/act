# 集装箱装载候选的静水证明

当前T级候选以源GLB的3525个可见甲板箱包围体积作均匀密度权重，货载高度固定，前中后三段等质量。基准λ=.6按GM_T=2m确定统一KG及固定部分质量分布。

两状态的geometry、来源、验证及源剖面按当前生成器重新计算，哈希记录于evidence-manifest.json。完整湿面可由同一源剖面和记录的生成器重建，源几何的舱内配载及质量分布仍待课程负责人审定。
