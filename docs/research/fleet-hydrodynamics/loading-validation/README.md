# LNG与集装箱变载荷验证

2026-11-14用户审定LNG基准2.5m为第一模态自由液面修正后的有效GM，并审定集装箱采用含舱内货载的T级分布。原基准GM、基础/货载质量和最小浸没压载规则继续参与计算。详细决策保存在OpenSpec变更`stabilize-ilab-simulation-experience`。

## LNG质量与静态耦合

四个44×38×26m等效舱采用450kg/m³、阻尼比.03。基准.85时几何GM为5.563340m，自由液面修正3.063340m，有效GM为2.5m，KG为15.841925m。固定50e6kg部分的龙骨重心20.220986m及惯量由此反算一次，其他填充率复用该分布。

纵倾平衡同时计入液面模态静态位移的一阶矩。初始模态取q=−4Lsinθ/π²及零速度，船体与八个纵/横模态的联合平衡由Rust直接检验。实际推进、液舱反力、恢复载荷与惯性共同进入RK推进。

## 集装箱T级配载

甲板组沿用源模型实例体积加权重心，经同一尺度变换得到龙骨高度40.347093m。舱内组从源封闭船体的对称可容纳体元求得。T级候选范围为x=±.35Lpp、y=±.45B、龙骨高度2m至型深减2m，网格48×20×24。剔除与任意船壳三角形包围盒相交的体元，核验内部中心，并保留x/y镜像共同部分。

21124个体元形成397274.760684m³等效容积，重心高度16.357519m。均匀体元的中心惯量及每个体元自身惯量共同进入货载质量分布。λ≤.6时甲板/舱内质量为80%/20%，λ>.6时甲板质量固定115.2e6kg，新增质量进入内舱。该比例和装载策略属于本轮选择的T级假设。

λ=.6时按GM=2m反算一次固定72e6kg部分，龙骨重心19.157028m。λ=.9时总质量288e6kg、KG=26.653226m、横向GM=1.164064m。装载比较同时包含甲板/内舱质量比例、惯量、吃水和最小压载的变化。
