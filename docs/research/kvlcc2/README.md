# KVLCC2常阻力模型基准

模型按Yasukawa与Yoshimura的MMG方程转录主尺度、船体导数、桨舵互作用和试验条件。当前阻力使用表2的L3常数R0′=0.022，参数包保留其适用边界。[原论文](https://doi.org/10.1007/s00773-014-0293-y)

本地复用了PR #2193的源代码，来源提交为19f4b6d8f50921c63a39e694bf72f6b0eee8b504。后续复核修正了自航点求解中的推力减额遗漏。原实现使直航初态纵向加速度达到−0.003047m/s²。自航点现满足(1−tP)T=R，并验证120秒直航保持初速。

## 数值复核

回转采用航向90度的纵向位移及180度的横向偏距，跨越时刻线性插值。Z形试验在达到指定航向后换舵，由艏摇角速度变号定位峰值。时间步为0.1秒，并以0.05秒核验各指标变化低于1%。

| 配置与指标 | 原论文计算值 | 当前计算值 |
|---|---|---|
| L7右回转前进指数 | 3.31 | 3.13924 |
| L7右回转战术直径 | 3.36 | 3.13441 |
| L7左回转前进指数 | 3.26 | 3.14462 |
| L7左回转战术直径 | 3.26 | 3.10458 |
| L7 10/10第二超越角 | 15.8度 | 14.80032度 |
| 实尺度右回转前进指数 | 3.62 | 3.03573 |
| 实尺度右回转战术直径 | 3.71 | 3.02559 |
| 实尺度10/10第二超越角 | 20.5度 | 14.00870度 |

L7常阻力近似的回转误差低于10%，第二超越角绝对差低于5度，符合当前自动验收阈值。实尺度结果超出相应误差阈值，验证状态为not_ready。原论文采用Schoenherr三维阻力外推，完整输入尚待补齐。实尺度残差的其他来源继续保留调查空间。

机读结果保存在validation.json。重新生成时从仓库根目录运行，设置ACT_KVLCC2_REPORT_PATH为该文件的绝对路径，并将本机Rust工具链bin加入PATH。

```bash
rtk proxy env ACT_KVLCC2_REPORT_PATH="$PWD/docs/research/kvlcc2/validation.json" cargo test --manifest-path rust/control-engine/Cargo.toml --test sixdof_benchmark_kvlcc2 -- --nocapture
```

该基准只用于验证KVLCC2模型。七船参数映射及对应模型可信度由各自参数包记录。
