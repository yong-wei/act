## 已知偏差与归因（诚实记录，不以猜测替代）

**主验证锚点为 L7 模型（表 4/5）**：论文对 L7 与实尺度使用同一组导数，差异仅 wP0 与 Schoenherr 摩擦外推。本复现（常数 R0'）在 L7 配置下回转四锚点 −1~−5.4%、2nd OSA −7.6%；实尺度锚点系统性偏小（论文自述实尺度回转比模型差 ~10%、2nd OSA +4.7°），方向与缺项 Schoenherr 尺度效应一致——不虚构该项，记录为已知偏差。

**2nd OSA(10/10) 实尺度 20.5° 不可达**：敏感性测试证明合理
wP0∈[0.35,0.40]×R0'∈[0.018,0.026] 只覆盖 12.7–16.0°；L7 配置
（wP0=0.40，不依赖 Schoenherr 尺度差）交叉验证 14.6° vs 论文 L7 Cal
15.8°（−7.6%）。残余差距归因于论文实尺度模拟按 **Schoenherr 3D 外推
的随航速变化摩擦阻力**（表内未列、不可转录）——本基准用常数 R0'=0.022
（表 2 L3 值）显式近似。xP'=−0.5 为标准 MMG 假设（论文未单列）。

## 边界（issue 合同）

不把 KVLCC2 直接命名为 LNG 或 055——基准参数只属于 KVLCC2 油轮。
