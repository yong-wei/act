# 知识绑定维护在最小可教学或评价单元

资源知识绑定必须维护在能够独立展示、指派、练习或评价的原子教学资源上。习题逐题绑定，互动课程按活动或检查点绑定，BOPPPS 按 LessonItem 或对应资源单元绑定；作业、讲义、课次等容器的知识覆盖由下级绑定自动汇总，不允许再人工维护另一套容器级事实。

## Considered Options

- 只在整份资源或文档层绑定：录入量较小，但无法解释具体教学活动或评价证据对应哪个概念。
- 单元和容器都允许人工绑定：表达灵活，但两套绑定会发生漂移并产生冲突真相。

## Consequences

- 评价证据只能归属到具有评价绑定的原子教学资源，不能从容器覆盖推定细粒度掌握状态。
- 长文档若无法定位到内部教学单元，只能声明整体讲解覆盖，不能产生细粒度评价证据。
- 容器覆盖发生变化时由系统重新计算，不需要人工同步。
- 新资源格式必须先定义其原子教学单元，才能进入知识绑定和发布流程。
