# 近义重复候选必须逐组裁定

规范化后同名、规范名称与受控同义词冲突由确定性闸门直接阻断。词法、向量或代理分析识别的近义概念只形成身份候选组，不能按相似度自动合并；每组必须明确裁定为合并或确有区别。确有区别时必须给出不同定义、语义边界和能够反映差异的唯一名称，未裁定候选阻断最终硬闸门。

## Considered Options

- 达到相似度阈值后自动合并：吞吐量高，但容易错误合并名称相近而语义不同的控制概念。
- 只检查完全同名：确定性强，但无法发现拉氏变换与拉普拉斯变换等同义异名。

## Consequences

- 重复扫描必须结合规范名称、受控同义词、定义和语义边界生成候选。
- 已裁定结果写入治理工件；相关名称和边界未变化时，不重复制造相同未决项。
- 相似度分数只能用于排序审查优先级，不能作为身份真相。
- 新增和改名审核必须重新运行全局近义候选检查，并阻断所有新增未决冲突。
