# 优先复用规范身份并永久映射旧节点 ID

重复概念合并时，优先选择一个经过审核的现有节点 ID 作为规范知识 ID，其他仍被活跃引用的旧 ID 通过经审核的身份迁移映射指向该身份。当前资源、进度、笔记和未完成路径引用执行迁移；历史学习事实与已完成路径保留原图谱修订并通过 legacy snapshot 解析。新概念使用与名称和章节无关的稳定隐藏 ID；只有现有身份无法准确代表治理后概念时才创建新 ID。

## Considered Options

- 为所有概念生成全新 ID：形式最整洁，但会扩大资源、证据、路径和历史快照的迁移风险。
- 不迁移历史引用：实施成本最低，但会切断长期学习真相和既有教学资源。

## Consequences

- 身份迁移映射是长期兼容事实，不能在一次回填后随意删除。
- 合并节点的关系、领域归属和活跃资源引用必须先映射再审核，不能简单拼接。
- 历史事实不因节点合并或拆分而重放、去重或复制到新概念。
- 规范名称变化不生成新 ID，身份映射也不能依赖名称模糊匹配。
