# 优先复用规范身份并永久映射旧节点 ID

重复概念合并时，优先选择一个经过审核的现有节点 ID 作为规范知识 ID，其他旧 ID 通过不可丢失的身份迁移映射指向该身份。资源绑定、学习证据和当前路径数据执行回填，历史快照可继续解析旧 ID。新概念使用与名称和章节无关的稳定隐藏 ID；只有现有身份无法准确代表治理后概念时才创建新 ID。

## Considered Options

- 为所有概念生成全新 ID：形式最整洁，但会扩大资源、证据、路径和历史快照的迁移风险。
- 不迁移历史引用：实施成本最低，但会切断长期学习真相和既有教学资源。

## Consequences

- 身份迁移映射是长期兼容事实，不能在一次回填后随意删除。
- 合并节点的关系、领域归属、资源和证据必须先映射再去重，不能简单拼接。
- 一个旧节点若被裁定为混合多个概念，不得把旧证据自动复制给所有拆分后的新概念；此类记录必须重新裁定或标记为歧义历史证据。
- 规范名称变化不生成新 ID，身份映射也不能依赖名称模糊匹配。
