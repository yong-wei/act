# 全部治理完成后一次性替换正式知识基座

当前正式图谱在治理期间保持不变。所有节点身份、领域归属、课程编排、三类关系、规范知识卡、派生卡、资源绑定、活跃引用迁移和 legacy 解析兼容都在非活动候选知识基座中完成；全图确定性闸门、分块审核、跨块审核和独立收尾审核全部清场后，才执行一次性正式切换。业务运行中不提供逐块上线、新旧双读或混合过渡状态。

## Considered Options

- 每个审查块完成后逐块替换：能够较早交付局部改进，但会让新旧身份、关系和资源绑定长期混合。
- 在当前正式图谱原地修改：实现直接，却难以保证中间状态对路径、证据和资源引用始终一致。

## Consequences

- 分块治理成果只是候选工件，任何单块清场都不能触发正式发布。
- 候选知识基座必须在切换前完成全部规范知识卡和资源绑定，不允许上线后再补齐。
- 经审核的 active legacy 映射和活跃引用迁移在同一次切换中生效；历史事实不回填到新图谱。
- 部署可以保留仅用于故障回滚的旧版本快照，但业务不能同时消费两个知识基座版本。
