# 已发布概念只归档不物理删除

合并导致的旧节点退役不重新审核名称不变的保留节点，旧 ID 通过身份迁移映射指向保留身份。没有合并去向的独立删除会改变规范名称集合，必须执行身份审核和引用影响检查；已发布概念只能进入归档状态，不做物理删除，并继续支持历史学习事实解析。

## Considered Options

- 所有删除都免审核：操作简单，但可能在没有替代身份时切断路径和资源引用。
- 直接物理删除并在历史事实保存名称：能够清理数据，但名称不足以恢复当时的概念边界和关系真相。

## Consequences

- 合并退役前必须迁移活动关系、课程编排和资源绑定，并保存旧 ID 到保留 ID 的映射。
- 独立归档前必须确认活动资源、课次编排和直接先修关系已迁移或明确移除。
- 归档概念不能成为新资源绑定、路径规划或课程编排目标，但历史事实仍可引用其身份和修订。
- 归档名称默认保留为历史名称；若未来重新使用相同名称，必须经过身份审核以防语义冲突。
