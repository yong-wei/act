# 关系审核前必须完成概念语义档案

每个候选概念在进入关系审核前必须完成概念语义档案，包括唯一语义名称、严格定义、语义边界、与近邻概念的区分、受控同义词、课程范围依据、至少一个领域归属，以及是否为基础概念及其理由。缺少任一必填语义信息的候选节点不能通过准入闸门。

## Considered Options

- 只要求名称和定义：录入较快，但无法可靠裁定近义合并、限定语和概念边界。
- 定义留到知识卡阶段：可以先构图，却会让关系建立在未确定的概念语义上，随后大量返工。

## Consequences

- 名称限定语必须能够由语义边界和近邻区分解释，不能使用“建模”“分析”等无法独立界定概念的临时标签蒙混过关。
- 受控同义词参与全局冲突检查，不能与其他规范名称冲突或无解释地指向多个概念。
- 关系、知识卡和资源绑定都引用已审核的概念语义档案，不得各自维护不同定义。
- 概念定义或边界发生实质变化时，必须重新评估身份、关系、卡片和资源绑定影响。
