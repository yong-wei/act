# 关联覆盖以语义价值和接入完整性为准

知识基座不设置每个节点必须具有固定数量关联关系的配额。规范知识概念必须通过包含、先修或关联至少一种关系接入图谱，或者被明确裁定为合法基础概念；关联关系只有在能够支持有价值的比较、迁移、应用或解释拓展，并且具有关系依据时才可发布。

## Considered Options

- 每个节点设置最低关联数量：便于量化覆盖，但会激励生成无教学价值的弱关联。
- 不对关联设置硬闸门：维护成本较低，但会保留当前大量仅凭共现或名称相似产生的噪声。

## Consequences

- 关联治理检查语义理由、端点有效性和节点接入完整性，不检查固定边数。
- 数据层保存所有通过审核的有效关联；画布层根据选中节点和相关性限制同时显示的边数。
- 同章出现、名称相似或模型建议只能形成待审核候选，不能单独作为发布依据。
- 没有任何关系的非基础概念必须阻断发布。
