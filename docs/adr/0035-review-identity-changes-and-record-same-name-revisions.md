# 命名变化执行身份审核，同名维护只记录修订

知识基座采用“命名变化必审、命名不变免代理审核”的轻量治理。新增概念、改名和拆分改变规范语义名称集合，必须执行身份审核；合并后保留节点名称不变时，保留节点无需重新审核，被并入 ID 进入身份迁移映射。同一名称下的表述、资源链接、资源绑定、直接先修、包含和关联维护不执行代理审核，也不建立候选发布版本，但必须通过确定性结构闸门并生成带生效时间的不可变知识真相修订。

## Considered Options

- 所有语义和关系变化都建立候选版本并复审：可控性最强，但对日常维护过度工程化。
- 同名修改直接覆盖且不记录：实施最简单，但无法解释修改前学习事实依据的关系和资源真相。

## Consequences

- 名称不变不代表可以绕过名称唯一、关系类型、无环、直接性、端点存在和资源角色等确定性硬闸门。
- 学习事实必须记录其生成时采用的知识真相修订或等价的不可变修订标识；后续修改只影响生效后的新事实。
- 身份审核重点检查规范名称、受控同义词、语义边界和近义冲突，不重复审核未受影响的全图内容。
- 合并导致的旧 ID 退役通过身份迁移映射处理；拆分产生新名称，因此必须重新执行身份审核。
- 知识真相修订是历史可解释性记录，不允许业务同时选择多个活动知识基座。
