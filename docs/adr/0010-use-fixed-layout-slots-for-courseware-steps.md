# 课件步骤采用固定布局模板与模块槽位

规范化课件步骤不使用自由坐标或仅按面积总和判断容量，而是在固定 16:9 网格上选择有限布局模板；每个模板定义互不重叠的模块槽位，模块通过已注册尺寸档位占用匹配槽位。模型只能选择模板、槽位和模块尺寸档位，教师可以切换已注册模板并重新分配槽位，但不能自由拖拽缩放或输入任意坐标；不兼容的模板变更必须通过调整尺寸、删除模块或拆分页解决。确定性门禁验证不越界、不重叠和尺寸匹配。模块内部可在预设可读字号范围内适应内容，并按模块类型与尺寸提供建议文本长度；达到字号下限仍溢出时必须精简内容或拆分课件步骤。该约束牺牲任意排版自由度，以换取在线展示、PDF 导出和自动生成版式的稳定一致。
