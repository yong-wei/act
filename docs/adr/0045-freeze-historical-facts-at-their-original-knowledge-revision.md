# 历史学习事实冻结在其原知识修订

知识基座重建只迁移切换时仍被当前业务读取或继续执行的知识引用。历史 `LearningFact`、事件、诊断、画像、风险、成长、推荐、班级聚合和 Arena 记录继续绑定其原图谱修订；没有可证修订的旧事实通过不可变的 `legacy-unversioned` 或 legacy snapshot 兼容解析，不按新图谱逐行重解释、重放、去重或回填。

切换后产生的新事实必须在写入时绑定唯一活动的新图谱修订。切换门槛只验证这条新写入边界，不要求恢复全库历史 producer、decoder 或 writer 闭包。

活跃引用包括仍被当前业务读取或继续执行的课程、资源、学习进度、笔记和未完成路径引用。已完成路径、历史事件及其派生状态不是迁移输入。

## Considered Options

- 将全部历史事实回填到新图谱：会把今日语义错误地覆盖到当时事实，并扩大隐私、血缘和停机风险。
- 重放历史事件后重新生成派生状态：无法保证旧 producer 与 decoder 的原始语义仍可重现。

## Consequences

- 阶段一权威输入仅包括当前正式课程与已审核范围锚点、当前 authoring 内容与资源、当前发布图谱及绑定迁移比对、活跃知识引用和经审核的 active legacy ID 映射。
- 本系列不生成、不消费、不验证历史 decoder、lineage、writer、事实/事件或派生状态诊断目录；外部独立治理可另行存在，但不属于本系列工件、输入或验收。
- 新旧图谱不并行生成事实；切换后只有一个活动新修订可用于新事实写入。
- 0030、0031 和 0037 中关于全历史回填、重放或全量历史硬闸门的要求由本 ADR 取代。
