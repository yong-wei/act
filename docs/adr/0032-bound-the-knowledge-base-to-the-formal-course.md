# 正式知识基座受课程知识边界约束

正式知识基座只发布属于正式课程能力目标、为理解这些目标所必需的基础概念，以及具有明确学习目标或正式教学资源的拓展概念。旧图谱中仅因历史存在、教材偶然提及或可能未来使用而保留的节点不自动进入新知识基座；它们作为归档概念保留历史身份和迁移记录。

## Considered Options

- 保留现有图谱中所有语义成立的控制理论概念：覆盖广，但会迫使课程为缺少实际用途的概念制作卡片、关系和资源。
- 只保留已有卡片或资源的概念：实施范围小，但会遗漏尚未完成资源建设的必要课程目标和先修基础。

## Consequences

- 每个候选概念必须提供课程目标、必要先修或明确拓展用途中的至少一项范围依据。
- 归档概念不参与活动图谱、路径规划和新资源绑定，但旧 ID 仍可通过历史迁移信息解释。
- 拓展概念与核心概念执行相同的名称、领域、关系、知识卡和资源绑定发布闸门。
- 新增超出当前课程知识边界的概念必须先完成课程范围变更，不能由资源生成过程顺带创建。
