# 每个已发布概念使用一张规范 Markdown 知识卡

每个已发布规范知识概念必须恰好对应一张通过审核的规范 Markdown 知识卡。该卡片是概念内容的可审查真源；生成式知识卡、信息图和其他视觉版本是带来源版本的派生知识卡，可以有多个，但不能成为并列真源。治理中的草稿概念可以暂时没有卡片，未完成规范卡片的概念不能正式发布给学生或被新教学资源引用。

## Considered Options

- Markdown 卡与生成式卡并列为真源：视觉表达灵活，但内容发生冲突时无法确定课程真相。
- 一个概念允许多张独立卡片：适合多种讲法，却会把资源变体重新混入概念身份和内容治理。

## Consequences

- 规范知识卡与规范知识 ID 建立一对一约束，且必须具有明确版本。
- 派生知识卡必须记录规范卡版本；源卡变化后，旧派生物必须重新验证、重新生成或明确失效。
- 知识概念发布闸门必须同时验证节点、领域归属、关系和规范知识卡。
- 多种讲法、案例和练习作为普通教学资源绑定同一概念，不创建第二张规范卡。
