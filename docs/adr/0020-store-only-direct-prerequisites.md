# 只存储直接先修并动态计算传递关系

知识基座只保存具有独立教学依据的直接先修关系，所有间接先修通过无环先修路径动态计算。课程中的相邻教学顺序不自动构成先修关系；每个非基础概念必须能够沿直接先修关系追溯到至少一个基础概念。

## Considered Options

- 保存全部直接和间接先修：查询简单，但会制造大量冗余边，使人工审核、图谱显示和关系迁移难以维护。
- 按课程顺序连接相邻知识点：容易生成路径，但会把教学安排误写为理解依赖。

## Consequences

- 先修关系必须构成有向无环图；自环和循环依赖阻断发布。
- 生成器和治理脚本必须检测可由其他路径完全推导的冗余先修候选。
- 图谱、路径规划和资源推荐通过传递闭包计算完整先修范围，但不得把计算结果写回为事实边。
- 没有先修入边的节点必须被明确裁定为基础概念，否则视为未完成治理。
