# 明确资源绑定确定性迁移，歧义绑定分块审核

现有资源若具有明确旧节点 ID、该 ID 能够一对一映射到规范知识 ID，且资源类型合同能够确定讲解、练习、评价或引用角色，则执行确定性迁移。旧节点拆分、自由文本知识点、一个旧 ID 对应多个新概念、角色无法确定或完全缺少绑定的资源，形成歧义资源绑定并交由代理分块审核；名称相似和模型建议不能直接发布为正式绑定。

## Considered Options

- 每条绑定全部由代理重审：质量可控，但会重复审核大量已有明确来源的一对一映射。
- 所有绑定由模型推断并抽样检查：吞吐量高，但无法证明未抽样资源的教学角色和概念边界正确。

## Consequences

- 确定性迁移规则必须显式列出可接受的来源字段、身份映射和资源类型到绑定角色合同。
- 旧节点一拆多时，原资源绑定不能复制到所有新概念，必须阅读原子教学资源后裁定。
- 缺失绑定的资源可以由模型生成候选，但必须经过代理审核才能写入作者真源。
- 最终硬闸门对确定性迁移和代理审核结果执行相同的端点、角色、覆盖和反查一致性验证。
