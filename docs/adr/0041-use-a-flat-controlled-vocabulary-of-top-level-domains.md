# 知识领域采用扁平受控顶级词表

知识基座使用一组具有唯一名称、定义和纳入边界的扁平顶级知识领域。领域不形成父子树，概念细分由规范知识概念之间的包含关系表达；跨领域概念通过多领域归属进入多个领域视图。首页只展示顶级领域。

## Considered Options

- 允许领域形成多级层次：可以表达更细分类，但会与概念包含层级重叠，并重新混合不同抽象尺度。
- 使用自由标签自动聚类：扩展灵活，但无法形成稳定首页入口和可验证的领域归属。

## Consequences

- 每个领域必须具有规范名称、简短定义和明确纳入边界，领域名称不得混入课程模块、课次或教学组织视图。
- “课程全景”“建模专题速通”“知识边界与方法迁移层”等如需保留，只能作为课程编排或专题筛选，不进入领域词表。
- 领域词表变化需要检查所有概念归属和首页导航，但不改变规范知识 ID。
- 领域内部不创建子领域节点；需要层级浏览时使用概念包含图。
