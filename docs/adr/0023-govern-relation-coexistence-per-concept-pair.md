# 同一概念对执行关系兼容约束

同一概念对、同一关系类型只能存在一条规范关系。关联关系不得与包含或先修关系并存；包含和先修互不推导，只有在二者分别具有独立、可复核依据时才允许同时存在。关联按无序端点唯一化，不能同时保存两个方向的副本。

## Considered Options

- 每个概念对最多一种关系：最容易理解，但会丢失少数同时具有真实概念层级和直接学习依赖的情况。
- 三种关系任意并存：表达自由，但会重新产生当前 `related + 具体关系` 的冗余和视觉歧义。

## Consequences

- 发布门禁必须验证关系三元组唯一性、关联无序端点唯一性和关系兼容矩阵。
- 从旧关系迁移时，已有具体关系的概念对默认淘汰泛化关联候选。
- 包含与先修并存必须分别提供层级依据和学习依赖依据，不能由一条理由同时推定两种关系。
