# 全局重复预扫描后按语义邻近划分审查块

知识治理先对全量节点执行重复候选扫描。规范化精确同名和已审核受控同义词形成不可跨块拆分的身份等价分量；高度近义只形成分量之间的评审边，可以跨块。随后按语义邻近和关系连通性将等价分量划分为每块约四十至八十个候选概念的临时审查块。所有块完成后再次执行全局重复扫描，防止分块边界遗漏语义冲突。

## Considered Options

- 直接按当前知识领域分块：便于分工，但当前领域本身待治理，并会让跨领域同义节点由不同代理竞争裁定。
- 按课程模块和课次分块：贴近教学材料，却会把课程编排重新当作概念身份边界。

## Consequences

- 全局身份等价分量生成是任何并行块审核的前置条件。
- 一个身份等价分量只能由一个审查块负责；跨块高度近义边进入单独审核，不能自动合并分量。
- 多领域归属在概念所属审查块中审核，不为每个领域复制审核对象。
- 块大小是上下文容量目标，可以因不可拆分的等价分量和语义连通性适度调整，不构成运行时限制。
- 分块结果合并后必须重新运行全局名称唯一和近义重复检测。
