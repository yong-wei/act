# 知识概念采用多领域归属且不设强制主领域

每个规范知识概念必须至少归属一个知识领域，并可同时归属多个领域，不指定唯一主领域。领域是知识分类和浏览投影，不拥有概念身份；同一概念在多个领域出现时引用同一个规范知识 ID，不复制节点。

## Considered Options

- 一个主领域加多个次领域：便于单一导航归类，但会迫使跨领域概念接受任意的主次判断。
- 每个概念只属于一个领域：实现简单，但会重新引入当前以复制节点表达跨领域复用的问题。

## Consequences

- 领域首页和领域内部图谱必须按领域归属投影同一规范节点，不能生成领域专属副本。
- 领域调整不改变规范知识 ID，也不迁移概念本身。
- 发布硬闸门必须阻止没有任何领域归属的规范知识概念。
