# Markdown 知识卡全覆盖，视觉卡按教学价值制作

每个已发布规范知识概念必须具有一张规范 Markdown 知识卡。生成式视觉卡只用于具有关键结构、过程、比较、路径、图形或高密度总结价值的概念；不适合视觉化的概念记录简短理由，不强制生成装饰性图片。派生视觉卡不改变规范 Markdown 卡的内容真相。

## Considered Options

- 每个概念同时强制视觉卡：界面覆盖统一，但会增加低价值图片、数学误导和大规模审核成本。
- 只保留 Markdown 卡：内容最稳定，但会错失结构图、路径图和高密度信息图的教学价值。

## Consequences

- 视觉化适用性必须逐概念裁定，制作或不制作都留下明确结论。
- 生成式卡必须经过数学正确性、文字准确性、概念边界和视觉误导检查。
- 坐标图、响应曲线、根轨迹和其他要求数值或几何准确性的图形使用原生绘制或规范绘图工具，不由图像模型自由生成。
- 规范 Markdown 卡变化后，相关视觉卡必须重新验证、重新生成或标记失效。
