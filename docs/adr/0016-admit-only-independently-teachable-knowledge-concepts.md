# 只将具有独立教学价值的内容建为知识概念

候选内容必须可独立定义并能够独立教学或评价，才有资格进入知识基座；单独成为关系端点不足以准入。候选还必须以正式课程目标、必要先修或明确拓展之一作为范围锚点。公式片段、普通例子、性质、章节标题和概念的简单属性作为知识卡片或教学资源中的支持性内容，不为追求术语穷举而单独节点化。

## Considered Options

- 穷举所有术语、公式和例子：检索粒度更细，但会制造大量缺少独立教学意义的节点，稀释学习路径并增加关系噪声。
- 只保留课程章级主题：结构简单，但不能支持细粒度评价、资源绑定和先修路径。

## Consequences

- 节点准入必须提供独立定义、教学或评价价值，以及 `formal_objective`、`necessary_prerequisite` 或 `explicit_extension` 类型的范围锚点。
- 例题、案例和教学材料通过资源绑定关联知识概念，不以复制知识节点的方式进入图谱。
- `contains` 不能用于表达章节收录或资源提及，只能在后续关系规则允许的真实概念结构中使用。
- 关系端点身份不能替代范围锚点；公式、例子、性质和章节标题不能只因被关系引用而节点化。
