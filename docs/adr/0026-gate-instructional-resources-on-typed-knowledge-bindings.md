# 教学资源必须具有非引用知识绑定

所有教学资源发布前必须绑定至少一个已发布规范知识概念，并具有与资源用途相符的讲解、练习或评价角色；仅有引用绑定不能通过发布闸门。封面、导航、版权说明、纯布局组件和运行配置等可以显式分类为非教学资产并豁免绑定，但不得进入学习路径、教学资源推荐或掌握证据。

## Considered Options

- 所有文件和组件一律绑定：规则表面统一，但会迫使非教学资产制造虚假知识关系。
- 只对习题强制绑定：无法保证讲义、视频、仿真和知识卡能够被知识基座反查和路径选择。

## Consequences

- 讲义、知识卡、视频和仿真至少需要讲解绑定；练习和互动任务至少需要练习绑定；声称产生掌握证据的资源至少需要评价绑定。
- 资源生成器必须先接收已发布规范知识 ID 及预期绑定角色，再开始生成，不能在生成后以名称猜测知识点。
- 非教学资产豁免必须显式声明并通过类别检查，不能把缺失绑定自动解释为豁免。
- 作者态、导出态、数据库写入和发布态必须执行同一绑定闸门。
