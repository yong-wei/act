# 先修条件支持组内合取和组间析取

一个目标概念可以声明一个或多个先修要求组。同一组内的直接先修必须全部满足，不同组之间满足任意一组即可进入目标概念；未显式声明替代组时，目标概念的全部直接先修属于同一默认组。多条学习路径由真实的替代知识准备方式产生，不以随机调整同一批节点顺序伪造。

## Considered Options

- 所有入边全部必修：模型简单，但不能表达不同知识背景通向同一目标的替代入口。
- 任意一条入边满足即可：路径数量多，但会把必要的组合条件错误地弱化。

## Consequences

- 先修关系数据必须能够标识所属要求组，同时保持关系类型仍为“先修”。
- 路径规划、解锁判断和学习状态计算必须按组内合取、组间析取执行。
- 每个替代组都必须独立通过课程语义审核，证明其足以支持目标概念，而不是仅为了增加路径数量。
- 先修覆盖审计既要验证图可达性，也要验证每个要求组完整、非空且没有循环依赖。
