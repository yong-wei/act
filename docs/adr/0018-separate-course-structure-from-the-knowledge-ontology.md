# 将课程模块和课次编排与知识本体分离

现有章节在领域语言中统一称为课程模块，模块下组织课次。课程模块和课次不作为知识图谱节点；课次通过可编辑、可过滤的多对多课程编排关联引用规范知识概念。领域图谱以知识领域为顶级入口，课程界面可按模块或课次过滤同一组规范知识概念。

## Considered Options

- 将章节保留为知识图谱顶层节点：可以直接复用现有结构，但会继续混淆课程顺序、知识分类和概念层级。
- 在知识概念上保留单值 `chapter`：过滤简单，但无法表达同一概念在多个模块或课次中被引入、深化和复习。

## Consequences

- 课程模块与课次属于具体课程版本；调整课程编排不改变规范知识 ID。
- 同一规范知识概念可以被多个模块和课次引用，无需创建章节副本。
- 现有 `chapter` 元数据仅可作为离线审计和迁移输入；一次切换后正式运行态与数据库读模型不得继续消费该字段。
- `contains` 不用于表达模块、课次与知识概念之间的课程收录关系。
