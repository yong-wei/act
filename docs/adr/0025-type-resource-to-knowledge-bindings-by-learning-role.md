# 资源与知识概念的绑定使用四种教学角色

教学资源通过讲解、练习、评价或引用四种角色绑定已发布的规范知识概念。一项资源可以绑定多个概念，同一资源与概念之间也可以具有多个真实角色。无类型的“相关知识点”列表不再作为正式绑定事实。

## Considered Options

- 只保存无类型的相关知识点：录入简单，但无法支持资源选择、学习证据和路径规划的不同语义。
- 只区分主要与次要知识点：能够表达权重，却不能说明资源是在教授、练习还是评价概念。

## Consequences

- 所有正式绑定必须引用已发布的规范知识 ID，不能以自由文本名称代替。
- 知识点详情页可以按讲解、练习、评价和引用分类反查资源。
- 路径规划、教师指派和学习证据只能消费与用途匹配的绑定角色。
- 历史资源中的 `knowledgeNodeIds` 和相关知识点文本必须迁移为带角色的绑定，无法判断角色的记录进入人工裁定。
