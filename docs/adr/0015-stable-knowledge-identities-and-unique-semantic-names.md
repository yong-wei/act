# 知识概念采用稳定身份与唯一语义名称

知识基座中的每个规范知识概念使用不可变、用户不可见的规范知识 ID，并使用面向人的唯一语义名称。语义名称不得充当持久主键；概念改名不改变身份。同名概念以及名称不同但语义实质相同的概念必须合并，语义名称冲突作为发布硬闸门；只有确有独立教学意义的概念才允许保留为不同节点，并通过语义限定语说明实质差异。

## Considered Options

- 采用语义名称作为主键：形式直观，但术语调整会迫使关系、资源、学习证据和历史快照整体迁移。
- 保留名称加章节或随机编码：能够避免技术冲突，但会把同一概念拆成多个身份，并向内容生产者暴露无语义编码。

## Consequences

- 章节和知识领域只能引用规范知识概念，不能通过复制节点表达复用。
- 所有节点导入、资源绑定和发布流程必须验证语义名称唯一性，并检测同义、近义的重复候选。
- 历史节点合并必须保留旧 ID 到规范知识 ID 的迁移映射，以维护既有资源和学习证据。
