# 概念层级采用允许多父的直接包含无环图

包含关系形成允许多父的有向无环图，并且只保存直接包含。一个规范知识概念可以具有多个独立成立的直接父概念；祖先关系动态计算。包含自环、循环和可由其他包含路径完全推导的冗余边必须阻断发布。

## Considered Options

- 严格单父树：布局和导航简单，但会迫使跨结构概念接受任意父级或产生节点副本。
- 不限制循环和冗余：录入自由，但无法形成可解释、可计算的概念层级。

## Consequences

- 包含关系审核必须验证端点语义、无环性、直接性和多父关系的独立依据。
- 领域视图可以为布局选择当前上下文中的显示父级，但不得删除或复制数据层中的其他真实父级。
- 包含关系的传递闭包用于层级查询，不写回 canonical 关系源。
