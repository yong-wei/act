# 知识基座采用分块并行审核和全图收尾审核

知识节点数量较大，治理工作采用知识审查块分割有限上下文。每个块先通过确定性闸门，再由课程教学审核代理和独立审核代理分别复核；块内关系随块审核，跨块关系在端点身份稳定后单独并行审核。全部结果合并后必须执行全图确定性检查和独立收尾审核，冲突、低置信度判断和高影响合并交人工裁定。

## Considered Options

- 一次性审核完整图谱：全局视野完整，但超出稳定上下文容量，容易遗漏细节并产生不可复现判断。
- 每个分块独立发布：吞吐量高，但无法发现跨块重复、循环、路径断裂和关系冲突。

## Consequences

- 知识审查块是治理工件，不得成为知识领域、课程模块或节点属性。
- 一个候选概念在一轮治理中只能由一个审查块负责身份裁定，防止并行代理产生竞争性合并结果。
- 跨块关系必须等待两个端点的规范知识身份确定后审核。
- 分块清场不是全图发布证据；全局名称唯一、包含无环、先修无环、路径覆盖、关系兼容、资源迁移和跨块一致性必须在收尾审核中重新验证。
- 生成者不能兼任同一块的独立审核者；并行审核结论必须保留可合并的结构化证据。
