# 附件 2：开发与应用报告

## 一、开发背景

“自动控制原理”课程长期存在三个难点：一是微分方程、传递函数、根轨迹、频域判据等内容抽象，学生容易把知识点记成孤立公式；二是课堂仿真、课后练习和工程案例分散，教师难以看到学生在建模、调参、约束判断中的真实思维过程；三是生成式 AI 已进入学习场景，但如果只作为通用聊天工具使用，容易变成直接给答案，无法形成可解释的学习证据。

本案例以船舶控制工程为主线，建设 AI-OBE 船舶智控平台。平台把互动课堂、3D 虚拟仿真、知识图谱、课堂数据采集、能力画像和生成式 AI 辅助连接起来，用信息系统支撑“看见对象、操作参数、解释现象、反思决策”的学习过程。

## 二、设计与开发

### （一）平台与技术选择

系统采用 Next.js 14、TypeScript、PostgreSQL、Prisma 构建教学平台主干，使用 Rust/WASM 承担船舶动力学、控制响应和数值分析等高频计算，使用 Three.js 与 React Three Fiber 呈现 3D 仿真场景。AI 能力通过 Vercel AI SDK 接入 SiliconFlow API，默认模型为 deepseek-ai/DeepSeek-V4-Flash。课堂运行采用 DB BOPPPS 教案、TeachingResource 资源注册和 ClassSession 会话同步，学习数据进入 InteractionLog、LearningFact、StudentCompetencySnapshot 等结构化表。

### （二）开发过程

开发过程围绕“教学问题 -> 课程活动 -> 数据证据 -> AI 反馈”展开。首先借助生成式 AI 梳理课程痛点、教学目标和工程场景，形成船舶航向控制、邮轮舒适度控制、破冰船鲁棒性等任务。其次按 BOPPPS 组织互动课，设计前测、显影推导、参数操作、后测和总结。再次编写仿真模型与前端交互，将实时步进迁入 Rust/WASM，保证同一模型既能服务课堂互动，也能服务数值 API 和评估分析。最后设计事件协议，把学生查看、参数调整、提交、AI 提问、仿真完成等行为转化为学习事实，再计算六维能力画像。

AI 开发证据主要体现在三类提示词：需求拆解提示词用于把课程难点转为系统功能；实现提示词用于生成页面、接口、数据结构和测试方案的初稿；教学提示词用于约束“控灵”只做引导、验证和追问，不直接替代学生完成推理。系统运行时的 AI 工具支持读取仿真状态、提出参数修改建议、分析仿真结果和检查建模答案，关键提示词与截图可随配套资源提交。

### （三）功能架构

平台包含六个核心模块。第一，精品互动课堂模块，支持课程入口、教师端、学生端、课堂码、步骤级活动与知识卡片。第二，虚拟仿真模块，覆盖驱逐舰、邮轮、集装箱船、LNG 船、挖泥船、钻井平台、破冰船等场景。第三，AI 学习助手“控灵”，接收当前页面、课程阶段、学生画像和仿真状态，给出引导式反馈。第四，数据治理模块，将课堂事件沉淀为 LearningFact，并生成学生六维能力画像。第五，教师学情分析模块，提供班级能力分布、风险学生、个体诊断和建议。第六，资源与知识图谱模块，支持运行时课程资源、知识卡片、讲义和多媒体资源统一调用。

## 三、应用过程与效果

应用时，教师先从预置教案创建课堂，学生通过课堂码进入互动课。学生在页面中完成前测、公式推导、对象判断、参数调整和仿真实验；系统同步记录关键事件。AI 助手根据当前步骤和学生行为进行提问式反馈，例如在学生提交建模方程后指出缺少惯性项、阻尼项或重力矩项，在仿真结束后结合平均误差、舵角速度、超调和调节时间分析参数风险。课后，学生可在个人中心查看六维能力画像和个性化补强路径，教师可在班级学情页查看整体分布与个体诊断。

已形成的应用价值包括：抽象知识可视化，学生能在极点、时域、频域和工程对象之间建立联系；教师获得过程性数据，不再只依赖最终作业分数判断学习状态；AI 从通用问答转为带课程上下文、仿真状态和能力画像的学习支持；平台资源可以持续复用到不同课次，降低后续建设成本。正式报送前应补充真实班级规模、使用次数、问卷反馈、学生作品和教师访谈截图。

## 四、创新与反思

本案例的创新点在于把生成式 AI 放进完整教学信息系统，而不是孤立聊天窗口。AI 既参与开发过程，也在运行时读取课程、仿真和画像上下文；Rust/WASM 数值内核保证仿真结果稳定可复现；LearningFact 和六维能力画像使学习过程能够解释、追溯和反馈；船舶控制场景把控制理论、工程约束和伦理安全连接起来。

当前仍有三点需要继续改进：一是应用成效还需用更完整的真实班级数据支撑；二是配套资源在无法公开完整代码时，需要提供足够详细的流程、截图和提示词，使他人能够复现关键思路；三是学生隐私保护必须贯穿演示视频和资源包，所有截图应脱敏，不出现学生正面画面，AI 生成的文本、图片、视频、音频和动画均应标记“AI 生成”。
