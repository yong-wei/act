## 案例内容简介

本案例面向高等教育“自动控制原理”课程，建设 AI-OBE 船舶智控平台。系统以船舶航向、邮轮舒适度、破冰船鲁棒性等工程场景为载体，提供 3D 虚拟仿真、精品互动课堂、知识图谱导学、课堂事件采集、学生七维 portrait v2 主画像、教师班级学情分析和“控灵”AI 学习助手。平台接入国产大模型服务，支持仿真状态读取、建模答案检查、参数分析和个性化学习建议，帮助学生从公式记忆转向工程判断，帮助教师基于真实过程数据开展分层指导。
