# 配套资源说明

本资源包按“无法提供完整代码”的情况组织，目标是让评审者理解系统如何开发、如何使用、如何安装、如何复现关键流程。后续可将本目录导出为 PDF，并连同截图、视频和必要的脱敏配置打包为 ZIP。

## 资源结构

| 文件 | 内容 |
| --- | --- |
| `development-process.md` | 完整开发流程、模块划分、复现步骤 |
| `prompt-pack.md` | 生成式 AI 辅助开发与运行提示词 |
| `screenshot-list.md` | 所需截图与录屏清单 |
| `user-manual.md` | 教师、学生、管理员使用手册 |
| `installation-manual.md` | 本地与服务器安装手册 |
| `development-record.md` | 关键开发记录、测试验证和隐私合规记录 |

## 截图与代码替代说明

如无法提供完整代码，应提交以下证据：

1. 系统整体架构图。
2. 关键页面截图：课程入口、教师端、学生端、仿真页、AI 助手、个人中心、教师学情页、管理员统计页。
3. 关键数据结构截图：事件采集、学习事实、能力画像。
4. 关键提示词截图：需求拆解、AI 助手系统提示词、建模检查提示词、开发调试提示词。
5. 关键验证截图：单元测试、构建、浏览器验收、隐私脱敏检查。

所有截图应去除学生姓名、手机号、学号全量信息、访问令牌、API Key、数据库连接串和服务器地址。
