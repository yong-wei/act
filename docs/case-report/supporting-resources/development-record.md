# 开发记录

## 1. 关键迭代

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| 课程框架统一 | 建立 DB BOPPPS、资源注册、课堂会话主干 | 统一课程运行链路 |
| 精品互动课建设 | 建设课程入口、教师页、学生页、知识卡片与互动步骤 | 可复用互动课堂样板 |
| 虚拟仿真升级 | 将船舶仿真实时步进迁入 Rust/WASM | 稳定可复现的数值内核 |
| AI 助手接入 | 接入 SiliconFlow API 与 Qwen 模型，支持工具调用 | 控灵上下文学习助手 |
| 数据治理建设 | 设计 LearningEvent、LearningFact、六维能力画像 | 学生画像和教师学情分析 |
| 运维与验证 | 补充 lint、test、build、Playwright 与部署脚本 | 可验证、可部署的系统状态 |

## 2. 关键验证

正式提交前建议补齐以下截图或日志摘要：

- `npm run lint` 通过。
- `npm run test` 通过。
- `npm run build` 通过。
- Rust 控制内核 `cargo test` 通过。
- WASM 构建通过。
- Playwright 完成课程入口、学生课堂、教师课堂、仿真页面浏览器验收。
