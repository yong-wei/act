# 提示词资源

以下提示词用于证明案例开发和运行过程中的生成式 AI 使用方式。正式提交时建议配合截图，标注“AI 生成”。

## 1. 需求拆解提示词

```text
请以高等教育“自动控制原理”课程为对象，分析学生在微分方程建模、传递函数、根轨迹、频域判据和控制器设计中的真实学习困难。请把困难转化为智能信息系统功能需求，输出学生端、教师端、管理员端三类用户场景，并说明哪些行为数据可以作为学习证据。
```

## 2. 课程互动设计提示词

```text
请把“船舶航向控制 PID 参数整定”设计为 90 分钟互动课堂。要求包含前测、对象建模、参数操作、仿真观察、AI 反馈、后测和总结。每一步说明学生操作、教师可见数据、系统记录的事件字段，以及该事件如何贡献到能力画像。
```

## 3. AI 助手系统提示词摘要

```text
你是 AI-OBE 平台的智能学习助手“控灵”。你的职责是协助学生理解自动控制原理，回答课程概念、公式和方法问题，引导学生独立思考，而不是直接给出答案。你可以读取当前仿真状态、分析仿真结果、提出参数修改建议。回答应简洁，使用 Markdown 和 LaTeX，优先提问和解释依据。
```

## 4. 建模检查提示词摘要

```text
你是自动控制原理的总工程师，负责审核学生的方程建模。请检查学生答案是否包含惯性项、阻尼项、弹性项或重力项，符号和导数阶次是否正确，是否考虑必要的线性化。不要求格式完全一致，只要物理意义正确即可。错误时指出具体问题，但不要直接给完整答案。
```

## 5. 仿真结果分析提示词

```text
请分析以下船舶航向控制仿真结果：控制模式、PID 参数、诺莫托模型参数、平均航迹误差、最大舵角速度、超调量、调节时间和仿真时长。请判断控制性能是否达标，是否存在过调、震荡或安全隐患，并给出具体参数调整建议。
```

## 6. 开发调试提示词

```text
请审查以下互动课堂事件采集接口设计。重点检查：是否能稳定记录查看、互动、参数调整、提交、AI 提问、完成和异常；是否能避免非法 resourceId 导致数据库外键错误；高价值事件如何同步沉淀为 LearningFact；哪些字段需要脱敏。
```

## 7. 隐私合规提示词

```text
请检查以下演示视频脚本和截图清单是否存在学生隐私风险。要求不出现学生正面画面、不展示手机号、完整学号、访问令牌、API Key、数据库连接串和真实服务器敏感地址。凡 AI 生成的文本、图片、视频、音频和动画，均需标记“AI 生成”。
```
