# 使用手册

## 1. 教师使用流程

1. 登录教师账号。
2. 进入教师工作台，选择预置教案或已有课程。
3. 创建课堂，生成课堂码。
4. 课堂中推进 BOPPPS 环节，查看学生提交、作答分布和互动状态。
5. 在需要时释放答案、查看 AI 辅助反馈或调整课堂节奏。
6. 课后进入班级学情页，查看班级能力分布、风险学生和个体诊断。

## 2. 学生使用流程

1. 登录学生账号或使用课堂码加入课堂。
2. 按页面步骤完成前测、阅读、推导、互动操作和提交。
3. 在仿真页面调整参数，观察航向、舵角、误差、超调和调节时间。
4. 使用“控灵”AI 助手时，先提交自己的判断，再查看 AI 反馈。
5. 课后进入个人中心，查看七维 portrait v2 主画像、薄弱点、证据限制和推荐资源。

## 3. 管理员使用流程

1. 登录管理员账号。
2. 进入管理后台查看用户、系统使用量和数据治理状态。
3. 检查事件采集、学习事实、队列健康和能力画像更新情况。
4. 根据需要导出脱敏统计，用于教学改进和案例申报。

## 4. 注意事项

- 不在公开演示中展示真实学生姓名、手机号、完整学号、访问令牌或 API Key。
- AI 反馈仅作为学习引导，最终教学判断由教师完成。
- 若 AI 服务未配置或不可用，平台应保留基础课堂、仿真和数据记录能力。
