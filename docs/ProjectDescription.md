# AI-OBE 船舶智控平台项目说明

## 1. 项目愿景
AI-OBE (Artificial Intelligence - Outcome Based Education) 船舶智控平台是一个结合了**工程教育认证 (OBE)** 理念与**人工智能辅助教学**的综合性教育平台。本项目旨在通过高保真的虚拟仿真、个性化的 AI 学习路径以及伦理意识的培养，解决传统船舶控制工程教育中理论与实践脱节、伦理教育缺失等痛点。

## 2. 核心功能模块

### 2.1 船舶战术机动仿真 (Destroyer Tactical Maneuvering)
*   **高保真物理引擎**：基于 Nomoto 模型和叠加正弦波（Sum of Sines）算法，模拟真实的海浪浮力、船舶操纵响应及流体阻力。
*   **动态控制任务**：
    *   **直角转向**：测试控制系统对阶跃信号的响应能力。
    *   **复杂避障**：在动态海况下执行多段变向机动。
    *   **定常回转**：模拟标准的回转试验，验证船舶的回转性能。
*   **ACTE 评价体系**：引入平均航迹误差 (Average Cross-Track Error) 作为客观评分标准，实时反馈控制精度。
*   **可视化数据分析**：提供实时的航向、航速、舵角曲线图，支持控制算法（PID）参数的在线调优。
*   **快速仿真模式**：在曲线视图中通过关键点设定期望航向角，一键计算期望/实际航迹与航向曲线，并可回写为场景仿真参数。

### 2.2 知识图谱 (Knowledge Graph)
*   构建了覆盖船舶动力系统、控制理论、海洋环境等领域的结构化知识库。
*   支持可视化探索，帮助学生建立知识点之间的关联认知。

### 2.3 虚实实验室 (Virtual Lab)
*   汇总现有模型清单与仿真入口，统一管理虚拟/实体实验任务链状态。
*   覆盖半潜平台、破冰船、挖泥船、LNG船、集装箱船、豪华游轮与驱逐舰等典型船型。
*   支持 WebGL 3D 渲染，无需安装插件即可在浏览器中体验沉浸式仿真。

### 2.4 AI 工坊 (AI Workshop)
*   集成 AI 助教功能，基于大模型提供实时的答疑解惑、代码辅助和学习路径推荐。
*   支持个性化学习诊断，生成能力雷达图和成长建议。

### 2.5 思政沙盘 (Ethics Sandbox)
*   首创工程伦理决策模拟，通过两难场景（如自动驾驶事故责任、海洋环保与开发的平衡）培养学生的社会责任感。
*   结合案例库与决策树，量化评估学生的伦理决策能力。

## 3. 技术架构
*   **前端**：Next.js 14 (App Router), TypeScript, Tailwind CSS, Shadcn/ui, Three.js / React Three Fiber.
*   **后端**：Next.js API Routes, Prisma ORM.
*   **部署**：Docker 容器化部署，支持 CI/CD 流水线。

## 4. 创新点
1.  **所见即所得的仿真**：将复杂的数学模型转化为直观的 3D 交互体验。
2.  **全过程数据驱动**：从操作行为到学习结果，全程记录并分析，实现精准教学评价。
3.  **价值引领**：将思政教育无缝融入专业技能训练，实现立德树人。
