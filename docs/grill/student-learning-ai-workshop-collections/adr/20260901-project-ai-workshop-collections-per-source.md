# AI 工坊学习集合按来源独立投影

AI 工坊将任务、路径里程碑、成就、实验和学习日志作为相互独立的服务端投影集合，每个集合携带自身的来源状态和可追溯身份。已有画像或证据摘要只能说明对应摘要可用，不能授权其他集合显示个人记录；未确认的推荐候选、反思草稿和客户端预演也不能晋升为学习集合。该边界允许复用现有作业、学习路径、档案证据和成长记录来源，同时避免用一个聚合状态掩盖某个来源缺失。

## Considered Options

- 继续保留空面板并只提供跳转：能够避免虚假数据，但长期无法兑现 AI 工坊“学习证据与课程任务同一工作区”的产品职责。
- 仅依据整体 Learner State 状态填充全部面板：拒绝，因为画像、路径、作业、仿真和反思具有不同的权威来源与可用性。
- 将所有 GrowthRecord 或反思草稿直接映射到现有面板：拒绝，因为记录类型和生命周期不等价，容易把派生画像变化或未确认草稿误称为任务、成就或日志。

## Consequences

实现需要为每个集合定义学生安全的来源映射、状态和导航；没有合格来源的集合继续显示诚实的暂无或不可用状态。第一版不新增学习事实、不改变画像、评分、排行榜或草稿晋升规则。
