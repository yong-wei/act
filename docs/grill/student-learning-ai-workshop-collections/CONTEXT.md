# AI 工坊受治理学习集合

该上下文定义 AI 工坊中任务、路径进度、成就、实验和学习日志的学生可见集合，确保每条记录都来自当前学生的可追溯学习过程。

## 领域语言

**受治理学习集合**：
由服务端按当前学生身份从已持久化、可追溯的学习来源投影出的同类记录集合；每个集合独立保留可用、暂无记录或来源不可用状态。
_避免_：默认数组、样例集合、跨来源拼装记录

**学习任务记录**：
教师已发布给当前学生的作业，或当前学生已采用并持久化的学习路径任务；它保留来源、状态和可达行动。
_避免_：推荐候选、演示任务、仅存在于浏览器的任务

**学习里程碑**：
当前学生持久化学习路径中具有明确顺序和完成状态的阶段节点；它不由任务数量或画像分数临时推算。
_避免_：合成航线、统计百分比、未采用的候选路径

**受治理实验记录**：
当前学生已持久化且满足展示资格的仿真或竞技场运行摘要，保留来源类型、发生时间、结果性质和可展示参数。
_避免_：客户端预演样例、他人记录、把预览分数称为官方成绩

**学习日志记录**：
当前学生明确保存并已进入可展示学习记录生命周期的反思、伦理或成长记录；未确认的 AI 候选和可编辑草稿不属于学习日志。
_避免_：Copilot 对话、反思草稿、自动生成日志

**受治理成就记录**：
由持久化成就、证书或明确的达成事实投影出的学生记录；没有独立权威来源时保持暂无记录，不从分数或画像推断徽章。
_避免_：推断成就、锁定徽章列表、样例奖励

**集合来源状态**：
单个受治理学习集合自身的读取状态，用于区分已有记录、确认无记录和来源不可用；一个集合可用不能授权其他集合显示零值或个人事实。
_避免_：页面整体状态、空数组即无记录、静默降级
