# 学情精准诊断访谈上下文

## 目标

为教师助教场景建立受治理的学情诊断后端。教师应能在其当前班级范围内获取班级或学生诊断证据，并持久化结构化报告。

## 已确认约束

- 诊断以教师主动请求为入口。
- 后台扫描器只维护确定性风险，不生成报告。
- 当前风险类型仅为 `constraint`、`stagnation` 和 `cross_domain`。
- `participation`、`ai_misuse` 为历史审计类型，不进入当前输出。
- 所有学生级操作必须验证当前班级成员关系。
- 输出必须包含证据引用、截止时间、覆盖率、置信度和局限。
- 不暴露原始答案、事件载荷、私密对话、解析器原文或原始证据 JSON。
- 诊断报告独立持久化，历史读取不重新调用模型。
- 报告中的知识节点可导航到备课入口，但不得自动触发教学行动。

## 诊断工具

- `get_student_risk_flags`：获取授权班级或学生的当前风险摘要。
- `get_class_competency_summary`：按各维度独立证据分母聚合班级能力。
- `get_student_knowledge_progress`：获取授权学生的知识进度摘要。

## 分层输出

班级报告用于查看能力覆盖、维度均值、薄弱点和风险分布。学生报告用于个别辅导，包含该生的知识进度、能力证据、当前风险和局限。知识节点是报告中的证据和导航粒度，不单独形成第三类报告。

## 当前实施范围

本次 OpenSpec 只交付后端基础：风险工作器、诊断工具、报告模型、授权读写 API 和测试。教师仪表盘入口与报告渲染需要独立的前端变更。
