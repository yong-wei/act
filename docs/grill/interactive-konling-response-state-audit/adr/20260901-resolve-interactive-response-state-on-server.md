# 互动课程控灵只使用服务端解析的作答状态

互动课程当前在浏览器中依据本地作答和答案揭示状态生成 `systemPromptExtension` 与工具列表，但聊天路由不消费这些字段，服务端运行时也只重建静态步骤上下文。决定由服务端按认证学生、课堂会话、课程步骤和持久化作答解析学生安全的互动辅导状态，并让嵌入式互动 AI 与全局控灵共同消费该投影；浏览器字段只负责呈现和导航，不能成为提示词、工具权限或答案揭示事实。这样可以在提交前保持启发式辅导，在完整提交或教师揭示后检查真实作答，同时不暴露教师答案、其他学生数据或内部课堂状态。
