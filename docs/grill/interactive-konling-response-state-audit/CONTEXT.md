# 互动课程控灵作答状态

本上下文定义互动课程中控灵能够用于辅导的当前作答、提交与答案揭示状态，避免浏览器生成的提示文本替代服务端可核验的课堂事实。

## Language

**互动辅导状态**：
服务端根据当前学生、课堂会话、课程步骤和受治理作答记录形成的学生安全状态，区分未作答、部分作答、已完整提交和答案已揭示。
_Avoid_: 客户端页面上下文、systemPromptExtension、当前表单状态

**已确认作答摘要**：
当前学生在指定课堂会话和步骤中已经持久化的受限作答投影，可用于解释和检查，但不包含教师私有答案、评分规则或其他学生数据。
_Avoid_: 浏览器草稿、完整原始课堂状态、教师答案包

**答案揭示状态**：
服务端确认教师是否已向当前课堂和步骤公开答案或解析的状态，用于决定控灵能否检查已有作答。
_Avoid_: 客户端布尔值、模型自行判断、教师私有答案

**提交前辅导边界**：
学生尚未完整提交当前步骤时，控灵只能提供概念解释、观察顺序和启发性提示，不得生成可直接提交的完整答案或声称作答已完成。
_Avoid_: 客户端提示词约定、仅靠模型自律

**提交后检查边界**：
学生完整提交或教师已揭示答案后，控灵可以基于已确认作答摘要进行检查与解释，但仍不得改写提交、官方评分或学习事实。
_Avoid_: 自动批改、自动改写答案、正式成绩写回
