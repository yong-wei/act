# Arena Odyssey Turn Scoring Context

## Ubiquitous Language

- **PID 转向推荐场景**：用于生成学习者 PID 参数建议的确定性船舶转向仿真，不是 Arena 官方提交或排行榜评测。
- **参考航向日程**：按仿真时间定义的期望航向序列；它同时驱动参考轨迹和控制误差，二者不得采用不同的起点或转向时刻。
- **参考轨迹**：由参考航向日程、船速和仿真起点积分得到的空间路径，用于计算横向路径误差。
- **舵角命令**：PID 控制器在单个仿真步产生的目标舵角。
- **实际舵角**：应用舵机速率限制后进入 Nomoto 船模的舵角；舵速指标只基于实际舵角计算。
- **持续稳定时间**：最终参考航向完成后，响应首次进入容差带并保持在其中直到验证窗口结束的间隔。
- **推荐评分**：路径误差、实际舵速、超调和持续稳定性的加权质量分数；仅在各项度量来自同一可重放场景时可用于参数建议。
