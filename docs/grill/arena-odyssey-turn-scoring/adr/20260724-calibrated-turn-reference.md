# 校准 PID 转向推荐的参考与稳定性语义

## Context

现有推荐器把固定硬拐角、与仿真不一致的路径起点、无限舵机速率和首次穿越容差带混合到同一分数中。学习者无法通过 PID 调参改变这些结构性缺陷，推荐评分因此不能代表控制策略质量。

## Decision

将 90 度转向定义为由同一航向日程生成的圆弧参考轨迹。PID 输出视为舵角命令，船模在显式舵机速率限制后得到实际舵角。稳定时间从最终航向参考完成开始计量，要求响应进入容差带后持续保持。所有这些参数属于可重放评分场景的一部分。

## Consequences

推荐器将产生可完成且可解释的评分。已有未提供航向日程或舵机限制的通用快速仿真请求保持兼容；只有推荐器明确启用经过校准的转向场景。
