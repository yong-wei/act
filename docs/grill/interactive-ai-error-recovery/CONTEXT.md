# 互动课程 AI 错误恢复领域语言

本上下文描述互动课程嵌入式 AI 学伴的学生可见失败与恢复边界，确保服务端错误不会以实现细节进入课程页面。

## Language

**嵌入式互动学伴**：嵌入互动课程步骤页面、围绕当前课程资源提供辅导的 AI 入口。它受当前资源、步骤和服务端学习状态约束。
_Avoid_: 通用聊天、全局 AI 面板

**学生安全失败**：面向学生的受限失败类别和产品语言，不包含 HTTP 状态、机器码、供应商信息、堆栈或内部路径。
_Avoid_: 原始错误、服务端异常正文

**匹配恢复动作**：能够改变下一次请求条件的学生操作，例如重新登录、恢复会话、回到当前资源或稍后重试。
_Avoid_: 统一重试

**互动请求边界**：把互动学伴的网络响应、会话恢复状态和错误呈现连接起来的共享传输边界。
_Avoid_: 页面层错误拼接
