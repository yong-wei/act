# 互动课程 AI 失败先归一化再展示

`#1814` 已治理独立 Copilot 和全局入口，但 `useInteractiveAI` 使用另一条传输路径，当前仍把非 2xx 和网络异常转成原始 `Error.message` 并由 `InteractiveAIPanel` 直接渲染。决定让互动请求复用共享的学生安全失败契约，在 hook 边界完成失败分类，再由面板只展示安全文案和与状态匹配的恢复动作；不改变互动课程的服务端任务边界、会话持久化或正式学习记录。

## Considered Options

- 仅在 `InteractiveAIPanel` 中过滤字符串：无法覆盖其他调用者，也会让错误分类和恢复状态继续分散。
- 继续展示服务端返回正文：便于调试，但会把机器信息和内部诊断带到学生界面，违反现有控灵错误语言。
