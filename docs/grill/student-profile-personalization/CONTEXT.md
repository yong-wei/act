# 学生个人中心个性化

本上下文描述学生个人中心如何把受治理的学习证据转化为可执行的个性化学习行动。它强调推荐必须来源于当前学生的授权证据，并且在证据不足时明确降级。

## Language

**受治理推荐**：由 Personalization 的公开用例依据学生自己的受治理学习证据生成的学习行动建议，保留理由、置信度、来源覆盖和隐私范围。
_避免_：页面硬编码的样例推荐、仅依据浏览或点击行为的个性化结论

**个性化补强资源**：个人中心中根据当前学习证据和推荐策略呈现、能够直接进入下一项学习活动的资源卡片。
_避免_：普通资源列表、未经证据支持的学习路径、系统默认样例

**证据不足降级**：当学习证据缺失、过期、不完整或不可用时，系统对推荐强度和表述做出的明确限制；它可以提供证据收集或基础学习行动，但不能伪装成精确的个人诊断。
_避免_：把空集合解释为没有问题、把通用规则写成个性化事实

**学习行动闭环**：从受治理学习证据出发生成推荐，经个人中心展示并进入可执行资源，后续活动再形成新的受治理证据。
_避免_：只生成推荐文本而没有入口、只记录点击而没有学习证据
