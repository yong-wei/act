# 图谱受治理数学呈现

本上下文统一 Authority 图谱中混合文本与数学表达的领域语言，确保图谱保持 ActKG 发布语义并由 ACT 一致呈现。

## Language

**受治理图谱富文本**：
ActKG 发布中由有序普通文本片段与受信数学片段组成，并保留本地化、数学身份和精确回退语义的用户可读内容。
_Avoid_: 含公式的 Markdown 字符串、运行时猜测公式的普通文本

**图谱数学呈现适配**：
ACT 在不改变受治理图谱富文本及其数学身份的前提下，将普通文本和行内或块级数学片段投影为统一可读内容的呈现边界。
_Avoid_: 第二套公式格式、把数学片段拼回 Markdown 后重新解析、图谱专用数学引擎

**公式完整呈现表面**：
凡是向用户呈现受治理图谱富文本的界面，都必须按其行内或块级语义正确显示数学内容；范围包括 2D 与 3D 画布节点、悬浮预览、搜索与筛选结果、详情抽屉和知识卡片。纯文本只作为无障碍与不可视环境的等价表达，不替代可视数学排版。
_Avoid_: 画布纯文本公式、仅在详情中渲染、不同界面采用不同公式语义

**数学片段局部失败关闭**：
单个数学片段缺失、校验失败或无法呈现时，保留同一内容中的正常文本，并在原位置使用上游受治理回退文本或统一的“公式暂不可用”表达；不得向用户显示原始 LaTeX。公式化标题因此失去可理解语义时，该对象按名称暂不可用对象处理，在正式视图默认隐藏，并可在开发审核视图中筛出。
_Avoid_: 原始 LaTeX 回退、整段静默消失、失败片段污染相邻文本

**统一内容显隐层级**：
公式片段与相邻普通文本遵循同一套由缩放级别和节点密度决定的显隐规则。远景可以整体隐藏节点标题，进入可读层级后必须同时恢复完整文本与公式；悬浮预览和详情内容保持完整。公式不得被单独提前隐藏，也不得在远景替换为纯文本近似。
_Avoid_: 公式专属显隐规则、远景公式文本化、文本可见而同行公式消失

**可用数学表达**：
正确呈现的数学片段同时具备可视排版、等价的无障碍数学语义和显式复制能力。2D 与 3D 节点必须提供与可视标题等价的可访问名称；详情抽屉与知识卡片允许复制有效公式的标准 LaTeX。LaTeX 复制是用户主动操作，不构成普通显示或失败回退。
_Avoid_: 只有像素没有语义、画布节点无可访问名称、把复制源码当作页面正文

**已登记不可用公式**：
目标 Authority sidecar 中未能正确呈现、但已在开发过程中由课程所有者审核登记的数学片段。登记记录必须绑定 Authority 版本、数学片段身份、受影响内容、失败原因和安全回退，并形成可提交给 ActKG 的修复清单；这类片段可以按局部失败关闭规则进入生产。任何未登记的 Authority 失败仍阻止产品资格。ACT 自有知识卡、讲义和教材公式不适用该豁免，失败时必须修复后才能正式发布。
_Avoid_: 抽样遗漏、运行时自动豁免、没有版本身份的失败列表、把 ACT 自有内容缺陷报给 ActKG

**共享数学兼容能力**：
平台共同使用的数学呈现边界负责兼容 ActKG 已发布的版本化宏配置，使图谱、讲义和知识卡片获得一致结果。图谱数学呈现适配只解释受治理富文本的结构和数学身份，不改写公式，也不维护图谱专属宏别名。
_Avoid_: 图谱私有宏表、公式字符串改写、不同内容载体产生不同数学语义

**知识卡数学内容边界**：
规范知识卡继续以 Markdown 为内容真源，并由现有 Markdown 内容链解释正文中的行内与块级公式。ActKG 标题、描述等受治理图谱富文本由图谱数学呈现适配解释；两条内容链不互相转换，只共同使用共享数学兼容能力、无障碍语义和复制能力。
_Avoid_: 将知识卡迁移为图谱富文本、将图谱富文本拼成 Markdown、两套数学渲染结果

**Legacy 数学有界兼容**：
Legacy 数据模式只呈现其已有显式公式字段，并与 Active Authority 共用数学呈现能力；普通 Legacy 标题和描述不在运行时扫描或猜测公式。Active Authority 才消费 ActKG 受治理图谱富文本并取得完整结构化数学呈现。
_Avoid_: 猜测 Legacy 普通文本、运行时识别定界符、把 Legacy 内容冒充 ActKG 富文本
