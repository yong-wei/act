# 保留 ActKG 结构化数学语义并复用共享数学呈现能力

## 背景

ActKG 已将标题、描述等混合内容发布为有序文本片段与受治理数学片段，并为数学片段保留身份、显示模式、宏配置、无障碍标签和精确回退语义。ACT 的讲义、教材与规范知识卡则继续以 Markdown 为内容真源；Legacy 图谱还存在少量显式公式字段。

若把 ActKG 数学片段重新拼为 Markdown，ACT 会丢失上游数学身份、失败边界和版本化宏语义。若为图谱另建一套公式引擎，又会使图谱、讲义和知识卡片产生不同的渲染结果与兼容规则。

## 决策

1. ACT 保留 ActKG 受治理图谱富文本及数学片段结构，通过只读呈现适配将文本、行内数学和块级数学投影到用户界面；适配器不扫描定界符、不猜测公式，也不改写 LaTeX。
2. 图谱、讲义、教材和知识卡片共用平台数学呈现能力。ActKG 已发布的版本化宏配置在共享边界中获得兼容，不在图谱适配器内维护私有宏别名。
3. 公式化标题在 2D 与 3D 画布节点、悬浮预览、搜索与筛选结果、详情抽屉中正确呈现；知识卡片中的公式在所有卡片入口正确呈现。公式与普通文本遵循同一缩放和密度显隐规则。
4. 节点内容预算保持不变：标题自身包含的公式属于标题；定义、独立公式和长描述仍进入详情抽屉。节点大小继续遵循已有的受控动态范围。
5. 规范知识卡继续以 Markdown 为内容真源，不转换为 ActKG 富文本；ActKG 富文本也不转换为 Markdown。两条内容链只共享数学呈现、宏兼容、无障碍和复制能力。
6. Legacy 数据模式只兼容已有显式公式字段，普通标题和描述不执行运行时公式识别。
7. 正确呈现的公式同时提供视觉排版、等价无障碍语义和显式 LaTeX 复制。复制是用户主动操作，原始 LaTeX 不作为普通显示或失败回退。
8. 单个数学片段失败时保留相邻文本，并使用上游受治理回退或统一不可用表达。标题因此失去可理解语义时，节点按名称暂不可用对象处理。
9. 经课程所有者在开发过程中审核登记的 ActKG Authority sidecar 不可用公式可以按失败关闭规则进入生产。登记清单必须绑定 Authority 版本、数学片段身份、受影响内容、失败原因和安全回退，并作为 ActKG 后续版本的修复输入；任何未登记 Authority 失败仍阻止产品资格。ACT 自有知识卡、讲义和教材公式不进入该账本，失败时必须修复内容或共享兼容能力后才能正式发布。

## 后果

- ACT 需要一层结构化图谱富文本适配，但不新增数学内容格式或第二套数学引擎。
- 2D 与 3D 画布可以采用各自适合的绘制载体，但必须消费同一适配结果，并提供等价的视觉和无障碍语义。
- 共享数学能力升级会同时改善图谱、讲义、教材和知识卡片；兼容性回归必须覆盖这些消费者。
- 运行时失败关闭是可信显示边界；版本化失败清单负责将生产例外反馈给上游治理，不允许静默遗漏。

## 未采用方案

- 将 ActKG 富文本拼回 Markdown 后交给现有讲义渲染器。
- 在图谱中维护私有宏表、公式改写规则或独立公式引擎。
- 扫描 Legacy 普通字符串中的 LaTeX 定界符并猜测公式。
- 只在详情抽屉渲染公式，或在远景把公式替换为纯文本近似。
