# 控灵流式诊断领域语言

本上下文约束控灵流式引用诊断在开发环境中的可见边界，区分调试信息与学生正常看到的引用状态。

## Language

**开发诊断**：为开发者或支持人员解释引用守卫、缺失上下文和个性化限制的受控信息，不是学生学习内容。
_Avoid_: 普通回答提示、正式引用

**学生可见回答**：浏览器中作为控灵助学内容呈现给学生的助手文本及其附属状态。
_Avoid_: 内部流、模型上下文

**正式引用呈现**：从服务端拥有的引用元数据生成的标题、来源类型、置信度和安全链接，不依赖诊断文本。
_Avoid_: 诊断前缀、reason code

**诊断标识**：明确告诉浏览器使用者当前文本属于开发或支持诊断的可见标签，并与正式引用在语义和视觉上分开。
_Avoid_: 泛化的证据提示
