# 保留开发诊断但明确标识其身份

`#693` 已确定开发环境可以显示完整引用诊断、生产默认隐藏原始诊断；现行 `konling-agent-runtime` spec 进一步要求开发环境可见提示明确标识为开发模式诊断。当前实现虽然按环境控制注入，却只显示“控灵证据提示”，并把 reason code、缺失上下文等内容混在学生回答前缀中。决定保留已授权开发诊断内容，但使用明确的开发/支持诊断标识并与正式引用呈现分离；生产默认隐藏和诊断持久化不变。

## Considered Options

- 开发环境完全隐藏诊断：会破坏 #693 的开发排障能力。
- 继续使用通用“证据提示”：无法让使用者区分学习提示与内部诊断，违反现行 spec。
