# 成长诊断证据投影

本上下文记录成长中枢学生端诊断如何表达累计画像的证据基础、可用性状态和后续学习行动，确保诊断结论能够被学生理解和追溯。

## Language

**累计画像诊断**：基于学生当前受治理累计画像生成的整体能力判断；它不是单一任务或控制校正场景的专项诊断。

**证据引用**：学生端可展示的、经过脱敏的学习证据索引，用于说明某项诊断结论来自哪些受治理来源；它不是原始学习记录或私有载荷。

**证据可用性状态**：描述诊断所依赖证据当前是否可读取、为空或不可用；已有画像可用不代表所有证据明细都可用。

**学生安全投影**：仅包含学生有权查看且足以解释结论的摘要、来源覆盖、限制和行动，不暴露内部数据结构、原始引用或其他学生信息。
