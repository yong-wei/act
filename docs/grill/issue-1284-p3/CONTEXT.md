# 自适应学习路径纠偏结果

本上下文界定已确认纠偏方案在后续学习证据上的结果呈现，避免将结果状态误写为因果结论。

## Language

**纠偏结果状态**：
针对一项已确认纠偏方案、由其确认后产生的可验证学习证据得出的状态投影；它陈述证据所支持的结果，不证明纠偏方案导致该结果。
_Avoid_: 纠偏效果、干预成功、因果结论

**已改善**：
确认纠偏方案后，关联的后续检查点通过或终端验证完成所支持的纠偏结果状态。
_Avoid_: 已治愈、纠偏成功

**仍需复习**：
确认纠偏方案后，关联的后续检查点失败所支持的纠偏结果状态。
_Avoid_: 纠偏失败、能力下降

**尚未验证**：
已确认纠偏方案尚未产生足以判定结果的后续可验证证据时的纠偏结果状态。
_Avoid_: 无效、未完成纠偏

**无法判断**：
后续证据缺失、相互冲突或置信不足，因而不能可靠投影其他纠偏结果状态时的状态。
_Avoid_: 失败、未知原因

**教师纠偏结果汇总**：
按班级聚合且脱敏的纠偏结果状态统计，不暴露任何学生级结果或原始证据。
_Avoid_: 学生纠偏结果列表、个体追踪

## Example dialogue

开发者：该方案确认后只有一个检查点通过，能显示“已改善”吗？

领域专家：可以，但只能说后续证据支持“已改善”，不能说该方案造成了改善。

开发者：尚未出现检查点或终端验证时呢？

领域专家：显示“尚未验证”；证据相互冲突或置信不足时显示“无法判断”。
