# Issue #1158：补救资源与验证题编排

## 术语

### 微辅导任务快照

由一次受治理的错题归因触发、供学习者执行的不可变补救编排记录。快照包含明确的学习目标、5–10 分钟预计时长、受治理的资源引用、既有验证题引用，以及创建时采用的编排器版本。

## 已确认决策

- 微辅导任务快照按 `wrongAnswerAttributionId + orchestratorVersion` 幂等创建。
- 已创建的快照不可变；资源目录后续变化不得静默改写历史任务。
- 资源或验证题引用发生版本漂移时失败关闭，不得继续返回无法验证的任务。
- 需要重新编排时，通过新的编排器版本创建新快照，而不是覆盖历史快照。
- 错题归因完成后不自动创建快照；仅当学习者显式进入补救流程时，由服务端创建或返回幂等命中的快照。
- 教师操作不是本次微辅导编排的必要触发条件。
- 归因置信度不足时不创建微辅导任务快照；服务端只记录并返回结构化的不可用原因和通用人工练习路径。
- 不可用结果不得绑定候选知识节点、补救资源或验证题，避免将不确定归因固化为正式诊断。
- 补救资源采用确定性分层排序：同时匹配知识节点与误概念标签的资源优先，其次为知识节点匹配资源，再按前置知识路径补足。
- 同一匹配层内按受治理版本和稳定 ID 排序；相同归因、编排器版本及资源目录修订必须产生相同选择。
- 验证题必须来自既有受治理题库，且不得复用产生本次归因的原错题。
- 验证题必须匹配同一知识节点，并由同构/变式关系或相同误概念标签证明针对性；缺少合格候选时返回不可用结果，不创建任务快照。
- 模型不得生成或改写正式验证题。
- 创建快照时只允许写入学习者当时有权访问的资源和验证题引用。
- 读取快照时必须重新校验当前授权；权限已撤销时返回不可用结果，不得泄露资源标题、题目答案或教师私有数据。
- 资源与验证题必须提供版本化的预计时长元数据。
- 编排器按确定性排序选择总预计时长落入 5–10 分钟的最小资源组合；无法满足时长约束时返回不可用结果，不得伪造预计时长。
- 编排结果按 `wrongAnswerAttributionId + orchestratorVersion` 幂等持久化，结果状态区分 `AVAILABLE` 与 `UNAVAILABLE`。
- `AVAILABLE` 结果包含可执行、可验证的微辅导任务快照；`UNAVAILABLE` 结果只包含枚举原因、通用人工练习路径和版本信息，不保存候选知识节点、资源或题目。

## 待确认问题

- 无。
