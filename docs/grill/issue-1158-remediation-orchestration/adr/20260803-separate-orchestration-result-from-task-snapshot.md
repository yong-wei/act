# 将微辅导编排结果与任务快照分离

- 状态：已接受
- 日期：2026-08-03
- 范围：Issue #1158

## 背景

微辅导编排可能因归因不确定、资源或验证题缺失、时长不满足、授权失败或版本漂移而无法形成可执行任务。系统仍需要对同一归因和编排器版本给出可审计、幂等的结果，但不能把不完整记录表述为任务。

## 决策

持久化不可变的编排结果，并以 `wrongAnswerAttributionId + orchestratorVersion` 作为幂等边界。结果分为：

- `AVAILABLE`：包含完整的微辅导任务快照，具备目标、5–10 分钟受治理时长、可访问资源引用和既有验证题引用。
- `UNAVAILABLE`：只包含枚举原因、通用人工练习路径与版本信息，不保存候选知识节点、资源或题目。

读取 `AVAILABLE` 结果时仍需重新校验授权和引用版本；校验失败只返回不可用投影，不改写历史结果。

## 理由

该模型同时保留编排审计记录和“任务必定可执行、可验证”的领域语义。它也阻止不确定归因及无权访问的候选引用进入持久化结果。

## 后果

- 数据模型和接口需要明确区分编排结果与任务快照。
- 不可用原因必须是受控枚举，人工练习路径必须来自受治理配置。
- 资源目录变化不会静默改变既有结果；重新编排需要新的编排器版本。
- 读取阶段的授权或版本失效不会修改历史记录，但会使当前投影失败关闭。
