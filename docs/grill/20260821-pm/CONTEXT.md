# 新旧图谱产品语言

本上下文固定知识图谱双视图及节点关联内容的用户语言。系统内部称号只用于工程边界，不进入普通产品界面。

## 语言

**新版图谱**：
面向用户呈现当前已激活权威知识及教学投影的图谱视图。它与旧版图谱共享主要视觉与交互语言，但不混用两者的数据或状态。
_避免：权威图谱、当前 Authority、Authority_

**旧版图谱**：
面向用户提供的历史只读知识图谱视图，对应系统内部的 Legacy 路径。它与新版图谱保持独立的数据和交互状态。
_避免：Legacy、历史 Legacy、旧 Authority_

**节点关联内容**：
选定知识节点后，与该节点通过受治理绑定或已发布关系连接的知识卡、系统资源和相邻节点。知识卡直接阅读，系统资源经既有平台入口打开，关系节点可继续浏览。
_避免：任意推荐资源、抽屉内嵌资源运行、只列资源元数据_

**完整中文发布**：
由图谱项目发布、其中文显示内容完整覆盖本项目所消费对象、关系、类型和概念说明的版本。本项目只验证并接收该版本，不在本地补写权威翻译。
_避免：本地翻译补丁、英文缺省回退、部分中文发布_

**双语就绪发布**：
同一权威发布中具有完整、受治理且彼此对应的中文与英文显示内容的版本。任一语言覆盖不完整时，该发布不具备双语就绪资格。
_避免：混合语言发布、按字段零散回退、不同权威版本拼接语言_

**图谱显示语言**：
用户在新版图谱中选择的中文或英文呈现语言，只改变显示内容，不改变知识对象、关系、筛选或选择状态。中文是默认语言，英文只对双语就绪发布开放。
_避免：浏览器自动混合语言、切换语言后切换图谱版本、未完成翻译时开放英文_
