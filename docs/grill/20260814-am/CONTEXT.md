# 学习路径返回与恢复

本上下文定义学习路径中心、已保存路径和路径执行页之间的导航语义，避免返回动作误入候选比较或重置学习进度。

## Language

**学习路径中心入口**：展示当前已保存路径及路径创建入口的页面。返回学习路径动作应回到这里，而不是保留路径执行参数。

**已保存路径**：学生已经创建并持久化、可继续执行的学习路径；返回中心不会修改其进度、当前节点或配置。

**继续原路径**：从学习路径中心恢复已保存路径的未完成节点，直接进入路径执行页，不进入候选方案比较。

**新建学习路径**：从学习路径中心启动新的候选路径生成与比较流程；只有用户明确选择此动作时才创建候选路径批次。

**候选路径比较**：新建学习路径流程中的方案选择页面，不属于继续原路径的恢复流程。

**返回上下文**：返回中心入口时可保留学习目标，用于恢复正确的路径上下文；必须清除 `pathId`、`nodeId`、路径执行意图和候选批次等执行态、候选态参数。

## Example dialogue

开发者：用户点击资源页的“返回学习路径”后应去哪里？

领域专家：回到学习路径中心入口，保留已保存路径。用户可选择“继续原路径”恢复进度，或选择“新建学习路径”进入候选路径比较。

开发者：如果没有已保存路径呢？

领域专家：只展示“新建学习路径”，不能展示不存在的“继续原路径”。
