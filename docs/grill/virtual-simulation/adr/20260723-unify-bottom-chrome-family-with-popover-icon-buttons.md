# 统一底部 chrome 家族为单排弹出式按钮并引入 tooltip 依赖

仿真页底部的场景视觉控制（视图、环境预设、画质档位、仿真速率、音效、标注）统一收敛为**单排**「底部 chrome 家族」：图标+两字名称的按钮整体排布于底部工具条，点击向上展开选择或弹出层，选中后按钮只显示当前状态；「标注」为网格与教学标注两行独立开关的合并弹出控件；全部按钮经 `@radix-ui/react-tooltip` 提供功能与当前状态提示。选择单排弹出式而非既有平铺 radio 条与 bottom-32 散放开关，是因为七枚控件平铺与散放在窄屏互相挤压（C6 期 Codex review 实证），且"按钮显示当前态、弹出做选择"与游戏级控制台语义一致；本地工具模板的占位命令条一并移除（其为无行为的设计稿移交物），仿真页底部不再保留第二套控件。引入 tooltip 依赖的代价（新增 `@radix-ui/react-tooltip`）已获显式授权；曾考虑原生 title 属性，被拒绝：提示需要同时承载功能说明与实时状态，且家族内所有按钮的提示形态应统一。（2026-07-23 修订：网格原拟并入视图弹出层，经用户指令改为与教学标注合并为「标注」控件；全部控件由分散的 bottom-32 挂载改为底部单排。）
