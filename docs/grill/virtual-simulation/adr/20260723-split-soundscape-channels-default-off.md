# 音效拆分场景与界面双通道并改为默认关闭（取代默认开启）

仿真音效拆分为两个独立开关的通道：场景音效（环境声海浪/风与告警音，由仿真事件驱动）与界面音效（按钮点击/操作反馈音，由 chrome 与控制面板交互驱动；「开始」按钮使用与普通点击不同的专属音效）；底部音效按钮向上弹出两通道开关，状态在浏览器内持久化（localStorage），仅对新用户默认关闭。本决定取代 C1 期 ADR「仿真场景启用全套音景并默认开启」的默认开启口径：教学平台默认出声即使受手势约束，仍会在首次交互后意外播放环境声，与课堂环境的安静预期不符；默认关闭并把选择权交给用户后，开启率交给真实需求决定。曾考虑每次进入重置为关闭（不持久化），被拒绝：会惩罚已主动开启的用户。
