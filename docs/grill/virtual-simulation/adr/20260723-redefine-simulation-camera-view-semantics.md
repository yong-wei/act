# 重定义仿真视图语义并确立视图交互模型

仿真视图语义重定义：跟船=正后方上部 45° 随船跟踪（纠正旧实现的低位跟随错误）；环绕=45° 俯角以船为中心的自动圆周运动（60 秒/圈、俯视顺时针，取代名不副实的静态舷侧视角）；「退却」更名「战术」并重定位为船后右侧 45°（原舰艏前方回望机位语义不明且少被使用）；顶视维持。视图交互模型统一为：左键拖拽以船为中心调整观察角，松手后角度保留且镜头持续以船为中心跟踪（StayPut 语义）；右键拖拽进入不以船为中心的自由视角；点击视图按钮锁定对应视图模式（再次点击同一按钮复位标准机位）。选择 45° 统一俯角，是因为跟船/战术/环绕构成同一镜头家族，教学上"高位观察"语义一致；保留 StayPut 而非固定机位，是因为用户已验收"拖拽后停留"的行为契约，固定机位优先会废掉该语义并与其 spec 契约冲突。镜头语义仍属呈现层，不进入 SceneSpec/Trace 协议（沿用既有 ADR 的边界）。
