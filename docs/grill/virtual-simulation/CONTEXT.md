# 虚拟仿真

该上下文描述船舶仿真实验的场景视觉语言与观感验收锚点；相关决策记录见同目录 `adr/`。

## 语言

**观感参照**：
虚拟仿真场景视觉验收的唯一对标锚点，当前定为《战舰世界》（World of Warships）的海面、舰船与尾流的写实渲染观感；管线特征与性能预算服务于该锚点，不作为并列验收项。
_避免：逐项管线指标验收、风格化卡通参照（如 Sea of Thieves）、无锚点的“好看”表述_

**场景游戏级**：
仿真实验的场景本体（海面、舰船、尾流、天空、光照、运镜）达到观感参照的写实游戏质感；不波及壳层与面板语义。
_避免：游戏 HUD、血条/技能栏式界面、卡通化场景_

**控制台面板**：
仿真实验壳层中的状态、控制与评估界面层，保持半透明玻璃、指挥甲板式控制台气质；场景游戏级改造不把它变成游戏 HUD。
_避免：游戏 HUD、全屏游戏菜单、血条/技能栏_

**环境预设**：
虚拟仿真场景与课程视频系统共享的海况/天空/光照成套设定（开阔海、薄雾黎明、暖色日落、阴云、风暴蓝五套），学生在场景内手动切换，不随平台明暗主题变化；面板与壳层仍跟随主题。
_避免：场景跟随系统主题自动变色、每套实验自定义一套环境语言_

**音景**：
与环境预设联动的场景音频层，包含环境声（海浪/风）、操作反馈音与告警音；默认开启，受浏览器自动播放策略约束在首次用户手势后解锁，场景内提供一键静音。
_避免：无手势自动出声、各实验各自为政的音效体系_
