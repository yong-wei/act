# 虚拟仿真

该上下文描述船舶仿真实验的场景视觉语言与观感验收锚点；相关决策记录见同目录 `adr/`。

## 语言

**观感参照**：
虚拟仿真场景视觉验收的唯一对标锚点，当前定为《战舰世界》（World of Warships）的海面、舰船与尾流的写实渲染观感；管线特征与性能预算服务于该锚点，不作为并列验收项。
_避免：逐项管线指标验收、风格化卡通参照（如 Sea of Thieves）、无锚点的“好看”表述_

**场景游戏级**：
仿真实验的场景本体（海面、舰船、尾流、天空、光照、运镜）达到观感参照的写实游戏质感；不波及壳层与面板语义。
_避免：游戏 HUD、血条/技能栏式界面、卡通化场景_

**控制台面板**：
仿真实验壳层中的状态、控制与评估界面层，保持半透明玻璃、指挥甲板式控制台气质；场景游戏级改造不把它变成游戏 HUD。
_避免：游戏 HUD、全屏游戏菜单、血条/技能栏_

**环境预设**：
虚拟仿真场景与课程视频系统共享的海况/天空/光照成套设定（开阔海、薄雾黎明、暖色日落、阴云、风暴蓝五套），学生在场景内手动切换，不随平台明暗主题变化；面板与壳层仍跟随主题。
_避免：场景跟随系统主题自动变色、每套实验自定义一套环境语言_

**音景**：
仿真场景的音频层总称，分场景音效与界面音效两个独立开关通道；新用户默认关闭，localStorage 分通道持久化，底部音效按钮弹出层分别控制，首次用户手势后解锁。（原「默认开启+一键静音」口径已由 20260723-split-soundscape-channels-default-off 取代。）
_避免：无手势自动出声、单一总开关、各实验各自为政的音效体系_

**视图交互模型**：
仿真场景统一的相机交互约定：左键拖拽以船为中心调整观察角，松手后角度保留且镜头持续以船为中心跟踪；右键拖拽进入自由视角（不以船为中心）；点击视图按钮锁定对应视图模式。
_避免：拖拽后镜头弹回默认机位、左键直接切换自由视角、各实验自定义交互_

**跟船**：
从正后方上部 45° 跟随船舶的镜头视图。
_避免：正后方低位贴水跟随（此前实现的错误语义）_

**战术**：
船后右侧 45° 的战术观察视角（原「退却」机位更名重定位）。
_避免：舰艏前方回望机位（原「退却」语义）、语义不明的「退却」命名_

**环绕**：
45° 俯角、以船为中心的自动圆周运动镜头（60 秒/圈、俯视顺时针）；左键拖拽按视图交互模型暂停并保留角度，再次点击重启轨道。
_避免：静态舷侧视角冒充环绕_

**底部 chrome 家族**：
仿真页底部**单排**的场景视觉控制按钮组：视图/环境/画质/速率/音效五枚"图标+两字"弹出式按钮（点击向上展开、按钮只显示当前态、再点收起），加上「标注」合并弹出控件（网格与教学标注两行独立开关）；全部带 tooltip 说明功能与当前状态。
_避免：平铺文字 radio 条、散放各处的控件_

**提示条**：
仿真页底部引导文案条，右上角提供关闭按钮；每次进入仿真页面时显示。
_避免：常驻不可关闭的引导文案、跨会话记忆关闭状态_

**贴水航迹**：
航迹线各点随波浪高度贴合水面的呈现；不固定在单一水平面上被涌浪淹没。
_避免：固定高度平面航迹_

**场景音效**：
由仿真事件驱动的声音通道：环境声（海浪/风）与告警音；与界面音效分别独立开关。
_避免：单一总开关一刀切、各实验各自为政的音效通道_

**界面音效**：
由 chrome 与控制面板交互触发的声音通道：按钮点击/操作反馈音；「开始」按钮使用与普通点击不同的专属音效；与场景音效分别独立开关。
_避免：与普通点击不区分的开始音效_
