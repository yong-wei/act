# 学习陪伴：标准仿真运行个人中心投影

## 领域术语

**标准仿真运行**：符合 `SimulationRun` 规范、带有学生归属和受治理摘要的可复核仿真运行；它是新仿真证据进入个人中心的统一运行身份。
_避免：单一页面的临时运行对象、原始轨迹、客户端展示样例_

**兼容仿真日志**：历史 `SimulationLog` 中能够确认学生、时间和仿真产品语义的记录；它只用于兼容回读，不能与已关联的标准仿真运行重复计数。
_避免：把所有旧日志自动视为有效证据、把旧日志当作新的 canonical identity_

**仿真证据投影**：从标准仿真运行或合格兼容日志生成的学生安全摘要集合；它只读，不创建新的学习事实。
_避免：直接展示轨迹或输入载荷、以投影替代原始证据_

**训练统计**：个人中心对可展示仿真证据形成的次数、时长、质量和最近活动摘要；统计不等同于官方成绩或能力达成。
_避免：把数据库行数直接当作训练次数、将预览计为正式提交_

**来源去重**：同一底层仿真产物同时存在于 `SimulationRun` 和 `SimulationLog` 时，以稳定来源身份只保留一条展示记录。
_避免：按表分别统计、依赖时间近似判断重复_

**未知证据状态**：标准运行或兼容日志缺少展示所需的完成状态、质量指标或归属信息时的 `empty` / `unavailable` 状态；不得转化为学生已完成或零分事实。
_避免：用 0 次、0 分掩盖缺失证据
