# 统一个人中心的仿真证据来源

日期：2026-09-05

## 背景

新仿真链路使用标准 `SimulationRun` 保存运行身份和摘要，但个人中心仍有旧 `SimulationLog` 消费路径。若继续分别展示，两套统计会让学生无法判断自己的训练记录；若直接删除旧路径，又会丢失历史记录。

## 决策

个人中心和个人仿真档案采用单一学生安全投影：优先消费可验证的 `SimulationRun`，对可确认归属和语义的旧 `SimulationLog` 做兼容回读，并通过稳定来源身份去重。投影只返回展示所需摘要，不扫描高频轨迹，也不改变官方提交、排行榜、正式成绩或能力达成的权威口径。

## 取舍

- **双口径并存**：拒绝，因为同一学生会看到两套无法比较的训练统计。
- **仅切换到 `SimulationRun`**：拒绝，因为历史日志尚未全部迁移，切换会造成历史训练消失。
- **统一投影并兼容去重**：采用，能够保持历史可见性并使新旧链路形成一个可解释的学习证据集合。

## 后果

个人中心必须区分可展示记录、暂无记录和来源不可用；标准运行与旧日志的关联需要稳定身份或显式映射。实现必须保留用户隔离，并禁止把预览证据伪装成官方结果。
