# ActKG 最新复合发布切换与 Legacy 式领域图谱

本上下文描述 ACT 接入当前最新稳定 ActKG 复合发布，并恢复面向人的分层图谱表达。ActKG 继续是工程知识权威端；ACT 负责验证、激活、教学投影与产品展示，不修改发布对象的身份或工程关系。

## 语言

**复合发布包络**：
由一个明确锁定的 Aggregate 发布及其 Component Manifest 确定的不可变版本集合。它同时约束 Aggregate、Integration、中文术语组件、Schema、Projection Profile、标签索引及其他声明组件；运行时不得分别挑选不同版本的“最新包”。
_避免：只切 Aggregate、混用 v0.9 目录与新 Authority、运行时自动追随 latest_

**复合切换**：
在候选导入、重建和验证完成后，把 Authority、Teaching Projection、先修关系、中文显示、领域目录及分片绑定到同一复合发布包络，并通过一个受控激活动作共同生效。任一组成仍绑定旧发布时，不能称为完整切换。
_避免：Authority 已更新但领域目录仍读取 v0.9、分别切换造成混合生产状态_

**领域圆形入口**：
首页用于进入知识领域的圆形交互节点。它显示领域名称和必要的简短说明，点击后进入该领域的二级关系图；它是产品导航投影，不冒充 ActKG 工程知识对象。
_避免：领域卡片墙、首页加载全部知识对象、在圆形节点上显示内部身份_

**领域关系图**：
进入领域后加载的局部节点—边视图。默认显示已发布的教学语义关系，并允许用户筛选工程关系；只绘制真实、可追溯的关系，缺少教学投影不阻断新 Authority 上线。
_避免：名称相似度推断、为改善布局补造关系、一次加载完整全局图谱_

**Legacy 式节点详情**：
用户选择领域关系图中的节点后，在稳定侧边栏中阅读面向人的名称、类型、说明、关系摘要，以及符合治理要求的知识卡和信息图。交互效果与 Legacy 图谱一致，但数据来自当前复合发布及其 ACT 展示投影。
_避免：把详情卡当作主图节点、显示对象 ID、关系 ID、版本号或哈希_

## 已确认事实

- 当前调查时 ActKG 最新稳定 Aggregate 为 `control-theory-engineering-v0.22`，其 Component Manifest 锁定 Integration v0.20、中文术语组件 v0.5 及其余发布组件。
- 首页领域入口数量以当前激活复合发布的领域目录为准；场景中"八个领域入口"为示意值。v0.22 在本仓库尚无本地镜像，实际领域数量在候选导入时按领域目录核实。
- v0.22 继续使用 `actkg-public-bundle/2`、Schema `0.3.0`，Schema 哈希与 ACT 已接入的 v0.18 相同；因此不需要再次设计 Schema 主版本适配器，但仍需增加明确的 v0.22 注册、镜像、验证和激活证据。
- ACT 当前领域显示目录仍绑定 `control-theory-engineering-v0.9`，只含少量人工归类成员。这解释了页面中每个领域仅显示一至两个“已审对象”，也证明现状不是完整的复合切换。
- 最新发布不得通过运行时扫描自动跟随；本轮应明确锁定经核验的 v0.22 复合发布包络。

## 已确认边界

- 下一次上线以复合切换为单位，不允许把 v0.22 Authority 与 v0.9 或 v0.18 的领域目录、中文标签、教学投影或运行时分片拼接为生产状态。
- 候选导入与生产激活仍是两个阶段；候选可审计不等于生产已切换。
- 首页采用圆形领域节点，不再使用当前卡片网格。点击领域后再渐进加载该领域的局部关系图。
- 二级图默认显示已有教学语义，用户可按关系族筛选工程关系；教学投影覆盖不足不阻断 Authority 切换，后续新增的已发布教学关系可以增量加载。
- 节点详情恢复 Legacy 式侧边栏体验，并接入现有知识卡和信息图治理结果。
- 普通界面不得暴露对象 ID、关系 ID、Release、ReleaseSet、Snapshot、Activation、Projection、版本哈希、内部枚举或路径。
- v0.9 只保留在独立只读历史入口和回滚证据中，不参与当前图谱的正常数据读取。
- 首页圆形领域入口之间不显示任何连接线；根视图只做圆形入口的空间排布，不表达导航结构或语义关系。领域间若未来出现已发布的权威或教学关系，另行提案后再上图，不默认绘制。（决定性证据：20260812-am ADR 规定边只能表示真实已发布的权威关系并禁止装饰线与布局连线；ADR 0041 禁止领域层级结构；Legacy 根视图历史实现从不绘制跨领域连线。）

## 典型场景

用户打开图谱首页时，看到八个圆形领域入口和一个综合入口。选择“频域分析”后，客户端只加载该领域的根分片与默认教学关系；继续选择节点时再加载相邻关系和详情内容。侧边栏展示中文名称、知识卡和信息图，页面不出现内部标识。

发布操作先把 v0.22 复合发布及其 ACT 投影注册为候选，验证组件清单、中文标签、领域成员、教学引用、分片重建和回滚。验证通过后，所有生产选择器共同指向同一复合发布包络；若任何选择器仍指向旧版本，激活失败并保持原生产状态。
