# 控灵学生错误与恢复

该上下文定义学习陪伴请求失败时面向学生的错误语言和恢复行为，避免把传输层、服务端代码或内部诊断直接展示为产品反馈。

## Language

**学生安全错误**：
由平台根据已知失败类别生成的简洁产品说明，不包含 JSON、英文异常、内部错误码、供应商名称、堆栈、路径或实现细节。
_避免：原始错误、`error.message`、服务端响应正文_

**恢复动作**：
与当前失败原因匹配、能够改变下一次请求条件的学生操作，例如重新登录、新建或恢复会话、返回有效任务入口、稍后重试。
_避免：统一重试、刷新页面、再次发送相同无效请求_

**可重试失败**：
会话和任务条件仍有效，仅因临时网络、限流或外部服务不可用而未完成的请求；重复请求可能成功。
_避免：所有非 2xx 响应、权限失败、状态冲突_

**状态修复失败**：
由登录失效、会话不存在、任务上下文无效或状态冲突造成的请求失败，必须先修复身份或任务状态，不能直接重放原请求。
_避免：临时失败、服务不可用、普通重试_

**诊断详情**：
供服务端日志、审计和开发排查使用的受控错误码与脱敏技术摘要，不属于学生可见文案。
_避免：用户提示、聊天消息、公开错误正文_
