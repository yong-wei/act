# 保持学习状态累计且仅由证据触发变化

学生能力、置信度、趋势和风险以全部有效学习事实形成的累计状态为准，仅在学习事实新增、撤销、更正或计算规则变化时更新。日历时间不降低历史事实权重，不使画像降级，也不重置趋势或风险；系统只显示证据截至时间和证据年龄，用于解释结论的新旧程度。学生端、教师个体页、班级聚合和整体诊断共享这一规范累计画像，只按角色投影可见字段。普通新增事实采用增量更新，撤销、更正和规则变化只触发受影响学生的有界重建。

同一学生的事实必须按稳定顺序逐条折叠并按稳定事实身份去重；worker 批次只用于并列处理不同学生。同一组事实无论增量分批、任务重试或完整重建，都必须产生相同的最终画像。

现有投影已经包含窗口筛选和时间衰减结果，因此切换时执行一次受控的累计画像迁移重建。本地生产数据副本必须先完成 dry-run、完整重建和结果验证；生产停服迁移再在备份后执行同一流程并重建当前班级聚合。重建只重算派生学习状态，不改写学习事实身份、来源或其绑定的原知识修订；该迁移不是日常全量计算机制。

生产切换前必须从生产数据库最新导出恢复本地副本，在本地完成完整迁移重建和结果验证；未经本地真实数据演练通过，不得开始上线操作。

演练通过后进入停服维护：停止应用、worker 和 scheduler，对生产数据库再次备份，并在生产执行同一份已验证的确定性迁移与回填。核验完成后再启动新版本，不建立在线双版本读取或原子激活机制，也不得使用演练期间导出的本地数据库覆盖生产数据库。

任何迁移步骤或验收失败都必须恢复停服前数据库备份和旧版本应用，不得启动部分迁移结果或在生产继续试错；修正后重新进行本地完整演练。
