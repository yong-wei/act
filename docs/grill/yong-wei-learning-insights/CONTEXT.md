# 领域语言（按上下文分组）

本文件收集本 scope（Git 用户 + 分支）grill 访谈产出的领域语言，按上下文分组；各 scope 的产出经 Git 合并后由 use-grill-me 全局扫描纳入共享知识。

## 学习画像与班级学情

该上下文描述学生累计学习状态以及教师面向当前班级成员观察整体和个体学情时使用的领域语言。

**学习事实**：
归属于单个学生、由受治理学习证据形成的原子记录；班级不是学习事实的所有者，也不限定学习事实的有效时间。
_避免：班级事实、近阶段事实_

**班级聚合边界**：
由班级当前学生成员集合形成的聚合范围；班级整体学情使用这些学生各自的完整累计学习状态，不按加入班级的时间截断。
_避免：班级事实归属、班级学习时间窗_

**班级整体学情**：
当前班级成员各自累计学习状态的群体投影；新增、移除或转入学生后，聚合结果随当前成员集合增量更新。
_避免：学生在该班期间的表现、班级历史事实汇总_

**累计学习状态**：
由学生全部有效学习事实支持的最新能力、趋势和风险状态；它只在新事实或受治理状态变更产生时更新，不因时间流逝而衰减、隐藏或失效。
_避免：近 30 天状态、按日历自动过期的画像_

**证据截至时间**：
累计学习状态所纳入的最后一条有效学习事实时间，用于解释状态的新旧程度，但不直接改变状态值。
_避免：画像失效时间、自动衰减时间_

**个人趋势**：
学生连续两次由有效学习事实触发的累计能力状态之间的方向性变化；没有新事实时保留最后一次趋势，不按日历窗口重新解释。
_避免：近 30 天趋势、无活动即下降_

**班级趋势分布**：
当前班级成员各自最后一次个人趋势的聚合，分别呈现上升、稳定、下降和尚无可比状态的人数与比例。
_避免：班级均值趋势、班级聚合值的趋势_

**风险状态**：
由学生最新一组有效学习事实支持的风险判断；没有新事实时保留最后状态，只有新的受治理计算结果才能降低、解除或替代它。
_避免：无近期活动即无风险、教师点击后自动解除_

**风险处置状态**：
教师对风险采取关注、干预或完成处置的工作流状态，不改变风险判断本身。
_避免：风险等级、风险解除证明_

**成长档案**：
归属于学生、记录累计能力变化和重要成长事件的受治理投影；当前班级教师可以查看完整历史摘要，学生离开该教师的班级后访问权立即结束。
_避免：班级成长记录、仅学生私有记录_

**成长档案摘要**：
教师可见的成长档案表达，包含能力变化、证据类型和发生时间，不默认包含原始答案、私人对话或隐藏评测内容。
_避免：原始学习载荷、完整私人记录_

**整体诊断**：
由七维累计画像、最后趋势、最后风险、成长事件和证据覆盖确定性形成的结构化判断，包含总体结论、优势、待提升点、限制和建议。
_避免：控制校正诊断、无证据的模型判断_

**诊断说明**：
对整体诊断结构化结论的可读表达；可以由 AI 辅助措辞，但不得增加结构化真源中不存在的判断。
_避免：AI 自主诊断、诊断真源_

**专项诊断**：
围绕单个能力、学习目标或任务形成的下一级诊断，例如控制校正诊断；它不是学生或班级整体诊断的替代品。
_避免：顶层整体诊断、默认诊断_

**班级诊断覆盖**：
当前班级成员中具备有效累计画像的人数与总人数；班级结论只聚合有画像成员，缺失成员单独报告且不按零分计入。
_避免：用零分补齐、因覆盖不全而隐藏全部结论_

**累计证据摘要**：
基于学生完整历史学习事实形成的数量、来源覆盖和证据截至时间摘要，不设置日历时间窗口。
_避免：近 30 天证据摘要、无限明细列表_

**最新学习活动**：
从学生完整历史活动中按发生时间倒序展示的分页记录；“最新”表示排序位置，不构成计算窗口。
_避免：近期活动、近 30 天活动_

**增量画像更新**：
新学习事实进入后，仅更新受影响学生的累计学习状态及包含该学生的当前班级聚合，不对全部学生或全部历史事实执行全局重算。
_避免：周期性全量重算、按时间窗口重建_

**有界画像重建**：
学习事实撤销、更正或计算规则变更时，对受影响学生的完整累计画像重新计算，再以新旧画像差量更新相关当前班级。
_避免：不可验证的反向扣减、全库画像重算_

**成员投影变更**：
学生加入、离开或转入班级时，将其最新累计投影加入或移出相应班级聚合；该过程不重建、复制或删除学生画像。
_避免：入班后重算历史、把学生数据迁移给班级_

**班级风险分布**：
当前班级成员各自最后一次有效风险状态的聚合，呈现风险等级、主要类型和尚无风险判断的人数与比例。
_避免：班级平均分风险、单一班级风险等级_

**教师历史证据视图**：
当前班级教师可以查看成员全部历史学习事实的标准教师投影，不按事实来源课程再次过滤；私人 AI 对话、隐藏评测内容和高频原始轨迹仍按角色级规则脱敏。
_避免：来源课程权限矩阵、取消所有敏感信息脱敏_

**证据年龄**：
证据截至时间与当前时间的距离，仅用于帮助读者理解状态来源；它不降低分数或置信度，不重置趋势或风险，也不使累计状态失效。
_避免：时间衰减、证据过期、无新事实即稳定_

**规范累计画像**：
学生端、教师个体页、班级聚合和整体诊断共同使用的唯一累计学习状态；角色差异只改变可见字段，不产生不同口径的画像。
_避免：学生版画像、教师版画像、近期兼容画像_

**累计画像迁移重建**：
新累计语义启用时对既有学生执行的一次性受控重建，用于清除旧时间窗口和时间衰减结果；完成后普通更新恢复为增量处理。
_避免：每次更新全量重算、沿用旧窗口画像_

**迁移演练**：
从生产数据库最新导出恢复到本地环境，执行完整迁移重建并核验画像、趋势、风险、班级聚合和诊断结果的上线前验证过程。
_避免：直接在生产首次试跑、仅用合成数据验证_

**生产迁移执行**：
本地真实数据演练通过后，在已备份的生产数据库上执行同一份确定性迁移与回填，并核验相同的计数、摘要和抽样结果。
_避免：用过期本地数据库覆盖生产、在生产首次试验_

**停服迁移**：
停止应用、worker 和 scheduler 后执行生产迁移与核验，完成前不接受新的学习事实，也不提供新旧混合的学情读取。
_避免：在线双版本切换、迁移期间继续写入_

**迁移回滚**：
生产迁移或验收失败后恢复停服前数据库备份和旧版本应用；部分迁移结果不得上线，修正后必须重新通过本地完整演练。
_避免：带错启动、在线补丁式修复_

**事实级累计折叠**：
同一学生的学习事实按稳定顺序逐条进入累计计算，并按稳定事实身份去重；worker 批次只能并列处理不同学生，不能把同一学生的多条事实合并为一次不可分计算。
_避免：批次级画像更新、依赖队列分批的结果_

**累计结果一致性**：
同一组有效学习事实经增量处理、重试或完整重建后必须产生相同的最终画像。
_避免：路径依赖画像、批量大小改变分数_

**事实发生顺序**：
学习事实按发生时间排序，同一时间使用稳定事实身份确定顺序；迟到事实插入历史序列后，对受影响学生执行有界重建。
_避免：按入库时间解释趋势、把迟到事实追加为最新变化_

**个人诊断覆盖**：
学生七个能力维度中具备有效证据的维度数与总维度数；总体分只计算有效维度，缺失维度单独报告且不计零分。
_避免：七维平均分、用零分补齐缺失维度_

**统一累计学情视图**：
个人和班级学情只呈现规范累计画像、最后趋势、最后风险、最新活动与累计证据，各区块分别标明证据截至时间。
_避免：累计与近阶段切换、`scope=recent` 学情口径_

**相关证据更新**：
新学习事实只更新其能够映射到的能力维度、趋势和风险类型；无关事实不得重置其他维度趋势或解除其他风险。
_避免：任意新事实全局刷新状态、无关证据解除风险_

**成长事件**：
进入成长档案的有意义状态变化，包括总体或能力等级变化、明确优势的形成或失去、风险的证据性变化，以及具有明确能力贡献的重要任务或里程碑。
_避免：每条学习事实的副本、普通活动流水账_

**画像对账**：
由学生或获授权教师主动触发的幂等检查，只处理尚未进入画像的新增、更正或撤销事实；没有待处理事实时不创建快照或改变状态。
_避免：无证据刷新、强制改变画像时间_

**班级学情对账**：
教师为当前班级成员分别排队执行画像对账，并在学生任务完成后更新班级聚合的操作；每个学生仍是独立处理单元。
_避免：合并全班事实计算、全库画像重建_

**画像对账任务**：
承载单生或班级画像对账的幂等后台任务，向页面报告处理中、完成数和失败数；重复请求不得重复计算同一待处理事实。
_避免：长时间同步请求、重复更新任务_

**诊断建议**：
由有证据的待提升维度、最后风险和当前可用教学资源确定性生成的建议动作，只能引用已注册且可访问的资源。
_避免：AI 临时编造资源、空数组冒充无建议_

**顶层整体诊断**：
个人和班级学情页面默认呈现的整体诊断；控制校正等专项诊断只在明确进入相应目标时展示。
_避免：以单项目标诊断替代整体诊断_

**画像合格事实**：
通过治理校验、允许进入画像且具有明确能力贡献的学习事实；只有这类事实能够改变分数、趋势、风险和诊断。
_避免：上下文事实、测试事实、演示事实、无法映射能力的事实_

**画像置信度**：
由有效证据数量、质量、来源覆盖和一致性形成的判断可靠程度，不随时间下降，也不表示能力高低。
_避免：证据新鲜度、能力分数、只增不减的计数_

**班级等权聚合**：
班级总体分和维度分对每个具备相应有效画像的当前成员赋予相同权重，并分别报告纳入人数、缺失人数和平均置信度。
_避免：按学生置信度加权、用班级总人数替代维度分母_

**能力维度范围**：
个人和班级整体诊断顶层固定使用规范累计画像的七个能力维度；课程学习目标和控制校正等专项目标不代表整体能力范围。
_避免：单一学习目标、以目标 ID 冒充能力维度_

**学情可用性原因**：
画像或诊断字段不可用时返回的明确原因，并关联可执行的恢复动作；缺失、迁移中、处理失败、无匹配资源和角色不可见必须区分。
_避免：暂无、待生成、无证据_

**趋势判定**：
当前累计分相对上一个证据触发状态变化超过 `+5` 为上升，低于 `-5` 为下降，其余为稳定；个人总体趋势使用总体分，班级只聚合个人总体趋势。
_避免：任意微小变化即趋势变化、班级均值趋势_
