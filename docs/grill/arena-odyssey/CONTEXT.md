# Arena Odyssey

This context defines the boundary between Arena-assigned Control Odyssey challenges and ordinary Control Odyssey progression.

## Language

**Arena-assigned Odyssey session**:
A Control Odyssey run launched from an Arena task and bound to that task's designated level.
_Avoid_: Free-play Arena run, level picker run

**Temporary level access**:
Permission to run a designated Odyssey level inside one Arena-assigned session without changing ordinary Odyssey unlock state.
_Avoid_: Permanent unlock, progression bypass

**Ordinary Odyssey progression**:
The learner's persistent Control Odyssey credits, completed tiers, and unlocked level chain outside Arena assignments.
_Avoid_: Arena progression, assignment unlock
