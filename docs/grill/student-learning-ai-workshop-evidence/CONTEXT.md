# AI 工坊学习证据投影

该上下文定义 AI 工坊中学生学习信息的来源边界和可见状态，避免将演示数据作为学生事实呈现。

## 领域语言

**AI 工坊学习证据投影**：
AI 工坊面向当前认证学生展示的、由服务端受治理学习状态派生的最小学习信息集合，并保留每项信息的可用性说明。
_避免_：样例画像、浏览器拼装画像、默认学生数据

**个性化可用性**：
当前学生是否具备足以支持某项学习提示或画像表达的受治理证据状态；缺失、不可用和数据不足必须与已有数据明确区分。
_避免_：默认可用、空值等同零分、静默降级

**样例学习数据**：
只用于开发夹具、组件预览或明确标注的演示场景的虚构学习信息，不能在生产学生视图中作为个人时长、能力、成就、任务进度或推荐结果出现。
_避免_：当前学生记录、默认画像、演示即真实
