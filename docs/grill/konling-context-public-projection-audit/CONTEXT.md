# 控灵运行上下文公开投影

本上下文界定学生浏览器可以获取的控灵上下文，避免将学习画像内部结构、私有记忆、治理标识和工具权限当作学生产品数据返回。

## Language

**学生安全上下文投影**：由服务端从受治理运行态派生的最小表示，只包含学生完成当前任务所需的产品语义、局限说明和可执行行动。_Avoid_：完整 runtime DTO、调试响应、客户端脱敏后的内部对象

**内部学习画像上下文**：服务端用于建模、证据聚合、策略决策和审计的结构化数据，可包含来源覆盖、缺失上下文和派生状态，不属于通用浏览器 API。_Avoid_：个人中心指标、学生可见画像卡片

**控灵私有记忆**：受服务端授权、保留和治理约束的会话或学习记忆，可用于模型执行，不得通过上下文接口整体返回给浏览器。_Avoid_：学生可见聊天历史、明确由学生保存的反思草稿

**内部治理诊断**：用于排障、缺失上下文识别、工具授权和来源追踪的标识与代码，只能留在服务端日志或受限管理面。_Avoid_：学生产品文案、通用 JSON 响应
