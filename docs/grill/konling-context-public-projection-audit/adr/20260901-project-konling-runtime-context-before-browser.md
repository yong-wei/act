# 控灵运行上下文必须先生成学生安全投影

`/api/ai/konling-context` 当前把学习画像、计划、知识工作区、教学投影、双域来源、私有记忆、允许工具和缺失上下文等内部运行结构整体返回给学生浏览器。决定废弃这个公开完整 runtime DTO：如果生产页面确有需求，必须由服务端显式映射为最小学生安全投影，仅使用产品语言表达当前帮助能力、可用性与局限。私有记忆、内部来源、缺失原因代码、工具权限和治理标识不得进入学生响应。仅测试使用不能成为保留生产公开诊断接口的理由；测试应改为验证服务端投影边界。
