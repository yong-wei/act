# 以标准仿真运行作为实验档案主身份

AI 工坊实验档案采用标准仿真运行作为仿真活动的主要身份，同时保留竞技场提交和历史日志的来源语义；同一次奥德赛活动在多个来源表中出现时只投影一个档案条目，并由来源专属入口承担复盘。这样可以利用平台已有的运行摘要和复现信息，避免学生看不到实际完成的控制工作台实验，也避免把一次活动误计为多次训练。旧日志仅在缺少对应标准运行时作为兼容来源，不能覆盖标准运行的权威性。

## Considered Options

- 继续分别读取日志和竞技场提交：实现简单，但会遗漏标准运行并产生重复活动。
- 只读取标准仿真运行：身份统一，但会丢失尚未桥接的历史奥德赛记录和竞技场正式提交语义。
- 以标准仿真运行为主、按稳定跨来源身份合并兼容来源：保留历史覆盖面，同时让学生看到单一、可复盘的学习活动。采用此方案。
