# AI 工坊实验档案

该领域定义 AI 工坊如何呈现学生已经完成或具备展示资格的仿真与竞技场实验，使学生能够从学习工作区回到真实实验过程并理解结果来源。

## 领域语言

**标准仿真运行**：
由平台统一记录、带有学生归属、任务身份、运行状态、结果摘要和复现信息的一次证据性仿真运行，是实验活动的主要身份。
_避免_：只存在于页面状态的实验、把日志明细当作完整运行身份

**实验档案条目**：
从当前学生的标准仿真运行或竞技场提交投影出的有界摘要，保留来源类型、结果权威性、发生时间和可达的复盘入口。
_避免_：样例卡片、无来源的分数、无法打开的历史记录

**来源专属复盘入口**：
与实验来源和稳定身份相匹配的学习页面或复盘页面，使学生能继续查看该次实验，而不是回到没有目标的通用入口。
_避免_：所有记录统一跳转到竞技场首页、只显示不可交互的历史卡片

**跨来源实验身份**：
用于识别同一次学习活动在仿真日志、标准仿真运行和竞技场提交中的对应关系的稳定身份。
_避免_：以表名或展示标题判断是否为不同实验

**结果权威性**：
实验结果属于预览、练习还是正式评测的明确语义；预览或无效结果不能被学生界面称为正式成绩。
_避免_：把存在分数的记录都称为官方结果
