# 学习过程陪伴：提示词评价历史

## 领域术语

**提示词评价尝试**：
学生围绕自动控制任务提交一次提示词后产生的质量评价记录，包含任务会话、版本、质量维度、改进建议与发生时间。
_避免_：官方成绩、学习事实、任意用户日志

**过程一致性结果**：
针对一个既有提示词评价尝试，将提示词声明的控制目标与该次参数迭代过程进行比较后得到的受限过程分析。它附着于同一评价尝试，不独立形成成绩或能力达成。
_避免_：独立成绩、画像贡献、自由文本诊断

**评价会话**：
学生在提示词评价工作台内进行连续版本迭代的稳定边界。版本号只在同一学生、同一会话内递增。
_避免_：浏览器进程、客户端声明的用户身份

**提示词评价历史**：
由认证学生拥有的、按评价会话和版本可追溯的评价尝试集合。其读取范围仅限记录所属学生。
_避免_：共享内存缓存、教师可见原始提示词、跨用户查询

**受限任务上下文**：
与一次评价尝试关联的来源、任务、意图与输出目标等有界描述，用于解释评价发生的学习场景；它不授予权限，也不决定任何正式写回。
_避免_：客户端权限声明、模型提示词、学习事实治理声明

**评价历史投影**：
供学生界面展示的版本、评分、建议、一致性结果与时间摘要。它不自动将原始提示词或结构化输入升级为学习画像证据。
_避免_：正式学习记录、能力证据、跨角色数据导出

## 已确认边界

- 认证会话中的学生身份是评价写入和历史读取的唯一归属来源；请求体或路径中的 `userId` 不构成授权依据。
- 演示模式只保留客户端本地样例，不调用生产评价接口绕过认证。
- `PromptAssessment` 记录用于学习过程回顾与审计；在没有独立治理变更前，它不写入 `LearningFact`，不影响学习画像、官方成绩、排行榜或推荐。
- 过程一致性必须绑定到已持久化且属于当前学生的评价尝试；无法找到该尝试时不得创建游离结果。
