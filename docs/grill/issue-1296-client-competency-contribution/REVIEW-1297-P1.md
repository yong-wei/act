# PR #1297 P1 审查处置

## 结论

处置：ACCEPT。

共享 LearningFact 物化器引入默认拒绝后，历史物化路径构造的服务端证据事件未获得内存授权，导致后续回填和重建写入空能力贡献。这改变了本变更明确要求保留的服务端历史证据语义。

## 边界

- `InteractionLog` 是原始客户端互动遥测。即使经过历史来源分类而成为 eligible，仍不具备能力贡献资格。
- 已通过来源、真实性与资格门禁的服务端来源在白名单内显式获得授权。
- 回填脚本继续调用同一个候选事实计划器；不增加 HTTP 字段、数据库结构或脚本参数。

## 验证

- 服务端历史 `SimulationLog` 仍保留静态能力映射贡献。
- 历史 `InteractionLog` 的静态事件映射仍物化为可追溯事实，但能力贡献为空。
- 原有客户端伪造、服务端自适应测评和教师审核回归持续执行。
