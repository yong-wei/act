# 将成长诊断建议连接到正式学习入口

## 状态

已接受

## 背景

成长中枢向学生展示“继续学习”或“巩固能力”等建议时，建议必须能够落到真实可用的学习行动。当前存在使用失效的旧课程路径、以及接口不提供行动地址导致前端退化为空链接的情况。两者都会使诊断与学习行动脱节，学生无法据此继续学习。

## 决策

成长诊断的建议统一使用平台正式的互动课程入口作为可执行导航边界。能够确定具体学习资源时，建议可以进入该资源的正式学习地址；不能确定具体资源时，进入正式课程目录，由学生继续选择。诊断建议的导航参数只表达学习入口，不改变学生的证据、成绩、解锁或路径状态。

## 取舍

- 使用正式互动课程路由可以避免旧路径产生 404 或空页面。
- 保留“无法定位具体资源时进入课程目录”的降级行为，可以避免臆造学生应进入的课程或任务。
- 该决策只修复诊断到学习行动的可达性，不扩大为重新设计路径规划或重新生成诊断规则。

## 验证要求

- 有诊断建议地址时，成长中枢的建议卡片必须进入有效的学生学习入口。
- 诊断卡片中的下一步行动必须不再使用失效的旧课程根路径。
- 建议地址不可用时，页面必须提供明确的不可执行状态，不渲染空链接。
- 现有诊断证据、权限和学习状态不得因导航而改变。
