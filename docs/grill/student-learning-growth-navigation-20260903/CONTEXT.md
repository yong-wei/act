# 成长诊断学习导航

本范围记录成长中枢中“诊断结论如何引导学生进入下一项真实学习行动”的共享术语与边界。

## 术语

**成长诊断**

基于学生已验证学习证据形成的能力状态、风险说明和下一步建议。成长诊断可以说明证据不足，但不得把缺少证据解释为能力为零。

**诊断建议**

成长诊断向学生展示的下一步行动提示。建议必须能够进入与当前学习目标相符的真实学习入口；不可执行时应明确说明原因。

**学习行动**

学生可以实际开始或继续的课程、资源或路径活动。学习行动不是仅改变页面地址的跳转，也不是通用页面中无法继续的占位链接。

**课程入口**

学生浏览和选择互动课程的正式入口。它用于没有足够信息定位到单个课程任务时的诚实降级，不代表诊断已经确定了具体任务。

## 边界

- 成长诊断只使用服务端拥有且已验证的学习证据。
- 诊断中的导航信息用于引导学生，不构成学习事实、成绩或路径解锁授权。
- 具体学习目标和资源能够可靠确定时，建议应指向对应的学习行动；无法确定时，应进入正式课程入口或显示可解释的不可用状态。
- 学生端所有学习入口必须使用平台当前有效的正式路由，不能依赖历史别名。
