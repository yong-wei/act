# 自适应路径推荐依据追溯

本上下文记录 Issue #1186 第一阶段的领域语言和实现边界：解释生成候选路径时采用的聚合推荐依据。Issue 仍保留活动路径节点解释和事件级证据回跳等后续工作。

## Language

**候选路径推荐依据**：
正式生成的候选路径卡片中，基于生成时聚合状态连接证据摘要、能力判断和推荐资源的学生可见说明。第一阶段只覆盖候选路径选择，不提供事件级证据追溯。
_Avoid_: 路径差异解释、活动路径节点说明、逐条证据来源或时间线

**脱敏证据摘要**：
候选路径生成时保存的聚合学习状态投影，包含目标名称、状态值、有效证据数量、置信度和学习记录入口；它不是逐条事件引用，不包含原始答案、私密对话、内部标识或原始证据载荷。
_Avoid_: 原始学习记录、事件级来源声明、无来源的薄弱结论、内部诊断载荷

**薄弱项解释链**：
候选路径内以一个知识或能力薄弱项为单位组织的推荐依据，依次呈现脱敏证据摘要、能力判断及由该判断影响的推荐资源。多个资源受同一薄弱项影响时归入同一解释链。
_Avoid_: 路径整体空泛理由、每个资源重复同一证据、路径差异指标

**低置信度推荐依据**：
有效学习证据不足以支持可靠个性化判断时的学生可见说明。它明确标注低置信度，说明路径主要依据课程知识结构、先修规则和可用资源生成，并给出完成诊断或练习等补证动作。
_Avoid_: 将缺失证据按零分处理、伪造个性化结论、静默隐藏证据缺口

**推荐依据摘要**：
候选路径卡片始终显示的一行关键结论，用于概括主要薄弱项或低置信度限制；完整薄弱项解释链由学生通过“查看推荐依据”按需展开。
_Avoid_: 始终展开全部证据、只提供离开页面的跳转按钮

## Confirmed Boundaries

- 第一阶段仅覆盖正式生成的候选路径卡片。
- 不修改活动路径执行区及其节点详情。
- 不把候选路径推荐依据表述为候选路径之间的差异解释。
- 学生可见内容采用生成时聚合摘要，并提供进入既有学习记录页面的通用复核入口；不声称能从摘要回跳到具体证据事件。
- 不在候选路径卡片中直接展开逐条原始证据。
- 推荐依据按薄弱项分组，明确每项判断影响的候选路径资源。
- 证据不足时保留候选路径，但必须标记低置信度、说明规则依据并提供补证动作。
- 卡片常显推荐依据摘要，完整解释链按需展开，并兼容桌面端与 320px 移动端。
- 完整解释链提供既有学习记录页面的复核入口，但不以跳转替代当前卡片内的解释。
- 任一解释条目为低置信度时，路径级摘要和置信度同步降级，避免混合证据被表述为可靠个性化结论。
- #1186 保持开放；活动路径节点推荐依据、节点调整解释和事件级证据回跳不属于本阶段。
