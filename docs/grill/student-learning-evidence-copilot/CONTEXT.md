# Evidence Copilot 领域语言

## 学习证据复盘

学生围绕已经产生的、可追溯学习事实进行理解、解释和下一步练习规划的陪伴过程。它不等同于通用问答，也不直接产生官方成绩或能力结论。

## 受治理学习证据

通过身份、来源、可见范围和质量规则校验，能够被授权投影给当前学生的学习事实或评测结果。未经验证的客户端描述不属于受治理学习证据。

## 证据上下文

服务端根据当前学生身份和受治理证据形成的、供陪伴回答使用的有限事实摘要；上下文必须保留来源状态和限制，不能扩展为未证实的个人判断。

## 证据可用性

当前是否存在可供 Evidence Copilot 使用的受治理证据，以及证据是否完整、部分可用或暂时不可用。无证据与服务不可用必须和已知的零值区分。

## 学习行动

学生可以立即执行的下一步学习操作，例如打开真实反思创建流程、补充一次练习或查看可用证据来源。行动必须与当前状态真实对应，不得只提供无上下文的装饰性链接。

## Evidence Copilot 边界

Evidence Copilot 只能解释已授权的学习证据并提出受限建议；它不能把 URL 参数、学生自填描述或模型推测提升为学习事实、官方成绩、学习画像或排行榜数据。
