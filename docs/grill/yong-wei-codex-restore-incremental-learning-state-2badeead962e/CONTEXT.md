# ACT 课堂教学

本上下文统一教师选择授课班级以及课堂创建过程中的领域语言。

## 班级选择

**默认班级**：
教师在账号范围内对其名下活动班级建立的全局唯一长期偏好关系，用于非班级内开课入口的预选；它归属于教师，不是班级自身的固有属性。教师只有一个活动班级时由该班级自动担任。默认班级停用或删除后，由创建时间最新的其余活动班级接替；没有活动班级时不存在默认班级，教师不能开启新课堂。新增或重新启用其他班级不会替换已有默认班级，替换必须由教师主动发起。默认班级的变化只影响未来课堂的预选，不改变任何既有课堂的授课班级。
_避免：临时课堂、最近使用班级、班级固有属性_

**临时课堂**：
不绑定授课班级、仅供管理员演示或运维使用的课堂。教师开启的课堂必须绑定其名下活动班级，不能使用临时课堂。
_避免：教师默认课堂、未选择班级的教师课堂_

**未归属历史课堂**：
既有数据中缺少真实授课班级证据的教师课堂。教师当前或后续设置的默认班级不能用于推定这类课堂的历史归属。
_避免：默认班级课堂、可自动回填课堂_

**授课班级**：
教师开启课堂时实际绑定的活动班级。班级内部开课以当前班级为授课班级且不得回退；当前班级已停用时必须先重新启用，才能开启课堂。教师为单次课堂选择其他授课班级不会改变默认班级。
_避免：默认班级、停用班级、临时课堂_
