# Issue #1097 学习路径分化

本词汇表记录个性化学习路径生成中与候选方案差异相关的业务语言，供本议题的决策与实现共用。

## Language

**有效方案差异**:
候选学习路径在教学意图和资源组合上存在可感知、可验证的差别，而非仅调整资源顺序、标题或说明。无法形成这种差别时，应减少候选方案数量。
_Avoid_: 装饰性差异、凑数方案

**配置兑现**:
结构化个性化配置在生成时改变候选路径的选择或编排；资源、目标和安全等硬约束优先，无法满足的配置必须被明确说明。
_Avoid_: 仅作评分信号、静默忽略配置

**自由文本意图**:
学习者以自然语言表达、经系统解释后可影响学习路径选择或编排的目标和偏好。解释失败或与硬约束冲突时，系统必须说明未满足原因。
_Avoid_: 仅存档的意图、不可解释的提示词

**配置生效证据**:
在资源池存在可行替代方案时，互斥配置导致非终点学习资源或方案数量发生变化的可验证结果；无可行替代方案时，以明确的未满足原因替代路径变化。
_Avoid_: 仅改变评分、理由或说明文字

**可验证意图映射**:
将自由文本意图识别为既有路径规划概念的确定性规则；只接受可映射的资源类型、节奏、检查点、外部资源和目标节点，其他表达必须声明未应用。
_Avoid_: 不可审计的语义猜测、原样透传

**可分化教学资源**:
在满足目标、先修条件和终点验证后，策略方案可替换或调整的教学资源。不同候选方案必须在这类资源上形成可验证差异；必需先修与终点验证节点可以共享。
_Avoid_: 全路径零重叠、只改变策略标签

**顺序避让生成**:
按照确定的策略优先级逐个生成方案；已保留方案的可分化教学资源成为后续方案的避让对象。没有满足约束的替代路径时，系统省略该方案并说明原因。
_Avoid_: 生成后只报告重叠、固定补充节点

**配置兑现说明**:
随路径结果返回并向学生展示的结构化摘要，列出已参与规划的配置、对路径造成的影响，以及无法满足的配置和原因。
_Avoid_: 仅服务端诊断、不可消费的说明文字

**请求级资源偏好**:
学习者在当前路径生成请求中显式选择的资源类型偏好。它覆盖历史学习者偏好；只有请求未提供该配置时，历史偏好才作为回退值。
_Avoid_: 与历史偏好并集、静默由历史偏好覆盖

**预算不足**:
在保留必需终点验证的前提下，学生请求的学习时长低于可执行路径的最低时长。系统不改写请求，而是说明最低时长和无法满足的原因。
_Avoid_: 静默提高预算、跳过终点验证
