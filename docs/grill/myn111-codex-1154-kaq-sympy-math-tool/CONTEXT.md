 # KA-Q SymPy 公式推导工具

 KA-Q SymPy 公式推导工具是 KA-Q 知识能力质量系统中的一个学生侧学习辅助组件，使用 SymPy 符号计算库自动执行数学公式的逐步推导。

 ## 术语

 **推导引擎**：
 由 Python SymPy 库驱动的符号数学计算核心，负责执行拉普拉斯变换、符号化简等数学运算，并生成可消费的推导步骤序列。
 _避免使用_：公式计算器、数学求解器

 **推导流水线**：
 从接收推导请求到返回结构化推导结果的完整处理链路。包含输入解析、SymPy 运算编排、步骤格式化、LaTeX 序列化四个阶段，由 Next.js API 路由编排。
 _避免使用_：推导函数、公式处理链

 **推导步骤序列**：
 推导过程中每一步的数学变换记录。每条步骤包含步骤序号、步骤描述（自然语言）、输入表达式（LaTeX）、变换操作和输出表达式（LaTeX），构成可逐步展示的教学路径。
 _避免使用_：推导日志、计算历史

 **拉普拉斯变换推导**：
 对给定的时域函数 \(f(t)\) 执行拉普拉斯变换 \( \mathcal{L}\{f(t)\} = F(s) \) 的逐步推导过程。推导覆盖常用变换对、线性性质、微分性质、积分性质和时移性质的自动应用，最终输出完整的 \(F(s)\) 表达式及中间步骤。
 _避免使用_：拉氏变换计算、直接输出结果

 **符号化简**：
 对有理传递函数、多项式、分式等符号表达式执行代数化简的过程。包括因式分解、部分分式展开、多项式除法和复数域化简等操作，得到最简形式或特定规范形式。
 _避免使用_：公式简化、自动约分

 **推导请求载荷**：
 客户端提交给推导 API 的结构化请求数据。包含推导类型（`laplace`、`simplify`、`inverse_laplace`）、输入表达式（LaTeX 字符串）、变量标识符以及额外参数（如初值条件）。
 _避免使用_：公式文本、输入字符串

 **推导响应载荷**：
 推导 API 返回给客户端的结构化响应数据。包含推导状态、步骤序列（每步含 description、operation、input、output 的 LaTeX）、最终结果以及错误信息（如有）。
 _避免使用_：计算结果、JSON 数据

 **交互式公式展示**：
 将推导步骤序列渲染为带有 LaTeX 公式、逐步动画和高亮变换的学习者界面的前端组件。
 _避免使用_：公式显示、数学卡片
