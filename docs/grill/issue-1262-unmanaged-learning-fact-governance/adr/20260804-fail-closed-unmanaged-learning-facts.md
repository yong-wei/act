# 未治理学习事实按零权重处理

Issue #1262 发现缺少 `evidenceGovernance.profileWeight` 的学习事实会因隐式默认值 `1` 影响画像、能力向量和推荐。决定采用失效封闭策略：只有明确声明画像贡献资格的学习事实才可参与个性化；声明缺失、不完整或不可解析时统一按权重零处理，并仅保留为上下文事实。

## 已考虑选项

- 默认低权重：仍会把没有质量依据的记录变成能力证据，无法表达“尚未审核”。
- 为历史来源建立兼容白名单：白名单会把未知语义重新编码为隐式信任，且随生产者演化失效。
- 失效封闭：要求有意参与画像的生产者写出 `profileWeight` 与 `skipProfileContribution`，历史未治理记录保持可审计但不回填或自动升级。

## 后果

缺少治理声明的历史事实将不再改变画像或基于画像的推荐。已审核且需参与画像的生产者必须在写入时明确质量治理字段；本变更不对历史数据做推断性回填。
