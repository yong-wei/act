# 学习事实质量治理

本上下文约束学习事实进入学习者画像、能力向量和个性化推荐时的证据资格。

## 术语

**受治理学习事实**：其 `evidenceGovernance` 同时明确 `profileWeight`、`skipProfileContribution` 与适用策略原因的学习事实。
_避免_：默认可信事实、隐式合格事实

**未治理学习事实**：缺少完整画像贡献治理声明的学习事实；它可被保留用于审计和活动上下文，但不构成学习能力证据。
_避免_：低质量事实、无效事实

**画像贡献**：学习事实对学习者画像、能力向量或以这些投影为依据的个性化决策产生的可计量影响。
_避免_：活动记录、审计线索

**上下文事实**：保留来源、时间和业务上下文但画像权重为零的学习事实。
_避免_：画像证据、能力证据
