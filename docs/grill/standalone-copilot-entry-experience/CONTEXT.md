# 独立 Copilot 入口体验

该上下文定义学生直接进入 `/ai/copilot` 时页面如何表达当前学习任务、可用能力和建议问题，避免把一个特定仿真场景伪装为通用学习陪伴。

## Language

**通用陪伴入口**：
学生未从受治理学习任务进入时看到的中性 Copilot 状态，只承诺通用解释、复盘和学习规划能力，不假定具体对象、方法、规范或运行数据。
_避免：默认船舶仿真、默认 PID、空任务页_

**任务匹配入口**：
由服务端已验证任务契约或学习证据决定标题、说明、建议问题和下一步行动的 Copilot 页面状态。
_避免：URL 文案驱动、客户端自由场景、固定快捷问题_

**能力承诺**：
页面明确告诉学生当前 Copilot 可以执行的操作；每项承诺必须有当前已绑定的工具、证据或任务流程支持。
_避免：宣传文案、不可执行按钮、模型可能会做_

**建议问题**：
与当前任务和可用上下文对应、学生点击后能够得到有根据回答的候选提问。
_避免：演示问题、固定 PID 问题、无运行态的数据请求_

**上下文空缺**：
当前没有受治理任务、课程资源或学习证据可供绑定的状态；页面应明确限制并提供选择真实学习入口的行动。
_避免：默认场景、伪造当前任务、静默降级_
