# Arena Learning Evidence Context

## Ubiquitous Language

- **Arena 虚拟训练运行**：学生在 Arena 工作台完成并持久化为 `ArenaVirtualSimulationRun` 与规范 `SimulationRun` 的预览性仿真；它具有任务、场景、摘要与重放来源，但不是官方评测。
- **训练证据**：从虚拟训练运行物化的、带有任务归因与预览来源的 `LearningFact`；它可用于低置信度学习画像和训练记录。
- **官方提交证据**：由 `ArenaSubmission` 与官方评测产生的权威成绩、约束和排行依据。
- **个人中心训练统计**：个人中心中单列的虚拟训练次数、近期训练和质量摘要；不得与官方提交统计混合。
- **能力观察信号**：训练证据对学习画像或成长建议提供的低置信度、可追溯信号；不得单独宣称正式能力达成。
