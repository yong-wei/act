# 虚拟训练证据与官方评测隔离

## Context

Arena 虚拟仿真训练能够反映学生在控制参数调节和场景理解上的练习过程，但它不是具有统一约束、有效性校验和排名语义的官方提交。将预览训练直接计入官方成绩、任务解锁或正式能力达成，会把不同可信度的学习证据混合，并破坏既有排行榜和评测契约。

个人中心仍需要呈现持续练习的可追溯记录。历史 `ArenaVirtualSimulationRun` 已保存训练事实，而历史 `LearningFact` 不一定具备 Arena 任务归因，不能通过猜测回填。

## Decision

- 将虚拟训练作为独立的预览性学习证据：后续训练以紧凑的任务、场景、预览边界和重放来源写入 `LearningFact`，其能力贡献保持低置信度并受限。
- 个人中心从学生自己的 `ArenaVirtualSimulationRun` 读取训练历史，官方提交统计保持只读取 `ArenaSubmission`。
- 全历史训练次数与最近五次训练的次数、质量均值和记录明确区分口径；页面和 API 不把最近窗口指标表述为全历史汇总。
- 不回填缺少任务归因的历史 `LearningFact`，也不把预览训练写入排行榜、有效提交率、任务解锁或正式能力达成。

## Consequences

学生可以在个人中心看到与任务关联的练习轨迹，学习画像可获得可追溯但受限的训练观察信号。官方评测的成绩、排名和能力结论保持原有可信度边界；历史数据保持可读，但不会被伪造为具有新语义的学习事实。

## Traceability

本 ADR 在实现完成后的交付复核中补录，依据 `surface-arena-training-evidence` OpenSpec 的 proposal、design、spec delta 和已完成 tasks；它不将该记录表述为实现前访谈。
