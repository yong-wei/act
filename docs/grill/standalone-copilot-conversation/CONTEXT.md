# 独立 Copilot 会话连续性

该上下文定义独立 `/ai/copilot` 页面与平台控灵持久会话之间的共同语言，避免把页面内临时消息误认为可恢复的学习陪伴历史。

## 领域语言

**独立 Copilot 会话**：
学生在 `/ai/copilot` 页面中进行的、归属于当前认证用户的控灵会话。它复用平台会话库和跨页面连续性，不是页面组件内的临时消息数组。
_避免：本地聊天、一次性问答、独立会话存储_

**会话恢复**：
页面刷新、离开后重开或从其他受支持页面继续时，重新读取同一用户会话及其可见消息、工具记录和受控页面上下文。
_避免：重新创建空会话、浏览器缓存恢复_

**会话清空**：
学生明确新建空白会话或确认删除既有会话的受治理操作；仅隐藏当前组件消息不构成清空。
_避免：`setMessages([])`、无持久化的清屏_

**任务态上下文**：
作品集反思、证据复盘等 Copilot 入口在当前轮次使用的服务端任务契约。任务态上下文可以随会话继续，但不能改写历史消息、扩大证据权限或改变候选草稿边界。
_避免：客户端自由提示词、会话权限声明、自动写回_

## 已确认边界

- 独立 Copilot 复用现有用户级控灵会话库，不建立第二套消息存储。
- 发送消息必须绑定服务端可验证的会话身份；刷新和重开不得静默显示为空历史。
- 当前页面和任务态变化以受控上下文追加表达，不覆盖既有会话记录。
- 会话消息仍是学习辅助内容，不自动写入成绩、排行榜、LearningFact、学习画像或正式反思记录。
