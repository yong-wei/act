# 个人档案使用服务端证据投影

个人学习档案改为通过认证后的服务端聚合接口读取课堂提交、仿真日志和伦理日志，并由服务端按当前用户和字段白名单生成展示摘要；不继续让客户端分别调用带有用户 ID 的接口，也不把客户端占位数据当作学习证据。这样可以同时保持用户隔离、来源可追溯和“暂无记录”与“来源不可用”的区分，而无需引入新的事实表或改变现有写入链路。

## Considered Options

- 继续在浏览器端调用现有写入接口：拒绝，因为 GET 语义缺失且会扩大越权与跨接口契约风险。
- 为档案新增独立作品表：拒绝，因为现有课堂提交、仿真日志和伦理日志已经是可追溯来源，新增表会产生重复真源。

## Consequences

档案接口只返回展示所需的摘要字段；提示词历史仍由独立的持久化与授权变更负责，本变更不复制其逻辑。
