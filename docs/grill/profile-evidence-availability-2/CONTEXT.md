# 学习档案证据投影

本上下文定义个人学习档案如何显示学生本人已经产生的课堂、仿真和伦理学习证据。它只描述领域语言，不替代 OpenSpec 的实现合同。

## 领域术语

**学习档案证据投影**：从已有受治理持久化记录生成的学生本人只读展示集合；它不创建新的学习事实，也不改变原始记录的权威性。
_避免：样例数据、学习画像、自动生成作品_

**课堂作品**：学生在已参加课堂会话中提交并持久化的步骤响应，经服务端压缩为可读的作品摘要后显示在个人档案中。
_避免：实时状态、教师同步状态、原始答案载荷_

**仿真设计记录**：学生本人一次已持久化仿真日志中的控制模式、得分、参数摘要和时间；轨迹与内部运行载荷不属于档案展示内容。
_避免：官方成绩、排行榜记录、客户端预览样例_

**伦理整改案例**：学生本人产生的伦理违规记录及整改文本；案例保留未整改状态，只有存在真实整改文本时才显示整改内容。
_避免：全局伦理统计、他人案例、自动生成的整改结论_

**来源不可用**：档案接口无法读取某一证据来源时的明确状态；它与“暂无记录”不同，不能静默显示为空。
_避免：空数组掩盖读取失败、伪造零记录
