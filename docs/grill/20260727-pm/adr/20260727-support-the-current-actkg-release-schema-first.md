# 首轮只兼容当前 ActKG 发布包 Schema

## 状态

已接受

## 背景

当前只有 `root-locus-engineering-v0.1` 一个正式局部发布包。ActKG Schema 仍在形成中，第二个发布包很可能发生真实结构变化。此时预建多版本 Schema 登记、自动兼容和迁移框架，会基于未知变化做过度抽象，也无法通过第二个真实样本验证。

## 决策

1. 首轮 Release 接入只支持并完整验证当前根轨迹发布包携带的 Schema 和 `contract_hash`。
2. 当前接入仍须保存完整对象、关系、来源、证据及原始 Release，并通过固定 Schema 校验和往返验证。
3. 不在首轮建设通用 Schema 合同登记、多版本适配或自动迁移框架。
4. 第二个正式发布包出现 Schema 变化时，基于真实差异扩展 ACT 接入合同、数据库信封或类型适配器，并补充兼容性测试。
5. 未完成明确适配和验证的新 Schema 发布包不能加入候选 ReleaseSet。
6. 当前发布包只携带来源运行和来源实现提交。首轮导入收据如实保存已有血缘，并将 CTKGDataset 与 RevisionProposalRegistry 引用标记为未提供；不得虚构缺失字段，也不得仅因这些未来字段缺失而拒绝当前锁定发布包。

## 结果

- 首轮范围集中在真实发布包的无损接入。
- 未来兼容设计由实际 Schema 变化驱动。
- 未知 Schema 不会被自动导入并误作已支持合同。
