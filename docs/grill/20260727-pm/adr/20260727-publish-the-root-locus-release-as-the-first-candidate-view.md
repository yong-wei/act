# 将根轨迹发布版作为首个公开候选视图

## 状态

已接受

## 背景

当前 ActKG 首版正式 Release 只覆盖根轨迹局部内容，但已经包含异质规范对象、六种精确工程谓词、核心与扩展关系、来源映射和治理字段。等待全课程图谱完成后才开放，会延迟对接入合同、投影、前端表达和候选控灵的真实验证。

候选预览与生产知识权威已经通过 Repository 状态、独立 API 和写入边界隔离，因此公开查看局部 Release 不需要提前迁移正式消费者。

## 决策

1. Release 接入合同、Repository 与投影、候选图谱、候选控灵四项变更完成并通过验证后，导入 `root-locus-engineering-v0.1` 作为首个候选 ReleaseSet。
2. 所有当前有权访问知识图谱的教师和学生均可查看；首次进入默认显示新版候选视图，并可显式切换旧版。
3. 界面明确显示“根轨迹局部发布版”、真实覆盖范围和教学关系尚未发布，不将局部内容表示为全课程完整图谱。
4. 候选控灵只查询该 ReleaseSet 并保持只读；RAG、SAR、KAQ、资源、路径和学习事实继续使用旧生产权威，直至最终一次性切换。

## 结果

- 首批正式 ActKG 数据可以尽早验证完整接入链路。
- 用户能够体验和检查新版权威表达，但不会影响正式教学状态。
- 后续 Release 继续通过显式 ReleaseSet 锁定清单增量加入候选视图。
