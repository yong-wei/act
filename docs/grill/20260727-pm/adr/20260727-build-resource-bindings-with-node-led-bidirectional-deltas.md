# 以节点主导并按变化端增量建立资源绑定

首次建立绑定以及新增或修订 ActKG Canonical Object 时，以节点语义档案作为稳定上下文，查询已经建立的 ACT 原子资源片段索引，并批量裁决召回候选与教学角色。完整资源库不反复进入模型上下文，旧节点绑定不作为新绑定依据。

新增或修订资源时，从资源侧只处理变化片段并查询既有 Canonical Object 索引。节点侧与资源侧最终使用同一个候选对裁决合同和资源绑定真源，未变化对象不重新匹配。

裁决缓存身份由 Canonical Object ID 与修订、资源片段 ID 与内容哈希、绑定提示词版本组成。任一组成变化只使受影响候选对失效。该机制保留节点上下文复用优势，同时保证后续新增资源不会遗漏。

只有资源片段与 ActKG EvidenceSegment 唯一对应，并且 ACT 原子资源类型合同能够唯一确定教学角色时，绑定可以直接生效。其他词面、向量或 GPT 结果只形成候选，必须完成独立语义审核后才能进入正式绑定真源。

语义候选由与生成上下文隔离的 GPT 审核者读取 Canonical 语义档案、原子资源片段和拟议角色，给出接受、拒绝或争议结论。争议、高影响或前后判断冲突的候选进入人工裁定；接受结果仍须通过端点、角色、版本和唯一性确定性闸门。
