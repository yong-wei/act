# 退役旧图运行时并保留独立只读归档

## 状态

已接受

## 背景

迁移期间，主知识图谱需要允许用户在旧版与 ActKG 候选新版之间切换，以便查看尚未纳入候选 ReleaseSet 的既有内容。生产权威切换后，继续在主图谱保留旧版切换会形成长期双入口，并使旧 API、旧 DTO 和运行查询边界难以真正退役。

旧图同时承担历史事实、旧知识修订、未完成路径和用户节点笔记的解释依据，不能随运行时退役而删除。

## 决策

1. 旧版与新版切换只存在于生产权威切换前的迁移期。
2. 权威切换后，主知识图谱移除旧版切换，只显示 ActKG 权威图谱。
3. 旧图业务 API、`UnifiedKnowledgeGraphPayload` 等旧 DTO 以及面向正式业务消费者的旧图运行读取路径一并退役。
4. 系统建立独立的 Legacy Archive，以固定快照只读展示切换时封存的旧节点、关系、知识修订和旧节点笔记。
5. Legacy Archive 延续切换前各角色对旧图内容的可见范围；个人旧节点笔记仅笔记所有者可见，管理员可以执行归档审计。
6. Legacy Archive 不提供编辑、控灵问答、资源推荐、学习路径执行、新学习事实写入或任何正式业务回退能力。
7. 旧历史事实和旧路径通过其原修订及归档快照解释，不建立到 ActKG Canonical Object 的映射。

## 结果

- 主知识图谱在切换后只有一个活动权威和一套正式业务合同。
- 历史解释依据与用户旧节点笔记仍可阅读。
- 归档能力不会延长旧图业务运行时的生命周期，也不会形成隐式双权威。
