# ActKG Teaching Projection 接管知识之间的教学关系

ActKG 正式发布 Teaching Projection 后，Canonical Object 之间的包含、先修和关联等教学关系以 ActKG 为权威。ACT 的 KAQ 继续拥有知识—能力—素养关系以及具体课程运行语义，不再长期维护第二套知识—知识关系。

ActKG 教学关系与既有 KAQ 知识关系不一致时进入一次性冲突审核。确认后退役相应 KAQ 旧关系；路径规划不得同时消费两个冲突版本，也不得通过简单并集掩盖循环或语义差异。

该边界使知识工程语义和教学语义最终统一回到 ActKG，同时保留 ACT 对能力、素养和教学运行的治理职责。
