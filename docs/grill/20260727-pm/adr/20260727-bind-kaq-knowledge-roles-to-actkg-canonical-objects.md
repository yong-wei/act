# 保留 KAQ 教学图并绑定 ActKG 规范知识对象

ACT 保留 KAQ 的知识角色节点、能力节点、素养节点及其教学治理关系。KAQ 知识节点不与 ActKG 工程对象合并，而是通过显式绑定指向一个或多个 ActKG Canonical Object；绑定记录教学角色、ActKG Release 和审核状态。

学习路径继续消费 KAQ 教学关系，并通过绑定解析规范知识身份。ActKG 尚未发布教学语义时，工程关系不得直接充当先修或路径关系；后续 Teaching Projection 到达后，再逐项审核其与现有 KAQ 关系的替代或并存方式。

该决定保留了 ACT 已有能力和素养治理语义，同时消除 KAQ 对退役 runtime ID 的长期依赖。
