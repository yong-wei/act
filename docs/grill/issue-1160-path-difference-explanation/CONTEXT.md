# 学习路径差异解释

本上下文约定学生比较同一候选路径组中两条学习路径时使用的领域语言。它只描述可核验的路径差异，不改变路径规划或选择结果。

## Language

**候选路径组**：
一次路径生成得到的有序候选方案集合；组内每条候选路径都属于同一个学习目标和同一个已保存路径版本。
_Avoid_: 推荐卡片集合、路径模板

**比较路径对**：
候选路径组中被一次差异解释明确比较的两条不同候选路径。学生只指定一条时，另一条按候选顺序确定：优先系统推荐路径，若所选路径就是推荐路径，则使用下一条候选路径。
_Avoid_: 当前路径和任意其他路径、历史路径对

**路径差异解释**：
由比较路径对的已保存事实确定生成的学生可读比较结果，包含比较对象、共同与独有节点、顺序差异、量化指标、取舍和限制。
_Avoid_: 路径推荐理由、通用选路建议

**共同节点**：
以稳定资源节点身份判断，同时出现在比较路径对两侧的学习节点。
_Avoid_: 标题相同节点、资源类型相同节点

**独有节点**：
以稳定资源节点身份判断，只出现在比较路径对其中一侧的学习节点。
_Avoid_: 推荐资源、差异节点

**顺序差异**：
同一个共同节点在两条候选路径中的执行位置不同所形成的结构差异。
_Avoid_: 节点数量差异、显示排序差异

**路径比较指标**：
直接来自候选路径事实的预计时长、节点数量、资源构成、检查点、准备度、锁定节点和终点验证数据。
_Avoid_: 综合评分、模型推测指标

**路径取舍**：
由共同节点、独有节点、顺序差异和路径比较指标直接支持的选择代价与收益陈述。
_Avoid_: 个性化推荐结论、自由生成建议

**比较限制**：
缺失或不足以支持可靠比较的路径事实，以及这些缺口对差异解释造成的明确约束。
_Avoid_: 通用免责声明、固定说明

**失效差异解释**：
不再属于当前候选路径组或当前已保存路径版本的比较结果；页面不得继续把它作为当前比较展示。
_Avoid_: 历史路径解释、缓存说明

## Flagged Ambiguities

- “推荐路径”仅指候选路径组中规划器给出的首选方案，不指学生已选择或正在执行的路径。
- “路径相同”要求节点身份及执行顺序均无实质差异；节点集合相同但顺序不同仍属于不同路径。
- “解释”只把结构化路径事实转换为学生可读内容，不允许补充路径数据未支持的原因或建议。

## Example Dialogue

开发者：学生点击“仿真驱动路线”的“解释差异”时，比较路径对如何确定？

领域专家：若“基础补救路线”是候选路径组中的推荐路径，就比较这两条路径，并明确显示双方名称。

开发者：两条路径节点相同但执行顺序不同，是否可以说没有差异？

领域专家：不可以。共同节点相同，但仍需列出顺序差异；只有节点、顺序和路径比较指标均无实质差异时，才说明没有实质差异。

开发者：缺少可靠节点摘要时是否返回通用建议？

领域专家：不返回。应记录比较限制，并说明当前无法生成可靠的路径差异解释。
