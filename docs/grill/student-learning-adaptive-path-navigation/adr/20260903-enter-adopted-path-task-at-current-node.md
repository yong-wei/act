# 采用路径任务必须进入当前节点

## 背景

AI 工坊已经把当前学生的已采用学习路径节点投影为学习任务，但任务入口若只携带路径身份，目标与执行意图无法在自适应练习页恢复。学生点击真实任务后会落入通用入口或缺少路径上下文的页面，学习陪伴链路因此在“学习任务记录 -> 可执行学习行动”处中断。

## 决策

每个路径任务记录必须携带能够恢复目标、路径、当前节点和路径执行意图的受治理导航描述。点击路径任务时直接进入该节点的执行状态；不展示自由选路径作为替代入口。服务端在加载路径与节点时重新确认当前学生的归属和可执行状态，客户端导航参数不能授予访问权限。

若路径或节点已经不可用，页面应显示可解释的恢复状态并提供重新生成或核对证据的行动；不得静默回退为通用练习，也不得把路径任务伪装为已完成或可执行。

## 取舍

- 只传 `pathId` 的方案改动最小，但无法确定目标和节点，且会让学生重新选择，放弃了任务卡片提供的上下文。
- 直接复用通用自适应练习入口可以避免新增导航字段，但会丢失已采用路径语义，无法保证继续的是当前学习任务。
- 携带完整受治理上下文并由服务端复核，增加了投影与导航契约，但能保持路径任务、学习证据和陪伴建议在同一条可追溯链路上。

## 验收方向

- 从 AI 工坊点击当前节点任务，进入目标明确、路径和节点一致的执行状态。
- 点击尚未到达节点时仍显示其真实锁定状态和下一步行动，不误报完成。
- 缺失或失效上下文时显示恢复状态，不进入通用练习并允许重新获取路径。
- 浏览器导航、服务端归属校验和学习证据回写均覆盖真实学生路径场景。
