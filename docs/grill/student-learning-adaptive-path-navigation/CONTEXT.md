# 学习陪伴中的路径任务入口

该上下文定义 AI 工坊把已采用学习路径呈现为可执行任务时使用的领域语言。

## 领域语言

**路径任务记录**：
当前学生已采用学习路径中的一个待执行节点，包含路径身份、节点身份、学生可见标题、当前状态和可达学习行动。
_避免_：推荐候选、路径统计、只有路径 ID 的展示卡片

**路径执行上下文**：
学生进入某个路径节点学习时，用于恢复目标、路径、节点和执行意图的一组受治理上下文；它必须能够唯一定位当前学习任务。
_避免_：仅由 URL 任意参数决定的授权、通用练习首页、重新选择路径替代恢复

**继续当前节点**：
从学习集合或学习记录返回时，进入服务端确认的当前可执行节点，并保留该节点的路径与目标语义。
_避免_：回到路径选择、进入首个节点、根据客户端标题猜测节点

**路径任务可达行动**：
学生点击任务后能够实际到达对应学习节点并继续形成学习证据的操作；静态链接存在但页面无法恢复任务不算可达。
_避免_：只验证 href、打开通用入口、显示路径不存在后要求学生重新寻找

## 边界

- AI 工坊只展示当前学生已持久化并可追溯的活动路径节点。
- 路径任务入口必须与目标、路径、节点和执行意图保持一致；候选路径与已确认路径不能混用。
- 路由参数是导航提示，不是授权依据；服务端仍须确认学生拥有该路径及节点上下文。
- 无法确认路径或节点时应显示诚实的恢复状态，不得伪造进度、完成状态或学习证据。
