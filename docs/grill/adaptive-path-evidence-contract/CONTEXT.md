# 自适应学习路径视觉证据维护

本上下文定义自适应学习路径落地页的可审计界面证据及其失效边界。它用于区分用户可见状态合同与会随实现重排而变化的页面源码。

## 语言

**落地页状态契约**：
自适应学习路径入口向学习者呈现的冷启动、加载、失败、恢复和活动状态，以及这些状态之间的排他关系。
_避免_：页面源码表达式、组件内部条件分支

**视觉证据清单**：
记录指定视口、界面状态、截图哈希和被追踪源码指纹的 manifest；它只证明生成它的源版本。
_避免_：永久有效截图、非受控验收附件

**失效关闭**：
当视觉证据清单所追踪的源码或截图哈希不一致时，验证直接失败，不能将旧证据视作当前页面的验收结果。
_避免_：忽略源码变更、自动接受过期证据

## 示例对话

开发者：页面将冷启动目标卡片的显示条件改为依赖落地页状态，还需要重拍证据吗？

领域专家：需要。视觉证据清单绑定的是旧源码指纹；即使状态契约不变，也必须重新证明当前页面在桌面端和 320px 视口符合该契约。

开发者：测试是否应断言新的完整条件表达式？

领域专家：不应。测试应验证冷启动目标选择和活动路径的排他展示这些落地页状态契约，而不是绑定某一种代码写法。
