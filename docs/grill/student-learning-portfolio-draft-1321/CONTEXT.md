# Student Learning Portfolio Reflection Draft

This context defines the learner-owned reflection draft created from a portfolio reflection candidate. It preserves a student's explicitly saved working reflection without promoting it to a formal learning record.

## Language

**作品集反思草稿**:
由学生明确保存的结构化反思候选，记录来源、任务、意图和可编辑内容，供学生在个人作品集中继续回顾与修改。
_避免_: 正式作品集、学习事实、官方成绩

**草稿候选**:
当前作品集页面展示、尚未保存的结构化反思内容；它只在学生点击保存后成为作品集反思草稿。
_避免_: 完整 Copilot 对话、自动生成的学习记录

**草稿保存**:
学生将当前结构化反思候选写入本人草稿集合的显式动作。重复提交同一请求身份只更新同一草稿，不产生重复记录。
_避免_: 自动写回、事实晋升、提交评分

**草稿丢弃**:
学生撤回本人已保存作品集反思草稿的动作。被丢弃草稿不在学生的活动草稿列表展示，且不会创建正式学习证据。
_避免_: 删除学习事实、画像回滚、成绩撤销
