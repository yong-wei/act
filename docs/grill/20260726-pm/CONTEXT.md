# 作业创作与批阅

**发布基线**：已经成功保存、与教师当前编辑内容一致且不存在保存冲突的作业草稿状态。发布操作只使用该状态，不包含额外保存。
_避免使用_：最后版本、当前版本、自动发布版本

**统一作答**：学生每道题至少提交文本或一个附件，两者也可以同时提交；每道题允许提交多个附件，文本与全部附件共同构成该题的完整答案。
_避免使用_：文本作答类型、文件作答类型、允许作答类型

**作答附件上限**：每道题最多提交十个附件，各附件继续遵循平台现有的单文件大小限制。学生在编辑器内插入的图片和独立上传的文件共同计数。

**附件解析路径**：PDF、办公文档和图片统一交由 Mathpix 转换为可供自动批改理解的结构化文本；Markdown 与纯文本文件由平台直接读取。多个附件转换后的内容与学生填写的文本共同组成评分依据。二进制附件不使用 MarkItDown、OOXML 或其他本地语义提取结果兜底；Mathpix 最终失败时按附件理解缺失处理。
_避免使用_：文件转文字、附件 OCR、单文档评分

**作答附件格式**：允许 PDF、DOC、DOCX、PPTX、PNG、JPEG、Markdown 和纯文本文件。ODT、XLS、XLSX 不属于可提交格式。

**批阅顺序**：自动批阅先读取学生填写的文本，再按学生排列的附件顺序读取各附件的转换结果。附件列表显示明确序号，学生可以拖动排序；界面提示系统将按该顺序批阅，并建议按重要程度排列。
_避免使用_：上传顺序、文件顺序

**评分标准**：教师为一个评分项填写的自然语言判分依据。未开启评分细则时，自动批改直接依据评分标准，在零分至该评分项分值之间给分。
_避免使用_：证据描述、评分标注

**评分细则**：教师按需开启的分档判分约束，用于在评分标准之上进一步规定不同得分范围的达成条件；默认关闭。
_避免使用_：分数档位、等级配置

**评价级别**：评分细则中的一个得分层级，包含级别名称、该级别的最高分值和对应评分准则。界面只显示最高分值，最低分值由相邻级别自动推断并在后台保存。
_避免使用_：档位、分数档位、等级

**默认评价级别序列**：逐条新增评价级别时，依次命名为“优秀、良好、中等、及格、不及格”；继续新增时使用“自定义”作为初始名称。首次开启评分细则时只建立“优秀”，其得分范围覆盖零分至该评分项满分。

**五级制**：优秀上限为满分，良好、中等、及格、不及格的默认最高分值依次为满分的 90%、80%、70%、60%，计算结果向上保留一位小数；最低级别覆盖至零分。

**两级制**：评价级别为“通过”和“不通过”，以满分的 60% 为分界；最低级别覆盖至零分。

**评价级别快捷设置**：教师可以将评分细则切换为五级制或两级制。目标级别数少于现有级别数时，必须提示多余级别及其内容将被丢弃，教师确认后才执行；目标级别数多于现有级别数时，保留已有级别内容并扩展缺少的级别。

**评价级别边界**：相邻评价级别的分界值属于较高一级。满分为 100 分时，优秀为 `[90, 100]`，良好为 `[80, 90)`，后续级别依此类推。

**级别内分数校正**：自动批改先给出评价级别和建议分数，平台再将建议分数限制在该级别的合法区间内，并将最终分数保留一位小数。高于上限的按上限处理，低于下限的按下限处理；非最高级别的上限不包含边界值，因此良好级别建议 90 分时，最终记为 89.9 分。

**评价级别扩展比例**：快捷设置需要增加评价级别时，使用最后两个现有级别最高分值之间的比例继续推算。例如现有上限为满分的 100% 和 80%，后续三级依次为 64%、51.2% 和 41.0%，各分值继续遵循向上保留一位小数的规则。

第六个及后续新增的“自定义”评价级别同样沿用最后两个现有级别的比例推算默认最高分值，教师可以直接替换其名称和分值。

比例推算因一位小数精度产生重复分值时，新级别改为比上一等级低 0.1 分；已经无法形成至少 0.1 分的有效区间时，拒绝继续添加评价级别。

**评价级别自动排序**：教师修改级别分值后，平台按最高分值从高到低自动重排。级别名称、评分准则和分值作为完整记录一起移动，不因排序错配内容。

**最高级别分值**：最高评价级别的最高分值始终与所属评分项满分同步，不允许单独修改；其他级别分值可以编辑。

**快捷设置内容保留**：对已经填写或由教师新增过级别的评分细则应用五级制或两级制时，保留能够容纳的现有级别名称、评分准则和分值。减少级别只删除末尾多余项，并让最低保留级别的下限覆盖至零分；删除前仍须确认将丢失的内容。增加级别时保留现有内容并按评价级别扩展比例补足。标准名称和标准百分比只用于尚未被教师编辑的空白细则。

**默认级别值**：系统建立的评价级别名称和分值属于可直接发布的真实值。教师编辑这些默认值时，首次输入或粘贴直接替换原值，不把默认值拼接进新内容。

**AI 填写评分细则**：评分细则区域提供带醒目图标的 AI 填写入口。AI 优先依据教师已经填写的评分标准生成各评价级别的评分准则；缺少评分标准时先弹出补充对话框，教师可以补充后生成，也可以忽略并继续。忽略后以评分项名称作为生成依据；评分项名称也为空时拒绝生成。

**评分细则发布条件**：开启评分细则后，每个评价级别都必须具有评分准则，教师可以手工填写或使用 AI 填写；任一级别缺少评分准则时阻止发布。系统生成的默认级别名称和分值可以直接发布。

未开启评分细则时，评分标准为发布必填项；开启评分细则且各评价级别评分准则完整时，通用评分标准可以为空。

**AI 重填评分细则**：AI 填写按一组评价级别整体重新生成。任一级别已经存在教师填写内容时，必须提示本次操作将覆盖全部级别的评分准则，并在教师确认后执行。

**作业身份**：教师在同一个作业编辑任务中保存和发布的内容始终属于同一个作业，不因重复点击发布而在学生端形成多份作业。

**发布完成流**：作业发布成功后立即返回教师作业列表，并展示刚发布的作业，不继续停留在可重复发布的编辑页面。

**发布幂等**：同一发布基线无论因双击、网络重试或并发请求被提交多少次，都返回首次成功发布的结果，不新增发布修订。

**重复发布数据修复**：旧重复发布版本没有任何学生提交时可以删除；已经存在学生提交时保留为历史版本，不破坏提交与批阅记录。修复后每个作业只有一个当前发布版本进入学生作业列表。

**证据不完整的批改建议**：多附件答案中部分附件转换失败时，平台继续使用学生文本和成功转换的附件生成批改建议，同时明确列出失败附件并标记证据不完整。该建议必须经过教师确认后才能形成成绩。
_避免使用_：部分批改、忽略失败附件

**草稿校验**：教师编辑过程中的不完整内容可以自动保存。字段问题在原位置提示，不因保存失败移动页面或焦点。

**发布校验**：教师点击发布时统一检查全部发布条件；未通过时保持当前页面位置，并提供能够定位到对应字段的问题清单。

**统一内容编辑器**：教师编辑题目和参考答案、学生编辑作答时使用同一个嵌入式编辑器。编辑状态输入 Markdown，并可预览公式和图片；支持选择文件、拖入和粘贴插入图片。保存后退出编辑状态，以渲染结果展示内容。
_避免使用_：题目文本框、答案文本框、浏览器编辑弹窗

**内嵌图片证据**：学生在统一内容编辑器内粘贴或插入的图片属于作答附件，并占用作答附件额度。自动批改使用 Mathpix 解析图片，并将解析结果放在图片对应的 Markdown 位置；独立附件仍按学生排列的顺序追加。

**发布设置摘要**：发布设置位于作业编辑主栏并默认折叠，折叠状态摘要显示目标班级、发布时间和截止时间。设置缺失或阻止发布时自动展开，并在原字段标出问题。

**原样批阅视图**：教师批阅区按照学生提交时的内容和顺序展示渲染后的正文与原始附件，不展示附件转换文本、转换状态或后台处理过程。附件转换结果只作为自动批改模型的理解材料。
_避免使用_：转换预览、解析状态、转换文本

**附件理解缺失提示**：附件转换失败时，学生原始作答区保持不变；AI 批改建议旁使用“部分附件未纳入本次建议，请结合原件核对”等非技术提示，并列出对应附件名称，不展示错误码或转换状态。

**题目大纲**：作业编辑页左侧依次提供“从题库选择”“新建题目”和当前题目列表。

**评分项摘要**：评分项使用手风琴展示。折叠时只显示评分项名称、分值、上移、下移和删除操作；展开后编辑评分标准与可选评分细则。

**占位提示**：编辑字段中的示例文字只作为浅色提示，不属于正文。教师输入或粘贴后提示立即消失，不需要先手工删除。

**作业总分**：作业总分由所有题目分值自动汇总，不允许另行输入一个可能不一致的总分。

**作业信息区**：作业标题和作业说明位于题目编辑区域之前，只出现一次，不在每道题的编辑窗口中重复显示。

**题库中文标签**：题库来源、题型、审核状态、版本和评分准备状态等内部枚举统一通过中文标签展示，不向教师暴露原始工程标识。

**发布结果定位**：发布成功返回教师作业列表时，列表展示刚发布的作业，并使用班级名称表达受众，不显示班级内部标识或序号。

**统一编辑器依赖**：作业题目、参考答案和学生作答复用平台统一内容编辑器，不在作业模块内另建一套 Markdown 编辑器。

**原始附件预览**：PNG、JPEG 在批阅页直接显示图片，PDF 使用内嵌阅读器；DOC、DOCX、PPTX 以文件卡片提供打开或下载原件。任何格式都不向教师展示后台转换文本。

**草稿保存状态**：作业编辑页持续显示“正在保存、已保存、保存失败、存在冲突”四种状态。只有当前内容处于“已保存”状态时允许发布；其他状态禁用发布并提供相应处理提示。

**作业草稿**：一个作业在发布前只有一份可变草稿，自动保存更新该草稿，不为每次保存建立版本历史；发布时才冻结不可变发布修订。

**附件上传错误**：客户端在上传前校验文件格式、单文件大小和附件数量，使用中文指出具体问题并展示允许格式；服务端返回可映射的结构化错误，不向学生显示 `invalid-payload` 等内部错误码。

**旧作答规则行为迁移**：现有发布版本中的 `TEXT`、`FILE` 等旧作答规则不再限制教师和学生界面，服务端统一按“统一作答”接收文本与附件；原发布快照字段、内容哈希和历史提交关联保持不变，用于审计追溯。

**作业评分精度**：评分项分值、评价级别分值、AI 建议分数、教师修订分数和最终成绩统一保留一位小数。

**评分项最低分值**：每个评分项的满分不得低于 1.0 分。

**附件外部处理边界**：Mathpix 处理继续遵循平台现有的班级范围外部处理策略。策略允许时附件进入 Mathpix；策略不允许时学生仍可提交，教师仍可查看并人工批阅原件，但该附件不纳入 AI 批改建议。
