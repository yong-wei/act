# 自适应学习路径纠偏

本上下文界定学生在学习路径出现可信偏离或检查点未通过后，对候选纠偏方案作出决策的领域语言。

## 纠偏决策

**暂缓决策**：
学生针对特定候选纠偏方案及其对应路径版本作出的“暂不处理”决定；它不改变当前路径，也不阻止后续不同候选方案再次出现。
_避免_：仅本次界面状态、永久忽略、自动拒绝

**过期候选**：
候选方案生成时绑定的路径版本已不再是当前版本的候选方案；学生确认过期候选必须被拒绝，并要求刷新后重新审阅。
_避免_：局部合并、旧候选覆盖当前路径

**拒绝决策**：
学生针对特定候选纠偏方案作出的不采用决定；该候选仍可在纠偏记录中查看，但不再主动重复展示，只有新的候选版本才能再次触发提醒。
_避免_：重复打扰、学生不可见的隐藏记录

**当前学习节点**：
学生已经进入但尚未完成的路径节点；确认纠偏方案时保持该节点不变，纠偏仅可改变它之后受影响的未完成节点。
_避免_：确认后立即中断当前学习活动

**纠偏决策快照**：
服务端在核验候选与当前路径版本一致后，冻结保存的原路径、候选方案、支持依据、学生决策与实际应用结果；客户端只提交候选标识和决策类型。
_避免_：客户端提交完整路径、事后重新推导历史方案

**已应用纠偏**：
已通过版本核验并写入后续未完成节点的候选纠偏结果；P2 不提供直接恢复原路径，原路径快照仅用于追溯，后续调整必须生成新的候选方案。
_避免_：覆盖确认后产生的新学习事实、直接回滚
