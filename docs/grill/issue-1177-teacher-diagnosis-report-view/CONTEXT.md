# 教师学情诊断报告查看

该上下文描述教师如何阅读已经持久化的学情诊断报告，并区分报告历史、当前证据和生成行为。

## Language

**诊断报告**：
教师主动生成并持久化的班级级或学生级学情判断快照，绑定明确的证据截止时间、置信度和局限。
_Avoid_: 实时诊断、当前画像

**报告历史**：
同一授权范围内按生成时间倒序排列的诊断报告集合；查看历史不会重新生成报告。
_Avoid_: 诊断时间线、实时流

**报告范围**：
诊断报告所属的教师班级，或该班级中的目标学生。学生级范围始终从班级成员关系派生。
_Avoid_: 客户端作用域、会话作用域

**受治理发现项**：
诊断报告中经过白名单和证据校验的结构化结论，可包含风险、严重程度、置信度及备课导航。
_Avoid_: 模型原文、原始证据

**降级报告**：
置信度为低或不可用，或明确声明局限的诊断报告。降级不等同于零分或没有风险。
_Avoid_: 无效报告、空报告

**证据台账**：
教师工作区中用于选择和阅读持久化报告快照的只读界面；它不承担报告生成或修改职责。
_Avoid_: 生成器、助教门户
