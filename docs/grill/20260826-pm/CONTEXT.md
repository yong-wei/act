# 个性化路径决策证据链

本上下文记录 Issue #1561：把画像事实、路径决策和候选差异冻结成可审计的生成时证据。

## Language

**决策快照**：
路径生成时复制的只读画像与规划输入，包含薄弱点、掌握度、资源偏好、证据窗、新鲜度、来源覆盖、缺失证据、降级原因和版本标识。
_Avoid_: 生成后用最新画像重算、原始作答、用户标识

**候选影响**：
一条候选相对同批次其他候选的节点加入、删除、提前，或资源类型选择结果。
_Avoid_: 最佳路径、系统排名、模型推测差异

**规则因素**：
由政策族、先修、准备度和资源约束产生的差异，不依赖当前画像事实。
_Avoid_: 把结构差异说成个性化

**画像因素**：
由薄弱点、掌握度或可信资源偏好产生的差异。
_Avoid_: 低置信偏好、过期证据

**冻结解释**：
生成时同时保存的结构化 code 与中文 studentText；前端只展示 studentText。
_Avoid_: 客户端重算、事后改写历史解释

## Confirmed Boundaries

- 继续原路径只恢复已保存路径，不重新生成。
- 新建学习路径才读取最新画像并创建新批次。
- 解释、比较和查看不得修改执行状态。
- 证据不足时只显示降级，不伪造个性化结论。
