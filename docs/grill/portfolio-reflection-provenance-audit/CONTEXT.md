# 作品集反思候选的来源语义

本上下文区分平台可核验来源与学生自填描述，避免将 URL 中的任意文本固化为不可修改的学习证据 provenance。

## Language

**平台核验来源**：服务端通过受授权的课程、任务、证据或作品身份解析的来源，其标题、任务和意图可以作为可追溯 provenance 保存。_Avoid_：URL 文本、客户端显示标签、仅通过字符串格式校验的来源

**学生自填标签**：学生为反思候选手动填写的标题或描述，必须在数据与界面中明确标记为学生提供，不得呈现为平台已核验来源。_Avoid_：作业编号、平台任务身份、官方证据引用

**来源身份**：服务端可重新解析并校验当前学生访问权的有界标识，用于派生反思任务语义与保存 provenance。_Avoid_：完整提示词、权限断言、任意 source/assignment/intent 三元组

**反思草稿 provenance**：草稿创建时固定的来源类型、可核验身份和学生标签属性，用于后续审计，不能在已保存后被改写。_Avoid_：将未验证 URL 文本标记为 verified
