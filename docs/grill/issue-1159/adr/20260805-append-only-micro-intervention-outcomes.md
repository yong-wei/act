# ADR：以追加式微干预实例记录结果，并保留受控建议

## 状态

已采纳。

## 决策

服务端在每次开始微辅导时创建独立的微干预实例。开始、资源使用、提示、完成和验证作答作为以事件键幂等的追加式事件保存。验证结果与建议绑定到该实例创建时的归因与任务快照，并在写入前重新核验当前访问与版本权威性。

验证通过时，仅推荐当前仍可访问的、显式受治理的高阶迁移练习；不存在时返回受控不可用建议。验证失败时，先输出确定性的受治理前置节点；不存在时才返回辅导策略/人工练习回退。所有建议只读，不更新掌握度或正式路径。

## 理由

独立实例与追加式事件同时满足网络重试幂等、学习尝试可追溯和历史不被后续操作覆盖。把评分放在服务端可防止客户端伪造通过状态；不复用自适应测评提交链路可避免把微干预结果错误写入掌握度或路径状态。受控不可用比推测性推荐更符合已建立的治理边界。

## 后果

- 数据库会增加可审计的实例和事件记录，读取响应必须经过学习者投影。
- 前端需要持久保存事件键以支持安全重试。
- 未配置受治理迁移练习或前置关系时，系统会明确显示限制，而不是提供看似合理但无证据的推荐。
