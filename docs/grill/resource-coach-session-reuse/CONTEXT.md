# 教材资源辅导会话复用

该上下文定义教材资源辅导入口如何恢复或创建版本绑定的控灵会话，避免页面重开时产生重复空会话并丢失连续问答。

## 领域语言

**资源辅导会话身份**：
由受治理教材资源、版本、结构单元、内容哈希和可选锚点共同确定的资源辅导绑定。身份由服务端验证并持久化，不能只存在浏览器会话存储中。
_避免：当前 URL、页面标题、客户端临时 binding_

**匹配会话恢复**：
资源辅导入口完成会话库加载后，选择当前用户已有且与完整资源辅导会话身份一致的会话，并恢复其消息和绑定。
_避免：默认选择最新通用会话、每次进入新建_

**待提问空白态**：
当前资源没有匹配历史时，页面呈现可开始提问但尚未创建持久会话的状态；首轮发送时再建立受治理会话。
_避免：页面挂载即写入空会话、伪造已恢复状态_

**孤立空会话**：
已经写入会话库但没有用户消息、助手消息或可恢复服务端资源绑定的记录。刷新重复创建这类记录会污染会话导航。
_避免：正常的新对话草稿、已绑定的待提问会话_

## 已确认边界

- 资源辅导必须先完成会话库恢复判定，再决定选择既有匹配会话或进入待提问空白态。
- 完整资源身份必须持久化为服务端可恢复绑定；`sessionStorage` 不能作为重开后的唯一依据。
- 页面刷新、重开或重新打开侧栏不得仅因绑定尚未加载而创建新会话。
- 不匹配的旧版本、其他单元、其他锚点和其他用户会话不得被复用。
