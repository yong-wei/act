# 学习过程陪伴：训练证据统计

## 领域术语

**可展示预览训练**：学生自己的虚拟仿真运行，同时满足已完成状态、明确的 `preview` 可见性、`officialEligible=false` 和完整质量指标。只有这类记录进入个人中心的预览训练统计和最近训练列表。

**治理候选运行**：已经持久化但尚未满足展示条件的运行，例如 pending、边界冲突或指标缺失。它可以保留供治理排查，但不能被描述为学生已完成的训练证据。

**训练统计口径**：`total`、`previewCount` 和 `recentRuns` 都以同一个可展示预览训练判定为准。统计必须覆盖全部候选记录；最近列表只保留最新五条。

**分页扫描**：服务端在同一 `RepeatableRead` 事务中按创建时间和 id 的稳定顺序，以 100 条一页继续扫描，直到候选耗尽；分页只限制单次内存，不限制统计范围。

## 领域边界

- 运行记录按 `userId` 隔离，不能读取其他学生的数据。
- 预览训练统计不等同于官方提交、正式成绩、排行榜或能力达成。
- 缺少可验证指标的运行不通过展示投影；不新增事后撤销或伪造证据的流程。
