# 仿真证据与能力映射

## 语言

**仿真验证与证据**：
七维累计画像中用于反映学生以可复核仿真结果支持判断、验证方案或说明局限的既有能力维度。它由受治理的仿真证据映射形成，不另设独立的“仿真能力”维度。

_避免：第八个仿真能力维度、只按参数调整次数计分_

**分层仿真贡献**：
通过治理校验的仿真过程记录可对任务进度产生较低且有上限的贡献；完成的可复核运行和竞技场正式结果产生主要贡献。任何过程记录都不得单独等价于一次完成验证。

_避免：只接受终态结果、将全部操作按同等权重累计_

**参数调整的归属**：
参数调整不是独立学习事实；只有当后续保存、运行、评估或提交结果被持久化时，参数调整才可作为该结果的过程证据。

_避免：为每次参数调整单独累计能力_

**仿真过程证据白名单**：
虚拟仿真的有效运行、控制工作台的模型或控制器保存以及完成运行、评估、提交、竞技场的有效运行、评测、提交、奥德赛的完成关卡、任务结果与得分记录，均可作为过程层证据。界面浏览和打开面板等非学习产物不计入。

_避免：用通用交互日志替代具有产品语义的仿真产物_

**历史仿真回填**：
对既有数据按相同的过程证据白名单回填。回填对象必须能确认学生、发生时间和产品语义；缺少课程或任务上下文时，只能形成较低层的过程证据，不能被表示为强验证证据。

_避免：忽略可辨识历史产物、用不完整上下文伪造验证结论_

**单一产物的最高贡献**：
同一仿真产物在保存、运行、评估或提交等后续阶段产生多项候选贡献时，只保留其中证据强度最高的一项。

_避免：让同一产物的过程记录与终态结果重复累计_

**任务归一化能力达成**：
能力达成以任务为单位规范化。平台中所有能对某项能力构成贡献的任务共同构成该能力的分母；学生已满分完成的相关任务数构成分子。仿真产物必须归入对应任务后，才可参与“仿真验证与证据”的达成计算。

_避免：以事件数量、操作次数或未归一化的产物数量表示能力高低_

**通用仿真实践任务**：
无法明确归属到具体任务、但满足仿真过程证据白名单的产物，按来源的稳定语义目标归入相应通用任务。该任务与可明确归属的任务共同参与“仿真验证与证据”的分子和分母计算。

_避免：因历史任务上下文缺失而丢弃有效仿真产物_

**仿真来源任务化与上限**：
奥德赛的每个关卡是独立任务；竞技场的每项挑战是独立任务；未由竞技场任务链接的控制工作台自由仿真是一个通用任务；具有稳定资源或任务标识的虚拟仿真按任务独立计入，缺少标识的历史虚拟仿真归入一个通用任务。不同来源任务分别设定达成上限：奥德赛以关卡通关程度、竞技场以正式评分、控制工作台以一定数量和质量的仿真结果达成上限；具有稳定标识的虚拟仿真任务和通用虚拟仿真均以三个不同的有效运行达到上限。

_避免：将所有无归属产物压入一个任务、由重复尝试无限抬升能力值_

**相关任务集合**：
“仿真验证与证据”的分母由当前已发布且可供学生完成的相关任务构成；草稿、下线任务和仅供教师预览的任务不纳入。

_避免：以未向学生开放的任务降低能力达成_

**任务目录增量**：
任务发布、下线或相关性变更是任务目录增量。它只更新受影响画像的分母和聚合值，不重放或重算既有学习事实。

_避免：为了任务目录变化而全量重算历史学习事实_

**来源自有达成标准**：
任务达成上限优先复用来源产品已有的通关、正式评分或完成标准；只有控制工作台自由仿真和通用虚拟仿真补充明确的数量与质量上限。

_避免：以跨来源统一阈值抹平不同产品的任务语义_

**自由仿真质量**：
控制工作台自由仿真的有效结果必须可复核，并具有持久化设计或结果；所选对象已有明确目标或评价指标时，还必须满足该指标。三个模型、控制器配置或被控对象不同的有效结果达到该通用任务上限。虚拟仿真以三个不同的有效运行达到上限。

_避免：以缺少结果、设计或可复核输出的操作充当高质量仿真，或用同一结果重复计数_

**任务构成展示**：
“仿真验证与证据”显示已满分完成任务数与相关任务总数，并可按奥德赛关卡、竞技场挑战、控制工作台和虚拟仿真展开查看任务构成。

_避免：只显示不可解释的能力比例_

**任务内达成累积**：
同一任务中不同的合格产物可以累积至该任务上限；同一产物只保留最高贡献。正式通关或评测按照其结果直接确定任务达成。部分达成仅保留为过程证据和任务进度，只有满分任务进入能力分子。

_避免：同一产物重复累计，或只保留任务中的单次过程结果_

**不同有效运行**：
同一任务中，运行的被控对象、模型、控制器配置或关键输入至少一项不同，才构成不同的有效运行；重放或完全相同的重复运行不计入。

_避免：用同一运行的重放或重复提交凑足任务上限_

**有效性状态边界**：
不新增通用的事后判无效或撤销流程。证据仅采用来源在写入时已经提供的有效性状态；不以假设中的人工撤销逻辑扩大画像更新范围。

_避免：为不存在的判定入口建立额外的事实撤回机制_

**无效正式评测的过程证据**：
无效正式评测不贡献正式结果；此前已满足白名单的模型保存、有效运行等过程贡献继续保留。

_避免：将无效评测误作正式达成，或抹除已经发生的有效过程学习_

**任务等权**：
相关任务在能力分母中各占一个相同份额；任务难度和来源差异仅体现在各自的达成规则与上限中。

_避免：在分母中引入不透明的来源或难度权重_

**竞技场满分标准**：
竞技场挑战采用该挑战已有的任务级正式评分标准；只有达到该标准的有效官方评测才使任务满分，不采用全局分数阈值。

_避免：将低分但有效的评测直接等同于满分，或以统一阈值覆盖任务差异_

**奥德赛满分标准**：
奥德赛每个关卡采用其已有的通关或得分标准；只有达到该关卡标准才使任务满分，不采用跨关卡统一阈值。

_避免：将任意完成记录或统一得分阈值误作全部关卡的满分标准_

**既有能力映射的保留**：
仿真产物继续对语义成立的建模、参数设计等既有维度贡献；任务归一化的“仿真验证与证据”贡献作为并行映射增加，不取代既有映射。

_避免：为增加仿真验证与证据而丢失原有学习语义_

**仿真任务目录**：
以一个只读目录统一汇集现有奥德赛、竞技场、资源注册表和控制工作台定义，提供任务集合、来源、上限和展示名称；不新增数据库表。

_避免：由各入口临时计算任务集合，造成分母与展示不一致_
