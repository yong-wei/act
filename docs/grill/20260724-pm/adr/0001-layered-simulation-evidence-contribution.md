# 0001. 采用分层仿真证据贡献

日期：2026-07-24

## 背景

平台中存在参数调整、模型保存、仿真运行、竞技场结果等不同强度的仿真产物。只接受终态结果会遗漏可沉淀的学习过程；将全部操作等权计入又会把操作次数误作验证能力。

## 决策

所有通过治理校验的仿真产物映射到既有的“仿真验证与证据”维度，并采用分层贡献：过程记录只产生较低且有上限的任务进度；完成的可复核运行和竞技场正式结果产生主要贡献。过程记录不得单独等价于完成验证；同一产物在多个阶段出现时，只保留其中最高强度的贡献。

## 后果

各仿真入口必须按证据强度写入可追溯来源和统一的贡献类别。白名单覆盖虚拟仿真的有效运行、控制工作台的模型或控制器保存以及完成运行、评估、提交、竞技场的有效运行、评测、提交、奥德赛的完成关卡、任务结果与得分记录；界面浏览等通用交互不纳入。既有产物按同一规则回填，但只有能确认学生、发生时间和产品语义的记录可回填；缺少课程或任务上下文的记录只形成过程证据。画像更新仍按新增有效学习事实增量计算，保留既有累计口径。仿真验证与证据的映射并行增加，不取代产物对建模、参数设计等既有维度的语义映射。

不新增通用的事后判无效或撤销流程；证据只采用来源在写入时已有的有效性状态。

无效正式评测不形成正式结果；此前符合白名单的过程证据继续保留其低层任务进度。
