# 0003. 按来源拆分仿真任务并设置达成上限

日期：2026-07-24

## 背景

单一“通用仿真实践”任务会把不同奥德赛关卡、竞技场挑战和控制工作台自由仿真混为一项，既掩盖任务差异，也无法阻止重复操作无限提高达成。

## 决策

奥德赛每个关卡为独立任务，竞技场每个挑战为独立任务，未由竞技场任务链接的控制工作台自由仿真为一个通用任务。具有稳定资源或任务标识的虚拟仿真按任务独立计入；缺少标识的历史虚拟仿真归入一个通用任务。各来源任务分别设置达成上限：奥德赛按关卡通关程度、竞技场按正式评分、控制工作台按达到一定数量和质量的仿真结果，具有稳定标识的虚拟仿真任务和通用虚拟仿真均按三个不同的有效运行。

已有来源产品的通关、正式评分或完成标准优先决定任务达成；仅控制工作台自由仿真和通用虚拟仿真补充数量与质量上限。

控制工作台自由仿真的质量由可复核结果和持久化设计或结果共同保证；所选对象已有明确目标或评价指标时，还须满足该指标。三个模型、控制器配置或被控对象不同的有效结果达到该通用任务上限。虚拟仿真以三个不同的有效运行达到上限。

同一任务中，运行的被控对象、模型、控制器配置或关键输入至少一项不同，才构成不同的有效运行；重放或完全相同的重复运行不计入。

竞技场挑战使用其已有的任务级正式评分标准判定满分，不采用跨挑战统一分数阈值。

奥德赛关卡使用其已有的通关或得分标准判定满分，不采用跨关卡统一阈值。

## 后果

无任务归属的历史产物可在来源语义足够明确时恢复为对应任务。任务投影需要保留来源、目标标识和已达成份额，避免将事件数量直接累加为能力值。
