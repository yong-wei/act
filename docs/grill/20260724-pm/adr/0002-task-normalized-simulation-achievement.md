# 0002. 按任务归一化仿真验证与证据达成

日期：2026-07-24

## 背景

仿真产物的数量受操作频率、重试和产品形态影响，不能直接解释为能力高低，也不利于学生与教师理解画像值的来源。

## 决策

“仿真验证与证据”按任务归一化：平台中当前已发布且可供学生完成的相关任务构成分母；学生已满分完成的这些任务数构成分子。草稿、下线任务和仅供教师预览的任务不纳入。每项仿真产物必须关联到相应任务，方可参与能力达成计算。无法明确归属任务、但满足过程证据白名单的产物，按来源的稳定语义目标归入相应通用任务，该任务同样参与分子和分母。

## 后果

证据写入、历史回填和画像投影都需要保留任务归属；归属无法恢复时使用来源语义明确的通用任务。画像可解释为已达成的相关任务份额，而非操作事件数量。

任务发布、下线或相关性变更按任务目录增量处理：只更新受影响画像的分母和聚合值，不重放或重算既有学习事实。

同一任务中，不同合格产物可以累积至任务上限；同一产物只保留最高贡献，正式通关或评测按其结果直接确定任务达成。部分达成只保留为过程证据和任务进度，只有满分任务进入能力分子。

相关任务在能力分母中等权；任务间差异只由各自达成规则与上限表达。
