# 控制工作台方案指标对照

该上下文统一控制工作台多方案指标比较中的领域语言。

## 语言

**方案快照**：
学习者在一次控制设计实验中保存的方案状态，用于保留某一阶段的设计结果，并与当前方案或其他快照进行比较。
_避免：正式提交方案、排行榜方案、分析结果副本_

**对照基线**：
指标差异的共同参照方案。系统默认采用第一个可见的方案快照作为对照基线，并允许学习者在当前方案和可见方案快照之间切换基线；隐藏的方案快照不参与当前对照。基线快照被隐藏或删除后，依次选用最早的剩余可见快照；没有可见快照时使用当前方案。
_避免：始终以当前方案为基线、自动判定最佳方案、不可切换的固定基线_

**指标差值**：
某一方案的关键性能指标相对于对照基线的有方向差异。百分比指标使用百分点表达，其他指标沿用原指标单位；差值只陈述量化变化，不表示方案优劣。
_避免：综合评分、排名结论、百分比指标的相对变化率_

**指标不可用原因**：
某项指标无法形成有效数值时保留的明确状态，包括当前分析数据不可用、当前频率范围内未观测到相位交叉，以及具有无穷增益裕度等不同控制语义；这些状态不得折算为零或相互替代。
_避免：统一显示为零、把未观测到相位交叉写成数据缺失、把无穷增益裕度写成不可用_

**自由探索量化对照**：
控制工作台在没有权威任务约束时，对多个方案的指标原值和相对差值进行并列展示。它帮助学习者形成设计判断，但不生成“满足约束”“最优方案”或其他评价结论；任务约束判定属于具有明确约束来源的评测场景。
_避免：从指标变化自动推断优劣、在通用工作台中虚构任务阈值、把量化对照作为 Arena 评分_

**指标对照空状态**：
当前没有可见方案快照时，指标对照区域只说明需要先保存并显示方案快照，不把当前方案的单列指标展示称为方案对照。
_避免：没有比较对象时渲染单列对照表、完全隐藏能力入口_
