# 控灵会话保留

该上下文定义用户级控灵会话库的保留和过期语义，避免把短期运行会话的技术期限误用于学生可恢复的学习陪伴历史。

## 领域语言

**持久会话历史**：
已经进入当前用户控灵会话库、包含可读消息或工具记录的会话。它在用户明确删除或全局数据治理政策执行前持续可见。
_避免：七天缓存、临时运行会话、浏览器历史_

**产品级自动过期**：
平台在没有用户删除或全局治理决定的情况下，仅因固定时长到达而隐藏或拒绝读取持久会话历史。
_避免：全局保留政策、用户删除、无用初始化清理_

**全局保留治理**：
适用于平台数据的统一保留、删除、法务保留和审计政策。只有该治理或用户明确删除可以结束持久会话历史的可读生命周期。
_避免：路由内写死 TTL、页面缓存期限_

**历史恢复回填**：
将仍保存在数据库中、仅因错误固定过期时间而从会话库隐藏的可用用户会话重新纳入持久会话库，并保留原始消息和时间。
_避免：创建新会话副本、重写历史时间_

## 已确认边界

- `libraryVisible=true` 的用户会话不使用固定七天产品过期；新会话默认没有产品级到期时间。
- 技术临时会话或不进入会话库的运行记录可以保留独立 TTL，但不得影响持久会话历史。
- 已因旧七天期限隐藏但仍可验证归属和内容的会话应幂等恢复，不能静默永久丢失。
- 用户删除和全局保留治理仍可终止会话；本变更不承诺无限制保留所有原始模型或供应商数据。
