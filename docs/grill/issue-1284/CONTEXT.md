# 自适应学习路径纠偏

本上下文限定学习路径在检查点失败或执行偏离后提供的学生侧纠偏建议，避免将候选建议与已生效的路径变更混为一谈。

## 语言

**纠偏方案**：由已记录的检查点结果或路径偏离触发、基于现有受治理节点和学习证据生成的候选路径调整建议；学生确认前不改变当前学习路径。
_避免：自动改路径、即时干预、已执行的纠偏_

**候选纠偏方案**：供学生查看和确认的纠偏方案，说明触发原因、节点变化、证据依据与预计影响；无法基于现有资源生成时，明确给出原因。
_避免：纠偏结果、已确认方案_

**已确认纠偏**：学生明确接受后才会成为路径状态变更的纠偏结果。本次变更不处理该状态。
_避免：候选方案、自动生效_

**路径偏离**：学生对路径节点作出的跳过、替换或放弃等、已记录且带上下文的执行事实。
_避免：学习困难、路径调整_

## 示例对话

开发者：学生跳过当前节点后，是否应立即替换后续路径？

领域专家：不应立即替换。系统先给出候选纠偏方案，学生确认后才形成已确认纠偏；本次仅交付前者。
