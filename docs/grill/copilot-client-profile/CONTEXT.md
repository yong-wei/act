# Copilot 学习画像信任边界

该上下文定义 Copilot 使用学习者信息时的来源、身份和可用性边界，服务于学习过程陪伴中的真实反馈与策略建议。

## 领域语言

**客户端页面提示**：
由浏览器根据当前页面生成的课程、步骤、主题和页面类型等定位信息，只用于帮助服务端识别辅导场景，不能证明学生身份、能力或学习事实。

**受治理学习画像**：
服务端依据当前认证学生、已验证学习事实和现行画像投影规则生成的、带有来源和限制说明的学习者信息。只有该信息可以作为 Copilot 个性化回答的依据。

**画像可用性**：
受治理画像是否存在足够证据支持当前辅导表达。缺失、不可用、过期或低置信度必须与有效画像区分，不得用默认数值补齐。

**冷启动辅导**：
画像证据不足时仍提供与当前课程内容相关的通用解释、诊断入口或证据采集行动，但不对学生能力、风格、进度或成就作个人化断言。

**学生安全投影**：
从服务端学习状态中去除内部身份、原始数据和实现细节后，供当前学生 Copilot 使用的最小画像与限制集合。

## 边界

- 浏览器提交的 `userProfile`、用户 ID、能力向量和学习风格均属于不可信输入。
- 服务端必须以认证会话确定学生身份，并从受治理学习状态派生可用画像。
- Copilot 可以使用当前页面定位信息，但页面定位不能扩大画像权限或替代学习证据。
- 画像缺失时，回答应回到课程内容和可执行的证据采集行动；不得生成精确的个人能力结论。
