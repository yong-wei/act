# 以答案为界的学生微辅导启动与验证题投影

## 决策

学生端以持久化自适应答案 ID 启动微辅导，而不接收或保存内部错答归因 ID。服务端在每次启动时用当前认证学生重新核验该答案并生成或读取归因，再调用既有编排服务。

开始干预后，验证题通过受限的学生接口投影为题面和选项；答案键、解析、原题标识、归因、知识节点和内部版本依据不发送到浏览器。

## 原因

现有编排接口以归因 ID 为输入，而自适应练习页面持有的是答案 ID。直接把内部归因暴露给前端会扩大可枚举和耦合的身份边界；让客户端自行串联归因与编排也会绕开服务端的归属复核。

现有微干预 API 可以验证提交，但没有可供学生作答的安全题面投影。复用其服务端校验并增加最小读取边界，可避免客户端读取正确答案或解释。

## 后果

- 微辅导仍由学生显式触发，且所有启动、读取和验证继续由服务端按当前身份和版本校验。
- 自适应练习页面只管理面向学生的流程状态，不复制编排规则、答案校验或推荐逻辑。
- 前端增加一次 answerId 到编排结果的安全转换，以及一次开始后的验证题读取请求。
