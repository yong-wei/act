# Evidence Copilot 导航边界

本上下文记录 Evidence Copilot 中“导航提示”和“学习证据”的边界，服务于学习过程陪伴的可信度与提示词安全。

## Language

**导航提示**：来自 URL 或客户端请求、用于标识入口或表达复盘目标的有限描述。导航提示不是学习事实、证据来源授权、成绩、薄弱点或诊断结论。

**受治理学习证据**：服务端依据当前认证学生、来源归属、可见范围和质量规则解析出的学习事实或评测结果。只有这类数据可以成为 Evidence Copilot 的事实依据。

**私有事实上下文**：发送给模型的服务端上下文，只包含当前学生授权的受治理证据及其状态、限制和允许的产品语义；客户端自由文本不能借此取得系统级指令地位。

**提示词注入**：把导航提示、学生自填文字或其他不可信输入解释为模型指令，使其改变事实范围、行为边界或诱导输出系统提示词、内部上下文和诊断信息。

## Resolved Boundaries

- Evidence Copilot 的回答只能解释服务端授权的受治理学习证据。
- URL 的 `source`、`assignment`、`intent` 可以帮助页面定位或表达学习目标，但不应作为原始自由文本进入模型私有事实上下文。
- 缺少证据时应保留缺失、部分、过期和不可用状态，不通过模型推测补齐个人事实。
- 普通 Copilot 没有 Evidence Copilot 上下文时保持既有行为。
