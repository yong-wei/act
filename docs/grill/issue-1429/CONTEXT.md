# Issue 1429 Context

本上下文记录自适应学习路径候选比较功能中的领域术语与边界，供本 Issue 的设计和实现共同使用。

## Candidate Comparison

**事实摘要**：只呈现当前候选批次中可核验的路径差异，例如学习时长、节奏、资源组合和检查点设置；它不表达系统认为哪条路径更优。

**系统推荐依据**：已有推荐流程产生并随候选路径保留的正式依据。只有该依据明确声明某条路径被推荐时，界面才可显示“系统推荐”；候选比较摘要不得自行推导推荐结论。

**明确比较对**：由用户主动选择的两个不同候选方案，作为两两差异详情的唯一输入。候选批次进入比较入口时不预设比较对；三候选批次必须允许选择 `A-B`、`A-C` 和 `B-C`，且候选顺序变化不能改写已选方案。

**比较结果有效性**：两两差异详情只对生成它的候选批次、路径版本和明确比较对有效。`candidateBatchId + pathVersion + leftOptionId + rightOptionId` 共同构成比较结果的身份；任一部分变化都会使旧响应失效。

**候选降级状态**：候选数量和事实证据完整度决定比较入口的可用状态。零候选时没有可比较方案；单候选时只展示该路径及可用事实，不展示比较选择器；证据不完整时明确标记数据不足，不推测缺失差异，同时保留继续学习能力。

**比较只读边界**：候选对选择、事实摘要和两两差异展示都不改变学习路径数据、当前执行进度或推荐状态。路径创建、覆盖、推进和删除只能由已有的明确动作触发。

**比较入口可达性**：候选比较在 320px 宽度下仍保留完整候选对和事实信息，并支持键盘完成定位、选择和确认；交互语义不能依赖悬停、拖拽或仅图标。

**规范化比较关系**：两两比较没有方向。同一候选批次和路径版本中的 `A-B` 与 `B-A` 共享一个规范化 pair key，避免重复请求和缓存分裂；界面可以按用户当前选择展示左右方案，但事实结果只有一个。

**多候选事实摘要**：以候选为行、固定事实维度为列，横向呈现当前批次中每条路径的可核验值。差异维度只来自已有事实；同值维度显示无差异，缺失事实显示数据不足，不生成总分、排序或胜负结论。

**比较查看状态**：只有用户完成明确比较对选择后，页面 URL 才持久化批次、路径版本和比较对，用于刷新及浏览器导航恢复只读查看状态。仅有候选批次参数时显示整体摘要；参数不完整或版本不匹配时回退摘要并要求重新选择。

**候选事实来源**：服务端候选事实与差异合同是唯一事实来源。前端不重新计算时长、节奏、资源差异或推荐结论；服务端未提供的字段必须显示数据不足。

## Example Dialogue

**开发者**：比较摘要能否根据差异自动告诉学生应该选哪条路径？

**领域专家**：不能。摘要只负责把候选批次中的事实差异讲清楚；推荐标识只能来自已有正式推荐依据，不能由比较页面自行评分或排序。

**开发者**：进入比较入口时可以默认比较前两条候选吗？

**领域专家**：不能。比较对象是用户的明确选择，入口先展示批次摘要和选择器；用户选择两个不同方案后，才展示这两个方案的差异详情。

**开发者**：旧请求在用户切换候选对后才返回，可以继续显示吗？

**领域专家**：不能。批次、路径版本或比较对变化后，旧响应必须被丢弃，界面清空过期详情并提示需要重新选择或重新加载。

**开发者**：证据缺失时能否用默认值补齐差异，让比较卡片保持完整？

**领域专家**：不能。默认值会把未知事实伪装成真实差异；应明确显示数据不足，并保留已确认的候选信息和继续学习入口。

**开发者**：用户在比较页选择某个候选方案时，是否可以立即把它写成当前学习路径？

**领域专家**：不能。比较页是只读解释流程；只有已有的继续原路径或明确采用方案动作，才允许改变执行上下文或创建路径。

**开发者**：窄屏是否可以隐藏部分候选对或只保留图标按钮？

**领域专家**：不能。窄屏只改变布局，不改变比较能力；所有候选对和事实摘要仍需可见或可访问，并有明确的键盘和辅助技术名称。

**开发者**：如果用户把 A 和 B 对调，是否应重新生成一份结果？

**领域专家**：不应。A-B 与 B-A 是同一个无方向的比较关系，应复用同一结果身份；只有展示顺序改变，事实不变。

**开发者**：三候选的摘要能否把差异折算成一个总分，帮助学生快速决定？

**领域专家**：不能。摘要必须保留固定事实维度和每个候选的原值；总分或胜负会把解释流程变成新的推荐流程，超出本 Issue 的边界。

**开发者**：只要 URL 有候选批次，就可以自动恢复上次比较详情吗？

**领域专家**：不能。只有 URL 同时包含完整且仍有效的比较对和版本信息，才能恢复详情；仅有批次参数只能进入摘要。

**开发者**：为了让界面更快，能否在浏览器端重新计算候选差异？

**领域专家**：不能。差异来自服务端合同，前端只做状态选择和展示；重复领域计算会造成服务端和客户端结果不一致。
