# 活动路径节点决策解释

本上下文统一 Issue #1186 第二阶段中活动路径节点入选、顺序调整与锁定说明所使用的领域语言。候选路径聚合推荐依据仍沿用第一阶段定义，事件级证据回跳不属于本阶段。

## Language

**活动路径节点决策**：
活动路径中一个节点当前被保留、调整顺序或锁定的学生可见决策事实。它解释节点为何处于当前位置和状态，不等同于节点完成结果。
_Avoid_: 通用推荐理由、节点结果、内部 reason code

**节点调整基线**：
学生确认一次纠偏前的上一版活动路径，是判断该次纠偏中节点提前或延后的唯一比较序列。最初选中的候选路径只负责说明节点为何入选，不替代逐次调整基线。
_Avoid_: 当前路径与初始路径的跨轮总差异、未经确认的候选纠偏方案

**节点提前**：
节点在一次已确认纠偏后，相对该次节点调整基线出现在更靠前位置的决策结果。
_Avoid_: 当前节点、自动解锁、相对初始路径的累计位移

**节点延后**：
节点在一次已确认纠偏后，相对该次节点调整基线出现在更靠后位置的决策结果。
_Avoid_: 锁定、跳过、未确认方案中的排序变化

**当前锁定依据**：
活动路径节点当前不能执行时，由受治理 readiness 状态给出的学生安全原因与解锁条件。它随先修完成和有效证据补齐而更新，不冻结为路径最初选中时的状态。
_Avoid_: 生成时锁定快照、仅凭界面状态推断原因、内部节点 ID 或 reason code

**解锁动作**：
学生为满足当前锁定依据可以执行的明确学习动作，例如完成先修节点、补充检查点证据或完成准备活动。
_Avoid_: 无法操作的原则说明、内部数据修复动作、保证完成后一定通过的承诺

**节点历史决策解释**：
活动路径节点在完成或跳过后仍保留的入选依据和最近一次已确认顺序调整说明，用于复核整条路径的安排过程。节点的当前锁定依据不属于历史决策解释。
_Avoid_: 完成后删除解释、把当前 readiness 冻结为历史事实、复制完整执行记录

**最近节点调整**：
最近一次已确认纠偏中直接影响某个节点位置或去留的调整事实。更早调整仍归属于既有纠偏决策历史，不在节点详情中重复展开。
_Avoid_: 未确认纠偏方案、节点内完整纠偏时间线、只比较最初候选路径

**历史路径解释限制**：
旧活动路径缺少节点决策投影时显示的明确限制，保留已有学生可见推荐理由，但不使用当前学习状态重新构造历史入选或调整事实。
_Avoid_: 从当前画像反推历史原因、伪造调整基线、隐藏解释缺口

## Example dialogue

> 开发：这个节点比最初候选路径靠后，是否直接标记为“延后”？  
> 领域专家：不能。先查看最近一次已确认纠偏的节点调整基线；只有本次确认使它向后移动，才称为“节点延后”。最初候选路径仍用于解释它为什么入选。

> 开发：节点生成时缺少证据，现在已经补齐，还要显示原来的锁定原因吗？  
> 领域专家：不要。当前锁定依据读取最新受治理 readiness；入选和顺序调整属于历史决策，锁定与解锁则反映当前可执行状态。

> 开发：节点完成后，推荐依据是否可以从详情中移除？  
> 领域专家：不可以。节点历史决策解释仍需说明它为何入选以及最近一次确认如何调整了顺序，便于学生复核整条活动路径。

> 开发：一个节点经历过三次纠偏，详情里是否列出三次记录？  
> 领域专家：节点详情只显示最近节点调整；完整过程继续查看既有纠偏决策历史，避免形成第二套时间线。
