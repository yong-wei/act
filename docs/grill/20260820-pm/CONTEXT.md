# 教学运行时资源分发

定义合作者在开发调试期间能够读取的教学运行时资源边界。

## Language

**当前生产运行时发布**:
已被生产环境明确激活的单个不可变教学运行时版本。它不包括历史版本或尚未激活的候选版本。
_Avoid_: 最新版本、全部运行时版本

**开发只读资源视图**:
授权合作者用于本地调试的当前生产运行时发布完整内容，包括教材正文、结构化索引和治理工件。教学服务只选择该发布，不选择历史或候选发布。
_Avoid_: 公共资源包、媒体包、OSS 全读权限

**开发工作站运行身份**:
每位合作者的个人电脑在启动和运行教学服务时使用的统一只读资源访问身份。教学服务通过本机挂载的开发只读资源视图检查运行正确性。
_Avoid_: 生产实例身份、资源分发包身份

**开发运行时只读命名空间**:
开发工作站运行身份在技术上能够读取的完整运行时对象范围。该范围与生产只读身份相当，可能包含历史或候选发布的对象，但不具有任何写入或管理能力。
_Avoid_: 仅活动发布权限、运行时维护权限

**混合平台开发工作站**:
合作者用于运行教学服务的个人电脑集合，包含 macOS、Windows 和 Linux 环境。开发资源访问方案不能假定所有工作站都具有相同的原生文件系统与挂载能力。
_Avoid_: 统一 Linux 工作站

**统一 Linux 开发运行层**:
混合平台开发工作站共同采用的 Linux 服务运行环境；Linux 使用原生环境，Windows 使用 WSL2，macOS 使用 Linux 虚拟机。教学服务及其运行时资源挂载均在该环境内运行。
_Avoid_: 跨平台原生挂载、仅封装 FUSE 的应用容器

**共享开发读取凭据**:
全部合作者在项目剩余周期内共同使用、并在项目结束时统一撤销的开发工作站运行凭据。该凭据只对应开发运行时只读命名空间，不能区分具体合作者的访问行为。
_Avoid_: Publisher 凭据、永久协作凭据

**生产活动发布发现**:
生产服务通过就绪信息公开的当前生产运行时发布身份，仅包含发布标识及内容完整性摘要。开发工作站据此选择资源，不以对象目录排序推断最新版本。
_Avoid_: 最新目录、候选发布发现

**开发启动发布固定**:
教学服务每次启动时解析并固定一个当前生产运行时发布，运行期间保持该发布不变。后续生产更新在下一次启动时生效。
_Avoid_: 运行中自动切换、永久版本固定
