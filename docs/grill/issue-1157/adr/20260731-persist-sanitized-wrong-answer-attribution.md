# 将错题归因保存为独立的脱敏快照

**Date:** 2026-07-31

**Status:** Accepted

## Context

自适应评测已经保存包含题干、选项、答案和解释的不可变作答证据快照。微辅导后续步骤需要稳定的知识节点、误区、置信度与证据引用，但这些消费者不应获得原始答案、解析文本、私有对话或未治理载荷。

把归因写回题目引用会混合共享题目与学生事实；把归因写入教师诊断报告会混合两个权限和生命周期不同的边界；每次临时重算则无法保证版本、审计和幂等性。

## Decision

每个错误作答与归因版本对应一个独立、不可变的脱敏归因快照。快照绑定学生、会话、作答、题目引用及题目内容哈希，并只保存：

- 已审核的规范知识节点标识；
- 受控误区标签；
- 脱敏证据摘要与稳定证据引用；
- 置信度、归因状态、限制和建议动作；
- 归因版本与创建时间。

归因输入必须通过当前学生所有权、会话一致性和题目快照版本校验。证据不完整或置信度不足时保存“不确定归因”，不得降级为事实性诊断。归因公开投影采用字段白名单，不传递原始作答载荷。

## Consequences

后续微辅导可以依赖稳定、可审计且权限边界清晰的归因结果。规则升级需要新的归因版本，不能静默改写历史结果。数据库增加独立模型和迁移，调用方必须显式处理不确定状态。
