# Issue #1157 术语表

## 错题证据归因

针对一次可追溯错误作答形成的、受治理的诊断结果。它描述该证据支持的知识节点与误区，不等同于原始作答上下文，也不直接改变掌握度或学习路径。

## 作答证据快照

在作答时固定、与学生、会话和题目版本绑定的不可变证据。后续归因以该快照为准，不使用后来被改写的题目内容。

## 规范知识节点

知识图谱中经过审核且具有稳定标识的节点。归因只能引用作答证据快照中固化的规范节点标识。

## 受控误区标签

来自已审核标签集合的稳定误区标识。自由文本推断不得作为受控误区标签保存或公开。

## 不确定归因

当证据不完整或置信度不足时保存的明确状态。该状态只能表达“尚不能确定”，并指向人工复核或重新练习，不得作为事实性诊断展示。

## 证据引用

指向受治理作答、会话、题目版本和知识节点的稳定引用。证据引用不包含原始答案、解析文本、私有对话或其他未治理载荷。

## 归因版本

标识归因规则与输出契约的稳定版本。相同作答与相同归因版本只能产生一个持久化结果。
