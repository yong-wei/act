# 控制工作台测试契约

本上下文约束控制工作台图表测试应验证的用户可见行为边界，避免测试将内部实现细节误作产品合同。

## 语言

**控制图表测试契约**：
控制工作台中 Bode、Nyquist 等图表围绕既定交互和可见结果形成的回归验证边界。源码级测试只验证关键参数已接入对应构造路径，不固定函数的完整内部参数序列或源文件换行形式；它保护图表构造、频率拖拽和视口保持等行为。
_避免_：源码文本快照、完整内部调用格式、图表运行逻辑重构

**测试契约维护**：
为恢复失效回归验证而调整测试表达的变更类型。它只修改测试断言；若发现图表实现未满足关键参数接入，运行逻辑缺陷必须作为独立 Issue 处理。
_避免_：借测试修复重构运行实现、混合功能变更

## 示例对话

开发者：这次 Bode 构造函数增加一个可选参数，原测试失败了，是否需要修改图表逻辑？

领域专家：先看控制图表测试契约。若频率拖拽和视口保持仍成立，只需验证关键参数仍被接入，不把参数排列本身当作功能。

开发者：如果测试发现关键参数实际没有传入图表构造函数，是否在这次顺手改运行代码？

领域专家：不属于测试契约维护。将运行缺陷另立 Issue，避免混入既有验证修复。
