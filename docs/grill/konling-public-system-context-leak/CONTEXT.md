# 控灵公开会话上下文边界

该上下文定义控灵持久会话在服务端记录与学生浏览器公开投影之间的边界，避免内部提示与治理标识被误当作学生可见聊天历史。

## Language

**公开会话投影**：
返回给当前认证学生浏览器的会话表示，只包含学生可见的用户消息、助手消息和经过单独约束的公开绑定信息。
_避免：完整会话记录、客户端过滤后的会话、原始消息数组_

**内部上下文记录**：
服务端以 `system` 角色持久化的页面范围、资源范围、权威发布和去重上下文，用于审计、恢复和服务端提示构造，不属于学生可见消息。
_避免：聊天消息、公开系统提示、前端隐藏消息_

**公开助手绑定**：
从内部会话状态单独派生的受限助手模式和允许提示，用于恢复学生可见的助手任务态，不包含原始 `system` 消息内容或内部治理标识。
_避免：系统消息副本、完整模式上下文、客户端授权信息_

**浏览器可见性过滤**：
界面为了渲染聊天气泡而筛选用户和助手消息的显示逻辑；它不是数据保密或公开 API 的安全边界。
_避免：服务端脱敏、访问控制、公开投影_
