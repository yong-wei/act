# 学习过程陪伴：多控制方法适配

本上下文记录 Issue #1181 中 AI 学伴对控制方法、任务指标和学习证据的共同语言，避免将 PID 调参语义误用于 MPC、黑箱辨识等不同学习场景。

## 语言

**陪伴场景配置**：由挑战任务、允许控制方法和指标档案共同确定的、用于解释一次练习记录的教学上下文。它不改变官方评分或挑战规则。
_避免_：PID 默认字段、通用调参表单

**官方评测事实**：由服务端官方评测产生并持久化的任务结果及其可追溯指标上下文。它可以作为学习诊断证据，但不能由陪伴界面伪造。
_避免_：客户端自报成绩、陪伴评分

**陪伴诊断**：基于已提供的尝试结果和陪伴场景配置，对失败模式、约束风险或探索停滞给出的学习解释与下一步建议。它不等同于错因事实或正式成绩。
_避免_：官方判分、能力结论

**错误归因**：对可追溯学习证据中错误原因的受治理判断。没有经验证的归因证据时，陪伴诊断只能陈述指标现象和练习建议，不能将猜测写成错因事实。
_避免_：AI 猜测错因、未验证的掌握度结论
