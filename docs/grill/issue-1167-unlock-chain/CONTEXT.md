# 学习路径解锁链路语境

本语境描述学习路径锁定节点向学生解释“为什么锁、缺什么、下一步做什么”的领域语言。

## 语言

**解锁链路**：
锁定节点面向学生展示的一组可读条件，说明当前未满足哪些 readiness 要求以及完成后如何解锁。
_避免_：全局进度图、完整前置依赖图

**锁定节点**：
当前学生尚未满足执行条件、不能启动的学习路径节点。
_避免_：不可用节点、灰色资源

**readiness 缺口**：
锁定节点所需前置条件中当前尚未满足的部分，例如缺少指定节点完成记录、证据数量、能力值或结果引用。
_避免_：阻塞原因、内部 reason code

**下一步解锁动作**：
学生为解除当前锁定最优先需要完成的单个可执行动作。
_避免_：笼统提示“完成准备节点”

**解锁条件文案**：
由资源配置提供的单句学生可见说明，只能作为解锁链路的降级兜底，不作为唯一解释来源。
_避免_：将 `unlockMessage` 当作完整解锁链路
