## 一级目录说明

- `10-project/`: 项目是什么、现在到哪一步、术语怎么理解
- `20-architecture/`: 系统如何工作，尤其是课程框架、鉴权、数据与资源注册
- `30-operations/`: 线上如何运行，环境、迁移、观测与部署风险
- `40-domain/`: 课程与教学域知识，帮助理解业务语义
- `50-decisions/`: 长期有效的设计决策
- `60-incidents/`: 真实事故和排障复盘
- `70-workflows/`: 高频操作流程
- `90-archive/`: 过期或被替代的历史记忆
