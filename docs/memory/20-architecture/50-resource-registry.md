## 约束

- 所有可编排资源都应注册到 `src/lib/resource-registry.tsx`
- 教案层只引用 `registryId`
- 不应在教案或课堂页中直接写资源组件路径

## 这样做的原因

- 资源可复用
- 配置覆盖更清晰
- 课堂渲染器可以统一处理埋点、AI 面板和嵌入模式
