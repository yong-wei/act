# 系统测试功能问题与改进建议


## 1. “了解课程设计”按钮点击无响应

### 页面链接

```text
https://act.adapt-learn.online/
```

### 问题描述

用户点击首页中的“了解课程设计”按钮后，页面无任何响应，未发生跳转、弹窗或提示信息。

从界面设计上看，该按钮样式明显属于可点击组件，但实际无法触发功能，容易让用户误认为系统卡顿或功能失效。

### 复现步骤

1. 打开系统首页
2. 在“开启任务链”旁边的“了解课程设计”按钮
3. 鼠标点击按钮
4. 页面无任何变化

### 预期结果

点击按钮后应：

- 跳转至课程介绍页面
- 或弹出课程设计说明窗口
- 或给予“功能暂未开放”等提示

### 实际结果

按钮点击后没有任何反馈。


### 问题类型

功能Bug


## 2. 数学公式显示方式不规范，影响界面美观

### 页面链接

```text
https://act.adapt-learn.online/arena/challenges/task-second-order-lead-pid
```

### 问题描述

当前系统中的数学公式采用普通文本形式显示：

```text
G(s)=16/(s^2+2.4s+16)
```

其中“s^2”使用了编程式写法（`^2`）表示平方，不符合数学公式的常规展示习惯，整体视觉效果一般。

尤其在教学或课程演示场景下，容易降低界面的专业性。

### 改进建议

建议使用标准数学公式渲染方式，将：

```text
s^2
```

显示为：

```math
s²
```

完整公式建议显示为：

```math
G(s)=16/(s²+2.4s+16)
```

以提升公式展示效果与专业性。

### 预期效果

数学公式能够以标准数学排版形式展示，提升页面美观度与阅读体验。

### 问题类型

显示优化


## 3. 知识图谱节点显示过于密集，信息可读性较差

### 页面链接

```text
https://act.adapt-learn.online/knowledge
```

### 问题描述

当前知识图谱页面中，节点数量较多且连线复杂，导致整体显示过于密集。大量文字标签相互重叠，节点与关系线交叉严重，难以快速识别节点内容及其关联关系。

在当前界面下：

- 节点名称遮挡严重
- 连线方向难以辨认
- 不同关系类型区分不明显
- 页面信息层次混乱

视觉效果较复杂，新用户很难快速理解知识图谱结构，看不出逻辑关系。

### 问题类型

显示优化


## 4. 反馈按钮点击后缺少结果提示

### 页面链接

```text
https://act.adapt-learn.online/simulations/destroyer?mission=cmjm54tor0000qs9duv0kga9a
```

- 弹出“反馈成功”提示
- 或按钮状态发生变化（如高亮、禁用、已提交）

### 实际结果

点击后页面无任何变化。

Bug


## 5. “本次尝试是否成功”使用勾选框设计不合理

### 页面链接

```text
https://act.adapt-learn.online/simulations/cruise
```

### 问题描述

在仿真界面中，“本次尝试是否成功”采用了单个勾选框的形式进行选择。

该设计存在一定的语义歧义：

- 用户无法直观理解“不勾选”是否代表失败
- 勾选框更适用于“多选”或“开关状态”
- 不符合“是 / 否”类问题的常规交互逻辑

对于结果判断类问题，当前设计容易让用户产生困惑。

### 改进建议

1. 建议改为单选按钮

示例：

```text
( ) 成功
( ) 失败
```

2. 或改为“是 / 否”双按钮形式

```text
[是]   [否]
```
