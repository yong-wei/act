 # KA-Q 公式推导工具

 KA-Q 公式推导工具为学生提供自动化的数学公式逐步推导能力，使用 SymPy 符号计算引擎，通过 API 路由在互动学习场景中集成。

 ## 术语

 **推导引擎**：由 Python SymPy 库驱动的符号数学计算核心，负责执行拉普拉斯变换、符号化简等数学运算，并生成结构化推导步骤。

 **推导流水线**：从接收推导请求到返回结构化推导结果的完整处理链路，包含输入解析、SymPy 运算编排、步骤格式化和 LaTeX 序列化四个阶段。

 **推导步骤序列**：推导过程中每一步的数学变换记录，包含步骤序号、描述、变换操作和 LaTeX 表达式，构成可逐步展示的教学路径。

 **拉普拉斯变换推导**：对时域函数 \(f(t)\) 执行拉普拉斯变换 \( \mathcal{L}\{f(t)\} = F(s) \) 的逐步推导，覆盖常用变换对、线性性质、微分/积分性质和时移性质。

 **符号化简**：对传递函数、多项式、分式等符号表达式执行代数化简，包括因式分解、部分分式展开、通分合并等操作。
