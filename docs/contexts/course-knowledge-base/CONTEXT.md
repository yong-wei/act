# 课程知识基座

课程知识基座定义控制理论课程中稳定的知识概念、概念间语义关系，以及教学资源对这些概念的引用语言。

## 知识身份

**规范知识概念**：
课程知识基座中具有唯一语义、可被关系和教学资源稳定引用的知识单位。同一概念在不同章节、领域或资源中出现时仍是同一个规范知识概念。
_避免使用_：章节知识点、同名副本

**规范知识 ID**：
规范知识概念不可变且不向学习者展示的稳定身份。概念更名、调整章节或改变领域归属时，规范知识 ID 保持不变。
_避免使用_：节点名称、显示名称

**语义名称**：
规范知识概念面向人的唯一名称，只表达概念本身，不附加无意义编码。语义相近且没有独立教学必要的名称必须归并；确需区分时使用能够说明实质差异的语义限定语。
_避免使用_：名称加编号、章节加名称、名称加随机后缀

**语义名称冲突**：
两个规范知识概念具有相同语义名称，或名称不同但实际表达同一概念的状态。语义名称冲突必须阻断知识基座发布。
_避免使用_：允许重复、后续人工清理

## 知识粒度

**知识概念准入**：
一个候选内容必须可独立定义并能够独立教学或评价，同时具有正式课程目标、必要先修或明确拓展之一的范围锚点，才有资格成为规范知识概念。单独成为关系端点不足以纳入。
_避免使用_：凡术语皆节点、凡公式皆节点、关系端点即准入

**支持性内容**：
用于解释规范知识概念但不具有独立教学身份的公式片段、普通例子、属性、注释或章节标题。支持性内容属于知识卡片或教学资源，不单独成为规范知识概念。
_避免使用_：附属知识点、章节节点

## 分类与组织

**知识领域**：
按照学科语义聚合规范知识概念的分类视角。每个规范知识概念至少属于一个知识领域，并可同时属于多个知识领域，不要求唯一主领域。
_避免使用_：章节、主领域、节点容器

**领域归属**：
规范知识概念与知识领域之间的多对多分类关系。同一概念出现在多个领域视图时仍保持同一规范知识身份。
_避免使用_：领域副本、跨领域复制

**课程模块**：
具体课程版本中的一级教学编排单元，对应现有课程语言中的章节。课程模块组织教学进度，但不是规范知识概念或知识领域。
_避免使用_：章节节点、知识领域

**课次**：
课程模块下可实施的一次教学编排单元。课次引用本次教学涉及的规范知识概念，但不拥有这些概念。
_避免使用_：知识点容器、知识节点

**领域视图**：
按知识领域过滤并呈现规范知识概念及其关系的图谱投影。领域视图的顶级入口是知识领域，不显示课程模块或课次节点。
_避免使用_：章节图谱、章节根节点

**课程编排关联**：
课次与规范知识概念之间可编辑、可过滤的多对多引用，说明某个概念在该课次中被引入、深化、练习、评价或复习。课程编排关联不改变概念身份或领域归属。
_避免使用_：节点章节属性、章节包含关系

## 知识关系

**包含关系**：
父概念到子概念的有向关系，只表达真实的概念组成或类型层级。课程模块、课次或资源收录不构成包含关系。
_避免使用_：章节包含、资源包含、同页出现

**先修关系**：
先学概念到后学概念的有向学习依赖。“后修”是从目标概念查看同一关系的反向称谓，不单独存储反向边。
_避免使用_：后修边、学习顺序备注

**关联关系**：
两个规范知识概念之间值得拓展学习的对称语义联系。关联关系不参与先修路径计算，并且必须说明关联理由。
_避免使用_：其他关系、弱关联、无理由关联

**关系依据**：
说明一条包含、先修或关联关系为何成立并支持复核的简短理由与证据。缺少关系依据的候选关系不能进入知识基座。
_避免使用_：自动推断即真相、无来源边

**直接先修**：
理解目标概念之前必须直接掌握、且不能完全由其他已声明先修概念传递替代的知识概念。知识基座只存储直接先修，间接先修由系统沿先修路径计算。
_避免使用_：全部历史先修、课程相邻顺序

**基础概念**：
在当前知识基座范围内不依赖其他规范知识概念即可开始学习的概念。基础概念是先修路径的合法起点，不因缺少入边被视为孤立。
_避免使用_：无关系节点、默认第一章知识点

**先修路径**：
由直接先修关系构成、从基础概念到目标概念的无环可达路径。传递先修是先修路径的计算结果，不作为独立事实边存储。
_避免使用_：课程课次顺序、全部可达边集合

**先修要求组**：
目标概念的一套完整直接先修条件。同一要求组内的概念必须全部掌握，不同要求组之间可以任选一组满足；没有替代声明时，全部直接先修属于同一要求组。
_避免使用_：先修标签、任意入边即可

**替代学习入口**：
能够独立满足同一目标概念准入条件的不同先修要求组。替代学习入口表达知识准备方式的差异，不是课程顺序的任意排列。
_避免使用_：随机路径、同组重排

**有效关联**：
能够引导学习者进行有价值的比较、迁移、应用或解释拓展，并且不能由包含或先修关系充分表达的关联关系。有效关联必须明确说明从一个概念继续查看另一个概念的学习价值。
_避免使用_：同章共现、名称相似、模型判定相关

**接入完整性**：
每个规范知识概念至少通过包含、先修或关联中的一种关系接入知识基座，或者被明确裁定为合法基础概念。接入完整性不要求固定数量的关联边。
_避免使用_：每节点关联配额、孤立待补

**关系兼容性**：
同一概念对允许哪些规范关系并存的约束。关联不得与包含或先修并存；包含和先修只有在分别具有独立关系依据时才可并存。
_避免使用_：任意多关系、具体关系加弱关联

**概念层级**：
由直接包含关系形成的有向无环结构。一个子概念可以具有多个直接父概念；祖先包含关系由系统计算，不作为独立事实边存储。
_避免使用_：强制单父树、循环包含、全部祖先边

## 教学资源

**资源知识绑定**：
教学资源与已发布规范知识概念之间带有明确教学角色的关联。资源知识绑定支持从资源定位概念，也支持从概念按角色反查资源。
_避免使用_：相关知识点文本、未校验节点名称

**讲解绑定**：
资源直接教授、解释或示范某个规范知识概念的绑定角色。
_避免使用_：提到、相关

**练习绑定**：
资源要求学习者运用某个规范知识概念完成活动的绑定角色。
_避免使用_：可能涉及、延伸阅读

**评价绑定**：
资源能够产生某个规范知识概念掌握证据的绑定角色。
_避免使用_：练过即掌握、资源完成状态

**引用绑定**：
资源提及某个规范知识概念，但不承担该概念的直接讲解、练习或评价目标。
_避免使用_：主要知识点、学习目标

**教学资源**：
承担讲解、练习或评价中至少一种教学作用的正式资源。教学资源发布前必须绑定至少一个已发布的规范知识概念，且不能只具有引用绑定。
_避免使用_：任意文件、无目标资源

**非教学资产**：
不承担知识讲解、练习或评价作用的封面、导航、版权说明、布局组件或运行配置。非教学资产可以免除知识绑定，但不能进入学习路径、教学资源推荐或掌握证据。
_避免使用_：无绑定教学资源、默认豁免资源

**规范知识卡**：
与一个已发布规范知识概念一一对应的 Markdown 内容真源，说明该概念的定义、边界、核心表达、常见误区和学习提示。
_避免使用_：多卡真源、生成图片真源

**派生知识卡**：
依据规范知识卡特定版本生成的信息图、视觉卡片或其他呈现形式。派生知识卡可以有多个版本，但不能独立改变概念真相。
_避免使用_：独立知识定义、无来源生成卡

## 知识治理

**知识审查块**：
为适配有限审核上下文而临时划分的一组候选概念及其块内关系。知识审查块只用于治理分工，不是知识领域、课程模块或运行时分类。
_避免使用_：审核领域、临时章节

**跨块关系**：
两个端点分属不同知识审查块的候选包含、先修或关联关系。跨块关系在端点身份稳定后单独审核，不由任一块内审核默认批准。
_避免使用_：自动接受的外部边、跨领域关系

**收尾审核**：
所有知识审查块和跨块关系完成后，对合并图执行的全局一致性、覆盖性、迁移影响和独立复核。收尾审核通过前，分块结果不能整体发布。
_避免使用_：抽样复查、单块清场

**身份候选组**：
由规范化后精确同名和已审核受控同义词形成的全局身份等价分量。一个分量全局闭合、不可跨块拆分且只有一个 owner；`pending split` 是分量内部的审核处置，不预先拆分所有权。
_避免使用_：把近义候选并入等价分量、自动合并组、预拆 owner

**近义审核边**：
连接两个不同身份等价分量的词法、向量或代理近义候选。近义审核边可以跨块，只进入审核队列，绝不自动合并或改变分量 owner。
_避免使用_：相似度即等价、近义候选不可拆分

**语义审查分块**：
在身份等价分量不可拆分的前提下，排除课程结构与导航维度污染，并按身份语义、文本和关系连通性形成的审查块。独立字段 `candidate_concept_count` 统计块内身份等价分量并以四十至八十为审核容量目标；pending split 在阶段一仍计为一个分量。该容量不得用还包含关系、卡片和迁移输入的 `exact_count` 代替。
_避免使用_：按旧章节分块、按旧领域直接分块

**身份迁移映射**：
从退役旧节点 ID 到保留规范知识 ID 的不可丢失映射，用于迁移资源、学习证据和路径引用，并兼容读取历史快照。
_避免使用_：删除旧 ID、名称猜测映射

**歧义历史证据**：
来源节点曾混合多个概念，因而无法可靠归属到单一治理后概念的历史记录。歧义历史证据不得自动复制给多个新概念，必须重新裁定或保留不确定标记。
_避免使用_：一拆多证据复制、默认继承掌握状态

**候选知识基座**：
在非活动状态下完成全量节点、领域、关系、知识卡、资源绑定和历史迁移审核的新知识基座。候选知识基座在全图清场前不向正式业务提供部分结果。
_避免使用_：过渡图谱、逐块上线

**知识基座切换**：
候选知识基座全部完成并通过收尾审核后，对正式活动知识基座执行的一次性整体替换。切换不允许新旧知识模型在业务中混合运行。
_避免使用_：渐进替换、双写过渡

**课程知识边界**：
由正式课程能力目标、理解这些目标所需的基础概念，以及具有明确学习目标或正式教学资源的拓展概念共同形成的知识基座发布范围。
_避免使用_：旧图谱全部内容、可能以后使用

**范围锚点**：
候选概念纳入课程知识边界的结构化依据，只允许 `formal_objective`、`necessary_prerequisite` 或 `explicit_extension`。每个候选概念最终至少有一个范围锚点。
_避免使用_：关系端点、历史存在、资源偶然提及

**归档概念**：
不属于课程知识边界但需要保留历史身份和迁移记录的旧知识节点。归档概念不出现在活动图谱中，也不能作为新教学资源的绑定目标。
_避免使用_：待补正式节点、隐藏活动节点

**原子教学资源**：
能够被独立展示、指派、练习或评价的最小资源单元。知识绑定在原子教学资源上维护，确保教学作用和学习证据具有明确概念归属。
_避免使用_：整课默认绑定、文档级证据

**容器知识覆盖**：
作业、讲义、课次或其他资源容器从其原子教学资源绑定自动汇总得到的知识概念集合。容器知识覆盖不是独立人工维护的事实。
_避免使用_：容器手工知识点、双重绑定真源

**概念语义档案**：
规范知识概念的名称、严格定义、语义边界、近邻区分、受控同义词、课程范围依据、领域归属和基础概念裁定。概念语义档案完整后才有资格进入关系审核。
_避免使用_：名称加描述、卡片代替定义

**受控同义词**：
用于检索和历史迁移、但不作为规范语义名称展示的概念别称。受控同义词不能与其他概念的规范名称冲突，也不能无解释地指向多个规范概念。
_避免使用_：自由标签、重复名称入口

**身份审核**：
规范语义名称集合发生变化时执行的名称唯一、近义冲突和概念身份复核。新增、改名和拆分需要身份审核；名称不变的内容和关系维护不触发身份审核。
_避免使用_：所有编辑全量复审、名称变化免审

**知识真相修订**：
记录同一规范知识身份下定义表述、关系或资源绑定变更及其生效时间的不可变事实。知识真相修订用于解释学习事实，不建立并行活动版本。
_避免使用_：无历史原地覆盖、公开双版本

**合并退役**：
旧概念身份因语义并入名称不变的保留概念而停止活动，并通过身份迁移映射保留明确去向。合并退役不等同于独立删除。
_避免使用_：删除重复节点、物理删除

**独立归档**：
规范概念在没有并入其他概念的情况下退出课程知识边界。独立归档改变规范名称集合，需要身份审核和引用影响检查，并永久保留历史身份。
_避免使用_：直接删除、隐藏但可新绑定

**离线知识治理**：
通过仓库内的软件开发变更系列重建和审核知识基座的工作方式。离线知识治理不向教师提供平台化草稿流程，最终合法性由变更系列末端硬闸门保证。
_避免使用_：教师自助建图、平台草稿状态机

**知识作者真源**：
仓库中经过审核的结构化知识数据，是规范概念、领域、关系、课程编排和资源绑定的唯一可编辑事实来源。
_避免使用_：数据库人工真源、runtime 手工数据

**知识运行投影**：
由知识作者真源确定性生成、供应用查询或部署使用的 runtime 和数据库数据。知识运行投影不能独立编辑，也不能反向覆盖作者真源。
_避免使用_：第二真源、回写同步源

**知识数据库投影**：
由知识作者真源整体生成并导入数据库、供正式应用统一查询的知识运行投影。节点图谱、路径、课程编排和资源反查都使用该投影。
_避免使用_：数据库知识真源、文件回退副本

**重复身份裁定**：
对身份候选组作出的合并或确有区别结论。确有区别的概念必须具有不同定义、明确语义边界和能够反映差异的唯一名称。
_避免使用_：相似度自动合并、未决放行

**领域词表**：
具有唯一名称、定义和纳入边界的受控顶级知识领域集合。领域词表保持扁平，概念细分由包含关系表达。
_避免使用_：子领域树、自由领域标签

**视觉化适用性**：
规范知识概念是否具有值得通过结构、过程、比较、路径、图形或高密度总结进行视觉表达的教学价值。视觉化适用性决定是否制作派生视觉知识卡。
_避免使用_：每节点配图、装饰性图片

**确定性资源迁移**：
旧资源已有明确节点 ID、该 ID 可一对一映射到规范知识 ID，且资源类型能够确定绑定角色时执行的无需语义猜测的绑定迁移。
_避免使用_：名称匹配迁移、模型自动绑定

**歧义资源绑定**：
因旧节点拆分、自由文本标注、角色不明或缺少原绑定而无法确定性迁移的资源知识候选。歧义资源绑定必须由代理分块审核后才能进入作者真源。
_避免使用_：默认相关、抽样放行

**知识基座硬闸门**：
候选知识基座上线前必须全部满足且不可通过白名单降级的身份、领域、关系、路径、卡片、资源、迁移、投影和审核合法性条件。
_避免使用_：警告式审核、生产豁免参数
