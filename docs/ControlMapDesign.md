# 控制理论全景交互地图 (Interactive Control Theory Map) - 设计规格说明书

## 1. 项目概述

本项目旨在将经典的“控制理论地图 (The Map of Control Theory)”数字化，构建一个单页面应用 (SPA)。用户可以通过缩放、平移和点击，探索控制工程的宏大体系。页面通过直观的分区（时域/频域、经典/现代）和层级展示，帮助初学者建立完整的知识架构。

## 2. 页面布局与视觉架构 (Visual Architecture)

### 2.1 核心视图：全景拓扑图 (The Canvas)

- **布局逻辑**：采用二维力导向图或预设坐标的SVG地图。
- **背景分区 (Background Zones)**：
  - 地图被背景色块划分为几个主要大陆（与原图色块对应），色块之间平滑过渡。
  - **横轴隐喻**：左侧偏向“经典/单输入单输出(SISO)”，右侧偏向“现代/多输入多输出(MIMO)/智能”。
  - **纵轴隐喻**：上方偏向“系统建模与分析”，下方偏向“具体控制算法与执行”。
  - **特殊维度**：通过UI开关切换“连续时间 (Continuous)”与“离散时间 (Discrete)”视图，或在地图中用虚线区域划分。

### 2.2 导航与HUD (Heads-Up Display)

- **左上角**：全局搜索框（支持搜索“PID”、“卡尔曼”等关键词）。
- **右上角**：视图过滤器。
  - [Toggle] 时域 (Time Domain) / 频域 (Frequency Domain) 高亮。
  - [Toggle] 连续 (Continuous) / 离散 (Discrete) 切换。
- **右侧滑出面板 (Detail Sidebar)**：点击地图节点后触发，展示详细文案。

## 3. 内容架构与文案 (Content & Copywriting)

> **文案风格指南**：通俗易懂，用类比解释数学概念，应用领域贴近生活。

### 区域 A：建模与仿真 (Modeling & Simulation) - 红色/粉色系

*位于地图核心偏上位置，是一切控制的基础。*

#### 1. 物理建模 (Physical Modeling)

- **核心内涵**：把现实世界的物理规律（牛顿定律、基尔霍夫定律）翻译成数学公式。就像给世界写代码。
- **应用领域**：机械臂受力分析、电路设计。
- **关键概念**：`F=ma`, 微分方程。

#### 2. 传递函数 (Transfer Functions)

- **核心内涵**：一个黑盒子，告诉我们“输入信号进去，会变成什么样出来”。主要用于经典控制。
- **应用领域**：滤波器设计、音响均衡器。
- **公式**：$G(s) = Y(s)/U(s)$。

#### 3. 状态空间 (State Space)

- **核心内涵**：用一组内部变量（状态）来描述系统的每一刻。它是现代控制理论的基石，能描述多输入多输出系统。
- **应用领域**：火箭姿态控制、多足机器人。
- **公式**：$\dot{x} = Ax + Bu$。

#### 4. 框图与简化 (Block Diagrams)

- **核心内涵**：控制工程师的通用语言。用方框和箭头画出信号的流向，把复杂的方程图形化。
- **交互逻辑**：点击展示一个典型的反馈回路图。

#### 5. 线性化 (Linearization)

- **核心内涵**：世界是非线性的（复杂的），但我们在一个小范围内把它假装成线性的（简单的）来处理。比如把地球表面近似看作平的。
- **应用领域**：倒立摆平衡点附近的控制。
- **关键概念**：泰勒展开，雅可比矩阵。

### 区域 B：系统分析 (System Analysis) - 绿色系

*位于建模区域右侧，用于判断系统“乖不乖”。*

#### 1. 稳定性 (Stability)

- **核心内涵**：系统受到扰动后，是会恢复平静，还是彻底失控？这是控制系统最重要的属性。
- **通俗解释**：把小球放在碗底（稳定）还是放在倒扣的碗顶（不稳定）。
- **关键判据**：Routh-Hurwitz, 奈奎斯特判据。

#### 2. 可控性 (Controllability)

- **核心内涵**：我们是否能通过操作手柄，让系统到达任何我们想要的状态？如果不可控，怎么努力都没用。
- **应用领域**：卫星变轨（推进器坏了可能就不可控了）。

#### 3. 可观测性 (Observability)

- **核心内涵**：我们能否通过观察输出（传感器读数），推算出系统内部的所有秘密（状态）？
- **应用领域**：电池管理系统（通过电压电流估算剩余电量SOC）。

### 区域 C：经典控制 (Classic Control) - 蓝色/青色系

*地图左下部分，基于频域和传递函数。*

#### 1. PID 控制 (PID Control)

- **核心内涵**：工业界的万金油。
  - **P (比例)**：这就去改，误差大改得多。
  - **I (积分)**：消除积累的误差，确保分毫不差。
  - **D (微分)**：预判趋势，防止刹车过猛。
- **应用领域**：空调温度控制、无人机悬停、汽车巡航。

#### 2. 根轨迹 (Root Locus)

- **核心内涵**：一张藏宝图。展示了当我们调整控制器增益（K值）时，系统的极点（决定稳定性的点）会如何在复平面上移动。
- **目的**：帮助我们找到让系统既快又稳的那个K值。

#### 3. 频域分析 (Bode/Nyquist Plots)

- **核心内涵**：通过给系统“喂”不同频率的正弦波，看它怎么反应。
  - **伯德图 (Bode)**：看对不同频率信号的放大倍数和延迟。
- **应用领域**：降噪耳机、抗震设计。

#### 4. 超前/滞后补偿 (Lead/Lag Compensator)

- **核心内涵**：PID的前身和变体。用来微调系统的响应速度和稳态精度。

### 区域 D：现代与最优控制 (Modern & Optimal) - 深蓝/紫色系

*地图右下部分，基于状态空间。*

#### 1. 极点配置 (Pole Placement)

- **核心内涵**：如果我们有“全能上帝视角”（全状态反馈），我们可以把系统的极点强行挪到任何我们需要的地方，让它随心所欲地表现。
- **前提**：系统必须是可控的。

#### 2. LQR (线性二次型调节器)

- **核心内涵**：精打细算的管家。它在一个数学公式里寻找平衡——既要误差最小（性能好），又要控制能量最少（省油/省电）。
- **应用领域**：自动驾驶汽车的平滑变道。
- **公式**：$J = \int (x^TQx + u^TRu)dt$。

#### 3. 卡尔曼滤波 (Kalman Filter)

- **核心内涵**：最强估算器。它结合了“我的猜测（模型预测）”和“我的眼睛（传感器测量）”，即使由于噪声干扰看不清，也能猜出真实位置。
- **应用领域**：GPS定位、雷达追踪、VR头显姿态解算。

#### 4. MPC (模型预测控制)

- **核心内涵**：像下棋一样，往后多看几步。它利用模型预测未来一段时间的轨迹，然后规划出当前最优的操作。
- **特点**：可以处理限制条件（比如方向盘只能转45度）。
- **应用领域**：化工过程控制、SpaceX火箭回收。

### 区域 E：非线性与智能控制 (Nonlinear & Intelligent) - 黄色/橙色/边缘区域

*处理复杂世界的工具。*

#### 1. 李雅普诺夫稳定性 (Lyapunov Stability)

- **核心内涵**：通过寻找一个“能量函数”，如果系统的总能量一直在减少，那么它最终一定会停下来（稳定）。
- **地位**：非线性系统稳定性的通用证明方法。

#### 2. 滑模控制 (Sliding Mode)

- **核心内涵**：暴力美学。通过高频切换控制量，强迫系统状态沿着一条预设的“滑动面”运动。
- **特点**：极其鲁棒（抗干扰），但会有“抖振”。
- **应用领域**：电机驱动、电力电子变换器。

#### 3. 神经网络与学习控制 (Neural Networks / RL)

- **核心内涵**：不完全依赖物理公式，而是通过大量数据训练，让机器自己学会控制策略。
- **应用领域**：人形机器人行走、复杂的仿生控制。

## 4. 交互逻辑详述 (Interaction Logic)

### 4.1 节点层级 (Node Hierarchy)

- **Level 1 (Continent)**: 大区域（如“线性控制”）。点击时，地图缩放至该区域，显示内部具体节点。
- **Level 2 (Topic)**: 具体节点（如“PID”）。
  - **Hover**: 高亮其前置节点（如“传递函数”）和后置应用（如“无人机”），连线发光。
  - **Click**: 呼出右侧侧边栏。

### 4.2 侧边栏结构 (Sidebar Component)

当用户点击“PID控制”时，侧边栏应包含：

1. **标题与标签**：例如 “PID控制 | 经典控制 | 时域”。
2. **一句话定义**：使用上文“核心内涵”中的文案。
3. **通俗解释**：使用上文“通俗解释”中的文案。
4. **图解/动图**：(开发预留位) 如PID调节水箱水位的示意图。
5. **核心公式**：渲染LaTeX公式。
6. **应用场景**：列举2-3个实际例子。
7. **相关链接**：跳转到“传递函数”或“超前补偿”。

### 4.3 视图切换 (Toggles)

- **连续 vs 离散**：
  - 切换到“离散”时，PID节点的公式从积分变为求和；
  - “状态空间”节点的公式从微分方程 $\dot{x}$ 变为差分方程 $x_{k+1}$。
  - 地图上点亮“Z变换”节点，变暗“拉普拉斯变换”节点。

## 5. 建议技术实施 (Implementation Suggestions)

- **数据结构**: 使用 JSON 树存储上述所有文案，Key 为节点 ID。
- **渲染引擎**: 推荐 `React Flow` 或 `D3.js` 处理拓扑关系。
- **公式渲染**: 使用 `KaTeX`。
- **样式**: Tailwind CSS，使用 Glassmorphism (毛玻璃) 风格以匹配现代科技感。
