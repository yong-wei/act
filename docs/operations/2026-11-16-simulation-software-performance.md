# 仿真软件优化与复测

## 交付版本

0.7.50将私有原始证据的gzip编解码改为异步处理，延迟恢复按需查询分块索引，并以每批四份运行读取初态和检查点。内容哈希、大小限制、原子存储、旧记录读取及返回顺序均经过回归核验。

0.7.50的十路探索负载发生两次结束保存超时。重试先读到进行中状态，原请求随后完成，重复暂存因此被409拒绝。0.7.51按本人运行、分块索引和完整正文哈希复用已提交引用，继续拒绝冲突及异主。原失败的981记录已在生产重新暂存八份原始分块并重试结束保存，原引用、恢复点和回执逐项一致。

当前阿里云应用及worker版本为0.7.51，修订为`32bb1c61ad80bb3fc2edcd82eaa81a4e7f3feac8`，镜像为`localhost/act-obe-platform:0.7.51-32bb1c6`。主机为2 vCPU、约7.83 GB内存。镜像归档831,191,040字节，SHA256为`4b5756bbae7d321f77de51ab31669833354f9afb570cbec0d63e72629e78a1c2`。数据库备份100,750,758字节且恢复列表有效，数据库/Redis容器及Runtime选择器核验通过。[0.7.51发布记录](https://github.com/yong-wei/act/releases/tag/v0.7.51)

## 生产负载与边界

发生器从Mac通过公网调用正常学生登录、本人原始证据、恢复、草稿与报告接口，输入复用每船一份代表首步轨迹。负载为8倍速，每5秒实际时间合并上传最多8份五仿真秒分块，并提交原子恢复点。草稿、恢复与页面请求周期为15、30、60秒，阶段末保存第一步尝试及报告草稿，并核验不完整报告返回400。

使用同一组十个专用PLATFORM来源QA账号，报告为local-only。正式实验空间回传与AI服务商压力调用均为0。0.7.50探索阶段、两次90秒诊断、0.7.51边界及持续阶段保留各自版本和时间窗。0.7.51继续使用已有QA历史，逐阶段记录起始运行与分块数量。前后分时观测包含同一公网来源和同一服务器上的其他负载。
