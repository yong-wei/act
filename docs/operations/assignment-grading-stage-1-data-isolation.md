## 范围与不变量

## 人工基准与敏感数据边界

- 本地离线解析得到 40 个匿名样本、四题分数、派生总分和 120 条非空教师批注；四题满分固定为 `20/20/20/40`，分值采用 0.5 粒度。
- 人工基准 schema 只接受匿名 sample ID、题号、满分、教师分数、受限教师批注和结构化扣分；未知身份字段由严格 schema 拒绝。
- 审查清单仅保存逻辑键、内容校验和、真实文件类型、只读状态和确认状态，不保存源绝对路径。
- 对本地隔离产物执行安全扫描：身份标签或连续长数字命中数为 0，审查清单绝对路径命中数为 0。

## AI 运行前隔离

- 数据集存储新增 `loadEvaluation()`。该入口只读取 manifest、权威量规、资源声明和已脱敏提交，不打开或解析 `baseline.json`。
- 创建划分、冻结配置、冻结视觉实验、启动运行、恢复运行和逐题执行上下文均使用 `loadEvaluation()`。
- manifest 通过 baseline SHA-256 承诺人工基准版本；AI 输入漂移检查无需读取人工分数。
- 报告和 AI—人工比较仍使用完整 `load()`，因此只能在独立 AI 结果持久化后的报告阶段读取人工基准。
- 回归测试物理移除 `baseline.json` 后，AI 评测输入仍可加载；完整报告加载按预期失败。

## G.1 首次独立审核与限定修复

- 审核基线为 `c2c5ffb71cdf54f7010ec15c038d91843b4f4e35`。独立只读审核结论为 `FAIL`；六项 finding 全部裁定为 `ACCEPT`，并进入任务清单允许的一次限定修复。
- `F1`：manifest 的 `scoreBand` 由人工总分派生。现改为固定的非评分来源标签，AI 评测入口不再接收任何人工分数派生信息。
- `F2`：报告、受控视觉对比报告和实验室概览可在独立运行完成前读取 baseline。现要求同配置、同分区的运行已终态持久化；概览只为终态运行加载并投影人工分数。
- `F3`：评分解析可能改写负号，且正式基准未持久化受控总分。现改为单一数值令牌解析，保留 `teacherTotalScore` 并由 schema 验证其等于四题之和。经不泄露正文的布局审计确认，源评分记录没有独立的可用总分字段，因此总分只由已验证的四题分数派生。
- `F4`：教师批注字段可携带身份信息。现对写入前批注实施长度、身份标签和长数字序列筛除；baseline schema 同步拒绝不安全批注内容。被筛除数量只以汇总计数输出。
- `F5`：任意改名的 T2 评测 ZIP 可绕过暂存敏感文件门禁。现按 manifest 声明的任意 Markdown 量规、baseline 和提交目录组合识别评测包，已加入 T2 量规回归。
- `F6`：准备器异常与成功输出会暴露本地路径。现只输出稳定失败阶段、异常类型和逻辑产物名；草稿 JSON 以无 BOM UTF-8 写入，并在归档中显式创建必需目录。
