## 口径

- **已完成**：有实现及相应验证或真实闭环证据。
- **待裁定**：实现或运行已完成，但需要负责人确认或独立复审，不能把它当作验收通过。
- **未完成**：尚缺实际操作、验证或交付证据。
- **失败后重做**：已执行但没有达到预冻结门槛；不等同于“完成”。
