# 阶段 2：评分标准与小题契约

状态：G.2 审核候选，尚未放行。

## 已实现契约

- 评测包导入解析权威题目文件，保留四道大题、参考答案、评分项、分值、评分分组和源文本追溯。
- 每个评分项使用由大题标识派生的稳定 ID；该 ID 贯通题目快照、AI criterion assessment、证据锚点、结构化复核结果及 PDF 批注元数据。
- 首轮评测包必须恰有四题、四题满分合计 100；每题评分项分值合计必须等于该题满分，所有分值使用 0.5 分粒度。
- AI 评分输出逐项携带得分、声明满分、扣分理由、学生可见批注及其区域锚点、局限性状态；声明满分必须和冻结评分项一致。
- 扣分评分项必须有至少一条批注；满分评分项不得凭空产生扣分批注。提示词要求将独立扣分原因分成独立批注。
- 作业级总评使用 `strengths`、`problems`、`suggestions` 三组字段；缺组、凭据样式或评分项、量规、锚点、置信度、模型、Provider、提示词等内部术语都会阻断结果。
- 结构化 PDF 结果校验题目分数之和等于总分、题目满分之和等于总满分，并为每条 PDF 批注保留稳定评分项 ID。
