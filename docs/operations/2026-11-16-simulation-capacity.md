## 持续实验负载

测试于2026年11月16日执行。HTTP发生器从Mac通过公网访问部署站点。每船只使用一份由实际原生会话生成的第一步轨迹，复用正式上传逻辑生成请求。055、集装箱、邮轮和雪龙的轨迹为60仿真秒，LNG、981和天鲸为120仿真秒。

负载采用页面支持的8倍速。每5秒实际时间合并最多8份、各5仿真秒的采样分块，并提交一次原子恢复点。每15秒保存草稿，每30秒恢复状态，每60秒请求一次页面。末尾集中提交已完成的第一步尝试、保存六部分报告草稿，并核验未完成报告被400拒绝。每次恢复核对同一运行、原始恢复点字符串及三类样本计数。

准备了210个独立的PLATFORM来源QA账号，发生器实际使用其中前10个。浏览器和网络验收使用另外的专用账号。所有测试走正常学生登录和本人证据接口，报告使用local-only模式。本轮压力请求中的正式实验空间回传和AI提供商调用均为0。批量ILAB来源身份、控灵提供商并发及外部成绩回传的容量尚未测量。

## 复现与证据

复现工具位于 `scripts/simulations/generate-load-fixtures.mts`、`scripts/simulations/http-load.mjs` 和 `scripts/simulations/cold-entry-load.mjs`。第一步夹具由真实原生会话生成，私有身份文件采用 `identities` 数组，每项包含专用测试账号的 `id`、`loginId` 和 `password`。资源清单包含 `origin` 及 `byCourse`，每船对应实际浏览器观测到的公开静态URL。

```bash
rtk npx tsx scripts/simulations/generate-load-fixtures.mts
rtk npx tsx scripts/simulations/http-load.mjs --origin https://act.adapt-learn.online --identities .tmp/load-identities-production.json --fixtures .tmp/load-fixtures --concurrency 2 --seconds 1800 --time-scale 8 --label capacity-repeat --revision c378178ad79495b777469e0e766f0808cead4063 --runtime-version cf146e828b1fab7e146132d95b42ad99f7e331340b478991aabbf620d9a7ec3d
rtk proxy node scripts/simulations/cold-entry-load.mjs --manifest docs/operations/2026-11-16-simulation-capacity.json --concurrency 7 --label cold-repeat
rtk proxy node scripts/simulations/cold-entry-load.mjs --manifest docs/operations/2026-11-16-simulation-capacity.json --concurrency 7 --fallback --label fallback-repeat
```

测试身份、原始请求日志、采样载荷、恢复点及私有CAS索引位于忽略目录。公开机器结果只保留部署身份、聚合计数、延迟、流量与去标识后的资源统计。正式实验空间仅有此前一份明确标注0分的邮轮联调成绩及HTML附件成功回传证据，七船完整正式报告、批量控灵及外部回传容量继续保留待验状态。

测试结束后，已按专用账号归属清理210个QA账号、664条运行、15份报告及17个本地实验轮次。12018份私有CAS对象经原始归属、哈希和其他记录引用检查后清理，共1,532,178,989字节，无缺失或共享引用。原始测试凭据及私有CAS索引随后从本机移除。

公开[机器结果](2026-11-16-simulation-capacity.json)同时包含本版静态资源清单，可直接传给资源重放工具。三份复现工具的ESLint通过，发布工具入口重新生成七份真实首步轨迹，正常生产HTTP复验73次请求的错误及状态失败为0，完成4次055运行。该短验收保留1.5秒延迟目标未达状态，其结果独立于30分钟容量阶段。
