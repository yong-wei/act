# 自动控制原理互动课程设计方案

## 1. 设计概述 (Design Overview)

本方案旨在将抽象的自动控制原理概念转化为可视化、可操作的互动体验。核心设计理念如下：
*   **探索式学习 (Exploratory Learning):** 鼓励用户通过“试错”和“观察”来理解理论，而非单纯的记忆。
*   **即时反馈 (Immediate Feedback):** 所有的操作（拖动、点击、参数修改）都应在毫秒级内反映在图表或动画上。
*   **游戏化体验 (Gamification):** 引入关卡、评分、计时和挑战模式，提升学习的趣味性和用户的粘性。
*   **科学严谨性 (Scientific Accuracy):** 底层基于真实的控制理论算法（如 Python `control` 库或 JS 等效库）进行实时计算，而非预设动画。

## 2. 核心模块详细设计 (Core Modules Detailed Design)

### 模块 1: 方框图化简大作战 (Block Diagram Reduction)
*   **互动方式:** 
    *   **手势操作:** 用户通过鼠标划线或手指拖拽将两个方框“框选”在一起。
    *   **模式选择:** 选中后弹出悬浮菜单，提供“串联”、“并联”、“反馈”三个图标供选择。
    *   **自动吸附:** 选择正确后，方框带有动画效果地合并为一个新方框，内部显示更新后的传递函数 $G(s)$。
    *   **错误惩罚:** 若选择错误的化简规则（例如将反馈误判为并联），方框会震动并弹出提示，扣除“生命值”。
*   **视觉表现:** 动态连线，合并时有粒子聚合特效。
*   **可玩性:** 设置“最少步数”挑战，鼓励用户寻找最优的化简路径。

### 模块 2: 信号流图构建器 (Signal Flow Graph Builder)
*   **互动方式:** 
    *   **拖拽连线:** 类似思维导图软件，点击节点拖出箭头至另一节点，输入增益（支持代数符号如 $a, b, G1$）。
    *   **自动整理:** 提供“一键美化”按钮，利用力导向算法（Force-directed graph）自动排布节点，减少交叉。
    *   **校验模式:** 用户完成绘制后点击“提交”，系统高亮显示错误或遗漏的路径。
*   **扩展功能:** “方框图 -> 信号流图”转换挑战，左侧显示方框图，要求右侧绘制对应的流图。

### 模块 3: 梅森公式寻宝 (Mason's Rule Treasure Hunt)
*   **互动方式:** 
    *   **路径点亮:** 系统给出一个复杂的信号流图。任务栏提示“寻找第1条前向通道”，用户需按顺序点击节点点亮路径。
    *   **回路识别:** 任务提示“寻找所有不接触回路”，用户点击回路中的所有边进行高亮确认。
    *   **公式拼图:** 底部提供分子、分母的各项组件（如 $1-\Delta$, $P_1\Delta_1$），用户将其拖拽到公式槽位中完成最终计算。
*   **视觉表现:** 正确识别的回路会持续发光，不同回路使用不同颜色区分。

### 模块 4: 谁是时域预言家 (Time Domain Estimator)
*   **互动方式:** 
    *   **盲测模式:** 屏幕只显示一个动态的单位阶跃响应曲线（无坐标轴数值），用户需凭直觉调整滑块估计 $\xi$ (阻尼比) 和 $\omega_n$ (自然频率)。
    *   **拟合挑战:** 系统给出目标曲线，用户调整参数，实时的曲线与目标曲线重合度越高，得分越高。
*   **可玩性:** 设置排行榜，看谁的参数估计误差最小。

### 模块 5: 典型信号实验室 (Typical Signal Laboratory)
*   **互动方式:** 
    *   **信号发生器:** 左侧为输入面板，可选阶跃、斜坡、抛物线、脉冲、正弦信号，支持手绘任意波形作为输入。
    *   **系统黑箱:** 中间为系统配置区，可快速切换 0型/I型/II型 系统，或 1阶/2阶 系统。
    *   **实时示波器:** 右侧实时显示 $r(t)$ 和 $c(t)$ 的对比。支持暂停、缩放、游标测量。
*   **特色:** “手绘输入”功能，用户画出一个爱心形状的输入，观察惯性环节输出的“变形爱心”。

### 模块 6: 稳态误差极速挑战 (Steady State Error Speed Run)
*   **互动方式:** 
    *   **卡牌模式:** 屏幕飞出“系统传递函数卡片”和“输入信号卡片”。
    *   **快速决策:** 底部有三个判定区：$e_{ss}=0$, $e_{ss}=C$ (常数), $e_{ss}=\infty$。用户需在倒计时内将卡片组合拖入正确区域。
*   **难度进阶:** 随着关卡提升，传递函数不再直接给出型别，需要用户心算积分环节个数。

### 模块 7: 极点操纵器 (Pole Manipulator / S-Plane Interactive)
*   **互动方式:** 
    *   **双视窗联动:** 左侧为复平面（S-Plane），右侧为时域响应图。
    *   **直接拖拽:** 用户用鼠标拖动复平面上的极点 $\times$。
        *   拖动实部：观察右侧响应衰减速度的变化。
        *   拖动虚部：观察右侧振荡频率的变化。
    *   **共轭锁定:** 拖动复数极点时，共轭极点自动对称移动。
    *   **网格与锁定:** 展示等阻尼/等频率极坐标网格，支持锁定实部、虚部、阻尼比与自然频率。
*   **教学点:** 实时展示 $\sigma$ 线（等衰减）和 $\beta$ 线（等阻尼）的含义。
*   **挑战模式:** 右侧叠加三条阶跃响应曲线，左侧拖拽三组同色极点完成匹配，提交后显示正确极点位置与得分。

### 模块 8: 根轨迹绘制向导 (Root Locus Step-by-Step)
*   **互动方式:** 
    *   **分步引导:** 
        1.  **定点:** 点击复平面标出开环极点和零点。
        2.  **实轴轨迹:** 点击实轴上的线段，确认哪些属于根轨迹。
        3.  **渐近线:** 拖动虚线确定渐近线的交点和角度。
        4.  **分离点:** 在实轴上滑动滑块寻找分离点（重根点）。
    *   **描绘:** 最后用户用画笔勾勒大致形状，系统生成标准轨迹进行对比打分。

### 模块 9: 根轨迹靶场 (Root Locus Target Practice)
*   **互动方式:** 
    *   **任务目标:** “调整增益 $K$，使得系统超调量 $\sigma\% < 20\%$”。
    *   **可视化操作:** 根轨迹上会显示满足 $\zeta$ 要求的扇形区域（靶区）。用户拖动轨迹上的闭环极点，使其落入靶区。
    *   **动态反馈:** 拖动过程中，实时显示当前的阶跃响应小窗口，直观看到性能指标变化。

### 模块 10: 伯德图逆向工程 (Bode Plot Reverse Engineering)
*   **互动方式:** 
    *   **积木拼接:** 屏幕是一张空的对数坐标纸。用户从工具箱拖入“积木”：比例环节 $K$（上下平移）、积分环节 $1/s$（-20dB/dec 斜率）、惯性环节 $1/(Ts+1)$（转折频率）。
    *   **曲线合成:** 每拖入一个环节，总曲线自动叠加变化。目标是拼凑出与背景阴影一致的目标伯德图。
*   **直观理解:** 深刻理解每个典型环节对幅频和相频特性的贡献。

### 模块 11: 奈奎斯特稳定性裁判 (Nyquist Stability Referee)
*   **互动方式:** 
    *   **围圈游戏:** 给定开环传函的奈奎斯特曲线。
    *   **判定交互:** 用户需要拖动探测点沿着曲线走一圈（或自动播放），同时观察并在计数器上按“+1”或“-1”来统计绕 $(-1, j0)$ 点的圈数 $N$。
    *   **最终判决:** 输入 $P$ 值（右半平面极点数），根据 $Z=N+P$ 判定系统是否稳定。如果判断正确，系统会盖上“STABLE”或“UNSTABLE”的印章。

### 模块 12: 频域整形大师 (Loop Shaping Master)
*   **互动方式:** 
    *   **所见即所得:** 允许用户直接用鼠标“捏”伯德图的幅值曲线（例如在中频段向上提拉）。
    *   **自动补偿:** 系统根据用户的形变，自动推荐需串联的超前/滞后校正装置参数。
    *   **对比:** 同时也显示校正前后的相角裕度（PM）和幅值裕度（GM）变化。

## 3. 拓展与进阶模块建议 (Extended & Advanced Modules)

为了完善课程体系，建议增加以下模块：

### 模块 13: 物理建模工坊 (Physical Modeling Workshop) - **[新增]**
*   **目的:** 解决学生“只懂公式不懂物理对象”的问题。
*   **互动:** 提供弹簧、阻尼器、质量块、电阻、电容、电感等元件。用户像搭积木一样组装机械系统或电路系统。
*   **反馈:** 系统自动生成对应的微分方程和传递函数，并演示物理运动动画。

### 模块 14: PID 调参挑战赛 (PID Tuning Challenge) - **[新增]**
*   **目的:** 训练对 P、I、D 三个参数物理意义的直觉。
*   **场景:** 
    *   **入门:** 控制水箱水位。
    *   **进阶:** 无人机悬停（抗风扰动）。
    *   **困难:** 倒立摆平衡。
*   **操作:** 提供三个旋钮 ($K_p, K_i, K_d$)。用户需在系统失稳前快速调整参数达到平衡。提供“一键整定（Ziegler-Nichols）”演示作为教学对比。

### 模块 15: 状态空间相轨迹画廊 (State Space Phase Portrait Gallery) - **[新增]**
*   **目的:** 引入现代控制理论视角，理解非线性与初始条件。
*   **互动:** 
    *   **发射点:** 在相平面（$x$ vs $\dot{x}$）上任意点击作为初始状态。
    *   **轨迹流:** 生成从此状态出发的系统轨迹。
    *   **极限环:** 展示非线性系统（如范德波尔振荡器）的极限环现象。

### 模块 16: 数字控制采样室 (Digital Control Sampling Room) - **[新增]**
*   **目的:** 理解采样定理和离散化影响。
*   **互动:** 
    *   **采样率调节:** 用户调节采样开关的频率 $T$。
    *   **混叠演示:** 实时展示连续信号与采样后恢复信号的差异，直观呈现混叠现象（Aliasing）。
    *   **Z平面稳定性:** 在单位圆内拖动极点，观察离散系统的响应收敛性。

## 4. 技术可行性与实现建议 (Technical Feasibility)

*   **前端框架:** 建议使用 **React** 或 **Vue 3** 构建组件化界面。
*   **图形渲染:** 
    *   **Canvas/SVG:** 使用 **d3.js** 或 **Konva.js** 绘制方框图、信号流图和曲线。
    *   **高性能绘图:** 对于实时刷新的波形（示波器），建议使用 **Canvas API** 或 **WebGl**。
*   **数学引擎 (核心难点):** 
    *   浏览器端不仅需要绘图，还需要进行多项式运算、求根、频率响应计算。
    *   **方案 A (推荐):** 使用 JavaScript 数学库，如 **math.js** 配合自定义的控制理论算法封装（实现 `poly`, `roots`, `freqs` 等基础函数）。
    *   **方案 B:** 通过 **WebAssembly (WASM)** 调用 Python 的 `scipy` 或 `python-control` 库（如使用 **Pyodide**），可直接复用成熟的科学计算代码，但需注意加载体积。
*   **数据结构:** 
    *   方框图和信号流图应采用 **有向图 (Directed Graph)** 数据结构存储，便于进行拓扑排序和算法分析（如梅森公式的路径搜索）。

## 5. 总结

本设计方案通过 16 个高度互动的模块，覆盖了从经典控制到现代控制、从建模到分析再到校正的全过程。重点在于将枯燥的数学运算转化为可视化的图形操作，并通过游戏化的机制激发学生的探索欲，完全符合“具备高度互动与可玩性，同时保证科学性”的目标。
