# Lesson 02: 机械的心跳——基于机理的微分方程建模

**BOPPPS 教学流程设计说明书**

## 1. 总体信息 (Meta Info)

- **课程 ID**: `lesson-02-differential-equations`
- **时长**: 90 分钟
- **教学目标 (Objectives)**:
  1. 能识别机械系统中的惯性、阻尼、弹性元件，并列写微分方程。
  2. 能识别电路系统中的 R、L、C 元件，利用 KVL 列写方程。
  3. 能阐述机电系统的相似性，并统一为二阶微分方程标准式。
- **核心场景**: 052D 驱逐舰电液伺服舵机拆解。

------

## 2. BOPPPS 教学流程详解

### 🟢 1. 导入 (Bridge-in) | 5 mins

**主题：看不见的“骨架”**

- **页面设计**:
  - **背景**: 全屏 3D 场景，一艘驱逐舰在 5 级海况下剧烈摇摆。
  - **前景**: 一个半透明的 HUD 面板，显示“航向误差: 15° (异常)”。
  - **动作**: 教师点击“透视”按钮，船体外壳虚化，高亮尾部的**舵机系统**。
- **引用资源**:
  - `scene-destroyer-rough-sea` (3D 场景)
  - `concept-modeling-intro` (引导话术)
- **AI 行为 (Agent)**:
  - 角色: **系统分析师**。
  - 台词: “指挥官，航向不稳不仅是因为浪大，更是因为控制器不懂舵机的‘脾气’（物理特性）。我们需要为舵机建立数学档案。”

### 🔵 2. 学习目标 (Objective) | 2 mins

**主题：本次任务清单**

- **页面设计**:
  - **布局**: 简洁的清单视图 (Checklist)，背景是蓝图风格。
  - **内容**: 三个待解锁的勋章图标（机械建模师、电路分析员、系统架构师）。
- **引用资源**:
  - `list-objectives-02` (文本资源)

### 🟡 3. 前测 (Pre-assessment) | 8 mins

**主题：装备点检**

- **页面设计**:
  - **交互**: **连线题**。左侧是物理元件图标（弹簧、质量块、电感、电容），右侧是物理定律（牛顿第二定律、胡克定律、法拉第电磁感应）。
  - **反馈**: 连对一条线，发出机械咬合的音效；连错弹出红色提示。
- **引用资源**:
  - `quiz-physics-basics` (测验题库)
- **AI 行为**:
  - 角色: **考官**。
  - 逻辑: 如果学生在“电感 vs 电容”上出错，AI 会在后续电路建模环节自动降低难度（开启辅助提示）。

### 🔴 4. 参与式学习 (Participatory Learning) | 60 mins

#### 4.1 环节一：机械建模工坊 (25 mins)

- **页面设计**: **Physics Builder (Mechanical Mode)**
  - **布局**: 左侧组件库 (Mass, Spring, Damper, Force)，右侧画布，底部公式栏。
  - **交互**:
    1. **拖拽**: 学生拖入滑块代表舵叶。底部显示 $m\ddot{x}=F$。
    2. **连接**: 拖入阻尼器连接滑块与墙壁。底部方程增加 $+f\dot{x}$。
    3. **受力**: 拖入向右的箭头 $F(t)$。
  - **动态演示**: 学生调整 $f$ 值，点击“运行”，滑块受到撞击后的振荡衰减速度发生变化。
- **引用资源**:
  - `widget-physics-builder` (核心组件)
  - `concept-newton-law-application` (侧边栏知识卡片：解释各项物理意义)

#### 4.2 环节二：电路建模工坊 (20 mins)

- **页面设计**: **Physics Builder (Electrical Mode)**
  - **布局**: 类似机械版，但元件换成 R, L, C, E。
  - **交互**:
    1. 搭建 R-L-C 串联回路。
    2. 点击“生成回路方程”，系统展示 KVL 路径动画，并生成 $L\frac{di}{dt} + Ri + \frac{1}{C}\int i dt = u(t)$。
    3. **变换**: 点击“电荷 $q$ 视角”，方程自动重写为关于电荷 $q$ 的二阶微分方程。
- **引用资源**:
  - `widget-circuit-builder` (组件)
  - `concept-kirchhoff-law` (知识卡片)

#### 4.3 环节三：机电相似性映射 (15 mins)

- **页面设计**: **Analogy Mapper (映射台)**
  - **布局**: 分屏。左边是机械方程，右边是电路方程。
  - **交互**:
    1. 学生将左边的 $m$ 拖到右边的 $L$ 上。
    2. 将 $f$ 拖到 $R$ 上。
    3. 将 $k$ 拖到 $1/C$ 上。
  - **效果**: 匹配成功后，两个方程合并为一个通用的二阶微分方程模板 $A\ddot{y} + B\dot{y} + Cy = u$。
- **引用资源**:
  - `widget-analogy-mapper` (组件)

### 🟣 5. 后测 (Post-assessment) | 10 mins

**主题：实战挑战——导弹发射架**

- **页面设计**: **Equation Editor (智能公式板)**
  - **场景**: 展示一个竖立的导弹发射架（倒立摆模型的一部分）。
  - **挑战**: “除了惯性、阻尼、弹性，还有一个力在阻碍它起竖，是什么？”（重力）。
  - **交互**: 学生在输入框中输入方程。支持 LaTeX 快捷键。
- **引用资源**:
  - `quiz-missile-modeling` (高阶应用题)
- **AI 行为**:
  - 角色: **总工 (Reviewer)**。
  - 逻辑: 检查学生是否包含了重力矩项 $mgl\sin\theta$。如果漏了，提示“地球引力去哪了？”；如果写了 $\sin\theta$，提示“如何线性化？”

### ⚪ 6. 总结 (Summary) | 5 mins

**主题：万物皆数**

- **页面设计**: **Knowledge Graph (知识星空)**
  - **效果**: “微分方程”节点点亮，向外发射光线，连接到后续的“传递函数”和“状态空间”节点。
  - **交互**: 点击节点，弹出今日核心公式卡片（便于截图复习）。
- **引用资源**:
  - `concept-summary-lesson03`

## 4. 交互实现规格 (For AI Developers)

请根据以下逻辑编写组件代码。

### 4.1 通用组件：`PhysicsBuilder`

- **路径**: `components/widgets/PhysicsBuilder.tsx`

- **Props**:

  TypeScript

  ```
  interface PhysicsBuilderProps {
    mode: 'mechanical' | 'electrical';
    initialItems?: string[]; // 侧边栏可用的元件ID列表
    onEquationChange?: (latex: string) => void; // 回调生成的方程
  }
  ```

- **状态逻辑 (Zustand)**:

  - 维护一个 `Graph` 结构：`nodes` (元件) 和 `edges` (连接)。
  - **核心算法**: `generateEquation(graph)`
    - **Mechanical**: 遍历所有连接到 Mass 节点的边。如果边是 Spring，添加 $+kx$；如果是 Damper，添加 $+f\dot{x}$。
    - **Electrical**: 遍历回路 (Loop Detection)。遇到 Inductor 添加 $+L\frac{di}{dt}$，以此类推。

### 4.2 专用组件：`AnalogyMapper`

- **路径**: `components/widgets/AnalogyMapper.tsx`
- **交互逻辑**:
  - 使用 `framer-motion` 实现拖拽。
  - 定义 `MappingPair[]` 状态。
  - **验证逻辑**: 当用户把 $m$ 拖到 $L$ 上时，检查 `type` 是否匹配（都是 Inertia/Storage 元件）。如果匹配，触发 `Confetti` 粒子特效。

### 4.4 AI 批改接口 (API Route)

- **路径**: `app/api/check-modeling/route.ts`

- **功能**: 接收学生输入的 LaTeX 或文本，判断是否包含关键项（如重力矩）。

- **Prompt**:

  > "Target Equation: $J\ddot{\theta} + f\dot{\theta} + K\theta - mgl\sin\theta = T$. Student Input: {input}. Check if the student included the gravity term ($mgl$). If not, explain that gravity creates a restoring torque."
