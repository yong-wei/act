# 课程知识节点提取协议 v1

你正在从自动控制原理权威教材中提取规范知识节点候选。该任务只建立候选节点，不生成关系、知识卡、资源绑定或学习事实。

## 固定准则

一个候选节点必须能够被独立定义，并且值得被独立教学、理解或考核。以下内容不能单独成为节点：

- 仅用于排版或导航的章节标题；
- 不能脱离上位概念解释的公式片段、符号、属性或注释；
- 只服务于某次推导的中间步骤；
- 只出现一次且没有一般教学意义的例题对象；
- 教材对同一概念使用的同义名称或中英文名称。

多份教材描述同一概念时，应当输出一个候选节点，并保留各来源证据。只有当两个术语具有不同定义、适用条件、输入输出或教学目标时，才允许拆成不同候选节点。

候选节点名称优先采用中文自动控制课程中的通行术语；英文教材名称进入 aliases。定义必须陈述概念本身，semantic_boundary 必须说明它包含什么、排除什么以及最容易与哪个近邻概念混淆。

只能依据提供的权威上下文包作答，不得使用旧知识图谱、运行态数据或未提供的外部资料补足结论。引用证据必须逐字来自上下文包，并标明 source_id。

## 输出合同

只输出一个 JSON 对象，不要输出 Markdown 或解释文字：

```json
{
  "pack_id": "与上下文包一致",
  "candidates": [
    {
      "canonical_name": "中文规范候选名称",
      "aliases": ["同义词或英文名称"],
      "definition": "独立、严格且不循环的定义",
      "semantic_boundary": "包含范围、排除范围和近邻区别",
      "independent_teaching_reason": "为何值得成为独立教学或考核节点",
      "source_evidence": [
        {
          "source_id": "上下文中的来源 ID",
          "quote": "支持该节点的最短原文证据"
        }
      ],
      "confidence": "high | medium | low"
    }
  ],
  "rejected_items": [
    {
      "label": "未入选的术语",
      "reason": "formula_fragment | example_only | synonym | attribute | navigation | insufficient_evidence"
    }
  ]
}
```

此文件是缓存前缀的一部分。除非提取协议发生版本升级，否则不得调整措辞、空白或字段顺序。
