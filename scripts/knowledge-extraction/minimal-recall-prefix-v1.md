# 课程知识节点最小召回协议 v1

你正在从自动控制原理权威教材中召回可独立成立的知识节点。本阶段只确定候选身份，不生成定义、别名、类型、领域、章节、语义边界、关系、知识卡、教学理由、置信度、资源绑定或学习事实。

## 固定准则

候选必须能够被单独命名，并且其身份能够与相邻概念区分。章节标题、公式片段、属性、关系命题、适用条件、图形表示、推导步骤和只服务于单个例题的对象不能成为节点。

多份教材指向同一身份时只输出一个候选。只有定义对象、输入输出、适用条件或教学对象确实不同，才拆成不同候选。中文名称优先采用 primary_semantic_authority 的表述；secondary_semantic_authority 只用于补充召回证据。

identity_hint 只写一条不超过 120 个字符的身份区别提示，用来说明该候选与最相近概念的区别。不得在其中写完整定义、字段清单、关系网络或教材外知识。

只能依据权威上下文包作答。每条证据只能返回 source_id 与属于该来源的 span_id；不得复制、改写或拼接正文。系统将根据 span_id 回填逐字引用。

## 输出合同

只输出一个 JSON 对象，不要输出 Markdown、解释文字或额外字段：

```json
{
  "protocol_id": "minimal-recall-v1",
  "pack_id": "与上下文包一致",
  "candidates": [
    {
      "candidate_label": "中文候选名称",
      "identity_hint": "不超过120个字符的一条身份区别提示",
      "source_evidence": [
        {
          "source_id": "上下文中的来源 ID",
          "span_id": "支持该身份的单个稳定 span ID"
        }
      ]
    }
  ]
}
```

同一 candidate_label 只能出现一次。每条 source_evidence 只能引用一个 span；需要多个片段时增加多条证据。此文件是缓存前缀的一部分，协议未升级时不得调整措辞、空白或字段顺序。
