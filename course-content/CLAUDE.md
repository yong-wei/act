# 项目说明：自动控制原理课程重构

## 项目目的

本项目为"自动控制原理"课程（约70学时，4.5学分）从零创作完整教学内容包。课程采用5模块+复习的新单元体系，依托 AI-OBE 船舶智控平台，以"先见森林，再见树木"为核心设计原则。

> **教学大纲 v4.0 设计文档**位于 `syllabus-refactor/`，以 `main.md` 为入口，`blueprint.md` 为总蓝图，`decisions.md` 为设计决策记录，`module-skeletons.md` 为模块骨架。单元级设计细节按模块拆分至 `unit-design-details/module1~5.md`。

## 工作原则

### 内容创作原则

1. **讲义优先**：学生版讲义是面向学生的唯一权威来源，自成体系，不引用平台操作或课堂活动。讲义引入默认从典型问题或任务开始，不先做大段上一课回顾或课程链条说明
2. **衍生顺序**：讲义 → 教案（BOPPPS，课堂后台控制文稿）→ 互动课程设计（课堂前台页面文稿）→ 媒体清单
3. **单元设计主线**：每个单元以"核心问题 → 前置缺口 → 能力产出 → 锚点案例 → 关键证据 → 练习闭环 → 边界情况"为主线
4. **AI融入点设计**：递进式人机协同（预测→AI对比→AI绘图验证→反思），不是简单"问AI"。模块5有统一的四步AI动作链：学生独立判断 → AI结构化比较 → 学生修订 → 教师收束
5. **设计文档分层**：
   - `syllabus-refactor/` 为教学大纲真源，记录蓝图、决策、模块骨架与单元边界
   - `authoring/lessons/{module}-{unit}/design/` 为各单元的四类产物（讲义/教案/互动页面/媒体）
   - 若入口页与分文件冲突，以模块分文件为准；若分文件与蓝图冲突，以 `decisions.md` 和 `blueprint.md` 为准

### 多媒体制作原则

媒体资源按**用途**（讲义 `h` / 互动课 `ic` / 共用 `sh`）和**生成方式**分类：

| 生成方式 | 判断标准 | 产出 |
|----------|----------|------|
| 代码直出图 | 响应曲线、根轨迹、Bode图、框图、信号流图等可矢量化图形 | 内容描述 + Python 示例代码 |
| 位图（AI生成） | 原理示意图、工程场景图、实物图 | 场景描述 + 英文生图提示词 |
| 互动前端绘制 | 互动课中需随参数动态变化的图表 | 前端绘制需求描述（无媒体文件） |
| 视频 | 仅互动课，动态演示 | Sora 提示词 |

**文件命名**：`{用途前缀}-{两位序号}-{简短描述}.{ext}`，例如 `h-01-step-response-family.py`

**文件存储**：`.py` 源文件和 AI 原始图 → `media/raw/`；产出 SVG/PNG、压缩后版本 → `media/processed/`

**引用回写**：Step 7 完成后，将 `![图注](../media/processed/{文件名})` 插入 handout.md 和 interactive-page.md 对应位置。

### 技能使用原则

- 课程创作技能：`.claude/skills/lesson/SKILL.md`（当前生效，v2.1）
- 技能以批判性教学专家身份参与，不全盘接受设计方案，主动指出认知负担和逻辑问题

### 笔记更新原则

- 每次会话结束前更新 `notes/progress.md`（当前进度、下次续接点）
- 重要设计决策追加到 `notes/discussion-log.md`

## 单元编号体系（v4.0 — syllabus-refactor）

课程按 **5 模块 + 复习** 组织，共约 70 学时。单元编号格式为 `{模块号}-{单元序号}`。

### 模块总览

| 模块 | 单元 | 学时 | 主线 |
|:---:|------|:----:|------|
| 模块1 反馈与建模 | 1-1, 1-2, 1-3, 1-4, 1-5 | ~10h | 从"反馈"核心思想出发，建立系统建模与结构简化能力 |
| 模块2 系统分析 | 2-1, 2-2, 2-3, 2-4 | ~8h | 在模块1建模基础上展开时域分析、稳定性与稳态误差 |
| 模块3 三域打通 | 3-1, 3-2, 3-3, 3-4, 3-5, 3-6, 3-7, 3-8, 3-9 | ~18h | 时域/频域/根轨迹三域融通，形成多角度分析能力 |
| 模块4 设计与校正 | 4-1, 4-2, 4-3, 4-4, 4-5, 4-6, 4-7 | ~14h | 基于三域工具展开串联校正、反馈校正与工程设计 |
| 模块5 知识边界与方法迁移 | 5-1, 5-2, 5-3, 5-4, 5-5, 5-6 | ~12h | 识别线性主干边界，引入非线性、MASS链路、数据驱动到策略学习的连续迁移链 |
| 复习与考核 | R1, R2, R3 + 中测/期末 | ~8h | 阶段复习与综合考核 |

### 模块详细单元

#### 模块1 — 反馈与建模

| 单元 | 课型 | 核心内容 |
|------|:----:|----------|
| 1-1 | 理论 | 反馈控制的核心思想：开环/闭环、扰动抑制、灵敏度 |
| 1-2 | 理论 | 微分方程与传递函数：从物理系统到数学模型 |
| 1-3 | 理论 | 方框图与信号流图：控制系统结构与拓扑 |
| 1-4 | 理论 | 梅森公式：系统传递函数的统一求解 |
| 1-5 | 实践 | 系统建模综合：从真实对象到模型的全流程练习 |

#### 模块2 — 系统分析

| 单元 | 课型 | 核心内容 |
|------|:----:|----------|
| 2-1 | 理论 | 性能指标：控制效果的评价语言 |
| 2-2 | 理论 | 欠阻尼二阶系统：衰减振荡的工程解读 |
| 2-3 | 理论 | 稳定性：控制系统首要任务（Routh判据） |
| 2-4 | 理论 | 稳态误差：准确性的度量 |

#### 模块3 — 三域打通

| 单元 | 课型 | 核心内容 |
|------|:----:|----------|
| 3-1 | 理论 | 根轨迹法：放眼大局的图形化思维 |
| 3-2 | 理论 | 根轨迹基本形态与绘制规则 |
| 3-3 | 理论 | 根轨迹细节修正与参数根轨迹 |
| 3-4 | 理论 | 根轨迹分析综合：从图形到设计判断 |
| 3-5 | 理论 | 频率特性：换个角度看控制 |
| 3-6 | 理论 | 近似叠加绘制Bode图 |
| 3-7 | 理论 | 幅相特性（Nyquist图）：换个角度看频域 |
| 3-8 | 理论 | 稳定判据：频域的启示（Nyquist稳定判据） |
| 3-9 | 理论 | 稳定裕度：宽备窄用的工程智慧 |

#### 模块4 — 设计与校正

| 单元 | 课型 | 核心内容 |
|------|:----:|----------|
| 4-1 | 理论 | 三频段概念：各司其职的频率设计观 |
| 4-2 | 理论 | 串联超前校正 |
| 4-3 | 理论 | 串联滞后校正 |
| 4-4 | 理论 | 滞后-超前校正与PID |
| 4-5 | 理论 | 反馈校正 |
| 4-6 | 理论 | 离散控制系统基础 |
| 4-7 | 实践 | 校正设计综合：同题多方法比较与工程设计闭环 |

#### 模块5 — 知识边界与方法迁移

> 模块5不按"前沿专题并列"组织，而是按**连续迁移链**组织：
> 识别线性主干边界 → 非线性最小分析入口 → 复杂系统链路视角 → 数据驱动迁移 → 策略学习迁移 → 方法比较收束

| 单元 | 课型 | 核心内容 |
|------|:----:|----------|
| 5-1 | 理论 | 线性主干的边界：饱和、死区、滞回、切换与模型失配 |
| 5-2 | 理论 | 非线性系统的最小分析入口：局部线性化、相平面与描述函数 |
| 5-3 | 理论 | 从单回路到复杂自主系统链路：MASS感知—估计—规划—控制协同 |
| 5-4 | 理论 | 从模型驱动到数据驱动：MPC再定位与数据代价 |
| 5-5 | 理论 | 从显式控制器到策略学习：强化学习的进入条件、收益与风险 |
| 5-6 | 实践 | 方法迁移与前沿比较：经典控制/数据驱动/策略学习的同题判断 |

### 创作前必读

在进行任何单元创作前，必须按以下顺序阅读：
1. `blueprint.md` — 确认该单元在总蓝图中的位置
2. `module-skeletons.md` — 确认模块骨架与前驱依赖
3. `unit-design-details/module{N}.md` — 确认单元的边界、核心问题与能力产出
4. `decisions.md` — 确认是否有相关设计决策约束
