## 说明

- 本讲真正训练的是“读图并做工程判断”，而不只是“会调用 `rlocus` 命令”。
- 课件中反复出现 4 个动作：
  - 先把闭环特征方程化为根轨迹标准形式；
  - 再从根轨迹图读稳定性与稳定区间；
  - 必要时把根轨迹增益换回原控制器增益；
  - 再结合主导极点与时域响应判断性能。
- 例 3 与例 4 共同说明：
  - 虚轴交点决定参数稳定边界；
  - 根轨迹增益常常只是中间量，必须再换回实际开环增益 `K`。
