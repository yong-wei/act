## 说明

- 本讲真正解决的问题不是“系统稳不稳”，而是“系统离不稳定还有多远”。
- 课件把稳定裕度明确定位为频域中的“稳定储备量”：
  - 相角裕度 `\gamma`：在单位增益穿越处，相位离 `-180^\circ` 还有多少余量；
  - 幅值裕度 `h`：在相位穿越 `-180^\circ` 时，幅值离单位增益还有多少余量。
- 后续讲“稳定裕度”“三频段”“串联校正”时，都可以直接复用本讲的 3 个动作：
  - 在极坐标或 Bode 图上定位两类穿越频率；
  - 从穿越频率读取两类裕度；
  - 用近似图和软件验证评估手算误差。
