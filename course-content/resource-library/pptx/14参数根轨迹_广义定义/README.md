## 说明

- 本讲的核心不在于“再发明一套新法则”，而在于“把一般参数变化转成普通根轨迹问题”。
- 第 7 页给出的稳定套路可恢复为：
  - 若闭环特征方程可写成 `B(s)+aA(s)=0`
  - 则可改写为 `1+a A(s)/B(s)=0`
  - 参数 `a` 就成为等效根轨迹增益
- 第 10 页特别提醒：变换后可能出现 `n' < m'`，从而出现来自无穷远极点的根轨迹分支。
