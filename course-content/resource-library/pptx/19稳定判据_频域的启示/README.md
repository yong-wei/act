## 说明

- 本讲的真正升级不是“又学一个判据”，而是把闭环稳定问题从求根问题改写成开环频率响应的几何问题。
- 全讲可以压缩成一条稳定主线：
  - 用幅角原理把零极点数与包围圈数联系起来；
  - 用 `F(s)=1+G(s)H(s)` 把“闭环极点是否在右半平面”转成“奈奎斯特曲线如何对待 `(-1,j0)`”；
  - 用半闭合曲线把完整包围问题转成负实轴穿越计数；
  - 再把穿越规则翻译成 伯德图上的幅值-相位联合判据。
- 本讲最值得后续课程直接复用的结论包括：
  - `R=P-Z`
  - 闭环稳定时 `Z=0`，因此完整奈奎斯特曲线应逆时针包围 `(-1,j0)` 共 `P` 周
  - 半闭合奈奎斯特曲线的穿越次数满足 `N=P/2`
  - 闭环不稳定根数可由 `Z=P-2N` 直接得到
