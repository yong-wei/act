## 说明

- 本讲的核心不是继续堆根轨迹规则，而是把根轨迹真正用于一个工程对象：
  - 从物理模型得到开环传函；
  - 用根轨迹确定稳定区和候选极点；
  - 用主导极点选择控制器参数；
  - 再用仿真验证“近似设计”和“真实表现”的差异。
- 课件中最值得保留的关键数字包括：
  - `G_1(s)=3.43/(s+2.14375)`
  - `G_2(s)=0.005/(s^2+0.1s)`
  - 闭环特征方程对应根轨迹对象 `0.01715K/[s(s+0.1)(s+2.14375)]`
  - 最佳阻尼比 `\zeta=0.707` 对应闭环极点 `-0.0488\pm j0.0495`
  - 对应 `k=0.0104`，实际比例增益 `K=0.6064`
