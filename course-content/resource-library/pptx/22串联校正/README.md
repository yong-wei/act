## 说明

- 本讲真正要解决的是：当系统“稳态差”和“动态差”呈现不同组合时，串联补偿网络应该改哪一段频率特性。
- 课件给出 3 类典型任务：
  - 暂态好、稳态差：提高低频增益；
  - 稳态好、动态差：改变中高频，主要提高相角裕度和截止频率；
  - 稳态暂态都不满意：低中高频都需要配合调整。
- 超前网络与滞后网络分别承担不同角色：
  - 超前网络：相角超前、幅值抬升，适合“截止频率不足、相角裕度不足”的情形；
  - 滞后网络：高频衰减、把截止频率左移，适合“截止频率有余、相角裕度不足”的情形。
