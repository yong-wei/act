## 说明

- 本讲不是在教一个新判据，而是在建立“频率分工观”：
  - 低频段主要决定稳态误差；
  - 中频段主要决定相角裕度、截止频率和动态性能；
  - 高频段主要决定抗高频干扰能力。
- 课件后半段进一步说明：
  - 只看开环频率特性可以做快速估计；
  - 若想从实验数据反推性能，还必须理解闭环频率特性、谐振峰值和带宽频率。
- 这讲最值得复用的是一条设计判断链：
  - 先看三频段形状；
  - 再看截止频率和相角裕度；
  - 再结合闭环带宽和谐振峰值估算真实动态表现。
