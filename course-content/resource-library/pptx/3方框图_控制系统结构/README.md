# `3方框图_控制系统结构` 提取产物

本目录保存对原始课件 `course-content/slides-ref/3方框图_控制系统结构.pptx` 的正式提取结果。

## 提取范围

- 纳入正文页：第 4-35 页
- 排除页面：
  - 第 1 页：封面
  - 第 2 页：目录导航
  - 第 3 页：学习目标/重难点概览
  - 第 36 页：结束页

## 交付内容

- `extracted.md`
  - 按主题与原页号整理的完整正文提取。
- `tikz/`
  - 对关键线框图的 `TikZ` 重建源文件。
- `tikz/rendered/`
  - `TikZ` 编译后的 PNG 预览图。

## 说明

- 本次提取以 `pptx` 对象层与内嵌媒体资源为主，不依赖 PDF OCR。
- 复杂结构图中的块内公式、变量名和局部标签，部分来自 `ppt/media/*.png` 的人工核读与整理。
- `TikZ` 图不追求逐像素复刻，而以“信息完整、结构清晰、可复用”为目标重建。
