## 说明

- 本讲的目标是把根轨迹“画得更准”，所以核心关注的是关键点而不是全局骨架本身。
- 例 2 `G(s)=K^\ast/[s(s+1)(s+2)]` 中，可稳定恢复的关键结果包括：
  - 分离点方程：`3d^2+6d+2=0`
  - 两个候选根：`d=-0.423`、`d=-1.577`
  - 真正位于根轨迹上的分离点：`d=-0.423`
  - 虚轴交点：`s=\pm j\sqrt{2}`，对应 `K^\ast=6`
