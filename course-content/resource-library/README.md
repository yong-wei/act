# Slides Ref 教学资源库

本目录保存从 `course-content/slides-ref/` 抽取出的参考资源，供大纲重构、讲义撰写和课程内容设计引用。当前 `resource-library` 已统一位于 `course-content/` 下。

## 目录结构

- `tex/`：从老版 TeX 源课件抽取的 Markdown，尽量保留章节、页标题、文本、公式块和绘图代码。
- `pdf/`：从中文系列 PDF 或历史编译产物按页抽取的 Markdown，便于检索主题、术语和例题位置。
- `pptx/`：从中文系列 `pptx` 课件提取出的页面级 Markdown 与 TikZ 重建包，供后续直接引用图示、公式和案例链路。
- `index.md`：总索引，按来源类型分组。
- `manifest.json`：机器可读的来源-输出映射。

## 使用边界

- TeX 抽取优先保留教学内容，不追求完全还原 Beamer 版式命令。
- PDF 抽取以文本检索为主，图示和复杂公式可能只保留局部字符信息。
- PPTX 提取以 `pptx` 对象层、媒体碎片与 TikZ 重建为主，要求保留可复用的图示和推导主链。
- 该资源库是参考素材库，不替代正式讲义、教案或互动课程成稿。
