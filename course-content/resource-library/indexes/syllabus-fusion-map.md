# 资源库到新课程框架的统一映射表

更新时间：2026-03-30

## 使用说明

- 本表是 `course-content/resource-library/` 正式并入新课程框架后的统一转译层。
- 读取顺序固定为：先看本表，再下钻到对应索引，最后进入具体资源文件。
- 本表的核心目标不是“把旧资源原样塞进新单元”，而是明确：
  - 哪些资源可以服务当前框架；
  - 应落在什么位置；
  - 应怎样吸收；
  - 不能怎样误用。

## 当前全局结论

- 资源库与新课程框架的关系是“转译关系”，不是“替代关系”。
- 模块 `1-3` 主要补资源锚点，不改主线骨架。
- 模块 `4` 必须通过转译层吸收 legacy 频域校正资源，而不能被其反向重构。
- 模块 `5` 继续按“边界识别 -> 方法迁移 -> 前沿比较”主线组织，旧资源只提供边界案例，不决定主线。
