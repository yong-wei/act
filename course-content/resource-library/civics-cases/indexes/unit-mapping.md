# 新框架单元与思政案例映射

更新时间：2026-03-28

## 使用说明

- 本表按“新课程框架下哪些单元适合优先接入哪些思政案例”重写，不再保留“待对接”状态。
- 思政案例默认是专业教学主线中的导入、过渡和收束材料，不单独承担知识主讲。
- 若某单元没有合适案例，应明确“不强行接入”，而不是为了完整性硬贴标签。

## 当前采用原则

- 模块 `1` 以 `01` 为主，其他案例不强行提前接入。
- 模块 `2` 只轻量使用 `02`，不把思政材料铺满对象建立链。
- 模块 `3` 以 `03/04/06` 服务“稳定 - 机理 - 频域综合”三条线。
- 模块 `4` 以 `05/06` 服务设计判断、裕度意识和多目标权衡。
- 模块 `5` 以 `08` 支撑边界意识，以 `07` 服务方法迁移背景；`5-3` 与 `5-5` 不因案例稀缺而被迫改骨架。
