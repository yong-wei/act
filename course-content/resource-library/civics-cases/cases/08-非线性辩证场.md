# 非线性辩证场

- 核心思政主题：系统思维、协同观与辩证统一
- 来源段落：244-265
- 适用方式：可作为讲义导入、课堂讨论触发器、BOPPPS 导入案例或课后延伸阅读。

## 教学目标
- 使学生了解非线性的普遍性以及非线性产生的根源，加深对自然社会的理解；
- 培养学生以系统视角认识世界、理解世界的能力；

- 通过介绍哲学中认识非线性的不同阶段，从经典还原论、系统论到现代还原论，引出系统论视角下部分之和大于整体的原理。借此引出团队协作、区域合作和国家间合作的重要意义，培养学生的团队意识和家国情怀。

## 案例内容
- 线性系统满足的叠加原理是一种朴素的还原论在系统中的体现，认为整体等于部分之和，而对整体的认识可以通过其构成元素的加和得到。还原论在科学发展的早期起到了重要的作用，但是随着人类对自然世界认识的加深，认识到事物之间的相互作用与耦合无处不在时，经典还原论就不再适用了。
- 系统论通过扬弃经典还原论，认识到部分之间的相互作用是非线性的来源，因此部分之和不总是等于整体，而取决于部分子系统之间相互作用的方式。这是典型的非线性特性，部分之间的互相的贡献如果为正，则有部分之和大于整体的效果，反之，则有部分之和小于整体的效果。以系统论的、非线性的视角观察和理解控制系统，甚至社会系统，才会深刻理解各部分之间的紧密配合才能取得整体的更大收益。
- 从这个意义上讲，良好的团队内协作，团队间协作，机构间、区域间、甚至国家间的协作，往往可以起到部分之和大于整体的效果。而部分之间的相互攻讦与阻挠破坏只会延缓团队、机构、区域、国家，乃至整个人类的发展与进步。
- 在系统论的基础上，随着人类对世界的理解进一步加深，现代还原论出现了。不同于将主体分解成个体的经典还原论思想，现代还原论将系统的复杂机制还原为简单机制的非线性叠加。例如分形中局部与整体的相似性，由简单的规则构造出复杂的整体；混沌系统由简单的混沌算子产生复杂的动态；神经网络通过简单的神经元结构产生复杂的学习效应甚至类智能；元胞自动机、群体智能等等，都是现代系统科学下，由简单机制产生复杂系统动力学行为的表现。
- 非线性的存在体现了矛盾的对立统一。非线性导致简单与复杂的统一，例如神经元与人工智能；非线性体现有限与无限的统一，例如有限的陆地面积和无限的分形海岸线长度。非线性所体现的对称破缺，杨振宁与李政道提出的宇称不守恒更是可以解释宇宙存在的原因。
- 非线性是自然世界的真实描述，随着对自然理解的加深，我们需要坚持实事求是的精神，需要探索非线性的规律，掌握非线性的方法，建立非线性的世界观[1]。
