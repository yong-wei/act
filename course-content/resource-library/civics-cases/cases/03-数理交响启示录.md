# 数理交响启示录

- 核心思政主题：科学史观、数学支撑与跨学科协同
- 来源段落：58-83
- 适用方式：可作为讲义导入、课堂讨论触发器、BOPPPS 导入案例或课后延伸阅读。

## 教学目标
- 使学生了解科学与技术的发展并不是一蹴而就的，而是相互促进相互影响的螺旋上升过程，培养正确的科学史观。
- 使学生理解数学与工程技术之间的关系，了解数学对工程技术发展的重大影响。

## 课堂实施
- 控制系统时域分析的第一步就是判断系统的稳定性。之前我们已经介绍了一阶和二阶系统的时间响应求解方法，理论上来说，只要得到了系统的时间响应，那么系统的稳定性可以通过求解时间响应在时间趋向于无穷时的极限进行判断。那么这样做会有什么困难呢？
- （引导学生讨论，2分钟，引导话题从时间响应求解到特征根求解，再到高阶多项式无法直接求根的问题）
- 既然没法直接求出高阶方程的根，那是不是就没法判断高阶系统稳定性了呢？让我们跳出思维的局限，考虑系统稳定性判定的本质：即极点是否位于复平面的左半平面。这个判定其实并不要求解出特征根，于是问题变成了“如何判别多项式的根是不是全部位于左半平面？”
- 这时候，系统稳定性的工程问题已经转化成了一个代数方程根的纯数学问题。幸运的是，数学家在控制论出现之前就已经帮我们解决了这个问题，而解决这个问题的人就是Edward John Routh以及Adolf Hurwitz。（介绍Routh和Hurwitz，3分钟）
- Routh在1877年提出了多项式根的判别方法，Hurwitz时隔18年后，于1895年独立提出了不同的判别方法，但是殊途同归。科学真理有时也会“横看成岭侧成峰”，不同的视角或方法下，却可以得到相同的结论。相同的原理在不同的领域或许也会有不同的叫法。
- 科学也不是一蹴而就的，即使Routh这样的Senior Wrangler，其提出的稳定性判据也是建立在欧拉算法、斯特姆定理和柯西指数基础上的，正如牛顿所言“站在巨人的肩膀上”。从1877年Routh给出稳定性判据的100年间，Routh-Hurwitz判据从数学家的理论研究变成了经典控制论的核心概念，而在计算机普及之后又逐渐式微，这个过程也正是人类工程技术发展的缩影。新的技术不断出现，老的技术不断淘汰，而且这个过程会越来越快。作为一名合格的工程师，不断更新知识储备，关注并应用最新技术解决问题，才能在技术的浪潮中生存下来。

## 案例内容
- Edward John Routh（1831-1907），出生于加拿大魁北克，父亲是一位英国军官。他11岁来到英国，于伦敦大学学院公学学习，后升入伦敦大学学院，在de Morgan指导下学习，并受其影响，决定成为一名数学家。Routh在伦敦大学学院分别于1849年和1853年获得文学士和文学硕士学位。后进入剑桥大学彼得学院在Isaac Todhunter和Willian Hopkins指导下学习，后者被誉为“Senior Wrangler（高级牧马人，wrangler有‘进行冗长而复杂的争吵或争执的人’的含义，这里只取字面含义）制造者”。Senior Wrangler即剑桥大学当年数学专业毕业生中得分最高的学生。1854年，Routh以Senior Wrangler身份从剑桥大学毕业，同年，Clerk Maxwell，被称为“那一年最聪明的人”，只能区居第二。
- Routh毕业后成为了剑桥大学彼得学院的数学老师，从1855年至1888年，Routh指导过的学生超过600人，期间培养了27位Senior Wrangler，比他的老师Willian Hopkins还多10位。在讲授天体运动时他会说：“所有漂浮的物体都可以称为船”，“现在让我们考虑一艘球形船”。他在数学教育中笃信竞赛测验方法，因为它自己也是这个体系的成功者。当1910年剑桥大学废止按照学业成绩对学生排名的做法时，他表示强烈反对。在学生成绩以字母表顺序公布时，他说：“下一步他们就要在赛马时按照字母表公布成绩了”。之后，剑桥大学数学专业只会公布每位毕业生的学位等级。考官会在读出Senior Wrangler的名字时戴上帽子，以此“非官方”地透露其身份，而其他排名则私下透露给其他学生。
- Routh是英国皇家学会会员，他最著名的学术成就是1877年发表的关于运动稳定性的论文，该论文获得了剑桥大学数学最高奖Adams Prize，获得该奖的还有James Clerk Maxwell（1857）和Routh的老师Isaac Todhunter（1871）等。Routh在1877年的论文中给出了线性系统特征多项式稳定根的判别方法，在1895年，德国数学家Adolf Hurwitz独立给出了另一种判别法，通过将特征多项式系数排列为Hurwitz矩阵，进而判断线性系统稳定性。劳斯判据可以通过列写劳斯表的形式进行，在计算机技术不发达的年代，这种不用求解特征方程而对更直接进行判定的方法具有重要的时代意义。在计算机技术大幅飞跃的现代，人们可以通过数值方法直接求解线性系统的特征根，劳斯判据的理论意义更大于实践价值了。
- Routh的老师Willian Hopkins也是非常成功的数学家，他的著名学生除了Routh之外，还包括George Stokes（斯托克斯，流体力学），James Clerk Maxwell（麦克斯韦，电磁学），William Thomson，Lord Kelvin（开尔文勋爵，热力学）。
