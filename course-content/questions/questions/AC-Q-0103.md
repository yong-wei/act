## 题面

已知下列系统开环传递函数（参数 $K, T, T_i > 0; i = 1, 2, \ldots, 6$）：

(1) $G(s) = \frac{K}{(T_1s+1)$T_2s+1$(T_3s+1)}$； (2) $G(s) = \frac{K}{s(T_1s+1)(T_2s+1)}$； (3) $G(s) = \frac{K}{s^2(T_3+1)}$； (4) $G(s) = \frac{K(T_1s+1)}{s^2(T_2s+1)}$； (5) $G(s) = \frac{K}{s^3}$； (6) $G(s) = \frac{K(T_1s+1)(T_2s+1)}{s^3}$； (7) $G(s) = \frac{K(T_3s+1)(T_4s+1)}{s(T_1s+1)$T_2s+1$$T_3s+1$(T_4s+1)}$； (8) $G(s) = \frac{K}{T_5s-1}$； (9) $G(s) = -\frac{K}{T_6s+1}$； (10) $G(s) = \frac{K}{s(T_6-1)}$。

其系统开环幅相特性曲线分别如图 5-63(a)～(j)所示，试根据奈氏判据判定各系统的闭环稳定性，若系统闭环不稳定，确定其 $s$ 右半平面的闭环极点数。

## 答案解析

解 本题主要考查如何根据系统的开环幅相特性曲线，运用奈氏判据来确定不稳定的闭环极点的个数，进而判别闭环系统的稳定性，特别要注意对含有积分环节的开环幅相曲线的处理。

$G(s)$ 在 $s$ 右半平面的极点数 $P = 0$，由奈氏曲线知 $N_- = 1, N_+ = 0$，故

应用奈氏判据，算得右半平面的闭环极点数为 $Z = P - 2N = 2$

所以系统闭环不稳定，有两个正实部闭环极点。

（2）$G(s) = \frac{K}{s(T_1 s + 1)(T_2 s + 1)}$

因为 $\nu=1$，从奈氏曲线上 $\omega=0^+$ 的对应点起逆时针补作 90° 且半径为无穷大的虚圆弧。由于 $G(s)$ 在 s 右半平面的极点数 $P=0$，由奈氏曲线知 $N_- = 0, N_+ = 0$，故 $N = N_+ - N_- = 0$

应用奈氏判据，算得右半平面的闭环极点数为 $Z = P - 2N = 0$

所以系统闭环稳定。

（3）$G(s) = \frac{K}{s^2}(T_1 s + 1)$

因为 $\nu=2$，从奈氏曲线上 $\omega=0^+$ 的对应点起逆时针补作 180° 且半径为无穷大的虚圆弧。由于 $G(s)$ 在 s 右半平面的极点数 $P=0$，由奈氏曲线知 $N_- = 1, N_+ = 0$，故 $N = N_+ - N_- = -1$

应用奈氏判据，算得右半平面的闭环极点数为 $Z = P - 2N = 2$

所以系统闭环不稳定，有两个正实部闭环极点。

（4）$G(s) = \frac{K(T_1 s + 1)(T_2 s + 1)}{s^3}$

因为 $\nu=3$，从奈氏曲线上 $\omega=0^+$ 的对应点起逆时针补作 180° 且半径为无穷大的虚圆弧。由于 $G(s)$ 在 s 右半平面的极点数 $P=0$，由奈氏曲线知 $N_- = 0, N_+ = 0$，故 $N = N_+ - N_- = 0$

应用奈氏判据，算得右半平面的闭环极点数为 $Z = P - 2N = 0$

所以系统闭环稳定。

（5）$G(s) = \frac{K}{s^3}$

因为 $\nu=3$，从奈氏曲线上 $\omega=0^+$ 的对应点起逆时针补作 270° 且半径为无穷大的虚圆弧。由于 $G(s)$ 在 s 右半平面的极点数 $P=0$，由奈氏曲线知 $N_- = 1, N_+ = 0$，故 $N = N_+ - N_- = -1$

因为 $\nu = 1$，从奈氏曲线上 $\omega = 0^+$ 的对应点起逆时针补作 90° 且半径为无穷大的虚圆弧。 由于 $G(s)$ 在 ( s ) 右半平面的极点数 $P = 0$，由奈氏曲线知 $N_- = 1, N_+ = 1$，故 $N = N_+ - N_- = 0$ 应用奈氏判据，算得右半平面的闭环极点数为 $Z = P - 2N = 0$ 所以系统闭环稳定。
