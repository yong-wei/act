## 题面

设控制系统如图 4-41 所示，其中 $G_r(s)$ 是为改善性能而加入的校正装置。若 $G_r(s)$ 可从 $K, K_a, K_a^2$ 和 $K_a^2/(s+20)$ 三种传递函数中任选一种，你选择哪一种？为什么？

### 配图

- 图题：`图 4-17-3 [ 1 + \frac{10K_s s^2 (s+20)}{s^3 + 30s^2 + 200s + 1000} = 0 ] 概略参数根轨迹图`
- 图题：`图 4-17-4 [ 1 + \frac{10K_s s^2 (s+20)}{s^3 + 30s^2 + 200s + 1000} = 0 ] 参数根轨迹图 (MATLAB)`
- 图题：`图 4-17-5 [ 1 + \frac{10K_s s^2}{s^3 + 30s^2 + 200s + 1000} = 0 ] 概略参数根轨迹图`
- 图题：`图 4-17-6 [ 1 + \frac{10K_s s^2}{s^3 + 30s^2 + 200s + 1000} = 0 ] 参数根轨迹图 (MATLAB)`
- 图题：`图 4-17-7 采用 G(s) = Ks 时系统的响应 (K, = 0.302, MATLAB)`

## 答案解析

解 本题考查参数根轨迹的绘制，并通过根轨迹研究系统性能。

由系统的结构图可知，系统的开环传递函数为

$$ G(s) = \frac{100}{s+20} \cdot \frac{10}{s(s+10)} = \frac{10000}{(s+20)(s^2+10s+10G_r(s))} $$

则系统的闭环特征方程为

$$ D(s) = (s+20)[s^2 + 10s + 10G_r(s)] + 10000 $$

$$ s^3 + 30s^2 + 200s + 1000 + 10G_c(s)(s+20) = 0 $$

系统的等效开环传递函数为

$$ G_1(s) = \frac{10G_c(s)(s+20)}{s^3 + 30s^2 + 200s + 1000} = 0 $$

（1）当 $G_c(s) = Ks$ 时。

$$ G_1(s) = \frac{10Ks(s+20)}{(s+23.25)(s+3.375+j5.63)(s+3.375-j5.63)} $$

根据绘制常规根轨迹的法则，可得此时的概略参数根轨迹如图 4-17-1 所示。其中分离点方程

$$ d^4 + 40d^3 + 400d^2 - 2000d - 20041.5 = 0 $$

可用试探法求得

$$ d = -6.3 $$

在分离点处，根轨迹增益可用模值条件求出为

$$ K = 0.79 $$

在这种情况下，可以在 ( 0 < K < 0.79 ) 范围内，通过改变 ( K ) 的值使系统的主导极点具有 $\zeta = 0.707$ 的最佳阻尼比，如图 4-17-2 所示。

（2）当 $G_c(s) = Ks^2$ 时。

$$ G_1(s) = \frac{10Ks^2(s+20)}{(s+23.25)(s+3.375+j5.63)(s+3.375-j5.63)} $$

根据绘制常规根轨迹的法则，可得到此时的概略参数根轨迹如图 4-17-3 所示。其仿真图如图 4-17-4 所示。

这种情况下，由于 $K_c$ 的值越大，系统闭环极点越靠近虚轴，从而使稳定性越差，所以不能通过改变 $K_c$ 的值来使系统的性能达到最佳。

图 4-17-3 $1 + \frac{10K_s s^2 (s+20)}{s^3 + 30s^2 + 200s + 1000} = 0$ 概略参数根轨迹图

图 4-17-4 $1 + \frac{10K_s s^2 (s+20)}{s^3 + 30s^2 + 200s + 1000} = 0$ 参数根轨迹图 (MATLAB)

(3) 当 $G_i (s) = \frac{K_s s^2}{s+20}$ 时。

$$ G_i (s) = \frac{10K_s s^2}{(s+23.25)(s+3.375+j5.63)(s+3.375-j5.63)} $$

根据绘制常规根轨迹的法则, 可得到此时的概略参数根轨迹如图 4-17-5 所示。其仿真图如图 4-17-6 所示。

图 4-17-5 $1 + \frac{10K_s s^2}{s^3 + 30s^2 + 200s + 1000} = 0$ 概略参数根轨迹图

图 4-17-6 $1 + \frac{10K_s s^2}{s^3 + 30s^2 + 200s + 1000} = 0$ 参数根轨迹图 (MATLAB)

这种情况下, 也不能通过改变 $K_s$ 的值来使系统的性能达到最佳。

通过以上分析, 最终选择第一种情况, 即 $G_i (s) = K_s$。

MATLAB 程序: exe417.m

G1 = zpk($0 - 20$, $-23.25 -3.375 -5.625i -3.375 +5.625i$, 1);

G2 = zpk($0 0 -20$, $-23.25 -3.375 -5.625i -3.375 + 5.625i$, 1);

G3 = zpk([0 0], $-23.25 -3.375 -5.625i -3.375 + 5.625i$, 1);

z = 0.707;

% 绘制相应系统的根轨迹

figure(1)

rlocus(G1);

sgrid(z, 'new')

hold on;

K = 3.02;

Kt = K/10;

rlocus(G1,K)

% 取阻尼比为 0.707

% 最佳阻尼比对应的根轨迹增益, Kt = K/10

% 阻尼比为 0.707 时, 系统的闭环特征根

figure(2)

rlocus(G2);

figure(3)

rlocus(G3);

% 采用方案 1 时, 系统的时间响应

num1 = [100];

den1 = [1 20];

num2 = [10];

den2 = [1 10 0];

num3 = [Kt 0];

den3 = [0 0 1];

[numf, denf] = feedback(num2, den2,num3, den3);

[numc, denc] = series(num1, den1,numf, denf);

[num, den] = cloop(numc, denc);

% 系统闭环传递函数

sys = tf(num, den);

t = 0:0.001:5;

figure(4)

step(sys, t);

grid on;

在采用 G(s) = Ks 的参数根轨迹图(图 4-17-2)上, 可以得出分离点 d = -6.29, 其相应的根轨迹增益 K* = 7.89, 此时 K, = 0.789; 然后作 ζ = 0.707 阻尼比线, 其与根轨迹的交点为主导极点 s1,2 = -4.58 ± j4.58 (如图中△所示, 另一个极点为 s3 = -23.9), 相应的根轨迹增益 K' = 3.02, 此时 K, = 0.302; 最后应用 MATLAB 软件包, 可得其单位阶跃响应如图 4-17-7 所示, 其动态性能为

\$\sigma = 4.12\%, \quad t_c = 0.737s \$

\$t_v = 0.964s \quad (\Delta = 2\%) \$

图 4-17-7 采用 G(s) = Ks 时系统的响应 $K, = 0.302, MATLAB$

应当指出：应用MATLAB软件包求单位阶跃响应时，闭环极点在参数根轨迹上确定，而闭环零点应采用原系统的闭环零点。本例无闭环零点。
