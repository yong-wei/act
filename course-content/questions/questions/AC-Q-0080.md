## 题面

设控制系统如图 4-40 所示, 试概略绘画 $K = 0, 0 < K < 1, K > 1$ 时的根轨迹。 若取 $K = 0.5$, 试求出 $K = 10$ 时的闭环零、极点, 并估算系统的动态性能。

### 配图

- 图题：`图 4-15-1 1+ ( \frac{K}{s(s+1)} = 0 ) 概略根轨迹图 (( K = 0 ))`
- 图题：`图 4-15-2 $K_i = 0$ 时 $1 + \frac{K_i (1 + K_i s)}{s(s+1)} = 0$`
- 图题：`图 4-15-4 $K_i = 0.5$ 时 $1 + \frac{K_i (1 + K_i s)}{s(s+1)} = 0$`
- 图题：`图 4-15-5 1+K(1+Ks)/s(s+1)=0`
- 图题：`图 4-15-6 K_s=2 时 1+K(1+Ks)/s(s+1)=0`

## 答案解析

解 本题研究闭环根轨迹的绘制及综合应用。

由图 4-40 所示的结构图可知, 系统的开环传递函数为

$$ G(s)H(s) = \frac{K(1+Ks)}{s(s+1)} = \frac{KK}{s(s+1)} $$

(1) 当 $K = 0$ 时系统的根轨迹。开环传递函数为

$$ G(s)H(s) = \frac{K}{s(s+1)} $$

① 根轨迹的分支和起点与终点。由于 $n=2, m=0, n-m=2$, 故根轨迹有两条分支, 其 起轴分别为 $p_1=0, p_2=-1$, 其终点都为无穷远处。

② 实轴上的根轨迹。实轴上的根轨迹分布区为 $$-1, 0$$。

根轨迹的分离点。根轨迹的分离点坐标满足

$$ \frac{1}{d} + \frac{1}{d+1} = 0 $$

解得

$$ d = -0.5 $$

图 4-15-1 1+ $\frac{K}{s(s+1)} = 0$ 概略根轨迹图 $( K = 0 )$

由以上分析绘制系统的概略根轨迹如图 4-15-1 所示。 其仿真图如图 4-15-2 所示。

(2) 当 ( 0 < K < 1 ) 时系统的根轨迹。开环传递函数为

图 4-15-2 $K_i = 0$ 时 $1 + \frac{K_i (1 + K_i s)}{s(s+1)} = 0$

根轨迹图 (MATLAB)

(3) 根轨迹的分离点。根轨迹的分离点坐标满足

$$\frac{1}{d} + \frac{1}{d + 1} = \frac{1}{d + \frac{1}{K_i}}$$

故有 $d^2 + \frac{2}{K_i} d + \frac{1}{K_i} = 0$，解得

$$d_{1,2} = -\frac{1 \pm \sqrt{1 - \frac{1}{K_i}}}{K_i}$$

由以上分析绘制系统的根轨迹如图 4-15-3 所示。在 $0 < K_i < 1$ 时，根轨迹的复数部分为一圆。当 $K_i = 0.5$ 时，其仿真图如图 4-15-4 所示。

$$G(s) H(s) = \frac{K}{s(s+1)} = \frac{K K_i (s + \frac{1}{K_i})}{s(s+1)}$$

$0 < $K_i$ < 1$

① 根轨迹的分支和起始点与终点。由于 $n = 2, m = 1, n - m = 1$，故根轨迹有两条分支，其起始点分别为 $p_1 = 0, p_2 = -1$，其终点分别为 $z = -\frac{1}{K_i}$ 和无穷远处。

由于 $0 < K_i < 1$，故负实零点 $z = -\frac{1}{K_i}$ 必位于开环极点 0 和 $-1$ 之左。

② 与轴上的根轨迹。与轴上的根轨迹分布区为 $(-\infty, -\frac{1}{K_i})$ 和 $$-1, 0$$。

图 4-15-4 $K_i = 0.5$ 时 $1 + \frac{K_i (1 + K_i s)}{s(s+1)} = 0$

根轨迹图 (MATLAB)

(3) 当 $K_i > 1$ 时系统的开环传递函数为

$$ G(s)H(s) = \frac{K(1+K_s)}{s(s+1)} = \frac{KK_s(s + \frac{1}{K_s})}{s(s+1)} \quad (K_s > 1) $$

① 根轨迹的分支和起点与终点。由于 $n=2, m=1, n-m=1$，故根轨迹有两条分支，其 起点分别为空 $p_1 = 0, p_2 = 1$，其终点分别为空 $z = -\frac{1}{K_s}$ 无无穷远处。

由于 $K_s > 1$，故负实零点 $z = -\frac{1}{K_s}$ 必位于开环极点 0 和 -1 之间。

② 实轴上的根轨迹。实轴上的根轨迹分布为 $[ -1, -\infty$, $0, -\frac{1}{K_s}$ )。

由以上分析绘制系统的概略根轨迹如图 4-15-5 所示。当 $K_s = 2$ 时，其仿真图如 图 4-15-6 所示。

(4) $K_s = 0.5, K = 10$ 时闭环系统零、极点及动态性能。系统的开环传递函数

$$ G(s)H(s) = \frac{10(1+0.5s)}{s(s+1)} = \frac{5(s+2)}{s(s+1)} $$

闭环传递函数

$$ \Phi(s) = \frac{G(s)}{1+G(s)H(s)} = \frac{10}{s(s+1)+5(s+2)} $$

则系统的闭环特征方程为

$$ D(s) = s(s+1) + 5(s+2) = s^2 + 6s + 10 = 0 $$

此时，系统的闭环极点为 $\lambda_1, \lambda_2 = -3 \pm j1$，无闭环零点。

由系统的闭环极点可知 $\zeta \omega_n = 3, \omega_n \sqrt{1-\zeta^2} = 1$，可得

$$ \omega_n = \sqrt{10} = 3.16, \quad \zeta = 0.95, \quad \omega_d = 1 $$

所以，系统的动态性能指标如下:

调节时间 $t_e = \frac{3.5}{\zeta \omega_n} = \frac{3.5}{3} = 1.17s (\Delta = 0.05)$ $t_e = \frac{4.4}{\zeta \omega_n} = \frac{4.4}{1.47} = 1.47s (\Delta = 0.02)$
