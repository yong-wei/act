## 题面

已知汽车点火系统中有一个单位负反馈子系统,其开环传递函数为 $G_c(s)G_0(s)$, 其中

$$ G_0(s) = \frac{10}{s(s+10)}, \quad G_c(s) = K_1 + \frac{K_2}{s} $$

若已知 $K_2/K_1 = 0.5$, 试确定 $K_1$ 和 $K_2$ 的取值, 使系统主导极点的阻尼比 $\zeta = 0.707$, 且单位阶跃响应的调节时间 $t_r \leq 2s (\Delta = 5%)$。

### 配图

- 图题：`图 6-16-1 汽车点火子系统的时间响应 (MATLAB)`

## 答案解析

解 本题根据阻尼比与调节时间的指标要求设计 PI 控制器参数，采用试探法选取控制器参数。

系统开环传递函数为

$$ G_c(s)G_0(s) = \frac{10K_1(s + K_2/K_1)}{s^2(s+10)} = \frac{10K_1(s+0.5)}{s^2(s+10)} $$

闭环特征方程为

$$ D(s) = s^3 + 10s^2 + 10K_1s + 5K_1 = 0 $$

劳斯表可写为：

| 行 | 第一列 | 第二列 |
| --- | --- | --- |
| $s^3$ | $1$ | $10K_1$ |
| $s^2$ | $10$ | $5K_1$ |
| $s^1$ | $9.5K_1$ | $0$ |
| $s^0$ | $5K_1$ | $0$ |

由劳斯判据知，只要 $K_1 > 0$，闭环系统即稳定。

试取 $K_1 = 5$，则闭环特征方程化为

$$ s^3 + 10s^2 + 50s + 25 = (s + 0.56)(s^2 + 9.44s + 44.71) = 0 $$

故闭环极点为

$$ s_1 = -0.56, \quad s_{2,3} = -4.72 \pm j4.74 $$

其中闭环极点 $s_1 = -0.56$ 与闭环零点 $z = -0.5$ 近似对消，因此系统主导极点为 $s_{2,3}$。此时阻尼比约为 $\zeta = 0.709 \approx 0.707$，预期调节时间

$$ t_s = \frac{3.5}{\zeta \omega_n} = \frac{3.5}{4.72} = 0.74\text{s} \quad (\Delta = 5\%) $$

考虑到 $s_1$ 与 $z$ 不能完全对消，实际调节时间会略大于理论估计，但仍满足题设指标，故最终取

$$ K_1 = 5, \quad K_2 = 2.5 $$

MATLAB 验证：对汽车点火子系统进行仿真，其单位阶跃响应如图 6-16-1 所示，可测得

$$ \sigma = 14\%, \quad t_p = 0.6\text{s}, \quad t_s = 1.55\text{s} \quad (\Delta = 5\%) $$

MATLAB 程序：

```matlab
K1 = 5;
K2 = 2.5;
G0 = tf(10, [1, 10, 0]);
Gc = tf([K1, K2], [1, 0]);
G = series(G0, Gc);
G1 = feedback(G, 1);
step(G1);
grid on;
```
