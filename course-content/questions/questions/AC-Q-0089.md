## 题面

在未来的智能汽车-高速公路系统中汇集了各种电子设备，可以提供事故、路径规划、路边服务和交通控制等实时信息。图 4-48(a)所示为自动化高速公路系统。图 4-48(b)给出的是保持车辆间距的位置控制系统。要求选择放大器增益 $K_1$ 和速度系数 $K_r$ 的取值，使系统响应单位斜坡输入 $R(s) = \frac{1}{s^2}$ 的稳态误差小于 0.5，单位阶跃的超调量小于 10%，调节时间小于 2s ($\Delta = 5%$)。

## 答案解析

解 本题应用等效根轨迹技术及 MATLAB 设计软件包，确定多个系统参数的!设计过程中，需要综合运用劳斯稳定判据、稳态误差计算法、主导极点法以及动态性能法等知识。

(1) 稳定性要求。由图 4-48(b)知，速度反馈内回路传递函数

开环传递函数

$$G_i(s) = \frac{K_a}{(s + 3)$s + 7$ + K_a}$$

$$G(s) = \frac{K_a}{s(s^2 + 10s + 21 + K_a)} = \frac{s(21 + K_a s + 10s + 21 + K_a)}{21 + K_a}$$

式中，速度误差系数

$$K_v = \frac{K_a}{21 + K_a}$$

闭环传递函数

$$\Phi(s) = \frac{K_a}{s(s^3 + 10s + 21 + K_a s + K_a)} + \frac{K_a}{s^3 + 10s^2 + (21 + K_a s + K_a)s + K_a}$$

首先，$K_i$ 和 $K_v$ 的选取应保证闭环系统具有稳定性。列劳斯表如下:

| $s^3$ | 1 | $21 + K_a s$ | | $s^2$ | 10 | $K_a$ | | $s^1$ | 10 | $(21 + K_a s) K_a$ | | $s^0$ | $K_a$ | $K_a$ |

由劳斯稳定判据知：使闭环系统稳定的充分必要条件是

$$K_a > 0, \quad 10(21 + K_a s) - K_a > 0$$

也即

$$K_a > 0, \quad K_i > 0.1 - \frac{21}{K_a}$$

(2) 稳态误差要求。根据系统在单位斜坡输入下的稳态误差要求

$$E_s(\infty) = \frac{1}{K_i} = \frac{21 + K_a s}{K_a} < 0.5$$

导出

$$K_a (0.5 - K_i) > 21$$

由于要求 $K_a > 0$，故应有 $(0.5 - K_i) > 0$，因此要求

$$K_i < 0.5 - \frac{21}{K_a}$$

从系统稳态性能（稳定性与稳态误差）考虑，$K_i$ 和 $K_v$ 的选取应满足

$$K_a > 0, \quad 0.5 - \frac{21}{K_a} > K_i > 0.1 - \frac{21}{K_a}$$

由于 $K_i > 0$，故应有 $K_a > 42$。于是，$K_i$ 和 $K_v$ 选取时应满足的条件可进一步表示为

$$K_a > 42, \quad 0 < K_i < 0.5 - \frac{21}{K_a}$$

显然，取 $K_i = 0.25, K_v > 0.5 K_i = 84$ 是一组允许值。$K_v$ 的最终确定，可根据对系统动态性能要求去选取。

(3) 动态性能要求。对于二阶系统，若取阻尼比 $\xi = 0.6$，则 $\sigma = 9.5% < 10%$，因为要求

$$ t_s = \frac{3.5}{\sigma} < 2 \quad (\Delta = 5%) $$

故应保证 $\sigma > 1.75$。

在 ( s ) 平面上，作了 $\zeta = 0.6$ 和 $\sigma > 1.75$ 扇形区域，令 $K_0 = 0.25, K_a$ 从 $0 \rightarrow \infty$，作系统根轨迹。在根轨迹图上，$K_0$ 的最终确定应使闭环极点位于扇形区域内。闭环特征方程

$$ D(s) = (s^3 + 10s^2 + 21s) + 0.25K_a(s+4) = 0 $$

等效根轨迹方程

$$ 1 + K* \frac{s+4}{s(s+3)(s+7)} = 0 $$

式中，$K* = 0.25K_a$。根轨迹参数：

渐近线:

$$ \sigma_a = -3, \quad \phi_a = \pm 90° $$

分离点：由

$$ \frac{1}{d} + \frac{1}{d+3} + \frac{1}{d+7} = \frac{1}{d+4} $$

解出

$$ d = -1.78 $$

系统概略根轨迹如图 4-24-1 所示。图中，复数根轨迹分支与 $\zeta = 0.6$ 阻尼比线的交点为

$$ S_{1,2} = 2.5 \pm j3.33 $$

$S_1$ 点处的根轨迹增益 $K* = 21.5$，相应的

$$ K_a = \frac{K*}{0.25} = 86, \quad K_a = \frac{K_a}{21 + K_a} = 2.024 $$

根据模值条件 $K* = 21.5$，可以确定第三个闭环极点 $S_3 = 4.92$。此时系统的近似性能

$$ \sigma_0 = 9.5% < 10% $$

$$ t_s = \frac{3.5}{2.5} = 1.4s < 2.0s \quad (\Delta = 5%) $$

$$ e_a(\infty) = \frac{1}{K_a} = \frac{1}{2.024} = 0.494 < 0.5 $$

满足全部设计指标要求。

基于 MATLAB 软件包，图 4-24-2 给出 $\zeta = 0.6$ 时的根轨迹增益，用以确定 $K_a$ 值；车辆间距控制系统根轨迹图，如图 4-24-3 所示，图中 $\triangle$ 表示 $\zeta = 0.6$ 时系统的闭环极点。
