## 题面

试简化图 2-57 中系统结构图，并求传递函数 $C(s)/R(s)$ 和 $C(s)/N(s)$。

### 配图

- 图题：`图 2-18-3 ( R(s) = 0 ) 时系统(a)结构图变换`
- 图题：`图 2-18-5 ( R(s) = 0 ) 时系统(a)结构图变换`
- 图题：`图 2-18-7 ( N(s) = 0 ) 时系统(b)结构图`

## 答案解析

解 本题研究结构图的等效变换。

（1）图 2-57（a）系统。仅考虑输入 $R(s)$ 作用于系统时，系统的结构图如图 2-18-1 所示。

经过反馈连接等效，可得图 2-18-2，则系统传递函数为

$$ \frac{C(s)}{R(s)} = \frac{G_1 G_2}{1 + G_1 G_2 H_1} \cdot \frac{1}{1 + \frac{G_1 G_2}{1 + G_2 G H_1}} = \frac{G_1 G_2}{1 + G_1 G_2 + G_1 G_2 H_1} $$

仅考虑扰动 $N(s)$ 作用于系统时，系统的结构图如图 2-18-3 和图 2-18-4 所示。

经过反馈连接等效可得图 2-18-5；经过比较点的移动，可得图 2-18-6，系统传递函数为

$$ \frac{C(s)}{N(s)} = \left( \frac{G_2 G_3}{1 + G_1 G_2 H_1} - 1 \right) \cdot \frac{1}{1 + \frac{G_1 G_2}{1 + G_1 G_2 H_1}} = \frac{1 - G_2 G_3 + G_1 G_2 H_1}{1 + G_1 G_2 + G_1 G_2 H_1} $$

图 2-18-3 ( R(s) = 0 ) 时系统(a)结构图变换

图 2-18-5 ( R(s) = 0 ) 时系统(a)结构图变换

图 2-18-7 ( N(s) = 0 ) 时系统(b)结构图

(2) 图 2-57(b) 系统。仅考虑输入 $R(s)$ 作用于系统时，系统的结构图如图 2-18-7 所示。

经过比较点后移，可得图 2-18-8；经过串联等效和并联等效，可得图 2-18-9；经过比较点后移，可得图 2-18-10，则系统传递函数为

$$\frac{C(s)}{R(s)} = (G_1 G_2 + G_2 + G_3) \cdot \frac{G_4}{1+G_1(G_2 + G_3)} = \frac{G_4}{1+G_2 G_4 + G_3 G_4}$$

仅考虑扰动 $N(s)$ 作用于系统时，系统的结构图如图 2-18-11 所示，则系统传递函数为

$$\frac{C(s)}{N(s)} = \frac{G_4}{1+G_1(G_2 + G_3)} = \frac{G_4}{1+G_2 G_4 + G_3 G_4}$$
