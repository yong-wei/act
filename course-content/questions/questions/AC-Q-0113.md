## 题面

根据题 5-11 所绘对数幅频渐近特性曲线，近似确定截止频率 $\omega_c$，并由此确定相角裕度 $\gamma$ 的近似值。

### 配图

- 图题：`图 5-24-3 的开环`

## 答案解析

解 本题主要考查如何根据系统的对数幅频渐近特性曲线确定截止频率，进而确定相角裕度。

(1) $G(s) = \frac{2}{(2s+1)(8s+1)}$

由图 5-11-1 对数幅频渐近特性曲线，并根据其几何性质，可以得

$$20\lg 2 = 20\lg \frac{\omega_c}{1/8}$$

解得 $\omega_c = 0.25\text{rad/s}$。再由

$$\gamma = 180^\circ - \arctan 2\omega_c - \arctan 8\omega_c$$

解得 $\gamma = 90^\circ$。

MATLAB 验证：

由开环对数频率特性的仿真结果，可以测得 $\omega_c = 0.196\text{rad/s}$，$\gamma = 101^\circ$，如图 5-24-1 所示。

(2) $G(s) = \frac{200}{s^2(s+1)(10s+1)}$

由图 5-11-2 对数幅频渐近特性曲线，并根据其几何性质，可以得

$$20\lg 200 + 40\lg \frac{1}{10} - 60\lg \frac{1}{10} = 80\lg \frac{\omega_c}{1}$$

解得 $\omega_c = 2.115\text{rad/s}$。再由

$$\gamma = 180^\circ - 180^\circ - \arctan \omega_c - \arctan 10\omega_c.$$

解得 $\gamma = -152^\circ$。

MATLAB 验证:

由开环对数频率特性的仿真结果，可以测得 $\omega_k = 2.06 \text{rad/s}$，$\gamma = -151^\circ$，如图 5-24-2 所示。

$$G(s) = \frac{8\left(\frac{s}{0.1} + 1\right)}{s(s^2 + s + 1)\left(\frac{s}{2} + 1\right)}$$

由图 5-11-3 对数幅频渐近特性曲线，根据其几何性质，可以得到

$$20\log 8 + 20\log \frac{1}{0.1} - 40\log \frac{2}{1} = 60\log \frac{\omega}{2}$$

解得 $\omega_k = 5.429 \text{rad/s}$。再由

$$\gamma = 180^\circ + \arctan \frac{\omega_k}{0.1} - 90^\circ - \left(180^\circ - \arctan \frac{\omega_k}{\omega_c - 1}\right) - \arctan \frac{\omega_k}{2}$$

解得 $\gamma = -60.04^\circ$。

MATLAB 验证:

由开环对数频率特性的仿真结果，可以测得 $\omega_k = 5.34 \text{rad/s}$，$\gamma = -59.6^\circ$，如图 5-24-3 所示。

$$G(s) = \frac{10\left(\frac{s}{400} + \frac{s}{10} + 1\right)}{s(s+1)\left(\frac{s}{0.1} + 1\right)}$$

对数频率特性（MATLAB）

$$G(s) = \frac{10\left(\frac{s}{400} + \frac{s}{10} + 1\right)}{s(s+1)\left(\frac{s}{0.1} + 1\right)}$$

$$\gamma = 180^\circ + \arctan \frac{\omega_k / 10}{1 - \omega_k / 400} - 90^\circ - \arctan \frac{\omega_k}{1} - \arctan \frac{\omega_k}{0.1}$$

解得 $\gamma = -33.57^\circ$。
