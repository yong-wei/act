## 题面

设有前置滤波器的鲁棒控制系统如图 6-46 所示，其中被控对象

$$ G_0(s) = \frac{10}{(s+1)(s+2)} $$

PID 控制器

$$ G_r(s) = \frac{K_3 s^2 + K_1 s + K_2}{s} $$

图 6-46 具有前置滤波器的鲁棒控制系统结构图

$G_r(s)$ 为前置滤波器。设计要求：

当 $K_n = 10, K_b = 0$ 时，设计 $G_r(s)$ 和 $G_p(s)$，使系统具有最小节拍响应，即系统在单位阶跃输入作用下 $e_n(\infty) = 0, \sigma% \leq 2%, t_e \leq 1s (\Delta = 2%)$;

若 $G_0(s)$ 的两个极点发生 $\pm 50%$ 范围摄动，在最坏情况下，被控对象变为

$$ G_0(s) = \frac{10}{(s + 0.5)(s + 1)} $$

试用（1）中的设计结果对系统性能进行考核，以检验系统的鲁棒性。

## 答案解析

解 本题联合采用 PID 控制器与前置滤波器，使系统具有最小节拍响应，保证系统有良好的稳态性能和动态性能；同时，采用内回路反馈包围被控对象，以减少被控对象参数摄动的影响，使系统具有鲁棒性。

PID 控制器与前置滤波器设计。内回路传递函数为

$$ K_n 包围部分 \Phi_i(s) = \frac{2}{s + (1 + 2K_n)} $$

K_2(s) = \frac{5}{s+2} \Phi_1(s) \frac{1+5K_a}{s+2} \Phi_1(s) \frac{s^2+(3+2K_b)s+(2+10K_a+4K_b)}{s(s^2+(3+2K_b)s+$2+10K_a+4K_b$)} G_p(s)

开环传递函数为

\Phi(s) = \frac{G(s)}{1+G(s) \Phi_2(s)} \frac{10(K_3s^2+K_1s+K_2)G_p(s)}{s^3+(3+2K_b+10K_a)s^2+(2+10K_a+4K_b+10K_1)s+10K_2}

选择

G_p(s) = \frac{K_2}{K_3s^2+K_1s+K_2}

可得

\Phi(s) = \frac{10K_2}{s^3+(3+10K_3)s^2+(102+10K_1)s+10K_2}

显然，系统在阶跃输入作用下，必有 $e_x(\infty) = 0$。

为了使系统成为最小节拍系统，根据教材中表 6-4，应有

$$ \Phi(s) = s^3 + 1.9 \omega_n s^2 + 2.2 \omega_n^2 s + \omega_n^3 $$

当 $K_a = 10, K_b = 0$ 时，系统实际闭环传递函数为

$$ \Phi(s) = \frac{10K_2}{s^3+(3+10K_3)s^2+(102+10K_1)s+10K_2} $$

对于三阶最小节拍系统，调节时间要求

$$ t_s = \frac{\omega_n}{0.4} \leq 1 $$

考虑到系统的鲁棒性要求，取 $t_s = 0.5$，故应有 $\omega_n = 8.08$。令标准化传递函数与实际闭环传递函数的对应项系数相等，可得 PID 控制器参数

$$ K_1 = 4.16, \quad K_2 = 52.75, \quad K_3 = 1.24 $$

于是 PID 控制器和前置滤波器为

$$ G_c(s) = 4.16 + \frac{52.75}{s} + 1.24s, \quad G_p(s) = \frac{52.75}{1.24s^2 + 4.16s + 52.75} $$

系统的实际性能为

$$ e_x(\infty) = 0, \quad \sigma% = 1.65%, \quad t_s = 0.5s (\Delta = 2%) $$

(2) 鲁棒性检验。在最坏情况下，被控对象传递函数

$$ G_0(s) = \frac{10}{(0.5s+1)(s+1)} = \frac{20}{(s+1)(s+2)} $$

表明被控对象极点位置摄动 50%，相当于对象增益加大一倍。

内回路传递函数

$$ G_c(s) = \frac{K_3s^2+K_1s+K_2}{s}, \quad G_p(s) = \frac{K_2}{K_3s^2+K_1s+K_2} $$

所以，开环传递函数 $G(s) = G_p(s)G_c(s)\Phi_2(s) = \frac{20K_2}{s^3 + (3 + 2K_b)s + (2 + 20K_a + 4K_b)}$ 闭环传递函数 $\Phi(s) = \frac{G(s)}{1 + G_p(s)G_c(s)} = \frac{20K_2}{s^3 + (3 + 2K_b + 20K_3)s + (2 + 20K_a + 4K_b + 20K_1)s + 20K_2}$ 代入上步设计结果 $K_a = 10, K_b = 0, K_1 = 1.24, K_2 = 52.75, K_3 = 4.16$，得 $\Phi(s) = \frac{1055}{s^3 + 27.8s^2 + 285.2s + 1055}$ 应用MATLAB软件包，可得系统在单位阶跃输入作用下的响应，如图6-14-1所示，测得 $e_a(\infty) = 0, \quad \sigma % = 0, \quad t_i = 0.626s$

图6-14-1 系统单位阶跃响应(MATLAB)

MATLAB程序: exe614.m

t=0:0.01:1;

K_a = 10; K_b = 0; K_1 = 4.16; K_2 = 52.75; K_3 = 1.24;

Gl=tf($20*K_2, [1,3+2*K_b+20*K_3,2+20*K_a+4*K_b+20*K_1,20*K_2]$);

\%系统闭环传递函数

step(Gl,t);grid

仿真表明在参数变化情况下，系统的性能仍然满足设计指标要求，具有良好的鲁棒性。 当 $K_0 \neq 0$ 时，可令 $K_0$ 为各种可能的数值重做本题，并进行相应的MATLAB仿真。
