## 题面

已知开环传递函数为

$$G(s) = \frac{K^* (s+2)}{(s^2+4s+9)^2}$$

试概略绘制其闭环系统根轨迹图。

## 答案解析

解 本题可应用根轨迹绘制法则，绘制开环系统具有复重极点时的闭环系统的概略根轨迹图。

$$G(s) = \frac{K^* (s+2)}{(s^2+4s+9)^2}$$

根轨迹的分支和起点与终点。由于 $n=4, m=1, n-m=3$，故根轨迹有四条分支，其中两条根轨迹的终点为 $z_1 = -2$，其余都为无穷远处。

实轴上的根轨迹。实轴上的根轨迹分布区为 $[-2, -\infty)$。

根轨迹的渐近线。

$$\sigma = \frac{2 \times (-2+j\sqrt{5}) + 2 \times (-2-j\sqrt{5}) + 2}{4-1} = -2, \quad \varphi = \pm \frac{\pi}{3}, \pi$$

根轨迹的分离点。根轨迹的分离点坐标满足

$$\frac{2}{d+2-j\sqrt{5}} + \frac{2}{d+2+j\sqrt{5}} = \frac{1}{d+2}$$

即

$$3d^2 + 12d + 7 = 0$$

解得

$$d_1 = 3.29, \quad d_2 = -0.71$$（舍去）

故分离点的坐标为 $d = -3.29$。

根轨迹与虚轴的交点。系统的闭环特征方程式为 $D(s) = (s^2 + 4s + 9)^2 + K^* (s + 2)$ $= s^4 + 8s^3 + 34s^2 + (72 + K^)s + $2K^ + 81$ = 0$ 令 $s = j\omega$，将其代入上式可得 $(j\omega)^4 + 8(j\omega)^3 + 34(j\omega)^2 + $72 + K^$$j\omega$ + $2K^ + 81$ = 0$ 即 $(\omega^4 - 34\omega^2 + 2K^* + 81) = 0$ $-8\omega^3 + 72 + K^* = 0$ 解得 $\omega = \pm 4.58, \quad K^* = 96$ 根据以上分析，画出系统的闭环根轨迹如图 4-8-1 所示。其仿真图如图 4-8-2 所示。
