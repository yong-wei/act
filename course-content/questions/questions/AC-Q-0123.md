## 答案解析

解 本题主要考察串联滞后-超前校正对系统性能的影响。

绘制出待校正系统、滞后-超前校正装置和已校正系统的对数幅频渐进特性曲线，如下图所示。(6分)

由图中与轴交点，得待校正系统的截止评率 rad/s，(2分)算出待校正系统的相角裕度为

由图中与轴交点，得已校正系统的截止评率 rad/s，(2分)算出已校正系统的相角裕度为

校正前后单位阶跃响应对比如下

应用MATLAB软件包，进行校正效果检验。作待校正系统的单位阶跃响应，如图6-5-2所示，测得 $$\sigma = 67%, \quad t_p = 1.61s$$ $$t_e = 14.6s \quad (\Delta = 2%)$$ 作已校正系统的单位阶跃响应，如图6-5-3所示，测得 $$\sigma = 8%$$ $$t_e = 4.89s \quad t_s = 16.9s \quad (\Delta = 2%)$$ MATLAB程序：exe605.m

w = 0.001:1:100;

GO = tf([8, [conv([1,0],[2,1])]]);

% 待校正系统的开环传递函数

Gc = tf([conv([10,1],[2,1])], [conv([100,1],[0.2,1])]);

G = series(G0,Gc);

% 已校正系统的开环传递函数

% 绘制待校正系统、滞后-超前校正装置和已校正系统的对数幅频渐近线

[x,Y] = bd_asymp(G0,w); [xc,yc] = bd_asymp(Gc,w);

[xl,Y1] = bd_asymp(G,w);

figure(1);

semilogx(x,Y,'r'); hold on;

semilogx(xc,yc,'b'); semilogx(xl,Y1,'k');

grid; hold off

% 待校正和已校正系统的闭环传递函数

Gl = feedback(G0,1); G11 = feedback(G,1);

figure(2); step(G1); grid

figure(3); step(G11); grid
