## 题面

设控制系统开环传递函数为

$$ G(s) = \frac{K^* (s + 1)}{s^2 (s + 2) (s + 4)} $$

试分别画出正反馈和负反馈系统的根轨迹图，并指出它们的稳定情况有何不同。

\textbf{解} 本题研究常规根轨迹和零度根轨迹的绘制与分析。

（1）负反馈系统的根轨迹。

① 根轨迹的分支和起点与终点。由于 $n=4, m=1, n-m=3$, 故根轨迹有四条分支，其 起点分别为 $\rho_1, \rho_2 = 0, \rho_3 = -2, \rho_4 = -4$, 其终点分别为 $z_1 = -1$ 和无穷远处。 ② 实轴上的根轨迹。实轴上的根轨迹分布区为 $[-4, -\infty), $-2, -1$$。 ③ 根轨迹的渐近线。

$$ \sigma = \frac{-2 - 4 + 1}{4 - 1} = -1.67, \quad \varphi = \pm \frac{\pi}{3} + \pi $$

④ 根轨迹与虚轴的交点。系统的闭环特征方程为

$$D(s) = s^4(s + 2)$s + 4$ + K^*$s + 1$ = s^4 + 6s^3 + 8s^2 + K^s + K^ = 0$$

令 $s = j\omega$, 代入上式可得

$$(j\omega)^4 + 6(j\omega)^3 + 8(j\omega)^2 + K^(j\omega) + K^ = 0$$

即

$$\omega^4 - 8\omega^2 + K^* = 0$$

$$-6\omega^3 + K^*\omega = 0$$

因 $\omega \neq 0$, 故可解得

$$\omega = \pm \sqrt{2}, \quad K^* = 12$$

根据以上分析，画出系统的闭环根轨迹如图 4-16-1 所示。其仿真图如图 4-16-2 所示，局部如图 4-16-3 所示。

由根轨迹图可知，当 $0 < K^* < 12$ 时，系统稳定。

(2) 正反馈系统的根轨迹。

① 根轨迹的分支和起点与终点。由于 $n=4, m=1, n-m=3$, 故根轨迹有四条分支，其 起点分别为 $\rho_1, \rho_2 = 0, \rho_3 = -2, \rho_4 = -4$, 其终点分别为 $z_1 = -1$ 和无穷远处。 ② 实轴上的根轨迹。实轴上的根轨迹分布区为 $$-4, -2$, [-1, \infty)$. ③ 根轨迹的渐近线。

$\sigma_a = \frac{-2-4+1}{4-1} = -1.67$, $\varphi_a = \pm \frac{2\pi}{3}, 0$

④ 根轨迹的分离点。根轨迹的分离点坐标满足

$$ \frac{2}{d} + \frac{1}{d+2} + \frac{1}{d+4} = \frac{1}{d+1} $$

由图法可得 $d = -3.08$。

根据以上分析，画出系统的闭环概略零度根轨迹如图 4-16-4 所示。其仿真图如图 4-16-5 所示。

由根轨迹图可知，当 $K^* > 0$ 时，系统恒不稳定。
