## 一、一个增益为什么会牵动三张图

在同一个单位负反馈系统中逐渐增大增益 $K$，阶跃响应会更早起步，却也可能出现更大的超调和更慢的衰减。只看时域曲线，容易把“起步快”误认为“收敛快”；同时观察闭环极点和环路频率特性，才能看清速度、阻尼与稳定余量之间的交换。

三张图并不对应三个彼此独立的系统。增益 $K$ 进入环路传递函数 $L(s)=KG_0(s)$，并通过特征方程 $1+L(s)=0$ 决定闭环极点；闭环极点塑造阶跃响应，环路 Bode 图则给出增益穿越频率和稳定裕度。它们从不同角度描述同一个反馈结构，因此应当彼此相容，但不能把某一域的指标直接当成另一域的指标。

完成这次课程后，你应当能够：

- 调节增益 $K$，读取闭环极点、阶跃响应和环路 Bode 图的同步变化
- 用极点实部、超调量、5% 调节时间、增益穿越频率和稳定裕度建立三域证据链
- 区分“上升更快”“收敛更快”和“环路速度尺度提高”三种不同含义
- 识别稳定、近临界、临界稳定和不稳定状态的三域信号
- 用 MATLAB/Octave 独立复现全部观察，并用三域对照表整理结果

## 二、实践准备：对象、工具与观察框架

### 2.1 本次实践采用的对象

选择三阶无零点对象

$$G_0(s) = \frac{1}{s(s+1)(s+6)}$$

比例增益 $K>0$ 与对象组成环路开环传递函数

$$L(s)=KG_0(s)=\frac{K}{s(s+1)(s+6)}$$

在单位负反馈下，闭环传递函数为

$$\Phi(s) = \frac{K}{s^3 + 7s^2 + 6s + K}$$

闭环特征方程为

$$s^3 + 7s^2 + 6s + K = 0$$

该对象具有三个开环极点，增益变化会使一对闭环极点逐步靠近虚轴。临界增益恰为 $K=42$；因此可以在一个连续参数区间内观察稳定、近临界、临界稳定和失稳四种状态。

### 2.2 复现方法

每次改变 $K$，依次使用 `pole` 或 `pzmap` 读取闭环极点，使用 `step` 观察单位阶跃响应，再使用 `margin` 读取环路开环的增益穿越频率、相位裕度和增益裕度。三个步骤必须使用同一个 $G_0(s)$、同一个 $K$ 和同一种单位负反馈约定。

### 2.3 观察框架：四个增益区段

为了有章法地观察而不是随机拖动参数，我们把 $K$ 的变化范围划分为四个区段。每个区段对应系统的一种典型状态：

<p align="center"><strong>表 1-5-1 四个观察区段</strong></p>

| 区段 | $K$ 范围 | 系统状态 | 三域预期特征 |
|------|:---:|------|------|
| I：低增益 | $3 \le K \le 6$ | 稳定余量充足 | 主导极点离虚轴较远，阶跃响应可收敛，相位裕度较大 |
| II：中增益 | $8 \sim 20$ | 振荡浮现，余量收缩 | 极点向虚轴靠近，超调明显增大，相位裕度显著下降 |
| III：高增益 | $22 \le K < 42$ | 接近稳定边界 | 极点逼近虚轴，振荡衰减缓慢，相位裕度趋近于零 |
| IV：边界与越界 | $K=42$；$K>42$ | 临界稳定；不稳定 | $K=42$ 时极点位于虚轴；继续增大后极点进入右半平面 |

你需要在这四个区段中各选至少一个代表性 $K$ 值，完成三域观察和记录。建议的具体取值在下文各节中给出。

## 三、区段 I：低增益——稳定余量充足

### 3.1 观察任务

取 $K = 3$。完成以下观察，并将结果填入记录表：

- **复平面**：闭环极点的位置在哪里？主导极点（离虚轴最近的一对或一个）的实部和虚部分别是多少？
- **时域**：单位阶跃响应的超调量和调节时间大约是多少？曲线形态是单调还是有振荡？
- **频域**：相位裕度大约是多少度？环路开环的增益穿越频率在什么位置？

### 3.2 参考观察结果

用以下代码获取三域数据：

```matlab
G0 = tf(1, [1 7 6 0]);               % 开环对象 G0(s) = 1/[s(s+1)(s+6)]
K = 3;

% 复平面——闭环极点
Phi = feedback(K*G0, 1);
p = pole(Phi);                        % 查看闭环极点数值
figure(1); pzmap(Phi);                % 极点-零点图
title(sprintf('闭环极点分布 K=%d', K));

% 时域——阶跃响应
figure(2); step(Phi);
title(sprintf('闭环阶跃响应 K=%d', K));

% 频域——Bode 图与稳定裕度
figure(3); margin(K*G0);              % Bode 图 + 增益/相位裕度标注
title(sprintf('环路开环 Bode 图 K=%d', K));
```

## 四、区段 II：中增益——振荡浮现，余量收缩

### 4.1 观察任务

取 $K = 12$。复现区段 I 的全部观察动作。此外，增加一个对比任务：将 $K=12$ 的阶跃响应曲线与 $K=3$ 的叠在同一张图上，用一句话描述两条曲线的核心差异。

### 4.2 参考观察结果

```matlab

Phi = feedback(K*G0, 1);

% 三域观察（同上）

figure(2); step(Phi); title(sprintf('闭环阶跃响应 K=%d', K));

% 叠加对比 K=3 和 K=12 的阶跃响应

figure(4); step(Phi3, Phi);

title('阶跃响应对比：K=3 vs K=12');
```

|------|------|:---:|------|

## 六、区段 IV：临界点与越界状态

### 6.1 观察任务

取 $K=42$。令特征方程中的 $s=j\omega$，分离实部与虚部可得

$$K-7\omega^2=0,\qquad 6\omega-\omega^3=0$$

非零振荡频率满足 $\omega=\sqrt{6}$，进而得到精确临界增益 $K=42$。此时闭环极点为 $-7$ 与 $\pm j\sqrt{6}$。验证任务是：

1. 确认阶跃响应中的振荡分量不再衰减，输出长期在约 $0.056$ 与 $1.944$ 之间振荡。
2. 确认增益穿越频率与相位穿越频率均为 $\sqrt{6}\ \mathrm{rad/s}$，相位裕度与增益裕度均为零。
3. 再取一个 $K>42$ 的值，确认共轭极点进入右半平面，振荡幅值随时间增大。

### 6.2 参考观察结果

```matlab
K = 42;
Phi = feedback(K*G0, 1);

% 复平面
figure(1); pzmap(Phi); title(sprintf('临界极点 K=%d', K));
% 极点为 -7 与 ±j*sqrt(6)

% 时域
figure(2); step(Phi); title(sprintf('临界阶跃响应 K=%d', K));
% 振荡分量不衰减，不存在有限调节时间

% 频域
figure(3); margin(K*G0); title(sprintf('临界 Bode K=%d', K));
% 相位裕度为 0°，增益裕度为 0 dB
```

<p align="center"><strong>表 1-5-5 区段 IV 临界状态的三域信号</strong></p>

| 域 | 临界信号 | 意味着 |
|------|------|------|
| 复平面 | 极点 $\pm j\sqrt{6}$ 位于虚轴，另一个极点为 $-7$ | 系统处于稳定与失稳的分界线 |
| 时域 | 阶跃响应含不衰减的周期分量 | 不存在有限的调节时间 |
| 频域 | 相位裕度 $0^\circ$，增益裕度 $0$ dB | 任一额外不利变化都可能越过边界 |

**三域一致性检查**：极点到达虚轴（复平面）→ 响应不收不放（时域）→ 相位裕度归零（频域）。三域在临界点上给出了完全一致的判决。这不是某一域的计算误差——这是同一物理事实在三个窗口中的同步呈现。

<p align="center"><strong>图1-5-4 K=42 的临界状态</strong></p>

共轭极点准确位于虚轴而不是“紧贴”虚轴；阶跃输出持续振荡，环路幅值在相位为 $-180^\circ$ 时恰好为 $0$ dB。

## 九、例题：为什么 $K=36$ 比 $K=12$ 更接近失稳

### 例题 1-5-1 三域证据链的一致性检查

已知该对象在 $K=12$ 和 $K=36$ 时的三域数据（见表1-5-6）。请判断哪一组更接近失稳边界，并按“复平面 → 时域 → 频域”的顺序写出证据链。

**解**

按三域顺序逐一比对：

1. **复平面**：$K=36$ 时主导极点实部为 $-0.06$，比 $K=12$ 时的 $-0.32$ 更接近虚轴。极点越靠近虚轴，系统越接近失稳——这是 1-2 建立的基本判断。

2. **时域**：$K=36$ 时超调约 $87.81\%$，5% 调节时间约 $52.44$ s——远大于 $K=12$ 时的 $45.59\%$ 和 $8.05$ s。超调更大、衰减更慢，说明闭环振荡模态更接近不衰减状态。

3. **频域**：$K=36$ 时相位裕度仅约 $3.12^\circ$，而 $K=12$ 仍有 $27.41^\circ$。在其他条件不变时，额外约 $3.12^\circ$ 的不利相位滞后就足以把 $K=36$ 的相位裕度降为零。

三条证据完全一致，指向同一结论：**$K=36$ 比 $K=12$ 更接近失稳边界。** 这种三域一致性不是巧合——增益增大同时改写了极点位置、时域形态和频域余量，因为三者归根结底由同一个闭环特征方程决定。

## 十一、总结与扩展思考

这组增益扫描留下三条可迁移的判断。

**先确认对象和通道。** 闭环极点与阶跃响应来自 $\Phi(s)=L(s)/[1+L(s)]$，稳定裕度来自环路开环 $L(s)$。三域共享同一个反馈结构，但指标定义不同。

**“快”至少有三种含义。** 上升时间描述第一次到达目标附近的速度，调节时间描述误差进入并保持在容差带内的速度，增益穿越频率描述环路开环的频率尺度。本例中三者随 $K$ 增大并不朝同一方向变化。

**临界点必须在三域中同时成立。** $K=42$ 时，闭环极点位于虚轴、阶跃振荡不衰减、相位裕度和增益裕度均为零；$K>42$ 时，共轭极点进入右半平面。任何只在一张图上成立的“临界”判断都需要重新核查。

**扩展思考。** 本例的超调量随 $K$ 增大而增加，相位裕度随 $K$ 增大而减小。这种单调性不是所有对象的普遍定理。加入零点或其他高阶模态后，超调量和调节时间都可能出现非单调变化；稳定性仍应由闭环极点或等价判据判断。

**习题 1**：（a）复平面。（b）时域。（c）频域。

**习题 2**：复算结果为：$K=5$ 时相位裕度约 $49.15^\circ$；$K=20$ 时主导极点实部约 $-0.225$；$K=38$ 时超调量约 $90.10\%$，相位裕度约 $2.02^\circ$。用相邻样本插值只能估计范围，最终数值应由对应模型计算。

**习题 3**：（c）$K=6$ 属于区段 I，$K=18$ 属于区段 II，$K=30$ 属于区段 III，$K=42$ 是区段 IV 的临界点。最后一条阶跃曲线不会收敛，因此不能报告有限调节时间。

**习题 4**：三项数据均对应 $K\approx18$。精确复算得到主导极点 $-0.2485\pm j1.6451$、超调量 $60.18\%$、相位裕度 $17.99^\circ$。不能只凭其中一项断言参数值；三项同时吻合才构成一致证据。

**习题 5**：（a）增大 $K$ 后，闭环最初到达目标附近的时间缩短，环路增益穿越频率也提高；与此同时，主导极点实部从 $-0.452$ 变为 $-0.324$，振荡包络衰减变慢，因此 5% 调节时间略有延长。增益穿越频率是环路开环指标，不能直接称为闭环“能跟随的最高频率”。（b）至少要区分上升速度与收敛速度；若讨论频域，还应把环路增益穿越频率与闭环带宽分开。

**习题 6**：（a）$K_{\text{crit}}=42$，临界频率为 $\sqrt{6}\ \mathrm{rad/s}$，闭环极点为 $-7$ 与 $\pm j\sqrt{6}$。（b）虚轴极点产生不衰减振荡，输出没有极限，5% 调节时间不存在；虽然数值曲线长期约在 $0.056$ 与 $1.944$ 之间振荡，但以最终稳态值为基准的稳定系统超调指标已不再适用。（c）新特征多项式为 $s^3+7s^2+(6+K)s+2K$。对 $K>0$，Routh 条件 $7(6+K)>2K$ 恒成立，因此闭环对所有正增益都稳定，不存在有限的正临界增益。这个结论也说明“增加左半平面零点通常提高临界增益”不能替代具体计算。

**习题 7**：$G_1(s)$ 的闭环特征多项式为 $s^3+7s^2+10s+K$。Routh 条件给出 $0<K<70$，所以 $K_{\text{crit}}=70$；临界极点为 $-7$ 与 $\pm j\sqrt{10}$。可选取 $K=5,25,55,70$ 作为四个代表点。与表1-5-6相同的是：稳定边界必须同时表现为虚轴极点、不衰减振荡和零相位裕度；不同的是具体临界增益、极点轨迹、超调量和调节时间，不能从原对象直接移植。
