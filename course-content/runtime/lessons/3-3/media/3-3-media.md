# handout.md

本讲义详细阐述了控制系统中**根轨迹分析法**的核心理论与应用技巧。内容重点讲解了绘制根轨迹的基本**数学准则**，包括如何确定**开环极点**、**零点**以及计算**渐近线**的交点和角度。通过具体的**传递函数**实例，演示了系统参数变化对闭环极点分布的影响。此外，资料还探讨了**广义根轨迹**的概念，并解释了在不同相位条件下如何利用**特征方程**进行系统稳定性分析。这套教学课件旨在指导学生掌握分析**闭环系统动态性能**的图解工具。
