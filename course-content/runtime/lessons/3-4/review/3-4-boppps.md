# 单元 3-4 BOPPPS 课案

**标题**：根轨迹读图与对象化验证：把法则真正用到主图、参数窗口与工程后果上
**课型**：实践主线课
**总学时**：90 分钟

本课承接 `3-3` 已经建立的普通根轨迹法则，但不再把课堂重心放在“证明规则”上，而是把那套法则压缩成一条可执行的判断链：先读关键节点，再判参数窗口，再完成增益换算，最后用时域与频域证据回查主图判断。整节课围绕同一个船舶航向控制对象推进，最终要让学生留下三份可提交的记录：`关键节点读图记录`、`参数窗口判断表`、`对象化验证记录`。

## B｜Bridge-in 场景导入（8 min）

导入不从“今天继续学根轨迹规则”开始，而从一个更贴近工程判断的问题切入：如果系统还稳定，是否就可以直接说它是好方案？教师可以先播放 `3-4-intro-video.mp4`，或展示封面漫画与根轨迹主图，让学生看到 A、B、C 三个版本都仍落在稳定区内，却已经表现出明显不同的气质。这样一来，“稳定只是下限，不是结论”便成为本课的共同起点。

教师板书本课主线：

```text
关键节点 -> 参数窗口 -> 增益换算 -> 三域验证
```

此处要明确边界：本课不重讲 `3-3` 的法则证明，也不提前进入零点、`PD` 或模块 4 的设计任务。学生首先需要建立的，是面对一张主图时应怎样读，怎样写，怎样验证。

## O｜Objective 课堂目标（4 min）

本课目标不宜写成抽象口号，而应与学生可见的课堂动作对应：

- 学完本节，我能按固定顺序读取根轨迹主图中的关键节点，而不是凭感觉挑点。
- 学完本节，我能区分“稳定窗口”和“可接受窗口”，并写出带证据的参数判断。
- 学完本节，我能把根轨迹图上的增益 `k` 正确换算成实际控制器增益 `K`。
- 学完本节，我能用时域与频域结果回查主图判断，形成对象化三域验证结论。

教师要让学生明白：这节课不是把 `3-3` 再重复一次，而是把“为什么这样走”的理论，推进到“怎样按图做判断”的实践层。下一课 `3-5` 之所以引入零点，也正是因为今天的方法已经暴露出“只调增益”的边界。

## P₁｜Pre-assessment 前测（6 min）

前测的作用，是让学生暴露他们最可能带进课堂的误判。形式可以采用举手投票加平台快答，问题不宜多，但应足够尖锐：

- 如果一个参数版本还在稳定区内，你会不会直接把它判成“可用”？
- 图上读到的增益，是否一定就是实际控制器增益？
- 你更倾向于先看根轨迹、时域还是频域来判断版本差异？

根据回答分布，教师可以即时调节课堂重心：若多数学生把“稳定”直接等同于“可用”，则在后续窗口判断环节加重“稳定窗口 vs 可接受窗口”的训练；若多数学生混淆 `k` 与 `K`，则在增益换算处增加一次集体板书；若多数学生只盯时域图，则在三域验证环节先把他们拉回主图，避免只凭一张响应曲线下结论。

## P₂｜Participatory Learning 主体教学（62 min）

### 段 1｜固定读图顺序（10 min）

教师先投出 `3-4-root-locus-summary.png`，把注意力统一到同一个对象上，再带学生走过一次固定读图顺序：先看骨架，再找分离点、虚轴交点和主导极点候选，再讨论窗口，最后才落回参数和后果。这一段的目标不是立即得出最佳答案，而是让全班形成同一种观察语言。

学生在这一段最常见的反应，是想立刻说“B 看起来最合适”。教师不必直接否定，而应追问：“你是从哪一个关键节点开始读出这个结论的？”这样既能压住仓促下结论的冲动，也能让后续实践活动有明确的入口。

### 段 2｜关键节点标注实践（18 min）

学生个体在平台上查看主图，圈出分离点、虚轴交点与主导极点候选，并填写 `关键节点读图记录`。这一段不要求学生一开始就把结论说得完整，而是先把“图上真正关键的位置”找准。

教师巡视时重点关注三种偏差：只找了一个点，却没有形成整条读图链；把“靠左”直接读成“更好”；忽视虚轴交点，把稳定边界当作模糊印象。汇总时，可以把“只找点位”和“能把点位连成窗口判断”的差别明白地展示出来，让学生意识到这节课要学的并不是“认点”，而是“用点”。

### 段 3｜参数窗口判断与增益换算（18 min）

这一段是本课最具工程意味的部分。学生需要根据主图和窗口卡片填写 `参数窗口判断表`，并把图上的 `k` 正确换算为实际控制器增益 `K`。建议先让学生独立完成，再引入 AI 或同伴做一次对照检查，核对换算链是否完整，而不是直接代替学生算出答案。

教师随后展示两类典型错误：一种只写“还稳定”，却没有说明窗口位置与代价；另一种把 `k` 直接当成 `K`。这里要特别强调，稳定窗口只是底线语言，可接受窗口才是工程判断语言。要求学生至少写出一句完整表达：它位于稳定窗口的哪里、它在可接受窗口中的位置如何、它换来的代价又是什么。

### 段 4｜对象化三域验证（16 min）

当学生已经拥有主图语言和窗口语言之后，再带他们回到 `3-4-step-compare.png` 与 `3-4-bode-compare.png`。这一段不是另开一节时域课或频域课，而是让学生看见：主图上的判断如何被对象的时域与频域表现支撑，哪些风险会先在频域暴露，哪些平衡点能在主导极点近似下得到解释。

分组讨论时，教师可以反复追问三件事：哪一个域最早暴露 C 的风险？为什么 B 的主导极点近似在这里仍可接受？为什么 A 不能因为“更稳”就直接更优？学生的 `对象化验证记录` 至少应写出一条完整证据句，把“图上读法”和“对象后果”明确连起来。

## P₃｜Post-assessment 后测（6 min）

后测仍围绕本课主线组织，不另起主题。可以直接使用以下三题：

- 为什么“还稳定”不足以构成完整工程判断？
- 若图上读得 `k=0.0104`，实际控制器增益 `K` 应是多少？
- A/B/C 中谁更适合作为参考工作点？请说出至少两条证据。

反馈时不必面面俱到，只抓错得最多的题。教师应要求学生回答时至少带出“关键节点 / 窗口 / 换算 / 三域”中的两个关键词，让他们把零散记忆压回同一条判断链。

## S｜Summary 总结（4 min）

总结不宜写成长串条目，而应回到一句清楚的话：`3-4` 的核心不是“继续讲法则”，而是把法则压成稳定的读图动作。今天学生学会的，不只是看懂一张图，而是用关键节点、参数窗口、增益换算和三域验证，把主图读成有证据的工程判断。下一课 `3-5` 将进一步说明：为什么只调增益很快就会走到边界，结构改变因此变得必要。

## 课前与课后

**课前准备**
复习 `3-3` 中“分离点、虚轴交点、主导分支”的意义，并准备一句“为什么知道轨迹怎样走还不够”的回答。

**课后作业**
以本课对象为例，分别完成 `关键节点读图记录`、`参数窗口判断表`、`对象化验证记录` 三张表；要求窗口判断中必须写出 `k -> K` 的换算链。
