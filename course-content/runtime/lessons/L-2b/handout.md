## 一、引入：上节课留下的问题

上节课（L-2a）我们认识了一件重要的事：**极点的位置决定系统的行为**。

复平面左半侧的复数极点 $s = -\sigma \pm j\omega_d$，对应振荡衰减的响应曲线——实部 $\sigma$ 越大，衰减越快；虚部 $\omega_d$ 越大，振荡越快。对于船舶航向控制，我们观察到：极点太靠近虚轴，船就会长时间来回摇摆；极点太靠近实轴，船又反应迟钝。

这引出了一个自然的问题：

> **我能不能主动"移动"极点，把它放到一个更好的位置？**

答案是肯定的。工程中最直接的手段，是调节一个叫做**增益**的参数——相当于给系统的"控制力度旋钮"拧大拧小。今天的核心问题就是：

**旋钮转动时，极点会怎么走？**

### 从"时间轨迹"到"复平面轨迹"

"轨迹"这个词，在 L-2a 中已经出现过——响应曲线 $y(t)$ 就是系统输出在**时间轴**上走过的轨迹。

今天我们要换一个视角：不看输出随时间怎么走，而看**极点随增益怎么走**。

| | L-2a 的轨迹 | L-2b 的轨迹 |
|:---:|:---:|:---:|
| **横轴** | 时间 $t$（秒） | 复平面实部 $\sigma$ |
| **纵轴** | 输出 $y$（度） | 复平面虚部 $j\omega$ |
| **变化的量** | 时间流逝 | 增益 $K$ 从小到大 |
| **点的含义** | 某时刻的输出值 | 某增益下的极点位置 |

两种轨迹的区别：一个是系统输出在时域里的运动，另一个是系统极点在复平面上随参数扫描的运动。**根轨迹指的是后者**。

## 二、核心内容

### 2.1 一个必须先说清楚的问题：为什么调"开环增益"，看"闭环极点"？

> 这是工程师的真实困惑，不是绕弯子。

回忆 L-1 中的船舶航向控制系统：
- **控制器**发出舵角指令
- **船**根据指令转动，产生实际航向
- **传感器**测量实际航向，反馈给控制器

这个"测量→比较→纠正"的闭合回路，就是**闭环系统**。我们关心的"系统是否稳定、响应好不好"，说的是整个闭环的行为——因此看**闭环极点**。

但增益 $K$ 在哪里？它在控制器里，放大误差信号的倍数。**控制器还没和船构成回路之前**，增益是"开环"的一部分——因此调的是**开环增益**。

用一个比喻来说：
> 你调收音机音量旋钮（开环增益），改变的是整个房间里的声音效果（闭环表现）。旋钮本身在信号进入扬声器之前就起作用，但你听到的效果是整个系统的输出。

**简洁版记忆**：开环增益是"我们手里的旋钮"，闭环极点是"旋钮拧动后系统的实际状态"。根轨迹告诉我们：旋钮从0拧到∞，极点怎么走。

→ 完整的开环/闭环数学关系见单元 2-3。

---

### 2.2 旋钮转动时，极点怎么走？

以一个简化的船舶航向控制系统为例。开环传递函数为：

$$G(s) = \frac{K}{s(s+2)}$$

其中 $K$ 是增益旋钮。闭环传递函数的极点由以下方程决定：

$$s^2 + 2s + K = 0$$

→ 完整推导见单元 2-3；这里只看结果。

对不同的 $K$ 值，求解上式，得到极点位置：

| 增益 $K$ | 极点 $s_{1,2}$ | 极点类型 | 对应响应 |
|:---:|:---:|:---:|:---:|
| $K = 0$ | $s = 0,\ s = -2$ | 两个负实极点 | 单调上升，无超调 |
| $K = 0.5$ | $s = -0.29,\ s = -1.71$ | 两个负实极点 | 单调上升，较快 |
| $K = 1$ | $s = -1 \pm 0j$ | 重实极点（临界） | 最快无超调 |
| $K = 2$ | $s = -1 \pm j$ | 复数极点 | 振荡衰减，小超调 |
| $K = 5$ | $s = -1 \pm 2j$ | 复数极点 | 振荡衰减，中超调 |
| $K = 10$ | $s = -1 \pm 3j$ | 复数极点 | 振荡衰减，大超调 |

![极点随K变化的迁移轨迹图](/course-runtime/lessons/L-2b/media/sh-01-pole-migration-locus.svg)

两个关键观察：

**观察1**：实部始终是 $-1$，不随 $K$ 变化。这意味着无论增益多大，这个系统的**衰减速度不变**（调节时间固定）。

**观察2**：虚部随 $K$ 增大而增大，振荡频率加快，超调量增大。

这两条轨迹合在一起，就是该系统的**根轨迹**。

---

### 2.3 根轨迹是"设计可行域地图"

根轨迹图的每一个点，对应一个特定的 $K$ 值，也对应一组特定的时域响应特征。

工程师用它来回答：**"在这个系统结构下，我最好能做到什么？"**

![根轨迹性能分区图](/course-runtime/lessons/L-2b/media/sh-02-root-locus-performance-zones.svg)

注意根轨迹的**边界含义**：
- 根轨迹在左半平面 → 所有 $K$ 值下系统稳定
- 若根轨迹越过虚轴进入右半平面 → 某个 $K$ 以上系统不稳定，有增益上限

> 航运工程视角：不能因为追求"响应快"就把增益调到极限——超过稳定边界的船，不是快船，是危险船。

### 2.4 挑战任务：找到最佳阻尼比

L-2a 中我们了解到：阻尼比 $\zeta = 0.707$ 是一个特殊值——它对应约 4.3% 的超调量，在"不超调"与"响应快"之间取得最优平衡，被称为**最佳阻尼比**。

现在有一个具体的问题：

> **对于上述船舶控制系统 $G(s) = \frac{K}{s(s+2)}$，能否找到一个增益 $K$，使闭环系统的阻尼比恰好等于 0.707？**

**几何方法（直觉版）**：

在根轨迹图上，$\zeta = 0.707$ 对应一条特定的射线。

阻尼比与极点位置的关系为：

$$\zeta = \frac{\sigma}{\sqrt{\sigma^2 + \omega_d^2}} = \cos\theta$$

其中 $\theta$ 是极点到原点连线与负实轴的夹角。$\zeta = 0.707$ 时，$\theta = 45°$。

→ 完整推导见单元 1-3。

![根轨迹+45°射线定位最佳阻尼比](/course-runtime/lessons/L-2b/media/sh-03-root-locus-optimal-damping.svg)

射线与根轨迹的交点即为目标极点：$s = -1 \pm j1$。

对应的增益：代入特征方程 $s^2 + 2s + K = 0$，得：

$$K = \sigma^2 + \omega_d^2 = 1^2 + 1^2 = 2$$

**结论**：将增益调至 $K = 2$，系统阻尼比恰好为 $\zeta = 0.707$，超调量约 4.3%。

→ 完整的阻尼比与极点位置推导见单元 1-3；根轨迹精化（含8条绘制规则）见单元 2-3。

[AI融入点]：在求解之前，先预测：你认为需要把增益调大还是调小，才能让系统从"无超调"变为"4.3%超调"的最佳状态？记录你的预测，用 $K=0.5$、$K=1$、$K=2$ 三个值向AI提问，对比实际极点位置与你的预测。

## 三、例题精解

### 例题1（验证性）：读懂一张根轨迹图

**题目**：某闭环控制系统的根轨迹如下图所示。开环零点为 $s=-3$，开环极点为 $s=0$ 和 $s=-5$。

![例题1根轨迹图（零点-3，极点0/-5）](/course-runtime/lessons/L-2b/media/h-04-example1-root-locus.svg)

根据此图回答：

（1）当 $K$ 很小（接近0）时，闭环极点在哪里？对应什么样的时域响应？

（2）当 $K$ 增大到极点分叉后，系统的时域响应会有什么变化？

（3）从根轨迹图判断：对于任意 $K>0$，该系统是否始终稳定？

**解题过程**：

**（1）K→0 时的极点**

$K=0$ 时，闭环极点趋近于开环极点位置：$s=0$ 和 $s=-5$。

$s=0$ 在虚轴上，对应系统响应不稳定（积分器行为）。实际上 $K$ 不能取0，这是理论边界。$K$ 略大于0时，极点进入左半平面，系统稳定，响应单调缓慢上升。

**（2）K增大后的变化**

两极点相向移动，在 $s=-2.5$ 处相遇，之后分叉为共轭复数极点。实部固定在 $-2.5$，虚部增大。

响应变化：由单调上升（无超调）→ 振荡衰减（出现超调）。超调量随 $K$ 增大而增大，但衰减速度由实部 $\sigma=2.5$ 决定，保持不变。

**（3）稳定性判断**

根轨迹的两支均在左半平面延伸（虚轴方向），始终不穿越虚轴。因此对任意 $K>0$，系统稳定。这是一个**无条件稳定**系统的典型根轨迹形态。

**工程意义**：即使把增益调得很大，这个系统也不会失稳——只会越来越"震荡"。但震荡本身会带来舒适性问题，工程上仍需限制增益。

### 例题2（拓展性）：增益上限与稳定边界

![三阶系统根轨迹与虚轴穿越点（例题2）](/course-runtime/lessons/L-2b/media/h-05-example2-root-locus-crossing.svg)

**题目**：某船舶航向控制系统开环传递函数为：

$$G(s) = \frac{K}{s(s+1)(s+3)}$$

已知该系统存在一个临界增益 $K_c$，当 $K > K_c$ 时系统不稳定（根轨迹穿越虚轴）。

（1）在根轨迹图上，穿越虚轴的点意味着什么？

（2）若已知虚轴穿越点的坐标为 $s = \pm j\sqrt{3}$，利用特征方程求临界增益 $K_c$。

（3）从工程角度，为什么要在 $K_c$ 的基础上再留出一定裕度，而不是恰好取 $K = K_c$？

**解题过程**：

**（1）虚轴穿越点的含义**

根轨迹上的点代表某个 $K$ 值下的闭环极点。当极点恰好在虚轴上（实部为零）时，系统处于**临界稳定**状态：输出既不增长也不衰减，产生等幅持续振荡。

穿越虚轴后进入右半平面，系统不稳定，输出发散。

**（2）求临界增益**

系统特征方程为（闭环）：

$$s(s+1)(s+3) + K = 0$$

展开：

$$s^3 + 4s^2 + 3s + K = 0$$

将 $s = j\sqrt{3}$ 代入（虚轴穿越点条件）：

$$(j\sqrt{3})^3 + 4(j\sqrt{3})^2 + 3(j\sqrt{3}) + K = 0$$

$$-j3\sqrt{3} - 12 + j3\sqrt{3} + K = 0$$

$$K - 12 = 0 \implies K_c = 12$$

> **计算提示**：一般三次特征方程没有简洁的手工求根公式。实际工程中通常用计算器或软件求解。MATLAB命令：`roots([1 4 3 K])` 可直接给出不同 $K$ 下的闭环极点。→ 完整推导方法（劳斯判据）见单元 2-1。

**（3）为什么需要稳定裕度**

$K = K_c = 12$ 是**数学上**的临界点，但工程中永远存在：
- 模型误差（实际船舶参数与模型不完全吻合）
- 环境扰动（风浪改变等效增益）
- 元器件老化（传感器精度下降）

若恰好取 $K = K_c$，任何微小扰动都可能将系统推入不稳定区域。因此工程实践中通常取 $K \leq K_c / (安全系数)$，预留**增益裕度**。

这正是后续课程中"相位裕度"和"增益裕度"概念的工程动机——→ 完整内容见单元 L-2c 和 2-5。

## 四、本节小结与前后衔接

### 核心要点

1. **根轨迹是极点的参数轨迹**：横轴是增益 $K$，轨迹上每个点是某个 $K$ 对应的闭环极点位置——不是时间轨迹，是参数扫描轨迹。

2. **开环增益是旋钮，闭环极点是结果**：调节开环增益，改变的是整个闭合回路的极点；根轨迹图描述了这一对应关系的全貌。

3. **根轨迹是设计可行域地图**：轨迹上每个点代表一种可实现的极点配置，工程师通过在轨迹上选点来确定增益。

4. **ζ=0.707 对应根轨迹上的45°射线**：最佳阻尼比可以用几何方法在根轨迹图上直接定位，对应唯一的增益值。

5. **稳定边界不能触碰，更不能逾越**：根轨迹穿越虚轴的点是临界增益，工程实践中必须预留裕度，不能恰好工作在边界上。
