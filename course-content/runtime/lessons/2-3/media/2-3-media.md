# handout.md

该教学文档详细介绍了**自动控制系统**中的**频率特性分析**，重点探讨了系统如何响应不同频率的信号。通过对比**低频指令**的高保真跟踪与**高频扰动**的显著抑制，说明了物理系统对输入信号具有选择性的过滤作用。文中提供了关键的**数学模型**，阐述了如何利用复频域转换将传递函数 $G(s)$ 变为频率响应函数 $G(j\omega)$，以此计算输出信号的**幅值衰减**与**相位滞后**。此外，资料还包含丰富的**可视化图表**与 **MATLAB/Octave 代码**示例，直观展示了典型环节（如比例、积分、惯性环节）在正弦输入下的稳态表现。这些内容旨在帮助学习者掌握 **Bode 图**与 **Nyquist 图**的理论基础，从而更有效地进行系统性能分析。
