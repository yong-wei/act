BOPPPS 课案 | 单元 3-8：频域判别与跨域综合语言
课型：理论 | 总学时：90 分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

B｜Bridge-in 场景导入（8min）
  形式：路径定位 + 四图并排判断
  对应页面：`step-01`、`step-02`
  内容描述：
  - 先用路径图回收 `3-5` 的零点动态改善线与 `3-7` 的低频补偿线，立住“3-8 不是新章，而是统一翻译器”。
  - 再用 `3-8-gain-effect.png`、`3-8-zero-effect.png`、`3-8-pole-effect.png`、`3-8-rhp-zero-effect.png` 并排抛出问题：同样是结构变了，为什么频域指纹完全不同。
  教师操作：
  - 只追问“先改写哪一段频率、相位代价在哪里”，不先报判据结论。
  - 当学生把判断缩成“曲线抬高了”时，立即压实“还要看相位与频带”。

O｜Objective 课堂目标（4min）
  呈现方式：翻译链卡 + 边界表
  对应页面：`step-03`
  目标描述：
  - 学完本节，我能把增益、零点、积分/滞后和非最小相变化翻译成频域指纹。
  - 学完本节，我能按 `P -> N -> Z` 的顺序用 Nyquist 图做基本判稳。
  - 学完本节，我能用 Bode 图读截止频率、相角裕度、增益裕度，并说明它与 Nyquist 判稳说的是同一件事。
  - 学完本节，我能按低频/中频/高频三段分工，把频域量读回稳态精度、速度、超调与高频代价。
  边界提醒：
  - 本课不重讲模块 2 的作图基础。
  - 本课不进入模块 4 的完整整定与优化排序。

P₁｜Pre-assessment 前测（6min）
  形式：平台四题前测 + 一句理由
  对应页面：`step-04`
  测试内容：
  - 增益提升与积分补偿是否优先改写同一段频率。
  - Nyquist 判稳是否可以不先数开环右半平面极点数。
  - 截止频率更大是否自动意味着系统更好。
  - 非最小相对象是否可以靠更大带宽直接压过去。
  根据结果的教学调整策略：
  - 若多数学生把“更大截止频率”直接等同于“更优系统”，则在后续 Bode 与三频段部分加强“中频余量”和“高频代价”的收束。
  - 若多数学生跳过 `P` 直接数包围圈，则在 Nyquist 部分增加一次顺序重述。

P₂｜Participatory Learning 主体教学（64min）

- 频域翻译段（10min）
  对应页面：`step-05`
  - 先落“结构变化 -> 主要频带 -> 收益与代价”的总表，再处理例题 1。
  - 固定学生动作：先判哪一段频率被改写，再说系统更快、更稳还是代价更高。
  - 教师介入点：当学生只说“增益大了/积分强了”而不说频带时，要求其回到总表。

- Nyquist 统一段（16min）
  对应页面：`step-06`、`step-07`
  - 先从 `F(s)=1+L(s)`、幅角原理和临界点 `(-1,0)` 把来路讲清。
  - 再用 `3-8-nyquist-quickcheck.png` 与 `3-8-nyquist-example.png` 压实 `P -> N -> Z` 的固定顺序。
  - 教师介入点：
    - 学生把右半平面零点误写成右半平面极点时，立即纠偏。
    - 学生把“靠近边界”误判成“已经失稳”时，要求回看判稳表。

- Bode 与三频段段（18min）
  对应页面：`step-08`、`step-09`
  - 用 `3-8-bode-example.png` 固定四类线：截止频率线、相位穿越频率线、PM 线、GM 线。
  - 明确“开环读余量，闭环看带宽”，把 Bode 判稳与 Nyquist 判稳重新接回同一稳定边界问题。
  - 再用 `3-8-three-band-overview.png` 和目标切换卡说明：低频看精度，中频看速度与边界，高频看代价。
  - [AI融入点]
    - 学生先独立写出“目标切换后应优先改哪一段频带、重点看哪两个频域量”。
    - 再进入 AI 对照区，核对自己的频带判断链。

- 工程案例段（20min）
  对应页面：`step-10`、`step-11`
  - 航向控制案例：
    - 先看基线 2×2，确认问题主要落在中频余量偏小。
    - 再把 `M_p`、`t_s` 逐步翻译成目标阻尼比、目标相角裕度和目标截止频率。
    - 最后对照超前校正后的 2×2 图与指标表，说明为什么中频超前能同时更快且更稳。
  - 稳定平台案例：
    - 先用结构图说清对象与三方案来源。
    - 再比较“激进基线 / 仅降增益 / 超前校正”三方案，压实“只降增益不够”的结论。
  - 教师介入点：
    - 当学生只会背结论“超前更好”时，必须要求指出主改频带和对应频域量。
    - 当学生把“降增益更稳”误当成“更优”时，要求同时比较速度损失。

P₃｜Post-assessment 后测（4min）
  形式：平台快答 + 一句出口反思
  对应页面：`step-12`
  测试内容：
  - `P/N/Z` 顺序题。
  - 截止频率和稳定裕度关系题。
  - 目标切换下的频带优先级题。
  - 非最小相边界直觉题。
  反馈方式：
  - 教师按“顺序仍乱”“频带仍乱”“截止频率与带宽混淆”三类剩余问题快速点评。

S｜Summary 总结（4min）
  方式：四条结论卡 + 去向卡
  对应页面：`step-12`
  核心要点：
  - 频域是统一翻译器，不是新章孤岛。
  - Nyquist 与 Bode 说的是同一个稳定边界问题。
  - 低频、中频、高频分别承担精度、速度与代价判断。
  - 真正有效的校正不是盲目改增益，而是定向改写关键频带。
  下节预告：
  - `3-9` 将把今天的频域判断链放到同一对象的多版本综合映射中。
  - 模块 4 将在此基础上进入约束驱动的设计行动。
