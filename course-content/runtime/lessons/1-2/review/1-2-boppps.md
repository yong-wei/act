BOPPPS 课案 | 单元 1-2：建模——从真实对象到可分析的系统
课型：理论 | 总学时：2h（90分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

B｜Bridge-in 场景导入（5min）
  形式：问题抛出 + 两种现象对比
  内容描述：展示船舶航向修正的三种表现（平稳靠近 / 先冲过头再摆回 / 越调越偏），紧接着反问——"但一个 RC 电路和一个热水箱，物理上毫无关系，为什么行为几乎一样？"两种现象并置，自然引出"在对象差异之下有一套统一语言"——这就是建模。
  教师操作：投影片展示两种现象对比 → 读出讲义开篇核心句"建模，就是把这套语言建立起来的过程" → 宣读三个课程目标（用自己的话概括"下课时你能做三件事……"）

O｜Objective 课堂目标（2min）
  呈现方式：PPT 展示或板书
  目标描述：
  - 区分机理建模和数据驱动建模，说出各自优势与边界
  - 从简单物理对象写出微分方程，解释其作为建模起点的优势和局限
  - 说出传递函数的核心思想——为什么能把微分运算变成代数运算
  - 读懂方框图和信号流图，识别串联、并联、反馈
  - 把模型→极点→复平面→行为连成完整判断链
  与全局框架的连接："1-1 你看到了整门课的地图。1-2 你回到地图上的第一个标记——建模。今天你要在一个课次内走完建模专题的全部地形。"

P₁｜Pre-assessment 前测（3min）
  形式：口头提问
  测试内容：
  1. "闭环控制与开环控制的根本区别是什么？"（目标：能说出闭环会利用输出信息持续修正控制动作）
  2. "若一个物理量随时间变化，只知道当前数值够不够？还需要什么信息？"（目标：意识到动态过程还需要变化率或变化趋势）
  3. "在平面直角坐标系中，点 (-2, 3) 的横坐标是多少？"（目标：确认学生能读取坐标中的横向位置）
  根据结果的教学调整策略：如果闭环/开环概念混淆，在建模两路径前用 1-1 的反馈示意做 1 分钟回看。如果学生对动态量和坐标读取不熟，在进入微分方程和复平面前分别补一句"变化率描述运动"和"横轴位置决定靠左还是靠右"。前测只检查进入建模专题所需的基础，不提前考察传递函数、极点或复平面行为规则。

P₂｜Participatory Learning 主体教学（70min）

  【段一：建模两条路径——概念引入】10min

  - 机理建模（5min）：从船舶例子自然过渡——"舵角→力矩→角速度→航向角，每一步都有物理定律。这就是机理建模。"口头强调三个关键词：可解释、每一项有物理含义、太复杂时写不出。
  - 数据驱动建模（3min）：一句话讲清——"给数据、训模型、出预测。"强调代价——"超出训练范围可能不靠谱。"
  - 收束（2min）："本课程以机理建模为主线。数据驱动在模块5再见。"
  教师操作：展示图1-2-1（两条路径对照），口头讲，不逐字念讲义。

  【段二：微分方程——概念引入 + 定量推导】15min

  - 船舶方程建立（3min）：黑板上写出 Jθ̈+Bθ̇=Ku，逐项解释物理含义。不推导——说"牛顿第二定律告诉我们……"直接给出。
  - 直接求解演示（9min）：这是本段教学锚点。取 J=1, B=2, K=5，在黑板上或页面上逐步展示：齐次解→猜特解→定系数→完全解 θ(t)=2.5t-1.25+1.25e^(-2t)。每步标注"换输入→重来"。
    展示图1-2-3（响应曲线）——"输出不是收敛到常值，而是持续增长。你花了这么大功夫，得到的结论用传递函数几秒就能看到。"
  - 四个不便总结（3min）：口头概括——换输入重来 / 串联变复杂 / 不同对象不好比 / 频域不好做。
  教师操作：求解过程在黑板上走，不要只放 PPT。让学生感受到繁琐——"如果你觉得繁琐，那就对了。这正是传递函数存在的理由。"

  【段三：传递函数——概念引入 + 定量推导】20min

  - 拉氏变换基本规则（5min）：展示表1-2-1，口头强调核心规律——"对时间求一次导→乘 s，两次导→乘 s²。这就是传递函数全部的秘密。"不展开积分定义，不推导反变换。
  - 三步法现场推导（10min）：黑板上完整走一遍——方程→变换→比值——每一步停在关键等式上 3 秒。
    走到 G(s)=K/(Js²+Bs) 时，把微分方程和传递函数并排展示——"左边是三个物理参数混在导数里的方程，右边是一个紧凑代数分式。同一个系统，两种语言。"
    走到 G(s)=(K/J)/[s(s+B/J)] 时，指着 s 说"积分效应"，指着 s+B/J 说"阻尼"——为极点埋伏笔。
  - 含义与迁移（5min）：两个核心含义口头概括——"G(s) 描述系统本身，与输入无关"；"分母结构暴露系统内在信息"。跨对象迁移用 RC 电路 vs 热水箱一句话带过。
  教师操作：推导全程在黑板上走，不依赖 PPT。展示图1-2-4（三列转换链）。关键停顿：在 G(s) 表达式处停 5 秒——"这是今天最重要的一个公式。后续所有内容都从它开始。"

  【段四：方框图与信号流图——概念引入】10min

  - 方框图（6min）：展示图1-2-5，从参考输入开始，逐环节走一遍闭环回路。三种连接各一句话——"串联→乘积，并联→求和，反馈→核心结构。"展示图1-2-6。
  - 信号流图（4min）：展示图1-2-7（方框图与信号流图对照）。核心信息——"方框图以谁对谁做了什么组织，信号流图以变量之间怎样互相决定组织。同一件事，两种视角。"不要求画图。
  教师操作：本节节奏要快。学生只需认识这两张图，不需要自己画。

  【段五：极点与复平面——概念引入 + 跨域直觉】10min

  - 极点名称来源（3min）：展示图1-2-8（三维幅值曲面）——"看到那两根柱子了吗？在 s=0 和 s=-B/J 两个点，|G(s)| 趋向无穷。这就叫极点。"快速展示图1-2-9（相位曲面）。
  - 极点图鉴表（3min）：表1-2-1 不逐行念。口头概括——"左半平面→收敛，右半平面→发散，离虚轴越远→越快，离实轴越远→越密。"
  - 复平面地名系统（4min）：展示图1-2-10（复平面行为地图）。像讲地图一样讲——"这是稳定区，这是不稳定区，这条线是稳定边界，这个走廊是振荡区，这个走廊是单调区。看到极点坐标，就像看到经纬度，你能立刻说出那个地方的气候。"
  教师操作：三维曲面图是本节最重要的教学资产——让学生第一次看到"极点"不是抽象名词，而是几何事实。

  【段六：案例 + 例题——学生自主探索】5min

  - 案例（3min）：展示三艘船的极点对比表。让学生先自己看 10 秒，再逐个分析。模型 B 是难点——强调"−0.8 比 −3.0 更靠右，所以它拖慢了整个过程"（主导极点直觉的第一次伏笔）。
  - 例题（2min）：黑板上走一遍——写特征方程→解二次方程→读出 σ 和 ω→翻译成行为描述。这是学生第一次亲手走完"模型→极点→行为"完整链。
  教师操作：例题让学生跟着在黑板上/纸上同步做。

P₃｜Post-assessment 后测（3min）
  形式：口头出口问题
  测试内容：
  1. "建模的两条路径各是什么？我们这门课主线走哪条？"
  2. "传递函数把微分运算变成了什么运算？靠哪个数学工具？"
  3. （指着复平面草图上的一个点）"极点在这个位置，系统大概是什么行为？"
  反馈方式：教师即时点评。目的不是考核——是帮学生确认自己真的带走了建模链的骨架。

S｜Summary 总结（2min）
  方式：教师总结 + 板书收束
  核心要点：
  1. 建模 = 把真实对象翻译成可分析的语言——两条路径，主线走机理
  2. 五个地标：微分方程→传递函数→方框图/信号流图→极点→复平面——每个解决一个问题，串成一条完整的建模链
  3. 复平面是行为地图——横轴管收放，纵轴管摆动，看到极点坐标就能读出行为
  下节预告："现在你手上有了对象。下次课 1-3，你开始改变参数——增大增益——观察极点在这张地图上怎么移动，响应曲线跟着怎么变。这就是根轨迹和时域响应的第一次直观接触。"
