# 牛顿定律在旋转体中的应用

一句话：平动的 `F = ma`，在转动世界里变成 `T = J\alpha`。

## 核心公式

- $$T = J\alpha = J\ddot{\theta}$$
- $T$：力矩（N·m）
- $J$：转动惯量（转动版“质量”）
- $\alpha$：角加速度

## 物理图像

- **转动惯量越大，越“难启动”**：同样的力矩，加速更慢。
- **角加速度就是转动的“加速”**：角速度变化有多快。

## 舵机系统小例子

驱动力矩要克服惯性、阻尼和弹性：

$$J\ddot{\theta} + f\dot{\theta} + k\theta = T$$

这就是一个典型的**二阶线性系统**。

## 记忆小贴士

- 平动看 **F**，转动看 **T**
- 质量换成 **转动惯量 J**
