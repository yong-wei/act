## 详情

### 完整解释

复平面可行域由两条约束线的交集确定：

**约束线1：阻尼比射线**（超调量约束）
- $M_p \leq 20\%$ → $\zeta \geq 0.45$ → 射线夹角 $\leq 63°$
- 极点必须在射线**下方**（夹角更小）

**约束线2：实部垂线**（调节时间约束）
- $t_s \leq 5\text{s}$ → $\sigma \geq 0.8$ → $\text{Re}(s) \leq -0.8$
- 极点必须在垂线**左侧**

两线交集 = 可行扇形区域。约束越严，扇形越小；约束过严，扇形可能与根轨迹无交点（系统无解）。

### 公式与推导路径

| 约束 | 关系 | 精化单元 |
|------|------|---------|
| $M_p \leq \sigma_0\%$ | $\zeta \geq \zeta_0$，$\theta = \arccos\zeta_0$ | 单元 2-1 |
| $t_s \leq T_0$（2%准则）| $\text{Re}(s) \leq -4/T_0$ | 单元 2-1 |

### 工程实例（船舶航向控制）

系统 $G(s)=K/[s(s+2)]$，要求 $M_p \leq 20\%$，$t_s \leq 5\text{s}$：
- 阻尼比射线：与负实轴成63°
- 实部垂线：$\text{Re}(s) = -0.8$
- 根轨迹实部恒为 $-1$，完全在垂线左侧（$ts$ 约束不紧）
- 可行弧段由阻尼比射线截断，对应 $K_{\max} \approx 4.84$

### 关联节点

| 方向 | 节点 | 关系说明 |
|------|------|---------|
| 前置 | 阻尼比 | ζ下限确定射线角度 |
| 前置 | 调节时间 | ts上限确定垂线位置 |
| 前置 | 极点迁移 | K变化→极点沿根轨迹穿越可行域 |
| 后续 | 设计可行域 | 是设计可行域的核心几何表达 |
| 跨域 | 时域响应包络 | 可行域在时域的投影 |
| 跨域 | 频域可行带 | 可行域在频域的投影 |

### 常见误区

1. **误区**：可行域是根轨迹上的一段。**纠正**：可行域是复平面上的区域（扇形），根轨迹与可行域的交叉才是"可行弧段"，两者不同。
2. **误区**：极点在可行域内就意味着性能最优。**纠正**：可行域内的极点都是"满足约束"的，最优点（如最佳阻尼比）是可行域内的进一步选择。
