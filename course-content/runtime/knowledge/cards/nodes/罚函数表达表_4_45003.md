# 罚函数表达表 | Penalty Function Expression Table

**一句话定义**：把越界代价显性写进总代价函数，让求解器主动远离不可用区域。

**核心直觉**：边界若只停留在注释里，搜索就会继续奖励失真解。

**关键公式**：
$$
J_{con}(\theta)=J_{free}(\theta)+50\max(0,M_p-20)^2+20\max(0,u_{\max}-7)^2+5\max(0,45-\phi_m)^2
$$

**关联**：前置 → 参数约束翻译表 · 后续 → 求解记录单

## 详情

### 完整解释

罚函数的作用不是替代偏好，而是给偏好加上一层明确边界。只要结果仍在允许区域内，总代价与上一课的自由目标保持一致；一旦越界，代价会迅速放大，搜索就必须回头。

### 常见误区

1. **误区**：罚函数只是技术性补丁。
   **纠正**：本课里它承担的是把“不能继续含糊处理的边界”写进模型本体。

2. **误区**：罚项越大越好。
   **纠正**：罚项需要与边界职责匹配，否则求解器会失去可解释的比较尺度。
