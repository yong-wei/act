# 极点迁移 | Pole Migration

**一句话定义**：调节增益K，闭环极点在复平面上移动的现象。

**直觉**：
```
K小 → 极点靠近实轴 → 响应慢、无超调
K大 → 极点远离实轴 → 响应快、有振荡
```
增益是"旋钮"，极点是"旋钮的实时位置"。

**关键公式**：
$$s^2 + 2s + K = 0 \implies s = -1 \pm \sqrt{1-K}$$

**关联**：前置 → 开环增益 · 后续 → 根轨迹 · 跨域 → 时域响应

---

## 详情

### 完整解释

极点迁移是理解根轨迹的核心直觉：系统的闭环极点不是固定不变的，而是随开环增益K的变化而移动。

```
复平面示意（船舶航向控制 G=K/s(s+2)）：

jω
↑
2|      ×  ← K=5，极点(-1,+j2)
 |      |
1|      ×  ← K=2，极点(-1,+j1)  ← ζ=0.707
 |      |
─┼──×───●────── σ
 |  -2  -1   0
 |  ↑   ↑
 | K=0  K=1（分叉点）
-1|      ×  ← K=2，极点(-1,-j1)
-2|      ×  ← K=5，极点(-1,-j2)
```

K从0增大：两极点从(0,0)和(-2,0)出发，相向移动 → 在(-1,0)相遇（K=1）→ 分叉为上下对称的复数极点，实部固定在-1，虚部持续增大。

### 公式与推导路径

特征方程：$s^2 + 2s + K = 0$

求根：$s = \frac{-2 \pm \sqrt{4-4K}}{2} = -1 \pm \sqrt{1-K}$

- $K < 1$：两个负实极点
- $K = 1$：重实极点 $s = -1$
- $K > 1$：复数极点 $s = -1 \pm j\sqrt{K-1}$

→ 完整推导见单元 2-3。

### 工程实例（船舶航向控制）

船舶参数：$G(s) = \frac{K}{s(s+2)}$

| K | 极点 | 阻尼比ζ | 超调量 | 调节时间 |
|:---:|:---:|:---:|:---:|:---:|
| 1 | -1±0j | 1.0 | 0% | ~4s |
| 2 | -1±j | 0.707 | 4.3% | ~4s |
| 5 | -1±2j | 0.45 | 20% | ~4s |

注意：调节时间由实部σ=1决定，不随K变化。

### 关联节点

| 方向 | 节点 | 关系说明 |
|------|------|---------|
| 前置 | 开环增益 | K是触发迁移的参数 |
| 前置 | 闭环极点 | 迁移的主体 |
| 后续 | 根轨迹 | 迁移路径的完整集合 |
| 跨域 | 时域响应 | 极点位置决定响应形状 |
| 跨域 | 阻尼比 | 极点方向角决定ζ |

### 常见误区

1. **误区**：极点迁移是指系统输出随时间变化的过程。**纠正**：极点迁移是参数（K）扫描时极点在复平面上的空间轨迹，与时间无关。
2. **误区**：增益越大，系统越好。**纠正**：增益过大会使极点虚部过大，超调和振荡增加；某些系统增益超过临界值后极点进入右半平面，系统不稳定。
