# 输出阻抗

**一句话定义**：前级网络输出端呈现的阻抗，要求趋于零以增强带负载能力。

### 完整解释

前级网络输出端呈现的阻抗，要求趋于零以增强带负载能力。

### 典型示例

- 在两级网络之间，要求前级网络的输出阻抗趋于零。
