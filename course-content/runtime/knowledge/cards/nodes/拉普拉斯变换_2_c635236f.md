## 首页

# 拉普拉斯变换

**一句话定义**：拉普拉斯变换把时域函数映射到复频域，使线性微分方程可以转化为代数表达，是建立传递函数和分析极点位置的基础工具。

**核心直觉**：它把“随时间变化的运动”搬到 s 域，让微分关系变成更容易操作的乘法关系。

**关联**：前置 → 微分方程模型 · 输出 → 传递函数、极点、频域响应

## 详情

一句话：把“时间里的变化”搬到 `s` 域，微分方程瞬间变代数。

## 定义

$$\mathcal{L}\{f(t)\} = F(s) = \int_0^{\infty} f(t) e^{-st} dt$$

其中 $s = \sigma + j\omega$。

## 为什么好用

- **把微分变成乘法**：计算更省力
- **稳定性一眼看**：看极点位置
- **控制器设计更顺手**：频域工具一整套

## 常用性质（够用版）

- 线性：$$\mathcal{L}\{af(t)+bg(t)\} = aF(s)+bG(s)$$
- 微分：$$\mathcal{L}\{\dot{f}(t)\} = sF(s) - f(0)$$
- 积分：$$\mathcal{L}\{\int_0^t f(\tau)d\tau\} = \frac{F(s)}{s}$$

## 控制工程小结

从时域到传递函数的标准流程：

$$J\ddot{\theta} + f\dot{\theta} + k\theta = T$$

$$G(s)=\frac{\Theta(s)}{T(s)} = \frac{1}{Js^2 + fs + k}$$
