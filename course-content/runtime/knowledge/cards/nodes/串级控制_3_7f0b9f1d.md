# 串级控制

**一句话定义**：一种具有内外两个回路的控制系统结构，内回路（副回路）快速抑制二次扰动，外回路（主回路）保证主被控量精度。

**关键公式**：

$$
G_{c2}(s) = \frac{G_2(s)}{1 + G_1(s)G_2(s)H_2(s)}
$$

$$
\frac{C(s)}{N_2(s)} = \frac{G_2(s)}{1 + G_1(s)G_2(s)H_2(s) + G_c(s)G_1(s)G_2(s)H_1(s)}
$$
