# 小范围稳定

**一句话定义**：系统受到有界扰动后，只有当初始偏移小于某一范围时，才能在扰动后恢复到初始平衡状态。

## 详情

### 完整解释

系统受到有界扰动后，只有当初始偏移小于某一范围时，才能在扰动后恢复到初始平衡状态。

### 关键词

有界扰动、初始偏移、范围
