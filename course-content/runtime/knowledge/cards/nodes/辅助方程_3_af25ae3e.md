# 辅助方程

**一句话定义**：当劳斯表中出现全零行时，用其上一行系数构造的方程，用于求解对称于原点的特征根。

**关键公式**：

$$
F(s) = s^4 + 3s^2 + 2 = 0
$$

$$
\frac{dF(s)}{ds} = 4s^3 + 6s
$$

## 详情

### 完整解释

当劳斯表中出现全零行时，用其上一行系数构造的方程，用于求解对称于原点的特征根。

### 典型示例

- 例3-10中，由s^3行系数构造辅助方程 F(s) = s^4 + 3s^2 + 2，求导后得到导数方程系数以取代全零行。

### 关键词

全零行、对称根、导数方程
