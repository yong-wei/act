# 信号流图 | Signal Flow Graph

**一句话定义**：用节点表示信号、用有向支路表示传递关系的图形模型，是结构图的另一种表达方式。

**直觉**：
- 节点 = 信号变量
- 支路 = 增益与方向
- 回路 = 反馈路径

**关联**：前置 → 系统结构图 · 后续 → 梅森增益公式

---

## 详情

### 完整解释

信号流图把“方框 + 比较点”的结构，重写为“节点 + 支路”的形式，更适合从全局识别前向通路和回路。

结构图转成信号流图时：
- 每个信号量对应一个节点
- 方框对应一条带增益的有向支路
- 反馈关系自然表现为闭合回路

### 为什么重要

当结构图存在多重交叉回路时，代数化简会很繁琐；而信号流图更容易直接列出前向通路与回路，为梅森增益公式做准备。

### 常见误区

1. **误区**：信号流图只是结构图的美化画法。**纠正**：它的价值在于让全局拓扑关系更清楚，便于直接应用梅森公式。
2. **误区**：信号流图中的箭头可以忽略方向。**纠正**：前向通路、回路和增益都依赖方向，箭头不可省略。
