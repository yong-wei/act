# 输入阻抗

**一句话定义**：后级网络对前级网络呈现的阻抗，要求足够大以减少对前级的影响。

## 详情

### 完整解释

后级网络对前级网络呈现的阻抗，要求足够大以减少对前级的影响。

### 典型示例

- 在两级网络之间接入隔离放大器时，要求后级网络的输入阻抗足够大。

### 关键词

阻抗、网络、隔离
