## 首页

**一句话定义**：响应从目标值的 10% 上升到 90% 所需的时间（欠阻尼系统）。

**核心直觉**：tᵣ 反映系统"起步有多灵敏"。主要受 ωₙ 控制，ωₙ 越大 tᵣ 越短。与超调量存在根本权衡。

```
  90%─ ─ ─ ─ ─ ─ ─ ─╭─────
  50%─ ─ ─ ─ ─ ─╭───╯
  10%─ ─ ─ ─╭───╯
    0%──────╯
           ↑←─tᵣ─→↑
```

**关联速查**：自然频率 · 动态性能指标 · 超调量

---

## 详情

### 完整解释

tᵣ 是三个动态性能指标中最能反映系统"起步速度"的指标。定义有两个版本：
- **欠阻尼系统**：从目标值的 10% 到 90%（测量上升段）
- **过阻尼系统**：从 0% 第一次到达目标值的时间

```
响应
  90%─ ─ ─ ─ ─ ─ ─ ─╭─────
  50%─ ─ ─ ─ ─ ─╭───╯
  10%─ ─ ─ ─╭───╯
    0%──────╯
           ↑tᵣ测量区间↑
     时间 ─────────→
```

### 公式路径

tᵣ 无简单解析公式，近似关系（欠阻尼，ζ < 1）：
$$t_r \approx \frac{\pi - \arccos\zeta}{\omega_n\sqrt{1-\zeta^2}}$$

> 完整推导 → **单元 1-3**

**关键性质**：
- ωₙ↑ → tᵣ 等比例缩短（反比关系）
- ζ↑ → tᵣ 增大（稳重但起步慢）
- **tᵣ 与 Mₚ 存在根本权衡**：起步越快 → 越容易冲过

### 船舶工程实例

| 场景 | tᵣ 要求 | 代价 | 典型 ζ |
|------|--------|------|-------|
| 紧急避碰 | 越小越好 | 接受较大超调 | ζ ≈ 0.3~0.5 |
| 常规转向 | 中等（~25s） | Mₚ 和 tᵣ 平衡 | ζ ≈ 0.5~0.7 |
| 港口精密作业 | 可以较大 | 换取 Mₚ 极小 | ζ ≈ 0.8~1.0 |

某船 ωₙ = 0.1 rad/s，ζ = 0.5 → tᵣ ≈ 25s

### 关联节点完整表

| 方向 | 节点 | 关系说明 |
|------|------|---------|
| 前置 | 自然频率 | ωₙ↑ → tᵣ 缩短（主要决定因素） |
| 前置 | 阻尼比 | ζ↑ → tᵣ 增大（次要影响） |
| 属于 | 动态性能指标 | tᵣ 是三指标之一（"快"） |
| 权衡 | 超调量 | 快速响应 vs 平稳落地的核心矛盾 |

### 常见误区

1. **误区**：上升时间是响应到达目标值的时间。
   **纠正**：tᵣ 只测量 10%→90% 这一段，是反映起步灵敏度的指标，不是"到达稳态"的时间（那是 tₛ）。

2. **误区**：tᵣ 和 tₛ 描述同一件事。
   **纠正**：tᵣ 描述"起步速度"，tₛ 描述"最终稳定"；二者描述曲线的不同阶段，差值可能达数倍。
