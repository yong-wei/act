# 力反馈

**一句话定义**：通过传感器测量力信号，并将其反馈给控制器以调整执行器动作的控制方法。

## 详情

### 完整解释

通过传感器测量力信号，并将其反馈给控制器以调整执行器动作的控制方法。

### 典型示例

- 打磨机器人引入腕力传感器构成力反馈，以控制接触力。

### 关键词

力传感器、反馈、接触力
