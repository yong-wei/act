# 系统型别 | System Type

**一句话定义**：按开环传函在原点的积分个数对系统进行分类，用来判断典型给定输入下的跟踪能力。

**核心直觉**：型别回答的是“哪一类输入的误差可以先天更小或归零”。

**关键公式**：
$$
G(s)H(s)=\frac{K_0}{s^v}G_0(s),\qquad G_0(0)\neq 0
$$

**关联**：前置 → 积分环节 · 后续 → 静态误差系数、稳态误差双路径判断

## 详情

### 完整解释

在 `3-7`，型别不再只是背表，而是拿来回答一个判断问题：如果某类误差想从有限值变成 0，单纯调增益够不够，还是必须改型别？

型别的关键不在编号，而在“原点积分个数”。积分个数一变，系统对阶跃、斜坡、抛物线的跟踪能力边界就会随之变化。

### 常见误区

1. **误区**：型别只和系统快慢有关。
   **纠正**：型别首先关系到稳态跟踪能力，而不是速度本身。

2. **误区**：只要增益足够大，就等价于提高型别。
   **纠正**：增益不会改变原点积分个数，因此不等价于改型别。
