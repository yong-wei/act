# 最佳阻尼比 | Optimal Damping Ratio

**一句话定义**：ζ=0.707，超调约4.3%，快速与平稳的工程最优平衡点。

**直觉**：
```
ζ→1：慢但稳（过阻尼）
ζ=0.707 ← 工程最优
ζ→0：快但震（欠阻尼）
```
在根轨迹图上对应从原点出发与负实轴成**45°**的射线。

**关键公式**：
$$\zeta = \cos\theta = 0.707 \implies \theta = 45°$$

**关联**：前置 → 阻尼比 · 工具 → 根轨迹 · 输出 → 开环增益K值

---

## 详情

### 完整解释

阻尼比ζ决定系统响应的"振荡程度"。从纯工程实用角度看：

- ζ太大（>1）：响应慢，但稳定，无超调——船舶转向太迟钝
- ζ太小（<0.3）：响应快，但超调大，振荡剧烈——船舶来回摆动
- ζ=0.707：超调约4.3%，调节时间最短，响应品质最优

```
根轨迹上的45°射线（ζ=0.707线）：

jω
↑    /  ← 45°射线（ζ=0.707）
3|  /
2| /
1|×  ← 交点(-1,+j1)，即ζ=0.707的极点
 |/
─●──────── σ
 原点
```

从原点向左上方45°方向画射线，与根轨迹的交点即为最佳阻尼比对应的极点位置。

### 公式与推导路径

阻尼比与极点夹角关系：

$$\zeta = \cos\theta, \quad \theta = \arctan\frac{\omega_d}{\sigma}$$

ζ=0.707时，θ=45°，即：$\omega_d = \sigma$（虚部等于实部的绝对值）

对船舶模型 $G(s)=\frac{K}{s(s+2)}$，极点实部固定为-1：

$$\omega_d = \sigma = 1 \implies s = -1 \pm j1$$

对应增益：$K = \sigma^2 + \omega_d^2 = 2$

→ 完整推导见单元 1-3；根轨迹精化见单元 2-3。

### 工程实例（船舶航向控制）

目标：找到最佳增益K使ζ=0.707。

步骤：
1. 在根轨迹图上画45°射线
2. 找射线与根轨迹的交点：(-1, ±j1)
3. 代入特征方程求K：$K = 1^2 + 1^2 = 2$
4. 验证：超调量 $M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} \approx 4.3\%$ ✓

### 常见误区

1. **误区**：最佳阻尼比ζ=0.707在所有系统中都是最优的。**纠正**：ζ=0.707是二阶系统综合响应速度与超调的工程经验值；对高阶系统或有特殊约束（如不允许任何超调）的场合，最优ζ可能不同。
2. **误区**：ζ=0.707对应的极点位置在所有系统中都是(-1,±j1)。**纠正**：(-1,±j1)只是本例系统的具体极点；45°射线与不同系统根轨迹的交点不同，对应的极点坐标也不同。
