# 奈奎斯特曲线

**一句话定义**：在复平面上，由开环频率特性曲线和根据虚轴极点补作的无穷大半径圆弧组成的半闭合曲线。

## 详情

### 完整解释

在复平面上，由开环频率特性曲线和根据虚轴极点补作的无穷大半径圆弧组成的半闭合曲线。

### 典型示例

- 用于奈奎斯特稳定判据中分析系统稳定性。

### 关键词

奈奎斯特曲线、半闭合曲线、开环频率特性
