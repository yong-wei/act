# 不稳定的极限环

**一句话定义**：一种极限环，其内部和外部的相轨迹均卷离该环，所表示的周期运动不稳定。

## 详情

### 完整解释

一种极限环，其内部和外部的相轨迹均卷离该环，所表示的周期运动不稳定。
