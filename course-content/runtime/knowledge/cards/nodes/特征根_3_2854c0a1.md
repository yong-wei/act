# 特征根

**一句话定义**：系统闭环传递函数分母多项式（特征方程）的根，决定了系统的稳定性和动态响应特性。

**关键公式**：

$$
\Delta(s) = 0
$$

## 详情

### 完整解释

系统闭环传递函数分母多项式（特征方程）的根，决定了系统的稳定性和动态响应特性。

### 典型示例

- 已知s=-2为系统的一个闭环特征根，计算控制器增益K并求其他特征根。

### 关键词

闭环极点、稳定性、动态响应
