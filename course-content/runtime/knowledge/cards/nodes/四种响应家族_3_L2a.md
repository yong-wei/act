## 首页

**一句话定义**：由系统极点在复平面的位置决定的四种基本时域响应类型。

**核心直觉**：极点位置就像"菜谱配方"，时域曲线就是"做出的菜"。看极点在复平面哪个区域，立刻知道系统会单调、振荡、持续还是发散。

```
极点位置（复平面） → 时域曲线形状
两个负实极点      → ────────  （过阻尼，单调稳定）
共轭复极点(左半)  → ~~~──     （欠阻尼，振荡衰减）✓最常见
共轭复极点(虚轴)  → ~~~~~~    （临界，等幅振荡）
极点在右半平面    → ↗∞        （不稳定，发散）
```

**关联速查**：阻尼比 · 阶跃响应 · 极点

## 详情

### 完整解释

四种响应家族是"时域直觉 ↔ 复域极点"的核心跨域映射框架。

```
复平面极点位置 ─────────────────→ 时域响应形状
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
两个负实极点（σ₁, σ₂ < 0）
  → 单调上升（过阻尼）  ████████──

共轭复极点 s = -α ± jω（α > 0）
  → 振荡衰减（欠阻尼）  ██╮ ╭╮──   ✓工程最常见

共轭复极点 s = ±jω（纯虚轴）
  → 等幅持续振荡（临界）╭╮╭╮╭╮╭╮

极点在右半平面（Re(s) > 0）
  → 发散（不稳定）       ██████████→∞
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 四族对照表

| ζ 范围 | 极点位置 | 响应特征 | 工程直觉 | 稳定性 |
|--------|---------|---------|---------|:------:|
| ζ > 1 | 两个负实极点 | 单调上升，无超调 | "老实型" | ✓ 稳定 |
| 0 < ζ < 1 | 共轭复极点，Re<0 | 振荡衰减，有超调 | "运动员型" | ✓ 稳定 |
| ζ = 0 | 纯虚轴极点 | 等幅持续振荡 | "钟摆型" | △ 临界 |
| ζ < 0 | 右半平面极点 | 发散 | "失控型" | ✗ 不稳定 |

### 公式路径

ζ 连续变化时，极点轨迹：
$$s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2}$$

- ζ = 0：极点在虚轴，等幅振荡
- 0 < ζ < 1：极点在左半平面，振荡衰减
- ζ = 1：极点合并到负实轴（临界阻尼）
- ζ > 1：两个不同负实极点，过阻尼

### 船舶工程实例

- 绝大多数受控船舶工作在**欠阻尼稳定族**（ζ ≈ 0.5~0.7）
- 极点设计目标：将极点配置在左半平面，且实部足够负（确保 tₛ 满足要求）
- 实例：某船 ζ = 0.5，ωₙ = 0.1 rad/s → 极点在 s = -0.05 ± 0.087j

### 常见误区

1. **误区**：只有完全不振荡才是好的系统。
   **纠正**：工程中欠阻尼（有轻微振荡）是最常见的设计选择，因为响应更快；关键是超调量和调节时间在可接受范围。

2. **误区**：四种家族是截然分开的。
   **纠正**：通过 ζ 连续变化，从欠阻尼→临界→过阻尼是连续过渡的；"家族"只是便于教学的分类框架。
