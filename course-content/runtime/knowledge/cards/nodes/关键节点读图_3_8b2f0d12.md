# 关键节点读图 | Key-Node Reading on Root Locus

**一句话定义**：按固定顺序读取分离点、虚轴交点、主导极点候选和稳定边界，把根轨迹主图变成可复核的判断入口。

## 详情

### 完整解释

3-4 的读图训练不是让学生重新背法则，而是把 `3-3` 的法则体系压成一套稳定的动作顺序：

1. 先看起点、终点和分支数，知道整图骨架是什么；
2. 再标出分离点、虚轴交点和主导极点候选；
3. 最后才进入参数窗口和工程后果。

这一步的价值不在“多记住几个点”，而在于防止学生直接跳到“哪个参数更好”的口头结论。

### 工程场景

对船舶航向控制对象，分离点决定了系统何时从“纯实轴慢响应”转向“共轭复极点主导”；虚轴交点则是稳定窗口的硬边界。
因此，关键节点一旦读错，后面的窗口判断和三域验证都会跟着失真。

### 关联节点

| 方向 | 节点 | 关系说明 |
|------|------|---------|
| 前置 | 根轨迹完整法则 | 决定你该按什么顺序看图 |
| 前置 | 根轨迹 | 给出读图对象本体 |
| 输出 | 参数窗口判断 | 关键节点决定窗口边界怎么读 |
| 输出 | 闭环主导极点 | 主导极点候选把图读回动态结果 |

### 常见误区

1. **误区**：先挑一个看起来顺眼的极点位置，再反推它为什么合理。**纠正**：必须先看整图骨架和关键节点，再谈具体参数。
2. **误区**：虚轴交点只是一个局部细节。**纠正**：它直接决定稳定窗口的上边界，绝不是可有可无的小点。
