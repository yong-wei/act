# 结构选型决策树 | Controller-Structure Selection Decision Tree

**一句话定义**：按照“任务证据 -> 频段/通道 -> 候选结构 -> 整定入口 -> 复核量”的顺序选择控制结构。

**核心直觉**：决策树不是答案表，而是把选型理由显性化的证据流。

**关键公式**：
$$
\text{任务证据}\rightarrow\text{频段/通道}\rightarrow\text{候选结构}
$$

**关联**：前置 -> 控制器频域特性矩阵 · 后续 -> 单结构整定四类复核量

## 详情

稳态误差和慢扰动优先检查 `PI` 或滞后；超调、振荡和相角裕度不足优先检查 `PD`、测速反馈或超前；稳态和动态同时不满足时，`PID` 或超前-滞后进入候选；参考轨迹已知或扰动可测时，前馈作为补偿通道加入。

### 常见误区

1. **误区**：决策树上出现的结构就是最终方案。
   **纠正**：它只给出候选和整定入口，最终还要复核响应、扰动、裕度和控制量。

2. **误区**：前馈在决策树中出现就说明反馈可以退出。
   **纠正**：前馈处理可测通道，反馈仍负责稳定性和鲁棒性。
