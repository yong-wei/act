# 统一对象多版本综合映射框架 | Unified Multi-Variant Mapping Framework

**一句话定义**：围绕同一个对象，把基准、积分和自选补强版本放进同一张映射表，统一比较结构变化、根轨迹信号、时域结果与频域后果。

**核心直觉**：模块 3 的出口不是再学一个新控制器，而是先学会在同一对象上横向比较不同机制线。

**关键公式**：
$$
\text{结构变化}
\rightarrow
\text{根轨迹第一信号}
\rightarrow
\text{时域结果}
\rightarrow
\text{频域解释}
\rightarrow
\text{任务标签}
$$

**关联**：前置 → 结构变化的频域指纹、频域综合判断与工程读回、根轨迹、主导极点 · 后续 → 任务标签与机制标签匹配、模块4入口的首轮任务判断

## 详情

### 完整解释

`3-9` 的关键动作，是把前面几课分散学过的语言压回同一个船舶航向控制对象上比较，而不是换一个新对象重新讲一遍。这样做有两个直接收益：

1. 基准版给出统一锚点，告诉我们系统当前处在怎样的折中位置。
2. 零点线补强、积分家族和滞后对照都能在同一口径下读出“收益先出现在哪一域、代价先暴露在哪一域”。

因此，这张卡强调的不是“版本越多越好”，而是“版本之间必须可比”。一旦换对象、换读图口径或换评价指标，任务标签就会漂移，模块 4 入口判断也会失真。

### 本课中的版本角色

- **基准版**：只负责提供统一锚点。
- **零点线补强**：代表更偏动态改善的机制线。
- **积分家族**：代表更偏稳态改善的机制线，并暴露低频收益与中频代价。
- **积分校正 / 滞后对照**：提醒“稳态改善”内部也有不同路径和不同代价分布。

### 常见误区

1. **误区**：只要每个版本都画了图，就自然能比较。
   **纠正**：必须固定同一对象、同一读图口径和同一任务问题，版本比较才有意义。

2. **误区**：综合映射就是把所有结论抄成一张表。
   **纠正**：真正重要的是因果链，尤其是结构变化先在根轨迹和频域哪里露出第一信号。
