# 静态误差系数 | Static Error Coefficients

**一句话定义**：把典型给定输入下的稳态误差快速判断压成 `K_p / K_v / K_a` 三个低频指标。

**核心直觉**：它们是快判工具，不是所有稳态误差问题的通用替身。

**关键公式**：
$$
K_p=\lim_{s\to0}G(s)H(s),\quad
K_v=\lim_{s\to0}sG(s)H(s),\quad
K_a=\lim_{s\to0}s^2G(s)H(s)
$$

**关联**：前置 → 系统型别 · 后续 → 稳态误差双路径判断

## 详情

### 完整解释

`3-7` 用静态误差系数做了两件事：

1. 把例题 1 的直接求结果快速复算一遍；
2. 给出“何时可先快判、何时必须回到完整列式”的边界。

所以这张卡的重点不只是定义，而是适用范围：标准单回路、典型给定输入、结构清楚时优先成立。

### 常见误区

1. **误区**：有了 `K_p/K_v/K_a`，就不用写误差传函。  
   **纠正**：它们只是在标准场景下替你省一步。

2. **误区**：扰动问题也能直接套这三个系数。  
   **纠正**：显式扰动题先看通道，再决定是否能退化成快判。
