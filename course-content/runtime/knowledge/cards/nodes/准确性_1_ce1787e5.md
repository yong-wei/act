# 准确性

**一句话定义**：对控制系统控制精度的要求，通常用稳态误差衡量，即过渡过程结束后被控量稳态值与期望值之间的误差。

### 完整解释

对控制系统控制精度的要求，通常用稳态误差衡量，即过渡过程结束后被控量稳态值与期望值之间的误差。

### 典型示例

### 关键词

稳态误差、控制精度、稳态值
