# 劳斯稳定判据

**一句话定义**：一种通过系统特征方程的系数构成的劳斯表来判断系统稳定性的代数判据。

**关键公式**：

$$
s^4 + 2s^3 + 3s^2 + 4s + 5 = 0
$$

$$
F(s) = s^4 + 2s^3 + 3s^2 + 4s + 5
$$

$$
s^n + a_{n-1}s^{n-1} + ... + a_1s + a_0 = 0
$$

## 详情

### 完整解释

一种通过系统特征方程的系数构成的劳斯表来判断系统稳定性的代数判据。

### 典型示例

- 例3-10：已知系统特征方程为 s^4 + 2s^3 + 3s^2 + 4s + 5 = 0，通过构造辅助方程并求导后继续计算劳斯表，判断系统不稳定且有一个正实部根。
- 例3-20中用于确定带速度反馈的磁盘驱动器系统稳定的放大器增益K_a取值范围。
- 用于确定火星漫游车转向控制系统中参数K1和K2的稳定区域。

### 关键词

稳定性、特征方程、劳斯表
