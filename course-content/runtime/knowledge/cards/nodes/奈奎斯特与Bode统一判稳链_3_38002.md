# 奈奎斯特与Bode统一判稳链 | Unified Stability Reading with Nyquist and Bode

**一句话定义**：Nyquist 曲线与 Bode 图不是两套独立规则，而是同一稳定边界问题在复平面和对数坐标下的两种读法。

**核心直觉**：Nyquist 看的是“怎样对待 `(-1,0)`”，Bode 读的是“何时撞上 `0 dB` 与 `-180^\circ` 这条临界边界”。

**关键公式**：
$$
|L(j\omega_c)|=1,\qquad \gamma=180^\circ+\angle L(j\omega_c)
$$
$$
\angle L(j\omega_\pi)=-180^\circ,\qquad G_m=\frac{1}{|L(j\omega_\pi)|}
$$

**关联**：前置 → 幅角原理、奈奎斯特稳定判据、截止频率、相角裕度、幅值裕度 · 后续 → 三频段闭环性能回读

## 详情

### 完整解释

`3-8` 把稳定判断固定成一条统一链：

1. 用 Nyquist 图判断曲线是否包围临界点 `(-1,0)`；
2. 用 Bode 图读取截止频率、相角裕度和增益裕度；
3. 再把“离边界还有多远”翻译成闭环动态风险。

两种图形的落点其实一致：

- **Nyquist**：几何上看是否围住临界点；
- **Bode**：数值上看在增益交叉点处，相位离 `-180^\circ` 还有多少余量，在相位穿越点处，幅值离 `0 dB` 还有多少余量。

因此，Bode 判稳不是另一套新定义，而是把同一临界边界拆成更容易读的频率线和裕度线。

### 工程场景

当需要快速回答“系统更快了，但是不是也更危险了”时，Nyquist 与 Bode 应联合使用：Nyquist 给出边界几何关系，Bode 给出可量化的余量读数。

### 关联节点

| 方向 | 节点 | 关系说明 |
|------|------|---------|
| 前置 | 奈奎斯特稳定判据 | 给出 `P/N/Z` 的闭环稳定结论 |
| 前置 | 截止频率 | Bode 读图的关键频率锚点 |
| 前置 | 相角裕度 / 幅值裕度 | 量化“离边界还有多远” |
| 输出 | 三频段闭环性能回读 | 把余量与速度、超调和代价接起来 |

### 常见误区

1. **误区**：Nyquist 和 Bode 说的是两种不同的稳定性。
   **纠正**：它们都在描述同一个临界边界问题，只是观察坐标不同。

2. **误区**：截止频率右移就已经足够说明系统更好。
   **纠正**：若相角裕度同步缩小，系统只是更快地逼近风险边界。
