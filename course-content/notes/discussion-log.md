## 2026-03-09 | 项目初始化

### 技能设计讨论

**背景**：课程重构报告和大纲已完成，需要设计一个 Claude Skill 来支撑约32个教学单元的内容逐步创作。

**关键设计决策**：

| 决策点 | 选定方案 | 理由 |
|--------|----------|------|
| 自动化模式 | 交互式共同创作（每步确认） | 内容质量要求高，需教师实时把关；避免批量生成造成大量返工 |
| 内容来源 | 从零创作，依据 SyllabusRefactor.md | 确保与重构大纲高度对齐，不受旧版教材限制 |
| 输出顺序 | 讲义→知识图谱→BOPPPS→互动页面→多模态资源 | 依赖顺序，讲义是后续所有内容的基础 |
| 知识图谱格式 | 自定义 JSON，启动时由用户提供模板 | 灵活性优先，格式待 Step 0 确认后固定 |
| 互动页面技术栈 | 先出内容结构，不绑定具体组件库 | 技术选型暂未确定，内容先行 |

**待确认事项**：
- [ ] 知识图谱 JSON 节点模板（Step 0 时用户提供）
- [ ] 知识图谱已有节点摘要（Step 0 时用户提供）
- [ ] 前端框架具体选型（React/Vue，组件库待定）

## 2026-03-10 | L-2a 讲义设计讨论

### 技能文件结构性修订（v1.1 → v1.3）

**触发原因**：L-2a 大纲讨论中发现技能文件缺少两条关键原则。

**修订决策**：

| 修订点 | 原描述 | 修订后 |
|--------|--------|--------|
| 讲义边界 | 未明确，[X]类内容含"[平台演示]"标注 | 讲义自成体系，只含书面内容；平台操作归教案 |
| 产物衍生关系 | 5类产物并列 | 明确为讲义→教案→互动页面→资源的衍生链 |
| 技能角色 | 执行者 | 批判性教学专家，主动审查设计，不全盘接受 |
| AI融入点标准 | 简单"问AI" | 四步递进：预测→AI对比→AI绘图→反思 |

---

### L-2a 内容设计决策

**单元定位**：层0第二轮速通首课，[X]跨域型，直觉层，不推导公式

**内容结构定型**：
- 引入：船舶航向阶跃响应曲线（正式插图替代ASCII）
- 四种响应家族：极点位置→曲线形态对照表
- 三个性能指标：$M_p$、$t_s$、$t_r$，只给含义不给推导
- 两个关键参数：$\zeta$（形状）、$\omega_n$（快慢）
- 响应族对图：两张（各自独立影响）
- 局限性说明：引出L-2b、L-2c
- 课后递进式AI任务

**关键设计争议与结论**：

| 议题 | 争议 | 结论 |
|------|------|------|
| $\zeta$定性规律是否放层0 | 担心认知负担 | 保留，但只给方向感（表格形式），不推导 |
| $t_s$随$\zeta$非单调是否提及 | 初学者可能困惑 | 保留，在表格注释中说明，不展开 |
| $\omega_n$变化图横轴设计 | 归一化vs统一时间窗口 | 统一时间窗口，利用"更多周期"视觉效果传达自然频率含义 |
| 课后任务是否要求提交 | 层0阶段负担问题 | 讲义只给任务内容，教案决定是否布置为提交 |

**插图需求（正式制作时）**：
1. 船舶航向阶跃响应（引入，含数据标注）
2. 四种极点家族曲线+复平面位置（四图并排）
3. $\zeta$变化响应族（5条，$\omega_n$固定）
4. $\omega_n$变化响应族（4条，$\zeta$固定，统一时间窗口）
