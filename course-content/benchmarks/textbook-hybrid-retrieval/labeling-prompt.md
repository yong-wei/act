# 教材混合检索基准标注合同

标注对象仅限七套公开教材结构运行态中的最小 `StructureUnit`。问题来自课程与控灵的公开教学用法，不得使用私人对话、学习者事实、原始答案或用户标识。

对每条问题逐一搜索全部七套来源，并记录所有能够直接、完整支撑回答的最小结构单元。只含关键词、仅提供背景、必须依赖相邻未引用内容或只回答问题一部分的单元不合格。图表问题还必须验证 fragment anchor 存在、归属该单元且正文实际引用图表。

`acceptableUnitIds` 必须穷尽本轮七书中符合条件的单元；`preferredUnitId` 必须属于该集合，并优先选择定义完整、表述清晰、版本较新且引用稳定的来源。跨教材问题至少包含两个不同 `bookId` 的合格单元。

标注代理只作教学语义裁决，不调整检索权重，也不以检索分数反推直接支撑关系。每条记录必须附简短、可复核的 `rationale`。
