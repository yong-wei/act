## 2026-04-21 | 细化 `4-4 / 4-5` 分工：`4-4` 只做无约束加权建模，`4-5` 再显化硬约束与罚函数

### 已确认决策

- `4-4` 收束为“固定结构下的无约束加权优化建模课”：
  - 从 `4-3` 的固定结构、参数起点与首轮证据出发；
  - 只讲加权目标函数、归一化基准、参数范围、权重偏好与候选解解释；
  - 不在本课显式引入输出侧硬约束、罚函数、`fmincon` 或“约束内展示解”。
- `4-5` 收束为“候选解越界揭露、硬约束显化与罚函数约束优化实践课”：
  - 以 `4-4` 产出的无约束候选解为固定输入；
  - 先用超调、控制峰值、相角裕度等证据指出“看似更优”如何越过硬边界；
  - 再把这些边界写成硬约束，并用罚函数法或 `fmincon` 完成带约束参数优化；
  - 结果必须在时域、频域、控制量和结构机理四类证据中解释。
- `4-4` 允许保留参数范围，但它只承担“固定结构可解释范围”的角色：
  - 作用是防止参数离开当前经典结构的有效区间；
  - 不等同于本课已经完成了工程硬约束的显化。
- `4-4` 与 `4-5` 的固定交接物改为：
  - `4-4` 输出：参数向量、归一化基准、加权目标函数、权重偏好、无约束候选解；
  - `4-5` 输出：越界证据、硬约束表、罚函数表达、带约束可用解与剩余风险。

### 主要理由

- 现有后半链虽然已经改成“优化设计链”，但 `4-4` 仍提前讲完硬约束、罚函数与约束内展示解，会压缩 `4-5` 的存在价值。
- `4-4` 若先让学生看到“只靠加权目标也能得到看似合理的候选解”，`4-5` 再揭示其越界，硬约束与罚函数的必要性会更清楚。
- 将输出侧硬约束显化后移到 `4-5`，能更稳定地形成“先建模偏好，再揭露边界，再做约束优化”的认知顺序，而不是在同一课里把取舍和修正同时讲完。

## 2026-04-20 | 模块 `4` 后半链重构为“显式带优化思想的控制器设计链”，并轻量回修 `4-1 / 4-3` 接口

### 已确认决策

- 模块 `4` 仍以经典结构控制器设计为核心，不改写为最优化算法课：
  - 经典结构包括 `PI / PD / PID / 超前 / 滞后 / 前馈 / 复合校正`；
  - 结构选择仍优先由对象分析、性能矛盾和经典机理确定；
  - 优化思想主要用于结构确定之后的参数选择、约束处理、结果解释与必要时的结构编码。
- `4-1` 轻量补入 `ITSE` 与控制量代价：
  - `ISE / IAE / ITAE / ITSE`、控制量代价、硬约束、软目标与观察指标共同构成后续优化评价语言；
  - 本课不提前讲优化算法细节。
- `4-3` 轻量补入“参数优化入口卡”：
  - 固定记录结构形式、待优化参数、硬约束、候选评价指标与初值来源；
  - 作为 `4-4` 固定结构优化建模的直接输入。
- `4-4` 固定为“固定结构下的优化建模课”：
  - 从 `4-3` 的固定结构、首轮证据与参数起点出发；
  - 把性能指标、控制量代价、权重偏好与硬约束写成目标函数和约束表达；
  - 只介绍 `fminsearch / fminunc / fmincon` 的工具入口和最小 `Pareto` 概念，不展开完整优化算法推导。
- `4-5` 固定为“参数约束翻译与带约束参数优化实践课”：
  - 在固定经典结构下定义参数向量、参数上下界、性能指标约束和控制量约束；
  - 用 `fmincon` 或罚函数完成一轮可解释的参数优化；
  - 优化结果必须回到时域、频域、控制量与工程约束证据中解释。
- `4-6` 固定为“固定结构优化边界与结构编码入口课”：
  - 把场景A中的固定结构参数优化结果带入迁移场景B；
  - 识别固定结构、固定加权方式和局部优化的失效证据；
  - 只把 `ga / pso` 作为结构编码与复杂搜索的入口，不讲成前沿算法大全。
- `4-7` 固定为“完整工程设计闭环实践”：
  - 完整执行“结构确定或编码—目标构造—约束建立—优化求解—解码解释—验证比较”；
  - 结论必须翻译回经典结构、参数含义、证据差异与工程责任边界。

### 主要理由

- 先前 `4-4` 以后仍沿用“权衡、修正、迁移、双场景比较”的旧叙述，容易重复经典设计语言，不能充分承接模块 `1` 中已引入的积分误差指标、控制代价和优化评价语言。
- 学生在 `4-3` 已经完成经典结构与经典设计方法落地后，后续课次更需要学习“如何把设计偏好、性能指标与约束转成可计算问题”，而不是再次按旧步骤讲一轮校正方法。
- 将 `fminsearch / fminunc / fmincon / 罚函数` 放在 `4-4 / 4-5` 主线中，能保持课程重点在控制器设计本身；将 `ga / pso` 后移到 `4-6 / 4-7`，能避免过早把结构选择变成黑箱搜索。
- 最小 `Pareto` 概念只用于说明多目标之间没有唯一绝对最优，不作为系统优化理论展开，避免增加不必要学习负担。

- 课程现有大纲中除 `4-2` 外，没有其他课次承担前馈的系统讲授职责；若本课继续把前馈写成边缘候选，学生后续只会在复合结构场景中被动看到它，却不知道它为何进入设计。
- 把前馈原理与单通道设计方法前移到 `4-2`，并不会挤占 `4-3` 的价值；相反，它能让 `4-3` 真正聚焦在“单结构不够时如何写成复合结构骨架”，而不是再替 `4-2` 补前馈启蒙。

- `pptx/21三频段_各司其职` 与 `pptx/20宽备窄用_稳定裕度` 只作为可选诊断图例资源，不重开理论主线。
- `pptx/22串联校正`、`pptx/23滞后超前`、`ship-control-cases/sections/6.3-船载稳定平台控制系统校正设计.md`、思政案例与题库资源不进入 `4-4` 主线。

- 明确把 `22/23/6.3` 和题库资源排除在 `4-4` 外，可以守住模块4内部“先诊断，再优化”的节奏，避免首轮验证课过早滑入方案修正和多目标权衡。

## 2026-03-22 | AI融入与提示词能力定位确认

### 已确认决策

- AI 融入不作为某一次课的独立事件，而作为“次次课都有、单元级可见”的固定动作。
- 单元级 AI 写法至少要回答：
  - 学生先做什么；
  - AI 在什么节点介入；
  - AI 输出后学生如何验证；
  - 教师据什么数据进行调整。
- 提示词能力在本课程中不按“提示词工程技巧”理解，而按“结构化控制问题表达与设计需求表达能力”理解。

### 主要理由

- 若 AI 只作为展示工具，无法改变学习路径与工程判断质量。
- 若把提示词能力降格为语言技巧，会削弱其在控制思维表达中的课程地位。

## 2026-04-01 | `3-6` 按资源库重定为统一对象四版本比较课

### 已确认决策

- `3-6（实践）` 不再只写成“比较零点引入前后的结构效应”的笼统实验课，而是明确固定为：
  - 一个统一基准对象；
  - `4` 个学生必做版本：基准、`PD`、测速反馈、简单超前；
  - `1` 个教师演示版本：右半平面零点。
- `3-6` 的课堂动作链固定为：
  - 先预测；
  - 再验证；
  - 最后完成“零点位置 -> 根轨迹变化 -> 时域表现 -> 频域变化”的一句话解释。
- `3-6` 的资源融入正式收束为：
  - 主资源：`pptx/12根轨迹_基本形态`、`pptx/10.1校正_实现控制的手段`、`pptx/22串联校正`；
  - 补强资源：`pptx/15.1根轨迹法_图形化思考`、`AC-Q-0044`、`AC-Q-0075`；
  - 本轮排除：思政案例、船舶根轨迹案例。
- `3-6` 必须显式给后续讲义、教案、互动课程设计、媒体清单提供本课级接口，不能再停留在“任务列表”层面。

### 主要理由

- 若没有统一对象和四版本并置，学生很容易把零点作用误读成“不同控制器的零散现象”，而不是同一条动态改善机制线。
- 若没有资源融入评审单，新增资源库只能停留在“知道有资源”，无法稳定指导后续作者态成稿。
- 若提前引入船舶案例或思政材料，会破坏 `3-6` 最核心的比较纯度，使课堂从机理验证退化为材料拼盘。
