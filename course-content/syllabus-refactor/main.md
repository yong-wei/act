  - `HW1` 边界进一步收紧为“只允许识别、比较、定性判断”，不允许隐含建模；
  - `T1-1` 以极点配置和响应特征匹配为主，正式出题默认采用“极点分布主输入”，不允许把结构图写成需反推传函的变相建模题；
  - `T1-2` 只允许基于题面给出的可见扰动现象做反馈意义辨析，正式出题必须给可见现象对比，不允许抽象化鲁棒性理论论证；
  - `T1-3` 只处理教师给定场景下的四要素识别，而 `O1` 专门承担学生自选对象的问题定义卡。
  - `O1` 进一步固定为“单一自选对象的问题定义卡”，只允许写四要素、闭环必要性与应用目标，不允许提前进入模型、指标和控制结构设想。
  - `T2-1` 固定为模块2入口建模题，正式出题只允许单输入单输出的一阶/二阶对象，不允许把负担转移为复杂机理建模或追加后续分析判断。
  - `T2-2` 固定为模块2中的连接结构求解题，结构复杂度只允许落在代表性例题范围内，梅森公式保持补充工具位阶，不回到技巧训练题。
  - `T2-3` 固定为模块2出口的基础跨域翻译与频域读图题，只允许围绕单一标准对象做时域-频域基础对照、基础 Bode 反识别，或相位裕度/增益裕度的图上读取与简单计算，不允许偷跑到判稳或模块3机理语言。
  - `T3-1` 固定为模块3入口的稳定性计算题，参数自由度只允许单主参数，题目只收口在劳斯阵列、稳定区间与临界条件，不追加动态或设计动作。
  - `T3-2` 固定为模块3中的根轨迹读图题，正式出题必须直接给可读图形或关键节点，不允许把读图题退回复杂手绘题，也不允许偷带后续设计语言。
  - `T3-3` 固定为模块3前半段的结构化判断题，必须给明确冲突情境和图/数据支撑，只允许做优先级判断，不允许滑成缩略版设计题。
  - 开放题 `O1-O7` 当前进一步固定为统一纵向主线：
    - 每次作业总分 `100分`，其中 `HW1-HW6` 的开放题各 `40分`，`HW7` 的开放题为 `50分`；
    - 开放题只设字数上限，不设字数下限；
    - 从 `O2` 开始，所有参考答案与示例结构必须沿用 `O1` 最终选定对象连续展开；
    - 允许使用 AI 协助研究，但必须提交 `AI 使用记录摘要`；
    - 凡涉及计算分析或方案验证的开放题，必须提交 `MATLAB/Octave` 仿真代码、结果图与简短复现实验说明；
    - 开放题统一按“继承连续性 / 本次任务完成度 / 边界控制 / 证据与验证质量 / AI 使用记录摘要”进行分维评分，不再鼓励长文堆砌。
- 模块1当前确认骨架为：
  - `1-1` 基本概念建立、课程规范与学习规则、课程总图发布
  - `1-2` 模型与复平面极点的第一轮速通
  - `1-3` 根轨迹与时域响应的第一轮速通
  - `1-4` 时域响应与频域响应的第一轮速通
  - `1-5` 平台初体验与三域联动探索
- 模块1当前进一步确认：
  - 不再按“导论 + 零散预告”理解，而按“总图建立 → 三轮速通 → 平台体验收束”理解；
  - 模块1只建框架，不提前承担模块2对象建立、模块3机理解释和模块4设计训练；
  - `1-5` 必须由学生完成第一次平台观察与结构化表达，不能只做教师演示。
