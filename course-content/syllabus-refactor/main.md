# 当前确认摘要

更新时间：2026-03-23

## 当前有效的总蓝图结论

- 课程总主线保持为“结构可见—结构可用—结构可评”。
- 模块编号体系已统一为 `模块1` 至 `模块5`，实践单元不再单列 `P-*` 编号，而是并入模块内连续编号。
- 当前确认的模块学时结构为：
  - 模块1：10学时
  - 模块2：8学时
  - 模块3：18学时
  - 模块4：16学时
  - 模块5：12学时
  - 期末复习：6学时
- 按当前已确认结构，全课程正式口径为 `72学时 = 48学时理论 + 24学时实践`。
- 其中实践学时分为两部分：
  - 课程内部可规划实践：18学时；
  - 教务协同外部实验：6学时，主题占位为时域、频域、非线性。
- 外部实验由不同部门教师负责，不纳入课程内部整体重构，只在对应时机预留占位。

## 各模块当前定位

- 模块1：导论串讲。负责首次课基本概念、课程规范与四次速通中的前三次理论串接，以及平台初体验；当前已确认其职责是“总图建立 + 三轮速通 + 一次平台体验收束”。
- 模块2：建模与基础响应层。负责建立变换语言、模型表达、时域响应对象与频域响应对象，为模块3准备正式分析入口。
- 模块3：结构机理层。按“作用机制”组织，讲清增益、极点、零点、型别、相位如何共同改变系统行为。
- 模块4：约束设计层。作为课程真正重心，把模块3形成的机理语言转化为设计行动。
- 模块5：前沿拓展。保留为主干的一部分，但不承担最核心能力生成任务；当前已强重构为“知识边界与方法迁移层”。

## 模块3当前确认骨架

- `3-1（理论）` 纯极点视角下的稳定与动态基础
- `3-2（实践）` 稳定边界可视化
- `3-3（理论）` 根轨迹机制与基本法则：增益如何推动闭环极点迁移
- `3-4（实践）` 极点作用与根轨迹综合实验：不同极点结构对轨迹、时域与频域的影响
- `3-5（理论）` 零点引入与动态改善：PD、测速反馈、超前校正与非最小相的多视角审视
- `3-6（实践）` 零点作用与动态改善实验
- `3-7（理论）` 型别、积分环节与稳态改善：PI与滞后校正的低频补偿机理
- `3-8（理论）` 频域判别与跨域综合语言
- `3-9（实践）` 稳定—动态—稳态综合映射实验

## 模块4当前确认骨架

- `4-1（理论）` 设计起点：性能指标体系、工程约束与可行域表达
- `4-2（理论）` 控制器选型原理：不同控制结构为何适合不同任务
- `4-3（理论）` 基于结构机理的初始方案形成：从选型判断到关键参数方向
- `4-4（实践）` 初始方案验证与失败诊断
- `4-5（理论）` 多目标权衡与控制器优化设计
- `4-6（实践）` 约束下的优化设计实践：平台引导下的方案修正与比较
- `4-7（理论）` 场景迁移与方案比较：AI协同验证的设计闭环
- `4-8（实践）` 综合工程场景对比设计：客船与驱逐舰双场景方案比较

## 当前已确认的关键原则

- `PD`、测速反馈、超前校正前移到模块3，只讲机理、趋势和同源性，不在模块3展开完整设计推导。
- `稳态误差`、系统类型（型别）、`PI`、滞后校正归入模块3，先承担机理解释功能，再在模块4服务约束下设计。
- 模块2当前确认骨架为：
  - `2-1` 建模与变换语言：拉氏变换、传递函数、结构图、信号流图、梅森公式、典型环节
  - `2-2` 时域响应基础：典型输入、一二阶响应与性能指标
  - `2-3` 频率响应基础：傅里叶级数、傅里叶变换、频率特性、`G(jω)` 与拉氏联系
  - `2-4` Bode 图与 Nyquist 图基础：原理与基本绘制法则
- 信号流图与梅森公式当前确认并入 `2-1`：
  - 作为“复杂连接结构的补充表达与求解工具”讲授；
  - 不再单独成章；
  - 不做高强度技巧训练。
- `2-1` 当前进一步确认按“主线 + 补充工具”组织：
  - 主线保留拉氏变换、微分方程到传递函数、典型环节、方框图表达；
  - 信号流图与梅森公式降为补充工具块；
  - 不再承担传统 `6h` 口径下的大量工具熟练训练。
- `2-2` 当前进一步确认：
  - 保留一阶惯性环节单位阶跃响应推导；
  - 保留一阶系统“上升时间约为 `3T`”这一重要工程估算结论；
  - 至少在二阶系统单位阶跃响应下保留完整时域响应数学推导；
  - 不把时域分析压缩成纯现象识别课；
  - 以此为后续理解高阶系统与不同输入作用提供理性基础；
  - 时域性能指标降为“公式给出 + 简要讲解 + 练习承接”；
  - 但高阶主导极点、卷积与稳态误差正式理论仍后移到模块3。
- `2-3` 当前进一步确认采用一条核心逻辑线：
  - 阶跃可理解为周期无限大的方波；
  - 方波可分解为不同频率正弦分量；
  - 系统对各正弦分量的响应不同；
  - 这些频率响应重新组合后形成实际阶跃响应；
  - 用这条线打通时域与频域，而不把 `2-3` 做成零散定义堆积。
- `2-4` 当前进一步确认：
  - Nyquist 图不只停留在“看过形态”，而要明确纯极点系统下的起始点、终止点、轨迹方向；
  - 需要讲清旋转角度与系统阶次的关系；
  - 但仍限制在纯极点系统，不提前引入零点、判据和裕度。
- 模块2单元设计细节现已从初稿升级为确认版：
  - 模块2固定按“对象建立链”组织，而不是按工具章节并列平铺；
  - 四单元职责固定为 `2-1` 建模对象、`2-2` 时域对象、`2-3` 频域对象、`2-4` 图形对象；
  - AI 在模块2中统一按“学生先独立判断 → AI 结构化比对 → 学生修订 → 教师按误判分布收束”的动作链介入；
  - AI 不承担完整推导、首次解释或提前越界到模块3判据与机制层。
- 模块2后的外部实验占位已经明确：
  - 时域实验放在 `2-2` 之后；
  - 频域实验放在 `2-4` 之后。
- 根轨迹基础、广义根轨迹、`0°/180°` 根轨迹、非最小相系统、Nyquist 判据与 Bode 判稳，不在模块2系统展开，而在模块3分布式安放并收束。
- `3-3` 当前已细化完成：
  - 以“增益变化为何导致闭环极点沿特定路径迁移”为核心；
  - 必含根轨迹基本定义、幅值/相角条件、基本绘制法则、广义根轨迹、`0°/180°` 根轨迹的联系与区分；
  - 不把手工绘图和高强度技巧训练作为重点。
- 模块3前半段当前已按“极点全方位影响 → 零点全方位影响”重排为：
  - `3-1/3-3/3-4`：极点语言、根轨迹机制及其实践展开；
  - `3-5/3-6`：零点语言、控制器联系及其实践展开。
- `3-1` 到 `3-5` 的边界拆分表已写入单元细节文件，作为后续细化的约束底板。
- `3-2` 当前已细化完成：
  - 采用一个统一高阶对象；
  - 对象选定为“积分 + 双惯性环节”；
  - 围绕单参数变化做稳定边界可视化；
  - 产出“判据结论—极点位置—响应状态”三联对应，不提前进入根轨迹法则。
- `3-4` 当前已细化完成：
  - 采用“同一对象族，三种极点结构版本”的组织方式；
  - 比较原点极点、实轴极点、共轭极点对根轨迹、时域与频域的综合影响；
  - 产出三版本对照表、预测与验证记录，以及机理解释。
- `3-5` 与 `3-6` 当前已细化完成：
  - `3-5` 以“零点”为主轴，而不是以控制器种类为主轴；
  - `3-6` 采用“4个学生必做版本 + 1个教师演示版本”的组织方式；
  - 学生必做版本为：基准、`PD`、测速反馈、简单超前；
  - 右半平面零点作为教师演示版本引入非最小相风险。
- `3-7` 当前已细化完成：
  - 作为模块3中“稳态改善线”的正式建立课；
  - 必含型别、`Kp/Kv/Ka`、积分环节、`PI`、滞后校正及其代价；
  - 明确与 `3-5/3-6` 的零点动态改善线形成对照；
  - 不提前承担 Nyquist 判据、Bode 判稳和完整频域校正设计。
- `3-8` 当前已细化完成：
  - 按“翻译优先”组织，而不是按判据清单平推；
  - 先把增益、零点、积分、滞后等结构变化统一翻译成频域变化；
  - 再收束到 Nyquist 判据、Bode 判稳、相位裕度、增益裕度、带宽等综合判断语言。
- `3-9` 当前已细化完成：
  - 作为模块3出口实践，不新增机制，只做综合映射；
  - 采用“3个学生必做版本 + 1个教师演示版本”的减载结构；
  - 学生必做为：基准、积分引入、极点线/零点线自选补强；
  - 教师演示为：滞后校正；
  - 产出跨域机制映射对照表和联动解释短报告。
- 模块3本轮全局检查结论已确认：
  - 主线完整，`3-1` 到 `3-9` 可以形成“稳定边界—极点/零点机制—稳态改善—频域翻译”的连续链条；
  - 减载主要通过三处收口：`3-2` 吸收劳斯操作化、`3-3` 前移单个极点类型影响、`3-9` 取消纯增益必做项；
  - 当前主要剩余风险已不再是模块5骨架未定，而转为后续如何把模块5内容继续转译为讲义、教案、互动课程与媒体清单成稿。
- AI 融入不按单次课处理，而按单元级固定动作链处理。
- 提示词能力在本课程中按“结构化控制问题表达能力”理解，不降位。
- 当前进一步明确：
  - 互动课程设计不是从传统 PPT 中切出的附加互动，而是课堂前台页面化主载体；
  - 页面既承载提纲、推导、图示、表格等静态展示，也承载适合改造的互动观察、比较与验证环节；
  - 教案转为课堂后台控制文稿，重点写教学意图、节奏、介入点与切换条件；
  - 媒体清单同时服务静态页面呈现与互动状态切换。
- 模块4的实践必须适配大教室、移动终端和平台留痕约束，学生个人独立提交。
- 模块4的场景迁移链已经确认：
  - 主场景A：客船航向控制
  - 迁移场景B：驱逐舰快速机动航向控制
  - 迁移条件：同类对象、模型结构不变、参数变化、目标优先级变化
- 模块5当前确认骨架为：
  - `5-1` 线性主干的边界：饱和、死区、滞回、切换与模型失配
  - `5-2` 非线性系统的最小分析入口：局部线性化、相平面与描述函数的边界角色
  - `5-3` 从单回路控制到复杂自主系统链路：MASS 的感知—估计—规划—控制协同
  - `5-4` 从模型驱动到数据驱动：MPC、数据驱动控制与模型依赖松动
  - `5-5` 从显式控制器到策略学习：强化学习的进入条件、收益与风险
  - `5-6` 方法迁移与前沿比较：经典控制、数据驱动与策略学习的同题比较
- 模块5当前进一步确认：
  - 不再按“前沿专题并列罗列”组织，而按“边界识别 → 方法迁移 → 前沿比较 → 工程收束”的迁移链组织；
  - 强化学习只作为方法迁移终点引入，不把模块5写成 RL 算法课；
  - 模块5改为 `5 理论 + 1 实践`，以把全课程内部实践总量压实回 `18h` 约束；
  - 模块5的唯一实践单元负责同题比较经典控制、数据驱动与策略学习三条路线，不做算法实现竞赛。
- 课程作业体系当前进一步确认：
  - 固定为 `7次作业`；
  - 其中 `作业1-6` 为 `3道闭题 + 1道开放题`，`作业7` 为 `2道闭题 + 1道开放题`；
  - 合计形成 `20道闭题题库 + 7段开放主线`；
  - 开放主线按 `O1 → O7` 递进，最终收束为一份自选对象或系统的完整控制方案；
  - 所有闭题统一构成期末题库，后续期末复习必须按题库簇而不是旧章节刷题逻辑重写。
- 模块1当前确认骨架为：
  - `1-1` 基本概念建立、课程规范与学习规则、课程总图发布
  - `1-2` 模型与复平面极点的第一轮速通
  - `1-3` 根轨迹与时域响应的第一轮速通
  - `1-4` 时域响应与频域响应的第一轮速通
  - `1-5` 平台初体验与三域联动探索
- 模块1当前进一步确认：
  - 不再按“导论 + 零散预告”理解，而按“总图建立 → 三轮速通 → 平台体验收束”理解；
  - 模块1只建框架，不提前承担模块2对象建立、模块3机理解释和模块4设计训练；
  - `1-5` 必须由学生完成第一次平台观察与结构化表达，不能只做教师演示。
