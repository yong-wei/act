# 当前确认摘要

更新时间：2026-03-29

## 当前有效的总蓝图结论

- 课程总主线保持为“结构可见—结构可用—结构可评”。
- 模块编号体系已统一为 `模块1` 至 `模块5`，实践单元不再单列 `P-*` 编号，而是并入模块内连续编号。
- 当前确认的模块学时结构为：
  - 模块1：10学时
  - 模块2：8学时
  - 模块3：18学时
  - 模块4：16学时
  - 模块5：12学时
  - 期末复习：6学时
- 按当前已确认结构，全课程正式口径为 `72学时 = 48学时理论 + 24学时实践`。
- 其中实践学时分为两部分：
  - 课程内部可规划实践：18学时；
  - 教务协同外部实验：6学时，主题占位为时域、频域、非线性。
- 外部实验由不同部门教师负责，不纳入课程内部整体重构，只在对应时机预留占位。

## 各模块当前定位

- 模块1：导论串讲。负责首次课基本概念、课程规范与四次速通中的前三次理论串接，以及平台初体验；当前已确认其职责是“总图建立 + 三轮速通 + 一次平台体验收束”。
- 模块2：建模与基础响应层。负责建立变换语言、模型表达、时域响应对象与频域响应对象，为模块3准备正式分析入口。
- 模块3：结构机理层。按“作用机制”组织，讲清增益、极点、零点、型别、相位如何共同改变系统行为。
- 模块4：约束设计层。作为课程真正重心，把模块3形成的机理语言转化为设计行动。
- 模块5：前沿拓展。保留为主干的一部分，但不承担最核心能力生成任务；当前已强重构为“知识边界与方法迁移层”。

- 模块5当前确认骨架为：
  - `5-1` 线性主干的边界：饱和、死区、滞回、切换与模型失配
  - `5-2` 非线性系统的最小分析入口：局部线性化、相平面与描述函数的边界角色
  - `5-3` 从单回路控制到复杂自主系统链路：MASS 的感知—估计—规划—控制协同
  - `5-4` 从模型驱动到数据驱动：MPC、数据驱动控制与模型依赖松动
  - `5-5` 从显式控制器到策略学习：强化学习的进入条件、收益与风险
  - `5-6` 方法迁移与前沿比较：经典控制、数据驱动与策略学习的同题比较
- 模块5当前进一步确认：
  - 不再按“前沿专题并列罗列”组织，而按“边界识别 → 方法迁移 → 前沿比较 → 工程收束”的迁移链组织；
  - 强化学习只作为方法迁移终点引入，不把模块5写成 RL 算法课；
  - 模块5改为 `5 理论 + 1 实践`，以把全课程内部实践总量压实回 `18h` 约束；
  - 模块5的唯一实践单元负责同题比较经典控制、数据驱动与策略学习三条路线，不做算法实现竞赛。
- 课程作业体系当前进一步确认：
  - 固定为 `7次作业`；
  - 其中 `作业1-6` 为 `3道闭题 + 1道开放题`，`作业7` 为 `2道闭题 + 1道开放题`；
  - 合计形成 `20道闭题题库 + 7段开放主线`；
  - 开放主线按 `O1 → O7` 递进，最终收束为一份自选对象或系统的完整控制方案；
  - 所有闭题统一构成期末题库，后续期末复习必须按题库簇而不是旧章节刷题逻辑重写。
  - `HW1` 边界进一步收紧为“只允许识别、比较、定性判断”，不允许隐含建模；
  - `T1-1` 以极点配置和响应特征匹配为主，正式出题默认采用“极点分布主输入”，不允许把结构图写成需反推传函的变相建模题；
  - `T1-2` 只允许基于题面给出的可见扰动现象做反馈意义辨析，正式出题必须给可见现象对比，不允许抽象化鲁棒性理论论证；
  - `T1-3` 只处理教师给定场景下的四要素识别，而 `O1` 专门承担学生自选对象的问题定义卡。
  - `O1` 进一步固定为“单一自选对象的问题定义卡”，只允许写四要素、闭环必要性与应用目标，不允许提前进入模型、指标和控制结构设想。
  - `T2-1` 固定为模块2入口建模题，正式出题只允许单输入单输出的一阶/二阶对象，不允许把负担转移为复杂机理建模或追加后续分析判断。
  - `T2-2` 固定为模块2中的连接结构求解题，结构复杂度只允许落在代表性例题范围内，梅森公式保持补充工具位阶，不回到技巧训练题。
  - `T2-3` 固定为模块2出口的基础跨域翻译与频域读图题，只允许围绕单一标准对象做时域-频域基础对照、基础 Bode 反识别，或相位裕度/增益裕度的图上读取与简单计算，不允许偷跑到判稳或模块3机理语言。
  - `T3-1` 固定为模块3入口的稳定性计算题，参数自由度只允许单主参数，题目只收口在劳斯阵列、稳定区间与临界条件，不追加动态或设计动作。
  - `T3-2` 固定为模块3中的根轨迹读图题，正式出题必须直接给可读图形或关键节点，不允许把读图题退回复杂手绘题，也不允许偷带后续设计语言。
  - `T3-3` 固定为模块3前半段的结构化判断题，必须给明确冲突情境和图/数据支撑，只允许做优先级判断，不允许滑成缩略版设计题。
  - 开放题 `O1-O7` 当前进一步固定为统一纵向主线：
    - 每次作业总分 `100分`，其中 `HW1-HW6` 的开放题各 `40分`，`HW7` 的开放题为 `50分`；
    - 开放题只设字数上限，不设字数下限；
    - 从 `O2` 开始，所有参考答案与示例结构必须沿用 `O1` 最终选定对象连续展开；
    - 允许使用 AI 协助研究，但必须提交 `AI 使用记录摘要`；
    - 凡涉及计算分析或方案验证的开放题，必须提交 `MATLAB/Octave` 仿真代码、结果图与简短复现实验说明；
    - 开放题统一按“继承连续性 / 本次任务完成度 / 边界控制 / 证据与验证质量 / AI 使用记录摘要”进行分维评分，不再鼓励长文堆砌。
- 模块1当前确认骨架为：
  - `1-1` 基本概念建立、课程规范与学习规则、课程总图发布
  - `1-2` 模型与复平面极点的第一轮速通
  - `1-3` 根轨迹与时域响应的第一轮速通
  - `1-4` 时域响应与频域响应的第一轮速通
  - `1-5` 平台初体验与三域联动探索
- 模块1当前进一步确认：
  - 不再按“导论 + 零散预告”理解，而按“总图建立 → 三轮速通 → 平台体验收束”理解；
  - 模块1只建框架，不提前承担模块2对象建立、模块3机理解释和模块4设计训练；
  - `1-5` 必须由学生完成第一次平台观察与结构化表达，不能只做教师演示。
