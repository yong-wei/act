- 本文件专门记录模块3的单元级设计细节：知识清单、能力清单、边界控制、与前后单元接口。
- 文件开头先给出模块3全部单元的边界详情表，后续再展开单元详细设计。

## 本文件在四类后续产物中的定位

- 本文件是模块3的总体设计文稿，负责把“结构机理层”的单元边界、主线和收束方式固定下来。
- 本文件当前重点不是把每个知识点都讲成最终成稿，而是确保后续四类产物都围绕同一张“机制地图”展开。
- 本文件必须先钉住：
  - 哪些机理首次出现；
  - 哪些内容只允许调用不允许重讲；
  - 哪些实践只做验证、不再新增机理；
  - 哪些知识必须为模块4设计层留出空间。

## 模块3对后续四类产物的模块级接口表

### 讲义设计接口

**模块级组织原则**

- 讲义必须把模块3写成“结构机理地图”，而不是重新长成传统章节拼接版教材。
- 模块3讲义的主线必须稳定保持为：
  - 纯极点语言；
  - 增益推动的根轨迹机制；
  - 零点引入与动态改善；
  - 型别、积分与稳态改善；
  - 频域判别与综合翻译。
- 讲义最重要的任务不是把公式堆满，而是把“为什么这样变”讲透，并为模块4设计语言留接口。

**单元到讲义接口表**

| 单元 | 讲义必须展开的内容 | 讲义可降位处理的内容 | 讲义禁止扩张的内容 |
|------|------------------|--------------------|------------------|
| `3-1` | 纯极点视角下稳定、模态、主导极点、`Bode` 近似对比与卷积实验的解释链 | 高阶对象的过多变体、判稳与设计技巧 | 根轨迹、零点和设计层内容 |
| `3-2` | 普通情形、特殊情况、参数可行域与跨域认识组成的完整劳斯链条 | 大量重复算表训练 | 根轨迹法则系统训练 |
| `3-3` | 根轨迹定义、幅角/幅值条件、完整法则体系与广义根轨迹总视角 | 关键节点精算与高强度手工绘图技巧 | 完整设计题、参数窗口精算与零点补偿设计 |

### 教案设计接口

**模块级组织原则**

- 教案必须把模块3组织成“机理讲授 + 验证实践 + 收束出口”的链条，而不是理论课和实验课互相分离的两条线。
- 教师后台控制的重点应是：
  - 哪些机理是首次进入；
  - 哪些只允许调用不允许重讲；
  - 何时切到平台验证；
  - 何时明确收束到模块4的设计语言。

**单元到教案接口表**

| 单元 | 教师主讲重点 | 教师介入点 | 课堂收束句 |
|------|-------------|-----------|-----------|
| `3-1` | 纯极点本身已经能解释很多动态现象 | 学生把极点只当坐标点、不当机理对象时 | 先看极点自己能说明什么 |
| `3-2` | 劳斯不是算表，而是高阶系统稳定分析与参数筛选工具 | 学生把 `首位为0` 误当成固定物理模式，或把临界边界看成“只是变慢”时 | 稳定边界和参数可行域是后续根轨迹与设计层的起点 |
| `3-3` | 增益变化为什么推动极点沿轨迹迁移，为什么先抓全局骨架就足以解释大趋势 | 学生把根轨迹误当纯画图规则，或急于陷入细节公式时 | 根轨迹先是增益作用的结构语言，再是读图工具 |
| `3-4` | 如何把关键节点、参数窗口和对象差异读成三域判断 | 学生只看一域变化、不做跨域对应，或把读图重新退回纯算点题时 | 图一旦读对，结构、参数和后果会一起出现 |
| `3-5` | 零点改善不是简单增益放大 | 学生把 PD/超前只当不同名字时 | 看零点，不只看控制器名称 |
| `3-6` | 零点线必须和极点线形成对照 | 学生只记“改善了”不说代价时 | 动态改善从来带条件 |
| `3-7` | 误差对象为什么必须按给定/扰动双通道分析，稳态改善为什么总伴随代价 | 学生把静态误差系数表当成所有问题通解，或把积分环节理解成“白送精度”时 | 先分清误差通道，再谈提高型别 |
| `3-8` | 前面所有结构变化都能被翻译到频域 | 学生把判据当新知识孤岛时 | 频域不是新章，而是统一翻译器 |
| `3-9` | 模块3出口是机制地图，不是最优答案 | 学生急于跳到设计结论时 | 先收束机制，再进入设计 |

### 媒体清单接口

**模块级组织原则**

- 模块3的媒体必须优先服务“机理看得见、对照看得见、代价看得见”，不能退回静态公式墙。
- 所有媒体优先分成两类：
  - 静态页面媒体：推导骨架、根轨迹主图、响应曲线、Bode/Nyquist 对照图、结构比较表；
  - 互动状态媒体：预测态、验证态、标注态、对错对照态、版本比较态。

**单元到媒体接口表**

### `3-1（理论） 纯极点视角下的稳定与动态基础`

**定位**

- 在不引入零点、不引入结构改动的前提下，用纯极点语言建立高阶系统稳定、动态与低阶近似判断基础。
- 把“为什么高阶系统仍常能用低阶模型理解”讲成模块3的第一堂双域基础课。
- 为后续根轨迹、零点机制与频域综合语言提供统一的极点出发点。

**前后接口**

- 前接 `2-2` 的低阶时域对象与指标语言，但不重复做一阶/二阶公式训练。
- 前接 `2-4` 的图形对象已可见状态，可调用 `Bode` 图做近似有效性的证据，但不在本课进入 Nyquist 判据或 Bode 判稳。
- 后接 `3-2` 的劳斯操作化与稳定边界可视化。
- 后接 `3-3` 的增益驱动根轨迹迁移机制。
- 后接 `3-8` 的频域综合语言，但不提前讲判稳与裕度。

**课次框架**

1. 从低阶对象回到一般高阶系统：
   提出“低阶系统可由参数和指标解释，那么高阶系统为什么仍然能抓住主要动态”的核心问题。
2. 用特征方程与闭环极点重建稳定底线：
   把稳定、临界稳定、不稳定重新压实为闭环极点位置问题，让左半平面、虚轴、右半平面的含义先稳定下来。
3. 用模态展开、共轭根与重根解释时域特征：
   把极点从“复平面坐标点”转成“运动模态”，说明无重根、共轭复根和重根怎样进入自由响应表达式。
4. 用主导极点与指标映射解释时域近似：
   说明快模态为何会退场，主导模态为何能决定主要超调、调节时间和振荡节奏。
5. 用高阶系统与近似低阶系统的 `Bode` 对比解释频域近似：
   说明被忽略极点在关注频段内影响为何可能很小，以及何时这种近似仍可信。
6. 用卷积数值实验与模态叠加收束：
   说明阶跃响应可以看成多个延时脉冲响应的叠加，并把“输入激发模态”的链条讲闭环。

### `3-2（实践） 稳定边界可视化`

**定位**

- 作为模块3中唯一系统讲透劳斯判据的高阶系统稳定分析课，把 `3-1` 建立的极点语言转化为“不显式求根也能分析高阶系统稳定性与参数可行域”的方法。
- 核心不再只是“看见稳定边界”，而是把劳斯判据讲成一套完整链条：普通判稳、特殊情况处理、跨域解释、参数反推与区域约束。
- 把“稳定 / 临界稳定 / 不稳定”与极点结构、时域响应和频域特性建立起第一轮明确对应，同时为 `3-3` 的根轨迹机制提供越轴与临界振荡直觉，但不提前进入根轨迹法则。

**前后接口**

- 前接 `3-1` 的稳定底线、左半平面条件和高阶纯极点语言，但不重复主导极点近似与双域近似主讲。
- 后接 `3-3` 的增益驱动迁移机制；本课负责把“参数推到哪里会碰到边界、碰到边界会发生什么”讲清，但不解释完整轨迹法则。
- 后接 `4-1 / 4-3` 的任务表达与初始方案形成；本课需先建立“参数先满足稳定可行域，再谈性能优化”的方法论入口。
- 与 `course-content/syllabus-refactor/homework-framework.md` 中 `T3-1` 对齐：闭题主任务仍以高阶系统稳定区间与临界条件为主，但课堂必须把特殊情况和参数设计升华讲透。

**组织方式**

- 采用一个统一高阶对象。
- 以高阶系统为默认对象位阶，不退回二阶模板。
- 采用“一个主对象族 + 两个短例”的组织方式：
  - 主对象族围绕单参数变化展开，负责普通情形、参数稳定范围与跨域对照；
  - 短例 A 负责 `首位为0且非全零行`；
  - 短例 B 负责 `全零行` 与辅助方程。
- 对象要求：
  - 闭环极点随单参数连续变化；
  - 能出现清晰稳定边界；
  - 临界点附近响应变化明显；
  - 结构上保持纯极点语言，不引入零点。
- 推荐对象结构：
  - `积分 + 双惯性环节`
- 该对象在增益增大后会演化出复平面上的共轭分支，可自然过渡到“二阶振荡 + 一阶惯性”的动态表现。

**课堂主线**

1. 用左半平面 / 虚轴 / 右半平面示意，回收 `3-1` 刚建立的稳定底线。
2. 用统一高阶主对象建立普通劳斯表，先讲清“第一列符号变化次数 = 右半平面根数”。
3. 在主对象上求稳定区间和临界参数，并对照极点分布与阶跃响应，说明“边界”不是“系统只是变慢了”。
4. 补入短例 A：讲清 `首位为0且非全零行` 时为什么要用极小正数替代，以及这更像算法奇点而不是一种固定物理模式。
5. 补入短例 B：讲清 `全零行`、辅助方程、虚轴根/对称根结构，以及临界振荡在时域和频域中的表现。
6. 在主对象上继续做典型参数的时域响应、极点位置和基础频率响应对照，形成“劳斯结论—极点结构—时域/频域表现”跨域映射。
7. 用带参数劳斯表把“判稳”提升为“反推参数可行域”。
8. 用变量代换与平移变换说明：如果要求极点落在某条竖线左侧，劳斯判据仍可继续服务参数设计。
9. 用一句桥接收束到后续模块：`3-3` 解释轨迹为何这样走，模块4再把可行域语言转成控制参数选择。

**定位**

### `3-5（理论） 零点引入与动态改善：PD、测速反馈、超前校正与非最小相的多视角审视`

**定位**

- 从根轨迹、频域和控制器结构三个视角讲清零点为什么会带来纯增益调整所没有的新变化。
- 以“零点”而不是“控制器种类”作为组织主轴。

**知识清单**

- 零点对根轨迹的吸引作用。
- 零点引入后闭环极点迁移趋势为什么改变。
- 零点引入后动态改善趋势的时域解释。
- 零点引入带来的相位提前趋势与带宽变化趋势。
- `PD` 与测速反馈的同源性。
- `PD/测速反馈` 与单纯增益校正的连续性与区别。
- 超前校正与 `PD` 的联系与区别。
- 非最小相系统的概念及其基本影响。
- 零点作用的频域解读。

**能力清单**

- 解释零点引入为何不是简单增益放大。
- 区分纯增益调整和零点引入带来的动态改善差异。
- 说明 `PD`、测速反馈与超前校正之间的同源性和差别。
- 识别右半平面零点带来的基本风险。

**边界**

- 不展开完整超前校正设计。
- 不系统展开 Nyquist 判据与 Bode 判稳。
- 不进入模块4的控制器选型与参数整定流程。

**建议课堂组织主线**

- 从 `3-4` 的边界回收：只调增益为什么很快不够。
- 先固定同一基准对象，比较“无零点 / 引入零点 / 不引入零点但改善阻尼”三类变化。
- 再把 `PD`、测速反馈、简单超前统一翻译为“结构怎样变、零点在哪里、极点为什么跟着变”。
- 最后用右半平面零点做教师演示，明确“不是所有零点都带来直观改善”。

**本课必须压实的三组对照**

- `纯增益调整 vs 零点引入`：
  - 重点回答“为什么轨迹和动态变化不再只是原轨迹上的平移”。
- `PD vs 测速反馈`：

### `3-7（理论） 型别、积分环节与稳态改善：PI与滞后校正的低频补偿机理`

**定位**

- 讲清误差为什么会在给定输入与外加扰动作用下出现，以及系统结构为什么会决定这些误差能否被根本消除。
- 作为模块3中“稳态改善线”的正式建立课，系统讲透闭环传递函数、误差传递函数、终值定理与静态误差系数，不再把它们散落在模块2的结构工具课或后续设计课里。
- 与 `3-5/3-6` 的“动态改善线”形成明确对照：前者回答“为什么还能更准”，后者回答“为什么能更快更稳”。

**建议课堂组织主线**

- 先从 `3-6` 回收一句核心结论：
  - 零点主导的动态改善并没有直接回答“误差为什么还能继续变小”。
- 第一段先立“误差两类来源”对象：
  - 一类来自系统结构本身，决定某类输入下误差能否被根本消除；
  - 一类来自输入信号形式，决定同一结构下误差会以何种方式暴露出来；
  - 对扰动问题，要显式说明它是通过扰动通道进入闭环，而不是被“输入型别表”直接替代。
- 第二段把“闭环对象”与“误差对象”都正式列出：
  - 输入作用下的闭环传递函数；
  - 扰动作用下的闭环传递函数；
  - 系统总输出与系统总误差的叠加表达；
  - 输入作用下与扰动作用下的误差传递函数。
- 第三段把“直接求”路径压实：
  - 必须先判定系统稳定；
  - 再基于输入/扰动通道写出闭环与误差传递函数；
  - 再用终值定理求稳态误差，并说明终值定理的适用前提。
- 第四段再把“快速判”路径压实：
  - 先把开环低频结构整理为型别与误差系数；
  - 再做 `Kp/Kv/Ka` 与输入类型匹配；
  - 最后明确“静态误差系数法主要解决给定输入下的快速判断，不能机械替代所有扰动分析”。
- 第五段明确“增益变大”和“型别提高”不是一回事：
  - 单纯增益只能在部分情况下减小误差；
  - 引入积分才是在结构上改变误差阶次。
- 第六段再比较 `PI` 与滞后校正：
  - 两者都站在“低频补偿线”上；
  - 但一个主要通过积分提高型别，一个主要通过低频增益重分配改善精度。
- 最后一段必须显式收束到 `3-8`：
  - 为什么积分和滞后主要影响低频；
  - 为什么改善稳态通常伴随动态代价与频域代价；
  - 下一课才把这种代价翻译成完整频域判断语言。

**知识清单**

- 误差的两类来源：
  - 系统结构来源；
  - 输入信号来源。
- 给定输入与外加扰动在闭环中的进入方式。
- 输入作用下的闭环传递函数。
- 扰动作用下的闭环传递函数。
- 系统总输出与系统总误差的表达。

- 扰动作用下的误差传递函数。
- 终值定理及其适用前提。

- `Kp/Kv/Ka` 与稳态误差的对应关系。

- 区分 `PI` 与滞后校正。
- 形成“积分还是滞后”的初步判断语言。
- 用“目标是稳态精度还是动态品质”区分不同补偿思路。

**本课必须压实的六组对照**

- `输入作用下闭环传递函数 vs 扰动作用下闭环传递函数`：
  - 重点回答“同一闭环结构下，不同信号从哪条通道进入、最后影响的是输出的哪一部分”。
- `系统总输出/总误差分解 vs 只盯单一路径`：
  - 重点回答“为什么总输出是多通道叠加结果，总误差也必须按通道来源拆开分析”。
- `终值定理直接求解 vs 型别/误差系数快速判断`：
  - 重点回答“什么时候该完整列式，什么时候可以先用结构判断快速估计”。
- `给定输入快速判断 vs 扰动问题完整列式`：
  - 重点回答“为什么 `Kp/Kv/Ka` 表主要服务给定输入，而扰动问题更需要回到误差传递函数和终值定理”。
- `增益增大 vs 型别提高`：
  - 重点回答“为什么前者通常只是减小误差，后者才可能根本消除某类输入下的稳态误差”。
- `PI vs 滞后校正`：
  - 重点回答“为什么两者都能改善稳态精度，但型别变化、动态代价和后续设计调用完全不同”。
- `动态改善线 vs 稳态改善线`：
  - 重点回答“为什么 `PD/超前` 主要回答快慢与阻尼，`积分/滞后` 主要回答精度与低频补偿”。

### `3-8（理论） 频域判别与跨域综合语言`

**定位**

- 作为模块3最后一个理论收束点，把 `3-1` 到 `3-7` 的机制线统一翻译成频域语言。
- 先做结构变化的频域翻译，再收束到频域判据与综合判断，不按“判据清单”顺序平推。

**建议课堂组织主线**

- 第一段先回收 `3-5/3-7` 的两条线：
  - 零点主导的动态改善线；
  - 积分/滞后主导的稳态改善线。
- 先回答“同样是结构变了，为什么在频域里看起来完全不同”，再进入判据。
- 第二段用 `pptx/16` 与 `pptx/21` 建立“频域不是新章节，而是统一翻译器”的总图：
  - 增益变化更像开环幅频曲线的整体抬升/平移；
  - 零点变化更多体现在中频相位与穿越位置改变；
  - 积分/滞后主要重塑低频与中低频段的代价分布；
  - 高频段则负责解释“为什么不是越快越好”。
- 第三段再进入 `pptx/19` 的正式判稳语言：
  - 奈奎斯特判据不是额外新规则，而是把闭环求根问题改写为开环曲线如何对待 `(-1,j0)`；
  - Bode 判稳也不是独立判据，而是对奈奎斯特穿越规则的对数图表达。
- 第四段最后用船舶频域案例把“开环图上怎么读”拉回“闭环性能会怎样”：
  - 航向控制例子负责把裕度、带宽与阶跃指标对上；
  - 稳定平台例子负责把谐振峰值、相角裕度、超调和调节时间对上；
  - 收束到模块4入口：频域语言的价值不止是判稳，而是帮助做任务表达与方案判断。

**知识清单**

- 增益变化在频域中的表现。
- 零点变化在频域中的表现。

**能力清单**

- `增益抬升 vs 零点引入 vs 积分/滞后补偿`：
  - 重点回答“为什么这三类变化在 Bode/Nyquist 上留下的痕迹不同，因此不能只用‘增益变大了’一句话概括”。

  - 重点回答“为什么两者描述的是同一件事，而不是两套互不相干的稳定判据”。

- `最小相对象 vs 非最小相对象`：
  - 重点回答“为什么相位代价会改变我们对‘更快更大带宽’的直觉”。

  - 前台页面至少要有一处“先预测结构变化会怎样影响频域图，再验证”的任务。
  - 必须至少有一处“由频域量反推动态品质”的任务，不做纯图形识别练习。
  - 船舶案例页面只做读图、判断和一句话解释，不做完整校正参数搜索。
- 媒体清单：
  - 必须准备三频段总图、`(-1,j0)` 包围示意图、`Bode/Nyquist/极点语言` 对照图。
  - 必须准备航向控制与稳定平台两个案例的开环/闭环频域图与对应时域曲线。
  - 如复用 `pptx/19` 或 `pptx/21` 图示，标题口径统一改写为“频域判断链”，不能保留旧课件式章节标题。

### `3-9（实践） 稳定—动态—稳态综合映射实验`

**定位**

- 作为模块3的出口实践，把稳定边界、极点/根轨迹、零点动态改善、型别/积分稳态改善和频域判据统一收束为一张跨域机制地图。
- 不新增机制，但必须把“结构变化会优先解决什么问题、又会额外带来什么代价”收束成模块4可调用的第一轮任务判断。

**建议课堂组织主线**

- 第一段先从 `3-8` 回收统一语言：
  - 频域不是新章，而是把 `3-1` 到 `3-7` 的结构变化重新翻译成同一张判断图；
  - 本课不是再讲一个新控制器，而是检验学生能否把这张图真正用于同一对象的多版本比较。
- 第二段固定围绕同一工程对象展开：
  - 先看基准版本；
  - 再看积分引入版本；
  - 再看学生自选的极点线补强或零点线补强版本；
  - 先不给“最优方案”，只要求学生先打标签：更偏向改善动态、改善稳态，还是以牺牲裕度换取速度。
- 第三段把比较顺序固定为：
  - 先看极点/根轨迹给出的第一信号；
  - 再看阶跃响应确认动态与稳态后果；
  - 最后回到 `Bode / Nyquist` 检查三频段、带宽与裕度代价；
  - 重点回答“哪一域最先暴露收益，哪一域最先暴露代价”。
- 第四段由教师演示滞后版本：
  - 不把它当成“第四个学生必做版本”，而是专门用来对照“积分改善稳态”与“滞后改善稳态”的差别；
  - 重点压实“同样是在低频补偿，为什么频域代价和动态代价并不一样”。
- 第五段最后收束到模块4入口：
  - 学生只能给出“哪条机制线更适合先承担哪类任务”的判断；
  - 不能直接越级给出完整控制器选型、参数整定和唯一最优结论。

**组织方式**

- 一个统一对象，默认采用与 `3-4 / 3-8` 连续的船舶航向控制对象。
- 3个学生必做版本：
  - 基准版本；
  - 积分引入的稳态改善版本；
  - 学生自选补强版本：
    - 极点线补强版本；或
    - 零点线补强版本。
- 1个教师演示版本：
  - 滞后校正。

**本课必须压实的四组判断**

- `极点线补强 vs 零点线补强`：
  - 重点回答“二者都可能让系统看起来更快，但在根轨迹、频域和代价分布上为什么不是一回事”。
- `积分改善 vs 滞后改善`：
  - 重点回答“二者都指向稳态改善，但低频收益、中频代价和实现难度为什么不同”。
- `极点/根轨迹第一信号 vs 阶跃验证 vs 频域复核`：
  - 重点回答“同一个版本应先看哪一域得到初判，再用哪一域补足风险信息”。
- `任务标签 vs 机制标签`：
  - 重点回答“学生说‘我想让它更快/更准/更稳’时，究竟应该先想到哪条机制线，而不是直接跳成控制器名称”。

**任务**

- 先对三个学生必做版本做预判：
  - 稳定性趋势；
  - 动态品质趋势；
  - 稳态误差趋势；
  - 频域指标趋势。
- 先为每个版本填写“任务标签”：
  - 更偏动态改善；
  - 更偏稳态改善；
  - 更偏综合折中；
  - 当前主要风险点。
- 在平台中逐个验证：
  - 极点/根轨迹；
  - 阶跃响应；
  - Bode / Nyquist 关键特征。
- 填写综合映射表：
  - 改了什么结构；
  - 极点/轨迹怎么变；
  - 时域怎么变；
  - 频域怎么变；
  - 稳态怎么变；
  - 主要收益；
  - 主要代价。
- 观看教师演示的滞后版本，补上“稳态改善的另一条路径”。
- 写出模块出口结论：
  - 哪类变化主要改善动态；
  - 哪类变化主要改善稳态；
  - 哪类变化更容易先吃掉裕度或带宽；
  - 为什么不同路径的代价不同。
