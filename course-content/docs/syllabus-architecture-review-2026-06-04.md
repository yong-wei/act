# 自动控制原理课程大纲 — 架构级审视与重构建议

评估日期：2026-06-04
评估范围：72 学时完整大纲（模块 1-5 + 期末复习），对照 31 份已写成的讲义反推实际执行状态
评估目的：在开始讲义修订前，确认大纲架构的合理性，确保最终合订本具备可出版品质

---

## 一、总体架构判断

### 1.1 设计理念：创新且站得住

当前大纲的核心设计——"先见森林，再见树木" + "机制主导" + "设计链"——代表了对传统自动控制原理教学体系的**真正重构**，而非表面翻新。三个设计支柱各自的判断：

| 设计支柱 | 创新度 | 教学合理性 | 执行状态 |
|---------|:---:|:---:|:---:|
| 模块1 先见森林（10h 速通五轮） | 高 | 强——解决了传统教学中"学到第8周还不知道整门课在干什么"的问题 | 讲义已基本就绪，8 项已知问题待修复 |
| 模块3 机制主导（按因果链而非方法章组织） | 最高 | 强——"极点→增益迁移→零点引入→型别改善→频域翻译"的因果链比传统章节拼接更符合认知规律 | 9 份讲义质量最高，已基本可试运行 |
| 模块4 优化设计链（从校正方法课转型为设计决策课） | 高 | 中强——理念先进但执行存在瓶颈单元 | 7 份讲义已完成但 4-2/4-6 密度过大 |

### 1.2 全局学时分配：基本合理，存在局部压力

```
模块1 ████████░░░░░░░░░░ 10h (14%)  框架建构
模块2 ██████░░░░░░░░░░░░  8h (11%)  对象建立
模块3 ██████████████░░░░ 18h (25%)  机制贯通  ← 最大模块
模块4 ███████████░░░░░░░ 14h (19%)  约束设计
模块5 █████████░░░░░░░░░ 12h (17%)  边界迁移
复习  ███░░░░░░░░░░░░░░░  4h (6%)   综合收束
外部  █████░░░░░░░░░░░░░  6h (8%)   教务协同
```

与胡寿松《自动控制原理》（第8版）教材章学时对比：

| 传统章 | 传统学时（估） | 当前课程对应 | 变化 |
|------|:---:|------|------|
| 第1章 概论 | ~4h | 模块1（10h） | ↑ 大幅扩展为"框架建构层" |
| 第2章 数学模型 | ~10h | 模块2 的 2-1（2h）+ 模块3 散布 | ↓ 压缩建模工具训练，拆分到后续单元 |
| 第3章 时域分析 | ~12h | 模块2 的 2-2（2h）+ 模块3 的 3-1/3-2/3-7（6h） | ↓ 压缩计算训练，强化机理解释 |
| 第4章 根轨迹 | ~10h | 模块3 的 3-3/3-4（4h） | ↓ 压缩手工绘图，强化读图判断 |
| 第5章 频域分析 | ~14h | 模块2 的 2-3/2-4（4h）+ 模块3 的 3-8（2h） | ↓ 大幅压缩，前移对象建立 |
| 第6章 校正 | ~12h | 模块3 的 3-5/3-6/3-7（6h）+ 模块4（14h） | ↑ 拆分为"机理"+"设计"两层 |
| 无对应 | — | 模块5（12h） | ⊕ 新增"知识边界与方法迁移" |

**整体判断**：压缩传统计算训练（约释放 8h），新增前沿与设计内容（约增加 12h+），净增 4h 来自外部实验占位的重新规划。方向正确，但个别位置的压缩程度需要审视（见下文）。

## 二、模块边界分析

### 2.1 模块 1 → 模块 2：直觉 → 形式化

**边界定义**：M1 只建骨架不做推导，M2 将骨架转成正式分析语言。

**判断**：✅ 边界清晰且必要。这是"先见森林"策略的核心交接点。

**潜在风险**：M1 的 1-5（平台三域体验）中出现了 Bode 图和相位裕度，但 M1 的 AI 边界明确禁止"提前讲 Bode 图"。学生在 1-5 中面对 Bode 图时会处于"会用但不懂"的状态。这不一定是问题——先操作、后理解也是合理的学习路径——但需要在 2-3 正式引入 Bode 图时做显式回收："你们在 1-5 已经拖动过这些曲线，今天我们来理解它们为什么长这样。"

### 2.2 模块 2 → 模块 3：对象 → 机理

**边界定义**：M2 提供分析语言（传递函数、时域指标、频域图形），M3 用这套语言解释"为什么"。

**判断**：⚠️ 边界理论上清晰，但实际执行中存在两个结构性问题。

**问题 A：M2 的信息密度与其学时严重不匹配**

M2 在 8 学时内需要完成：
- 拉氏变换 + 传递函数 + 典型环节 + 结构图 + 信号流图 + 梅森公式（2-1）
- 一阶/二阶时域响应完整推导 + 四个性能指标（2-2）
- 傅里叶级数/变换 + G(jω) + 频率特性 + 典型环节 Bode 图 + 手绘骨架（2-3）
- Nyquist 图 + Bode/Nyquist 对照 + 相位裕度/增益裕度 + 反向识别（2-4）

传统教材中这些内容通常需要 20-24 学时。8 学时完成意味着大量内容被压缩为"定义 + 结论 + 最小例题"，学生几乎没有消化时间。**M2 是整门课中单学时知识密度最高的模块。**

**问题 B：频域对象前移的连锁效应**

实际讲义已将 Bode/Nyquist 从模块 3 前移至模块 2。这意味着：
- 学生在学完根轨迹之前就已经接触了频域图形
- 频域在 M2 中只作为"另一种观察方式"出现，不承担判稳功能
- 从 2-4（学 Bode/Nyquist 读图）到 3-8（用 Bode/Nyquist 做判稳）之间有 **14 个教学单元** 的间隔

这 14 单元的"悬置期"是当前架构中最值得讨论的设计决策。支持者会说这符合"先见森林"——学生先认识工具，后面再学会用工具。反对者会说 14 单元太长，学生到 3-8 时已经忘记了 2-3/2-4 的内容。

**建议**：保留频域对象在 M2 的定位（这比传统"先讲完时域再讲频域"更合理），但在 3-3（根轨迹）和 3-5（零点）中增加对频域图形的轻量回看，维持频域语言的热度。

### 2.3 模块 3 → 模块 4：机理 → 设计

**边界定义**：M3 解释"为什么这样变"，M4 回答"知道为什么后该怎么做"。

**判断**：✅ 这是课程架构中最成功的边界设计。M3 的出口实践（3-9 综合映射实验）直接产生"M4 可直接调用的跨域机制地图"，M4 的入口课（4-1 任务表达）正是"把分析量改写成任务书"。两个模块之间形成了自然的概念接力。

**唯一需要警惕的**：M3 中 3-5/3-6（零点动态改善）和 3-7（稳态改善）已经涉及了 PD、PI、超前、滞后的参数设计。M4 的 4-2（控制器选型）不应重复这些内容，而应直接调用 M3 的机理结论——"在 M3 中你已知道 PD 改善动态的机理，现在我们来回答：面对一个具体任务，为什么先选它而非 PI。"

### 2.4 模块 4 → 模块 5：设计 → 边界

**边界定义**：M4 在经典线性框架内完成设计闭环，M5 揭示这个框架的边界。

**判断**：✅ 边界清晰。M4 的 4-7 末尾已埋入"M5 入口"（传统控制的四类局限）。这是全课程最自然的收束方式——先让学生把经典方法用到极致，再让他们看到边界在哪里。

## 三、单元级知识密度分析

### 3.1 密度分级标准

| 级别 | 定义 | 判断标准 |
|:---:|------|------|
| 🔴 过载 | 2 学时无法有效覆盖 | 传统教学需要 6h+ 的内容，或同时引入 4+ 个新概念体系 |
| 🟡 偏重 | 需要精准控时才能完成 | 传统教学需要 4-6h 的内容，或同时引入 2-3 个新概念体系 |
| 🟢 适中 | 2 学时可以完整展开 | 有足够时间做引入→推导→例题→练习的完整循环 |
| ⚪ 偏轻 | 内容可能不足 2 学时 | 可以合并或增加练习深度 |

### 3.2 各单元密度评估

#### 模块 1（10h）

| 单元 | 密度 | 判断依据 |
|------|:---:|------|
| 1-1 | 🟢 | 概念建立 + 术语基线 + 课程总图，内容量适合 2h |
| 1-2 | 🟢 | 模型直觉 + 极点直觉 + 复平面读图，直觉建立不追求推导完整 |
| 1-3 | 🟢 | 根轨迹雏形 + 时域联动，只用二阶示例，克制不进入正式法则 |
| 1-4 | 🟢 | 时域/频域并置，只做定性直觉不做计算 |
| 1-5 | 🟢 | 平台体验，操作+观察为主 |

→ M1 密度整体偏低，但这**符合设计意图**——"速通"阶段的克制是刻意为之。

#### 模块 2（8h）

| 单元 | 密度 | 判断依据 |
|------|:---:|------|
| 2-1 | 🔴 | 拉氏变换 + 微分方程→传递函数 + 五大典型环节 + 方框图三类连接 + 信号流图 + 梅森公式 → 传统 6-8h 内容压缩至 2h |
| 2-2 | 🟡 | 一阶/二阶完整推导 + 四个性能指标公式 + 阻尼比/自然频率映射 + 正反两道例题 → 传统 4-6h 内容 |
| 2-3 | 🔴 | 傅里叶级数/变换思想 + 正弦稳态响应 + G(jω) + Bode 概念 + 对数坐标理由 + 典型环节 Bode + 手绘骨架 + s=jω 合法性 → 传统 6-8h 内容 |
| 2-4 | 🟡 | Nyquist 原理 + 纯极点轨迹 + Bode/Nyquist 对照 + 五个频域指标 + 反向识别 → 传统 4-6h 内容 |

→ **M2 是全课程密度最高的模块。** 四个单元中两个 🔴 过载、两个 🟡 偏重。这是"M2 只有 8h 但承担了整门课的形式化基础"这一结构性矛盾的直接体现。

**缓解策略**（不增加学时的前提下）：
- 2-1：信号流图和梅森公式降为"补充工具"（讲义已执行），方框图化简只保留串/并/反馈三类
- 2-2：部分指标公式转入练习，课堂只讲推导主链和物理含义（设计文档已规定）
- 2-3：傅里叶部分只讲思想不讲推导，以"阶跃→方波→分量→正弦响应→重构"为主线
- 2-4：严格限制在纯极点系统，不引入零点系统的 Nyquist 图

#### 模块 3（18h）

| 单元 | 密度 | 判断依据 |
|------|:---:|------|
| 3-1 | 🟡 | 极点→模态→主导极点→双域近似→卷积实验 → 概念密集但逻辑链清晰 |
| 3-2 | 🟢 | 实践课，劳斯判据操作化 + 特殊情况 + 参数可行域 |
| 3-3 | 🔴 | 根轨迹定义 + 幅角/幅值条件 + 九项完整法则 → 传统 4-6h 内容 |
| 3-4 | 🟢 | 实践课，关键节点读图 + 广义根轨迹 + 主导极点验证 |
| 3-5 | 🟡 | 零点吸引 + PD/测速反馈/超前同源性 + 非最小相 → 三组对照密度高 |
| 3-6 | 🟢 | 实践课，五任务统一对象实验 |
| 3-7 | 🔴 | 双通道误差传递函数 + 终值定理 + 型别 + Kp/Kv/Ka + PI/滞后机理 → 传统 6h 内容 |
| 3-8 | 🔴 | 四类频域指纹 + 幅角原理→Nyquist 判据 + Bode 判稳 + 三频段理论 + 两个综合案例 → 全课程单单元密度最高 |
| 3-9 | 🟢 | 实践课，三个版本比较 + 积分家族谱系 + 综合映射表 |

→ M3 是内容最丰富的模块。三个 🔴 单元（3-3、3-7、3-8）都集中在理论侧。但 M3 有实践单元作为"减载缓冲"（3-2 吸收劳斯操作化、3-4 吸收广义根轨迹），部分缓解了理论单元的压力。

**3-8 值得特别讨论**：它是模块 3 的"统一翻译器"——需要在一节课内把前面七条机制线全部翻译为频域语言，同时还要首次引入 Nyquist 判据和 Bode 判稳。这可能是全课程中认知负担最大的 2 学时。

**缓解策略**：
- 3-3：长推导规则（出射角/入射角）可放附录，正文只讲规则用途和读图方法
- 3-7：型别表可压缩为速查卡，PI/滞后设计链保留但参数求解精简
- 3-8：Nyquist 判据的幅角原理推导可精简为"三个关键问题"式讲授（F(s)为何旋转、为何看 GH=-1、为何临界点是(-1,0)），三频段理论与前面单元的频域指纹合并

#### 模块 4（14h）

| 单元 | 密度 | 判断依据 |
|------|:---:|------|
| 4-1 | 🟢 | 指标体系 + 约束分类 + 任务书写法 + 可行域分层 |
| 4-2 | 🔴 | 八种控制结构 + 选型决策树 + 四种整定方法（ZN/频域/模型匹配/前馈）+ 五个例题 → 传统 6-8h 内容 |
| 4-3 | 🟢 | 实践课，复合方案分步建构 |
| 4-4 | 🟡 | 优化建模（目标函数构造 + 归一化 + 权重 + Pareto）→ 新概念体系，但逻辑链清晰 |
| 4-5 | 🟢 | 实践课，约束翻译 + 罚函数/fmincon |
| 4-6 | 🔴 | 场景迁移 + 目标重写 + 五类结构编码（含有效/忽略槽位）+ 混合编码搜索 + GA/PSO → 四套新概念体系 |

**4-2 是最需要重新审视的单元**。当前的"8 种结构全覆盖 + 四种整定方法"模式如果不加控制，课堂会退化为"方法目录浏览"。建议的收束策略：
- 主战线：围绕客船航向的**一个主矛盾**，比较 PI 和 PD 两条路线的定量差异
- 前馈线：讲透按输入补偿和按扰动补偿两条路径
- 其余结构（PID、超前、滞后、超前-滞后）降为速查表+"后续单元会用到时再展开"
- 四种整定方法精选两种（频域法 + ZN），其余作为课后参考

### 3.3 密度分布总览

```
单元密度分布（31个单元）：

🔴 过载：2-1, 2-3, 3-3, 3-7, 3-8, 4-2, 4-6  （7个，23%）
🟡 偏重：2-2, 2-4, 3-1, 3-5, 4-4, 4-7, 5-2  （7个，23%）

过载和偏重单元合计 45%，其中 M2 占 4 个、M3 占 5 个、M4 占 4 个。**这不是个别单元的问题，而是整个课程的知识压缩策略在 M2-M4 的集中体现。** 需要系统性审视——哪些压缩是合理的"减负"，哪些压缩会导致"夹生饭"。

## 四、前置依赖链完整性

### 4.1 宏观依赖链

```
M1（直觉层）
  ↓
M2（对象层）──→ 外部时域实验
  ↓
M3（机理层）──→ 外部频域实验
  ↓
M4（设计层）
  ↓
M5（边界层）
  ↓
期末复习
```

✅ 宏观链完整，不存在循环依赖或跳跃。

### 4.2 关键依赖路径逐条检查

| 依赖关系 | 状态 | 说明 |
|------|:---:|------|
| M1→M2 | ✅ | M1 提供术语基线和直觉底板，M2 将其形式化 |
| M2→M3 | ⚠️ | M2 提供的四类对象语言（传递函数、时域指标、频域图形）被 M3 全面调用，但 M3 开头缺少显式回收 |
| M2-2→M3-1 | ✅ | 一二阶时域响应是 3-1 主导极点近似的前置 |
| M3-1→M3-2 | ✅ | 极点语言是劳斯判据的前置 |
| M3-2→M3-3 | ✅ | 稳定边界意识是根轨迹迁移机制的前置 |
| M3-3→M3-4 | ✅ | 普通根轨迹法则是广义根轨迹实践的前置 |
| M3-3→M3-5 | ✅ | 根轨迹语言是零点吸引作用的前提 |
| M3-5→M3-6 | ✅ | 零点机理是零点设计实验的前置 |

### 4.3 发现的依赖链问题

**问题 1：M2 频域对象 → M3 频域判稳的 14 单元悬置**

2-3/2-4 建立的 Bode/Nyquist 读图能力在 14 个教学单元后才在 3-8 被正式调用。中间经历了：
- 3-1 纯极点语言
- 3-2 劳斯判据
- 3-3 根轨迹法则
- 3-4 根轨迹读图
- 3-5 零点动态改善
- 3-6 零点设计实验
- 3-7 稳态改善

建议在这些中间单元中增加对频域图形的轻量回看：
- 3-3 末尾："如果把这个根轨迹变化翻译到 Bode 图上，你会看到什么？"（一句话预告）
- 3-5 中："零点引入不仅改变根轨迹骨架，在频域中也会留下特征痕迹——3-8 会专门讨论"

**问题 2：3-7（稳态改善）的前置回收不完整**

3-7 需要学生回忆 2-1 的结构图/信号流图工具来做双通道误差分析，但 2-1 到 3-7 间隔了 11 个单元。讲义目前假设学生能直接上手写闭环传递函数和误差传递函数，但实际中学生可能已经生疏。

建议在 3-7 讲义开头增加一个"工具回收框"（半页篇幅），快速回顾结构图化简和信号流图的基本操作。

### 5.1 [C] → [X] → [D] 三阶段设计

```
模块2 [C] 计算型    →  模块3 [X] 跨域型    →  模块4 [D] 设计型    →  模块5 边界
─────────────────      ─────────────────      ─────────────────      ─────────
传递函数计算            极点→模态映射           任务书构造              线性边界识别
时域指标计算            根轨迹→时域→频域        结构选型                非线性入口
频域图形绘制            零点→动态改善           方案落地                迁移判断
手绘Bode/Nyquist       型别→稳态改善           优化建模                方法比较
                        频域统一翻译            约束优化
                                                场景迁移

**判断**：✅ 这是课程架构中最成功的设计线。三类知识的递进符合 Bloom 认知层次，且每个模块的重心明确。但需要注意一点：实际教学中 [C]/[X]/[D] 并非严格按模块分隔——M3 中 3-6（零点设计实验）已经涉及 [D] 型任务，M4 中 4-2（控制器选型）大量调用 [X] 型判断。这种"交叠"是健康的，不是问题。

## 六、与可出版教材的差距分析

### 6.1 当前讲义的出版级优势

| 维度 | 当前状态 |
|------|------|
| 教学内容原创性 | **强**——机制主导组织、优化设计链、迁移链均为原创设计 |
| 写作质量 | **强**——"我们"视角统一，问题驱动引入，克制标注到位 |
| 案例体系 | **强**——船舶锚点案例贯穿全课，工程场景真实可追溯 |
| 练习设计 | **中强**——分层练习（基础识别→比较判断→迁移应用）设计一致 |
| 数学严谨性 | **中**——推导链完整但附录和正文的分工需更明确 |

### 6.2 需要补齐的教材要素

**A. 数学基础的系统性处理**

目前数学工具（拉氏变换、傅里叶变换、复变函数）分散在各个单元中按需引入。教材需要一个集中的"数学基础附录"或"数学工具箱"章节，至少覆盖：
- 拉氏变换表与常用性质
- 傅里叶变换与拉氏变换的关系
- 复数的几何意义与复平面操作
- 部分分式展开的标准流程

这可以作为合订本的附录出现，每个单元只需引用而不重讲。

**B. 完整的符号约定表**

`authoring/terminology.md` 已提供了基础，但教材合订本需要在**卷首**发布一个完整的符号约定页，让读者在任何位置遇到符号都能回溯其含义。当前存在 $G_0(s)$ vs $G_{\mathrm{o}}(s)$ 的不一致，合订本前必须统一。

**C. 端到端的运行案例**

船舶航向控制是贯穿全课的锚点案例，但它目前分散在各单元中作为独立段落。教材需要一个**贯穿全书的运行案例附录**，将同一个 Nomoto 模型从模块 1 的"控制语言描述"到模块 2 的"传递函数建立"到模块 3 的"根轨迹/频域分析"到模块 4 的"控制器优化设计"到模块 5 的"非线性边界与数据驱动迁移"串联成一条完整链。

**D. 习题体系**

`homework-framework.md` 设计了 20 道闭题 + 7 道开放题，但教材合订本需要**每单元末尾的课后习题**，按难度分级（基础计算/概念判断/综合迁移），并有参考答案（至少奇数题）。

**E. 平台依赖的抽象化**

当前讲义大量引用"AI-OBE 船舶智控平台"的特定操作。对于可出版教材，需要将平台特定操作抽象为"仿真实验"或"交互式探索"的通用描述，使不接入该平台的读者仍能理解教学意图。具体的平台操作说明可以作为"教学平台使用指南"独立成册。

**F. 教师用书**

当前有 24 份教师版讲义（覆盖 M2-M5），但 M1 缺失。教师用书需要系统覆盖全部 31 个单元，包括：常见学生误判、课堂介入时机、板书组织建议、替代教学路径。

### 6.3 出版路径建议

考虑到当前状态，建议分三阶段走向出版：

**第一阶段（本学期）**：完成大纲定稿 + 修复已知问题 + 同步设计文档
**第二阶段（1-2 学期）**：课堂试运行 → 收集学生反馈 → 调整密度和节奏
**第三阶段（2-3 学期后）**：基于试运行数据，将讲义系统修订为教材合订本

## 七、大纲结构调整建议

### 7.1 不需要改变的结构（已确认合理）

以下结构经过了深度重构和实践检验，建议保持：

1. ✅ 模块 1 的"五轮速通"设计（1-1 总图→1-2 极点→1-3 根轨迹→1-4 频域→1-5 平台收束）
2. ✅ 模块 3 的"机制主导"组织（极点→增益→零点→型别→频域翻译）
3. ✅ 模块 3 的理论-实践交替节奏
4. ✅ 模块 4→5 的"设计→边界"收束路径
5. ✅ [C]→[X]→[D] 的知识类型递进

### 7.2 需要考虑调整的结构

**调整 1：模块 2 重新定位**

当前矛盾：M2 名为"建模与基础响应层"但实际承担了整门课的形式化基础，8 学时严重不足。

选项 A（推荐）：保持 8 学时不变，但将 M2 的定位从"基础响应层"升格为"**对象与语言层**"，承认它已经不再是"基础响应"而是整门课的共同语言基础。同时严格执行已设计的降位策略（信号流图/梅森降为补充工具，傅里叶只讲思想，手绘只做到骨架）。

选项 B：将 M2 拆分为 10 学时（从 M3 或期末复习抽 2 学时），给 2-1 和 2-3 各增加 1 学时。代价是 M3 或期末复习更紧张。

选项 C：将频域对象（2-3/2-4）移回 M3 开头，恢复传统"先时域后频域"的顺序。代价是失去"对象建立链"的连贯性。

**推荐选项 A。** M2 的密度问题可以通过严格执行降位策略来控制，不需要动学时。关键在于明确：M2 的目标不是"教会所有计算技巧"，而是"建立后续可调用的统一语言"。

**调整 2：4-2 的内容收束**

当前问题：4-2 在一个单元内覆盖 8 种控制结构 + 4 种整定方法。

建议：将 4-2 的内容分层——
- **课堂主线**（必讲）：围绕客船航向的一个主矛盾，完成 PI/滞后 与 PD/超前 的定量比较 + 前馈的两条路径
- **速查卡**（自读）：其余结构（PID 完整形式、超前-滞后组合）的频域特征和适用场景以速查表形式附录
- **整定方法**（精选）：频域整定法作为主线、ZN 法作为快速入口，其余（IMC/SIMC、极点配置）降为课后延伸阅读

**调整 3：4-6 的负载拆分**

当前问题：场景迁移 + 目标重写 + 结构编码 + GA/PSO 四套新概念在一个单元。

建议：
- 将结构编码和 GA/PSO 拆分为 4-6 的"第二部分"或独立附录，课堂只讲"结构编码为什么会出现"的最小思想，具体编码规则和 GA/PSO 的算法细节作为课后阅读
- 或者：将 4-6 和 4-7 重新整合——4-6 专注"场景迁移 + 固定结构失效证据"，4-7 再讲"结构编码搜索 + 解码解释"

**调整 4：3-8 的频域判据前置铺垫**

当前问题：3-8 是模块 3 的"统一翻译器"，但 Nyquist 判据、Bode 判稳和三频段理论都是首次出现。

建议：不改变 3-8 的主体结构，但在 M2 的 2-4（Nyquist 图与频域指标）末尾增加一句明确预告："这里你们已经会读相位裕度和增益裕度了。至于为什么裕度小到一定程度系统就会失稳，以及怎样用 Nyquist 图直接判稳——这些将在模块 3 的频域综合语言课中正式展开。"让学生知道手中的工具尚未完整，但不提前揭开答案。

### 7.3 建议的新增大纲元素

**新增 1：模块 2 末尾增加"对象语言收束"半页**

在 2-4 末尾增加一个"模块 2 出口检查"，将四类对象的调用关系画成一张图，告诉学生"你现在拥有的语言工具箱里有什么，每件工具将在模块 3 的什么位置被调用"。

**新增 2：补充离散控制的最小入口**

当前全课程没有离散控制的系统讲授——Z 变换、离散传递函数、采样定理、离散化方法均缺席。但模块 5 的 5-1 中提到了采样和量化作为线性主干的边界。建议：
- 在 5-1 的"边界现象"中增加 1-2 页的"离散实现带来的主干变化"（不展开 Z 变换推导，只讲：采样如何引入延迟、零阶保持器如何改变频率特性、离散化后稳定域如何从左半平面变成单位圆内）
- 或者：在期末复习中增加一个"离散控制速览"段落，帮助学生建立从连续到离散的过渡意识

理由：离散控制不是本课程的主干，但完全不提会让学生在后续课程（计算机控制系统）中缺少认知铺垫。

**新增 3：教材合订本的卷首元素**

- **符号约定页**：全局统一符号表（基于 `terminology.md` 精简）
- **阅读指南**：说明"先见森林"的设计意图，指导不同类型读者（首次学习者/复习者/教师）如何使用本书
- **案例索引**：列出船舶航向控制案例在全书各章的出现位置和角色

## 八、结论与建议优先级

### 8.1 总体判断

当前大纲架构**在理念层面是优秀的**——"先见森林"+"机制主导"+"设计链"三个设计支柱足以支撑一门高质量的控制理论课程。但在**执行层面存在三个结构性张力**：

1. **M2 的 8 学时承载了全课的形式化基础**——密度过高
2. **M3 的 18 学时是最大模块**——内容丰富但个别单元（3-8）认知负担过大
3. **M4 的优化设计链有两处瓶颈**——4-2 内容过载、4-6 新概念过密

这些问题**不需要推翻架构重来**，而是需要收束、降位和轻量重新分配。

### 8.2 大纲定稿前的必做决策

| 编号 | 决策问题 | 选项 | 推荐 |
|:---:|------|------|:---:|
| D1 | M2 是否保持 8 学时？ | A:保持 8h+严格执行降位 / B:扩至 10h / C:频域移回 M3 | **A** |
| D2 | 4-2 是否收束为"2-3 个核心结构的定量比较"？ | A:是，其余降为速查卡 / B:保持 8 结构全覆盖 | **A** |
| D3 | 4-6 的结构编码+GA/PSO 是否拆分为附录？ | A:课堂只讲最小思想，算法入附录 / B:保持当前负载 | **A** |
| D4 | 是否在 5-1 中补入离散控制的最小入口？ | A:增加 1-2 页"离散实现的主干变化" / B:保持当前边界 | **A** |
| D5 | 是否将频域对象保留在 M2？ | A:保留，在 M3 中间单元增加轻量回看 / B:移回 M3 开头 | **A** |

### 8.3 大纲定稿后的讲义修订顺序

一旦上述决策确认，建议按以下顺序推进讲义修订：

1. **M1 修复**（1-2 周）：按 module1-handout-review.md 的 8 项问题清单逐项修复
2. **M2 收束**（2-3 周）：执行降位策略 + 增加"M2 出口检查" + 同步设计文档
3. **M3 减载**（3-4 周）：缓解 3-3/3-7/3-8 的密度 + 增加频域轻量回看
4. **M4 重构**（4-6 周）：4-2 内容收束 + 4-6 负载拆分 + 同步设计文档
5. **M5 微调**（1-2 周）：术语统一 + 离散入口补入 + AI 融入嵌入
6. **合订本配套**（持续）：符号约定页 + 阅读指南 + 数学基础附录 + 运行案例附录
