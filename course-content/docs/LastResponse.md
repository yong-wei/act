  一、第二轮速通的本质区分问题

  您提到"否则和第一轮差别不大"，这是关键。两轮速通的区分必须足够清晰：

  ┌──────────┬──────────────────────────────┬────────────────────────────────────────────┐
  │   维度   │       第一轮速通（2h）       │           第二轮速通（建议6-8h）           │
  ├──────────┼──────────────────────────────┼────────────────────────────────────────────┤
  │ 语言     │ 直觉语言、类比、无公式       │ 数学语言，但应用先于推导                   │
  ├──────────┼──────────────────────────────┼────────────────────────────────────────────┤
  │ 数学工具 │ 无                           │ 传递函数、极点、Bode图——用起来，不推导     │
  ├──────────┼──────────────────────────────┼────────────────────────────────────────────┤
  │ 对象     │ 某个场景，整体感受           │ 固定一个系统（如船舶航向），完整走设计流程 │
  ├──────────┼──────────────────────────────┼────────────────────────────────────────────┤
  │ 学生角色 │ 观众+感受者                  │ 参与者（哪怕只是投票和预测）               │
  ├──────────┼──────────────────────────────┼────────────────────────────────────────────┤
  │ 认知目标 │ 感性整体印象，带着好奇心离开 │ 结构化框架，知道"这门课在算什么"           │
  └──────────┴──────────────────────────────┴────────────────────────────────────────────┘

  第二轮速通本质上是用数学工具把第一轮速通重做一遍——学生会有"啊，原来刚才那个感觉可以用这个公式表达"的认知对接感，这
  种体验比单纯推导更有价值。4个课时（8h）是必要的，否则压缩成2h就和第一轮差别消失了。
