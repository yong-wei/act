# 模块1讲义一致性、内容质量与能力递进评估

评估日期：2026-06-04
评估范围：`authoring/lessons/1-1` 至 `1-5` 全部五份讲义（handout.md）
对照基准：`syllabus-refactor/blueprint.md`、`syllabus-refactor/unit-design-details/module1.md`

## 一、整体判断

模块1的五份讲义在**设计理念上高度统一**——"先见森林，再见树木"的框架建构策略贯穿始终，每份讲义均明确标注"第一轮速通"定位，自觉克制不进入正式推导。从1-1的课程总图建立到1-5的平台三域整合，形成了一条清晰的递进弧线：

```
1-1 总图与术语基线 → 1-2 模型与极点直觉 → 1-3 根轨迹与时域联动 → 1-4 时域与频域并置 → 1-5 平台三域整合收束
```

**总体评分：内容质量 B+/A-，一致性 B，递进设计 A-。**

## 二、一致性分析

### 2.1 术语体系：基本一致，有少量未定义跳跃

1-1 建立了完整的术语基线表（对象、控制器、执行器、传感器、误差、反馈、开环/闭环、扰动、测量噪声）。后续单元稳定沿用这些术语，未出现术语漂移。

**存在以下术语未定义跳跃：**

| 术语 | 首次出现位置 | 问题描述 |
|------|-------------|---------|
| **超调量、调节时间** | 1-3 前置声明中声称学生已知 | 1-2 仅做定性行为描述（"平稳、摆动、发散"），从未出现这两个量化指标的名称。学生在1-3开头看到"也知道二阶响应常用超调量、调节时间等语言描述动态品质"时会感到困惑 |
| **Bode图** | 1-5 直接使用 | 1-4 只做了频域的定性介绍（幅值变化、相位变化），从未提及 Bode 图这个名称或其双坐标系结构。1-5 大量使用"Bode图"一词但从未解释它是什么 |
| **相位裕度** | 1-5 作为核心判据使用 | 1-4 只谈了"输出幅值相对输入是变大还是变小""相位滞后"，从未涉及"裕度"概念。相位裕度是一个复合概念（增益穿越频率处的相位余量），在1-5中却作为三域对照的频域支柱直接使用 |
| **$G(s)$ 与传递函数** | 1-3 使用 $G_0(s)$ | 1-2 提到"模型"但未引入传递函数的标准记法。1-3 直接写出 $G_0(s)=\frac{1}{s(s+4)}$ 而不解释分母各因式的含义 |

### 2.2 课程序号体系：1-1 的课程总图与实际大纲存在严重不一致

这是本次评估发现的**最严重的一致性问题**。

1-1 讲义的"表4. 课程总图的五个连续问题"对各模块的描述与实际大纲的对比如下：

| 模块 | 1-1 讲义中的描述 | 实际大纲（syllabus-refactor） | 匹配度 |
|:---:|------|------|:---:|
| 模块1 | 建立总图、反馈思想、系统观念与术语基线 | 反馈与建模（1-1~1-5） | ✅ |
| 模块2 | **模型、时域对象、频域对象和图形对象的正式建立** | **系统分析**：性能指标、欠阻尼二阶系统、稳定性(Routh)、稳态误差 | ❌ |
| 模块3 | 极点、零点、型别、相位等机制 | 三域打通（根轨迹+频域+Nyquist+稳定裕度） | ⚠️ |
| 模块4 | 设计起点、结构选择、优化修正与场景比较 | 设计与校正（串联校正+PID+离散+反馈校正） | ✅ |
| 模块5 | 经典主干方法的边界在哪里 | 知识边界与方法迁移（非线性→MASS→数据驱动→强化学习） | ✅ |

**问题本质**：1-1 讲义的课程总图描述的模块2内容（"模型、时域对象、频域对象和图形对象的正式建立"）与实际模块2（系统分析：时域指标、二阶系统、Routh判据、稳态误差）不匹配。当学生进入模块2时会发现实际内容与课程总图的预期不同，损害课程总图的可信度。

**根因分析**：1-1 讲义可能描述的是课程的概念性/逻辑性分组，但使用了与行政模块划分相同的"模块1~5"编号体系，造成混淆。实际大纲将"建模"放在模块1、时域分析放在模块2、频域对象放在模块3——而1-1的课程总图将这些合并描述为模块2的内容。

### 2.3 符号记法不一致

- 1-3 使用 $G_0(s)$（数字0下标）
- 1-5 使用 $G_o(s)$（字母o下标，表示 open-loop）

同指"开环传递函数"，记法不统一。**建议统一为 $G_o(s)$ 或 $G(s)$，并在术语表中明确。**

### 2.4 前置缺口表格式不统一

- 1-1、1-2、1-5 使用三列式表格（已有直觉 → 当前缺口 → 能力目标）
- 1-3、1-4 使用纯文本段落描述前置缺口

格式上的不一致影响阅读体验的连贯性。

## 三、能力递进评估

### 3.1 递进设计：结构良好

模块1的能力递进设计符合 Bloom 认知层次：

| 单元 | 认知层次 | 核心能力产出 |
|------|:---:|------|
| 1-1 | 识记 + 理解 | 用统一术语描述控制过程、识别系统组成、理解反馈思想 |
| 1-2 | 理解 + 初步应用 | 从模型语言理解极点意义、从复平面位置做出第一轮行为判断 |
| 1-3 | 理解 + 分析 | 建立"参数变化→极点迁移→响应变化"因果链、读根轨迹雏形 |
| 1-4 | 理解 + 分析 | 在同一系统上区分时域问题与频域问题、建立三域并置意识 |
| 1-5 | 应用 + 综合 | 在平台上整合三域观察、写出结构化的跨域判断链 |

### 3.2 发现的能力递进问题

**1-2→1-3：从"静态识别"到"动态追踪"的过渡未被显式标记**

1-2 的终点是"静止地看极点位置→判断行为"。1-3 的起点要求建立"参数变化→极点迁移→响应变化"因果链。从"静态读图"到"动态追踪"是一次认知升级，但1-3并未将这个升级作为一个教学时刻来标记。

**1-4→1-5：Bode 图和相位裕度的认知跳跃**

1-4 做的是频域的定性直觉（系统对不同节律态度不同）。1-5 却直接要求学生使用 Bode 图和相位裕度作为三域对照的频域一极。这两个对象在1-4中从未出现，在1-5中也未获任何解释。学生在平台体验中将面对一张完全不理解的图（Bode图），却要从中读出"相位裕度"并纳入判断链。

### 3.3 练习设计：层次分明

五份讲义的分层练习（基础识别→比较判断→迁移应用）设计一致且递进有序。唯一需要注意的是1-4练习2假设学生了解"客船航向控制"和"机动平台"在操作特性上的差异，属于领域知识前提而非控制理论知识前提。

## 四、内容质量与写作风格

### 4.1 优势

- **写作视角统一**：五份讲义均使用"我们"视角，语气沉稳，无教师身份残留
- **问题驱动引入**：每份讲义以真实工程场景中的困惑引入，而非"本节我们将学习……"
- **前置缺口表设计良好**（1-1、1-2、1-5）：三列式设计清晰建立学习动机
- **锚点案例具有连续性**：船舶/车辆主题贯穿1-1至1-5，增强认知锚定
- **克制原则执行到位**：每份讲义多次出现"这里不进入正式推导""后续才会正式展开"等边界标记

### 4.2 可改进之处

1. **1-3 和 1-4 缺少三列式前置缺口表**，与其余单元格式不统一
2. **1-5 数值表（表2）精度过高**：超调量精确到 7.1%/45.6%/71.3%/87.8%，相位裕度精确到 61.3°/27.4°/11.6°/3.1°。对于直觉建立而言，约数表述更合适
3. **1-2 特征方程的来源缺少一句话说明**：可直接补充"当模型写成微分方程后，我们可以提取一个对应的代数方程——称为特征方程——它的根就是极点"

## 六、问题汇总与优先修复建议

### 🔴 高优先级

1. **1-1 课程总图（表4）对模块2~3的描述与实际大纲不一致**
   - 修复方式：将表4的描述与 `syllabus-refactor/blueprint.md` 对齐，或明确标注"概念性分组"与"行政模块划分"的区别

2. **1-5 中 Bode 图和相位裕度从未被引入**
   - 修复方式A：在1-4中增加 Bode 图双坐标系的定性介绍
   - 修复方式B：在1-5开头增加一段"Bode图最小读图指南"
   - 修复方式C：在1-5中降级频域要求，仅观察"输出幅值变化趋势"而不使用"相位裕度"

### 🟡 中优先级

3. **1-3 前置声明中声称学生已知"超调量、调节时间"**，但1-2从未引入
   - 修复方式：在1-2中增加至少一次提及，或在1-3中首次引入时做简短定义

4. **1-3 和 1-4 缺少三列式前置缺口表**，格式与其他单元不统一

5. **$G_0(s)$ 与 $G_o(s)$ 符号不统一**（1-3 vs 1-5）

### 🟢 低优先级

6. **1-5 表2的数值精度过高**，建议改为约数或范围表述
7. **1-4 练习2** 假设了船舶领域知识前提
8. 五份讲义均缺少 `manifest.json`（不影响文本质量）
