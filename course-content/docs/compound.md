更合理的边界是：

**狭义的“复合控制”通常指前馈与反馈的组合，即开环补偿和闭环反馈并用。**国内自动控制教材中常把复合控制定义为“开环控制和闭环控制相结合”，并把它分成“按输入前馈补偿”和“按干扰前馈补偿”两类；其目的，是缓解闭环系统中精度和稳定性之间的矛盾。

**广义的“复合控制”则可以理解为：在基本单回路串联校正之外，引入额外的信息通道、局部回路、补偿环节、选择逻辑、模型预测或观测估计，以同时处理跟踪、抗扰、鲁棒性、约束、安全和工程实现问题。**按这个广义理解，前馈、局部反馈、测速反馈、串级控制、比值控制、选择/超驰控制、分程控制、解耦控制、Smith 预估、扰动观测器、二自由度 PID、微分滤波、抗积分饱和等，都可以放在“复合控制结构”或“复杂控制策略”的框架下讨论。MIT 的过程控制材料也明确把串级和前馈看作在单回路反馈之外，利用额外过程测量来改善控制结构的方法。([MIT OpenCourseWare][1])

不过要注意一个边界：**微分滤波本身通常不宜单独称为一种复合控制方法**。它更准确地说是 PID/PD 的工程实现环节，目的是限制高频增益、避免噪声放大。类似地，抗积分饱和、给定滤波、输出限幅、斜率限制、无扰切换，也更多是“实现层复合”或“工程保护环节”。它们不一定改变控制策略的主结构，但在真实系统中非常关键。Åström 和 Hägglund 的 PID 资料也把滤波、抗饱和和改善给定响应视为高级 PID 实现的重要内容。([isa.org][2])

## 1. 复合控制的内涵：不是“控制器变复杂”，而是“信息结构变丰富”

基本串联校正通常是：

[
u=C(s)(r-y)
]

控制器只看一个误差信号 (e=r-y)，然后通过 (C(s)) 改变闭环特性。PI、PD、PID、超前、滞后、超前-滞后大多属于这一类。

复合控制则不再只依赖误差信号，而是引入更多信息。例如：

[
u=C(s)(r-y)+F_r(s)r+F_d(s)d+H(s)x_m
]

这里：

[
F_r(s)r
]

是参考前馈；

[
F_d(s)d
]

是扰动前馈；

[
H(s)x_m
]

可以是速度反馈、电流内环、局部反馈、观测器补偿或其他内部变量反馈。

所以复合控制的本质不是“多放几个环节”，而是改变系统的因果路径：

反馈路径负责稳定、鲁棒和未知扰动修正；
前馈路径负责提前补偿可测扰动或可预测参考；
局部反馈负责改善子系统特性；
串级结构负责利用中间变量提前抑制扰动；
选择/限幅/超驰结构负责安全和约束；
模型/观测器结构负责补偿不可直接测量的扰动或动态。

这比“串联校正”更接近真实工程系统。真实系统很少只有一个误差输入、一个控制器、一个执行器这么干净。

## 2. 前馈-反馈复合控制

这是最典型、最狭义的复合控制。

设对象为：

[
y=G_u(s)u+G_d(s)d
]

其中 (u) 是控制输入，(d) 是扰动。反馈控制为：

[
u_f=C(s)(r-y)
]

如果扰动 (d) 可测，可以加入扰动前馈：

[
u=C(s)(r-y)+F_d(s)d
]

理想情况下，希望扰动对输出的影响抵消：

[
G_u(s)F_d(s)+G_d(s)=0
]

于是：

[
F_d(s)=-\frac{G_d(s)}{G_u(s)}
]

这就是扰动前馈补偿的基本公式。

如果是参考跟踪问题，也可以加入参考前馈：

[
u=C(s)(r-y)+F_r(s)r
]

理想上希望：

[
G_u(s)F_r(s)\approx 1
]

即：

[
F_r(s)\approx G_u^{-1}(s)
]

但真实系统里不应直接追求完美逆模型，因为逆模型可能不可实现、不稳定，或者会放大高频噪声。实际前馈常写成：

[
F_r(s)=Q(s)G_u^{-1}(s)
]

其中 (Q(s)) 是低通滤波器。

前馈-反馈复合控制的关键分工是：

**前馈处理“已知的、可测的、可预测的东西”；反馈处理“未知的、模型误差、未测扰动和残余误差”。**

过程控制教材中也强调，纯前馈只能针对可测扰动，不能知道补偿是否成功，也不能处理未测扰动，所以通常要和常规反馈一起使用；前馈算法还依赖具体过程模型和扰动模型。([MIT OpenCourseWare][1])

适用情况：

可测扰动明显，例如进料流量、进料温度、负载转矩、坡度、风速等；
参考轨迹可预测，例如机器人轨迹、电机速度规划、船舶航迹规划；
反馈太慢，等误差出现再纠正已经晚了；
对象模型至少在主要频段内可信。

不适用或需谨慎的情况：

扰动不可测；
模型误差大；
对象有非最小相位零点或纯滞后，导致逆模型不可实现；
参考信号不光滑，直接前馈会产生尖峰；
执行器余量不足，前馈容易导致饱和。

一个重要教学判断是：

**前馈不能替代反馈。前馈是“预补偿”，反馈是“兜底稳定和修正”。**

## 3. 给定补偿与二自由度控制

二自由度控制可以看作“参考通道”和“反馈通道”分开设计。

普通单自由度反馈控制通常是：

[
u=C(s)(r-y)
]

同一个 (C(s)) 同时决定参考跟踪和扰动抑制。这会造成冲突：为了抗扰，需要较强反馈；但强反馈在给定阶跃时又可能带来超调和冲击。

二自由度结构改成：

[
u=C_r(s)r-C_y(s)y
]

其中 (C_y(s)) 主要决定闭环稳定性和抗扰性能，(C_r(s)) 主要调节给定响应。

二自由度 PID 的常见形式是：

[
u=K_p(\beta r-y)+K_i\int(r-y)dt+K_d(\gamma \dot r-\dot y)
]

其中 (\beta) 是比例给定权重，(\gamma) 是微分给定权重。工程中常取：

[
\gamma=0
]

也就是微分只作用在输出上，避免给定阶跃导致 derivative kick。MathWorks 的二自由度 PID 文档也明确指出，比例和微分通道中的设定值权重可以调节设定值响应；当微分权重取 0 时，可避免设定值变化引起的微分冲击。([MathWorks][3])

二自由度控制适合：

扰动抑制要求强，但给定变化时不希望超调太大；
希望独立塑造“跟踪性能”和“抗扰性能”；
PID 已经能抗扰，但给定阶跃响应不好；
伺服系统、过程控制、温控、速度控制中都常见。

它和前馈有交叉。参考前馈、给定滤波、设定值权重，本质上都在改变参考通道，而不是简单改变反馈回路。

## 4. 串级控制

串级控制是另一类非常重要的复合控制结构。

典型结构是：

外环控制主要被控量 (y_1)，外环控制器输出作为内环设定值；
内环控制中间变量 (y_2)，内环控制器直接驱动执行器。

形式上可以写成：

[
r_2=C_1(s)(r_1-y_1)
]

[
u=C_2(s)(r_2-y_2)
]

其中 (C_1) 是主控制器，(C_2) 是副控制器。

串级控制的核心不是“两个 PID 串起来”，而是利用一个**更快、更靠近扰动源或执行器的中间变量**。MIT 过程控制资料指出，中间变量应该比最终输出更早响应扰动，并且能反映扰动对最终输出的影响；副回路通过控制这个中间变量，先于主变量变化之前抑制扰动。([MIT OpenCourseWare][1])

Control.com 对串级控制的描述也很清楚：一个控制器的输出作为另一个控制器的设定值，两个反馈回路是嵌套的，并且副变量通常应比主变量响应更快、滞后和纯滞后更小。([控制网][4])

典型例子：

温度外环 + 流量内环；
位置外环 + 速度内环；
速度外环 + 电流/转矩内环；
液位外环 + 流量内环；
压力外环 + 阀门定位内环；
船舶航向外环 + 角速度/舵角内环。

串级控制的参数设计通常遵循：

**先调内环，再调外环；内环带宽应明显高于外环。**

MIT 资料也强调，串级调试时应先在外环手动状态下整定内环，然后再把内环置于自动状态整定外环；两个控制器都会影响闭环极点和稳定性。([MIT OpenCourseWare][1])

适用条件：

存在可测中间变量；
中间变量比最终输出响应更快；
主要扰动先影响内环变量；
执行器或局部过程动态对外环性能影响明显；
需要把快动态和慢动态分层处理。

不适合的情况：

中间变量不可靠或噪声太大；
内环并不比外环快；
中间变量与最终输出关系弱；
内外环带宽设计太接近，导致相互打架。

一个实用原则：

**串级控制不是为了“多加一个控制器”，而是为了让内环先把快问题消掉，让外环只面对一个更规整、更快、更线性的等效对象。**

## 5. 局部反馈、小回路反馈与测速反馈

局部反馈，也称 minor loop feedback、小回路反馈，是指不直接围绕整个对象闭环，而是围绕对象的某个局部环节闭环。

例如：

执行器位置反馈；
电机电流反馈；
速度反馈；
加速度反馈；
阀门定位器；
功率放大器内环；
船舶操舵系统中的舵角伺服内环。

局部反馈的作用是改变某个子系统的等效动态。MIT 的小回路反馈材料把它描述为一种可以改变被控对象特性的补偿方式：在相关频率范围内，通过小回路使对象看起来像一个期望的等效对象。

测速反馈是最典型的局部反馈之一。

对机械对象：

[
J\ddot y+B\dot y=u
]

加入位置比例和测速反馈：

[
u=K_r(r-y)-K_v\dot y
]

闭环为：

[
J\ddot y+(B+K_v)\dot y+K_r y=K_r r
]

可见 (K_v) 直接增加等效阻尼。国内控制课程资料也指出，输出微分反馈或测速反馈能改善二阶系统动态性能，增加阻尼比，而不引入给定微分导致的零点效应。

适用情况：

机械系统阻尼不足；
执行器或局部环节动态太差；
需要提高子系统带宽；
希望把非线性、摩擦、滞后等局部问题限制在内层；
存在可靠的局部测量量，如速度、电流、舵角、阀位。

主要风险：

局部测量噪声会被反馈放大；
内环带宽过高可能激发未建模动态；
局部反馈改变了外环看到的对象，外环参数要重新设计；
多个局部回路之间可能发生耦合。

从广义复合控制角度看，局部反馈当然应包括在内。它不是串联校正，而是改变对象结构的反馈补偿。

## 6. 微分滤波、给定滤波、抗积分饱和：实现层复合

这些环节经常被忽略，但在真实系统中很重要。

实际 PID 很少使用理想形式：

[
C(s)=K_p\left(1+\frac{1}{T_i s}+T_d s\right)
]

因为理想微分的高频增益无限大，会放大传感器噪声。实际常用：

[
C_D(s)=K_p\frac{T_d s}{1+\frac{T_d}{N}s}
]

其中 (N) 是微分滤波系数。

此外，工程 PID 还常加入：

给定滤波；
输出微分，而不是误差微分；
积分限幅；
条件积分；
反算抗积分饱和；
输出限幅；
斜率限制；
手自动无扰切换；
控制量死区补偿。

这些结构的地位要准确理解：

它们通常不是“主控制策略”，但它们会显著影响闭环行为；
它们属于工程实现中的结构复合；
在执行器饱和、测量噪声、给定突变、手自动切换频繁的场景中，它们不是可选项，而是必要项。

例如在超驰控制和选择控制中，如果某个控制器暂时不掌握执行器，积分项仍然持续累积，就会产生严重 windup。ISA 的过程控制材料也明确指出，在超驰控制中积分控制器需要 windup 保护，否则保护动作可能来得太晚或恢复异常。

所以判断上可以这样说：

**微分滤波本身不是狭义复合控制，但属于复合控制系统中的重要实现环节。没有这些实现环节，很多复合结构在实机上会失败。**

## 7. 比值控制

比值控制常见于过程工业。它的目标不是让某个变量等于固定设定值，而是让两个变量保持某个比例。

典型形式：

[
u_2=k u_1
]

或：

[
\frac{F_2}{F_1}=k
]

其中 (F_1) 是主流量，也叫 wild stream；(F_2) 是从流量，也叫 captive stream。Siemens 的过程控制资料把比值控制描述为保持两个过程变量之间比例恒定，常用于流体混合；从流量按主流量比例调节。([西门子工业支持][5])

常见应用：

燃料-空气比控制；
物料混合；
化学反应配比；
回流比控制；
稀释与浓度控制；
船舶或能源系统中的功率分配。

比值控制可以看作一种特殊前馈。UCSB 的过程控制材料也明确指出，比值控制是过程工业中常用的一种特殊前馈控制形式。([sites.chemengr.ucsb.edu][6])

适用条件：

主变量可测；
比例关系明确；
从变量执行器可调；
比例关系比绝对值更重要；
扰动主要来自主流变化。

风险：

低流量时比值计算容易放大测量误差；
流量测量需要量程匹配和滤波；
执行器饱和会破坏比例；
比例设定错误会导致质量、安全或能耗问题。

## 8. 选择控制、超驰控制与分程控制

这类结构不是为了改善常规动态指标，而是为了处理约束、安全和多执行器问题。

### 8.1 选择控制

选择控制通过高选、低选、逻辑选择器，在多个信号或多个控制器输出之间选择一个参与控制。ISA 资料把选择器、限幅器、加减乘除等看作特殊控制策略中的常用计算模块。

典型例子：

多个温度测点取最高值控制；
多个压力约束取最危险值控制；
多个控制器输出取低选或高选；
正常控制与保护控制之间切换。

### 8.2 超驰控制

超驰控制 override control 是一种保护性控制。当安全变量接近边界时，保护控制器接管执行器，使系统不越限。ISA 资料把超驰控制定义为选择控制的一种特殊形式，用于把过程变量限制在保护边界内，比联锁停机更温和。

典型例子：

压缩机防喘振；
锅炉压力上限保护；
反应器温度上限保护；
电机电流限制；
船舶推进功率限制；
电池充放电电流限制。

超驰控制的关键不是调得多快，而是：

正常控制器和保护控制器如何切换；
未被选中的控制器如何防止积分 windup；
切换是否无扰；
保护边界是否有足够裕量。

### 8.3 分程控制

分程控制 split-range control 是一个控制器输出驱动多个执行器。例如一个温度控制器输出在低段控制冷却阀，在高段控制加热阀。ISA 资料指出，分程控制用于一个过程变量由多个操纵变量调节，一个控制器输出分配给多个最终控制元件；典型例子就是加热和冷却。

适用情况：

一个变量需要多个执行器协同；
执行器工作区间不同；
需要节能或安全优先级；
存在加热/冷却、粗调/细调、大阀/小阀等组合。

风险：

执行器切换区间容易振荡；
死区或重叠区设计不当会引起来回切换；
不同执行器动态不同，导致闭环性能不一致；
需要限幅、滞环、优先级和抗饱和设计。

## 9. 多变量解耦与交叉补偿

单回路 PID 隐含一个前提：一个控制量主要影响一个输出。

但多变量系统中，经常出现：

[
\begin{bmatrix}
y_1\
y_2
\end{bmatrix}
=============

\begin{bmatrix}
G_{11}(s) & G_{12}(s)\
G_{21}(s) & G_{22}(s)
\end{bmatrix}
\begin{bmatrix}
u_1\
u_2
\end{bmatrix}
]

此时 (u_1) 不只影响 (y_1)，也影响 (y_2)；(u_2) 也类似。若仍用两个独立 PID，回路之间可能互相打架。

解耦控制的思想是在控制器和对象之间加入补偿网络 (D(s))，使等效对象：

[
G(s)D(s)
]

尽量接近对角矩阵。IFAC 的多变量控制资料也把解耦控制的本质概括为用计算网络抵消过程交互，使各个反馈回路尽量独立工作。([UNED][7])

常见形式：

静态解耦；
动态解耦；
相对增益阵列 RGA 选配对；
分散 PID + 解耦器；
集中式 MIMO 控制器；
MPC。

适用情况：

多输入多输出系统；
变量之间耦合强；
单回路调参出现“一个回路好，另一个回路坏”；
执行器之间有协同关系；
过程变量有多个约束。

典型例子：

精馏塔温度/组成控制；
多区域温度控制；
无人船航向-速度耦合控制；
飞行器姿态控制；
机器人多关节耦合；
交通信号多交叉口协调。

风险：

模型不准会导致解耦错误；
动态解耦可能不可实现或不鲁棒；
强约束系统中，仅靠解耦 PID 不够，需要 MPC 或优化分配。

## 10. Smith 预估与纯滞后补偿

纯滞后是反馈控制的难点。若对象为：

[
G(s)=G_0(s)e^{-Ls}
]

纯滞后 (e^{-Ls}) 带来相位滞后，严重限制可实现带宽。

Smith 预估器的思想是：用模型把无滞后部分放入内环设计，使控制器好像面对的是 (G_0(s))，再用外部修正处理模型误差和扰动。EOLSS 的 Smith Predictor 资料指出，它对长纯滞后过程很有效；其内环按无纯滞后模型设计，外环用于修正负载扰动和模型误差。([生命支持系统百科全书][8])

适用情况：

对象稳定；
纯滞后显著；
模型较可信；
主要目标是提高长滞后系统的闭环性能；
传统 PID 因滞后大而必须调得很慢。

不适用或需谨慎：

模型误差大；
纯滞后变化明显；
对象不稳定或非最小相位；
主要扰动进入点在模型难以覆盖的位置。

一个关键判断：

**如果主要扰动可测，优先考虑前馈；如果扰动不可测但对象长滞后且模型可信，可以考虑 Smith 预估。**EOLSS 资料也指出，对于长纯滞后过程，若主要扰动可测，前馈常是最有效方法；否则才需要纯滞后补偿。([生命支持系统百科全书][8])

---

## 11. 扰动观测器、ADRC 与复合抗扰控制

前馈要求扰动可测。但很多扰动不可测，例如负载转矩、摩擦、风浪、参数摄动、未建模动态。

扰动观测器 disturbance observer, DOB 的思想是：通过输入输出数据和对象模型估计总扰动，然后把估计扰动补偿掉。

可以抽象写成：

[
\hat d = Q(s)\left(y-G_n(s)u\right)
]

再用：

[
u=u_0-\hat d
]

这里 (G_n(s)) 是名义模型，(Q(s)) 是滤波器。

ADRC 中的扩张状态观测器 ESO 也有类似思想：把未知扰动、模型误差和外部扰动合并成“总扰动”，作为扩张状态估计，再在控制律中补偿。相关综述指出，扰动观测器控制、ADRC、扰动适应控制和复合分层抗扰控制，都属于围绕扰动/不确定性估计与补偿展开的抗扰方法；核心是估计扰动或不确定性，再与已有线性或非线性控制器结合。([ResearchGate][9])

适用情况：

扰动不可直接测量，但可以从系统响应中估计；
模型不完全准确，但名义模型大体可信；
负载扰动、摩擦、参数变化明显；
需要在普通反馈之外提高抗扰性能。

典型场景：

伺服电机负载扰动补偿；
机械臂摩擦和外载补偿；
船舶风浪流扰动估计；
无人车坡度和阻力补偿；
精密运动平台。

风险：

观测器带宽越高，估计越快，但噪声越敏感；
模型误差过大时估计会偏；
补偿过强可能破坏鲁棒性；
离散实现中延迟和滤波会显著影响效果。

从结构上看，DOB/ADRC 是典型的复合控制：基本反馈控制器仍然存在，扰动估计与补偿作为额外通道加入。

## 12. 内模控制、重复控制与迭代学习控制

有些扰动或参考信号不是随机的，而是具有明确模式，例如常值、斜坡、正弦、周期信号。

积分控制本质上就是对常值扰动或常值参考的内模。重复控制 repetitive control 则把周期信号的内模放入控制器中，用于周期扰动抑制或周期参考跟踪。ScienceDirect 的重复控制综述指出，重复控制主要用于周期扰动抑制或周期参考跟踪；其理论基础是内模原理，即控制器中包含能生成该类信号的模型。([科学直接][10])

典型结构中会出现延迟环节：

[
\frac{1}{1-q(s)e^{-Ts}}
]

其中 (T) 是周期。

适用情况：

扰动或参考高度周期性；
周期已知且相对稳定；
每个周期重复执行相似任务；
允许利用前一周期误差改善后一周期性能。

典型例子：

旋转机械周期扰动；
硬盘、光刻台、精密平台；
电机转矩脉动；
周期轨迹跟踪；
批次过程或重复工况。

风险：

周期变化会降低效果；
高频段容易放大噪声；
非最小相位对象和不稳定零点要谨慎；
通常需要低通滤波 (Q) 和稳定补偿 (L)。

迭代学习控制 ILC 与重复控制接近，但更强调“每次任务重复执行后，用前一次误差修正下一次输入”。它更适合有限时间轨迹任务，如机器人重复搬运、加工轨迹、实验平台重复运行。

## 13. 增益调度与自适应控制

当系统工作点变化很大时，一组固定 PID 参数往往无法兼顾所有工况。

增益调度 gain scheduling 的思路是：

[
K_p=K_p(\rho),\quad K_i=K_i(\rho),\quad K_d=K_d(\rho)
]

其中 (\rho) 是调度变量，例如速度、负载、温度、高度、流量、工况编号等。NI 和 MathWorks 的控制文档都把增益调度描述为根据测量的工作条件或操作点自动调整控制器参数，适用于对象动态随工况变化的场景。([NI][11])

适用情况：

对象非线性明显；
不同工况下时间常数、增益、滞后变化大；
可以找到可靠的调度变量；
每个局部工况都能用较简单控制器控制。

典型例子：

飞行控制随速度和高度调度；
电机控制随转速和负载调度；
船舶操纵随航速调度；
热过程随工况调度；
车辆纵向/横向控制随速度调度。

风险：

调度变量选错会导致参数跳变；
不同控制器之间切换可能不连续；
局部稳定不等于全局稳定；
需要插值、限速、无扰切换和边界保护。

自适应控制比增益调度更进一步：参数不是预先查表，而是在线估计或在线调整。它适合参数未知或缓慢变化的对象，但设计和验证难度也更高。

---

## 14. 模型预测控制 MPC

MPC 不属于传统教材中狭义的“复合控制”，但它代表了现代复杂场景中很典型的复合控制框架。

MPC 的基本思想是：

用模型预测未来输出；
在有限时域内优化未来控制序列；
显式处理输入、输出和状态约束；
只执行当前第一个控制动作；
下一采样时刻重新测量、重新优化。

MathWorks 文档把 MPC 描述为一种对受约束动态系统进行有限时域滚动优化的最优控制技术；它利用内部模型、测量输出和扰动信息计算控制动作。([MathWorks][12])

Seborg 的 MPC 教材资料也指出，MPC 适合处理困难的多变量控制问题和不等式约束；它利用模型和测量预测未来输出，协调多个输入，并能显式考虑约束。

MPC 可以同时吸收很多复合控制思想：

反馈：每步重新测量并滚动优化；
前馈：可加入可测扰动和已知参考轨迹；
多变量协调：集中处理 MIMO 耦合；
约束控制：显式处理限幅、速率限制、安全边界；
优化控制：在性能、能耗、平滑性之间权衡。

适用情况：

多输入多输出；
耦合明显；
约束很多；
执行器限幅和变化率限制重要；
未来参考或扰动部分已知；
希望同时优化能耗、误差、平滑性和安全裕度。

风险：

模型依赖强；
计算量大；
调参维度多；
稳定性和可行性需要专门处理；
对实时平台和异常工况处理要求高。

## 15. 这些方法之间的关系

可以把复合控制按“增加了什么”来分类。

| 复合形式   | 增加的东西         | 代表方法                 | 主要解决的问题        |
| ------ | ------------- | -------------------- | -------------- |
| 前馈复合   | 可测扰动或参考通道     | 扰动前馈、参考前馈、比值控制       | 不等误差出现，提前补偿    |
| 多自由度复合 | 参考通道与反馈通道分离   | 二自由度 PID、给定滤波、I-PD   | 兼顾给定跟踪和扰动抑制    |
| 多环复合   | 内环或局部反馈       | 串级控制、速度内环、电流内环、阀门定位器 | 改善局部动态，提前抑制扰动  |
| 局部状态复合 | 速度、加速度、电流等内部量 | 测速反馈、加速度反馈、小回路反馈     | 增阻尼、提高子系统带宽    |
| 工程实现复合 | 滤波、限幅、抗饱和     | 微分滤波、抗 windup、无扰切换   | 处理噪声、饱和、切换     |
| 逻辑约束复合 | 选择器、限幅器、保护逻辑  | 选择控制、超驰控制、分程控制       | 安全、约束、多执行器     |
| 多变量复合  | 交叉通道补偿        | 解耦控制、MIMO PID、MPC    | 处理变量耦合         |
| 模型补偿复合 | 对象模型或逆模型      | Smith 预估、内模控制、前馈逆模型  | 处理滞后、周期信号、模型动态 |
| 观测估计复合 | 扰动或状态估计       | DOB、ADRC、ESO、扰动适应控制  | 处理不可测扰动和不确定性   |
| 优化复合   | 目标函数和约束       | MPC、实时优化 RTO         | 多目标、多约束协调      |

## 16. 如何判断该用哪一种复合控制

可以按问题症状判断。

| 场景特征             | 优先考虑的复合结构             |
| ---------------- | --------------------- |
| 扰动可测，但反馈纠正太慢     | 扰动前馈 + 反馈             |
| 参考轨迹已知，跟踪总是滞后    | 参考前馈、二自由度控制           |
| 给定响应超调大，但抗扰又不能减弱 | 二自由度 PID、给定滤波、输出微分    |
| 存在响应更快的中间变量      | 串级控制                  |
| 执行器或局部对象动态差      | 局部反馈、小回路反馈、阀门定位器、电流内环 |
| 机械系统阻尼不足         | 测速反馈、加速度反馈、PD 输出微分    |
| 测量噪声明显           | 微分滤波、低通滤波、降低带宽        |
| 执行器容易饱和          | 抗积分饱和、限幅、斜率限制、超驰保护    |
| 多个执行器作用于同一变量     | 分程控制、控制分配             |
| 一个执行器受多个安全变量约束   | 选择控制、超驰控制             |
| 多变量耦合强           | 解耦控制、集中式 MIMO 控制、MPC  |
| 纯滞后大             | Smith 预估、前馈、MPC       |
| 不可测扰动显著          | DOB、ADRC、ESO          |
| 扰动或参考周期性         | 重复控制、迭代学习控制、内模控制      |
| 工况变化大            | 增益调度、自适应控制            |
| 约束多、目标多、耦合强      | MPC                   |

## 17. 对几个具体例子的归类

你提到的几个例子，可以这样判断。

**前馈：属于复合控制的核心形式。**
尤其在狭义教材中，前馈 + 反馈几乎就是“复合控制”的代表结构。

**局部反馈：属于广义复合控制。**
它不是串联校正，而是通过局部回路改变对象等效动态。测速反馈、电流环、阀门定位器都属于这一类。

**串级控制：属于广义复合控制，也可单独称为复杂控制系统或多回路控制。**
它的核心是嵌套反馈回路和时间尺度分离，不只是两个控制器串接。

**微分滤波：不宜单独称为复合控制策略，但属于复合控制系统的实现环节。**
它通常服务于 PD/PID、测速反馈、观测器或前馈逆模型，主要处理噪声和高频不确定性。

**抗积分饱和、给定滤波、限幅、斜率限制：也是实现层复合。**
它们往往不改变主控制思想，但直接决定系统能不能在真实执行器上安全运行。

**解耦、Smith 预估、DOB、MPC：属于更高级的复合控制或复杂控制结构。**
它们引入模型、估计、预测、优化或多变量协调，已经超出传统串联校正的范围。

## 18. 更凝练的教学表述

可以把这部分课程逻辑组织成三层。

第一层是**基本串联校正**：

PI、PD、PID、超前、滞后、超前-滞后。
它们主要在单个误差信号通道上塑造闭环的低频增益、带宽、相位裕度和阻尼。

第二层是**经典复合控制**：

前馈-反馈、给定补偿、测速反馈、局部反馈、串级控制、比值控制。
它们开始引入额外信息通道或额外反馈回路，解决单回路难以兼顾的性能矛盾。

第三层是**复杂工程控制结构**：

选择/超驰/分程、解耦、Smith 预估、DOB/ADRC、重复控制、增益调度、MPC。
它们处理的是约束、安全、耦合、时滞、不确定性、周期扰动和多目标优化。

最关键的判断是：

**串联校正是在“一个误差信号上做文章”；复合控制是在“系统信息结构上做文章”。**

当问题只是“稳态误差、超调、响应速度、相位裕度”时，基本控制结构通常够用。
当问题变成“扰动能提前知道、内部变量更快、执行器有约束、变量之间耦合、模型有纯滞后、工况变化大、扰动不可测但可估计”时，就应进入复合控制设计。
