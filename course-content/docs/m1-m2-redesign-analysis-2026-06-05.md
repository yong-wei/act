# M1-M2 衔接重设计分析

分析日期：2026-06-05
触发条件：用户提出 1-1 应承担"一节课学会自动控制"的闪电速通功能，M1 构成"两轮速通"（1-1 全貌→1-2~1-5 工具级），M2 作为第三轮的正式原理展开
分析范围：M1（5 单元 10h）+ M2（4 单元 8h），合计 18h

---

## 零、设计思想校准

### 用户构想的核心逻辑

```
M1 第一轮速通（1-1，2h）
  "知道有这些东西"——面向问题，以最小代价遍历整门课的全部主题
  微分方程→传递函数→方框图→时域→性能指标→稳定性→根轨迹→频域→校正→代码

M1 第二轮速通（1-2~1-5，8h）
  "知道有哪些具体工具，能完成最简单的任务"
  1-2 模型与极点深化 → 1-3 根轨迹与时域深化 → 1-4 频域深化 → 1-5 平台三域整合

M2 第三轮：正式原理（2-1~2-4，8h）
  "补充更为细节的原理"——建立在两轮速通之上的正式推导与计算
```

### 这个设计如何改变了之前的判断

之前将 M1 评估为"偏轻的框架层"、M2 评估为"密度过高的形式化基础"，**前提是假设 M2 是学生第一次接触这些概念**。如果 M1 已经完成两轮铺垫，那么 M2 的 8 学时不是在"从零建立"，而是在"给已有直觉穿上数学外衣"——密度评估需要彻底重新校准。

以下分析基于这个新前提。

### 1.3 闪电速通的 90 分钟可行性

```
问题引入 + 控制骨架             ~10 min
⚡ 闪电速通（8 个主题 × 5-7min）  ~45 min
反馈为什么是核心                 ~10 min
课程总图（速通主题→模块映射）    ~5 min
锚点案例收束                     ~5 min
```

5-7 分钟每个主题是可行的——关键是**每个主题只答三个问题**：它解决什么？核心思想是什么？一行代码长什么样？不求推导、不求公式、不求细节。

## 二、"两轮速通"框架下 M1 内部一致性重新检查

### 2.1 M1 各单元的新定位

| 单元 | 当前定位 | 新定位（两轮速通框架下） | 需要调整的内容 |
|------|------|------|------|
| 1-1 | 课程总图 + 反馈概念 + 术语基线 | **第一轮闪电速通**：整门课全貌 + 反馈思想确立 + 术语基线 | 🔴 需大幅重写（+8 个主题段 + 代码示例） |
| 1-2 | 模型与极点第一轮速通 | **第二轮速通-建模深化**：比 1-1 多看一层细节（极点如何在复平面上读），但不进入正式推导 | 🟡 应在开头显式标注"第二轮速通"，并回看 1-1 中已出现的概念 |
| 1-3 | 根轨迹与时域第一轮速通 | **第二轮速通-时域与根轨迹深化**：比 1-1 多看一层（参数扫描的连续性），但不进入完整法则 | 🟡 同上，应显式标注第二轮定位 |
| 1-4 | 时域与频域第一轮速通 | **第二轮速通-频域深化**：比 1-1 多看一层（三域并置），但不进入正式计算 | 🟡 同上 |
| 1-5 | 平台初体验 | **第二轮速通收束**：三域联动→平台操作，形成"我有三张图可以同时看"的能力 | 🟢 基本不变，但可回看 1-1 的代码示例 |

### 2.2 发现的新问题

**问题 1：1-2~1-5 需要显式标注"第几轮"**

当前讲义没有"轮次"概念。1-2 自称"第一轮速通"，但按照新框架它应该是"第二轮"。这种错位会让学生困惑——"到底有几个第一轮？"

建议统一标注体系：
- 1-1：**第一轮（闪电速通）**——遍历整门课的全貌
- 1-2~1-4：**第二轮（领域速通）**——在特定领域深入一层，能做最简单判断
- 1-5：**第二轮收束**——把分散的领域视角整合到平台操作
- 模块 2：**第三轮（正式展开）**——给直觉穿上数学外衣

**问题 2：1-1 闪电速通中引入的术语量巨大**

如果 1-1 覆盖了建模、时域、根轨迹、频域、校正 8 个主题，每个主题至少产生 3-5 个新术语，总计 25-40 个术语一次暴露给学生。虽然设计意图是"不求甚解"，但术语量过大可能导致认知关闭（"太多新词，听不懂"）。

建议分层处理：
- **第一层（必须记住的）**：对象、控制器、反馈、误差、传递函数、极点、稳定性（~8 个）
- **第二层（知道有这个东西的）**：根轨迹、Bode 图、相位裕度、Routh 判据、校正、PID 等（~15 个）
- 在术语表中用 ⭐/🔷 标记区分两层

**问题 3：1-1 的 MATLAB 代码需要贯穿后续单元**

如果 1-1 展示了 `step(G)`, `rlocus(G)`, `bode(G)`, `margin(G)` 等一行代码，那么 1-2~1-5 应该**继续使用相同的代码骨架**，只是对代码结果做更深入的解释。这样学生看到的不再是零散的代码片段，而是一条"代码如何随理解加深而变丰富"的连续线。

当前问题：1-2~1-5 的讲义几乎没有代码。需要在第二轮速通的每个单元末尾增加一个"代码回看"框（2-3 行代码 + 一句话解释）。

**问题 4：1-1 闪电速通与 1-2~1-5 之间的重叠度控制**

如果 1-1 已经讲完了"传递函数是什么"（5 分钟版本），1-2 如何避免完全重复？关键的区分是：
- 1-1：传递函数是微分方程的替代品，写成 G(s)=输出/输入，它让我们能方便地分析系统
- 1-2：传递函数怎么从微分方程得到（拉氏变换的具体步骤），极点为什么在 G(s) 的分母里，复平面怎么读

即：1-1 给"是什么"，1-2 给"怎么来 + 怎么看"。这个区分需要在每个主题上严格执行。

## 三、两轮速通后 M2 的角色重新评估

### 3.1 M2 的新定位

在前次分析中，M2 被判定为"全课程密度最高的模块"——因为在假设"M2 是学生第一次接触"的前提下，8 学时覆盖传统 20-24 学时的内容确实过载。

但在两轮速通框架下：

```
1-1（闪电速通）：学生知道了"传递函数""Bode图""根轨迹"这些名字和它们大致是干什么的
1-2~1-5（领域速通）：学生能在特定领域做最简单的判断（读极点位置→稳定/不稳定、读Bode→低频/高频行为）
M2（正式展开）：学生现在有完整的直觉底板，M2 的任务是"你们已经知道这些东西存在，现在来学怎么算"
```

**M2 的 8 学时不再是"从零建立"，而是"从直觉到公式"的翻译过程。** 这让 8 学时变得合理。

### 3.2 重新评估各单元的密度

| 单元 | 前次评估 | 两轮速通框架下的重评估 | 理由 |
|------|:---:|:---:|------|
| 2-1 | 🔴 过载 | 🟡 偏重 | 学生已在 1-1 见过"传递函数→方框图→信号流图"的概念链，也已在 1-2 见过极点。2-1 只需要把"是什么"翻译成"怎么来"——拉氏变换的工程动机、微分方程到传函的转换、典型环节的数学形式。信号流图/梅森仍是新内容，但降为补充工具后可控。 |
| 2-2 | 🟡 偏重 | 🟢 适中 | 学生已在 1-1 见过"时域响应→模态叠加→性能指标"的概念，也已在 1-3 做过最简单的极点→时域判断。2-2 只需要把推导链补全（一阶/二阶的完整数学推导）并给出指标的精确公式。 |
| 2-3 | 🔴 过载 | 🟡 偏重 | 学生已在 1-1 见过"频域→Bode"的概念，也已在 1-4 见过"系统对不同节律态度不同"的直觉。2-3 需要建立 G(jω) 的数学合法性和典型环节 Bode 图的手绘骨架。傅里叶部分仍偏重但可以思想性引入。 |
| 2-4 | 🟡 偏重 | 🟢 适中 | 学生已在 1-5 平台上见过 Bode 图和相位裕度的联动。2-4 只是把"操作经验"翻译成"图上读取+指标计算"。反向识别是新内容但负担可控。 |

**结论**：在两轮速通铺垫下，M2 的 8 学时不再是瓶颈。四个单元全部从 🔴 降级为 🟡/🟢。18 学时（M1+M2 合计）对于建立完整的控制理论形式化基础是**充分且合理的**。

### 3.3 M2 需要增加的"第三轮"标注

M2 的每个单元应在开头显式标注这是"第三轮——正式展开"，让学生知道他们不是第一次面对这些概念：

> 在模块 1 中，你已经两度遇到过传递函数：1-1 的闪电速通告诉你"它把微分方程变成代数问题"，1-2 的领域速通让你用它做了最简单的极点判断。今天，我们把它正式建立起来——你会看到它是怎样从微分方程中推导出来的，以及它的数学结构为什么能支撑后续所有分析。

## 四、发现的新 GAP

### GAP 1：1-1 缺失的"一节课学会自控"核心段落 🔴

这是最大的 gap。当前 1-1 完全没有建模、时域、根轨迹、频域、校正、代码的任何内容。需要增加约 200 行 markdown（~8 个主题段 + 代码示例段）。

**这段内容的质量直接决定了 M1-M2 整个 18 学时的教学效率。** 如果 1-1 的闪电速通做得好，学生在后续 8 个单元（1-2~1-5，2-1~2-4）中每次面对"新概念"都会觉得"这个我在第一课见过"；如果做得不好（信息过载、术语轰炸、缺乏主线），反而会让学生在第一课就产生畏难情绪。

建议的关键设计要点：
- 每个主题必须有**同一个贯穿案例**（如船舶航向的 Nomoto 模型），不要每个主题换一个例子
- 每个主题只答三个问题：**解决什么？核心思想？一行代码？**
- 代码段放在最后统一展示，而不是每个主题后插一段
- 主题之间必须有**因果连接句**（"微分方程求解不便→于是有了传递函数""传递函数看不到内部结构→于是有了方框图"），让 8 个主题形成一条连续的问题解决链

### GAP 2：1-2~1-5 缺少与 1-1 的显式回看 🔴

当前 1-2~1-5 各自独立引入主题，不引用 1-1。在"两轮速通"框架下，它们应该在开头做 1-1 回看：

| 单元 | 应回看 1-1 的内容 | 建议回看句 |
|------|------|------|
| 1-2 | 1-1 中"微分方程→传递函数→极点"链 | "在 1-1 中，你第一次听到了'传递函数'和'极点'这两个词。今天，我们来看看它们到底怎么来的。" |
| 1-3 | 1-1 中"参数变化→极点迁移→根轨迹"链 | "在 1-1 中，你看到增益增大后极点在复平面上移动。今天，我们把这条移动的路径画得更清楚。" |
| 1-4 | 1-1 中"正弦输入→幅值/相角变化→Bode"链 | "在 1-1 中，你第一次知道系统对不同节律态度不同。今天，我们把这种'态度'变成可以看图说话的语言。" |
| 1-5 | 1-1 的完整代码示例 | "在 1-1 中，你用几行代码看到了三张图同时变化。今天，你将在平台上亲手操作同样的联动关系。" |

### GAP 3：M2 缺少与 M1 的承接 🔴

前次分析中已指出，但需要补充：M2 各单元不仅应回看 M1，还应显式标注"第三轮"定位。建议在 M2 每个单元开头增加一个标准化的"三轮定位框"：

```
┌─────────────────────────────────────────────┐
│ 🔄 三轮学习路径                              │
│ 第一轮（1-1）：你知道了"传递函数"这个名字       │
│ 第二轮（1-2）：你用极点位置做了最简单的判断     │
│ 👉 第三轮（本单元）：你将学会如何自己推导传递函数 │
└─────────────────────────────────────────────┘
```

### GAP 4：1-1 闪电速通中的术语分层未定义 🟡

闪电速通必然带来术语轰炸。需要明确区分：
- **速通中只需露出名字的**：根轨迹、Bode 图、Nyquist 图、Routh 判据、相位裕度、截止频率
- **速通中需要稍微解释的**：传递函数、极点、稳定性、反馈、误差
- **速通中需要重点讲透的**：反馈思想（全课灵魂）

建议在 1-1 讲义末尾增加一个"你今天听到的新词"速查表，按上述三层标注 ⭐（必须记住）/ 🔷（知道有这个东西）/ ◌（听到名字即可），让学生有心理预期。

### GAP 5：1-1 的课程总图（表 4）需要与闪电速通的主题顺序对齐 🟡

当前表 4 用五个模块描述课程。但闪电速通用 8 个主题（建模→时域→稳定→根轨迹→频域→校正）描述课程。这两个框架需要互相映射——表 4 中应该增加一列"在闪电速通中的对应主题"，让学生看到"速通中的这个东西会在哪个模块被正式展开"。

### GAP 6：M1 的练习体系需要配合"两轮速通"重设计 🟡
