### 模块 2：对象建立层（8 学时） — 质量 A-，内部一致性 A / 对设计文档一致性 C

#### 结构：严格的"对象建立链"

```
2-1 建模对象（传递函数+典型环节+结构表达）
  → 2-2 时域对象（阶跃响应+动态指标+极点桥接）
    → 2-3 频域对象（G(jω)+频率特性+Bode 骨架）
      → 2-4 图形对象（Nyquist 轨迹+频域指标+双图对照+反向识别）
```

每份讲义在前一份基础上建立，接力设计出色。

#### 核心优势

- 2-1 开篇问题驱动力极强——"微分方程擅长描述系统如何运动，却不易承担系统如何连接、如何分析、如何比较等任务"
- 2-2 的"正反两道例题"（正向分析参数→指标 + 逆向设计指标→参数范围）是全局最佳教学设计之一，在模块 2 中最早引入设计思维
- 2-2 的 2.5 节（时域指标到极点趋势的桥接）完成了关键的认知飞跃
- 2-3 的 s=jω 替换合理性讨论解决了传统教学中常见的概念困惑点
- 2-4 的 Bode/Nyquist 双图对照框架（"同一对象在两张图中必须讲述同一件事"）非常清晰
- 四份讲义均配备完整附录（拉氏表、推导、代码示例）

#### 🟡 严重问题：设计文档不匹配

实际讲义内容与 `syllabus-refactor/unit-design-details/module2.md` 描述的旧体系完全不同：

| 旧设计（已过期） | 实际讲义（新） |
|------|------|
| 2-1 性能指标 | 建模与变换语言 |
| 2-2 欠阻尼二阶系统 | 时域响应基础 |
| 2-3 稳定性（Routh 判据） | 频率响应基础与 Bode 图初步 |
| 2-4 稳态误差 | Nyquist 图与频域指标入口 |

**实际讲义已将频域对象从模块 3 前移至模块 2，形成了清晰的对象建立链。这是正向改进，但设计文档必须同步。**

#### 其他发现

- 2-1 船舶航向案例在后续单元中未直接复用（每个单元用独立类比，而非复用 2-1 的精确传递函数）

- 2-4 存在节编号跳跃（缺少第 7 节）
- 2-3 和 2-4 中 Bode 手绘缺少完整逐步演示

### 模块 3：结构机理层（18 学时） — 质量 A，内部一致性 A / 对 CLAUDE.md 一致性 D

#### 结构：机制主导的 9 单元体系

```
3-1 纯极点语言(理论) → 3-2 稳定边界(实践) → 3-3 根轨迹法则(理论) → 3-4 根轨迹读图(实践)
  → 3-5 零点动态改善(理论) → 3-6 零点设计实验(实践) → 3-7 稳态改善(理论)
    → 3-8 频域统一翻译(理论) → 3-9 综合映射(实践)
```

理论与实践的交替节奏（理论→实践→理论→实践→理论→理论→实践）是课程体系中最完善的教学模块。

#### 核心优势

- "机制主导"组织原则执行彻底——不是罗列控制器名称或方法类别，而是以背后的机制呈现
- 3-1 通过三组模型对比（参考模型 / 系统 A / 系统 B）使主导极点概念可视化，时域和频域显式分离为两个独立证据维度
- 3-2 全文使用同一四阶特征方程族 D(s,k)，从固定参数到参数化再到变量平移，统一性极佳
- 3-4 的"稳定窗口 vs 可接受窗口"区分、根轨迹增益 k 与实际控制器增益 K 的换算，解决了学生常见的概念混用
- 3-5 的"等效阻尼相同不等于响应相同"（PD vs 测速反馈对比）是教学设计亮点
- 3-6 的五个任务共用同一对象、同一组目标，形成可直接比较的设计实验序列
- 3-7 的"给定通道与扰动通道分离"是稳态误差教学中最基础也最常被跳过的概念
- 3-8 的"频域指纹"模型（四种结构变化各自在幅频/相频上留下特征痕迹）是强教学模型
- 3-9 的积分家族渐变谱系（弱积分→强积分→积分校正→滞后对照）是极好的出口教学设计

#### 与 CLAUDE.md 的描述严重不一致

CLAUDE.md 中模块 3 的描述（3-1 高阶低阶近似、3-2 劳斯判据、3-3 根轨迹细节修正...3-7 幅相特性 Nyquist、3-8 稳定判据、3-9 稳定裕度）与实际讲义的重大偏差——这是设计文档过期问题，不是讲义质量问题。

#### 发现的问题

- **3-3 与 3-4 符号差异**：3-3 使用 K 表示根轨迹增益，3-4 显式区分根轨迹增益 k 与实际控制器增益 K。教学上合理，但过渡需标注
- **3-7 案例断裂**：单元 3-1 至 3-6 和 3-8 至 3-9 使用统一的船舶航向控制对象，3-7 换成 Gp(s)=4/[s(s+4)]，打破案例连续性
- **广义根轨迹覆盖范围有限**：3-4 仅通过局部反馈系数 a 的单一扩展处理，未讨论其他非增益参数如时间常数
- **模块 2 前置未显式回收**：讲义假设模块 2 材料已掌握，但缺少诊断模块 2 准备的练习

### 模块 4：约束设计层（14 学时） — 质量 A-，内部一致性 B+ / 对设计文档一致性 D

#### 结构：经历了最深度的重构

```
4-1 任务表达(理论) → 4-2 结构选型(理论) → 4-3 复合方案落地(实践)
  → 4-4 无约束优化(理论) → 4-5 约束优化(实践) → 4-6 场景迁移+结构编码(理论)
    → 4-7 闭环验证(实践)
```

#### 核心优势

- **从传统的"校正方法罗列"彻底转型为"工程设计动作链"**——这是全课程中最有野心的重构
- 每个相邻单元之间有明确的"参数交接"（表到表的精确引用），接力设计出色
- 4-3 的分步建构法（逐节叠加复合环节：扰动前馈→参考前馈→给定滤波→限幅抗饱和，每步配结构图和响应对比图）是全局最佳教学策略之一
- 4-4→4-5→4-6→4-7 的优化设计链是全局最连贯的四课次链路：偏好建模→约束建模→结构选择→全流程验证
- 4-5 是唯一含完整可运行 MATLAB 代码附录的单元
- 4-6 的四类方案 2×2 矩阵对比（客船/驱逐舰 × 固定/变结构）是模块 4 中最有结构性的比较设计

#### 🟡 最严重的设计文档错位

`syllabus-refactor/unit-design-details/module4.md` 描述的单元主题与实际讲义完全不匹配：

| 旧设计（已过期） | 实际讲义（新） |
|------|------|
| 4-1 三频段概念 | 设计起点：指标体系、约束与可行域 |
| 4-2 串联超前校正 | 控制器选型与单结构整定（8 种结构） |
| 4-3 串联滞后校正 | 经典复合控制（前馈+反馈+实现层保护） |
| 4-4 滞后-超前校正与 PID | 多目标权衡与无约束加权优化 |
| 4-5 反馈校正 | 约束优化（罚函数+fmincon） |
| 4-6 离散控制基础 | 场景迁移与结构编码搜索（GA/PSO） |
| 4-7 设计综合 | 高保真辨识、验证与扰动边界 |

这不是渐进调整，而是结构性重写。全课程体系中设计文档与实际内容差距最大的模块。

#### 发现的问题

- **4-6 教学密度过大**：一个 90 分钟课次内需消化场景迁移、目标函数重写、五类结构编码（含有效/忽略槽位）、GA/PSO 四套新概念体系
- **4-7 存在 LaTeX 格式残留**：`\newpage`、`\begin{table}[H]`、`\end{table}` 等命令在 Markdown 环境下不生效
- **优化算法缺少教学铺垫**：梯度下降（4-4）、GA（4-6 附录）、PSO（4-6 附录）在模块 4 中被引入，但没有任何单元专门讲解这些算法的工作原理
- **客船案例疲劳**：客船航向控制在 4-1 至 4-6 共六个课次中作为核心锚点案例贯穿，教学一致性优秀，但可能导致案例疲劳

### 模块 5：知识边界与方法迁移层（12 学时） — 质量 A-，一致性 A-

#### 结构：连续迁移链

```
5-1 线性主干边界识别 → 5-2 非线性最小分析入口 → 5-3 复杂自主系统链路(MASS)
  → 5-4 模型驱动到数据驱动 → 5-5 显式控制到策略学习 → 5-6 方法比较收束
```

每一环都是"上一环发现了什么不足，这一环用什么方法补足"，递进压力构建自然。

#### 核心优势

- "迁移链"组织是全课程中最具创新性的结构设计——不是前沿专题并列罗列，而是连续迁移判断链
- 5-1 的"五个默认条件"框架和五步边界判断框架设计精良，局部线性化的"合理 vs 不合理"对比较扎实
- 5-3 的"避碰转向过急"定量分析（从启动距离公式到舵角估算到 R_min 计算）是全局最佳工程案例之一
- 5-4 的三种路线同题对比（传统固定控制 vs 名义模型 MPC vs 数据驱动模型 MPC）提供了可复现的量化比较基准
- 5-5 的十步 RL 设计路线从结构到评价覆盖了工程部署的完整思考流程
- 5-6 的方法选择说明卡是模块 5 的可交付成果，实践性强

#### 发现的问题

- **场景断裂**：5-1 到 5-5 以船舶/MASS 为统一主线，5-6 突然切换到疫苗冷链场景，失去贯穿全课程的锚点连续性
- **术语差异**：5-5 用"安全外壳"（safety shield），5-6 用"安全壳"（safety shroud），同一概念不同用词
- **单元深度不均衡**：5-2（约 7000 token）显著长于 5-3（约 5000 token），描述函数的数学推导对 90 分钟可能超载
- **AI 融入不可见**：模块 5 的四步 AI 动作链（学生独立判断→AI 结构化比较→学生修订→教师收束）在讲义正文中完全没有体现
- **5-5 RL 评价结果的叙事张力不足**：RL 直接控舵的 RMS 误差（30.62°）比 PID（4.43°）高出一个数量级，可能强化"RL 不可用"的刻板印象

### 3.2 🟡 跨模块术语和符号不一致

- **$G_0(s)$ vs $G_{\mathrm{o}}(s)$**：1-3 使用数字 0 下标，1-5 使用字母 o 下标。术语表已规定统一为 $G_{\mathrm{o}}(s)$。
- **"安全外壳" vs "安全壳"**：模块 5 内 5-5 和 5-6 的用词不同
- **案例对象不连续**：船舶航向控制是模块 1-4 和模块 5 前半的统一锚点，但 3-7 换成独立对象 Gp(s)=4/[s(s+4)]，5-6 换成疫苗冷链温控
- **"方框图" vs "结构图"**：2-1 统一使用"方框图"，但其他模块偶见"结构图"

### 3.3 🟡 模块间前置依赖回收不够显式

- 模块 3 没有显式回收模块 2 建立的四类对象语言（时域指标、频域对象、Bode/Nyquist 图形语言），依赖学生自己记住
- 模块 4 大量调用模块 3 的机理图，但只在内部交接表中标注，不在讲义开头做显式回收
- 模块 5 的前置依赖相对清晰，5-1 开篇即回收"模块 2-4 的线性主干"

### 3.4 🟢 教师版讲义覆盖不均衡

- 模块 2 有四份教师版讲义（双轨完整）
- 模块 3 有八份（缺 3-1 教师版）
- 模块 4 有六份（缺 4-4 教师版）

### 3.5 🟢 配套文件缺失

## 六、结论

### 6.1 体系质量判断

这个课程讲义体系的质量远超一般高校自编教材水平。31 份讲义在教学内容、教学设计、写作质量三个维度均达到了可出版的品质。模块 3 的"机制主导"组织和模块 4 的"优化设计链"代表了对传统自动控制原理教学体系的真正重构，不是表面翻新。

### 6.2 当前状态

- **可以直接进入课堂试运行的模块**：模块 3（条件最成熟，九单元体系完整、理论与实践交替节奏合理、术语一致性好）
- **修复 1-2 周后可试运行的模块**：模块 1（8 项已知问题）、模块 2（设计文档同步 + 少量修复）
- **修复 2-4 周后可试运行的模块**：模块 4（设计文档需完全重写 + 4-6 密度调整 + 4-7 格式修复）
- **修复 1-2 周后可试运行的模块**：模块 5（场景断裂 + 术语统一 + AI 融入嵌入）

### 6.3 最关键的行动项

1. **立即同步设计文档**（第一批 D1-D6）：让 `syllabus-refactor/` 和 `CLAUDE.md` 反映已经完成的讲义重构，这是后续一切工作的基础
2. **修复模块 1 的 8 项已知问题**（第二批 M1-M7）：它们直接影响学生第一印象中的课程总图可信度
3. **修复跨模块术语和符号不一致**（第三批 C1-C7）：消除学生在跨模块学习中的认知摩擦

### 6.4 后续维护建议

- 今后每次完成一个模块的讲义重构后，**同步更新对应的 `unit-design-details/module{N}.md`**，不让设计文档再次过期
- 新单元引入新术语时，**同步更新 `authoring/terminology.md`**
- 每完成一个模块的修复，**更新本评估报告**，标注已修复项
- 将 `CLAUDE.md` 中的模块描述与 `blueprint.md` 保持为"活文档"——它们应该是已实现内容的最新索引，而非历史蓝图
