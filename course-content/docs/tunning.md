典型控制结构的参数设计，表面是在调 (K_p,T_i,T_d,\alpha,\beta) 等参数；本质是在调四件事：

1. **低频增益**：决定稳态误差和低频抗扰能力。PI、滞后主要改这里。
2. **交越频率 / 带宽**：决定响应速度。比例、超前、PD 会显著影响这里。
3. **相位裕度 / 阻尼**：决定超调、振荡和鲁棒性。PD、超前、测速反馈主要改这里。
4. **高频增益**：决定噪声敏感性和控制量抖动。微分、超前、前馈逆模型都可能带来问题。

所以参数设计不要从“我该怎么调 PID”开始，而应从指标出发：

稳态误差是多少？
超调允许多少？
调节时间要求多快？
扰动主要在低频还是高频？
噪声大不大？
执行器是否容易饱和？
模型是否可信？

下面按结构总结。

---

# 1. 统一的设计框架

设被控对象为

[
G(s)
]

控制器为

[
C(s)
]

开环传递函数为

[
L(s)=C(s)G(s)
]

闭环特征方程为

[
1+C(s)G(s)=0
]

设计参数时常用两类指标。

一类是时域指标：

[
M_p,\quad t_s,\quad t_r,\quad e_{ss}
]

其中 (M_p) 是超调量，(t_s) 是调节时间，(e_{ss}) 是稳态误差。

如果闭环主导极点近似为二阶系统，则常用关系是：

[
M_p=e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}}
]

[
t_s\approx \frac{4}{\zeta\omega_n}
]

这里 (\zeta) 是阻尼比，(\omega_n) 是自然频率。

另一类是频域指标：

[
\omega_c,\quad PM,\quad GM
]

其中 (\omega_c) 是幅值交越频率，(PM) 是相位裕度，(GM) 是幅值裕度。一般来说：

[
\omega_c \uparrow \Rightarrow 响应更快
]

[
PM \uparrow \Rightarrow 阻尼更好，超调更小，鲁棒性更强
]

但 (\omega_c) 太高会放大噪声，也会激发未建模高频动态。

一个比较稳妥的工程目标是：相位裕度通常取 (45^\circ\sim 60^\circ)，要求高鲁棒性时取更大；带宽不能超过传感器、执行器和对象模型可信频段。

---

# 2. 参数设计方法的总分类

典型结构的参数设计方法大致分成六类。

## 2.1 经验调参法

适合对象模型不清楚，但允许做实验的场景。

典型流程是：

先用 P 控制调出基本响应；
再加 I 消除稳态误差；
如果超调或振荡明显，再加 D 或测速反馈增加阻尼；
最后检查噪声、饱和和鲁棒性。

优点是简单，缺点是依赖经验，且容易得到“能跑但不优”的参数。

---

## 2.2 Ziegler-Nichols 临界比例法

适合能做闭环实验的系统。

步骤：

只使用比例控制 (K_p)，逐渐增大 (K_p)，直到系统出现等幅振荡。此时的比例增益称为临界增益 (K_u)，振荡周期称为临界周期 (P_u)。

经典 Ziegler-Nichols 闭环整定表为：

| 控制器 |     (K_p) |     (T_i) |   (T_d) |
| --- | --------: | --------: | ------: |
| P   |  (0.5K_u) |         — |       — |
| PI  | (0.45K_u) | (P_u/1.2) |       — |
| PID |  (0.6K_u) |   (P_u/2) | (P_u/8) |

如果用的是

[
C(s)=K_p\left(1+\frac{1}{T_i s}+T_d s\right)
]

则

[
K_i=\frac{K_p}{T_i},\qquad K_d=K_pT_d
]

这个方法通常偏激进，超调较大。教学上很有价值，但工程上经常要把 (K_p) 和积分作用适当减弱。

一个更保守的版本是 Tyreus-Luyben 整定：

| 控制器 |     (K_p) |    (T_i) |     (T_d) |
| --- | --------: | -------: | --------: |
| PI  | (K_u/3.2) | (2.2P_u) |         — |
| PID | (K_u/2.2) | (2.2P_u) | (P_u/6.3) |

它比 Ziegler-Nichols 更稳健，但响应也更慢。

---

## 2.3 开环阶跃响应法

适合过程控制对象，例如温度、液位、压力、流量等。

先用阶跃实验把对象近似成一阶惯性加纯滞后模型：

[
G(s)=\frac{K e^{-Ls}}{\tau s+1}
]

其中：

[
K
]

是对象静态增益；

[
L
]

是等效纯滞后时间；

[
\tau
]

是时间常数。

经典 Ziegler-Nichols 开环整定为：

| 控制器 |                (K_p) |   (T_i) |  (T_d) |
| --- | -------------------: | ------: | -----: |
| P   |    (\frac{\tau}{KL}) |       — |      — |
| PI  | (0.9\frac{\tau}{KL}) | (3.33L) |      — |
| PID | (1.2\frac{\tau}{KL}) |    (2L) | (0.5L) |

这个方法也偏激进。纯滞后 (L) 越大，闭环越难做快，参数必须更保守。

---

## 2.4 IMC / SIMC 整定法

IMC，即 internal model control，适合有近似模型、希望参数稳健的过程控制场景。

仍以一阶惯性加纯滞后对象为例：

[
G(s)=\frac{K e^{-Ls}}{\tau s+1}
]

常用 PI 参数可取：

[
K_p=\frac{\tau}{K(\lambda+L)}
]

[
T_i=\min{\tau,;4(\lambda+L)}
]

其中 (\lambda) 是期望闭环时间常数。

[
\lambda \downarrow \Rightarrow 响应更快，但鲁棒性变差
]

[
\lambda \uparrow \Rightarrow 响应更慢，但鲁棒性更好
]

一般可以先取

[
\lambda \ge L
]

如果对象模型不确定、噪声较大、执行器余量小，就取更大的 (\lambda)。

对于二阶惯性加纯滞后对象：

[
G(s)=\frac{K e^{-Ls}}{(\tau_1s+1)(\tau_2s+1)}
]

且 (\tau_1\ge \tau_2)，可用近似 PID 参数：

[
K_p=\frac{\tau_1}{K(\lambda+L)}
]

[
T_i=\min{\tau_1,;4(\lambda+L)}
]

[
T_d=\tau_2
]

IMC/SIMC 的价值在于：它把“调参问题”转化成“选闭环速度 (\lambda)”的问题，比纯经验调参更清楚。

---

## 2.5 极点配置法

适合对象模型比较明确、阶次不高的场景。

核心思想是：希望闭环极点在哪里，就让闭环特征方程的系数匹配目标多项式。

例如对象为一阶：

[
G(s)=\frac{b}{s+a}
]

采用 PI 控制器：

[
C(s)=K_p+\frac{K_i}{s}
]

闭环特征方程为：

[
1+C(s)G(s)=0
]

整理得：

[
s^2+(a+bK_p)s+bK_i=0
]

如果希望闭环为：

[
s^2+2\zeta\omega_n s+\omega_n^2
]

则直接得到：

[
K_p=\frac{2\zeta\omega_n-a}{b}
]

[
K_i=\frac{\omega_n^2}{b}
]

这就是非常清楚的“按目标阻尼和速度设计 PI”。

再例如对象为二阶：

[
G(s)=\frac{b}{s^2+a_1s+a_0}
]

采用 PID：

[
C(s)=K_p+\frac{K_i}{s}+K_d s
]

闭环特征方程为：

[
s^3+(a_1+bK_d)s^2+(a_0+bK_p)s+bK_i=0
]

如果目标闭环多项式为：

[
(s^2+2\zeta\omega_n s+\omega_n^2)(s+p_f)
]

其中 (p_f) 是一个非主导极点，通常取为主导极点实部的 (3\sim 5) 倍以上，则展开后匹配系数即可得到 (K_d,K_p,K_i)。

极点配置法的优点是结构清晰；缺点是对模型敏感，并且没有天然处理噪声、饱和和未建模动态。

---

## 2.6 频域设计法

适合使用 Bode 图、Nyquist 图、相位裕度、幅值裕度进行设计的场景。超前、滞后、超前-滞后最适合用这种方法。

设计目标通常是：

[
|C(j\omega_c)G(j\omega_c)|=1
]

[
\angle C(j\omega_c)G(j\omega_c)=-180^\circ+PM
]

也就是说，参数设计的核心是：在目标交越频率 (\omega_c) 附近，把幅值调到 0 dB，把相位调到满足相位裕度要求。

---

# 3. PI 控制器的参数设计

PI 控制器常写为：

[
C(s)=K_p\left(1+\frac{1}{T_i s}\right)
]

也可写为：

[
C(s)=K_p+\frac{K_i}{s}
]

其中：

[
K_i=\frac{K_p}{T_i}
]

PI 的两个参数作用是：

[
K_p \uparrow \Rightarrow 响应更快，但可能超调、振荡
]

[
T_i \downarrow \Rightarrow 积分更强，稳态误差更小，但更容易超调和振荡
]

## 3.1 经验整定法

先设 (K_i=0)，只调 (K_p)。

把 (K_p) 从小到大增加，直到响应速度基本满意，但不出现严重振荡。

然后加入积分，逐渐减小 (T_i)，直到稳态误差满足要求。

如果加入积分后超调变大或振荡明显，有三个处理办法：

增大 (T_i)，减弱积分；
减小 (K_p)；
加入超前、PD 或测速反馈提高阻尼。

PI 调参中最常见的错误，是为了消除稳态误差而把积分调得太强。这样短期看误差消得快，实际会带来超调、低频振荡和积分饱和。

---

## 3.2 基于稳态误差的设计

PI 的积分环节会提高系统型别。例如原系统对阶跃输入存在稳态误差，加入 PI 后通常可以消除阶跃稳态误差。

如果主要目标是消除阶跃稳态误差，PI 很直接。

如果只是希望稳态误差变小，但不一定要求完全消除，可以考虑滞后校正，因为它比 PI 温和。

---

## 3.3 频域设计法

PI 的零点在：

[
\omega_z=\frac{1}{T_i}
]

PI 会带来低频增益，但在交越频率附近会引入负相位。因此常见做法是把 PI 零点放在目标交越频率以下：

[
\omega_z=\frac{\omega_c}{5}\sim \frac{\omega_c}{10}
]

即：

[
T_i=\frac{1}{\omega_z}
]

这样在 (\omega_c) 附近 PI 的相位滞后较小，不会严重破坏相位裕度。

确定 (T_i) 后，再由幅值条件确定 (K_p)：

[
|C(j\omega_c)G(j\omega_c)|=1
]

因为

[
\left|1+\frac{1}{j\omega_c T_i}\right|
======================================

\sqrt{1+\left(\frac{1}{\omega_cT_i}\right)^2}
]

所以

[
K_p=
\frac{1}
{|G(j\omega_c)|\sqrt{1+\left(\frac{1}{\omega_cT_i}\right)^2}}
]

---

## 3.4 PI 的适用边界

PI 适合稳态误差明显、扰动偏低频、噪声不太严重的场景。

但以下情况要谨慎：

对象本身已有积分环节；
执行器容易饱和；
对象有大纯滞后；
闭环要求很快；
低频扰动很强且积分会 windup。

实际工程中 PI 几乎必须配合抗积分饱和。

常见抗饱和做法包括：

积分限幅；
条件积分；
反算抗饱和 back-calculation；
执行器饱和时暂停或削弱积分。

---

# 4. PD 控制器的参数设计

PD 控制器常写为：

[
C(s)=K_p(1+T_d s)
]

实际中通常不用理想微分，而用带滤波的 PD：

[
C(s)=K_p\left(1+\frac{T_d s}{1+\frac{T_d}{N}s}\right)
]

其中 (N) 通常取 (5\sim 20)。

PD 的作用是提高阻尼、减小超调、抑制振荡、改善动态。

参数作用是：

[
K_p \uparrow \Rightarrow 响应更快，但超调可能变大
]

[
T_d \uparrow \Rightarrow 阻尼增强，但噪声放大更明显
]

---

## 4.1 基于二阶模型的设计

对机械位置系统，一个常见模型是：

[
J\ddot y+B\dot y=u
]

若采用 PD 控制：

[
u=K_p(r-y)-K_d\dot y
]

闭环特征方程为：

[
Js^2+(B+K_d)s+K_p=0
]

与标准二阶系统比较：

[
s^2+2\zeta\omega_n s+\omega_n^2=0
]

得到：

[
K_p=J\omega_n^2
]

[
K_d=2\zeta\omega_nJ-B
]

这个公式非常有教学价值：比例增益主要决定“弹簧刚度”，微分增益主要决定“阻尼”。

如果 (K_d<0)，说明你选择的 (\zeta,\omega_n) 与系统原有阻尼不匹配，需要重新选目标指标。

---

## 4.2 频域设计法

PD 在频率 (\omega) 处提供的相位超前为：

[
\phi_D=\arctan(\omega T_d)
]

如果希望在目标交越频率 (\omega_c) 处提供相位 (\phi_D)，可取：

[
T_d=\frac{\tan\phi_D}{\omega_c}
]

然后由幅值条件确定 (K_p)：

[
K_p=
\frac{1}
{|G(j\omega_c)|\sqrt{1+(\omega_cT_d)^2}}
]

但理想 PD 高频增益无界，所以实际设计必须加入微分滤波。滤波越强，实际提供的相位超前越少。

---

## 4.3 根轨迹设计法

如果希望闭环主导极点为：

[
s_d=-\zeta\omega_n+j\omega_n\sqrt{1-\zeta^2}
]

PD 提供一个零点：

[
C(s)=K(s+z)
]

通过根轨迹角度条件确定零点位置：

[
\angle C(s_d)G(s_d)=(2k+1)180^\circ
]

也就是：

[
\angle (s_d+z)
==============

180^\circ-\angle G(s_d)
]

确定 (z) 后，再由幅值条件确定 (K)：

[
|K(s_d+z)G(s_d)|=1
]

根轨迹法适合解释 PD 为什么能“拉动根轨迹”经过期望极点。

---

## 4.4 PD 的适用边界

PD 适合阻尼不足、超调大、振荡明显的系统。

但测量噪声大时要谨慎。微分对高频噪声非常敏感。

实际中常用“输出微分”而不是“误差微分”：

[
u=K_p(r-y)-K_d\dot y
]

这样可以避免给定阶跃变化时产生微分冲击。

---

# 5. PID 控制器的参数设计

PID 控制器常写为：

[
C(s)=K_p\left(1+\frac{1}{T_i s}+T_d s\right)
]

实际形式通常是：

[
C(s)=K_p\left(1+\frac{1}{T_i s}+\frac{T_d s}{1+\frac{T_d}{N}s}\right)
]

也可写为：

[
C(s)=K_p+\frac{K_i}{s}+K_d s
]

其中：

[
K_i=\frac{K_p}{T_i},\qquad K_d=K_pT_d
]

PID 的三个作用分别是：

P：提供基本纠偏能力；
I：消除稳态误差；
D：增加阻尼、改善动态。

---

## 5.1 经验整定流程

比较稳妥的流程是：

先关掉 I 和 D，只调 P。
增大 (K_p)，让系统响应速度接近要求，但不要让振荡太严重。

再加入 I。
减小 (T_i)，使稳态误差满足要求。若超调或振荡变大，说明积分太强。

最后加入 D。
增大 (T_d)，抑制超调、提高阻尼。若控制量抖动或噪声明显，说明微分太强或滤波不够。

最后整体回调：

如果响应慢，略增 (K_p) 或减小 (\lambda) / 提高带宽；
如果超调大，减小 (K_p)，增大 (T_i)，或增大适量 (T_d)；
如果稳态误差消除慢，减小 (T_i)；
如果噪声大，减小 (T_d)，减小 (N)，或降低带宽。

---

## 5.2 Ziegler-Nichols / Relay Autotuning

PID 的快速整定可以用临界比例法。

找出：

[
K_u,\quad P_u
]

然后取：

[
K_p=0.6K_u
]

[
T_i=\frac{P_u}{2}
]

[
T_d=\frac{P_u}{8}
]

等价地：

[
K_i=\frac{K_p}{T_i}
]

[
K_d=K_pT_d
]

Relay autotuning 的思想是用继电器非线性激发系统产生极限环，从而估计 (K_u,P_u)，再代入整定公式。它比手动把系统逼到临界振荡更安全一些，但本质仍是频域临界整定。

---

## 5.3 极点配置法

对于二阶对象：

[
G(s)=\frac{b}{s^2+a_1s+a_0}
]

PID 闭环特征方程为：

[
s^3+(a_1+bK_d)s^2+(a_0+bK_p)s+bK_i=0
]

设目标闭环多项式为：

[
(s^2+2\zeta\omega_n s+\omega_n^2)(s+p_f)
]

展开：

[
s^3+(2\zeta\omega_n+p_f)s^2+(\omega_n^2+2\zeta\omega_np_f)s+\omega_n^2p_f
]

于是：

[
K_d=
\frac{2\zeta\omega_n+p_f-a_1}{b}
]

[
K_p=
\frac{\omega_n^2+2\zeta\omega_np_f-a_0}{b}
]

[
K_i=
\frac{\omega_n^2p_f}{b}
]

其中 (p_f) 越大，第三极点越快，但控制量可能越激烈，噪声和执行器压力也越大。

---

## 5.4 IMC-PID 设计

对于二阶惯性加纯滞后对象：

[
G(s)=\frac{K e^{-Ls}}{(\tau_1s+1)(\tau_2s+1)}
]

常见近似 PID 参数为：

[
K_p=\frac{\tau_1}{K(\lambda+L)}
]

[
T_i=\min{\tau_1,;4(\lambda+L)}
]

[
T_d=\tau_2
]

这里 (\lambda) 是闭环速度参数。它越小，系统越快；越大，系统越稳健。

---

## 5.5 二自由度 PID

实际系统中，给定跟踪和扰动抑制经常有冲突。

一种常用形式是：

[
u=K_p(\beta r-y)+K_i\int(r-y)dt-K_d\dot y
]

其中 (\beta) 是比例给定权重，通常：

[
0\le \beta\le 1
]

[
\beta=1
]

表示普通 PID；

[
\beta<1
]

可以减小给定阶跃引起的超调。

微分项通常只对输出 (y) 做，而不是对误差 (r-y) 做，这样可以避免 derivative kick。

如果系统主要问题是给定变化时超调大，但扰动抑制又需要较大的反馈增益，二自由度 PID 比单纯减小 (K_p) 更合理。

---

# 6. 超前校正的参数设计

超前校正常写为：

[
C_{\text{lead}}(s)=K_c\frac{Ts+1}{\alpha Ts+1}
]

其中：

[
0<\alpha<1
]

零点为：

[
\omega_z=\frac{1}{T}
]

极点为：

[
\omega_p=\frac{1}{\alpha T}
]

因为 (\alpha<1)，所以：

[
\omega_p>\omega_z
]

超前校正的最大相位超前为：

[
\phi_{\max}
===========

\sin^{-1}\left(\frac{1-\alpha}{1+\alpha}\right)
]

发生在：

[
\omega_m=\frac{1}{T\sqrt{\alpha}}
]

在 (\omega_m) 处的幅值提升为：

[
\left| \frac{j\omega_mT+1}{j\omega_m\alpha T+1} \right|
=======================================================

\frac{1}{\sqrt{\alpha}}
]

---

## 6.1 频域设计步骤

第一步，确定期望交越频率 (\omega_c) 和期望相位裕度 (PM^\star)。

第二步，计算当前对象在 (\omega_c) 处的相位：

[
\angle G(j\omega_c)
]

需要控制器补充的相位近似为：

[
\phi_{\text{need}}
==================

-180^\circ+PM^\star-\angle G(j\omega_c)
]

实际设计时要多留 (5^\circ\sim 12^\circ) 余量，因为超前校正会改变交越频率。

第三步，令：

[
\phi_{\max}\approx \phi_{\text{need}}+5^\circ\sim 12^\circ
]

由

[
\alpha=\frac{1-\sin\phi_{\max}}{1+\sin\phi_{\max}}
]

求出 (\alpha)。

第四步，把最大相位超前点放在目标交越频率附近：

[
\omega_m=\omega_c
]

所以：

[
T=\frac{1}{\omega_c\sqrt{\alpha}}
]

第五步，根据幅值条件求 (K_c)：

[
|C_{\text{lead}}(j\omega_c)G(j\omega_c)|=1
]

因为在 (\omega_c=\omega_m) 处超前环节幅值约为 (1/\sqrt{\alpha})，所以：

[
K_c=
\frac{\sqrt{\alpha}}{|G(j\omega_c)|}
]

---

## 6.2 超前校正的设计判断

超前校正适合以下情况：

响应太慢；
相位裕度不足；
增大比例增益会引起振荡；
希望提高带宽和阻尼。

但超前校正会提高中高频增益，所以噪声大、对象高频模型不可信、执行器带宽不足时不能过度使用。

单个超前环节通常提供 (30^\circ\sim 50^\circ) 的有效相位补偿较合适。若需要更大相位，常用两个超前环节分担，而不是一个超前环节硬撑。

---

# 7. 滞后校正的参数设计

滞后校正可写为：

[
C_{\text{lag}}(s)=\beta\frac{Ts+1}{\beta Ts+1}
]

其中：

[
\beta>1
]

该形式下：

低频增益为：

[
C_{\text{lag}}(0)=\beta
]

高频增益近似为：

[
C_{\text{lag}}(\infty)\approx 1
]

所以它的作用是：提高低频增益，但尽量不改变交越频率附近的幅值。

滞后校正的极点为：

[
\omega_p=\frac{1}{\beta T}
]

零点为：

[
\omega_z=\frac{1}{T}
]

其中：

[
\omega_p<\omega_z
]

---

## 7.1 频域设计步骤

第一步，先确定系统需要把稳态误差改善多少倍。

例如当前稳态误差为 (e_{ss})，目标为 (e_{ss}^\star)，粗略需要低频增益提高：

[
\beta \approx \frac{e_{ss}}{e_{ss}^\star}
]

如果是速度误差常数 (K_v)、位置误差常数 (K_p^\ast) 或加速度误差常数 (K_a) 不足，也可按误差常数所需提高倍数来取 (\beta)。

第二步，选择滞后零点在交越频率以下一段距离：

[
\omega_z=\frac{\omega_c}{10}
]

甚至更低。

于是：

[
T=\frac{1}{\omega_z}
]

第三步，滞后极点取为：

[
\omega_p=\frac{\omega_z}{\beta}
]

等价于：

[
\omega_p=\frac{1}{\beta T}
]

第四步，检查相位裕度。

滞后校正会带来负相位。虽然把极点和零点放在 (\omega_c) 以下可以减少影响，但不会完全没有影响。如果相位裕度不够，就需要重新降低 (\beta)，或配合超前校正。

---

## 7.2 滞后校正的设计判断

滞后校正适合：

动态响应基本可以接受；
主要问题是稳态误差太大；
希望提高低频增益；
不希望显著提高交越频率。

滞后校正不适合用来加快系统。它甚至可能让系统变慢。

PI 和滞后校正很像，但区别在于：

PI 包含积分，低频增益趋于无穷，可以消除某些稳态误差；
滞后校正只是有限提高低频增益，更温和，对稳定性的破坏通常比强积分小。

---

# 8. 超前-滞后联合校正的参数设计

超前-滞后联合校正常写为：

[
C(s)=K_c
\frac{T_1s+1}{\alpha T_1s+1}
\cdot
\beta\frac{T_2s+1}{\beta T_2s+1}
]

其中：

[
0<\alpha<1,\qquad \beta>1
]

超前部分负责：

提高相位裕度；
提高带宽；
改善动态响应。

滞后部分负责：

提高低频增益；
改善稳态误差；
增强低频抗扰。

---

## 8.1 推荐设计顺序

更稳妥的顺序是：

先按动态指标设计超前部分；
再按稳态误差指标设计滞后部分；
最后重新检查交越频率和相位裕度。

原因是：动态指标主要由交越频率附近决定，而滞后部分如果设计不当，会改变交越频率和相位裕度。

具体步骤如下。

第一步，确定目标 (\omega_c) 和 (PM^\star)。

第二步，设计超前校正，使系统在目标 (\omega_c) 附近满足相位裕度要求。

第三步，计算稳态误差是否满足要求。

如果低频增益还不够，设需要提高的低频增益倍数为 (\beta)。

第四步，设计滞后环节：

[
\omega_{z,\text{lag}}=\frac{\omega_c}{10}
]

[
\omega_{p,\text{lag}}=\frac{\omega_{z,\text{lag}}}{\beta}
]

第五步，重新画 Bode 图或计算裕度。

如果相位裕度下降过多，需要：

减小 (\beta)；
把滞后极点和零点再往低频移动；
增加超前补偿；
降低目标交越频率。

---

## 8.2 参数设计中的核心矛盾

超前-滞后联合校正不是简单把两个环节拼起来。

真正的矛盾是：

超前希望提高交越频率；
滞后希望提高低频增益但尽量不动交越频率；
如果滞后零极点离交越频率太近，就会损害相位裕度。

所以滞后部分一定要尽量低频布置，超前部分则布置在交越频率附近。

---

# 9. 测速反馈的参数设计

测速反馈常见于机械伺服、位置控制、电机控制等系统。

典型形式为：

[
u=K_r(r-y)-K_v\dot y
]

其中 (K_v) 是测速反馈系数。

对于机械对象：

[
J\ddot y+B\dot y=u
]

代入控制律：

[
J\ddot y+(B+K_v)\dot y+K_r y=K_r r
]

闭环特征方程为：

[
Js^2+(B+K_v)s+K_r=0
]

与标准二阶系统比较：

[
s^2+2\zeta\omega_n s+\omega_n^2=0
]

得到：

[
K_r=J\omega_n^2
]

[
K_v=2\zeta\omega_nJ-B
]

这说明：

位置反馈增益 (K_r) 主要决定系统刚度和响应速度；
测速反馈增益 (K_v) 主要决定阻尼；
系统原有阻尼 (B) 越小，需要的测速反馈越大。

---

## 9.1 测速反馈与 PD 的关系

PD 常写为：

[
u=K_p(r-y)+K_d(\dot r-\dot y)
]

如果给定 (r) 是阶跃信号，(\dot r) 会产生冲击。因此实际常用：

[
u=K_p(r-y)-K_d\dot y
]

这就非常接近测速反馈。

因此可以说：

PD 是对误差信号加微分；
测速反馈是对输出速度加反馈；
在位置控制中，测速反馈通常比误差微分更自然。

---

## 9.2 测速反馈的工程整定

基本流程：

先用位置比例反馈 (K_r) 调到接近目标速度；
如果超调大、振荡明显，增大测速反馈 (K_v)；
如果响应变慢或控制量噪声变大，说明 (K_v) 过大；
速度信号噪声大时，需要滤波或速度观测器。

实际测速反馈常写成：

[
K_v\frac{s}{1+T_f s}
]

其中 (T_f) 是滤波时间常数。

(T_f) 太小，滤波不够，噪声大；
(T_f) 太大，相位滞后明显，测速反馈的阻尼效果下降。

---

# 10. 前馈控制的参数设计

前馈控制的核心不是“稳定闭环”，而是“提前补偿已知输入或扰动”。

常见结构为：

[
u=C(s)(r-y)+F_r(s)r
]

其中 (C(s)) 是反馈控制器，(F_r(s)) 是参考前馈。

若对象为 (G(s))，理想情况下希望：

[
G(s)F_r(s)\approx 1
]

因此：

[
F_r(s)\approx G^{-1}(s)
]

这就是逆模型前馈。

但真正的工程问题是：对象 (G(s)) 未必可逆，逆模型未必稳定，未必真有物理可实现性。

---

## 10.1 参考前馈设计

如果对象是：

[
G(s)=\frac{K}{\tau s+1}
]

理想逆为：

[
G^{-1}(s)=\frac{\tau s+1}{K}
]

这意味着前馈中需要参考信号的微分。

如果参考信号很平滑，例如轨迹规划给出的 (r,\dot r,\ddot r) 都已知，则这种前馈很好用。

但如果参考是阶跃信号，直接微分会产生冲击，所以要加入滤波：

[
F_r(s)=Q(s)G^{-1}(s)
]

其中 (Q(s)) 是低通滤波器，例如：

[
Q(s)=\frac{1}{\lambda_f s+1}
]

(\lambda_f) 越小，前馈越激进；
(\lambda_f) 越大，前馈越平滑但补偿变慢。

---

## 10.2 扰动前馈设计

如果系统为：

[
y=G(s)u+G_d(s)d
]

其中 (d) 是可测扰动，采用扰动前馈：

[
u=C(s)(r-y)+F_d(s)d
]

希望扰动 (d) 对输出 (y) 的影响被抵消，则令：

[
G(s)F_d(s)+G_d(s)=0
]

得到理想扰动前馈：

[
F_d(s)=-\frac{G_d(s)}{G(s)}
]

如果这个传递函数稳定、因果、可实现，就可以直接用；如果不可实现，就加滤波或只补偿主要低频部分。

---

## 10.3 前馈参数的实用整定

前馈参数一般不应盲目调得太激进。

可以按下面方式做：

先保证反馈闭环稳定、鲁棒；
再加入前馈；
前馈增益从理论值的 (50%\sim 80%) 开始；
观察跟踪误差是否由“滞后型”变小；
如果误差反向或超调变大，说明前馈过强或模型不准；
最后加入限幅、斜率限制、滤波和饱和保护。

前馈的基本判断是：

模型越准，前馈越可以强；
模型越不准，前馈越应保守；
前馈负责已知部分，反馈负责未知部分。

---

# 12. 不同方法应该在什么情况下用

如果对象模型基本未知，但能实验：

优先用经验法、Ziegler-Nichols、Relay autotuning。
然后再根据实际响应修正。

如果对象可以近似为一阶惯性加纯滞后：

优先用 IMC/SIMC 或开环阶跃响应法。
过程控制中这比纯 PID 盲调更可靠。

如果对象是低阶、模型清楚：

优先用极点配置。
它能直接把超调、调节时间转化成闭环极点，再转成控制器参数。

如果主要指标是相位裕度、幅值裕度、带宽：

优先用频域设计。
超前、滞后、超前-滞后最适合这种方法。

如果是机械伺服系统：

优先用二阶模型设计 PD 或测速反馈。
先定 (\zeta,\omega_n)，再算 (K_p,K_d) 或 (K_r,K_v)。

如果参考轨迹和扰动可测：

反馈参数先保证稳定和鲁棒；
再用前馈补偿已知部分；
不要指望前馈替代反馈。

如果系统强非线性、强耦合、多约束：

可以用优化整定。
目标函数可以是：

[
J=\int_0^\infty
\left(
w_e e^2(t)+w_u u^2(t)+w_{\Delta u}\dot u^2(t)
\right)dt
]

也可以用 IAE、ISE、ITAE：

[
IAE=\int_0^\infty |e(t)|dt
]

[
ISE=\int_0^\infty e^2(t)dt
]

[
ITAE=\int_0^\infty t|e(t)|dt
]

但优化整定不能只最小化误差，还要加入约束：

相位裕度；
幅值裕度；
控制量限幅；
控制量变化率；
抗噪能力；
参数摄动鲁棒性；
执行器饱和后的恢复能力。

否则很容易得到“仿真里很好、真实系统很差”的参数。

---

# 13. 参数变化对系统的典型影响

| 参数变化                | 常见效果           | 代价                |
| ------------------- | -------------- | ----------------- |
| (K_p) 增大            | 响应变快，稳态误差减小    | 超调增大，稳定裕度下降，控制量增大 |
| (K_i) 增大 / (T_i) 减小 | 稳态误差消除更快       | 振荡、超调、积分饱和        |
| (K_d) 增大 / (T_d) 增大 | 阻尼增加，超调减小      | 噪声放大，控制量抖动        |
| 微分滤波 (N) 增大         | 微分更接近理想，阻尼效果增强 | 高频噪声更明显           |
| 超前 (\alpha) 减小      | 相位超前增加         | 高频增益增加，噪声风险增加     |
| 滞后 (\beta) 增大       | 低频增益提高，稳态误差减小  | 相位滞后增加，响应可能变慢     |
| 测速反馈 (K_v) 增大       | 阻尼增加，超调减小      | 速度噪声放大，响应可能变钝     |
| 前馈增益增大              | 跟踪误差减小         | 模型不准时容易过补偿        |

# 14. 离散实现时的参数注意事项

连续域设计完成后，数字实现不能直接照搬。

采样周期 (T_s) 应明显小于闭环主要时间尺度。常用经验是：

[
T_s \le \frac{1}{10\sim 20}\cdot \frac{1}{\omega_c}
]

更准确地说，采样频率应至少是闭环带宽的 (10\sim 20) 倍。

积分项可用后向欧拉：

[
I[k]=I[k-1]+K_iT_s e[k]
]

微分项不要直接用：

[
\frac{e[k]-e[k-1]}{T_s}
]

而应使用滤波微分，否则噪声会很严重。

数字 PID 中还必须处理：

输出限幅；
积分限幅；
抗积分饱和；
微分滤波；
给定斜坡限制；
执行器死区；
采样延迟。

很多系统连续域仿真很好，数字实现变差，原因不是理论错了，而是忽略了采样、饱和、量化、噪声和执行器速率限制。

---

# 15. 一个可直接使用的设计流程

更可靠的参数设计流程可以整理为：

第一步，建立对象模型。

至少要知道对象大致属于哪类：

一阶惯性；
二阶振荡；
积分对象；
纯滞后对象；
非最小相位对象；
机械惯性对象；
强非线性对象。

第二步，把指标转成控制语言。

稳态误差对应低频增益或积分；
超调对应阻尼比或相位裕度；
调节时间对应自然频率或带宽；
抗扰能力对应灵敏度函数；
噪声抑制对应高频增益和互补灵敏度。

第三步，选择结构。

稳态误差优先 PI 或滞后；
阻尼不足优先 PD、超前、测速反馈；
既要稳态又要动态，用 PID 或超前-滞后；
已知参考或扰动，用前馈；
大时滞系统不要盲目追求高带宽。

第四步，初算参数。

低阶模型用极点配置；
频域指标用 Bode 设计；
过程对象用 IMC/SIMC；
模型不清用 Z-N 或 Relay；
复杂系统用优化整定。

第五步，仿真检查。

至少检查：

阶跃响应；
扰动响应；
噪声输入；
参数摄动；
执行器饱和；
控制量峰值；
控制量变化率。

第六步，实机保守上线。

实际系统中先把参数放保守一些：

降低 (K_p)；
减弱积分；
减弱微分；
增加滤波；
逐步提高性能。

第七步，加入工程保护。

包括：

抗积分饱和；
输出限幅；
斜率限制；
异常检测；
软启动；
给定滤波；
前馈限幅；
速度估计滤波。

# 16. 最后用一张“设计判断表”收束

| 主要问题        | 优先结构        | 参数设计重点                       |
| ----------- | ----------- | ---------------------------- |
| 稳态误差大       | PI          | 选 (K_p,T_i)，积分不要过强           |
| 稳态误差大但动态还可以 | 滞后          | 选 (\beta)，零极点放在交越频率以下        |
| 响应慢但裕度足够    | 增大 (K_p)    | 检查超调和控制量                     |
| 响应慢且一快就振    | 超前          | 选 (\alpha,T,K_c)，提高相位裕度      |
| 超调大、振荡明显    | PD / 测速反馈   | 选 (T_d) 或 (K_v)，增加阻尼         |
| 既有稳态误差又有超调  | PID         | 平衡 (K_p,T_i,T_d)，注意滤波和抗饱和    |
| 稳态和动态都不满足   | 超前-滞后       | 先超前满足动态，再滞后补稳态               |
| 参考轨迹已知      | 参考前馈        | 设计 (F_r\approx G^{-1})，加低通滤波 |
| 扰动可测        | 扰动前馈        | 设计 (F_d=-G_d/G)，保留反馈兜底       |
| 速度可测且机械振荡   | 测速反馈        | 用 (K_v) 增加等效阻尼               |
| 噪声大         | 少用强 D / 强超前 | 降低带宽，加强滤波                    |
| 执行器易饱和      | 减弱 I，限幅     | 必须抗积分饱和                      |
| 纯滞后大        | 降低带宽        | 考虑 Smith 预估、前馈、MPC           |

最核心的判断是：

**PI 和滞后调低频；PD、测速反馈和超前调阻尼与相位；PID 和超前-滞后做综合折中；前馈不负责稳定性，负责把已知变化提前补偿掉。参数设计的关键不是把某个公式套上去，而是让低频精度、交越频率、相位裕度、高频噪声和执行器能力同时成立。**
