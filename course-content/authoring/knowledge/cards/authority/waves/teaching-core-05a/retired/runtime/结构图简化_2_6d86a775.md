# 结构图简化 | Block Diagram Reduction

**一句话定义**：利用基本连接规则和等效变换，把复杂结构图逐步化为单个等效方框的过程。

**标准流程**：
1. 找最内层反馈
2. 做必要等效变换
3. 化简串联/并联/反馈
4. 重复直到剩一个方框

**关联**：前置 → 串联连接、并联连接、反馈连接、结构图等效变换 · 后续 → 闭环传递函数

---

## 详情

### 完整解释

结构图简化的目标不是“画得更简单”，而是求出系统总传递函数。最稳妥的做法是：
- 先识别最容易化简的局部结构
- 若被支路打断，先做等效变换
- 每一步只进行一种基本连接化简
- 保持中间结果清晰，避免跨步跳算

### 典型策略

对于多环系统，通常从**最内层反馈环**开始，因为内环化简后，外层结构往往会自然露出串联或反馈关系。

### 常见误区

1. **误区**：看到多个环路就直接整体套公式。**纠正**：若结构不满足标准反馈形式，必须先通过等效变换和局部化简把结构整理出来。
2. **误区**：等效变换顺序只有一种。**纠正**：路径可以不同，但最终传递函数应一致；要选择最少、最清晰的化简路径。
