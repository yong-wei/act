# 梅森公式六卡固定模型

来源已捕获于scope/source-inventory。注意“前向通路总增益”的来源定义是单条通路上支路增益乘积P_k，不是所有通路增益之和。不得根据标题自行改写语义。

verify-models.py先于正文，使用有理数精确枚举回路组合与余子式，并用另一组节点矩阵独立求解。全图为无量纲代数模型，无动态稳定性结论。不得改图或另造数字。

共同图：r→x:2，x→y:3，y→x:-0.1，r→y:1，y→z:1，r→q:4，q→q:0.2，q→z:0.5。方程x=2r-0.1y，y=3x+r，q=4r+0.2q，z=y+0.5q。r=1时x=19/13，y=70/13，q=5，z=205/26。

三条前向通路：P1为r-x-y-z，增益6；P2为r-y-z，增益1；P3为r-q-z，增益2。增益和9仅用于比较，不是单条P_k或闭图总增益。

两个基本回路：L1是x-y-x，节点{x,y}，增益-3/10；L2是q自环，节点{q}，增益1/5。两者无公共节点，不接触；乘积-3/50。自环也是合法基本回路。

1. 前向通路总增益：说明每条P_k的连乘，给6、1、2；不要将所有前向路径总和9当作该节点的定义。完整传输还需考虑回路和余子式。
2. 信号流图特征式：Delta=1-(L1+L2)+L1L2=26/25=1.04。两回路乘积项前虽然是加号，乘积本身为负，不能误改成正.06。只有互不接触组合进入乘积项。
3. 第k条前向通路特征余子式：P1/P2接触L1而不接触L2，所以Delta1=Delta2=1-L2=4/5；P3接触L2不接触L1，所以Delta3=1-L1=13/10。余子式按“不接触该通路的回路”重新构造，不是删掉一条支路后随意求图。
4. 梅森增益公式：分子sum(P_k Delta_k)=6*.8+1*.8+2*1.3=41/5=8.2，分母26/25，z/r=205/26。独立节点消元验证z=y+.5q=70/13+5/2。错误的未加权路径和9除Delta为225/26，不能代替正确结果。
5. 不接触回路：强调无共同节点；仅无共同支路不够。用{x,y}与{q}说明图中两个回路不接触，输出汇点z不属于这两个回路，所有输入输出路径共用某些点也不影响回路自身节点集合的判断。
6. 梅森公式通路余子式：重点审核乘积项。针对P1，需同时去掉-L1与+L1L2，剩1-L2；只从完整Delta删去单回路项会留下不该保留的混合项。针对P3也同理。与第3卡区分：第3卡讲构造，第6卡讲展开式中识别、去除所有含接触回路的项。
