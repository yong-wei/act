# 运动稳定性

**一句话定义**：系统方程在不受任何外界输入作用下，其解在时间t趋于无穷时的渐近行为，即系统齐次微分方程的解，称为系统方程的一个运动，因而谓之运动稳定性。

**核心直觉**：在图谱邻接中可把握：前置 → 平衡状态稳定性 · 后续 → 稳定性。

**关联**：前置 → 平衡状态稳定性 · 后续 → 稳定性
