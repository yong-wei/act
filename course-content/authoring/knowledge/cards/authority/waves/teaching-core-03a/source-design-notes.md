# 平衡点与局部线性化六卡固定模型

scope 和 source-inventory 已捕获当前 v0.48 六个节点。原方程验算见 verify-models.py/model-verification.json。所有变量与时间采用无量纲教学例，x允许正负；不是液位或实测参数。不得更换模型、输入、参数或另造数字。

1. 线性化：用 x_dot=u-x²，在平衡点 x0=2,u0=4 附近，精确增量方程 delta_x_dot=delta_u-4delta_x-delta_x²，一阶近似删去二次项。强调这是局部近似、增量模型，原系统未变成全局线性；小输入须结合状态偏离和时段检查。
2. 切线局部线性化法：静态 g=x²，在 x0=2 时 g0=4、斜率4。绝对量近似 g≈4+4(x-2)，增量近似 delta_g≈4delta_x。delta_x=.1 时真值4.41，近似4.4，绝对余项.01；delta_x=.5 时真值6.25，近似6，余项.25。勿漏绝对量截距，不把连续性直接当成可微性；尖点处不能直接用唯一切线。
3. 平衡点泰勒级数线性化：同一动态系统的 A=-4,B=1，零增量初态传函1/(s+4)。说明先满足 f(x0,u0)=0，再定义偏差和求雅可比；平衡常项为零的原因。不得把非零工作点当作原点后省略输入偏置。
4. 工作点泰勒级数近似：先用静态切线公式保留g0，重点比较非平衡点展开。固定 x0=1,u0=4 时 f0=3，故 delta_x_dot≈3-2delta_x+delta_u，常项不能删除。工作点一词不自动意味着平衡点；若围绕名义轨迹展开，应使用轨迹与时变系数，勿声称本例是平衡增量模型。
5. 微变小信号线性化法：同一稳定平衡点，delta_u=.4阶跃、delta_x(0)=0，线性响应 .1(1-exp(-4t))，线性终值增量.1；原非线性终值sqrt4.4-2≈.0976177。在delta_x=.1时，被忽略二次状态项与保留一次状态项的幅值比为.025；它是项的比值，不是全响应误差。原方程积分在0至2的网格最大绝对响应差约.00237145，仅为本例有限时段证据，不外推全局误差界。
6. 平衡点：固定u=4时x=±2均满足静止条件，但局部线性极点分别为+4和-4，对应不稳定和局部渐近稳定。再用 x_dot=-x³ 与 x_dot=x³ 的原点反例：两者雅可比都0，一阶模型都delta_x_dot=0，非线性稳定性却相反。对初态.1、t=10，解分别约.0912871、.1118034；结论依据解析解/相线，不是仅从一个采样点证明稳定性。正号系统解析解在有限时间会发散，示例时段在其存在区间内。
