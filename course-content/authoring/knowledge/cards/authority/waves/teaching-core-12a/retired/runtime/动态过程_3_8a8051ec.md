# 动态过程

**一句话定义**：系统在典型输入信号作用下，输出量从初始状态到最终状态的响应过程，又称过渡过程或瞬态过程。

## 详情

### 完整解释

系统在典型输入信号作用下，输出量从初始状态到最终状态的响应过程，又称过渡过程或瞬态过程。

### 典型示例

- 表现为衰减、发散或等幅振荡形式

### 关键词

过渡过程、瞬态、响应、稳定性
