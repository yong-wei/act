## 136 个节点与 2,967 条错误的含义

- 比较对象是当前本地 v0.48 engineering.json 的 Canonical ID 集合，与当前 B′ bindings.jsonl 的 canonicalId。
- 136 是不在当前对象集合中的唯一节点 ID 数；2,967 是引用这些 ID 的绑定行数；同一个节点被多个资源或多个课次引用会重复计数。
- 涉及 862 个不同资源。分类：step 2,077、textbook-section 207、lesson 135、textbook 128、audio 97、simulation 85、card 64、video 54、infographic 50、handout 47、exercise 23。
- 旧 cards-index 另有 58 条指向快照外节点；当前 core-nodes 与 prerequisites 的端点检查均为 0 个缺失。
- 当前投影的 manifest 声明 v0.48，但声明一致不能证明每条内部引用有效。本轮已证实引用集合不一致；未据此断言全部 136 个概念已被删除，也未在缺少 successor/crosswalk 证据时按中文名重绑定。
- 本批加入前后完整 B′ 重建错误都是 2,967 条。本批 12 个 Canonical ID 全部有效。本轮通过独立绑定发布接入，而不是把历史错误伪装成已修复。

具体逐节点计数见 projection-drift.json；后续应按“有明确后继映射 / 多对象需裁决 / 确实退役 / 需要恢复权威对象”分组处理。

## 路径不可达的三个层次

### 1. 资源是否存在且可打开

本轮已完成：12 张均进入完整本地绑定包，目录与抽屉真实解析通过。同节点 21 张旧卡已退役删除。目录原来只枚举旧 B′ 中的卡片，导致新增卡片缺席的问题已修复。

### 2. 是否在目标的知识范围内

现有规划器取“目标节点 + 已发布教学先修祖先”，再按精确 ID 选取资源绑定。不沿全部工程 association、has_formula、applies_to 等关系扩张。关联关系丰富，不自动等于教学先修成立。

当前九个预设目标的范围只覆盖首批 4 张不同卡片：传递函数、伯德图、相角裕度、超前补偿。其余 8 张是有效且可推荐的资源，但当前预设范围未包含它们。

已核实 3 个目标含 4 个失效目标 ID：

| 预设目标 | 失效目标 |
|---|---|
| 频率响应基础 | 频率响应 |
| 时域响应分析 | 超调量、稳态误差 |
| 根轨迹分析基础 | 根轨迹 |

例如目标仍指向旧“稳态误差”ID，而新卡绑定当前“稳态误差”ID；标题相同不会触发匹配。“根轨迹法”与旧目标“根轨迹”也不能仅凭名称认为等价。完整 ID 见 runtime-verification.json。

### 3. 在范围内是否最终被选中

可达仅表示进入候选范围。最终选择还受学习状态、时间预算、资源偏好与约束影响；不保证每条路径安排全部卡片。
