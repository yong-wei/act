# 自激振荡

**一句话定义**：非线性系统在没有外界周期信号作用时，内部产生的具有固定振幅和频率的稳定周期运动。

**关键公式**：

$$
\ddot{x} - \mu(1 - x^2)\dot{x} + x = 0
$$

## 详情

### 完整解释

非线性系统在没有外界周期信号作用时，内部产生的具有固定振幅和频率的稳定周期运动。

### 典型示例

- 范德波尔方程描述的系统能产生幅值为1的等幅自激振荡。

### 关键词

稳定周期运动、范德波尔方程、固定振幅
