# 对数幅频渐近特性曲线

**一句话定义**：在控制工程中，为简化惯性环节、一阶微分环节、振荡环节和二阶微分环节的对数幅频曲线的作图，常用低频和高频渐近线近似表示对数幅频曲线，称之为对数幅频渐近特性曲线。

**核心直觉**：在图谱邻接中可把握：前置 → 交接频率、低频段 · 后续 → 截止频率。
