# 平衡状态稳定性

**一句话定义**：系统在平衡工作点处，当输入信号为零时输出信号亦为零，在扰动作用下偏离平衡点后，系统输出量增量随时间变化趋于原平衡点的性质。

**核心直觉**：对于线性系统，运动稳定性与平衡状态稳定性等价。

**关联**：后续 → 稳定性、运动稳定性
