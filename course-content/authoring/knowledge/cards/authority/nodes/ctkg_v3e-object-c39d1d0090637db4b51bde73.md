# 绘制概略开环幅相特性曲线方法

**一句话定义**：根据系统开环频率特性的表达式，通过取点、计算和作图等方法绘制系统开环幅相特性曲线。

**核心直觉**：概略开环幅相特性曲线应反映开环频率特性的三个重要因素：起点和终点、与实轴的交点、变化范围。

**关联**：后续 → 频率特性
