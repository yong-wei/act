# 部分分式法

**一句话定义**：先求出已知连续时间函数e(t)的拉氏变换E(s)，然后将有理分式函数E(s)展成部分分式之和的形式，使每一部分分式对应简单的时间函数，因其相应的z变换是已知的，于是可方便地求出E(s)对应的z变换E(z)。
