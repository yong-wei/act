## 详情

### 完整解释

A root-locus problem with respect to the parameter ρ, which weighs the relative cost of tracking error z^2 with respect to the control effort u^2 in the performance index. For any root s0, there will also be a root at -s0, resulting in symmetry with respect to the imaginary axis.
