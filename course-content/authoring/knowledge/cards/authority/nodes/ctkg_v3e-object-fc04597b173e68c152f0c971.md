# 可观测性

**一句话定义**：如果系统所有状态变量的任意形式的运动均可由输出完全反映，则称系统是状态完全可观测的，简称为系统可观测；反之，则称系统是不完全可观测的，或简称为系统不可观测。

**核心直觉**：反之，则称系统是不完全可观测的，或简称为系统不可观测。

**关联**：前置 → 系统完全可观测、系统不可观测
