# Bryson's Rule

## 详情

### 完整解释

A method to start the LQR design iteration by initially choosing diagonal matrices Q and R such that Q_ii = 1 / maximum acceptable value of [x_i^2] and R_ii = 1 / maximum acceptable value of [u_i^2].
