# 矩阵指数函数

**一句话定义**：由幂级数 \sum_{k=0}^{\infty} \frac{1}{k。

**核心直觉**：在图谱邻接中可把握：前置 → 状态转移矩阵。

**关联**：前置 → 状态转移矩阵

## 详情

### 完整解释

由幂级数 \sum_{k=0}^{\infty} \frac{1}{k!} A^k t^k 定义的矩阵函数，记为 e^{A t}
