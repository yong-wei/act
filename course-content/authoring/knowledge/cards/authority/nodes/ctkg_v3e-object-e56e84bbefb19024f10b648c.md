# 小范围稳定系统

**一句话定义**：系统受到有界扰动作用后，只有当扰动引起的初始偏差小于某一范围时，系统才能在取消扰动后恢复到初始平衡状态，否则就不能恢复到初始平衡状态。

**核心直觉**：在图谱邻接中可把握：后续 → Stable System、稳定性。

**关联**：后续 → Stable System、稳定性
