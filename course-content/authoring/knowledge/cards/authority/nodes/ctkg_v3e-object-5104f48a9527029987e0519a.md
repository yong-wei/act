# 前馈校正

**一句话定义**：前馈校正又称顺馈校正，是在系统主反馈回路之外采用的校正方式。

**核心直觉**：前馈校正装置接在系统给定值（或指令、参考输入信号）之后及主反馈作用点之前的前向通道上。

**关联**：前置 → 前置滤波器 · 后续 → 校正装置、前置滤波器
