# 频率特性

**一句话定义**：谐波输入下，输出响应中与输入同频率的谐波分量与谐波输入的幅值之比A(ω)为幅频特性，相位之差φ(ω)为相频特性，并称其指数表达形式G(jω)=A(ω)e^{jφ(ω)}为系统的频率特性。

**核心直觉**：在图谱邻接中可把握：前置 → 绘制概略开环幅相特性曲线方法、频率特性实验确定方法 · 后续 → 相频特性、幅频特性。
