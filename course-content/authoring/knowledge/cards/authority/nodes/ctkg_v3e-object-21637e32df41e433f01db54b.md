# 等倾线法

**一句话定义**：等倾线法是求取相轨迹的一种作图方法，不需求解微分方程。

**核心直觉**：先确定相轨迹的等倾线，进而绘出相轨迹的切线方向场，然后从初始条件出发，沿方向场逐步绘制相轨迹。
