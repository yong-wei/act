# 极限环

**一句话定义**：非线性系统中出现的一条孤立的封闭曲线，曲线附近的相轨迹都渐近地趋向这条封闭的曲线，或者从这条封闭的曲线离开。

**核心直觉**：极限环把相平面划分为内部平面和外部平面两部分，是相平面上的分隔线。

**关联**：前置 → 半稳定极限环、稳定极限环、不稳定极限环 · 后续 → 分隔线、奇线、相平面
