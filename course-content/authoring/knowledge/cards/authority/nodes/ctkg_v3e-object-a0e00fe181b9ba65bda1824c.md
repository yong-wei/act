# 相平面法

**一句话定义**：相平面法是推广应用时域分析法的一种图解分析方法。

**核心直觉**：该方法通过在相平面上绘制相轨迹曲线，确定非线性微分方程在不同初始条件下解的运动形式。

**关联**：前置 → MATLAB绘制相轨迹 · 后续 → 相平面、非线性系统、相轨迹

## 详情

### 完整解释

相平面法是推广应用时域分析法的一种图解分析方法。该方法通过在相平面上绘制相轨迹曲线，确定非线性微分方程在不同初始条件下解的运动形式。相平面法仅适用于一阶和二阶系统。
