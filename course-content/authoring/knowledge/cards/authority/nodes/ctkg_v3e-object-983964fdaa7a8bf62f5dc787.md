# 幅相频率特性曲线绘制方法

**一句话定义**：以横轴为实轴、纵轴为虚轴构成复数平面，对于任一给定频率ω，频率特性值为复数，实部为实轴坐标值，虚部为虚轴坐标值，或表示为复平面上的向量，向量长度为幅值，向量与实轴正方向的夹角等于相位。

**核心直觉**：一般只绘制ω从零变化至+∞的幅相曲线，用小箭头表示ω增大时的变化方向。

**关联**：前置 → 幅相频率特性曲线
