# 采样器

**一句话定义**：采样器是离散系统中的一种元件，它对连续信号进行采样，将连续时间信号转换为离散时间信号。

**核心直觉**：采样器不影响开环脉冲传递函数的极点，但影响零点，从而影响闭环离散系统的动态性能。

### 完整解释

采样器是离散系统中的一种元件，它对连续信号进行采样，将连续时间信号转换为离散时间信号。采样器不影响开环脉冲传递函数的极点，但影响零点，从而影响闭环离散系统的动态性能。
