# Controllability matrix

**一句话定义**：Controllability matrix：A matrix used to determine whether a system is completely controllable

**核心直觉**：在图谱邻接中可把握：前置 → Ackermann's form · 后续 → Controllability。

## 详情

### 完整解释

A matrix used to determine whether a system is completely controllable; for a single-input, single-output system, full rank implies invertibility.
