## 首页

**一句话定义**：按阻尼比取值划分的四类典型二阶响应：无阻尼、欠阻尼、临界阻尼和过阻尼。

**核心直觉**：同样是二阶系统，只要阻尼比不同，曲线就会从“持续振荡”连续过渡到“振荡衰减”、再到“单调收敛”。

```
ζ = 0      → 等幅振荡（无阻尼）
0 < ζ < 1  → 振荡衰减（欠阻尼）
ζ = 1      → 无振荡且通常最快（临界阻尼）
ζ > 1      → 无振荡但更慢（过阻尼）
```

**关联速查**：阻尼比 · 二阶系统标准型 · 闭环极点

## 详情

### 完整解释

1-3 关心的是标准二阶系统在不同阻尼比下的典型时域表现：

| 阻尼比范围 | 响应名称 | 主要特征 |
|-----------|---------|---------|
| $\zeta=0$ | 无阻尼 | 等幅振荡，不收敛到稳态 |
| $0<\zeta<1$ | 欠阻尼 | 振荡衰减，是最常见工程情形 |
| $\zeta=1$ | 临界阻尼 | 不振荡，通常是不振荡前提下最快 |
| $\zeta>1$ | 过阻尼 | 单调收敛，但通常比临界阻尼更慢 |

这四类不是彼此割裂的，而是随着 $\zeta$ 连续变化而连续过渡的四种典型区段。

### 常见误区

1. **误区**：$\zeta=0$ 属于临界阻尼。  
   **纠正**：$\zeta=0$ 是无阻尼，表现为持续振荡；临界阻尼对应的是 $\zeta=1$。

2. **误区**：四种响应家族里必须包含“右半平面发散”。  
   **纠正**：1-3 这里讨论的是标准二阶系统按阻尼比分出的四类典型响应；右半平面不稳定是另一类稳定性问题，不属于本卡片的四分法。
