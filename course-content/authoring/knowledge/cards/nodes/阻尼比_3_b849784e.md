## 首页

**一句话定义**：描述二阶系统振荡衰减程度的无量纲参数，ζ = 实际阻尼 / 临界阻尼。

**核心直觉**：ζ 是系统的"稳重程度"。ζ = 0.7 是工程黄金点——轻微超调但快速稳定。

```
响应幅值
      ↑  ζ=0.1（几乎不稳定）
   1.5┤ ╭──╮
   1.2┤ │  ╰╮  ζ=0.3
   1.0┤─┤───╰─────  ζ=0.7（黄金点）
   0.8┤ │      ╰──  ζ=1.0（临界）
      └─────────────→ 时间
```

**关联速查**：二阶系统标准型 · 超调量 · 调节时间

---

## 详情

### 完整解释

ζ 是二阶系统最重要的设计参数，决定系统的响应"形态"（形状），而 ωₙ 决定响应的"速度"（时间尺度）。

ζ 的四个关键分界：
- ζ = 0：纯振荡，永不停止（理想弹簧，纯虚数极点）
- 0 < ζ < 1：欠阻尼，振荡衰减（最常见的工程选择）
- ζ = 1：临界阻尼，无超调但响应最慢
- ζ > 1：过阻尼，单调上升，无超调但非常慢

### 公式路径

**几何关系**（ζ 即极点角度的余弦）：
$$\zeta = \cos\beta \quad \text{（β为极点向量与负实轴夹角）}$$

**超调量关系（精确公式）：**
$$M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} \times 100\%$$

> 完整推导（含极坐标表示）→ **单元 1-3**

**工程记忆捷径**：ζ = 0.7 → Mₚ ≈ 5%，ζ = 0.5 → Mₚ ≈ 16%

### 船舶工程实例

| ζ 值 | 极点位置 | 船舶响应特征 | 工程适用场景 |
|------|---------|------------|------------|
| 0.1~0.3 | 近虚轴 | 剧烈振荡，高超调 | 不适用实船 |
| 0.5~0.7 | 左半平面中段 | 轻微超调，快速稳定 | 标准海况操纵 |
| 0.7~0.9 | 左半平面中段 | 极少超调，较快 | 精密操纵 |
| 1.0 | 负实轴重合点 | 无超调，较慢 | 客船（舒适优先）|

### 常见误区

1. **误区**：ζ 越大越好（"越稳重越好"）。
   **纠正**：ζ 越大意味着响应越慢（tᵣ 增大，tₛ 先减后增），存在 ζ ≈ 0.7 的工程平衡点，不是越大越好。

2. **误区**：ζ = 1 是最理想的（"恰好不超调"）。
   **纠正**：临界阻尼虽无超调，但调节时间比 ζ ≈ 0.7 时更长；实际工程中 ζ ≈ 0.5~0.7 综合性能更优。
