# 频率响应直觉 | Frequency Response Intuition

**一句话定义**：系统对不同频率正弦输入的"放大与延迟"规律，可用 Bode 图可视化。

**直觉**：
- 低频（慢信号）→ 忠实跟踪（约 0 dB）
- 高频（快信号）→ 逐渐衰减（负 dB）
- 中间有个"门槛"：截止频率 $\omega_c$

**关联**：前置 → 传递函数、极点 · 后续 → 截止频率直觉 · 精化 → 频域分析（2-4）

---

## 详情

### 完整解释

把系统想象成一个"频率过滤器"：

```
输入信号频率 ω:

低频 ω << ωc  → 幅值 ≈ 1（0dB），输出 ≈ 输入  ✓ 跟踪
中频 ω ≈ ωc   → 幅值开始下降                    ⚠ 过渡
高频 ω >> ωc  → 幅值 << 1（负dB），输出被压制   ✗ 过滤
```

Bode 图就是把这条"幅值 vs 频率"曲线画出来，用对数刻度展示。

### 工程实例（船舶航向控制）

船舶航向控制系统 $\omega_c \approx 0.02$~$0.1$ rad/s：
- 能跟踪周期 $T = 2\pi/\omega_c \approx 60$~$300$ s 的指令变化（航向缓慢调整）
- 海浪周期约 8~15 s（$\omega \approx 0.4$~$0.8$ rad/s）远高于 $\omega_c$，自然被过滤
- 这正是工程设计的合理权衡：控制系统不必响应每一个海浪

### 常见误区

1. **误区**：Bode 图和时域响应曲线是同一回事。**纠正**：时域响应是输出随时间的变化；Bode 图是幅值/相位随频率的变化——横轴一个是时间，一个是频率，描述的是不同维度。
2. **误区**：频率响应只对正弦输入有效，阶跃输入不适用。**纠正**：任何信号都可以分解为正弦分量的叠加（傅里叶），频率响应描述的是系统对每个分量的处理方式，因此对任意输入都有意义。
