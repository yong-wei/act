## 首页

**一句话定义**：描述控制系统阶跃响应过渡过程质量的量化指标集合（tᵣ、Mₚ、tₛ）。

**核心直觉**：三个指标从三个维度评价同一条曲线——**快**（tᵣ起步速度）× **冲**（Mₚ超调程度）× **稳**（tₛ收敛时间）。三者无法同时最优，设计就是找平衡。

```
  "冲"Mₚ ─ 冲过头多少？
  "快"tᵣ ─ 起步有多灵敏？
  "稳"tₛ ─ 何时真正结束？
  → 三维权衡，没有全优解
```

**关联速查**：超调量 · 上升时间 · 调节时间

---

## 详情

### 完整解释

动态性能指标从阶跃响应曲线上直接读取，反映系统过渡过程质量：

```
响应曲线的三个维度：
┌──────────────────────────────────────┐
│          ╭── 峰值（Mₚ描述"冲"）       │
│        ╭─╯                            │
│       ╱   ╲                           │
│      ╱     ╲────────────────          │
│     ╱  ↑tᵣ↑  ← 过渡过程  → ↑tₛ↑    │
│    ╱         （"快"）    （"稳"）     │
└──────────────────────────────────────┘
```

### 三指标速查表

| 指标 | 描述 | 通俗语 | 主要受控于 |
|------|------|-------|-----------|
| tᵣ（上升时间） | 10%→90% 时间 | 快不快起步 | ωₙ（主）、ζ（次）|
| Mₚ（超调量） | 峰值超出百分比 | 稳不稳落地 | ζ（唯一决定）|
| tₛ（调节时间） | 进入 ±2% 带 | 何时真正结束 | ζωₙ 共同决定 |

**根本矛盾**：tᵣ 小 → 系统起步快 → 容易冲过 → Mₚ 大。快速与平稳是工程设计的核心权衡。

### 船舶工程实例

某船实测：指令 10° 转向
- tᵣ ≈ 25s（从 0° 到 9° 用时 25 秒）
- Mₚ ≈ 20%（峰值 12°，超调 2°）
- tₛ ≈ 90s（90 秒后进入 ±0.2° 误差带）

| 应用场景 | 主要约束 | 典型权衡结果 |
|---------|---------|------------|
| 紧急避碰 | tᵣ 最小 | 接受较大 Mₚ |
| 客船常规 | Mₚ < 5% | 接受较慢 tᵣ |
| 港口靠泊 | tₛ 最短 | ζ ≈ 0.7，综合最优 |

### 常见误区

1. **误区**：三个指标可以同时最优。
   **纠正**：tᵣ 小 ↔ Mₚ 大是根本矛盾，控制设计本质是在约束条件下寻找三者的工程平衡点。

2. **误区**：稳态误差也是动态性能指标。
   **纠正**：稳态误差属于**稳态性能指标**，与描述过渡过程的动态性能指标分属不同类别，评价阶段不同。
