## 首页

# 幅值裕度直觉 | Gain Margin Intuition

**一句话定义**：系统相位恰好到达 -180° 时（穿越频率 $\omega_g$ 处），此时幅值距 0 dB 的差值 $K_g$。

**直觉**：相位已经"反了"，但幅值还不够大——差多少 dB，就是还能放大多少倍才失稳。

**工程建议**：$K_g \geq 6$ dB（意味着增益加倍系统仍稳定）

**关联**：相关 → 相位裕度直觉 · 精化 → 幅值裕度（2-4）

---

## 详情

### 完整解释

第一轮速通讲过：幅值裕度是"系统实际反向时，幅值离 0 dB 的距离"。精确定位：

- **在哪里量？** 穿越频率 $\omega_g$ 处（相频曲线恰好穿越 -180° 的那个频率）
- **量什么？** 该处幅值（单位 dB）与 0 dB 的差距

```
幅频（dB）:
  0dB ─────────────────────────────  ← 若幅值达到这里 → 失稳
-10dB ────────────────── Kg=10dB ──← ωg 处幅值为 -10dB
      低频              ωg       高频  →  ω
```

**与相位裕度的关系**：
- 相位裕度：在 $\omega_c$ 处量相位还差多少到 -180°
- 幅值裕度：在 $\omega_g$ 处量幅值还差多少到 0 dB
- 两者从不同角度描述系统离失稳的余量

### 工程实例（船舶航向控制）

设计要求 $K_g \geq 6$ dB：即使控制器增益因老化或参数漂移而翻倍，系统仍能保持稳定。

### 常见误区

1. **误区**：截止频率 $\omega_c$ 和穿越频率 $\omega_g$ 是同一个频率。**纠正**：$\omega_c$ 是幅频穿越 0 dB 处；$\omega_g$ 是相频穿越 -180° 处——两者一般不相等，是完全不同的特征频率。
2. **误区**：只要相位裕度够大，幅值裕度就不重要了。**纠正**：对于高阶系统，可能相位裕度充足但幅值裕度偏小；两个裕度都需要检查，不可互相替代。
