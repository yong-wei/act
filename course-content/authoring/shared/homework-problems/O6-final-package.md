# 自动控制原理 作业6：约束、迁移与高保真验证下的方案修正

## 题号与题型

- 题号：O6
- 题型：开放题 [O]
- 分值：40分
- 标题：约束、迁移与高保真验证下的方案修正

## 题干

请沿用你在 `O5` 中已经提交的初始控制方案，不得更换控制对象，也不得把模块5中的非线性、数据驱动或强化学习方法作为本题解决方案。现在同一对象进入新工况，出现新的硬约束、扰动/噪声边界或结构编码入口。请在经典控制主线内部完成一次方案修正与交付判断。

提交内容包括：

1. 回收 `O5` 的对象、控制结构和首轮验证结论，说明原方案在新工况下最可能暴露的风险。
2. 给出新工况或第二场景的硬约束，至少包含 `1` 项不可放宽约束和 `1` 项软目标。
3. 给出一张迁移前后比较表，覆盖原工况、新工况、关键指标、约束是否满足和修正方向。
4. 说明结构编码入口或固定结构修正入口，例如保留原结构、补充限幅/抗饱和、加入滤波或前馈，但不得引入模块5方法替代。
5. 附 `MATLAB/Octave` 仿真代码、结果图和复现实验说明，验证迁移前后或高保真/扰动/噪声边界。
6. 写出一段高保真、扰动或噪声验证边界说明：哪些证据足以支持交付，哪些证据只能说明“保留候选”。
7. 附 `AI 使用记录摘要`，说明 AI 参与了哪些整理、代码检查或文字润色工作，以及你如何核查关键判断。

提交约束：

- 主体正文不超过 `900` 字。
- 必须附 `1` 张迁移前后比较表。
- 必须附 `1` 段高保真或扰动/噪声边界说明。
- 必须附 `MATLAB/Octave` 仿真代码、结果图与简短复现实验说明。
- 允许原方案在新工况下不满足全部指标，但必须说明修正入口和再次验证条件。
- 不得使用罚函数或 `fmincon` 作为作答主体，不得把模块5方法作为本题解决方案。

## 参考答案

以下示例沿用 `O5` 中“小型直流电机转速控制”的首轮 `PI` 方案。学生可使用自己的连续对象，但必须保持 `O5-O6` 的对象和证据连续。

`O5` 中采用

$$
C_0(s)=1.2+\frac{0.8}{s},\qquad G_0(s)=\frac{1}{0.35s+1}.
$$

首轮验证显示稳态误差明显下降，但超调和控制量峰值开始上升。现在迁移到负载惯量增大、扰动加重且执行器限幅更严格的工况。新硬约束为：$M_p\le12\%$、$t_s\le3.0\,\mathrm{s}$、$|u|_{\max}\le3.5$；软目标为尽量缩短恢复时间并减少控制能量。（8分）

| 项目 | O5 原工况 | O6 新工况验证 | 判断 | 修正方向 |
|---|---:|---:|---|---|
| 超调 $M_p$ | 约 `9%` | 约 `15%` | 硬约束失败 | 降低 $K_i$ 或加入抗饱和 |
| 调节时间 $t_s$ | 约 `2.2s` | 约 `3.4s` | 硬约束失败 | 降低积分累积并复核带宽 |
| 控制峰值 $|u|_{max}$ | 约 `3.1` | 约 `4.2` | 限幅失败 | 加限幅/抗饱和结构 |
| 稳态误差 | 明显下降 | 仍可接受 | 可保留 | 保留 PI 主结构 |

因此原 `PI` 结构不能直接交付，但不需要更换为模块5方法。修正入口为保持 `PI` 主结构，加入执行器限幅与抗饱和，并把参数方向改为降低 $K_i$、适度保留 $K_p$，例如试探

$$
C_1(s)=1.1+\frac{0.45}{s},
$$

并在限幅 $|u|\le3.5$ 下重新验证。（8分）

示例 `MATLAB/Octave` 代码如下：

```matlab
pkg load control
s = tf('s');
G0 = 1/(0.35*s + 1);
Gm = 1/(0.75*s + 1);      % 新工况：等效惯量增大
C0 = 1.2 + 0.8/s;          % O5 首轮 PI
C1 = 1.1 + 0.45/s;         % O6 修正入口
T0 = feedback(C0*G0, 1);
Tm0 = feedback(C0*Gm, 1);
Tm1 = feedback(C1*Gm, 1);
t = 0:0.01:10;
figure;
step(T0, Tm0, Tm1, t);
grid on;
legend('O5 original', 'O6 migrated baseline', 'O6 revised candidate');
title('O6 migration validation');
print('-dpng', 'O6-validation.png');
```

结果图应显示三条阶跃响应：原工况、迁移后未修正方案、迁移后修正候选。若修正候选仍未满足全部硬约束，只能保留为候选；若在扰动/噪声和限幅条件下同时满足 $M_p$、$t_s$ 与 $|u|_{max}$，才可写为可交付。（8分）

高保真或扰动/噪声边界说明：本题不能只用简化模型的阶跃曲线作交付依据。交付证据至少应包含迁移后对象、负载扰动、执行器限幅和噪声条件下的同一组指标。若只有简化模型达标，而扰动或限幅下超调、调节时间、控制峰值任一硬约束失败，则结论应为“需修正”或“保留候选”。（8分）

AI 使用记录摘要示例：AI 参与了迁移前后比较表整理、Octave 代码语法检查和文字压缩；关键模型、参数、仿真运行、图像生成和交付判断由学生自行核查，特别核查了硬约束是否在迁移后仍成立。（8分）
