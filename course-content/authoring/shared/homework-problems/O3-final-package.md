# O3 结构机理诊断

## 1. 题号 / 题型 / 难度

- 题号：`O3`
- 题型：`O`
- 难度：`⭐⭐`
- 分值：`40分`

## 2. 最终题面

请沿用你在 O2 中已经固定的同一对象、简化模型与最小三域表征，不得更换对象。围绕该对象当前的基线方案，完成一次“结构机理诊断”。

请完成以下内容：

1. 先在“稳定问题 / 动态问题 / 稳态问题”中判断当前最主要的问题属于哪一类，并用 O2 中已有模型、响应或仿真结果给出 1-2 条直接证据。
2. 明确说明它属于哪条机理线。不能只说“响应不好”，必须说清你为什么把它判为稳定机理线、动态机理线或稳态机理线。
3. 只使用本阶段允许的语言，对主要问题给出结构机理解释。允许使用：稳定边界、极点位置、主导极点、增益变化与极点迁移、根轨迹趋势、时域响应现象。若你选择“稳态问题”，只能用 O2 中可直接观察的终值偏差或低频现象作证据，不得调用型别、积分、静态误差系数等后续语言。
4. 给出 1 张必要图表或对照表，并用 2-3 句说明该图表支持了哪条诊断。图表可采用“极点-响应对照”“增益-极点迁移对照”“模型参数-现象对照”等形式。
5. 若诊断涉及动态或稳定判断，必须附 MATLAB/Octave 仿真代码、结果图与最小复现实验说明。
6. 最后用“主要矛盾清单”收束：写出当前主要矛盾、一个次要矛盾，以及为什么本次不进入控制结构最终定夺。
7. 附 AI 使用记录摘要，写明你如何使用 AI、如何核查和修改 AI 输出。

提交约束：

- 主体正文不超过 `700` 字。
- 允许附 `1-3` 张图、表或示意图。
- 本题只做机理诊断，不做控制结构最终定夺，不允许写成完整设计报告。
- 不得调用零点、型别、积分稳态改善、Nyquist 判据、Bode 判稳或完整控制器选型语言。

## 3. 标准答案

可接受答案必须形成“延续 O2 -> 问题归类 -> 证据 -> 机理线 -> 结构解释 -> 主要矛盾清单”的闭环。答题开头必须先说明：本次沿用 O2 的同一对象、同一简化模型和同一最小三域表征，不更换对象。（4分）以下三类诊断路线任选其一，但必须与你的 O2 证据一致。

**路线 A：稳定机理线。** 先明确写出“当前最主要的问题属于稳定机理线”，并给出直接证据，例如：参数稍变或增益稍增时，闭环极点已逼近虚轴，或稳定窗口很窄，说明当前首要矛盾不是“响应还不够快”，而是“离失稳边界过近”。（8分）随后说明：之所以把它归为稳定机理线，是因为关键矛盾首先表现为稳定边界被压缩，而不是一般性的响应不理想；如果不先守住这一条，后续讨论动态优劣就失去前提。（8分）再进一步解释：从结构机理上看，增益变化会推动主导极点沿根轨迹向虚轴迁移，稳定裕量被压缩，因此主要问题应诊断为稳定问题，而不是直接进入后续结构定夺。（10分）图表与仿真应能支撑“边界逼近”这一判断，例如给出极点位置表、增益变化下的响应对照，或稳定边界附近的对比图，并附最小复现实验说明。（6分）

**路线 B：动态机理线。** 先明确写出“当前最主要的问题属于动态机理线”，并给出直接证据，例如：系统能够收敛，但超调偏大、振荡明显、调节时间过长，且主导极点相对虚轴位置表明阻尼不足。（8分）随后说明：之所以把它归为动态机理线，是因为核心矛盾不是是否还能稳定，而是极点位置对应的动态品质失衡；不能只写“响应不好”，必须指出问题落在超调、振荡和衰减快慢这些动态后果上。（8分）再进一步解释：若增益变化使极点更靠近虚轴或虚部增大，就会表现为振荡增强、超调增大、衰减变慢，因此当前主要问题应归到动态机理线。（10分）图表与仿真应能把“极点位置变化”与“响应品质变化”对上，例如极点-超调对照、极点-调节时间对照或两组阶跃响应图，并附最小复现实验说明。（6分）

**路线 C：稳态机理线。** 若你选择稳态问题，必须先明确写出“当前最主要的问题属于稳态机理线”，并给出直接证据，例如：系统虽稳定且动态尚可，但终值偏差或跟踪偏差仍明显存在。（8分）随后说明：之所以把它归为稳态机理线，是因为主要矛盾首先体现为误差现象持续存在，而不是边界逼近或振荡恶化；这里不能提前调用型别、积分或静态误差系数语言。（8分）再进一步解释：在当前阶段只能用 O2 可直接观察到的误差现象、低频表现或响应终值作机理诊断，因此你的论证重点应放在“误差现象持续存在、主要矛盾尚未被当前基线模型解决”这一点。（10分）图表可用响应终值对照、输入输出偏差对照或扰动前后误差对照；若附仿真，也应只服务于这一诊断。（6分）

无论采用哪一条路线，最后都必须收束为“主要矛盾清单”：明确当前主要矛盾、一个次要矛盾，以及为什么本次只做到机理诊断而不进入控制结构最终定夺，并附 AI 使用记录摘要，说明 AI 在检索、整理、绘图或润色中的作用，以及你如何自行核查关键结论、代码和图表。（4分）

## 4. 分步评分标准

1. `4分`：明确沿用 O2 的同一对象、模型和三域表征，不另起炉灶。
2. `8分`：在稳定 / 动态 / 稳态三类中明确选出当前主要问题，并给出 1-2 条直接证据。
3. `8分`：说明为何该问题属于对应机理线，而不是泛泛而谈“响应不好”。
4. `10分`：结构机理解释只使用当前阶段允许的语言，不越界调用零点、型别、积分稳态改善、Nyquist 或 Bode 判稳语言。
5. `6分`：图表或对照表直接服务于诊断；若涉及稳定 / 动态判断，补齐 MATLAB/Octave 仿真代码、结果图与最小复现实验说明。
6. `4分`：写出主要矛盾、次要矛盾及本次不进入结构定夺的理由，并附 AI 使用记录摘要。
