## 2. 最终题面

**题目**: 某二阶系统的闭环主导极点为 $s_{1,2} = -3 \pm 4j$。假设系统可用标准二阶模型近似描述。

**符号定义**:
- $\omega_n$: 无阻尼自然频率（rad/s）
- $\zeta$: 阻尼比（无量纲）
- $\omega_d$: 阻尼自然频率（rad/s）
- $\sigma\%$: 超调量（百分比）
- $t_p$: 峰值时间（s）
- $t_s$: 调节时间（s，按2%误差带计算）
- $\varphi_m$: 相位裕度（度）

**任务**:

① 计算该系统的无阻尼自然频率 $\omega_n$、阻尼比 $\zeta$ 和阻尼自然频率 $\omega_d$。

② 计算系统的超调量 $\sigma\%$、峰值时间 $t_p$ 和调节时间 $t_s$（按2%误差带）。

③ 用近似公式 $\varphi_m \approx 100\zeta$（单位：度，适用于 $0 < \zeta < 0.7$）估算系统的相位裕度 $\varphi_m$。

④ 若将闭环极点向左移动（即增大实部绝对值，变为 $s_{1,2}^{'} = -6 \pm 4j$），定性分析以下指标的变化趋势（变大/变小/基本不变）：$\omega_n$、$\zeta$、$\sigma\%$、$t_p$、$t_s$、$\varphi_m$。

---

## 3. 标准答案

### 任务①：计算 $\omega_n$、$\zeta$、$\omega_d$

**已知**: 主导极点 $s_{1,2} = -3 \pm 4j$，即 $-\zeta\omega_n = -3$，$\omega_d = 4$

**推导**:
- 由 $s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} = -\zeta\omega_n \pm j\omega_d$
- 得：$\omega_d = \omega_n\sqrt{1-\zeta^2} = 4$
- $\zeta\omega_n = 3$
- 联立：$\omega_n^2 = (\zeta\omega_n)^2 + \omega_d^2 = 9 + 16 = 25$

**答案**:
- $\omega_n = 5$ rad/s
- $\zeta = 0.6$
- $\omega_d = 4$ rad/s

---

### 任务②：计算 $\sigma\%$、$t_p$、$t_s$

**公式**:
- 超调量：$\sigma\% = e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}} \times 100\%$
- 峰值时间：$t_p = \frac{\pi}{\omega_d}$
- 调节时间（2%）：$t_s = \frac{4}{\zeta\omega_n}$

**计算**:
- $\sigma\% = e^{-\frac{\pi \times 0.6}{\sqrt{1-0.36}}} \times 100\% = e^{-\frac{1.885}{0.8}} \times 100\% = e^{-2.356} \times 100\% \approx 9.48\%$
- $t_p = \frac{\pi}{4} \approx 0.785$ s
- $t_s = \frac{4}{3} \approx 1.333$ s

**答案**:
- $\sigma\% \approx$ 9.5%（接受 9.4% ~ 9.6%）
- $t_p \approx$ 0.79 s（接受 0.785 s 或 $\pi/4$）
- $t_s \approx$ 1.33 s（接受 4/3 s 或 1.3~1.4 s）

---

### 任务③：估算相位裕度 $\varphi_m$

**公式**: $\varphi_m \approx 100\zeta$（度）

**计算**: $\varphi_m \approx 100 \times 0.6 = 60°$

**注**: 由于 $\zeta = 0.6 < 0.7$，该近似公式适用。

**答案**: 约 60°（接受 55°~65° 范围，若用更精确公式计算可接受相应结果）

---

### 任务④：极点左移定性分析

**新极点**: $s_{1,2}^{'} = -6 \pm 4j$

| 指标 | 变化趋势 | 分析理由 |
|------|----------|----------|
| $\omega_n$ | 变大 | 新 $\omega_n' = \sqrt{36+16} = \sqrt{52} \approx 7.21 > 5$ |
| $\zeta$ | 变大 | $\zeta' = \frac{6}{\sqrt{52}} \approx 0.832 > 0.6$ |
| $\sigma\%$ | 变小 | $\zeta$ 增大，阻尼增强，超调减小 |
| $t_p$ | 基本不变 | $t_p = \frac{\pi}{\omega_d}$，$\omega_d$ 不变（仍为4），故峰值时间不变 |
| $t_s$ | 变小 | $t_s = \frac{4}{\zeta\omega_n} = \frac{4}{6} \approx 0.67 < 1.33$，调节时间缩短 |
| $\varphi_m$ | 变大 | $\zeta$ 增大，相位裕度随之增大（稳定性增强） |

## 附录：关键易错点（供阅卷参考）

1. **混淆 $\omega_n$ 和 $\omega_d$**: 部分学生直接将 $\omega_n$ 当作4（虚部），实际上 $\omega_d = 4$，$\omega_n = 5$

2. **超调量公式记错**: 常见错误：$\sigma\% = e^{-\pi\zeta}$ 漏掉分母的 $\sqrt{1-\zeta^2}$

3. **调节时间公式混淆**: 2%误差带用 $t_s = \frac{4}{\zeta\omega_n}$，5%误差带用 $t_s = \frac{3}{\zeta\omega_n}$

4. **④问中 $t_p$ 判断错误**: 极点左移时实部变化，但虚部（$\omega_d$）不变，故 $t_p = \pi/\omega_d$ 不变

5. **相位裕度近似公式适用范围不清**: $\varphi_m \approx 100\zeta$ 仅适用于 $0 < \zeta < 0.7$
