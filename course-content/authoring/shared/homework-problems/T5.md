## T5-1 由任务约束反推首轮参数起点（20分）

某单位过程模型为 $G(s)=1/[s(s+2)]$，单位反馈下需选择一条首轮超前校正起点参数，使系统同时满足：$M_p\le10\%$、$T_s\le2\,\mathrm{s}$（按 `2%` 判据）、闭环目标相位裕度 $\phi_m\ge50^\circ$。作业要求仅给出“首轮参数起点”，不得完成最终优化。为避免起点选择歧义，本题固定首轮交叉频率取 $\omega_c=5\,\mathrm{rad/s}$。

请按以下步骤计算并给出起点：

1. 先由时域约束反推 $\zeta$ 与 $\omega_n$ 下限。
2. 在 $\omega_c=5\,\mathrm{rad/s}$ 下计算该模型的幅值与相位。
3. 根据目标相位裕度确定需补偿的额外相位。
4. 由超前校正第一型参数形式 $C(s)=K_c\frac{1+sT}{1+\alpha sT},\,0<\alpha<1$ 给出首轮参数起点 $(\alpha,T,K_c)$，并说明该结果只是首轮验证起点，不是最终最优参数。

## T5-2 目标、约束、权重偏好到目标函数语言（20分）

某电液伺服执行机构的速度闭环面向三类任务：

1. 短时定位到位，重点关注时域性能。
2. 面对机械振动和参数摄动时保持可接受的鲁棒性，重点关注频域裕度。
3. 周期工况下能耗受控，重点关注控制量代价。

现有初始方案需要围绕以下指标建立一版无约束加权目标函数语言：

- 上升时间：$t_r \le 1.6\,\mathrm{s}$；
- 超调量：$M_p \le 15\%$；
- 稳态误差：$e_{ss} \le 1\%$；
- 扰动抑制时间：$t_d \le 0.8\,\mathrm{s}$；
- 相位裕度：$\phi_m \ge 45^\circ$；
- 闭环带宽：$\omega_c \ge 3\,\mathrm{rad/s}$；
- 控制能量：$\int_0^{t_f}u^2(t)\,dt \le 6\,\mathrm{V^2\cdot s}$；
- 阻尼系数目标范围：$\zeta \in [0.55,0.80]$。

请完成以下四项：

1. 把上述需求整理为可执行的目标项，说明每个指标属于哪一类性能目标。
2. 给出每一目标项的归一化基准；若题目中未给明确基准，需给出你选择基准的理由与替代表达。
3. 给出权重偏好与排序，体现快慢、精度、鲁棒、节能之间的工程取舍。
4. 写出一条单一目标函数形式的无约束加权目标函数表达式，并说明其工程解释。

本题只要求建立目标函数语言，不要求给出最终最优参数、罚函数或 `fmincon` 式求解步骤。
