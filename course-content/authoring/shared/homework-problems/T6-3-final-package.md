# 自动控制原理 作业6：约束、迁移与高保真验证下的方案修正

## 题号与题型

- 题号：T6-3
- 题型：设计题 [D]
- 分值：20分
- 标题：高保真验证下的多目标交付判断

## 最终题面

某液位控制系统拟定三个有限候选控制方案 A/B/C，用于单回路液位调节。请基于给定的硬约束、模型来源与高保真验证证据，判断每个候选方案的交付状态：**可交付 / 需修正 / 只能保留为候选**。并说明判断依据（取舍逻辑必须关联硬约束、扰动/噪声证据与模型来源）。

- 总任务：
  - 不要求重新优化算法，不要求设计新方法。
  - 只能基于下表已有数据做交付判断。
  - 不允许将模块5方法用于修补。

- 课程单元要求：
  1. 识别并区分模型来源（简化模型 / 辨识模型 / 高保真模型）。
  2. 结合扰动、噪声与不确定性验证结果。
  3. 做出分类判断并给出可追踪依据。

**不可放宽硬约束（全部课题共用）**
- 峰值超调：$M_p \le 5\%$
- 稳态误差：$|e_{ss}| \le 1\%$
- 稳定上升沿时间：$t_s \le 1.5\,\text{s}$
- 执行机构限幅：$|u|_{\max} \le 4.0$

**高保真扰动与噪声试验条件（判定依据）**
- 扰动：负载扰动 $\Delta d=\pm 10\%$
- 噪声：传感噪声标准差 $\sigma_n=0.02$（量纲一化）
- 高频未建模动态：执行机构滞后 $0.25\,\text{s}$ + 轻微摩擦项

**候选方案与证据**

| 方案 | 简化模型来源 | 辨识模型来源 | 高保真模型来源 | 指标及结果 |
|---|---|---|---|---|
| A | 二阶等效模型（主导共轭实根） | ARX 辨识（5 Hz 采样） | 非线性液位机理模型 + 饱和+摩擦 + 噪声 | 简化：$t_s=1.1\,\text{s},\ M_p=4.5\%,\ e_{ss}=0.8\%,\ |u|_{\max}=3.6$；辨识：$t_s=1.0\,\text{s},\ M_p=4.0\%,\ e_{ss}=0.6\%,\ |u|_{\max}=3.8$；高保真（含扰动/噪声）：$t_s=1.6\,\text{s},\ M_p=6.1\%,\ e_{ss}=0.7\%,\ |u|_{\max}=3.9$ |
| B | 一阶延迟近似模型 | 互补试验辨识（不同工况拼接） | 统一高保真模型 + 相同工况扰动/噪声 | 简化：$t_s=1.4\,\text{s},\ M_p=4.8\%,\ e_{ss}=0.9\%,\ |u|_{\max}=3.7$；辨识：$t_s=1.5\,\text{s},\ M_p=5.0\%,\ e_{ss}=0.9\%,\ |u|_{\max}=3.9$；高保真：$t_s=1.4\,\text{s},\ M_p=4.6\%,\ e_{ss}=0.8\%,\ |u|_{\max}=3.8$ |
| C | 二阶标准型线性模型 | 经验模型外推（仅局部有效） | 高保真模型（含执行器死区0.12） | 简化：$t_s=1.2\,\text{s},\ M_p=3.2\%,\ e_{ss}=0.5\%,\ |u|_{\max}=4.1$；辨识：$t_s=1.3\,\text{s},\ M_p=3.8\%,\ e_{ss}=0.7\%,\ |u|_{\max}=4.4$；高保真：$t_s=2.3\,\text{s},\ M_p=4.0\%,\ e_{ss}=2.9\%,\ |u|_{\max}=4.3$ |

问题：请按课程要求写出三方案判定，并对每个方案给出一句解释其结论的依据，强调“为何硬约束决定了该结论”。

## 标准答案

1. 先确定不可放宽的硬约束与证据优先级。四项硬约束为 $M_p\le5\%$、$|e_{ss}|\le1\%$、$t_s\le1.5\,\mathrm{s}$、$|u|_{\max}\le4.0$。本题给出了简化模型、辨识模型与高保真模型三类来源，其中交付判断必须以含扰动、噪声、执行机构滞后与摩擦项的高保真验证为最终依据；简化模型和辨识模型只能作为候选筛选证据，不能覆盖高保真越界结论。（4分）

2. 逐项判定三组候选：

| 方案 | 高保真证据 | 硬约束结论 | 交付状态 |
|---|---|---|---|
| A | $t_s=1.6\,\mathrm{s}$，$M_p=6.1\%$，$e_{ss}=0.7\%$，$|u|_{\max}=3.9$ | $t_s$ 与 $M_p$ 越界，$e_{ss}$ 与 $|u|_{\max}$ 仍满足 | 需修正 |
| B | $t_s=1.4\,\mathrm{s}$，$M_p=4.6\%$，$e_{ss}=0.8\%$，$|u|_{\max}=3.8$ | 四项硬约束全部满足 | 可交付 |
| C | $t_s=2.3\,\mathrm{s}$，$M_p=4.0\%$，$e_{ss}=2.9\%$，$|u|_{\max}=4.3$ | $t_s$、$e_{ss}$、$|u|_{\max}$ 多项越界 | 只能保留为候选 |

因此，A 不是可交付方案，但越界集中在动态性能，且执行机构限幅未超出，适合在原结构内继续修正；B 在高保真扰动/噪声条件下全部满足硬约束，可进入交付；C 多项硬约束越界，且辨识模型来源为经验外推、仅局部有效，同时高保真模型含执行器死区，当前证据不足以支撑交付，只能保留为后续候选。（10分）

3. 取舍说明如下：本题不能按“简化模型指标最好”或“单项性能最好”直接选择方案，而要先守硬约束，再看高保真证据。A 在简化和辨识模型下表现较好，但高保真下暴露超调和响应时间风险，所以应修正后重验；B 的目标表现不是所有表中最优，但它在最完整证据链中全部达标，是唯一可交付方案；C 虽然超调较低，但稳态误差、响应时间和执行器限幅同时失败，且模型来源不够稳健，不能以低超调掩盖交付风险。最终结论为：A 需修正，B 可交付，C 只能保留为候选。（6分）
