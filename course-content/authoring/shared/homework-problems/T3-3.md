## 2. 最终题面

已知某单位负反馈系统的开环传递函数为：

$$G(s) = \\frac{K}{s(s+2)(s+4)}$$

该系统的根轨迹图如下图所示（已绘制完成，包含等阻尼比辅助线）：

**根轨迹图描述：**
- 开环极点：$p_1 = 0$，$p_2 = -2$，$p_3 = -4$（实轴上的三个极点）
- 实轴上的根轨迹段：$(-\\infty, -4]$ 和 $[-2, 0]$
- 渐近线：与实轴交点为 $\\sigma_a = \\frac{0 + (-2) + (-4)}{3} = -2$，夹角为 $\\pm 60°$ 和 $180°$
- 分离点：$s_d \\approx -0.845$（位于 $[-2, 0]$ 区间内）
- 与虚轴交点：当 $K = 48$ 时，$s = \\pm j2\\sqrt{3} \\approx \\pm j3.46$
- **等阻尼比辅助线**：图中已绘制 $\\zeta = 0.456$（对应 $\\sigma\\% = 20\\%$）的射线，该射线与根轨迹的交点约为 $s \\approx -0.5 \\pm j1.0$

**时域性能指标公式（假设系统为典型二阶系统近似）：**
- 超调量：$\\sigma\\% = e^{-\\pi\\zeta/\\sqrt{1-\\zeta^2}} \\times 100\\%$
- 调节时间（$\\Delta = 2\\%$）：$t_s \\approx \\frac{4}{\\zeta\\omega_n} = \\frac{4}{|\\text{Re}(s)|}$
- 峰值时间：$t_p = \\frac{\\pi}{\\omega_d} = \\frac{\\pi}{\\text{Im}(s)}$

**请完成以下分析：**

**(1)** 在根轨迹图上标出满足 $\\sigma\\% \\leq 20\\%$ 和 $t_s \\leq 4\\text{s}$ 的可行闭环极点区域，并说明判定依据。（8分）

**(2)** 确定使闭环极点位于可行区域内的增益 $K$ 的取值范围。（10分）

**(3)** 若在此基础上再增加约束条件 $t_p \\leq 1\\text{s}$，判断三个约束条件之间是否存在可行解。若存在，在图中标出最终可行区域；若不存在，用图形方式说明原因。（12分）

## 3. 标准答案

### (1) 可行极点区域的确定

可行区域为根轨迹上满足以下两个条件的极点位置：

**条件1：$\\sigma\\% \\leq 20\\%$**
- 由 $\\sigma\\% = e^{-\\pi\\zeta/\\sqrt{1-\\zeta^2}} \\times 100\\% \\leq 20\\%$，解得 $\\zeta \\geq 0.456$
- 在根轨迹图上，这对应于等阻尼比线 $\\zeta = 0.456$ 右侧的区域（即更靠近实轴的区域）
- 因此，闭环极点必须位于 $\\zeta = 0.456$ 射线与根轨迹交点的右侧分支上

**条件2：$t_s \\leq 4\\text{s}$**
- 由 $t_s \\approx \\frac{4}{|\\text{Re}(s)|} \\leq 4$，得 $|\\text{Re}(s)| \\geq 1$，即 $\\text{Re}(s) \\leq -1$
- 在根轨迹图上，这对应于垂直线 $s = -1$ 左侧的区域

**可行区域**：根轨迹上同时满足 $\\zeta \\geq 0.456$ 且 $\\text{Re}(s) \\leq -1$ 的部分。

根据图中数据，$\\zeta = 0.456$ 线与根轨迹交于 $s_{A,B} \\approx -0.5 \\pm j1.0$，而 $\\text{Re}(s) = -1$ 与根轨迹的交点约为 $s_{C,D} \\approx -1.0 \\pm j1.73$。

因此，可行区域为根轨迹上从 $s_C \\approx -1.0 + j1.73$ 到分离点方向，以及对称的下半平面对应部分。

---

### (2) 增益K的取值范围

利用根轨迹的幅值条件 $K = \\prod_{i=1}^{3}|s - p_i|$ 计算：

**在点 $s_C \\approx -1.0 + j1.73$ 处：**
- $|s_C - p_1| = |(-1+j1.73) - 0| = \\sqrt{1 + 3} = 2$
- $|s_C - p_2| = |(-1+j1.73) - (-2)| = |1+j1.73| = \\sqrt{1 + 3} = 2$
- $|s_C - p_3| = |(-1+j1.73) - (-4)| = |3+j1.73| = \\sqrt{9 + 3} = \\sqrt{12} \\approx 3.46$
- $K_C = 2 \\times 2 \\times 3.46 \\approx 13.86$

**在等阻尼比线与根轨迹交点 $s_A \\approx -0.5 + j1.0$ 处：**
- $|s_A - p_1| = |(-0.5+j1.0) - 0| = \\sqrt{0.25 + 1} = \\sqrt{1.25} \\approx 1.118$
- $|s_A - p_2| = |(-0.5+j1.0) - (-2)| = |1.5+j1.0| = \\sqrt{2.25 + 1} = \\sqrt{3.25} \\approx 1.803$
- $|s_A - p_3| = |(-0.5+j1.0) - (-4)| = |3.5+j1.0| = \\sqrt{12.25 + 1} = \\sqrt{13.25} \\approx 3.640$
- $K_A = 1.118 \\times 1.803 \\times 3.640 \\approx 7.34$

**结论**：满足两个约束条件的增益范围为 $\\boxed{7.34 \\leq K \\leq 13.86}$

（注：若取 $K < 7.34$，则 $\\sigma\\% > 20\\%$；若取 $K > 13.86$，则 $t_s > 4$s）

---

### (3) 增加tp约束后的可行性分析

**新增条件：$t_p \\leq 1\\text{s}$**

由 $t_p = \\frac{\\pi}{\\omega_d} = \\frac{\\pi}{\\text{Im}(s)} \\leq 1$，得：
$$\\text{Im}(s) \\geq \\pi \\approx 3.14$$

这意味着闭环极点的虚部必须满足 $\\omega_d \\geq 3.14$。

**可行性判断：不存在可行解**

**图形说明：**

1. 在根轨迹图上，$\\text{Im}(s) = 3.14$ 是一条水平线
2. 该水平线与根轨迹的交点约在 $s \\approx -0.3 \\pm j3.14$ 附近（根轨迹在分离点后向渐近线 $60°$ 方向延伸）
3. 计算该交点的实部：$\\text{Re}(s) \\approx -0.3 > -1$

**矛盾分析：**
- 要求 $t_p \\leq 1$s 需要 $\\text{Im}(s) \\geq 3.14$，对应根轨迹上靠近渐近线的区域
- 但此区域的实部 $\\text{Re}(s) \\approx -0.3$，不满足 $t_s \\leq 4$s 要求的 $\\text{Re}(s) \\leq -1$
- 同时，该区域远离等阻尼比线，阻尼比 $\\zeta \\approx 0.1$，超调量 $\\sigma\\% \\approx 73\\% > 20\\%$

**结论**：三个约束条件 $\\sigma\\% \\leq 20\\%$、$t_s \\leq 4\\text{s}$、$t_p \\leq 1\\text{s}$ 在根轨迹上无交集，**不存在可行解**。

## 5. 参考作答

### 作答摘要

**第(1)部分：可行闭环极点区域**
- 超调量约束 $\\sigma\\% \\leq 20\\%$ 转化为 $\\zeta \\geq 0.456$，对应等阻尼比线左侧区域
- 调节时间约束 $t_s \\leq 4$s 转化为 $\\text{Re}(s) \\leq -1$，对应垂直线 $s=-1$ 左侧
- 可行区域为根轨迹上同时满足两个条件的部分

**第(2)部分：增益K的范围**
- 利用幅值条件 $K = |s||s+2||s+4|$ 计算
- 在 $\\zeta=0.456$ 线交点处 $K \\approx 7.34$
- 在 $\\text{Re}(s)=-1$ 交点处 $K \\approx 13.86$
- K的范围约为 $[7.34, 13.86]$

**第(3)部分：增加 $t_p \\leq 1$s 约束**
- $t_p \\leq 1$s 转化为 $\\text{Im}(s) \\geq \\pi \\approx 3.14$
- 分析表明：当 $\\text{Im}(s) \\geq 3.14$ 时，根轨迹上的点实部约为 $-0.3$，不满足 $\\text{Re}(s) \\leq -1$
- **结论**：三个约束无共同可行解

### 物理意义解释
这体现了控制系统设计中性能指标之间的内在矛盾：快速响应（小 $t_s$）要求极点远离虚轴，而小超调（小 $\\sigma\\%$）要求足够阻尼，这两者与快速上升（小 $t_p$）对高频特性的要求存在冲突。
