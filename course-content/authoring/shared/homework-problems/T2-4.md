## 最终题面

**参数变化与系统响应联动分析**

某单位负反馈控制系统的前向通道传递函数为：

$$G(s) = \\frac{K}{s(s+4)}$$

其中 K > 0 为系统增益参数。

**符号定义**：
- s：复频域变量
- K：系统开环增益，无量纲
- ζ：阻尼比
- ωn：自然频率（rad/s）
- σ%：超调量（百分比）
- Kcr：临界稳定增益（本题取临界阻尼点 Kcr = 4）

**请完成以下分析：**

**(1) 极点表达式推导（20分）**
求闭环系统极点关于参数 K 的表达式，并说明极点随 K 变化的规律。

**(2) 极点轨迹绘制（25分）**
画出当 K 从 0 增加到 Kcr 时，闭环极点在复平面上的轨迹示意图（需标注关键点坐标和箭头方向）。

**(3) 参数表格计算（30分）**
填写下表，计算 K = 0.5, 1, 2, Kcr 时的阻尼比 ζ、超调量 σ% 和系统稳定性：

| K | ζ | σ% | 稳定性 |
|:---:|:---:|:---:|:---:|
| 0.5 | | | |
| 1 | | | |
| 2 | | | |
| Kcr | | | |

**(4) 工程指标约束（25分）**
若工程要求超调量 σ% ≤ 16.3%，求满足该条件的 K 取值范围。

## 标准答案

### 第(1)部分：极点表达式推导（20分）

**闭环传递函数**：
$$\\Phi(s) = \\frac{G(s)}{1+G(s)H(s)} = \\frac{\\frac{K}{s(s+4)}}{1+\\frac{K}{s(s+4)}} = \\frac{K}{s^2 + 4s + K}$$

**闭环特征方程**：$s^2 + 4s + K = 0$

**极点表达式**：
$$s_{1,2} = \\frac{-4 \\pm \\sqrt{16 - 4K}}{2} = -2 \\pm \\sqrt{4 - K}$$

**极点随 K 变化的规律**：
- 当 0 < K < 4 时：Δ = 16 - 4K > 0，两相异实根 $s_{1,2} = -2 \\pm \\sqrt{4-K}$，系统**过阻尼**
- 当 K = 4 时：Δ = 0，重根 $s_{1,2} = -2$，系统**临界阻尼**
- 当 K > 4 时：Δ < 0，共轭复根 $s_{1,2} = -2 \\pm j\\sqrt{K-4}$，实部恒为 -2，系统**欠阻尼**

**系统稳定性**：极点实部恒为负，系统对所有 K > 0 **始终稳定**。

### 第(2)部分：极点轨迹绘制（25分）

**轨迹特征**：
- **起点**（K → 0⁺）：$s_1 \\to 0$，$s_2 \\to -4$
- **K 从 0 增至 4**：两极点沿实轴相向移动，在 s = -2 处汇合
- **K 从 4 继续增大**：极点分离为共轭复根，沿垂直线 Re(s) = -2 向上/下移动

**示意图要点**（需包含）：
- 实轴上的轨迹段：从 (-4, 0) 到 (0, 0)
- 汇合点：(-2, 0)，标注 K = 4
- 分离后的垂直轨迹：直线 Re(s) = -2，向上延伸至 (-2, +j∞)，向下至 (-2, -j∞)
- 箭头方向：从起点指向无穷远

### 第(3)部分：参数表格计算（30分）

标准二阶系统形式：$s^2 + 2\\zeta\\omega_n s + \\omega_n^2 = 0$

对比特征方程 $s^2 + 4s + K = 0$，得：$\\omega_n = \\sqrt{K}$，$\\zeta = \\frac{2}{\\sqrt{K}}$

超调量公式：$\\sigma\\% = e^{-\\frac{\\pi\\zeta}{\\sqrt{1-\\zeta^2}}} \\times 100\\%$（仅当 ζ < 1 时有超调）

**完整表格**：

| K | ζ | σ% | 稳定性 |
|:---:|:---:|:---:|:---:|
| 0.5 | 2.83 | 0 | 稳定 |
| 1 | 2.00 | 0 | 稳定 |
| 2 | 1.41 | 0 | 稳定 |
| 4 (Kcr) | 1.00 | 0 | 稳定 |

计算说明：
- K = 0.5：ζ = 2/√0.5 ≈ 2.83 > 1（过阻尼，无超调）
- K = 1：ζ = 2/1 = 2 > 1（过阻尼，无超调）
- K = 2：ζ = 2/√2 ≈ 1.41 > 1（过阻尼，无超调）
- K = 4：ζ = 2/2 = 1（临界阻尼，无超调）

### 第(4)部分：工程指标约束（25分）

要求 $\\sigma\\% \\leq 16.3\\%$

首先确定临界阻尼比。已知当 ζ = 0.5 时：
$$\\sigma\\% = e^{-\\frac{\\pi \\times 0.5}{\\sqrt{1-0.25}}} \\times 100\\% = e^{-\\frac{1.571}{0.866}} \\times 100\\% = e^{-1.814} \\times 100\\% \\approx 16.3\\%$$

因此要求 $\\sigma\\% \\leq 16.3\\%$ 等价于要求 **ζ ≥ 0.5**

由 $\\zeta = \\frac{2}{\\sqrt{K}} \\geq 0.5$：
$$\\frac{2}{\\sqrt{K}} \\geq 0.5 \\Rightarrow \\sqrt{K} \\leq 4 \\Rightarrow K \\leq 16$$

综合 K > 0 的物理意义：

**最终答案**：$\\mathbf{0 < K \\leq 16}$

验证：当 K = 16 时，ζ = 2/4 = 0.5，σ% = 16.3% 恰好满足；当 K > 16 时，ζ < 0.5，超调量将超过 16.3%。

## 关键易错点

1. **极点轨迹绘制错误**：部分学生可能误认为极点轨迹是圆形或抛物线，实际上当 K > 4 时极点沿垂直线 Re(s) = -2 移动，形成直线轨迹
2. **超调量计算条件混淆**：当 ζ ≥ 1（过阻尼/临界阻尼）时，系统无超调，σ% = 0。部分学生可能对 K = 0.5, 1, 2 仍使用欠阻尼公式计算超调量
3. **临界稳定增益理解偏差**：本题系统特征方程实部恒为负，理论上始终稳定，不存在有限临界增益。Kcr = 4 是过阻尼到欠阻尼的分界点，而非临界稳定点
