## 2. 最终题面

**T3-1 劳斯判据判稳定性与临界增益**

已知某单位负反馈系统的开环传递函数为：

$$G(s) = \frac{K}{s(s+1)(s^2+2s+2)}$$

其中 $K > 0$ 为开环增益。

**要求：**

1. 写出系统的闭环特征方程；
2. 构建劳斯阵列（Routh Array），写出完整的劳斯表；
3. 分析劳斯阵列第一列元素的符号条件，确定使闭环系统稳定的增益 $K$ 的取值范围；
4. 求系统处于临界稳定状态时的临界增益 $K_{cr}$ 和虚轴穿越频率 $\omega_{cr}$。

---

## 3. 标准答案

### 步骤1：求闭环特征方程

单位负反馈系统的闭环特征方程为 $1 + G(s) = 0$，即：

$$1 + \frac{K}{s(s+1)(s^2+2s+2)} = 0$$

两边同乘分母得：
$$s(s+1)(s^2+2s+2) + K = 0$$

展开计算：
$$s(s+1)(s^2+2s+2) = s(s^3+2s^2+2s+s^2+2s+2) = s(s^3+3s^2+4s+2)$$
$$= s^4 + 3s^3 + 4s^2 + 2s$$

因此，闭环特征方程为：
$$\boxed{s^4 + 3s^3 + 4s^2 + 2s + K = 0}$$

### 步骤2：构建劳斯阵列

特征方程：$s^4 + 3s^3 + 4s^2 + 2s + K = 0$

劳斯阵列构建如下：

| $s^4$ | 1 | 4 | K |
| $s^3$ | 3 | 2 | 0 |
| $s^2$ | $b_1$ | $b_2$ | |
| $s^1$ | $c_1$ | | |
| $s^0$ | $d_1$ | | |

其中：
$$b_1 = \frac{3 \times 4 - 1 \times 2}{3} = \frac{12-2}{3} = \frac{10}{3}$$

$$b_2 = \frac{3 \times K - 1 \times 0}{3} = K$$

$$c_1 = \frac{b_1 \times 2 - 3 \times b_2}{b_1} = \frac{\frac{10}{3} \times 2 - 3K}{\frac{10}{3}} = \frac{\frac{20}{3} - 3K}{\frac{10}{3}} = \frac{20 - 9K}{10}$$

$$d_1 = \frac{c_1 \times b_2 - b_1 \times 0}{c_1} = b_2 = K$$

完整劳斯阵列：

| $s^4$ | 1 | 4 | K |
| $s^3$ | 3 | 2 | 0 |
| $s^2$ | $\frac{10}{3}$ | $K$ | |
| $s^1$ | $\frac{20-9K}{10}$ | 0 | |
| $s^0$ | $K$ | | |

### 步骤3：确定稳定区间

根据劳斯稳定判据，系统稳定的充要条件是劳斯阵列第一列所有元素同号（且为正，因为 $a_0 = 1 > 0$）。

第一列元素：
- $s^4$ 行：$1 > 0$ ✓
- $s^3$ 行：$3 > 0$ ✓
- $s^2$ 行：$\frac{10}{3} > 0$ ✓
- $s^1$ 行：$\frac{20-9K}{10} > 0 \Rightarrow 20 - 9K > 0 \Rightarrow K < \frac{20}{9}$
- $s^0$ 行：$K > 0$（题设条件）

综合得稳定条件：
$$\boxed{0 < K < \frac{20}{9} \approx 2.22}$$

### 步骤4：求临界增益和虚轴穿越频率

**临界增益 $K_{cr}$：**

当系统处于临界稳定状态时，劳斯阵列某一行全为零。观察 $s^1$ 行，令其等于零：
$$\frac{20-9K}{10} = 0 \Rightarrow 20 - 9K = 0 \Rightarrow K_{cr} = \frac{20}{9}$$

$$\boxed{K_{cr} = \frac{20}{9} \approx 2.22}$$

**虚轴穿越频率 $\omega_{cr}$：**

当 $K = K_{cr}$ 时，$s^1$ 行全零，此时存在共轭虚根。由 $s^2$ 行构造辅助方程：
$$A(s) = \frac{10}{3}s^2 + K_{cr} = 0$$

代入 $K_{cr} = \frac{20}{9}$：
$$\frac{10}{3}s^2 + \frac{20}{9} = 0$$

$$s^2 = -\frac{20}{9} \times \frac{3}{10} = -\frac{60}{90} = -\frac{2}{3}$$

$$s = \pm j\sqrt{\frac{2}{3}} = \pm j\frac{\sqrt{6}}{3}$$

因此：
$$\boxed{\omega_{cr} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3} \approx 0.816 \text{ rad/s}}$$

## 5. 参考作答

**选择作答1（solver-1）作为参考作答**，原因：该作答提供了最完整、最清晰的推导过程，包含详细的文字说明和验证环节。

### 详细推导过程

#### 1. 闭环特征方程推导
单位负反馈系统闭环特征方程为 $1 + G(s) = 0$

$G(s) = K / [s(s+1)(s^2+2s+2)]$

$1 + K/[s(s+1)(s^2+2s+2)] = 0$

展开分母：
$s(s+1)(s^2+2s+2) = s(s^3 + 2s^2 + 2s + s^2 + 2s + 2)$
                $= s(s^3 + 3s^2 + 4s + 2)$
                $= s^4 + 3s^3 + 4s^2 + 2s$

因此特征方程为：
$s^4 + 3s^3 + 4s^2 + 2s + K = 0$

#### 2. 劳斯阵列构建
系数：$a_4=1, a_3=3, a_2=4, a_1=2, a_0=K$

计算中间项：
$b_1 = (a_3 \cdot a_2 - a_4 \cdot a_1)/a_3 = (3 \times 4 - 1 \times 2)/3 = 10/3$
$b_2 = (a_3 \cdot a_0 - a_4 \cdot 0)/a_3 = 3K/3 = K$
$c_1 = (b_1 \cdot a_1 - a_3 \cdot b_2)/b_1 = [(10/3) \times 2 - 3K]/(10/3) = (20/3 - 3K)/(10/3) = (20-9K)/10$
$d_1 = b_2 = K$

#### 3. 稳定性条件分析
劳斯判据要求第一列元素均为正（因$a_4=1>0$）：
- $s^4$行：$1 > 0$ ✓
- $s^3$行：$3 > 0$ ✓
- $s^2$行：$10/3 > 0$ ✓
- $s^1$行：$(20-9K)/10 > 0 \rightarrow K < 20/9$
- $s^0$行：$K > 0$

稳定区间：$0 < K < 20/9$

#### 4. 临界稳定状态求解
临界条件：$c_1 = 0$
$(20-9K_{cr})/10 = 0 \rightarrow K_{cr} = 20/9 \approx 2.222$

求穿越频率：用$s^2$行构建辅助方程
$A(s) = (10/3)s^2 + K_{cr} = 0$
$(10/3)s^2 + 20/9 = 0$
$s^2 = -(20/9) \times (3/10) = -2/3$
$s = \pm j\sqrt{2/3} = \pm j(\sqrt{6}/3)$

因此：$\omega_{cr} = \sqrt{2/3} = \sqrt{6}/3 \approx 0.816$ rad/s

### 最终答案汇总

| 项目 | 结果 |
|------|------|
| 特征方程 | $s^4 + 3s^3 + 4s^2 + 2s + K = 0$ |
| 劳斯阵列 | $s^4$: 1, 4, K; $s^3$: 3, 2, 0; $s^2$: 10/3, K; $s^1$: (20-9K)/10; $s^0$: K |
| 稳定区间 | $0 < K < 20/9$（约 $0 < K < 2.222$） |
| 临界增益 | $K_{cr} = 20/9 \approx 2.222$ |
| 穿越频率 | $\omega_{cr} = \sqrt{2/3} = \sqrt{6}/3 \approx 0.816$ rad/s |

### 验证说明
1. 当$K=0$时，系统有极点在$s=0$，临界稳定，符合边界条件
2. 当$K=K_{cr}$时，劳斯阵列$s^1$行全零，辅助方程给出纯虚根$s=\pm j\sqrt{2/3}$，系统处于临界稳定状态
3. 当$K>K_{cr}$时，$s^1$行第一列元素为负，第一列符号变化两次，系统有两个极点位于右半平面，不稳定
