## 2. 最终题面

**题目 T2-2：结构图化简求闭环传递函数**

已知某控制系统的结构图如下所示，其中各环节的传递函数为：

**结构图描述：**
- 输入信号：$R(s)$
- 输出信号：$C(s)$
- 前向通路1：$G_1(s) = K_1$（比例环节，$K_1 = 2$）
- 前向通路2：$G_2(s) = K_2/s$（积分环节，$K_2 = 3$）
- 前向通路3：$G_3(s) = 1$（单位增益）
- 内环反馈：$H_1(s) = 1$（单位负反馈，从$G_2$输出反馈到$G_2$输入）
- 外环反馈：$H_2(s) = K_3$（比例反馈，$K_3 = 0.5$，从$C(s)$反馈到求和点）

**结构图连接关系：**
1. 输入$R(s)$进入第一个求和点，与$H_2$反馈信号相减
2. 求和点输出分为两路：
   - 上路经$G_1(s)$直接到第二个求和点
   - 下路经$G_2(s)$，$G_2(s)$带有内环负反馈$H_1(s)$
3. 第二个求和点将上路信号与$G_2(s)$输出相加，再经$G_3(s)$得到$C(s)$
4. $C(s)$经$H_2(s)$反馈回第一个求和点（负反馈）

**要求：**

1. 化简内环（$G_2$与$H_1$构成的局部反馈），求等效传递函数$G_2'(s)$。（6分）
2. 化简外环，求系统的闭环传递函数$T(s) = C(s)/R(s)$。（10分）
3. 若前向通路增益$K_1$变为原来的2倍（即$K_1' = 4$），分析闭环传递函数$T(s)$将如何变化（定性说明：增大/减小/基本不变，并简述理由）。（4分）

---

## 3. 标准答案

### 步骤1：化简内环求$G_2'(s)$

内环结构：$G_2(s) = K_2/s = 3/s$，$H_1(s) = 1$（单位负反馈）

局部闭环传递函数公式：
$$G_2'(s) = \frac{G_2(s)}{1 + G_2(s) \cdot H_1(s)}$$

代入：
$$G_2'(s) = \frac{3/s}{1 + \frac{3}{s} \times 1} = \frac{3/s}{(s+3)/s} = \frac{3}{s+3}$$

$$\boxed{G_2'(s) = \frac{3}{s+3}}$$

---

### 步骤2：化简外环求$T(s)$

化简内环后，系统前向通路有两条并联支路：
- 上路：$G_1(s) = 2$
- 下路：$G_2'(s) = \frac{3}{s+3}$

并联等效：
$$G_{12}(s) = G_1(s) + G_2'(s) = 2 + \frac{3}{s+3} = \frac{2(s+3)+3}{s+3} = \frac{2s+9}{s+3}$$

外环反馈：$H_2(s) = 0.5$

闭环传递函数：
$$T(s) = \frac{G_{12}(s) \cdot G_3(s)}{1 + G_{12}(s) \cdot G_3(s) \cdot H_2(s)}$$

代入$G_3(s)=1$：
$$T(s) = \frac{(2s+9)/(s+3)}{1 + \frac{2s+9}{s+3} \times 0.5}$$

分母化简：
$$1 + \frac{0.5(2s+9)}{s+3} = \frac{s+3+s+4.5}{s+3} = \frac{2s+7.5}{s+3}$$

因此：
$$T(s) = \frac{2s+9}{s+3} \times \frac{s+3}{2s+7.5} = \frac{2s+9}{2s+7.5}$$

$$\boxed{T(s) = \frac{2s+9}{2s+7.5} = \frac{4s+18}{4s+15}}$$
（等价形式均可）

---

### 步骤3：$K_1$变为2倍时$T(s)$的变化分析

当$K_1' = 4$时，重新计算：

新的并联等效：
$$G_{12}'(s) = 4 + \frac{3}{s+3} = \frac{4(s+3)+3}{s+3} = \frac{4s+15}{s+3}$$

新的闭环传递函数：
$$T'(s) = \frac{(4s+15)/(s+3)}{1 + 0.5 \times \frac{4s+15}{s+3}} = \frac{4s+15}{s+3+2s+7.5} = \frac{4s+15}{3s+10.5}$$

对比：
- 原系统：$T(s) = \frac{2s+9}{2s+7.5}$
- 新系统：$T'(s) = \frac{4s+15}{3s+10.5}$

稳态增益对比：
- 原系统：$T(0) = \frac{9}{7.5} = 1.2$
- 新系统：$T'(0) = \frac{15}{10.5} \approx 1.43$

**结论**：闭环传递函数$T(s)$将增大。理由：前向通路增益增大使开环增益增大，在负反馈系统中，虽然反馈会部分抵消，但闭环增益仍会随开环增益增大而增大（稳态增益从1.2增至约1.43）。

## 5. 参考作答

**选择作答2（solver-2）作为参考作答**，原因：该作答结构最为清晰，每一步都有明确的公式引用和代数运算验证。

### 详细推导过程

#### 1. 内环化简

内环由$G_2(s)$和$H_1(s)$构成局部负反馈回路。

根据局部反馈化简公式：
$$G_2'(s) = \frac{G_2(s)}{1 + G_2(s) \cdot H_1(s)}$$

已知$G_2(s) = K_2/s = 3/s$，$H_1(s) = 1$，代入得：
$$G_2'(s) = \frac{3/s}{1 + (3/s) \times 1} = \frac{3/s}{(s+3)/s} = \frac{3}{s+3}$$

#### 2. 外环化简

化简内环后，系统前向通路有两条并联支路：
- 上路：$G_1(s) = 2$
- 下路：$G_2'(s) = \frac{3}{s+3}$

并联等效传递函数：
$$G_{12}(s) = G_1(s) + G_2'(s) = 2 + \frac{3}{s+3} = \frac{2(s+3) + 3}{s+3} = \frac{2s+9}{s+3}$$

再考虑外环负反馈$H_2(s) = 0.5$和$G_3(s) = 1$，闭环传递函数：
$$T(s) = \frac{G_{12}(s) \cdot G_3(s)}{1 + G_{12}(s) \cdot G_3(s) \cdot H_2(s)}$$

代入：
$$T(s) = \frac{(2s+9)/(s+3)}{1 + \frac{2s+9}{s+3} \times 0.5}$$

分母化简：
$$1 + \frac{0.5(2s+9)}{s+3} = \frac{s+3+s+4.5}{s+3} = \frac{2s+7.5}{s+3}$$

因此：
$$T(s) = \frac{2s+9}{s+3} \times \frac{s+3}{2s+7.5} = \frac{2s+9}{2s+7.5}$$

或等价形式：$T(s) = \frac{4s+18}{4s+15}$

#### 3. 增益变化分析

当$K_1$变为原来的2倍（即$K_1' = 4$）时：

新的并联等效：
$$G_{12}'(s) = 4 + \frac{3}{s+3} = \frac{4(s+3)+3}{s+3} = \frac{4s+15}{s+3}$$

新的闭环传递函数：
$$T'(s) = \frac{(4s+15)/(s+3)}{1 + 0.5 \times \frac{4s+15}{s+3}} = \frac{4s+15}{3s+10.5}$$

稳态增益对比：
- 原系统：$T(0) = \frac{9}{7.5} = 1.2$
- 新系统：$T'(0) = \frac{15}{10.5} \approx 1.43$

**结论**：闭环传递函数$T(s)$将增大。

**理由**：前向通路增益$K_1$增大使并联等效传递函数$G_{12}(s)$增大，进而使开环增益增大。在负反馈系统中，虽然反馈作用会部分抵消增益变化，但闭环增益仍会随开环增益增大而增大。

### 最终答案汇总

| 项目 | 结果 |
|------|------|
| 内环等效传递函数 | $G_2'(s) = \frac{3}{s+3}$ |
| 闭环传递函数 | $T(s) = \frac{2s+9}{2s+7.5} = \frac{4s+18}{4s+15}$ |
| $K_1$增大后 | $T(s)$增大（稳态增益从1.2增至约1.43） |

### 验证说明
1. **内环化简**：使用标准负反馈公式$G/(1+GH)$，结果正确
2. **外环化简**：正确识别并联结构（$G_1$与$G_2'$相加），闭环公式应用正确
3. **增益变化分析**：定性结论与定量计算一致，稳态增益对比验证了结论
