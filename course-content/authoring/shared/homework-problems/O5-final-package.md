# O5 初始控制方案

- 题号：`O5`

请沿用你在 `O4` 中已经保留的首选候选结构与放弃理由，不得更换对象，也不得推翻 `O3-O4` 的主线证据。围绕同一对象，完成一次“初始控制方案”提交。

请完成以下内容：

1. 回收 `O4` 的候选结构排序：写清你最终保留哪一个结构作为首轮方案，为什么暂时放弃其他结构。
2. 写出本次任务的目标与约束表达：至少包含一个主要性能目标、一个不能破坏的边界和一个可接受的首轮偏差。
3. 写出所选结构的表达式、关键参数及参数方向。例如 `PI`、`PD`、超前校正、滞后校正或你在 `O4` 中保留的经典固定结构。
4. 给出首轮参数起点，并说明这些参数如何来自 `O4` 的证据、`T5-1` 的参数起点计算或本次合理试探。

6. 根据验证结果写出参数优化入口卡：列出固定结构下可调整的参数、归一化基准、目标项和权重偏好。

## 参考答案

以下示例沿用 `O4` 中“小型直流电机转速控制”的示例对象。学生可以使用自己的对象，但必须保持 `O3-O4-O5` 的对象、主要矛盾和候选结构连续。

### 1. O4 继承与结构选择

继续沿用小型直流电机转速控制对象，简化模型取

$$
G(s)=\frac{1}{0.35s+1}.
$$

`O4` 已确认主要矛盾是恒定负载下长期转速偏差偏大，而不是稳定性失控或高频振荡。因此首轮保留 `PI` 结构，暂不采用超前校正作为主方案；滞后校正保留为更温和的备选。（8分）

### 2. 目标与约束表达

本次目标是先形成一个可验证的首轮方案，使单位阶跃跟踪的稳态误差明显下降，并在恒定负载扰动下保留恢复趋势。不能破坏的边界是：超调不应明显超过 `20%`，控制量峰值不应出现持续饱和。可接受的首轮偏差是：调节时间可以暂时变长，但必须能从验证表中看出参数优化方向。（6分）

### 3. 结构表达与首轮参数

首轮结构取

$$
C(s)=K_p+\frac{K_i}{s}.
$$

根据 `O4` 的判断，`K_i` 主要服务于压低长期偏差，`K_p` 主要影响响应速度和超调。首轮参数可取

$$
K_p=1.2,\qquad K_i=0.8.
$$

这不是最终参数，只是用于验证 `PI` 路线是否能回应长期偏差问题的起点。（6分）

### 4. 首轮验证记录

示例验证表如下。

| 项目 | 基线比例控制 | 首轮 PI 方案 | 判断 |
|---|---:|---:|---|
| 单位阶跃稳态误差 | 仍有残差 | 明显下降，理论上可趋近零 | 主矛盾被正向回应 |
| 最大超调 | 较小 | 有上升风险 | 需作为后续目标项 |
| 调节时间 | 较短 | 可能变长 | 需权衡速度 |
| 控制量峰值 | 较温和 | 上升 | 需加入控制代价 |

首轮验证说明：若仿真曲线显示稳态误差下降但超调和控制量峰值上升，则说明 `PI` 候选结构有效，但还不能交付；下一步应进入固定结构下的参数优化入口。（8分）

### 5. MATLAB/Octave 复现实验代码

```matlab
pkg load control
s = tf('s');
G = 1/(0.35*s + 1);

C0 = 1.2;
C1 = 1.2 + 0.8/s;

T0 = feedback(C0*G, 1);
T1 = feedback(C1*G, 1);

t = 0:0.01:8;
figure;
step(T0, T1, t);
grid on;
legend('baseline P', 'first-round PI');
title('O5 first-round validation');
```

学生提交时应附运行得到的阶跃响应图，并用 `2-3` 句话说明曲线中“误差下降、超调或调节时间变化、控制量风险”分别如何支持下一步优化入口。（4分）

### 6. 参数优化入口卡

| 字段 | 内容 |
|---|---|
| 固定结构 | `PI` |
| 参数向量 | $\theta=[K_p,K_i]^T$ |
| 归一化基准 | 基线调节时间、首轮超调、基线稳态误差、允许控制量峰值 |
| 目标项 | 稳态误差、调节时间、超调、控制量峰值 |
| 权重偏好 | 先压低稳态误差，再限制超调和控制量，最后改善调节时间 |
| 待显化约束 | 执行器饱和、最大超调上界、调节时间上界 |

该入口卡只给出无约束加权建模语言，不求约束内最优解，也不使用罚函数或 `fmincon`。（4分）
