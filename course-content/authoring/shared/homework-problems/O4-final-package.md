# O4 候选控制结构比较

## 1. 题号 / 题型 / 难度

- 题号：`O4`
- 题型：`O`
- 难度：`⭐⭐`
- 分值：`40分`

## 2. 最终题面

请沿用你在 `O3` 中已经固定的同一对象、简化模型、主要矛盾清单与必要证据，不得更换对象，也不得把 `O3` 的诊断结论推倒重来。围绕该对象当前的主要矛盾，完成一次“候选控制结构比较”。

请完成以下内容：

1. 先用 `2-3` 句话回收 `O3` 的结论：写清当前主要矛盾是什么、哪两条约束最不能破坏，以及为什么这些约束会直接决定本次候选结构的筛选范围。
2. 只允许从本阶段已学结构中选择 `2-3` 个候选结构进行比较。可选范围限定为：`PD`、`PI`、超前校正、滞后校正；你不必把四类结构都写上，但必须解释为什么保留当前候选、为什么暂不采用其他结构。
3. 给出 `1` 张候选结构比较表。比较表至少包含以下四列：结构名称、优先改善什么、主要代价或风险、与 `O3` 证据的对应关系。
4. 对每个候选结构分别说明：它最可能优先解决哪个主要矛盾；它可能带来的新代价是什么；在你这个对象上，什么现象或证据支持你把它列入候选。
5. 若你使用了性能比较、曲线对照或参数试探，必须附 `MATLAB/Octave` 仿真代码、结果图与最小复现实验说明；若本次只做机理层比较而未做参数试探，也要明确写出“本次暂不进入最终定参”的理由。
6. 最后给出当前阶段的候选结构排序，并写出“首选保留理由”和“末位放弃理由”。排序只用于进入 `O5` 的下一步，不代表最终控制器已经确定。
7. 附 `AI 使用记录摘要`，写明 AI 在整理比较表、润色表述或检查越界风险中的作用，以及你如何核查关键判断。

提交约束：

- 主体正文不超过 `800` 字。
- 允许附 `1` 张候选结构比较表；如有需要，可再附 `1-2` 张结果图。
- 本题只做候选结构比较，不做最终参数整定，不写完整设计报告。
- 不得调用模块4中的正式任务表达、多目标可行域、约束激活、失败诊断或迁移排序语言。
- 若 `O3` 的主要矛盾仍未先说清，就直接进入结构比较，按主线连续性扣分。

## 3. 标准答案

可接受答案必须形成“延续 `O3` -> 提出候选结构 -> 比较收益与代价 -> 给出当前排序 -> 把结果交给 `O5`”的闭环。答题开头必须先说明：本次沿用 `O3` 的同一对象、同一模型与同一主要矛盾清单，不更换对象，也不提前做最终定参。（8分）

以下给出三种常见路线；学生可任选与自己 `O3` 诊断一致的一条，但必须让比较逻辑与 `O3` 证据相匹配。

**路线 A：`O3` 的主矛盾是稳态偏差或低频精度不足。**  
此时比较应优先围绕 `PI`、滞后校正，以及一个用于对照的动态改善结构展开，例如超前或 `PD`。合格答案必须说明：`PI` 或滞后之所以进入前两位，是因为它们直接服务于低频增益提升或长期误差压低，而不是因为它们“看起来更高级”。其中，`PI` 的主要收益是更强地压低恒值误差，但代价是相位更吃紧、超调或振荡风险上升；滞后校正的主要收益是温和提高低频作用、对高频噪声更克制，但代价是速度可能变慢、额外滞后不能设计过重；若把超前或 `PD` 作为对照候选，则必须指出它们更偏动态改善，对当前主矛盾针对性不足。（10分）合格排序应体现“稳态改善结构优先，动态改善结构不能无理由排首位”；若 `O3` 证据已经显示相角裕度很紧或噪声明显，则通常应把更温和的低频改善结构排在更前。（10分）

**路线 B：`O3` 的主矛盾是动态品质失衡。**  
此时比较应优先围绕超前校正、`PD`，以及一个用于对照的 `PI` 或滞后结构展开。合格答案必须说明：超前或 `PD` 排在前列，是因为它们更直接地改变相位与动态过程，能优先回应“超调偏大、振荡明显、阻尼不足或调节时间过长”这一类证据；而 `PI` 或滞后虽然可能改善低频误差，但对当前主矛盾并不直接，甚至可能进一步压缩相位裕度。（10分）若学生把 `PI` 排到首位，就必须同时给出非常强的 `O3` 证据说明“稳态问题已反客为主”；否则视为比较逻辑与 `O3` 断裂。最终排序应体现“动态改善结构优先，稳态改善结构作为对照或后备”。（10分）

**路线 C：`O3` 的主矛盾是稳定边界或相位裕度过紧。**  
此时比较应优先围绕超前校正、`PD` 与 `PI`/滞后的风险对照展开。合格答案必须说明：若主要问题是离稳定边界过近、相位裕度不富余或稍加增益就逼近失稳，那么更有希望优先缓解问题的是超前校正或温和的动态改善结构；`PI` 与重滞后之类结构虽然能改善低频误差，但在当前阶段更可能恶化边界，因此只能作为风险更高的候选。（10分）最终排序不能把会继续压缩相位边界的结构放在首位，除非学生能给出额外证据说明其风险可控。（10分）

无论采用哪一条路线，答案都必须显式给出一张候选结构比较表或等价的结构化比较清单，并至少包含“优先改善什么、主要代价是什么、与 `O3` 哪条证据对应、是否保留到 `O5`”这四个维度。（8分）最后必须写出当前排序、首选保留理由、末位放弃理由，并附 `AI 使用记录摘要`，说明 AI 只参与整理与润色，关键结构判断与是否越界由学生自行核查。（4分）

## 4. 分步评分标准

1. `8分`：明确沿用 `O3` 的同一对象、模型和主要矛盾清单，不另起炉灶，并能说清本次比较为何受 `O3` 约束。
2. `10分`：提出 `2-3` 个候选结构，选择与 `O3` 主矛盾一致；若候选集合与 `O3` 证据明显错位，本项最多给 `4分`。
3. `10分`：对每个候选结构都写出“优先改善什么、主要代价是什么、为什么与当前对象有关”，比较逻辑完整且不空泛。
4. `8分`：给出结构化比较表或等价比较清单；若涉及性能比较，补齐 `MATLAB/Octave` 仿真代码、结果图与最小复现实验说明。
5. `4分`：写出当前排序、首选保留理由、末位放弃理由，并附 `AI 使用记录摘要`。

## 5. 裁判结论

本题面严格遵守 `HW4` 开放题边界：它要求学生沿用 `O3` 的主要矛盾，在有限候选结构中做 `2-3` 个方案比较，核心是解释“为什么这些结构会带来不同收益和代价”，而不是直接写成模块4的完整设计题。题面显式限制了结构范围，也显式禁止最终定参、多目标优化和失败诊断，因此与 `HW4` 的阶段能力一致。
