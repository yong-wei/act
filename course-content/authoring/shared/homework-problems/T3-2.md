## 2. 最终题面

**题目：根轨迹基本规则应用**

已知单位负反馈系统的开环传递函数为：

$$G(s)H(s) = \frac{K(s+4)}{s(s+2)(s+6)}$$

其中 $K \geq 0$ 为开环增益。

**要求完成以下内容：**

**①** 确定根轨迹的起点（开环极点）和终点（开环零点及无穷远处）

**②** 用实轴判别法确定实轴上的根轨迹段

**③** 计算渐近线的角度和质心（重心）

**④** 如有分离点/会合点，用 $\frac{dK}{ds} = 0$ 方法求之

**⑤** 估算当 $K = 10$ 时，闭环系统主导极点的近似位置

**附注（题面中已给出的公式）：**
- 根轨迹方程：$1 + G(s)H(s) = 0$
- 分离点方程：$\frac{dK}{ds} = 0$，其中 $K = -\frac{s(s+2)(s+6)}{s+4}$
- 渐近线角度：$\varphi = \frac{(2k+1)\pi}{n-m}$，$k = 0, 1, ..., n-m-1$
- 渐近线质心：$\sigma = \frac{\sum \text{极点} - \sum \text{零点}}{n-m}$

## 3. 标准答案

### ① 起点与终点（3分）

**起点（开环极点）：**
- $p_1 = 0$
- $p_2 = -2$
- $p_3 = -6$

**终点：**
- 有限零点：$z_1 = -4$
- 无穷远处：$n - m = 2$ 条分支趋向无穷远

---

### ② 实轴上的根轨迹段（3分）

**判别法则：** 实轴上某段右侧实极点和实零点的总数为奇数时，该段存在根轨迹。

| 区间 | 右侧极点/零点 | 数量 | 是否在根轨迹 |
|------|--------------|------|-------------|
| $[-2, 0]$ | $p_1=0, p_2=-2$ | 2（偶数） | 否 |
| $[-4, -2]$ | $p_1=0, p_2=-2, z_1=-4$ | 3（奇数） | **是** |
| $[-6, -4]$ | $p_1=0, p_2=-2, p_3=-6, z_1=-4$ | 4（偶数） | 否 |
| $(-\infty, -6]$ | 全部 | 4（偶数） | 否 |

**结论：** 实轴上的根轨迹段为 $[-4, -2]$

---

### ③ 渐近线（4分）

**已知：**
- 极点之和：$0 + (-2) + (-6) = -8$
- 零点之和：$-4$
- $n = 3$，$m = 1$，$n - m = 2$

**质心：**
$$\sigma = \frac{-8 - (-4)}{2} = \frac{-4}{2} = -2$$

**角度：**
- $k = 0$：$\varphi = \frac{(2 \times 0 + 1)\pi}{2} = \frac{\pi}{2} = 90°$
- $k = 1$：$\varphi = \frac{(2 \times 1 + 1)\pi}{2} = \frac{3\pi}{2} = -90°$（或 $270°$）

**结论：** 渐近线质心为 $\sigma = -2$，角度为 $\pm 90°$

---

### ④ 分离点/会合点（4分）

由特征方程 $1 + \frac{K(s+4)}{s(s+2)(s+6)} = 0$，得：

$$K = -\frac{s(s+2)(s+6)}{s+4} = -\frac{s^3 + 8s^2 + 12s}{s+4}$$

令 $\frac{dK}{ds} = 0$：

设 $N(s) = s^3 + 8s^2 + 12s$，$D(s) = s + 4$

$$\frac{dK}{ds} = -\frac{N'(s)D(s) - N(s)D'(s)}{D^2(s)} = 0$$

其中 $N'(s) = 3s^2 + 16s + 12$，$D'(s) = 1$

分子为零：
$$(3s^2 + 16s + 12)(s+4) - (s^3 + 8s^2 + 12s) = 0$$

展开并合并：
$$2s^3 + 20s^2 + 64s + 48 = 0$$

即：
$$s^3 + 10s^2 + 32s + 24 = 0$$

**求解与验证：**
- 数值求解得：$s_1 \approx -0.92$，$s_2 \approx -4.54$
- 验证：$s \approx -0.92$ 不在实轴根轨迹段 $[-4, -2]$ 内
- $s \approx -4.54$ 也不在 $[-4, -2]$ 内

**结论：** 该根轨迹在实轴上无分离点/会合点（或：分离点方程的根均不在实轴根轨迹段上）

---

### ⑤ 当 $K = 10$ 时的极点位置（6分）

**特征方程：**
$$s(s+2)(s+6) + 10(s+4) = 0$$

展开：
$$s^3 + 8s^2 + 12s + 10s + 40 = 0$$

即：
$$s^3 + 8s^2 + 22s + 40 = 0$$

**数值求解：**
- 实根：$s_1 \approx -4.5$
- 分解：$(s + 4.5)(s^2 + 3.5s + 8.9) \approx 0$
- 共轭复根：$s_{2,3} = \frac{-3.5 \pm \sqrt{12.25 - 35.6}}{2} \approx -1.75 \pm j2.42$

**主导极点判定：**
共轭复根 $s_{2,3} \approx -1.75 \pm j2.42$ 距离虚轴更近，为主导极点。

**结论：** 当 $K = 10$ 时，闭环极点约为：
- $s_1 \approx -4.5$
- $s_{2,3} \approx -1.75 \pm j2.42$

## 附录：关键易错点（供教学参考）

1. **实轴判别法应用错误**：错误计算实轴某段右侧的极点零点总数，或误判奇偶性
2. **渐近线质心计算错误**：忘记减去零点之和，或符号计算错误
3. **渐近线角度计算错误**：混淆 $n-m$ 的值，导致角度计算错误
4. **分离点方程求导错误**：对 $K = -N(s)/D(s)$ 求导时符号出错
5. **分离点未验证**：求出分离点后未检验其是否位于实轴根轨迹段内
6. **K=10极点估算错误**：特征方程展开错误，或数值估算偏差过大
