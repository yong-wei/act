# 自动控制原理 — 统一术语与符号表

本文件为课程内容创作提供统一的术语、符号和命名约定。所有 `authoring/lessons/` 下的讲义、教案、互动页面和媒体清单应遵守本表中的定义。

**维护规则**：新单元引入新术语时，必须同步更新本表。若发现现有讲义中的术语或符号与本表冲突，以本表为准并修正讲义。

---

## 一、符号书写约定

### 1.1 通用规则

| 类别 | 约定 | 示例 |
|------|------|------|
| 变量 | 斜体 | $y(t)$、$K$、$\omega$ |
| 函数/算子 | 斜体 | $G(s)$、$H(s)$ |
| 虚数单位 | 罗马体 | $\mathrm{j}$ 或 $j$（统一用 $j$） |
| 微分算子 | 斜体 $s$ | $s = \sigma + j\omega$ |
| 向量/矩阵 | 粗斜体 | 暂不涉及 |
| 默认对象 / 开环传递函数 | 斜体函数 | $G(s)$ |
| 默认闭环传递函数 | 大写希腊字母 | $\Phi(s)$ |

### 1.2 关键符号统一

| 符号 | 含义 | 备注 |
|------|------|------|
| $r(t)$ | 期望输入 / 参考输入 | 1-1 引入 |
| $y(t)$ | 实际输出 | 1-1 引入 |
| $y_m(t)$ | 测量输出 | 1-1 引入 |
| $e(t)$ | 误差信号，$e(t) = r(t) - y_m(t)$ | 1-1 引入 |
| $u(t)$ | 控制输入 / 控制信号 | 1-2 引入船舶建模输入；模块2正式系统化 |
| $G(s)$ | 被控对象传递函数；默认也表示开环传递函数 | **默认开环使用此记法** |
| $\Phi(s)$ | 闭环传递函数 | **统一使用此记法**，不用 $G_{\mathrm{c}}(s)$ 或 $G_c(s)$ |
| $L(s)$ | 环路开环传递函数 | 通常为 $C(s)G(s)H(s)$，用于 Bode 与稳定裕度分析 |
| $H(s)$ | 反馈通路传递函数 | 模块2引入 |
| $K$ | 增益（泛指比例系数） | 1-2 引入船舶模型控制增益；1-3 进入参数变化主线 |
| $s$ | 复变量，$s = \sigma + j\omega$ | 1-2 引入 |
| $\omega$ | 角频率 (rad/s) | 1-4 引入 |
| $\varphi$ | 相位角 | 1-4 引入 |
| $\sigma$ | 实部 | 1-2 引入 |
| $M_p$ | 超调量（百分比） | 1-3 首次出现，模块2正式定义 |
| $t_s$ | 调节时间 | 1-3 首次出现，模块2正式定义 |
| $t_r$ | 上升时间 | 模块2引入 |
| $\zeta$ | 阻尼比 | 模块2引入 |
| $\omega_n$ | 无阻尼自然频率 | 模块2引入 |

## 二、术语对照表

### 2.1 模块1已引入的术语

#### 控制系统基础（1-1）

| 中文术语 | 英文 | 定义 | 引入单元 | 备注 |
|---------|------|------|:---:|------|
| 控制系统 | control system | 让对象持续朝期望状态工作的整体结构，包含对象、控制器、执行器、传感器及信息链路 | 1-1 | 全课程最顶层概念 |
| 对象 / 被控对象 | plant / controlled object | 被控制的物理过程或设备 | 1-1 | 在后续单元中常与"系统"互换，但"对象"强调物理本体 |
| 控制器 | controller | 根据目标与测量结果作出决策的环节 | 1-1 | |
| 执行器 | actuator | 把控制决策真正施加到对象上的装置 | 1-1 | |
| 传感器 | sensor | 获取对象状态或输出信息的装置 | 1-1 | |
| 期望输出 | desired output / reference input | 我们希望系统达到的状态，记为 $r(t)$ | 1-1 | 后续统一称"参考输入"或"期望输入" |
| 实际输出 | actual output | 系统当前真实呈现的状态，记为 $y(t)$ | 1-1 | |
| 测量输出 | measured output | 传感器测得的输出值，记为 $y_m(t)$ | 1-1 | 理想情况下 $y_m(t) = y(t)$，实际中存在测量噪声 |
| 误差 | error | 期望输出与测量输出的差值，$e(t) = r(t) - y_m(t)$ | 1-1 | 控制器真正关心的量 |
| 反馈 | feedback | 把输出信息送回比较与决策环节的机制 | 1-1 | 课程核心思想 |
| 开环控制 | open-loop control | 不利用输出信息修正控制动作的方式 | 1-1 | |
| 闭环控制 | closed-loop control | 利用输出信息持续修正控制动作的方式 | 1-1 | |
| 扰动 | disturbance | 来自外界或对象内部、会破坏目标实现的影响 | 1-1 | |
| 测量噪声 | measurement noise | 来自传感器或测量链的附加误差 | 1-1 | |
| 课程总图 | course map | 整门课程的知识结构地图，以五个连续问题为主线展开 | 1-1 | 模块1的核心交付物之一 |

#### 模型与极点（1-2）

| 中文术语 | 英文 | 定义 | 引入单元 | 备注 |
|---------|------|------|:---:|------|
| 模型 | model | 保留对象主要动态关系、省去次要细节的数学描述 | 1-2 | 课程中主要指线性定常模型 |
| 传递函数 | transfer function | 在零初始条件下，输出拉氏变换与输入拉氏变换之比，记为 $G(s)$ | 1-1（预览）| 1-2建立概念直觉，模块2正式定义 |
| 极点 | pole | 使传递函数分母为零的 $s$ 值，决定系统自然演化方式的关键坐标 | 1-1（预览） | 1-2正式进入模型与极点主线；与"特征根"等价 |
| 特征方程 | characteristic equation | 令传递函数分母等于零得到的代数方程 | 1-2 | |
| 特征根 | characteristic root | 特征方程的解，即极点 | 1-2 | 与"极点"等价使用 |
| 复平面 | complex plane / $s$-plane | 以实部 $\sigma$ 为横轴、虚部 $j\omega$ 为纵轴的平面，用于标注极点位置 | 1-1（预览） | 1-2正式展开；也称 $s$ 平面 |
| 实部 | real part | 复数的实数分量 $\sigma$，关联衰减/发散倾向 | 1-1（预览） | 1-2正式展开 |
| 虚部 | imaginary part | 复数的虚数分量 $\omega$，关联振荡倾向 | 1-1（预览） | 1-2正式展开 |
| 共轭复数对 | complex conjugate pair | 形如 $\sigma \pm j\omega$ 的一对极点，使响应带有振荡成分 | 1-2 | |
| 主导极点 | dominant pole(s) | 离虚轴最近、对系统行为影响最大的极点 | 1-2（直觉层）| 模块3正式定义 |

#### 根轨迹与时域（1-3）

| 中文术语 | 英文 | 定义 | 引入单元 | 备注 |
|---------|------|------|:---:|------|
| 根轨迹 | root locus | 当某个参数（通常为增益 $K$）从零变到无穷时，闭环极点在复平面上移动的路径 | 1-1（预览） | 1-3建立雏形直觉，模块3给出正式法则 |
| 时域响应 | time-domain response | 输出 $y(t)$ 随时间变化的过程曲线 | 1-1（预览） | 1-3正式组织为时域主线 |
| 阶跃响应 | step response | 输入为单位阶跃函数时的系统输出过程 | 1-1（预览） | 1-3正式组织为时域主线 |
| 超调量 | overshoot / percent overshoot | 响应峰值超出稳态值的最大百分比，记为 $M_p$ | 1-3（首次出现）| 模块2正式定义与计算 |
| 调节时间 | settling time | 响应进入并保持在稳态值附近容许带内所需的时间，记为 $t_s$ | 1-3（首次出现）| 模块2正式定义与计算 |
| 闭环极点 | closed-loop pole | 闭环传递函数分母的根，决定了闭环系统的动态行为 | 1-3 | |
| 重实极点 | repeated real pole | 两个极点重合在实轴上同一点的情况 | 1-3 | 标记"单调区"与"振荡区"的过渡点 |
| 参数扫描 | parameter sweep | 系统性地改变某一参数并观察极点与响应的连续变化 | 1-3 | |

#### 频域与三域（1-4）

| 中文术语 | 英文 | 定义 | 引入单元 | 备注 |
|---------|------|------|:---:|------|
| 频域响应 | frequency-domain response | 系统对不同频率正弦输入的稳态响应特性，表现为幅值变化和相位变化 | 1-1（预览） | 1-4正式组织为频域主线 |
| 幅值变化 | amplitude change / magnitude response | 输出正弦幅值 $B$ 与输入正弦幅值 $A$ 在不同频率下的比值变化 | 1-4 | |
| 相位变化 | phase change / phase response | 输出正弦相对于输入正弦的相位偏移 $\varphi$ | 1-4 | |
| 复平面表征 | complex-plane representation | 从极点位置和迁移趋势观察系统结构 | 1-4 | 三域之一 |
| 时域表征 | time-domain representation | 从输出随时间的过程曲线观察系统表现 | 1-4 | 三域之一 |
| 频域表征 | frequency-domain representation | 从对不同频率输入的响应差异观察系统特性 | 1-4 | 三域之一 |
| 三域并置 | three-domain juxtaposition | 将复平面、时域、频域三种表征放在同一框架下理解同一系统 | 1-4 | 模块1的核心方法论 |
| 多表征阅读 | multi-representation reading | 用多种表征方式互相印证地理解同一系统行为的习惯 | 1-4 | |

#### 平台与三域联动（1-5）

| 中文术语 | 英文 | 定义 | 引入单元 | 备注 |
|---------|------|------|:---:|------|
| 三域联动 | three-domain linkage | 同一参数变化在复平面、时域、频域三张图中同步呈现的联动关系 | 1-5 | |
| Bode 图 | Bode plot | 频域响应的图形表示，包含幅频曲线和相频曲线两张子图，横轴均为对数频率 | 1-1（预览） | 1-5 定性读图，模块2-3正式展开 |
| 相位裕度 | phase margin | 在增益穿越频率处，相频曲线距离 $-180^\circ$ 的余量 | 1-1（预览） | 1-5 读值比较，模块3正式定义与判据 |
| 截止频率（开环）/ 增益穿越频率 | gain crossover frequency | 环路开环幅频曲线穿越 0 dB 线处的频率 | 1-4（预览） | 后续单元沿用“截止频率”；不等同于闭环带宽 |
| 闭环带宽 | closed-loop bandwidth | 闭环传递函数幅值相对低频值下降 3 dB 时对应的频率；具体通道必须明确 | 1-4（预览） | 常见简称“带宽” |
| 临界稳定 | marginal stability | 闭环无右半平面极点、虚轴上存在单极点且其余极点位于左半平面；自由响应含不衰减分量 | 1-5 | 重复虚轴极点不属于该状态 |
| 稳定边界 | stability boundary | 复平面虚轴，系统从稳定过渡到不稳定的分界线 | 1-5 | |
| 根轨迹图 | root locus plot | 复平面上闭环极点随参数变化的轨迹图 | 1-5 | |
| 阶跃响应图 | step response plot | 时间轴上输出对单位阶跃输入的响应曲线 | 1-5 | |
| 三域对照表 | three-domain comparison table | 将不同参数下的三域观察并列整理的结构化表格 | 1-5 | 本单元核心输出格式 |

## 三、命名约定速查

### 3.1 文件命名

| 文件类型 | 命名模式 | 示例 |
|------|------|------|
| 讲义 | `{module}-{unit}-handout.md` | `1-1-handout.md` |
| BOPPPS 教案 | `{module}-{unit}-boppps.md` | `1-1-boppps.md` |
| 互动课设计 | `{module}-{unit}-interactive-page.md` | `1-1-interactive-page.md` |
| 媒体清单 | `{module}-{unit}-multimedia.md` | `1-1-multimedia.md` |

### 3.2 媒体资源命名

| 前缀 | 用途 | 示例 |
|:---:|------|------|
| `h-` | 讲义（handout）用图 | `h-01-step-response.png` |
| `ic-` | 互动课（interactive course）用图 | `ic-01-root-locus-demo.png` |
| `sh-` | 共用（shared）图 | `sh-01-block-diagram.png` |

### 3.3 代码中的符号命名

在 Python 仿真脚本或前端代码中，遵循以下变量命名：

| 数学符号 | 代码变量名 | 说明 |
|------|------|------|
| $K$ | `K` | 增益 |
| $s$ | （不使用） | $s$ 是拉氏域算子，不在代码中直接出现 |
| $\omega$ | `omega` | 角频率 |
| $\zeta$ | `zeta` | 阻尼比 |
| $\omega_n$ | `wn` | 无阻尼自然频率 |
| $M_p$ | `Mp` 或 `overshoot` | 超调量 |
| $t_s$ | `ts` 或 `settling_time` | 调节时间 |
| $G(s)$ | `G` | 传递函数（通常用 control 库的 `tf` 对象表示） |
| $\Phi(s)$ | `Phi` | 闭环传递函数；带参数时可写作 `Phi2`、`PhiK` 等 |
