# 3-1 作者态交接简报

更新时间：2026-04-17
状态：authoring-bridge

本文件不是 `3-1` 的正式讲义、教案或互动页成稿，而是后续作者态续写、改写、补写 `handout.md`、`boppps.md`、`interactive-page.md`、`multimedia.md` 前必须先对齐的共用约束。

## 一句话主线

`3-1` 不是把模块2的一二阶结论扩展成“更多公式”，而是把学生已经熟悉的时域/频域对象语言推进成一条新的机理主线：

`稳定底线 -> 极点即模态 -> 主导极点近似 -> 双域证据核验 -> 卷积与模态叠加收束`

## 课堂固定产出

后续所有作者态成稿都必须围绕以下 3 项学生产出组织，不得删成“看图听结论课”：

1. `稳定与模态判断记录`
   至少覆盖左半平面 / 虚轴 / 右半平面的稳定含义，以及负实极点、左半平面共轭复极点、右半平面极点、重根对应的动态特征。
2. `主导极点近似证据表`
   必须同时包含三模型时域对照、附加模态退场快慢判断，以及“`3~5` 倍更靠左只是经验起点”的边界说明。
3. `双域近似解释卡`
   必须同时回答两个问题：为什么某个附加极点在时域里可以近似忽略；为什么还必须回到 `Bode` 图检查它是否侵入主要带宽。

## 对 handout 的约束

- 讲义必须围绕“为什么高阶系统仍常能用低阶模型理解”这一单一问题组织，不得拆成“稳定一节 + 模态一节 + 频域一节”的并列知识点堆放。
- 必须显式出现以下 5 个证据节点：
  - 半平面稳定判据；
  - 一般模态展开与重根项；
  - 三模型时域对照；
  - 三模型 `Bode` 对照；
  - 卷积与模态叠加收束。
- 时域近似部分必须压实：主导极点重要，但不是唯一证据；附加模态退场快慢、模态权重、重根/聚集极点都会改写近似可靠性。
- 频域近似部分必须压实：是否可忽略，取决于附加极点对应转折频率是否侵入主要工作带宽，而不是只看“更靠左”。
- 不得把 `3-1` 写成：
  - 劳斯判据课；
  - 根轨迹预习课；
  - Nyquist/Bode 判稳课；
  - 控制器调参或补偿设计课。

## 对 BOPPPS 的约束

- `Bridge-in` 必须从“三个系统拥有同一对主导极点，却呈现不同响应”切入，而不是从“今天继续学高阶系统”切入。
- `Participatory Learning` 至少分成 4 段：
  - 稳定底线与极点位置；
  - 极点到模态的翻译；
  - 三模型时域近似判断；
  - 三模型频域近似核验与卷积收束。
- 教师介入点固定检查 3 件事：
  - 学生是否把“稳定”误当成“表现已经足够好”；
  - 学生是否把“主导极点相同”误当成“响应必然近似相同”；
  - 学生是否能把“带宽内外”说成近似是否成立的频域证据。

## 对 interactive-page 的约束

- 页面必须优先承载“判断 -> 对照 -> 解释 -> 核验”，不做连续调参式仿真试玩。
- 至少需要 5 类页面状态：
  - 稳定半平面判断态；
  - 极点与模态配对态；
  - 三模型时域对照态；
  - 三模型频域对照态；
  - 卷积与模态叠加解释态。
- 学生提交内容应直接对应三项固定产出，不额外发明与课堂目标无关的开放式互动。
- AI 只可用于“先自判、再对照、再回图核验”的证据校对，不可替学生直接给出最终判断。
