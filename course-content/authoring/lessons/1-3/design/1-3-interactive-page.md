**元素顺序**：标题 → 左侧情境要点 → 右侧导入漫画 → 底部问题句

- **标题**：拧一个旋钮，整条曲线就变了
- **标题说明**：自动舵上有一个增益旋钮。船还是那条船，反馈结构没有改——只把这个旋钮拧大了一点，航向修正就变快；再拧，曲线开始越过目标值并出现摆动。
- **左侧情境要点**：
  - 任何带可调参数的控制系统——电机转速环、温控箱 PID、机器人关节伺服——调参时都会出现类似模式
  - 1-2 建立了复平面这张**静态地图**：极点在左就收敛，在右就发散
  - 本讲的核心追问：**如果系统中有一个可调参数——比如增益——极点的位置会发生什么？响应又会跟着怎么变？**
- **右侧导入漫画**：`1-3-cover-comic.png`。画面中一只手正在拧动船桥控制台上的增益旋钮，背景中同时浮现复平面上两个极点沿实轴相向移动、时域响应从单调过渡到振荡、根轨迹分支从实轴离开的三张虚影图。
- **图下文案**：同一个旋钮，牵动复平面、时域和根轨迹三张图——本讲揭示这条链背后的代数事实。
- **底部问题句**：参数不是在直接"改曲线"，而是在"推极点"。理解了这条链，调参就不再是盲目拧旋钮——你是在复平面上推着一组坐标走，并预期每一步的后果。

**自包含检查**：漫画场景提出增益旋钮改变系统行为这一普遍现象，左侧情境衔接 1-2 的静态地图并引出本讲追问，学生明确本讲要回答的核心问题。

## 步骤 4｜开环与闭环——同一个增益，两种命运

**对应讲义**：二

**模板**：`visual.blockDiagram` + `content.reveal` + `content.code` + 1 题（`activity.panel` 单选）

**学生状态**：默认显影第 1 层展开，第 2-3 层由教师控制释放；题目锁定，教师发放后作答

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：闭环推导链分三层逐步显影——(1)开环证明→(2)闭环三行代数推导→(3)关键对比句。每题独立提交。显影链保留全部公式。

**元素顺序**：标题 → 原生开环/闭环方框图 → 2.1 开环证明（代码+图1-3-1+结论，第1层常显）→ 2.2 闭环推导（三行代数→Φ(s)→特征方程，第2层教师释放）→ 关键对比句（第3层教师释放）→ 单选互动题

- **标题**：开环与闭环——同一个增益，两种命运
- **标题说明**：同一个增益 $K$，放在开环中和放在闭环中，扮演的角色完全不同。

**第 1 层：开环——增益只按比例缩放响应**（常显）

- **对象**：$G_0(s) = \frac{1}{s(s+4)}$
- **开环传递函数**：$G_{\text{开}}(s) = \frac{K}{s(s+4)}$
- **关键观察**：$K$ 只在分子上——分母 $s(s+4)$ 不受 $K$ 影响。开环特征方程始终是 $s(s+4)=0$，极点固定在 $s=0$ 和 $s=-4$，不随 $K$ 改变。
- **MATLAB/Octave 验证**：
  ```matlab
  G0 = tf(1, [1 4 0]);
  K1 = 1; K2 = 2; K3 = 4;
  step(K1*G0, K2*G0, K3*G0);  % 三条曲线形态完全一致，仅幅度不同
  pole(K1*G0)                   % 始终返回 [0; -4]
  ```
- **图 1-3-1**：开环系统在三组增益下的单位阶跃响应——三条曲线保持相同形态，按增益成比例缩放。
- **图下文案**：开环中增益 $K$ 只缩放输出，不改变极点位置因而也不改变响应形态。
- **结论**：开环下调节 $K$，只是在放大或缩小同一条响应曲线。$K$ 没有进入特征方程，行为模式固守不变。

**第 2 层：闭环——增益进入了特征方程**（教师释放）

- **结构**：单位负反馈——输出 $y(t)$ 被测量送回输入端，与期望 $r(t)$ 比较形成误差 $e(t)$，误差放大 $K$ 倍后驱动对象 $G_0(s)$。
- **推导**（三步）：
  1. 误差与测量：$E(s) = R(s) - Y(s)$
  2. 输出由误差驱动：$Y(s) = E(s) \cdot K \cdot G_0(s)$
  3. 消去 $E(s)$：$Y(s) = (R(s)-Y(s)) \cdot K G_0(s)$

  整理：$Y(s) \cdot (1 + K G_0(s)) = R(s) \cdot K G_0(s)$

  **闭环传递函数**：$\Phi(s) = \frac{Y(s)}{R(s)} = \frac{K G_0(s)}{1 + K G_0(s)}$

- 代入 $G_0(s) = 1/[s(s+4)]$：

  $$\Phi(s) = \frac{K}{s^2 + 4s + K}$$

  **闭环特征方程**：$s^2 + 4s + K = 0$

- **MATLAB 验证**：
  ```matlab
  K = 3;
  Phi = feedback(K*G0, 1);
  pole(Phi)  % 极点已随 K 移动，不再是 [0; -4]
  ```

**第 3 层：关键对比**（教师释放）

- **原生方框图**：使用 `visual.blockDiagram` 表达开环与单位负反馈闭环。切换到闭环时高亮从 $Y(s)$ 返回比较点的反馈通路，并保持 $R(s)$、比较点、$K$、$G_0(s)$、$Y(s)$ 的连接关系可读。图 1-3-2 仅作为加载失败时的后备证据。
- **图下文案**：同一增益，两种命运——结构把 $K$ 从分子推进了分母。
- **标志性结论**：反馈闭环使增益进入特征方程。每取一个新的 $K$ 值，特征方程就变了，它的根——闭环极点——也随之改变。

**主要公式与符号说明**：

| 符号 | 含义 |
|------|------|
| $G_0(s)$ | 开环对象传递函数，本讲使用 $1/[s(s+4)]$ |
| $K$ | 比例增益，唯一连续可调参数 |
| $\Phi(s)$ | 闭环传递函数，$\Phi(s) = K G_0(s) / [1 + K G_0(s)]$ |
| $s^2 + 4s + K = 0$ | 闭环特征方程——$K$ 出现在系数中 |

**互动题**（单选）：同一个增益 $K$，在开环和闭环中扮演的角色有何根本不同？
- A. 开环中 $K$ 改变极点位置，闭环中 $K$ 只缩放输出
- B. 开环中 $K$ 只缩放输出，闭环中 $K$ 进入了特征方程并改写极点
- C. 开环和闭环中 $K$ 的作用完全相同
- D. 开环中 $K$ 改变稳定性，闭环中 $K$ 改变稳态值
- 答案：B

**自包含检查**：开环证明（代码+极点不变）和闭环推导（完整三行代数）均完整呈现于显影层中。学生通过显影链看到 $K$ 从分子"跳"进分母的全过程。对比图提供视觉锚点。

## 步骤 5｜极点移动有连续性，响应变化也有连续性

**对应讲义**：三

**模板**：`content.reveal` + `content.table`

**学生状态**：默认显影第 1 层展开（极点表达式+三区段分析），第 2 层（三条结论）由教师控制释放；无作答

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：三区段分析（0<K<4 / K=4 / K>4）逐段显影，每段配合极点坐标和文字描述。三条结论作为独立显影层最后释放。不设互动题——本页是纯理解页。

**元素顺序**：标题 → 极点表达式 $s_{1,2}=-2\pm\sqrt{4-K}$ → 三区段分析（三段逐层显影）→ 三条结论（最终显影层）

- **标题**：极点移动有连续性，响应变化也有连续性
- **标题说明**：从闭环特征方程 $s^2+4s+K=0$ 出发，直接求根。极点随 $K$ 的移动路径就写在这个表达式里。

**第 1 层：三区段分析**（常显）

- **极点表达式**：$s_{1,2} = -2 \pm \sqrt{4-K}$

- **区段一：$0 < K < 4$ —— 两个负实极点**
  - 根号内 $4-K$ 为正。$K \to 0$ 时 $\sqrt{4-K} \approx 2$，极点约在 $s=0$ 和 $s=-4$
  - $K$ 增大 → 根号值缩小 → 两个极点沿实轴**相向而行**：一个从 $-4$ 向右，一个从 $0$ 向左
  - 响应始终单调。更靠右的极点向左移动 → 衰减在加快 → 系统在变快

- **区段二：$K = 4$ —— 重实极点**
  - 根号内为零 → 两个极点重合在 $s = -2$
  - 这是过渡位置——极点从"都在实轴上"走到"准备离开实轴"
  - 对应**临界阻尼**状态

- **区段三：$K > 4$ —— 共轭复极点**
  - 根号内为负 → $s_{1,2} = -2 \pm j\sqrt{K-4}$
  - 实部固定在 $-2$——衰减包络不再随 $K$ 加速
  - 虚部 $\sqrt{K-4}$ 随 $K$ 增大 → 振荡频率升高 → 摆动越来越密
  - 时域中开始出现超调和振荡

**各区段特征对照表**：

| K 范围 | 极点类型 | 极点表达式 | 响应特征 |
|:---:|------|------|------|
| $0 < K < 4$ | 两负实极点 | $-2 \pm \sqrt{4-K}$（实数） | 单调收敛，$K$↑ 变快 |
| $K = 4$ | 重实极点 | $s=-2$（二重） | 临界阻尼，单调中最快 |
| $K > 4$ | 共轭复极点 | $-2 \pm j\sqrt{K-4}$ | 衰减振荡，$K$↑ 振荡加密 |

**第 2 层：三条结论**（教师释放）

1. 极点移动是**连续的**——$K$ 连续增大，极点沿实轴滑行，会合，再平滑地离开实轴，整个过程没有跳跃。
2. 响应变化也是**连续的**——从单调到会合点到振荡，中间没有断层。
3. 参数的作用分为两个阶段：$0<K<4$ 时主导极点向左移动，单调响应逐渐加快；$K>4$ 后实部固定为 $-2$，虚部持续增大。速度与振荡的权衡来自同一特征方程，但两种变化并非在整个参数区间内同步发生。

**主要公式与符号说明**：

| 符号 | 含义 |
|------|------|
| $s_{1,2} = -2 \pm \sqrt{4-K}$ | 闭环极点随 $K$ 的解析表达式 |
| $\sqrt{4-K}$ | 判别项——正→实极点，零→重极点，负→复极点 |
| $j$ | 虚数单位，$j^2 = -1$ |

**自包含检查**：极点表达式→三区段分析→各区段特征对照表→三条结论。学生能从表达式出发独立理解极点迁移的完整轨迹，不需要参考讲义就能说出每个区段的极点类型和响应特征。

**第 3 层：$K=8$ —— 衰减振荡**（教师释放）

- $\Phi(s) = \frac{8}{s^2+4s+8}$，极点 $-2 \pm j2$

| 4 | $-2, -2$ | 单调，临界阻尼 | 0 | $\sim 2.37$s |

- **标题说明**：同一艘船，同一个航向保持回路，只改变比例增益 $K$。三次试验记录对应 $K=1, 4, 8$ 三个工作点。

| 工作点 | $K$ | 极点 | 模型内响应 | 指标说明 |
|:---:|:---:|------|------|------|

- $K > 4$ 后，实部永远停在 $-2$——衰减包络不再加速

  ```matlab
  G0 = tf(1, [1 4 0]);
  for K = [1 4 8]
      Phi = feedback(K*G0, 1);
      step(Phi); hold on;
  end
  legend('K=1','K=4','K=8');
  ```

- B. 不再加快（实部固定为 $-2$）
- C. 先加快后减慢
- D. 取决于输入信号

- **标题**：总结——参数变化与极点迁移
- **标题说明**：反馈结构使参数进入闭环特征方程，参数变化因而转化为闭环极点和时域行为的连续变化。

- **课程信息图**：`1-3-info.png`。以信息图形式组织本讲核心链路——上方开环vs闭环增益角色对比，中部 K 值三段论配合极点迁移箭头，下方根轨迹雏形与三个可带走判断。

**判断一：闭环让增益成为"结构变量"**
开环中增益只决定幅度；闭环中增益决定极点的位置——从而决定稳定与否、快慢和振荡倾向。这不是增益本身的魔力，而是反馈结构把增益推进了特征方程的分母。

**判断二：参数作用具有阶段性**
对于本讲考察的二阶无零点对象，$0<K<4$ 时主导实极点向左移动，单调响应逐渐加快；$K>4$ 后两极点实部固定为 $-2$，指数包络衰减率不再提高，而虚部和超调继续增大。实际调节时间还会受到振荡相位和误差带穿越影响。

**判断三：根轨迹是"参数→极点→行为"这条链的可视化**
不需要记住绘制规则——那是模块 3 的任务。现在只需要把根轨迹当作一张地图来读：起点告诉你零增益时系统在哪儿，轨迹方向告诉你参数增大时往哪儿走，关键位置告诉你什么地方的行为会发生质变。

**本讲主要内容**：
- 开环中 $K$ 在分子上只缩放输出；闭环中 $K$ 进入特征方程分母改写极点
- 极点随 $K$ 连续迁移：实极点（$0<K<4$）→ 重极点（$K=4$）→ 共轭复极点（$K>4$）
- 时域行为随区段连续变化：单调收敛 → 临界阻尼 → 衰减振荡
- 根轨迹雏形：将 $K$ 扫描下的极点路径连成复平面上的连续曲线

**本讲边界（局限性）**：
- 只考察了二阶无零点对象——有零点的对象可能出现非单调的超调变化
- 会合点恰为开环极点中点的规律只在无零点二阶系统中严格成立
- 根轨迹的正式法则（幅角条件、渐近线、出射角）尚未引入——那是模块 3 的内容

**重点难点**：
- **重点**：闭环特征方程 $s^2+4s+K=0$ 的推导——$K$ 从分子"跳"进分母是全文最关键的一步
- **难点**：$K>4$ 后实部固定为 $-2$——为什么衰减不再加速？原因在于根之和原则（两极点实部之和恒等于开环极点实部之和 $-4$），模块 3 将给出完整证明

**拓展思考**：
本讲全程使用比例控制 $C(s)=K$——最简单的控制器结构。如果换成 $C(s)=K/s$（积分控制）或 $C(s)=Ks$（微分控制），参数扫描下极点还会沿类似的路径移动吗？记录你的猜测，模块 3 和 4 会给出精确答案。
