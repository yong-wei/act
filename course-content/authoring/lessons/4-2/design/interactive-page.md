## 文档职责
- 本文件只保留 4-2 当前审定后的 13 步课堂蓝图。
- 作者态与 `interactive-contract.yaml` 必须同名、同序、同互动类型。
- 本课唯一正式产物是“单结构首轮起步卡”；复合结构骨架一律留给 4-3。

## 本轮整改结论
- 删除原 `step-05` 的“课程总结信息图”步骤，后续整体前移编号。
- `step-03` 只保留判断链与参数方向提示，不再设置学生作答区。
- `step-04` 上方静态表至少复现讲义表 3 前三列，下方作答改为多选矩阵。
- `step-05` 与 `step-07` 改为 Rust/WASM 驱动的原生统一面板，四面板板式 + 底部增益控件 + 实时性能指标。
- `step-06`、`step-08`、`step-09` 采用逐步显影，作答区统一左右双栏，题面写在卡片标题中，不再在卡体重复文案。
- `step-10` 作答区同样改为左右双栏；结构图与四联图均读取 runtime 媒体。
- `step-11` 起步卡工作区简化为六字段最小卡片。
- `step-12` 后测与总结彻底分离，后测只检查判断链。
- 本次补充硬约束：互动页必须按讲义逻辑与内容证据排序，不以大图首屏效果为目标；结构图、四联图和对比图只能出现在其对应原理、公式或分析链之后。
- `step-05` 与 `step-07` 的案例没有明确讨论可行域，统一面板不得绘制可行域，也不得继承 4-1 的可行域夹具。
- `step-06`、`step-08`、`step-09` 的逐步显影必须包含后续层级，不能只显示第一层。

## 逐步说明

### step-03｜判断链静态页
- 必须完整保留 `L(s)=C(s)P(s)`。
- 必须完整列出六步判断链。
- 必须给出参数方向句式提示。
- 不设置学生作答区，也不显示“本页无需提交”类占位文案。

### step-04｜结构工具箱
- 上方先呈现“结构工具箱总表”，完整保留讲义表 3 的关键列：
  - 结构名称；
  - 数学表达式；
  - 最小作用语义；
  - 首轮使用边界。
- 数学表达式至少覆盖：
  - `C_P(s)=K_p`；
  - `C_{PI}(s)=K_p+\dfrac{K_i}{s}`；
  - `C_{PD}(s)=K_p+K_d s`；
  - `C_{PID}(s)=K_p+\dfrac{K_i}{s}+K_d s`；
  - `C_{lead}(s)=K\dfrac{Ts+1}{\alpha Ts+1}, 0<\alpha<1`；
  - `C_{lag}(s)=K\dfrac{Ts+1}{\beta Ts+1}, \beta>1`；
  - `u(s)=C(s)(r(s)-y(s))+F(s)r(s)`。
- 下方学生区改为多选矩阵，允许同题多选。
- `PID` 只以“压后进入候选”的原则卡出现，不作为默认答案。

### step-05｜客船入口
- 图片区改为 Rust/WASM 原生统一面板，不再复用 4-1 静态 PNG。
- 板式保持四面板阅读逻辑，下方统一设置增益控件。
- 必须实时显示性能指标，如 `Mp`、`t_s`、`ω_c`、`PM`。
- 讲义没有讨论可行域，本页不得绘制可行域；分析请求必须显式不携带 `feasibleRegion`。
- 学生作答区保持左右双栏。

### step-06｜客船展开
- 题面不得隐藏。
- 分析过程必须逐步显影，至少包含“锁定对象 -> 写出基线 -> 对照表 5 -> 形成起步句”四层，不能只剩第一层或结论性文本。
- 页面必须出现讲义“表5”并作为对比表。
- 学生作答区左右双栏，题目写在卡片标题中，不再重复卡片文案。

### step-07｜平台入口
- 与客船入口一致，改为 Rust/WASM 原生统一面板。
- 保持现有图片对应的四面板信息结构。
- 底部统一放置增益控件，指标实时刷新。
- 讲义没有讨论可行域，本页不得绘制可行域；分析请求必须显式不携带 `feasibleRegion`。
- 学生作答区左右双栏。

### step-08｜平台展开
- 必须按讲义分析链逐步显影，至少包含“锁定对象 -> 定位中频 -> 比较 PI 与 PD/超前 -> 形成起步句”四层。
- 必须通过对比表说明为何先选 `PD/超前`，而不是先补 `PI`。
- 学生作答区左右双栏，题目写在标题中。

### step-09｜输入前馈
- 结构图与四联图都必须读取 runtime 媒体。
- 公式必须正确渲染，禁止双反斜杠误写。
- 必须严格按讲义顺序实现：先给“参考通道提前出力、反馈保底”的原理逐步显影；再给 runtime 结构图；再围绕“闭环结果—验证目标”做分析逐步显影；最后给四联对比图片。
- 原理显影和分析显影是两条独立显影链，均要有后续层级，不能只显示第一层。
- 学生作答区左右双栏，不加重复文案。

### step-10｜扰动前馈
- 必须严格按讲义顺序实现：先给扰动前馈的公式与原理；再给 runtime 结构图；再给抗扰分析逐步显影；随后给边界结论；最后给四联对比图。
- 结构图、公式链、四联图都必须正常显示，但结构图不得被放在公式和原理之前。
- 强调“前馈削弱误差来源，反馈负责保底”的边界。
- 学生作答区左右双栏，不加重复文案。

### step-11｜起步卡工作区
- 只保留六字段：
  - 当前任务
  - 最紧矛盾
  - 首选单结构
  - 参数起步方向
  - 预期收益
  - 主要代价
- 删除“留给 4-3 的问题”等扩展字段。
- 工作区采用左右双栏。

### step-12｜后测
- 后测只检查判断链和边界意识，不与总结混页。
- 作答区维持简化布局，双栏展示题卡即可。

### step-13｜收束
- 只做五句带走与去向说明。
- 明确提示 4-3 才进入复合结构骨架。

## 媒体与公式口径
- 正式互动页面只允许读取 runtime 媒体路径，不得回读 authoring `media/processed`。
- React + KaTeX 场景下，公式字符串必须直接写 LaTeX 命令，禁止使用 `String.raw` 再叠加双反斜杠。
- 客船与平台入口页采用原生统一面板；输入前馈与扰动前馈仍保留 runtime 结构图与四联图。
- 原生统一面板只有在讲义明确讨论可行域时才绘制可行域；4-2 客船与平台案例不绘制可行域。
