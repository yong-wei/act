## 文档职责

- 本文件是 `3-4` 作者态互动页面蓝图，负责把讲义中的主图读图、参数窗口判断、对象化三域验证与广义根轨迹改写成学生可直接阅读的页面内容。
- 同目录 `interactive-contract.yaml` 是机读真源；两者必须在步骤顺序、标题、页面模板、互动类型、教师控制和学生默认状态上逐项对齐。
- 本课保留 `3-4` 既有 `17` 步结构，不压缩为对比海报，也不把广义参数判断退回课末附注。
- 页面蓝图 prose 只写学生真正会看到的内容与阅读顺序，不把实现术语、审查术语和脚本口令写成页面正文。

## 表述规则

- 每一步都必须回答四件事：对象是什么、正在判断什么、关键证据在哪里、结论如何接回“关键节点 -> 参数窗口 -> 三域验证 -> 广义参数”主线。
- 图片、根轨迹图、Bode 图和航迹图一律服从讲义证据顺序，不得抢在题面、公式链和判断语句之前。
- 逐步显影页中，题面、对象、已知条件与目标判断固定可见；可以隐藏的是求解步骤，不是题面本身。
- 除前测、后测与专门题组页外，单页作答默认不超过两张卡；本课的例题页、判断页和比较页均采用轻量双卡或单卡提交。

## 逐步说明

## step-01｜回到地图：从 `3-3` 法则走向 `3-4` 判断
- 页面骨架：上半区放 `3-3 -> 3-4 -> 3-5` 路径图，中部放主问题卡，下半区放边界卡。
- 静态承载内容 / 页面正文内容：标题句写“`3-3` 解决的是法则与稳定边界，`3-4` 要把这些法则翻译成真正可执行的工程判断”。主问题卡写“沿既有根轨迹继续调增益时，哪些工作点只是还稳定，哪些工作点才值得选用”。边界卡写“本课不重讲 `3-3` 法则证明，不进入零点、`PD` 与模块 `4` 的设计任务”。
- 证据顺序：先看路径，再读主问题，最后读边界。
- 互动升级点：本页只阅读，不安排作答。
- 教师控制：四项控制均不适用。
- 学生默认状态：页面全部可见。
- 本页脱离讲稿后的自包含检查：学生只看本页，也知道 `3-4` 是把法则翻译成判断。
- 预览口径：学生预览进入本页时，应先看到路径与边界，而不是任何根轨迹图。

## step-02｜问题提出与三张记录表：稳定之后还要回答什么
- 页面骨架：上半区放核心问题卡，中部放三张记录表，下半区放判断链摘要卡。
- 静态承载内容 / 页面正文内容：核心问题卡写“同样位于稳定窗口内的参数，也可能对应完全不同的速度、振荡、风险与工程后果”。中部表格不能只写三张记录表名称，而要直接写清三列内容：“记录表 / 要回答的问题 / 至少应包含的信息”。三行分别写“关键节点读图记录：主图上先看哪些位置，至少包含分离点、虚轴交点、主导极点候选、稳定窗口”“参数窗口判断表：哪些参数只是稳定、哪些参数更值得选用，至少包含根轨迹增益、实际控制器增益、非增益参数窗口、稳定性判断、性能趋势”“对象化验证记录：图上的判断落回真实对象后是否仍成立，至少包含时域后果、频域后果、主导极点近似是否可信、低中频近似与高频差异”。摘要卡写“三张记录表首尾相接：关键节点读图 -> 参数窗口判断 -> 对象化三域验证 -> 广义参数验证”。
- 证据顺序：核心问题卡 -> 三张记录表 -> 判断链摘要。
- 互动升级点：本页只阅读，不安排作答。
- 教师控制：四项控制均不适用。
- 学生默认状态：全部静态可见。
- 本页脱离讲稿后的自包含检查：学生能明确本课最后要交的不是一句结论，而是三份可回看的判断记录。
- 预览口径：三张记录表必须完整出现，不得退化成一句“形成记录”。

## step-03｜固定对象与三个版本：先暴露“稳定=可用”的第一误判
- 页面骨架：上半区放对象公式卡，中部放 `A/B/C` 版本表，下半区放三题初判。
- 静态承载内容 / 页面正文内容：对象卡写 `$G(s)=\\dfrac{0.01715K}{s(s+0.1)(s+2.14375)},\\ k=0.01715K$`。版本表给出 `A/B/C` 三个版本的 `K`、`k`、闭环极点特征与第一判断。三题初判围绕“谁最慢、谁最均衡、谁最冒险”展开，但只暴露误判，不提前公布标准排序。
- 证据顺序：对象与记号 -> 版本表 -> 三题初判。
- 互动升级点：入口快答只做误判暴露，不做长文本作答。
- 教师控制：教师独立释放作答与参考答案。
- 学生默认状态：对象卡与版本表可见，题卡默认隐藏。
- 本页脱离讲稿后的自包含检查：学生能读出三版是在同一对象、同一口径下比较。
- 预览口径：题卡不可抢在对象卡和版本表之前。

## step-04｜固定读图顺序：先骨架，再关键节点，再窗口，再后果
- 页面骨架：上半区放四步法卡片，下半区放排序区与误判提示。
- 静态承载内容 / 页面正文内容：四步法不能只保留四个短标签，而要把每一步真正看的对象与产出的判断写在卡片正文里。第 `1` 步写“看骨架：先看起点、终点和分支数量，判断对象的整体骨架”；第 `2` 步写“找关键节点：把分离点、虚轴交点和主导极点候选找出来，判断主导形态与边界位置”；第 `3` 步写“区分窗口：从这些节点走到稳定窗口与可接受窗口，判断参数处在窗口哪一侧”；第 `4` 步写“翻译后果：把图上的位置改写成参数语言和工程后果，说明快慢、振荡、裕量与风险”。误判提示写“不能因为某个点看起来顺眼，就跳过前两步直接宣布哪个版本更好”。
- 证据顺序：四步法卡片 -> 排序区 -> 误判提示。
- 互动升级点：学生任务是把四步法排成稳定读图动作链。
- 教师控制：教师独立释放作答与参考答案。
- 学生默认状态：卡片可见，排序区默认隐藏。
- 本页脱离讲稿后的自包含检查：学生能明确本课先训练读图顺序，再处理节点和窗口。
