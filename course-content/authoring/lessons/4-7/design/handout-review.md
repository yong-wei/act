---

## 0. 本单元要解决的问题

前几个单元已经给出了三类能力：

1. 在给定控制器结构时，通过优化方法确定参数；
2. 在执行机构、超调量、稳定裕度等约束下重新理解“最优”；
3. 当任务变化导致固定结构职责过载时，把结构本身有限地放入搜索空间。

这些能力仍然没有自动构成一个完整的控制器设计。真实工程中的控制器设计不是从“选一个算法”开始，也不是在“得到一组最优参数”处结束。它从任务需求开始，经由指标翻译、结构与参数设计、仿真验证、实现审查，最后形成一份可交付的控制器方案。

本单元的主线是：

> **把真实航向控制任务翻译成可计算、可验证、可交付的控制器设计问题，并解释最终响应曲线与性能指标在真实场景中的含义。**

本单元不再把 GA、PSO 或多结构编码作为讲述中心。它们只是设计链条中的求解工具。本单元真正要完成的是“任务书 → 指标合同 → 设计方案 → 测试证据 → 工程交付”的闭环。

## 1. 真实任务：舰船航向自动控制的工程委托书

### 1.1 工程背景

设船舶已经具备航向测量装置和舵机执行机构。控制系统接收期望航向 $r(t)$，根据实际航向 $\psi(t)$ 计算误差，并输出舵角指令 $\delta(t)$。控制目标不是单纯让曲线“看起来快”，而是在执行机构边界、稳定裕度和任务节律共同限制下，使船舶按任务要求完成航向控制。

闭环结构采用单位负反馈形式：

$$
e_\psi(t)=r(t)-\psi(t), \qquad \delta_c(t)=C(s)e_\psi(t),
$$

其中 $C(s)$ 为待设计控制器，$\delta_c(t)$ 为控制器输出的舵角指令。进入真实执行机构后，舵角还要接受幅值限制、速率限制和离散实现的影响。

### 1.2 本单元采用的教学任务书

本单元不是抽象地讨论“船舶航向控制”，而是把两个具有工程含义的任务放在同一个设计链条中：

- **任务 A：客船巡航航向保持**。客船在巡航状态下进行小到中等幅度航向调整，设计重点是平顺、不过度用舵、保持稳定裕度，避免乘坐舒适性和执行机构寿命受到影响。
- **任务 B：驱逐舰快速机动航向控制**。驱逐舰需要按照战术机动指令快速改变航向。参考航向每 $20\,\mathrm{s}$ 在两个方向之间切换，设计重点是切换段响应速度、下一段开始前的误差残留、舵角边界以及稳健性。

任务 A 不是为了再次证明旧设计正确，而是作为基线：它告诉我们固定结构在原任务下能够承担哪些控制职责。任务 B 是本单元的主设计任务：它要求我们把真实任务节律翻译为新的指标排序，并判断固定结构是否仍然够用。

表 4-7-1 给出本单元的教学任务书。

| 项目         | 任务 A：客船巡航航向保持     | 任务 B：驱逐舰快速机动航向控制                               |
| ------------ | ---------------------------- | ------------------------------------------------------------ |
| 任务语义     | 航向保持与平顺调整           | 周期性快速航向切换                                           |
| 参考信号     | 单次航向阶跃或低频航向调整   | 方波航向指令，切换周期 $T_{sw}=20\,\mathrm{s}$               |
| 教学仿真参考 | $r_p(t)=10^\circ \cdot 1(t)$ | $r_d(t)=10^\circ\operatorname{sgn}\left[\sin\left(\dfrac{\pi t}{20}\right)\right]$ |
| 首要目标     | 平顺、稳定、少用舵           | 快速接近新航向，减少切换段误差                               |
| 关键边界     | 舵角不过界，稳定裕度不低     | 舵角不过界，下一次切换前误差不能长期残留                     |
| 设计判断     | 固定超前是否足够             | 先重整定固定结构；若职责过载，再有限换结构                   |

这里的方波指令不是为了制造数学上的“复杂输入”，而是为了模拟真实机动中的连续命令切换。若一个控制器在单次阶跃下表现不错，但在 $20\,\mathrm{s}$ 的切换节律中总是把上一段误差拖入下一段，它就不适合任务 B。

## 2. 从真实任务翻译为控制指标

### 2.1 工程语言不能直接进入优化器

真实任务通常以工程语言提出：

- “转向要快一点”；
- “不能频繁打满舵”；
- “不要刚跟上就又被下一条指令打乱”；
- “在模型有偏差时也不能变得危险”；
- “控制器以后要能实现、能维护、能重新整定”。

这些表达不能直接作为优化目标。设计者必须把它们翻译为可计算指标，并区分硬约束、主目标、次目标和诊断指标。若这一步没有做清楚，后面的优化会变成一堆权重的游戏。

### 2.2 指标合同：硬约束、主目标、次目标、诊断指标

本单元采用四层指标结构。

第一层是**硬约束**。硬约束失守时，方案不进入最终候选，不允许用其他指标的改善抵消。

$$
M_p \le 20\%, \qquad \max_t |\delta(t)| \le 7.1^\circ, \qquad \phi_m \ge 45^\circ.
$$

其中 $M_p$ 表示超调量，$\max_t |\delta(t)|$ 表示最大舵角，$\phi_m$ 表示相角裕度。舵角边界来自执行机构能力，稳定裕度来自模型不确定性和扰动环境，二者都不是可以随意牺牲的性能指标。

第二层是**主目标**。主目标由任务语义决定。对于客船航向保持，主目标是平顺、稳态误差、调节时间和控制能量之间的协调；对于驱逐舰快速机动，主目标是切换后快速减小误差，并尽量减少下一次切换前的残留误差。

第三层是**次目标**。次目标用于区分已经满足硬约束的候选方案，例如控制能量、舵角变化率、低频扰动抑制能力、频域带宽等。

第四层是**诊断指标**。诊断指标不一定直接进入目标函数，但用于解释方案为什么好或为什么坏，例如频繁饱和时间占比、积分器状态是否风up、噪声下舵角抖动程度、离散化后相角裕度变化等。

表 4-7-2 给出从任务语言到控制指标的翻译。

| 真实任务需求         | 控制指标表达                                               | 类型            | 工程含义                                                   |
| -------------------- | ---------------------------------------------------------- | --------------- | ---------------------------------------------------------- |
| 船舶不能明显转过头   | $M_p\le 20\%$                                              | 硬约束          | 防止过度偏航，避免航迹越界和人员不适                       |
| 舵机不能长期接近极限 | $\max |\delta(t)|\le 7.1^\circ$，饱和时间占比 $\rho_{sat}$ | 硬约束 + 诊断   | 幅值越界意味着执行机构无法实现；频繁接近极限意味着方案脆弱 |
| 模型有误差也要安全   | $\phi_m\ge45^\circ$，增益裕度，参数摄动测试                | 硬约束 + 诊断   | 频域裕度是模型失配下的安全余量                             |
| 客船要平顺           | $ITAE$、$ITSE$、$\int \delta^2(t)dt$                       | 主目标 / 次目标 | 误差和用舵都要小，不能靠剧烈控制换性能                     |
| 驱逐舰要快速完成切换 | 切换窗口误差 $E_{sw}$，段末误差 $E_{tail}$                 | 主目标          | 每段命令开始后要尽快靠近新航向，不能把误差带入下一段       |
| 真实航迹不要偏太远   | 横向偏离估计 $Y_{dev}$                                     | 主目标 / 诊断   | 航向误差在运动中会积累成实际航迹偏离                       |
| 控制器要能实现       | 采样周期、离散化后裕度、抗饱和、滤波                       | 实现审查        | 仿真中的连续控制器必须能落到实际自动舵中                   |

### 2.3 驱逐舰任务的核心指标

对于任务 B，仅看单次阶跃响应是不够的。因为参考命令每 $20\,\mathrm{s}$ 切换一次，控制器必须在有限时间窗口内完成主要动作。设切换时刻为 $t_k$，则可以定义切换窗口误差

$$
E_{sw,k}=\int_{t_k}^{t_k+T_w}|e_\psi(t)|dt,
$$

其中 $T_w$ 是切换后的评估窗口，例如 $T_w=8\,\mathrm{s}$ 或 $10\,\mathrm{s}$。它衡量控制器在新命令刚到来后的快速响应能力。

段末残留误差定义为

$$
E_{tail,k}=|e_\psi(t_{k+1}^-)|.
$$

它衡量下一次切换到来之前，上一段误差是否已经基本清除。如果 $E_{tail,k}$ 长期偏大，说明控制器在任务节律内没有真正完成任务。

航迹偏离可以通过小角度近似估计。设航速为 $V$，航向误差以弧度计，则横向偏离近似为

$$
Y_{dev}(t)\approx V\int_0^t e_\psi(\tau)d\tau.
$$

这个指标的意义是把“航向误差曲线”翻译成“真实船舶运动后偏离了多少”。在工程讲授中，必须让学生看到：同样的航向误差，在高速舰船上会更快积累成航迹偏离。

> **仿真 / 插图占位说明**：建议绘制 $r_d(t)$、$\psi(t)$、$e_\psi(t)$ 三条曲线，并用阴影标出 $[t_k,t_k+T_w]$ 的切换窗口，用竖线标出 $t_{k+1}^-$ 的段末误差。

## 3. 被控对象与设计边界

### 3.1 对象模型

本单元沿用前面单元中的两个船舶航向对象模型。

客船航向对象为

$$
P_p(s)=\frac{0.01715}{s(s+0.1)(s+2.14375)}.
$$

驱逐舰航向对象为

$$
P_d(s)=\frac{0.0216}{s(s+0.16)(s+2.85)}.
$$

两个模型都包含积分环节，表示舵角作用会积累为航向变化。二者不是完全不同的问题类型，而是同一类航向控制任务在不同船型、不同任务节律下的两个实例。

这里容易出现一个错误判断：既然两个对象结构相近，就以为控制器结构也应相同。更合理的理解是：对象族相近只说明已有设计经验可以迁移，不能说明任务排序也可以迁移。客船关注平顺保持，驱逐舰关注快速切换完成度。任务排序变化以后，原来能闭合的控制职责可能被重新撕开。

### 3.2 控制器实现边界

课堂设计中必须同时保留两类边界。

第一类是课程硬约束：

$$
M_p \le20\%,\qquad \max |\delta(t)|\le7.1^\circ,\qquad \phi_m\ge45^\circ.
$$

第二类是工程复核项：

- 舵角速率限制：$|\dot{\delta}(t)|\le \dot{\delta}_{max}$；
- 饱和时间占比：$\rho_{sat}=T_{sat}/T_{sim}$；
- 积分抗饱和：若使用积分支路，必须加入 anti-windup；
- 测量噪声：超前、微分或高带宽控制会放大噪声；
- 离散实现：采样和离散化会改变相位裕度；
- 模型失配：船速、载荷、海况变化会改变对象参数。

这些工程复核项不一定都写入最初的优化函数，但必须进入最终测试。若它们从讲义中消失，学生就会误以为控制器设计在连续域仿真曲线处结束。

## 4. 从控制职责出发，而不是从结构名称出发

### 4.1 控制职责分解

控制器结构不是一串传递函数名称，而是一组控制职责的分配方式。本单元至少要区分五类职责。

| 控制职责     | 具体含义                           | 典型承担环节                | 失效表现                       |
| ------------ | ---------------------------------- | --------------------------- | ------------------------------ |
| 低频误差回收 | 消除稳态误差，清理段末残留误差     | 积分、PI、滞后环节          | 段末误差大，连续切换时误差累积 |
| 中频提速     | 提高切换后的响应速度               | 超前环节、适当带宽提升      | 切换窗口误差大，响应拖沓       |
| 相位补偿     | 提高相角裕度，避免动态不稳定       | 超前环节                    | 快是快了，但稳定裕度不足       |
| 边界控制     | 控制峰值舵角和控制能量             | 参数约束、限幅、权重、滤波  | 舵角接近或超过执行机构极限     |
| 实现与维护   | 便于离散实现、抗噪、抗饱和、再整定 | 滤波、anti-windup、低阶结构 | 仿真可行但实际舵机抖动或饱和   |

客船任务中，固定超前结构可以主要承担中频整形和相位补偿，并在控制量边界内获得可接受平衡。驱逐舰任务中，参考命令不断切换，低频误差回收和中频提速同时变得紧迫。若仍然只让一个超前环节承担全部职责，它很可能出现职责过载。

### 4.2 候选结构库

本单元候选控制器不无限扩张，只允许五类低阶结构进入比较。这样做的目的是保持可解释性，避免把课程收口变成黑箱搜索。

| 编号 | 控制器结构  | 形式                                                        | 主要职责            | 主要风险                   |
| ---- | ----------- | ----------------------------------------------------------- | ------------------- | -------------------------- |
| S1   | PI          | $K\dfrac{T_i s+1}{T_i s}$                                   | 低频误差回收        | 可能降低相位裕度，响应变慢 |
| S2   | 超前        | $K\dfrac{T_zs+1}{T_ps+1}$，$T_z>T_p$                        | 中频提速，相位补偿  | 低频残留误差处理能力有限   |
| S3   | PI + 超前   | $K\dfrac{T_i s+1}{T_i s}\dfrac{T_zs+1}{T_ps+1}$             | 低频回收 + 中频提速 | 参数更多，需要 anti-windup |
| S4   | 滞后 + 超前 | $K\dfrac{T_{lag,z}s+1}{T_{lag,p}s+1}\dfrac{T_zs+1}{T_ps+1}$ | 低频增益 + 相位补偿 | 滞后设计不当会拖慢响应     |
| S5   | 带滤波 PID  | $K_p+\dfrac{K_i}{s}+K_d\dfrac{Ns}{s+N}$                     | 综合整形            | 微分支路可能放大噪声       |

注意，候选结构库不是为了证明“复杂结构一定更好”。它的作用是让设计者在固定结构证据不足时，有边界地比较不同职责分配方式。

## 5. 设计决策阶梯：什么时候调参数，什么时候换结构

本单元采用四级设计决策阶梯。

第一级：**只重整定参数**。若任务变化后，原结构的职责分配仍然成立，先不要换结构。改变参数的成本最低，解释性最强，工程维护代价也最小。

第二级：**补充职责支路**。若原结构在某类职责上明显不足，例如连续切换导致段末误差残留，则考虑增加积分或低频增强支路。

第三级：**有限换结构**。若补充职责后仍无法在约束内闭合证据链，才把结构放入有限候选库中搜索。这里的“有限”很关键：结构库要小、低阶、可解释。

第四级：**升级到策略层**。若单一固定结构无法覆盖工况切换、船速变化、载荷变化或海况变化，则需要增益调度、切换控制、鲁棒控制或更高层监督策略。本单元只指出边界，不展开这些高级方法。

![图 4-7-3 占位：控制器设计决策阶梯](../media/placeholder-4-7-3-design-decision-ladder.png)

> **插图占位说明**：建议画成判断树。起点为“任务变化”，依次判断“原结构职责是否仍成立”“硬约束是否满足”“证据链是否闭合”“工况变化是否超出单一结构能力”。

这张阶梯是本单元真正要留给学生的迁移性方法。以后面对其他对象时，学生不一定还会使用这里的船舶模型，但应能保留这个判断顺序：先确认任务，再翻译指标，先调参数，再审查职责，最后才有限换结构。

## 6. 目标函数与约束处理

### 6.1 统一代价函数框架

对于驱逐舰任务，可以把目标函数写成分项加权形式：

$$
J(\theta)=w_{sw}J_{sw}+w_{tail}J_{tail}+w_uJ_u+w_yJ_y+w_rJ_r+J_{penalty}.
$$

其中 $\theta$ 表示待优化参数。各项含义如下：

$$
J_{sw}=\sum_k\int_{t_k}^{t_k+T_w}|e_\psi(t)|dt,
$$

表示切换窗口误差；

$$
J_{tail}=\sum_k|e_\psi(t_{k+1}^-)|,
$$

表示段末残留误差；

$$
J_u=\int_0^{T_{sim}}\delta^2(t)dt,
$$

表示控制能量；

$$
J_y=\int_0^{T_{sim}}|Y_{dev}(t)|dt,
$$

表示由航向误差积累形成的航迹偏离代价；

$$
J_r=\int_0^{T_{sim}}\dot{\delta}^2(t)dt,
$$

表示舵角变化率代价，用于避免舵机频繁剧烈动作。

约束项通过惩罚函数处理：

$$
J_{penalty}=\lambda_1\max(0,M_p-0.2)^2+
\lambda_2\max(0,\max|\delta|-7.1)^2+
\lambda_3\max(0,45^\circ-\phi_m)^2.
$$

这个表达式的教学意义不在于某一组权重一定最佳，而在于告诉学生：硬约束不能被悄悄并入普通性能指标。如果 $\phi_m<45^\circ$，即使 $J_{sw}$ 很小，也不能直接接受。

### 6.2 权重不是价值判断的替代品

权重只表达任务排序，不能替代工程判断。对于客船任务，$w_u$ 和平顺性相关指标应占较高权重；对于驱逐舰任务，$w_{sw}$ 与 $w_{tail}$ 应占较高权重。但无论权重怎样变化，硬约束都必须先满足。

因此，本单元的优化流程应遵循如下原则：

1. 先用硬约束筛掉不可交付方案；
2. 再用主目标比较任务完成能力；
3. 然后用次目标比较代价和可维护性；
4. 最后用诊断指标解释响应曲线背后的风险。

## 9. 设计流程三：固定超前结构下的约束优化

### 9.1 固定结构先行的理由

在工程设计中，低阶固定结构通常优先于复杂结构。原因很直接：低阶结构实现容易、整定经验多、维护成本低、故障诊断也更清楚。因此，驱逐舰任务下的第一轮正式设计仍然固定为超前结构：

$$
C_{lead}(s)=K\frac{T_zs+1}{T_ps+1},\qquad T_z>T_p>0.
$$

设计变量为

$$
\theta_{lead}=[K,T_z,T_p].
$$

目标函数采用第 6 节中的驱逐舰任务代价，约束保持

$$
M_p \le20\%,\qquad \max |\delta|\le7.1^\circ,\qquad \phi_m\ge45^\circ.
$$

### 9.2 固定结构优化过程

固定结构优化可以采用 GA、PSO、模式搜索、贝叶斯优化或其他黑箱优化方法。算法不是本节重点。重点是把优化器限制在明确设计合同内：

- 输入：驱逐舰对象 $P_d(s)$、方波任务 $r_d(t)$、超前结构 $C_{lead}(s)$、目标函数 $J(\theta)$、硬约束；
- 输出：满足硬约束的若干固定超前候选方案；
- 解释：固定结构是否仍能在新任务下闭合证据链。

### 9.3 固定结构优化结果的解释

固定超前结构优化后，可能出现三种情况。

第一种情况：硬约束和主目标都满足。这时不应再换结构。任务 B 虽然改变了排序，但原结构通过重整定仍然够用。

第二种情况：硬约束满足，但主目标之间明显冲突。例如切换窗口误差下降以后，段末误差仍然偏大，或者舵角能量显著增加。这说明固定结构还能工作，但职责分配已经紧张。

第三种情况：无论如何重整定，总有硬约束被破坏。此时固定结构证据链断裂，结构应进入有限搜索空间。

本单元强调第二种和第三种情况的区分。若只是某个指标还不理想，但硬约束和主要任务都能闭合，就没有充分理由换结构。若固定结构为了降低切换误差而不断逼近舵角边界或牺牲稳定裕度，就说明它可能已经职责过载。

## 10. 设计流程四：有限候选结构的混合搜索

### 10.1 结构为什么可以进入搜索变量

当固定结构无法同时承担低频误差回收、中频提速、相位补偿和边界控制时，继续只调三个参数会导致解释链撕裂。此时结构可以进入搜索变量，但必须满足两个条件：

1. 候选结构有限、低阶、可解释；
2. 搜索结果必须能够解码回控制职责，而不是停留在编码向量。

本单元采用第 4 节中的五类候选结构：PI、超前、PI + 超前、滞后 + 超前、带滤波 PID。

### 10.2 混合编码方式

可以用一个离散变量 $m$ 表示结构类型，用连续变量 $\theta_m$ 表示该结构的参数：

$$
x=[m,\theta_m].
$$

其中

$$
m\in\{1,2,3,4,5\}.
$$

例如：

- $m=1$：PI，$\theta_1=[K,T_i]$；
- $m=2$：超前，$\theta_2=[K,T_z,T_p]$；
- $m=3$：PI + 超前，$\theta_3=[K,T_i,T_z,T_p]$；
- $m=4$：滞后 + 超前，$\theta_4=[K,T_{lag,z},T_{lag,p},T_z,T_p]$；
- $m=5$：带滤波 PID，$\theta_5=[K_p,K_i,K_d,N]$。

为了避免搜索器给出物理意义不清的结果，还需要设置参数范围。例如所有时间常数为正，超前环节满足 $T_z>T_p$，微分滤波系数 $N$ 不能无限大。

### 10.3 粗搜与 shortlist

混合搜索分两步。

第一步是全局粗搜。目标是找出值得保留的结构类型，而不是直接相信某个最优个体。此处可使用 GA、PSO 或混合启发式算法。

第二步是 shortlist 精修。把粗搜中排名靠前且具有工程解释的候选结构拿出来，用局部搜索或更细的参数网格精修。

## 11. 设计流程五：终选方案的职责解码

### 11.1 示例终选方案

在本单元示范设计中，驱逐舰任务的终选方案采用 PI + 超前结构：

$$
C_d^{final}(s)=1.5200\frac{14.5000s+1}{14.5000s}\frac{8.8000s+1}{2.4000s+1}.
$$

这不是因为“参数更多所以更好”，而是因为它把两个在任务 B 中同时紧张的职责拆开了。

### 11.2 终选方案的职责分工

PI 支路为

$$
C_{PI}(s)=\frac{14.5000s+1}{14.5000s}.
$$

它的主要职责是低频误差回收。对于连续切换任务，积分支路可以减少段末误差，把上一段残留误差清理掉，避免误差跨段积累。

超前支路为

$$
C_{lead}(s)=\frac{8.8000s+1}{2.4000s+1}.
$$

它的主要职责是中频提速和相位补偿。它让系统在切换后更快响应，同时通过相位补偿保持必要稳定裕度。

总增益 $1.5200$ 负责整体响应强度。增益不能孤立解释，它必须和积分时间常数、超前零极点一起看。若只增大增益，可能降低切换误差，但也可能把舵角和稳定裕度推向边界。

![图 4-7-9 占位：PI + 超前终选方案的职责解码图](../media/placeholder-4-7-9-final-controller-role-decode.png)

> **插图占位说明**：建议把 $C_d^{final}(s)$ 拆成 PI 支路、超前支路和总增益三部分，并在图中标注“低频误差回收”“中频提速”“相位补偿”“舵角边界共同约束”。

### 11.3 为什么不是直接选最小总代价方案

如果另一个候选方案的总代价略低，但相角裕度接近 $45^\circ$ 边界，或者舵角饱和时间占比更高，则它不一定是更好的工程方案。最终控制器不是优化日志中的一个数字，而是要回答三个问题：

1. 它是否满足硬约束？
2. 它是否完成了任务 B 的主目标？
3. 它的响应、舵角和裕度能否被同一条控制职责解释链解释？

只有三个问题同时回答清楚，才能形成控制器定案。

第二类测试是稳健性测试。不能只看标称模型。至少应考虑以下摄动：

稳健性测试需要回答：

- 参数变化后闭环是否仍稳定？
- $\phi_m$ 是否仍有足够余量？
- 方波任务下 $E_{tail}$ 是否明显恶化？
- 舵角是否更频繁逼近边界？

### 12.3 噪声与离散实现测试

第三类测试是实现测试。实际航向传感器存在测量噪声，控制器最终也要离散实现。连续域设计通过以后，至少要进行如下检查：

- 在测量端加入噪声 $n(t)$，观察 $\delta(t)$ 是否出现高频抖动；
- 选定采样周期 $T_s$，例如 $T_s=0.1\,\mathrm{s}$ 或根据设备确定；
- 使用 Tustin 方法或零阶保持等方式离散化控制器；
- 重新计算离散闭环响应和等效裕度；
- 若存在积分环节，加入 anti-windup 并测试饱和解除后的恢复。

![图 4-7-12 占位：测量噪声与离散实现下的舵角响应](../media/placeholder-4-7-12-noise-discrete-rudder-response.png)

> **仿真占位说明**：绘制无噪声连续控制、含噪声连续控制、含噪声离散控制三种情况下的舵角曲线。重点观察舵角抖动和边界接近程度。

### 12.4 执行机构饱和与 anti-windup 测试

若控制器含积分支路，饱和问题必须单独测试。积分器在舵角饱和时仍继续累积，会造成 windup，表现为饱和解除后响应迟钝、反向超调或误差长期不能恢复。

工程实现中可采用反算式 anti-windup：

$$
\dot{x}_I=e_\psi+K_{aw}(\delta-\delta_c),
$$

其中 $x_I$ 为积分状态，$\delta_c$ 为未限幅的控制器输出，$\delta$ 为限幅后的实际舵角，$K_{aw}$ 为抗饱和反馈系数。

![图 4-7-13 占位：有无 anti-windup 的饱和恢复对比](../media/placeholder-4-7-13-anti-windup-comparison.png)

## 13. 如何把性能指标解释回真实场景

### 13.1 指标不是数字排名，而是任务解释

最终证据表不能只报告“总代价更低”。每个指标都要翻译回真实任务。

| 指标现象                        | 真实场景解释                             | 设计判断                                  |
| ------------------------------- | ---------------------------------------- | ----------------------------------------- |
| $J_{sw}$ 大                     | 命令刚切换时跟不上，新航向建立慢         | 中频提速不足或带宽受限                    |
| $E_{tail}$ 大                   | 下一条命令来之前上一段误差仍未清除       | 低频回收不足，可能需要积分或低频增强      |
| $\max|\delta|$ 接近 $7.1^\circ$ | 控制器要求舵机接近极限，留给扰动的余量小 | 即使未越界，也属于工程风险                |
| $J_u$ 大                        | 舵机动作代价高，疲劳与能耗增加           | 不能只追求响应速度                        |
| $\phi_m$ 接近 $45^\circ$        | 模型稍有变化就可能带来明显风险           | 不宜接受“刚好压线”的方案                  |
| 噪声下 $\delta(t)$ 抖动         | 传感器噪声被控制器放大                   | 需要降低带宽、增加滤波或调整微分/超前参数 |
| 离散化后性能恶化                | 连续域设计没有考虑采样相位损失           | 需要重新设计或按离散域直接优化            |

### 13.2 对响应曲线的工程解读

看响应曲线时，不应只问“谁更快”。应按真实任务问四个问题。

第一，切换后几秒内是否明显接近新指令？这对应 $J_{sw}$，决定战术机动任务中最初阶段是否有效。

第二，下一次切换前误差是否已经小到可接受？这对应 $E_{tail}$，决定系统是否在任务节律内完成了上一段命令。

第三，响应变快是否靠更激烈舵角换来的？这对应 $\max|\delta|$、$J_u$ 和 $J_r$，决定执行机构是否承受了过高代价。

第四，当前响应是否仍有稳定余量？这对应 $\phi_m$、增益裕度和摄动测试，决定模型误差出现时系统是否仍可接受。

![图 4-7-14 占位：固定超前与 PI + 超前方案的真实场景解释对比](../media/placeholder-4-7-14-real-scenario-interpretation.png)

> **插图占位说明**：建议做成一张“曲线 + 标注”的解释图，在响应曲线上直接标出切换窗口、段末误差、舵角边界、可能的饱和区和稳健性风险提示。

### 13.3 固定超前与 PI + 超前的典型解释差异

若最终仿真显示 PI + 超前方案相对于固定超前重整定方案具有更小的段末误差和切换窗口误差，同时舵角边界和相角裕度仍满足要求，则可以作如下解释：

- 固定超前结构主要通过中频整形加快响应，但低频误差回收能力有限；
- 在连续切换任务中，低频残留误差会被下一段命令放大为新的初始误差；
- PI + 超前结构把低频误差回收交给 PI 支路，把中频提速和相位补偿交给超前支路；
- 因此它不是“更复杂所以更优”，而是“职责分工更符合任务 B 的指标排序”。

如果仿真结果没有显示上述证据，则不应强行选 PI + 超前。结构升级必须由证据支持。

## 14. 最终交付：控制器设计说明书

完整设计的终点不是仿真曲线，而是一份可交付说明书。本单元建议使用表 4-7-6 作为交付模板。

表 4-7-6 控制器设计交付卡

| 项目             | 内容                                                         |
| ---------------- | ------------------------------------------------------------ |
| 任务名称         | 驱逐舰快速机动航向控制                                       |
| 对象模型         | $P_d(s)=\dfrac{0.0216}{s(s+0.16)(s+2.85)}$                   |
| 参考任务         | $20\,\mathrm{s}$ 节律方波航向指令，教学幅值 $\pm10^\circ$    |
| 硬约束           | $M_p\le20\%$，$\max|\delta|\le7.1^\circ$，$\phi_m\ge45^\circ$ |
| 终选控制器       | $C_d^{final}(s)=1.5200\dfrac{14.5000s+1}{14.5000s}\dfrac{8.8000s+1}{2.4000s+1}$ |
| 职责解释         | PI 支路负责低频误差回收，超前支路负责中频提速与相位补偿      |
| 名义测试结果     | 待填：$J_{sw}$、$J_{tail}$、$J_y$、$J_u$、$\max|\delta|$、$\phi_m$ |
| 稳健性测试结果   | 待填：参数摄动、噪声、离散化、饱和恢复测试结论               |
| 实现要求         | 加入舵角限幅、速率限制、anti-windup；离散化后复核裕度        |
| 适用边界         | 适用于当前船速、载荷和 $20\,\mathrm{s}$ 指令节律附近的任务   |
| 重新设计触发条件 | 指令幅值增大、切换周期缩短、舵角频繁饱和、模型参数明显变化、离散实现后裕度不足 |

### 14.1 适用边界

终选方案必须声明适用边界。对于本单元的 PI + 超前方案，至少应声明：

- 它针对当前驱逐舰航向模型设计，不自动适用于其他船速和载荷；
- 它针对 $20\,\mathrm{s}$ 左右的切换节律设计，若节律显著缩短，需要重新测试；
- 它在舵角边界 $7.1^\circ$ 下验证，若执行机构边界改变，需要重新优化；
- 它含积分支路，实际实现必须配合 anti-windup；
- 它的频域裕度必须在离散实现后重新确认。

### 14.2 重新设计触发条件

出现以下情况时，不应继续相信原控制器：

1. 任务指令幅值明显增大，例如从 $\pm10^\circ$ 扩展到更大机动角；
2. 切换周期明显短于 $20\,\mathrm{s}$，系统没有足够时间完成上一段命令；
3. 舵角饱和时间占比持续升高，或饱和解除后响应恢复明显变慢；
4. 船速、载荷、海况导致对象参数偏离设计模型；
5. 离散化、滤波或传感器噪声使实际舵角响应与连续仿真差异明显；
6. 稳定裕度低于设计边界，尤其是相角裕度接近或低于 $45^\circ$。

这部分是模块 4 的重要收口：控制器不是一次性“求出最优”后永久有效。控制器有适用边界，边界被触发时，重新设计是工程责任，不是算法失败。

## 15. 本单元小结

本单元把控制器设计从“求解问题”拉回到“工程任务”。完整设计链条如下：

1. 从真实任务出发，明确对象、参考信号、执行机构边界和任务节律；
2. 把任务语言翻译为硬约束、主目标、次目标和诊断指标；
3. 先复核客船基线，确认旧结构在旧任务中的职责闭合；
4. 把旧控制器直接迁移到驱逐舰任务中测试，识别任务排序变化；
5. 先在固定超前结构下进行约束优化，判断只调参数是否足够；
6. 当固定结构职责过载时，才进行有限候选结构搜索；
7. 对终选方案做职责解码，说明各支路承担什么控制任务；
8. 用名义响应、频域裕度、舵角边界、稳健性、噪声、离散实现和 anti-windup 测试完成证据闭环；
9. 最后形成控制器交付卡，说明方案、参数、证据、适用边界和重新设计触发条件。

本单元的核心结论是：

> **控制器设计的完成标志，不是得到一组最优参数，而是形成一套能够解释真实任务、满足硬约束、经受测试验证、并明确适用边界的控制方案。**

## 16. 课堂讨论与分层练习

### 16.1 课堂讨论

1. 如果固定超前结构已经满足 $M_p\le20\%$ 和 $\phi_m\ge45^\circ$，但在方波任务中 $E_{tail}$ 偏大，是否一定要换成 PI + 超前？为什么？
2. 若某个 PID 候选方案的 $J_{sw}$ 最小，但测量噪声下舵角明显抖动，它是否应成为最终方案？
3. 若 PI + 超前方案的段末误差明显更小，但舵角峰值长期贴近 $7.1^\circ$，最终设计说明书中应怎样表述它的风险？
4. 如果任务从 $20\,\mathrm{s}$ 切换周期改为 $10\,\mathrm{s}$，原控制器的哪个指标最先需要重新审查？

### 16.2 基础练习

给定客船对象 $P_p(s)$ 和基线控制器 $C_p(s)$，完成单次阶跃仿真，记录 $M_p$、调节时间、$\max|\delta|$ 和相角裕度。说明该控制器为什么适合客船巡航航向保持任务。

### 16.3 进阶练习
