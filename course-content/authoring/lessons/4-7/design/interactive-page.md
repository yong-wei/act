## 文档职责

- 本文件是 `4-7` 作者态互动页面蓝图，负责把讲义中的高保真任务观察、分段辨识、指标翻译、传统设计、优化设计、跨模型验证、扰动噪声边界、结构局限和后测落成可直接实现的课堂页面。
- 同目录 `interactive-contract.yaml` 是机读真源；两者必须在步骤顺序、标题、模板、互动类型、教师控制和学生默认状态上逐项一致。
- 本轮设计以讲义顺序为硬约束：`真实任务 -> 分段辨识 -> 指标翻译 -> 传统设计 -> 优化设计 -> 跨模型验证 -> 扰动 -> 噪声 -> 后测 -> 总结`。后测与总结分离。

## 表述规则

- 每一步都必须回答四件事：对象是什么、正在判断什么、关键证据在哪里、结论如何接回“高保真辨识、设计验证与扰动边界”。
- 图片、结构图、四联图和对比图都服从讲义证据顺序，不得统一抢到页面顶端。
- 曲线图默认先复现讲义静态图，再允许通过勾选、显影或对照卡改变阅读层。
- 作答卡默认隐藏，教师发放后单卡提交；逐步显影只隐藏分析步骤，不隐藏题面、公式或判断对象。

## step-03｜真实航迹任务与分段辨识模型结构

### 页面骨架
- 顶部放两类真实航迹任务表和统一航速条件。
- 中部依次放主通道结构、舵机惯性辨识、船体艏摇辨识和扰动等效入口。
- 下方放分段辨识结构图、三张辨识图、三层显影链和最终名义模型。

### 模块清单
- 航线任务表、航速条件卡、主通道公式卡、舵机模型卡、船体模型卡、扰动模型卡、分段结构图、三张辨识图、三层显影链、最终模型卡。

### 静态承载内容
- 方波任务：$+45^\circ/-45^\circ$，半周期 $300\,\mathrm{s}$，总时长 $1200\,\mathrm{s}$，覆盖两个完整周期。
- 回转任务：$60\,\mathrm{s}$ 开始从 $0^\circ$ 单调增加到 $360^\circ$，总时长 $780\,\mathrm{s}$。
- 航速条件：$v=15.0\,\mathrm{m/s}\approx29.2\,\mathrm{kn}$。
- 主通道：$\delta_c \rightarrow \frac{1}{T_rs+1}\rightarrow\delta\rightarrow\frac{K_h}{T_hs+1}\rightarrow r\rightarrow\frac{1}{s}\rightarrow\psi$。
- 舵机：$G_r(s)=\delta(s)/\delta_c(s)=1/(T_rs+1)$，$T_r=1.10\,\mathrm{s}$。
- 船体：$G_h(s)=r(s)/\delta(s)=K_h/(T_hs+1)$，$T_h=42.00\,\mathrm{s}$，$K_h=0.0700\,\mathrm{rad/s/rad}$。
- 扰动：$G_d(s)=d_e(s)/d(s)=K_d/(T_ds+1)$，$T_d=54.00\,\mathrm{s}$，$K_d=0.0150\,\mathrm{rad}$。
- 最终名义航向模型：$P_{id}(s)=K/[s(1.10s+1)(42.00s+1)]$，$K=0.0700/(1.10\times42.00)$。

### 混合证据顺序
- 先真实任务和航速 -> 再主通道 -> 再舵机/船体/扰动辨识 -> 再图像证据 -> 最后最终模型。

### 互动升级点
- 显影层 1：舵机惯性、船体惯性和积分航向构成本课名义设计主通道。
- 显影层 2：船体参数可服务传统设计，因为舵角到艏摇角速度的主通道稳定可解释；航向角是艏摇角速度的积分，必须同时关照 $r(t)$ 与积分后的 $\psi(t)$。
- 显影层 3：扰动等效通道只能作为边界入口，不能证明风浪扰动被充分建模。

## step-04｜指标到代价函数：航迹、舵角和裕度怎样进入同一个判断

### 页面骨架
- 顶部放真实指标到课程指标表。
- 中部放综合代价函数和五类罚项。
- 底部放指标分类说明与两张作答卡。

### 模块清单
- 指标翻译表、综合代价公式卡、罚项公式卡、分类说明卡、两张作答卡。

### 静态承载内容
- 综合代价：$J=w_eJ_e+w_yJ_y+w_uJ_u+w_{\dot u}J_{\dot u}+w_sJ_s+J_{penalty}$。
- 主要分项解释：$J_e=\int_0^T|e_\psi(t)|dt$ 是航向误差主目标，$J_y=\int_0^T|Y_{dev}(t)|dt$ 是航迹偏离主目标或诊断指标，$J_u=\int_0^T\delta^2(t)dt$ 与 $J_{\dot u}=\int_0^T\dot{\delta}^2(t)dt$ 是控制动作代价但不能替代执行硬边界，$J_s$ 记录稳定裕度不足风险。
- 罚函数：$J_{penalty}=\lambda_\delta P_\delta+\lambda_{\dot\delta}P_{\dot\delta}+\lambda_{sat}P_{sat}+\lambda_yP_y+\lambda_mP_m$。
- 五类罚项：$P_\delta$ 舵角越界，$P_{\dot\delta}$ 舵速越界，$P_{sat}$ 饱和时间过长，$P_y$ 航迹偏离超限，$P_m$ 稳定裕度不足。
- 指标表正文：
  - 航向误差：$e_\psi(t)=\psi_d(t)-\psi(t)$，对应 $J_e$，用于判断是否跟住期望航向。
  - 航迹偏离：$Y_{dev}$ 或轨迹 RMSE，对应 $J_y$，用于判断航向误差是否积累成位置偏差。
  - 舵角：$\max\delta(t)$ 与 $J_u$，既是硬约束，也是执行负担。
  - 舵速：$\max\dot{\delta}(t)$ 与 $J_{\dot u}$，判断舵机是否需要不可实现的快速动作。
  - 稳定裕度：相位裕度、增益裕度或 Nyquist 距离，对应 $J_s$，用于保留模型误差和扰动余量。
  - 饱和占比：$\rho_s=T_s/T$ 与 $J_{sat}$，用于判断控制器是否长期贴着执行边界工作。
  - 航向角速度：$r(t)$ 峰值与振荡，用于诊断是否出现过强艏摇或持续摆动。
  - 任务完成时间：达到航向窗口或回转任务窗口的时间，对应机动是否在要求时间内完成。
- 罚项正文：舵角越界、舵速越界、饱和时间过长、航迹偏离超限和稳定裕度不足都进入 $J_{penalty}$；它们不是偏好项，而是交付边界。
- 结论：违反舵角边界或稳定裕度边界的方案，不能因为航向误差小而直接接受。

### 混合证据顺序
- 先指标表 -> 再代价函数 -> 再罚项公式 -> 最后分类判断。

### 互动升级点
- 单选卡 1：哪一项指标直接把航向误差积累成位置偏离？
- 单选卡 2：舵角越界方案为什么不能靠更小航向误差被接受？

### 教师控制

### 学生默认状态

## step-05｜传统设计诊断四联图：为什么结构定型为 $PI+\text{超前}$

### 页面骨架
- 顶部放传统设计对象和四域诊断任务。
- 中部放诊断四联图。
- 底部放结构选型显影链和结论卡。

### 模块清单
- 对象公式卡、四域任务卡、诊断四联图、选型显影链、结论卡。

### 静态承载内容
- 设计对象：$P_{id}(s)=K/[s(T_rs+1)(T_hs+1)]$。
- 四域诊断：时域看响应慢，根轨迹看积分环节和慢极点牵制，Bode 看中频相位不足，Nyquist 看相对 $-1$ 点距离。
- 选型链保留四个后续计算符号：$\alpha$、$T_z$、$T_p$、$K_c$，本页先解释为什么需要这些参数，下一页再计算数值。
- 四域读图口令：
  - 时域：先看未校正阶跃响应的上升时间、调节时间和稳态误差，再判断“慢”和“有偏差”分别来自对象惯性还是型别不足。
  - 根轨迹：再看积分环节和慢极点怎样限制闭环极点可移动区域，判断单纯提高增益是否会把阻尼和舵角余量推到边界。
  - Bode：随后看目标穿越频率附近的相位裕度，若相位不足，就需要能在该频段补相位的超前校正。
  - Nyquist：最后看曲线离临界点的距离，把鲁棒裕度和执行器余量一起纳入结构选择。
- 结构结论：低频误差需要积分支路，中频相位需要超前支路，控制量边界要求不能只提高比例增益，因此传统设计定型为 $PI+\text{超前}$。

### 混合证据顺序
- 先对象 -> 再诊断任务 -> 再四联图 -> 再选型显影 -> 最后结构结论。

### 互动升级点
- 显影层 1：时域慢不能只靠增益硬提速。
- 显影层 2：根轨迹说明慢极点与积分环节限制闭环极点位置。
- 显影层 3：Bode 相位不足要求超前补偿。
- 显影层 4：Nyquist 距离和舵角/舵速边界要求保留裕度。

- 教师逐层显影四域证据，学生端默认不能自主展开。

### 学生默认状态
- 对象、四联图和最终结构结论常显，显影链默认收起。

### 本页脱离讲稿后的自包含检查
- 学生能从四域证据解释为什么是 $PI+\text{超前}$，而不是只背结构名。

### 预览口径
- 曲线互动镜像说明：四联图是诊断证据，默认镜像讲义静态图；控件区不绘制可行域，只保留时域、根轨迹、Bode、Nyquist 四域读图口令和结构职责。

## step-06｜传统控制器参数计算与名义验证：控制值怎样落成可复核公式

### 页面骨架

- 中部放 $C_{trad}(s)$ 与校正四联图。
- 底部放传统控制器在方波和回转任务中的辨识模型/高保真模型验证图。

### 模块清单

### 静态承载内容
- 参数链常显起点：$T_i=T_h=42.00\,\mathrm{s}$，$\omega_c=0.040\,\mathrm{rad/s}$，$\phi_m=35^\circ$。
- 参数计算链：
  - 用辨识船体时间常数确定积分零点：$T_i=T_h=42.00\,\mathrm{s}$，使低频稳态误差由积分环节消除。
  - 选取目标穿越频率 $\omega_c=0.040\,\mathrm{rad/s}$，对应方波半周期 $300\,\mathrm{s}$ 下的慢速航向任务。
  - 按相位补偿目标 $\phi_m=35^\circ$ 计算超前强度 $\alpha=(1-\sin\phi_m)/(1+\sin\phi_m)=0.271$。

- 验证口径：同一航速 $15.0\,\mathrm{m/s}$，方波和回转任务都要先看辨识模型，再看高保真模型。

## step-07｜优化设计编码与解码：搜索结果怎样回到确定控制值

### 页面骨架

### 模块清单

### 静态承载内容
- 候选结构：$PI$、超前、$PI+\text{超前}$、滞后 + 超前、带微分滤波的 $PID$。
- 搜索设置：种群 $48$，代数 $40$，精英 $6$，交叉率 $0.70$，变异率 $0.18$，随机种子 $4707$。
- 离散控制律：$\delta_c[k]=k_pe[k]+k_iI[k]+k_dD[k]+a_\ell(e[k]-e[k-1])/\Delta t+a_gz[k]$。
- 状态更新：$I[k]=I[k-1]+e[k]\Delta t$，$D[k]=\beta D[k-1]+(1-\beta)((e[k]-e[k-1])/\Delta t-r[k])$，$z[k]=z[k-1]+\Delta t\,a_g(e[k]-z[k-1])$。
- 编码字段：结构编号决定启用的结构族，连续字段为 $k_p,k_i,k_d,a_\ell,a_g,\beta,\tau_m$；解码后仍回到可解释的经典控制结构。
- 控制器符号含义：
  - $C_0$：比例 + 微分基线，用作未增强参考。
  - $C_1$：超前 + 微分滤波，改善相位和舵速噪声。
  - $C_2$：传统 $PI+\text{超前}$ 结构，兼顾稳态误差和中频相位。
  - $C_3$：滞后 + 超前结构，在高保真任务中增强低频修正并保留相位。
  - $C_4$：抗噪优化的 $PID$ 滤波结构，强化微分动作并加大测量滤波。
- 参数列含义：$k_p,k_i,k_d$ 分别为比例、积分和微分滤波支路系数；$a_\ell$ 为超前强度，$a_g$ 为滞后强度；$\beta$ 为微分滤波系数，$\tau_m$ 为测量低通时间常数。
- 参数表正文：
  - $C_0$：比例 + 微分基线，$k_p=0.80,k_i=0,k_d=11.0,a_\ell=0,a_g=0,\beta=0.90,\tau_m=0$。
  - $C_1$：超前 + 微分滤波，$k_p=1.05,k_i=0,k_d=18.0,a_\ell=0.38,a_g=0,\beta=0.82,\tau_m=0.20$。
  - $C_2$：$PI+\text{超前}$，$k_p=1.18,k_i=0.0030,k_d=19.0,a_\ell=0.34,a_g=0,\beta=0.78,\tau_m=0.35$。
  - $C_3$：滞后 + 超前，$k_p=0.95,k_i=0.0015,k_d=20.0,a_\ell=0.28,a_g=0.18,\beta=0.80,\tau_m=0.55$。
  - $C_4$：抗噪优化的 $PID$ 滤波结构，$k_p=1.35,k_i=0.0040,k_d=28.0,a_\ell=0.15,a_g=0,\beta=0.62,\tau_m=0.80$。
- 解码结论：$C_3$ 的 $a_g$ 表示新增低频滞后修正，$C_4$ 的较大 $k_d$ 与较小 $\beta$ 表示强化微分动作并用测量滤波抑制噪声放大。

### 混合证据顺序
- 先结构集合 -> 再搜索设置 -> 再收敛曲线 -> 再控制律 -> 再控制器符号含义 -> 再参数表 -> 最后作答。

## step-09｜扰动边界：为什么中等扰动需要重新搜索抗扰控制器

- 扰动不是简单“有/无”：轻扰动约 $10\%-20\%$，中等扰动约 $30\%-50\%$，强扰动超过 $80\%$ 才接近执行能力边界。

## step-10｜航向传感器噪声：噪声只进入测量通道时怎样抗噪

### 静态承载内容
- 测量航向：$\psi_m(t)=\psi(t)+b_\psi(t)+\sigma_\psi\xi_k$。
- $\psi(t)$ 是真实航向，$b_\psi(t)$ 是慢变偏置，$\sigma_\psi$ 是噪声强度，$\xi_k$ 是离散零均值随机量。

- 控制器符号含义：
  - $C_1$：无抗噪传统设计，保留较强微分动作但缺少充分测量滤波。

  - $C_3$：无抗噪优化设计，用作高保真优化但未专门处理测量噪声的对照。
  - $C_4$：有抗噪优化设计，通过较强微分动作和测量滤波降低噪声放大。
- 参数列含义：$k_p,k_i,k_d$ 分别为比例、积分和微分滤波支路系数；$a_\ell$ 为超前强度，$a_g$ 为滞后强度；$\beta$ 为微分滤波系数，$\tau_m$ 为测量低通时间常数。
- 读图口令：噪声不改变真实运动本身，而改变控制器看到的航向，微分和舵速代价因此必须被重新检查。
- 图后解释：方波噪声图先看测量噪声是否放大为舵角抖动，再比较抗噪方案是否降低舵速代价；回转噪声图先看连续转向时航向测量抖动是否破坏单调跟踪，再看轨迹是否仍完成一个圆周。

- 先噪声方程 -> 再控制器符号含义 -> 再参数表 -> 再方波图 -> 再回转图 -> 最后作答。

### 模块清单

### 静态承载内容
- 四类局限：固定低阶传递函数、固定结构、线性反馈、单传感器反馈。
- 局限解释：
  - 固定低阶传递函数能解释主要航向通道，但不能完整表达横荡、舵效变化和工况切换。
  - 固定结构便于解释和复核，但难以同时适配名义、扰动和噪声场景。
  - 线性反馈围绕局部工作点设计，遇到饱和、强扰动和非线性舵效时需要额外边界处理。
  - 单传感器反馈只看航向测量，容易遗漏航迹、横向偏离、舵机状态和环境估计。
- 前沿入口：鲁棒控制处理模型不确定性，扰动观测器估计外部扰动，增益调度按工况切换参数，模型预测控制显式处理约束，学习型策略用于复杂环境中的策略更新。
- 图后解释：真实场景解释图用于回看本课证据链，说明低阶模型、优化搜索、扰动和噪声都只是高保真任务中的一部分；封底信息图用于收束学习路径，强调经典结构先给可解释基线，再由边界问题引出更强方法。
- 证据桥接：本课不是否定传统控制，而是用高保真任务说明传统控制在哪些条件下可靠、在哪些条件下需要鲁棒控制、扰动观测、增益调度、MPC 或学习型策略。
- 收束句：先确认低阶经典设计能做到什么，再判断什么时候必须越过它。
