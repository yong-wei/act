# 单元 5-6 教师版讲义 | 方法迁移与前沿比较：冷链仓库温控同题评审

**课程**：自动控制原理
**课型**：实践
**学时**：90 分钟
**知识类型**：[D] 综合判断与方法迁移
**学生讲义真源**：`design/5-6-handout.md`

## 一、课堂主线与关键判断

本单元的核心判断是：方法迁移不能按算法新旧排序，路线选择要回到任务证据、失效来源、收益边界和验证责任。同一个生物制剂冷链温控任务中，经典 PI/PID、数据驱动预测补偿和策略学习监督层都可以成立，但它们进入系统的位置、需要证明的证据和承担的风险不同。

课堂应让学生完成一次完整的方法评审，不停留在“三类方法各自优缺点”的记忆层面。评审的主线是：

1. 冷链任务的硬约束来自 $2^\circ\mathrm{C}$ 至 $8^\circ\mathrm{C}$ 温区、连续监测和异常处置。
2. 二状态热模型把空气温度 $T_a$ 与货品核心温度 $T_p$ 分开，避免只看传感器读数。
3. 三条路线必须面对同一扰动日志和同一评价指标。
4. 性能改善只有在解释、验证和安全责任可闭合时，才构成路线选择理由。

讲授时要避免把“冷链”扩展成法规课。外部资料只承担温区和质量责任背景，所有曲线、指标和结论都来自本单元固定种子仿真。

## 二、课堂目标

完成本单元后，学生应能够：

1. 从同一控制任务中提取模型可信度、数据覆盖、扰动来源、动作边界和安全后果。
2. 解释二状态冷链热模型中空气温度、货品核心温度、开门热负荷、入库热负荷和压缩机占空比的作用。
3. 比较经典 PI/PID、数据驱动预测补偿和策略学习监督层在闭环实现上的差异。
4. 根据 E1、E2、E3 三组指标判断常规日、入库高峰和未见扰动下的优先路线。
5. 写出方法选择说明卡，说明推荐路线、主要收益、关键风险、验证路径和暂不采用其他路线的依据。

## 三、二状态热模型的讲授要点

模型公式是本单元的对象边界，不宜略读。学生需要看懂两个状态为什么同时存在：

$$
T_a(k+1)=T_a(k)
+\frac{T_{\mathrm{amb}}(k)-T_a(k)}{420}
+\frac{T_p(k)-T_a(k)}{92}
+0.040q_{\mathrm{door}}(k)
+0.030q_{\mathrm{load}}(k)
-0.080c(k)u(k),
$$

$$
T_p(k+1)=T_p(k)
+\frac{T_a(k)-T_p(k)}{250}
+0.0062q_{\mathrm{load}}(k).
$$

讲授顺序建议为：

1. 先解释空气温度 $T_a$ 响应快、可测、受开门和压缩机直接影响。
2. 再解释货品核心温度 $T_p$ 响应慢，冷链风险不能只用空气温度代替。
3. 最后解释压缩机项只直接降低 $T_a$，$T_p$ 只能通过空气-货品换热间接恢复。

学生常见误判是把 $T_a$ 当成唯一风险指标。处理方式是让学生读 E2 图：空气温度已经下行时，货品核心温度仍可能接近峰值。

## 四、三条路线的讲授要点

### 4.1 经典 PI/PID

经典路线的重点放在冷链任务中的可审查结构，不重复展开 PID 原理。

板书保留三行：

$$
T_m(k)=T_a(k)+b(k),\qquad e(k)=T_m(k)-T_{\mathrm{set}},
$$

$$
u^\star(k)=K_p e(k)+I(k)+K_d[e(k)-e(k-1)]+u_{\mathrm{ff}}(k),
$$

$$
u(k)=\mathrm{clip}(u^\star(k),0,1).
$$

讲授时要强调：控制器使用的是传感器测量值 $T_m$，不是直接知道真实空气温度 $T_a$。E3 中传感器偏置 $b(k)<0$ 正是用来暴露“读数偏低时控制器会低估热风险”的问题。

参数说明应服务实践判断：

| 参数 | 课堂解释 |
| --- | --- |
| $K_p=0.42$ | 温度偏高时立即增加制冷 |
| $K_i=0.010$ | 累积慢偏差，但受抗饱和限制 |
| $K_d=0.08$ | 抑制开门扰动后的快速变化 |
| $I_{\min},I_{\max}$ | 防止压缩机饱和时积分项继续推高控制量 |

经典路线在 E1 常规日已足够，因此课堂应把它作为基线和安全退路，避免把它误判为落后方法。

### 4.2 数据驱动预测补偿

数据驱动路线预测的是未来一小时热负荷等级 $\hat H_{60}$，不是直接预测压缩机占空比。这个边界必须讲清，否则学生容易把数据驱动理解成替代控制器。

预测器使用三类信息：

| 输入 | 工程含义 |
| --- | --- |
| 未来一小时开门记录 | 外界热空气进入仓内的短时冲击 |
| 未来一小时入库热负荷 | 温热货品带入货架后的慢释放 |
| 未来一小时平均外界温度 | 仓体换热背景强弱 |

补偿进入控制器有两步：一是高热负荷前把设定点临时下调到 $4.25^\circ\mathrm{C}$；二是加入受限前馈项 $u_{\mathrm{ff}}(k)$。课堂要把 E2 的结果读成“当前组合实现适合入库高峰”，不要读成“数据驱动必然优于经典控制”。

### 4.3 策略学习监督层

策略学习监督层不直接控制压缩机，而是选择“预冷、正常、节能、保守恢复”四种模式。这里的策略是从 E1/E2 开发场景蒸馏出的阈值监督策略，不是神经网络强化学习策略。

讲授重点是安全分层：

| 层级 | 保留责任 |
| --- | --- |
| 监督层 | 选择模式，不输出连续压缩机占空比 |
| PI/PID 层 | 计算控制量，保留限幅和抗饱和 |
| 安全壳 | 检查温区、拒绝危险模式、允许回退经典控制 |

E3 是策略监督层的关键压力测试。传感器读数偏低、制冷能力下降和门封退化都不在开发覆盖内，因此策略监督层没有足够证据进入主闭环。

## 五、指标表与图表读解

课堂读图应先定义指标，再比较方法。

| 指标 | 读法 |
| --- | --- |
| 越界分钟数 | $T_a$ 或 $T_p$ 离开 $2^\circ\mathrm{C}$ 至 $8^\circ\mathrm{C}$ 的分钟数 |
| 恢复时间 | 主要热负荷结束后，$T_a$ 与 $T_p$ 同时回到 $5.8^\circ\mathrm{C}$ 以下的分钟数 |
| 能耗 | $\sum u(k)/60$，表示归一化压缩机运行小时数 |
| 切换次数 | $u(k)>0.80$ 高负荷状态进入和离开次数 |
| 路线验证负担 | 路线选择所需补充证据，不是标准控制性能指标 |

E2 是课堂重点。经典路线恢复时间为 $22\ \mathrm{min}$；数据驱动预测补偿把恢复时间降为 $0\ \mathrm{min}$，同时空气峰值和核心峰值略降；策略监督层没有明显超过数据驱动路线。这个结果支持 E2 推荐“PI/PID + 数据驱动预测预冷 + 前馈补偿”的混合路线。

右下角不绘制告警次数，是因为本组仿真告警次数全部为 0，不能提供方法差异。学生如果问“没有告警是否说明都能部署”，应回应：没有越界只是必要条件，不足以证明数据覆盖、异常诊断和部署监控成立。

## 六、课堂实践组织

实践任务分三层推进。

第一层是证据辨析。要求学生把常规日、集中入库、门封退化、训练覆盖不足、能耗上升等现象放入对应路线，并说明证据来源。

第二层是定量判断。学生必须引用 E1/E2/E3 指标表，不允许只说“曲线更好”。重点看 E2 恢复时间、峰值温度、能耗和切换次数之间的权衡。

第三层是方法选择说明卡。卡片至少包含任务对象、主要证据、推荐路线、选择理由、主要收益、关键风险、验证路径和暂不采用其他路线的依据。

## 七、常见误判与处理

| 学生误判 | 典型表现 | 处理方式 |
| --- | --- | --- |
| 只看温度最低 | 认为预冷越强越好 | 追问冻伤风险、能耗、切换和恢复条件 |
| 数据驱动等于替代控制器 | 希望直接预测压缩机占空比 | 回到 PI/PID 主结构、前馈补偿和温区检查 |
| 策略学习更前沿所以应优先 | 不讨论训练覆盖和安全壳 | 要求列出状态、动作、拒绝条件和回退路线 |
| 没有越界就能部署 | 忽略 E3 故障覆盖 | 区分单次仿真合格与部署证据闭合 |
| 验证负担是性能指标 | 把“高负担”当成曲线计算值 | 说明它是方法选择证据维度，不替代控制性能指标 |

## 八、板书收束

建议用以下判断链收束：

```text
冷链任务约束：2°C-8°C + 连续监测 + 异常处置
        ↓
二状态模型：空气温度快，货品核心温度慢
        ↓
同一日志三路线比较：经典 / 预测补偿 / 策略监督
        ↓
常规日：经典足够
入库高峰：预测补偿有明确收益
未见扰动：策略监督层验证不足
        ↓
方法选择说明卡：收益、风险、验证路径同时写清楚
```

收束句可以落在：更前沿的方法扩大了选择空间，但真正决定路线的是证据能否闭合。

## 九、批改关注点

批改方法选择说明卡时优先看四件事：

1. 是否写清任务对象和安全后果，避免只列方法名。
2. 是否引用 E1/E2/E3 的具体指标支持路线选择。
3. 是否说明数据驱动解决的是入库热负荷预判与恢复时间，并非全局替代控制器。
4. 是否把策略学习限定在监督层候选，并写出训练覆盖、安全壳、拒绝条件和部署监控。

只写“采用数据驱动，因为效果最好”或“采用策略学习，因为更先进”的答案，应判定为证据不足。
