**模板**：`content.formula` + `content.figure` + `content.reveal`

**学生状态**：正文自由阅读；显影链默认收缩，不可自主展开

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：本步骤互动方式由学生状态、元素顺序、作答卡或显影链定义。
**教师控制**：`teacher_step_reveal` 逐层显影

**元素顺序**：标题 → 船舶方程+解释 → 图 1-2-2 → 显影链（4 层）→ 四不便总结

- **标题**：微分方程——物理对象的第一次翻译
- **标题说明**：建模的第一步——把运动规律写成微分方程。贴近物理直觉，但串联、比较、频域分析不便。
- **船舶方程**：

  $$J\ddot{\theta}(t) + B\dot{\theta}(t) = K u(t)$$

  | 符号 | 含义 | 物理效应 |
  |------|------|------|
  | $\theta(t)$ | 航向角 | 输出 |
  | $u(t)$ | 舵机控制作用 | 输入 |
  | $J$ | 转动惯量 | 抵抗角加速度 |
  | $B$ | 阻尼系数 | 抵抗角速度 |
  | $K$ | 控制力矩系数 | 控制效率 |

- **图 1-2-2**：船舶航向物理示意图——船体俯视图，标注舵角、航向角、力矩方向、阻尼方向、因果关系箭头。

**显影链——直接求解的代价**（取 $J=1, B=2, K=5$，单位阶跃，零初值）：

- **静态提示**：下面演示一个具体求解——看看仅为了回答"对阶跃输入怎么响应"需要走多远。
- **第 1 层·齐次解**：特征方程 $r^2+2r=0$ → $r_1=0, r_2=-2$ → $\theta_h(t)=C_1+C_2e^{-2t}$
- **第 2 层·特解**：输入为常数 5，猜 $\theta_p(t)=At$，代入得 $A=5/2$ → $\theta_p(t)=\frac{5}{2}t$
- **第 3 层·定系数**：$\theta(0)=0, \dot{\theta}(0)=0$ → $C_1=-\frac{5}{4}, C_2=\frac{5}{4}$ → $\theta(t)=\frac{5}{2}t-\frac{5}{4}+\frac{5}{4}e^{-2t}$
- **第 4 层·响应曲线 + 四不便**：
  - 图 1-2-3：$\theta(t)$ 曲线——输出持续增长，不收敛（系统本身不稳定）
  - **四个不便**：①求解步骤与对象、输入绑定——换输入重来 ②多环节串联时联立求解繁琐 ③不同对象即使结构相似，也不易从求解中认出 ④天然在时间轴，做频域需重新架桥
- **知识卡片**：微分方程_1_2（常显）

## 步骤 6｜传递函数——从微分运算到代数运算

**对应讲义**：四

**模板**：`content.table` + `content.formula` + `content.reveal` + `activity.panel`（1 题）

**学生状态**：正文自由阅读；显影链默认收缩；作答区默认隐藏

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：本步骤互动方式由学生状态、元素顺序、作答卡或显影链定义。
**教师控制**：`teacher_step_reveal` + `release_activity`

**元素顺序**：标题 → 拉氏变换规则表 → 显影链（4 层）→ 图 1-2-4 → 含义要点 → 跨对象迁移 → 作答

- **标题**：传递函数——从微分运算到代数运算
- **标题说明**：借助拉氏变换，导数 → 乘法，微分方程 → 代数分式。三步得到 $G(s)$。

**拉氏变换基本规则**：

| $f(t)$ | $F(s)$ | 说明 |
|:---|:---|:---|
| $1(t)$ | $1/s$ | 单位阶跃 |
| $\dot{f}(t)$ | $sF(s)-f(0)$ | 一阶导 → × $s$ |
| $\ddot{f}(t)$ | $s^2F(s)-sf(0)-\dot{f}(0)$ | 二阶导 → × $s^2$ |

> 核心规律：对 $t$ 求一次导 → 在 $s$ 域多乘一个 $s$

**显影链——三步法**（船舶 $J\ddot{\theta}+B\dot{\theta}=Ku$，零初值）：

- **第 1 层·拉氏变换**：$\mathcal{L}\{J\ddot{\theta}\}=Js^2\Theta$，$\mathcal{L}\{B\dot{\theta}\}=Bs\Theta$，$\mathcal{L}\{Ku\}=KU$ → $Js^2\Theta+Bs\Theta=KU$
- **第 2 层·提取公因子**：$\Theta(Js^2+Bs)=KU$
- **第 3 层·写出比值**：$G(s)=\frac{\Theta}{U}=\frac{K}{Js^2+Bs}$
- **第 4 层·分解分母**：$G(s)=\frac{K/J}{s(s+B/J)}$——$s$：积分效应；$s+B/J$：阻尼决定的衰减因素

- **图 1-2-4**：三列并排——时域 DE → $s$ 域代数方程 → $G(s)$
- **两个核心含义**：① $G(s)$ 描述系统本身，与输入无关 ② 分母结构暴露内在信息——极点、型别、阻尼比的共同源头
- **跨对象迁移**：RC 电路与热水箱 → 共用 $G(s)=\frac{K}{\tau s+1}$。不是物理相似，是动态结构相似。
- **知识卡片**：拉氏变换_1_2、传递函数_1_2（常显）

**作答**（单选，双栏左）：拉氏变换的核心效果是？
- A. 代数→微分 / B. 对 $t$ 求导→乘 $s$，微分方程→代数方程 / C. 复数→实数 / D. 输入→输出
- 答案：B

## 步骤 9｜极点的几何来源——三维幅值曲面

**对应讲义**：六·6.1

**模板**：`content.rich` + `content.formula` + `compute.panel`（可拖动三维曲面）

**学生状态**：自由阅读 + 自由拖动探索；无普通互动题

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：本步骤互动方式由学生状态、元素顺序、作答卡或显影链定义。

**元素顺序**：标题 → 极点名称来源简述 → 船舶 $G(s)$ 两极点 → 三维幅值曲面面板 → 相位方向曲面参照 → 面板下总结 → $e^{\sigma t}\sin(\omega t)$ 公式 → 图鉴表

- **标题**：极点的几何来源——三维幅值曲面
- **标题说明**："极点"名字来自几何直观——$\vert G(s)\vert$ 在分母根处 → ∞，曲面上竖起"极柱"。

$$G(s)=\frac{K/J}{s(s+B/J)}$$

极点：$s=0$，$s=-B/J$

**三维幅值曲面面板**（`compute.panel`）：

- 内容：$20\log_{10}\vert G(s)\vert$ 在 $s$ 平面上的三维曲面。$s$ 平面为底（横 $\sigma$，纵 $j\omega$），高度 = 对数幅值（dB）。$s=0$ 和 $s=-B/J$ 处高峰（截顶）。
- 控件（图下方）：水平拖拽旋转 · 滚轮缩放 · 俯视图按钮（切换顶视，标注极点 × 位置）
- 读图口令：找最高的两根柱 → 切换俯视 → 看到两个 × 的坐标 → $s=0$ 在原点（虚轴上），$s=-B/J$ 在左半平面实轴上

- **相位方向曲面参照**：`1-2-fig-09-phase-surface.png`。它显示 $\sin(\arg G(s))$ 随 $s$ 平面位置变化的方向信息，用来补充幅值曲面只能显示"极柱高度"的局限；学生只需观察相位方向会随位置改变，不展开复变函数主值分支。
- **面板下总结**：极点位置由系统参数决定（$J, B$ → $-B/J$）。极点位置反过来决定系统行为——$\vert G(s)\vert$ 的柱在哪里，响应就被哪里左右。
- **公式**：极点 $s=\sigma\pm j\omega$ → 响应含 $e^{\sigma t}\sin(\omega t)$。$\sigma$ 管包络（衰减/放大/快慢），$\omega$ 管填充（单调/振荡/密疏）

**极点图鉴**：

| 极点位置 | 行为 |
|------|------|
| 左半平面，远离虚轴 | 快速单调收敛 |
| 左半平面，靠近虚轴 | 缓慢单调收敛，拖尾 |
| 左半平面，远离实轴 | 边摆边收，摆动密 |
| 左半平面，靠近实轴 | 边摆边收，摆动疏 |
| 虚轴上 | 等幅振荡 |
| 右半平面 | 幅度放大，失控 |
