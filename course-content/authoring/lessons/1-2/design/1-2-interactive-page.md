## 全课总览

14 步互动课件，覆盖建模专题全地形：机理 vs 数据驱动 → 微分方程 → 传递函数 → 方框图 → 信号流图 → 极点三维曲面 → 拖极点看响应 → 案例仿真 → 例题显影 → 后测 → 总结。

## 步骤 1｜导入——不同对象的行为差异与共性

**对应讲义**：一

**模板**：`content.rich` + `content.figure`，双栏

**学生状态**：自由阅读，无作答

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：本页不设置作答。导入漫画和问题句承担 Bridge-in 作用，必须常显，不能被教师显影或学生提交状态遮挡。

**元素顺序**：标题 → 左侧情境要点 → 右侧导入漫画 → 底部问题句

- **标题**：不同对象的行为差异与共性
- **标题说明**：同样的"到目标值"任务，不同对象表现截然不同；有些物理上毫无关系的对象，行为却会呈现同一种动态结构。
- **左侧情境要点**：
  - 船舶航向修正：平稳靠近 / 先冲后摆 / 越调越偏
  - 电机调速、液位控制、温度调节也会出现相似的响应形态
  - **反向证据**：RC 电路与热水箱物理机理完全不同，却都可能表现为一阶惯性响应
- **右侧导入漫画**：`1-2-cover-comic.png`。画面中船舶、方程、传递函数和 s 平面行为地图同时出现，用场景提出"真实对象怎样变成可分析模型"的问题。
- **图下文案**：图中同一艘船既是工程对象，也是方程和极点地图的来源；本课要把这种转换链写清楚。
- **底部问题句**：在工程对象的差异之下，是否存在一套统一的描述语言？→ **建模**

**自包含检查**：漫画场景提出真实对象如何进入统一分析语言的问题，左侧现象对比引出建模定义。

**互动升级点**：用非线性推导舞台替代普通纵向折叠显影。物理项、齐次解、特解、定系数、响应曲线和四个不便分布在不同舞台区域，教师可非线性跳转和局部强调。
**教师控制**：`teacher_step_reveal` 逐层显影

**元素顺序**：标题 → 船舶方程舞台 → 图 1-2-2 → 非线性显影链 → 四不便总结

- **标题**：微分方程——物理对象的第一次翻译
- **标题说明**：建模的第一步——把运动规律写成微分方程。贴近物理直觉，但串联、比较、频域分析不便。

**推导舞台**（`visual.derivationStage`）：

- **左上·物理对象区**：船舶航向控制对象，保留图 1-2-2 的舵角、航向角、力矩方向、阻尼方向。
- **右上·方程区**：主公式以 LaTeX 呈现：

  $$J\ddot{\theta}(t)+B\dot{\theta}(t)=Ku(t)$$

  公式块按语义分色：$J\ddot{\theta}(t)$ 为惯性项，$B\dot{\theta}(t)$ 为阻尼项，$Ku(t)$ 为控制输入项。颜色使用语义 role，不写局部颜色值。
- **左下·符号区**：$\theta(t)$ 航向角，$u(t)$ 舵机控制作用，$J$ 转动惯量，$B$ 阻尼系数，$K$ 控制力矩系数。
- **右下·求解代价区**：直接求解链和四个不便。

- **图 1-2-2**：船舶航向物理示意图——船体俯视图，标注舵角、航向角、力矩方向、阻尼方向、因果关系箭头。

**非线性显影链——直接求解的代价**（取 $J=1, B=2, K=5$，单位阶跃，零初值）：

- **静态提示**：下面演示一个具体求解——看看仅为了回答"对阶跃输入怎么响应"需要走多远。
- **第 1 层·物理项定位**：高亮惯性项、阻尼项和输入项，说明方程每项来自真实对象。
- **第 2 层·齐次解**：特征方程 $r^2+2r=0$ → $r_1=0, r_2=-2$ → $\theta_h(t)=C_1+C_2e^{-2t}$。
- **第 3 层·特解**：输入为常数 5，猜 $\theta_p(t)=At$，代入得 $A=5/2$ → $\theta_p(t)=\frac{5}{2}t$。
- **第 4 层·定系数**：$\theta(0)=0, \dot{\theta}(0)=0$ → $C_1=-\frac{5}{4}, C_2=\frac{5}{4}$ → $\theta(t)=\frac{5}{2}t-\frac{5}{4}+\frac{5}{4}e^{-2t}$。
- **第 5 层·响应曲线 + 四不便**：
  - 图 1-2-3：$\theta(t)$ 曲线——输出持续增长，不收敛（系统本身不稳定）
  - **四个不便**：①求解步骤与对象、输入绑定——换输入重来 ②多环节串联时联立求解繁琐 ③不同对象即使结构相似，也不易从求解中认出 ④天然在时间轴，做频域需重新架桥
- **知识卡片**：微分方程_1_2（常显）

**认知负荷限制**：每个显影步骤最多新增 2 个公式块；长公式必须拆成“特征方程”“通解”“完全解”三个块；公式块可语义变色，但同屏同时强调的颜色角色不超过 3 个。

## 步骤 6｜传递函数——从微分运算到代数运算

**对应讲义**：四

**模板**：`visual.derivationStage` + `content.table` + `activity.panel`（1 题）

**学生状态**：正文自由阅读；推导舞台按教师节奏显影；作答区默认隐藏

**静态承载内容**：拉氏变换规则表、微分方程到传递函数的公式链、含义要点和作答题面直接承载。

**互动升级点**：用 `visual.derivationStage` 承载“时域方程 → 拉氏变换 → 代数整理 → $G(s)$ → 分母结构”的二维转换链。长公式按块显影，导数项、输出项、输入项可语义变色。
**教师控制**：`teacher_step_reveal` + `release_activity`

**元素顺序**：标题 → 拉氏变换规则表 → 公式推导舞台 → 图 1-2-4 对照 → 含义要点 → 跨对象迁移 → 作答

- **标题**：传递函数——从微分运算到代数运算
- **标题说明**：借助拉氏变换，导数 → 乘法，微分方程 → 代数分式。三步得到 $G(s)$。

**拉氏变换基本规则**：

| $f(t)$ | $F(s)$ | 说明 |
|:---|:---|:---|
| $1(t)$ | $1/s$ | 单位阶跃 |
| $\dot{f}(t)$ | $sF(s)-f(0)$ | 一阶导 → × $s$ |
| $\ddot{f}(t)$ | $s^2F(s)-sf(0)-\dot{f}(0)$ | 二阶导 → × $s^2$ |

> 核心规律：对 $t$ 求一次导 → 在 $s$ 域多乘一个 $s$

**公式推导舞台**（`visual.derivationStage`）：

- **左侧·时域方程**：$J\ddot{\theta}(t)+B\dot{\theta}(t)=Ku(t)$。
- **中部·变换规则应用**：$\mathcal{L}\{\ddot{\theta}\}=s^2\Theta(s)$，$\mathcal{L}\{\dot{\theta}\}=s\Theta(s)$，$\mathcal{L}\{u(t)\}=U(s)$。每个公式块保留 LaTeX 源。
- **右侧·代数对象**：$Js^2\Theta(s)+Bs\Theta(s)=KU(s)$ → $\Theta(s)(Js^2+Bs)=KU(s)$ → $G(s)=\frac{\Theta(s)}{U(s)}=\frac{K}{Js^2+Bs}$。
- **底部·结构解释**：$G(s)=\frac{K/J}{s(s+B/J)}$，其中 $s$ 表示积分效应，$s+B/J$ 暴露阻尼决定的衰减因素。

**显影步骤**：

- **第 1 层·导数变乘法**：只显影变换规则应用区，强调对时间求导在 $s$ 域变成乘以 $s$。
- **第 2 层·方程变代数式**：显影 $Js^2\Theta+Bs\Theta=KU$，连接线从时域方程指向代数方程。
- **第 3 层·输出输入比值**：显影 $G(s)=\frac{\Theta}{U}$，把输出项与输入项分别高亮。
- **第 4 层·分母结构**：显影 $s(s+B/J)$，用语义色区分积分效应与阻尼衰减因素。

- **图 1-2-4**：三列并排——时域 DE → $s$ 域代数方程 → $G(s)$
- **两个核心含义**：① $G(s)$ 描述系统本身，与输入无关 ② 分母结构暴露内在信息——极点、型别、阻尼比的共同源头
- **跨对象迁移**：RC 电路与热水箱 → 共用 $G(s)=\frac{K}{\tau s+1}$。不是物理相似，是动态结构相似。
- **知识卡片**：拉氏变换_1_2、传递函数_1_2（常显）

**作答**（单选，双栏左）：拉氏变换的核心效果是？
- A. 代数→微分 / B. 对 $t$ 求导→乘 $s$，微分方程→代数方程 / C. 复数→实数 / D. 输入→输出
- 答案：B

**视觉组件状态矩阵**：教师端支持上一层、下一层、跳转、局部高亮、答案揭示和复位；学生提交时记录已看到的最大显影层、当前显影层和作答结果。

## 步骤 9｜极点的几何来源——三维幅值曲面

**对应讲义**：六·6.1

**学生状态**：自由阅读 + 自由拖动探索；无普通互动题

- **标题**：极点的几何来源——三维幅值曲面
- **标题说明**："极点"名字来自几何直观——$\vert G(s)\vert$ 在分母根处 → ∞，曲面上竖起"极柱"。

$$G(s)=\frac{K/J}{s(s+B/J)}$$

极点：$s=0$，$s=-B/J$

**三维幅值曲面面板**（共享三维曲面计算面板）：

- 内容：$20\log_{10}\vert G(s)\vert$ 在 $s$ 平面上的三维曲面。$s$ 平面为底（横 $\sigma$，纵 $j\omega$），高度 = 对数幅值（dB）。$s=0$ 和 $s=-B/J$ 处高峰（截顶）。
- 视觉要求：采用类似 MATLAB 的曲面视觉效果，默认视角接近 MATLAB `surf` 视角；采样率高于旧静态图，网格线、色带、坐标轴、极点标注都可读。
- 控件（图下方）：水平拖拽旋转 · 滚轮缩放 · 俯视图按钮（切换顶视，标注极点 × 位置）
- 读图口令：找最高的两根柱 → 切换俯视 → 看到两个 × 的坐标 → $s=0$ 在原点（虚轴上），$s=-B/J$ 在左半平面实轴上

- **相位方向曲面参照**：`1-2-fig-09-phase-surface.png`。它显示 $\sin(\arg G(s))$ 随 $s$ 平面位置变化的方向信息，用来补充幅值曲面只能显示"极柱高度"的局限；学生只需观察相位方向会随位置改变，不展开复变函数主值分支。
- **面板下总结**：极点位置由系统参数决定（$J, B$ → $-B/J$）。极点位置反过来决定系统行为——$\vert G(s)\vert$ 的柱在哪里，响应就被哪里左右。
- **公式**：极点 $s=\sigma\pm j\omega$ → 响应含 $e^{\sigma t}\sin(\omega t)$。$\sigma$ 管包络（衰减/放大/快慢），$\omega$ 管填充（单调/振荡/密疏）

**极点图鉴**：

| 极点位置 | 行为 |
|------|------|
| 左半平面，远离虚轴 | 快速单调收敛 |
| 左半平面，靠近虚轴 | 缓慢单调收敛，拖尾 |
| 左半平面，远离实轴 | 边摆边收，摆动密 |
| 左半平面，靠近实轴 | 边摆边收，摆动疏 |
| 虚轴上 | 等幅振荡 |
| 右半平面 | 幅度放大，失控 |

| B | $-3.0,\ -0.8$ | 两实极点均在左：单调收敛，$-0.8$ 更近虚轴 → 主导慢衰减 |
| C | $0.3\pm1.4j$ | 右半平面 + 明显虚部：摆动着发散 |

**共享控制对比面板**：三艘船航向响应。控件：A/B/C/全部切换 · 时间轴缩放 · 单船高亮。默认三线并排——A（边摆边收），B（单调收敛），C（发散）。三条曲线必须使用语义系列标签、线型或标记区分，颜色只来自主题 token，不能依赖固定蓝/绿/红。曲线、图例、时间轴和 fallback 均复用共享工作台。

**图上证据任务**（`visual.annotatedMedia`）：

- **媒体**：三艘船响应曲线或控制对比面板截图/画布锚点，alt 为“三艘船航向响应对比”。
- **热点**：
  - A 的超调与衰减区：证据角色 `oscillatory-decay`
  - B 的慢尾部：证据角色 `dominant-pole`
  - C 的发散包络：证据角色 `unstable-growth`
  - B 的 $-0.8$ 极点位置：证据角色 `near-imaginary-axis`
- **嵌入活动**：题面“模型 B 的收敛速度主要由哪个证据决定？”锚定在 B 曲线尾部旁，选项与下方作答一致。

- **读图**：A——左半平面保证了衰减，虚部 → 可见摆动，先冲后收。B——无摆动，但 $-0.8$ 离虚轴近 → 衰减慢，不保证比 A 快。C——实部正，幅度放大，失控。
- **收束**：三组极点 → 三种行为。复平面上的点把"平稳、摆动、失控"压缩进一张统一地图。

**作答**（单选，双栏左）：模型 B 的收敛速度主要由哪个极点主导？
- A. $-3.0$ / B. $-0.8$（离虚轴更近） / C. 平均值 $-1.9$ / D. 无法判断
- 答案：B

**教师诊断口径**：统计学生是否选中了 B 的近虚轴极点、是否误把 $-3.0$ 当主导极点、是否忽略 C 的发散包络。热点选择和单选答案应进入同一次视觉任务证据。

**释放与提交状态**：释放前学生可浏览极点表、响应图和工作台预览，但热点选择与单选作答锁定；释放后热点可选、客观题可提交。教师端需要分别统计热点诊断、工作台参数提交和客观题答案，不能把三类证据混成一个“已操作”计数。

**视觉组件状态矩阵**：学生端显示对比表、工作台、热点图和单选题；教师端可释放热点任务并查看遗漏热点、误选热点和选项分布；浅色/深色/投影端必须保证 A/B/C 系列标签、热点圈、热点说明和单选控件可读；移动端热点说明可用底部浮层呈现，但必须保留被选证据可见。工作台或热点图不可用时使用课程态文案，引导学生依据极点表和热点文字判断，不显示 capability、spec、payload、Rust、WASM 等工程语义。

## 步骤 12｜例题——从特征方程到行为判断

**对应讲义**：八、九

**模板**：`visual.derivationStage` + `activity.panel`（1 题）

**学生状态**：题面常显；推导舞台按教师节奏显影；作答隐藏

**静态承载内容**：题面、特征方程、求根过程、读图判断、行为结论和分层练习均直接承载。

**互动升级点**：用非线性推导舞台替代普通纵向折叠显影。推导链允许从题面跳到特征方程、再跳到极点、再回到复平面读图区域；公式严格以 LaTeX 源渲染，长公式按块显影。
**教师控制**：`teacher_step_reveal` + `release_activity` + `reveal_reference_answer`

**元素顺序**：标题 → 题面（常显）→ 非线性推导舞台 → 分层练习卡 → 收束 → 作答

- **标题**：例题——从特征方程到行为判断
- **标题说明**：完整求解链——微分方程 → 特征方程 → 极点 → 读图 → 行为。

**题面**（常显）：系统模型 $\ddot{y}+2\dot{y}+5y=5r$，$r$ 为期望位置。根据极点位置判断行为特征。

**非线性推导舞台**（`visual.derivationStage`）：

- **左上·题面区**：系统模型 $\ddot{y}+2\dot{y}+5y=5r$，保留为常显题面，不受显影控制。
- **右上·特征方程区**：$s^2+2s+5=0$。
- **右中·求根区**：$\Delta=4-20=-16$，$s_{1,2}=\frac{-2\pm4j}{2}=-1\pm2j$。公式分块显影：判别式、根公式、最终极点三块独立。
- **左下·复平面读图区**：标出 $-1\pm2j$，高亮左半平面和振荡走廊。
- **右下·行为结论区**：边摆动边收敛；位置先越过目标，再边摆边收回。

**显影链**：

- **第 1 层·特征方程**：$s^2+2s+5=0$ → 知识卡片：特征方程_1_2
- **第 2 层·解极点**：$\Delta=4-20=-16$，$s_{1,2}=\frac{-2\pm4j}{2}=-1\pm2j$ → 知识卡片：特征根_1_2
- **第 3 层·读图**：$\sigma=-1$（左半平面 → 衰减），$\omega=\pm2$（不为零 → 摆动）
- **第 4 层·行为**：边摆动边收敛。位置先越过目标，再边摆边收回。粗粒度判断——方向感已建立；精确数值指标在模块 2 引入。

**分层练习卡**：

- 基础辨认：给定左半平面实极点、左半平面共轭极点、右半平面极点，写出第一轮行为描述。
- 反向读图：给定"缓慢单调收敛""边摆边收""越调越偏"，推断极点大致落在复平面的哪个区域。
- 迁移应用：电机转速、房间温度、船舶航向若具有相近极点分布，可用同一条"对象 → 模型 → 极点 → 行为"链讨论动态品质。

**作答**（单选，双栏左）：极点 $s=-3$ 的系统行为是？
- A. 边摆边收，摆动密 / B. 单调收敛，较快 / C. 等幅振荡 / D. 单调发散
- 答案：B

**视觉组件状态矩阵**：学生端已释放时显示当前显影层和已浏览层；教师端支持任意跳转到题面、特征方程、求根、读图、行为结论五个区域。浅色/深色/投影端必须保证公式分块、根的位置和行为判断颜色 role 可读；移动端长公式可分块换行和逐步显影，不得裁切或转成图片；提交证据记录最大显影层、当前显影层和答案，显影浏览不单独计为掌握证据。

## 步骤 13｜后测

**模板**：`activity.panel` 题组

**学生状态**：每题独立提交

**静态承载内容**：本步骤正文、图表、题面、公式或收束句为页面直接承载内容。

**互动升级点**：后测只使用 `activity.panel` 题组，不额外添加说明卡或互动任务标题模块。两道客观题进入自动统计，主观题进入教师复核列表。

- **标题说明**：2 客观 + 1 主观，对应五个能力项。

**题 1**（单选）：机理建模与数据驱动建模的主要区别？
- A. 一个快一个慢 / B. 前者从物理定律出发（可解释），后者从数据出发（不依赖先验知识） / C. 一个只用于船一个只用于电路 / D. 无本质区别

**题 2**（判断）：极点在复平面上越靠近虚轴，系统衰减越慢，拖尾越长。

**参考要点**：物理定律→微分方程；拉氏变换→传递函数 $G(s)$；分母=0→极点坐标 $(\sigma, j\omega)$；标注于 $s$ 平面——$\sigma$ 管收放，$\omega$ 管摆动；读极点位置→判断行为。

## 步骤 14｜总结——建模专题的局部地图

**对应讲义**：十

**模板**：`visual.stage` 总结地图 + `analytics.summary`

**学生状态**：自由阅读

**静态承载内容**：课程信息图、五个地标、局限性、拓展思考和统计摘要直接承载。

**互动升级点**：用 `visual.stage` 把五个地标放在同一张建模地图上：真实对象 → 微分方程 → 传递函数 → 结构表达 → 极点/复平面 → 行为。总结不新增作答，只作为统计回看和课程链路收束。

**元素顺序**：信息图 → 总结地图舞台 → 局限性 → 拓展思考 → 学生/教师统计

- **标题**：总结——建模专题的局部地图
- **信息图**：1-2-info（顶部常显）

**总结地图舞台**（`visual.stage`）：

- **左侧起点**：真实对象。标注“工程对象具体不同，行为可进入同一语言”。
- **第一地标·微分方程**：建模起点，直接翻译物理定律。不便串联/比较/频域。
- **第二地标·传递函数**：拉氏变换 → 导数变乘法。$G(s)$ 紧凑代数对象。不同对象进入同一语言。
- **第三地标·方框图/信号流图**：方框图表达环节结构；信号流图表达变量关系。两者描述同一系统的不同组织方式。
- **第四地标·极点与复平面**：分母根 → 行为坐标。$s$ 平面五区——横轴管收放，纵轴管摆动。
- **右侧终点**：行为判断。收敛、发散、摆动、单调、快慢可以被同一张地图读取。
- **教师显影**：可按五个地标逐个显影，也可一次显示完整地图。学生端默认完整显示。

- **局限性**：粗粒度行为地图——知脾气（收敛/发散/摆动/单调/快慢），不知精确指标值。高阶系统和零点影响在模块 3。
- **拓展思考**：两物理对象极点分布相近 → 能否用同一语言讨论动态品质？哪些细节可省略，哪些必须保留？
- **学生统计**（`analytics.summary`）：提交次数 · 客观题正确率 · 前测/后测对比 · 步骤 10 极点探索记录
- **教师统计**（`analytics.summary`）：班级客观题正确率、视觉组件提交覆盖、结构图常见遗漏、热点任务误选分布、后测主观题待复核数量
- **知识卡片**：模型结构相似性_1_2（总结回看）

**视觉组件状态矩阵**：学生端显示五个地标的空间地图和学习统计；教师端可高亮任一地标并回指对应页面；浅色/深色/投影端必须保证地标、路径和统计摘要可读；移动端可纵向展开地图节点但不得变成空白统计模块；总结图不可用时保留五地标文字回顾和拓展思考。
