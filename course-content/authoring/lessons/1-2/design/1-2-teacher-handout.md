# 单元 1-2 教师版课堂讲义

## 课堂定位

本课是模块1"先见森林"的第二站——**建模专题的第一轮速通**。学生在 1-1 已经见过整门课的全貌（八个问题 + 二十行代码），本课的任务是把"模型怎么来"这条线，从微分方程一直拉到极点与复平面，在一个课次内让学生建立起建模专题的完整地形感。

核心定位：**这不是建模的正式讲授，而是建模的"预告片"**。微分方程、拉氏变换、传递函数、方框图、信号流图——五个地标全部经过，但每个只讲"它是什么、它解决什么问题、它和前后地标怎么连"。正式的形式化推导在 2-1 中展开，2-1 会把今天种下的每一颗种子都长成完整的树。

本课最需要避免两件事：一是在任何一个地标上停留太久（一旦进入推导模式，90分钟不够用），二是让学生觉得"每个都只讲了一点，什么都没学会"（需要在开场和收束时反复锚定"局部地图"这个框架）。

## 各节教学要点

### 第一节·开场
- 读出两种现象的对比段——"有的平稳靠近目标，有的先冲过头……"和"RC 电路和热水箱行为几乎一样"——这两句话并置，本身就是建模动机
- 三个课程目标口头过一遍，但不要逐字念——说"下课时我希望你们能做三件事"然后用自己的话概括

### 第二节·建模的两条路径
- 机理建模用船舶例子自然过渡——"刚才说的船，物理定律你都清楚，这就是机理建模"
- 数据驱动用一句话讲清：给数据、训模型、出预测。代价用"超出训练范围可能不靠谱"就够了
- 关键收束句："本课程以机理建模为主线。你在模块5会重新遇见数据驱动。"——让学生知道这条路没有被放弃

### 第三节·微分方程
- 船舶方程的建立不需要推导——说"牛顿第二定律告诉我们……"直接写出 $J\ddot{\theta}+B\dot{\theta}=Ku$，解释三项的物理含义即可
- **直接求解演示是本节的教学锚点**：把 $J=1, B=2, K=5$ 代入，在黑板上或页面上展示求解过程（齐次解→特解→定系数→完全解），每一步标注"这一步换一个输入就得重来"。节奏是让学生感受到繁琐，而不是让他们记住求解技巧
- 最后的响应曲线 $\theta(t) = \frac{5}{2}t - \frac{5}{4} + \frac{5}{4}e^{-2t}$ 要展示出来——"注意看，这个输出不是收敛到一个常值，而是持续增长。换句话说，这个系统本身是不稳定的。你花了这么大功夫，得到的结论用传递函数几秒钟就能看到。"
- 四个不便只口头概括，不逐条念——"换输入重来、串联变复杂、不同对象不好比、频域分析不好做"

### 第四节·传递函数
- 拉氏变换表只展示三行，口头强调："对时间求一次导→乘一个 $s$，求两次导→乘 $s^2$。这就是传递函数全部的秘密。"
- 三步法现场走一遍：方程→变换→比值。每一步停在关键等式上 3 秒，让学生看到变形
- 走到 $G(s)=\frac{K}{Js^2+Bs}$ 时，把微分方程和传递函数并排放——"左边是三个物理参数混在导数里的方程，右边是一个紧凑的代数分式。同一个系统，两种语言。"
- 含义段只强调一句话："$G(s)$ 告诉你系统本身是什么，跟输入没关系。"
- 分解分母 $G(s)=\frac{K/J}{s(s+B/J)}$ 时，指着 $s$ 说"这是积分效应"，指着 $s+B/J$ 说"这是阻尼在起作用"——为后续讲极点埋伏笔

### 第五节·方框图与信号流图
- 方框图五要素用一个闭环例子一口气讲完，不要在单个要素上停留
- 三种连接各一句话："串联→乘积，并联→和，反馈→这是控制的核心结构"
- 信号流图的核心信息：方框图以"谁对谁做了什么"组织，信号流图以"变量之间怎样互相决定"组织。两者说的是同一件事
- 不需要让学生画图——只需要他们看到一张图时，能认出"这是方框图""这是信号流图"

### 第六节·极点与复平面
- **复变函数三维可视化是本节最重要的教学资产**。展示幅值曲面时，指着 $s=0$ 和 $s=-B/J$ 两处的高峰说："这就是极点——传递函数在这两个地方趋向无穷。所以叫'极点'，不叫别的名字。"
- 相位曲面快速展示即可——"相位在极点附近会剧烈翻转，这是同一枚硬币的另一面。"
- 极点图鉴表不逐行念。用一句话概括："左半平面→收敛，右半平面→发散，离虚轴越远→越快，离实轴越远→越密。"
- 复平面地名系统要讲出"地图感"——"你可以像记地名一样记这张图：稳定区、不稳定区、振荡走廊、单调走廊、稳定边界。看到极点坐标，就像看到地图上的经纬度，你能立刻说出那个地方的气候。"

### 第七节·案例 + 第八节·例题
- 案例的三艘船并排展示——让学生先自己看表格 10 秒，再逐个分析
- 模型 B 的分析是难点：两个实极点都在左侧，但 $-0.8$ 比 $-3.0$ 更靠近虚轴，所以它拖慢了整个过程。让学生意识到"最靠右的极点决定衰减快慢"——这是主导极点直觉的第一次伏笔
- 例题可在黑板上一步一步走：写特征方程 → 解二次方程 → 读出 $\sigma$ 和 $\omega$ → 翻译成行为描述。这是学生第一次亲手走完"模型→极点→行为"的完整链

### 第十节·收束
- 朗读五个地标总结段。读完一段停 2 秒，让学生自己把五个地标在脑子里排一遍
- 最后一句"深挖时，你手上已经有了一张可以随时参照的地图"——停顿，让学生感受到这句话的分量

## 常见学生误判与介入策略

| 学生可能的误判 | 教师介入 |
|------|------|
| "拉氏变换看不懂，这课跟不上了" | "今天只需要知道它把求导变乘法。怎么变的、为什么能这样变，2-1 会用一整节课专门讲。你今天唯一的任务——记住这个效果。" |
| 看到直接求解演示后："微积分都忘光了" | "你不是一个人。这个演示的目的恰恰是让你看到——不用微积分，改用传递函数，问题会简单多少。如果刚才的求解让你感到繁琐，那就对了。这正是传递函数存在的理由。" |
| "方框图和信号流图有什么区别？为什么要学两种？" | "就像看地图——方框图是卫星图，信号流图是路网图。同一座城市，不同视角。哪个好用用哪个。" |

## 板书建议

- 黑板**左侧**固定保留：建模链——`微分方程 → 传递函数 → 方框图/信号流图 → 极点 → 复平面`（纵向排列），每个箭头旁标注核心操作关键词（"拉氏变换""串联/并联/反馈""特征方程求解""实部↔收放，虚部↔摆动"）
- 黑板**右侧**固定保留：船舶传递函数 $G(s)=\frac{K/J}{s(s+B/J)}$，标注两个极点位置 $s=0$ 和 $s=-B/J$，以及一个简笔复平面草图（左半平面、右半平面、虚轴、实轴）
- 黑板**中间**随进度擦写：第三节写求解过程，第四节写拉氏变换表和推导链，第五节画方框图和信号流图，第六节画极点在复平面上的位置
- 下课时黑板上只保留左右两列——**左侧是建模全链，右侧是船舶例子和复平面草图**。这是学生最可能带走的两件事

## 附录：习题完整解答

### 练习 1 基础辨认

**1.** $s = -2.5$
- 虚部为零 → 无摆动倾向，过程为单调变化。
- 实部 $-2.5 < 0$，落在左半平面且离虚轴较远 → 偏差会收敛，衰减较快。
- 综合判断：快速单调收敛。实际装置上输出会平稳地趋向目标值，几乎看不到振荡。

**2.** $s_{1,2} = -0.4 \pm 1.8j$
- 虚部 $\pm 1.8 \neq 0$ → 有摆动倾向，$|\omega| = 1.8$ 不小，摆动比较明显。
- 实部 $-0.4 < 0$，落在左半平面但靠近虚轴 → 偏差会收敛，但衰减缓慢，拖尾长。
- 综合判断：边摆边收，摆动较明显，收敛较慢。实际装置上输出会多次越过目标值再收回，收敛过程拖得比较久。

**3.** $s = 0.2$
- 虚部为零 → 无摆动倾向，单调变化。
- 实部 $0.2 > 0$，落在右半平面 → 偏差会被放大而非收敛。在物理系统中，输出幅度随时间持续增长。
- 综合判断：单调发散。实际上意味着系统已经失控——任何微小的初始偏差都会被不断放大。

### 练习 2 反向读图

**1.** 系统单调收敛，但过程很慢
- 单调 → 无摆动 → $\omega = 0$ 或很小（极点落在实轴上或紧贴实轴）。
- 收敛 → $\sigma < 0$（左半平面）。
- 过程很慢 → 衰减弱 → $|\sigma|$ 很小（极点靠近虚轴）。
- 推断：极点落在左半平面实轴上、紧邻虚轴的位置，如 $s = -0.1$。

**2.** 系统快速摆动，同时幅度越来越大
- 快速摆动 → 振荡密 → $|\omega|$ 大（远离实轴）。
- 幅度越来越大 → 发散 → $\sigma > 0$（右半平面）。
- 推断：极点落在右半平面、远离实轴的位置，如 $s = 0.5 \pm 5j$。

**3.** 系统边摆边收，摆动稀疏但拖尾很长
- 边摆边收 → 有摆动 + 收敛 → $\omega \neq 0$ 且 $\sigma < 0$。
- 摆动稀疏 → $|\omega|$ 小（靠近实轴）。
- 拖尾很长 → 衰减慢 → $|\sigma|$ 小（靠近虚轴）。
- 推断：极点落在左半平面、靠近虚轴且靠近实轴的位置，如 $s = -0.3 \pm 1.2j$。

### 练习 3 迁移应用

**1.** 控制课程的分析语言建立在模型结构上，而不是建立在具体物理对象上。微分方程→传递函数→极点→复平面这条链，对船舶、电机、温控系统是完全相同的。一旦三个对象被写成具有相近极点分布的传递函数，它们就进入了同一套数学框架——后续的时域分析、频域分析、根轨迹工具对所有对象一视同仁。控制工程师关心的不是"对象是什么材料做的"，而是"对象的极点在哪里"。

**2.** "相近"主要指行为模式相近，具体包括三个维度：（a）衰减速度——由极点实部 $\sigma$ 决定，$\sigma$ 越负衰减越快；（b）摆动密度——由极点虚部 $\omega$ 决定，$|\omega|$ 越大摆动越密；（c）稳定性——由 $\sigma$ 的符号决定，全负则稳定。这才是控制工程师关心的动态品质，与对象的物理材质、工作原理、尺寸规模无关。

**3.** 模型最少必须保住**决定主要动态关系的那些结构和参数**。具体来说，就是那些会显著改变极点位置的物理效应——主导惯性（决定了时间常数量级）、主要阻尼（决定了衰减快慢）、关键刚度或增益（决定了响应幅度）。细节可以被省略——比如高阶模态、微小非线性、缓慢时变参数——只要它们的忽略不会让任何主导极点的坐标发生显著位移。判断标准只有一条：省掉这个效应之后，极点位置还对不对？如果极点的 $\sigma$ 和 $\omega$ 在省略前后没有实质性变化，模型就仍然有意义。如果一个被省略的效应会明显移动极点，那它就不是"细节"，而是模型必须保留的核心结构。
