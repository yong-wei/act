## 文档职责

- 本文件是 `4-6` 作者态互动页面蓝图，负责把讲义中的迁移任务重排、固定结构失配证据、驱逐舰专用代价函数、结构编码入口、四类方案比较、专项验证边界判断、后测与总结落成可直接实现的课堂页面。
- 同目录 `interactive-contract.yaml` 是机读真源；两者必须在步骤顺序、标题、模板、互动类型、教师控制和学生默认状态上逐项一致。
- 本轮设计以讲义顺序为硬约束：`4-5 可用解回收 -> 课程目标 -> 场景配置重排 -> 失配证据 -> 目标重排 -> 结构搜索引入 -> 统一编码与解码 -> 四类方案比较 -> 专项验证 -> 后测 -> 总结`。

## 表述规则

- 每一步都必须回答四件事：对象是什么、正在判断什么、关键证据在哪里、结论如何接回“固定结构边界与结构编码入口”。
- 图片、曲线图和收敛图都必须服从讲义证据顺序，不得抢到公式、题面或职责表之前。
- 后测与总结保持分离；后测只检查判断链，总结只负责收束与移交。
- 显影页可以隐藏的是步骤，不是题面或判断对象本身。

## step-01｜从 `4-5` 可用解到驱逐舰失配：为什么这次不能只说“再调一调参数”

### 页面骨架
- 左列依次放客船对象卡、`4-5` 固定超前可用解卡、迁移问题句与本页收束句。
- 右列放驱逐舰失配证据图与图后阅读口令。

### 模块清单
- 客船对象卡
- `4-5` 固定超前解卡
- 问题聚焦卡
- 驱逐舰失配图
- 图后阅读口令
- 桥接结论卡

### 静态承载内容
- 客船对象常显：`$P_p(s)=\\dfrac{0.01715}{s(s+0.1)(s+2.14375)}$`。
- 固定超前解常显：`$C_p(s)=1.7679\\dfrac{10.4676s+1}{2.6452s+1}$`。
- 问题句必须直接写出：同一对象族进入驱逐舰快速机动任务后，为什么“继续微调参数”已经不足以描述问题。
- 图题固定写“客船代价函数和固定超前结构在驱逐舰对象上的失配证据”。
- 收束句固定写：本课不是先换算法，而是先检查原来的问题写法为什么失效。

### 混合证据顺序
- 先客船对象与 `4-5` 可用解 -> 再问题句 -> 再失配图 -> 最后图后口令与收束句。

- 本页只阅读，不放作答卡。

### 教师控制

## step-04｜固定结构迁移后的失配信号：拖尾、航迹偏离与职责过载如何同时出现

### 页面骨架
- 顶部放客船平衡权重卡与沿用旧结构说明。
- 中部左侧放失配图，右侧放三层失配信号显影链。
- 底部放“旧问题写法失效”的结论卡。

### 模块清单
- 旧代价函数说明卡
- 失配图
- 失配显影链
- 结论卡

### 静态承载内容
- 旧代价函数权重常显：`$B=[0.30,0.30,0.20,0.20]$`。
- 旧总代价常显：`$J_p(\\theta)=0.30\\bar t_s+0.30\\overline{\\mathrm{ITAE}}+0.20\\overline{\\mathrm{ITSE}}+0.20\\bar E_u$`。
- 图后口令必须写明：左图看方波切换段拖尾，右图看航迹偏离如何被积分放大。
- 结论句：这里暴露的不是某一组参数偶然失败，而是固定超前结构和旧判断链一起迁移后已经不再对题。

### 混合证据顺序
- 先旧代价函数与结构沿用说明 -> 再失配图 -> 再三层失配显影 -> 最后结论。

### 互动升级点
- 三层显影链依次写：
  1. 客船语言把首段收敛和总体能量看得比连续快速机动更重。
  2. 固定超前结构只有三项有效参数，低频恢复、中频提速和动作边界只能互相挤占。
  3. 当验证换成“方波跟踪 + 航迹积分”后，旧写法的缺口被持续放大。

### 教师控制
- 教师独立控制显影链；学生端默认不能自主展开。

### 学生默认状态
- 图与结论常显，显影链默认收起。

### 本页脱离讲稿后的自包含检查
- 学生只看本页即可说出三类失配信号，并知道为什么它们共同指向“问题写法失效”。

### 预览口径
- 一个“图先于显影链”的失配证据页，但图前必须先交代沿用的旧代价函数和旧结构。

## step-05｜驱逐舰专用代价函数：为什么比较对象必须重写

### 页面骨架
- 顶部放客船总代价与驱逐舰总代价对照。
- 中部放五项职责表。
- 底部放两张职责判断卡和收束句。

### 模块清单
- 旧总代价卡
- 新总代价卡
- 五项职责表
- 判断卡 `哪一项直接回答船是否走到位`
- 判断卡 `为什么峰值动作和控制能量不能再糊成一项`
- 收束结论卡

### 静态承载内容
- 驱逐舰总代价常显：`$J_d(\\theta)=\\lambda_1\\bar E_{\\mathrm{trans}}+\\lambda_2\\bar E_{\\psi}+\\lambda_3\\bar E_{\\mathrm{traj}}+\\lambda_4\\bar u_{\\mathrm{peak}}+\\lambda_5\\bar E_u$`。
- 五项职责表完整保留：切换段误差、全程跟踪误差、航迹偏离、峰值动作、控制能量。
- 收束句：驱逐舰场景改写的不是一组权重，而是整张比较对象清单。

### 混合证据顺序
- 先旧目标与新目标对照 -> 再五项职责表 -> 最后两张判断卡和收束句。

### 互动升级点
- 两张作答卡题面常显：
  - 哪一项指标直接回答“船是否真正走到位”？
  - 为什么峰值动作与控制能量必须继续分开接受比较？

### 教师控制
- 教师控制作答卡发放与参考答案显示；正文默认常显。

### 学生默认状态
- 正文可见，作答卡默认隐藏。

### 本页脱离讲稿后的自包含检查
- 学生只看本页即可解释五项量各自承担的判断职责，不会把它们理解成旧指标换名版。

### 预览口径
- 先对照公式，再落职责表，不允许把公式压到图后说明里。

## step-06｜何时把结构选择正式抬成问题本身

- 中部放结构搜索引入条件三层显影。
- 底部放五类候选结构的入口卡与收束句。

### 模块清单
- 固定结构可用域收缩链
- 结构搜索引入条件显影链
- 五类候选结构入口卡
- 结论卡

### 静态承载内容
- 入口链常显：`$\\text{对象变换}\\rightarrow\\text{任务变换}\\rightarrow\\text{筛选线重排}\\rightarrow\\text{固定结构职责过载}$`。
- 五类候选结构必须完整列名：`PI`、`超前`、`PI+超前`、`滞后+超前`、带微分滤波的 `PID`。
- 收束句：引入结构搜索不是因为算法更复杂，而是因为固定结构已经不能完整承接当前任务。

### 混合证据顺序
- 先可用域收缩链 -> 再引入条件显影 -> 最后结构入口卡与收束句。

### 互动升级点
- 三层显影链依次写：
  1. 固定结构已无法同时解释速度收益、动作边界和稳健性余量。
  2. 同一组参数同时承担低频、中频和高频职责。
  3. 继续调参只会在同一小块可用域里交换代价。

### 教师控制
- 教师独立控制显影链；学生端默认不自主展开。

### 学生默认状态
- 结构入口卡常显，显影链默认收起。

### 本页脱离讲稿后的自包含检查
- 学生只看本页即可知道“为什么此时才引入结构搜索”，而不是把它理解成任意扩题。

### 预览口径
- 一个“入口判断页”，不提前展示编码细节。

## step-07｜五类结构的统一编码：先判结构，再解释参数

### 页面骨架
- 顶部放六维编码定义卡。
- 中部先放五类结构卡，再放两组最小解码示例显影链。
- 底部放两张解码判断卡和结论句。

### 模块清单
- 六维编码定义卡
- 五类结构卡组
- 解码示例显影链
- 判断卡 `先判结构编号`
- 判断卡 `有效槽位与忽略槽位`
- 收束结论卡

### 静态承载内容
- 六维编码常显：`$[z_0,z_1,\\ldots,z_5]\\in[0,1]^6,\\quad k=\\max(1,\\lceil 5z_0\\rceil)$`。
- 五类结构卡每张都要写清：有效槽位、忽略槽位、参数允许范围、控制器表达式。
- 两组示例向量必须完整出现：
  - `z=[0.50,0.28,0.93,0.78,0.16,0.62]`
  - `z=[0.33,0.44,0.82,0.18,0.91,0.73]`
- 收束句：统一编码的关键不在“六个数”，而在“先判结构，再按当前结构解释哪些槽位真正生效”。

### 混合证据顺序
- 先六维编码定义 -> 再五类结构卡 -> 再两组示例显影 -> 最后两张判断卡与收束句。

### 互动升级点
- 解码显影链至少三层：
  1. 先根据 `z_0` 判结构编号。
  2. 再列出有效槽位与忽略槽位。
  3. 最后把有效槽位映射回工程参数。
- 两张作答卡题面常显：
  - 为什么不能把 `z_1` 到 `z_5` 永远当作同时生效的五个参数？
  - 给定一个编码向量时，哪一步必须先做，为什么？

### 教师控制
- 教师控制显影链与作答卡发放；学生端默认不自主展开显影。

### 学生默认状态
- 结构卡常显，显影链与作答卡默认隐藏。

### 本页脱离讲稿后的自包含检查
- 学生只看本页就能完成“结构编号 -> 槽位解释 -> 参数解码”的基本链路。

### 预览口径
- 一个“结构卡组 + 解码显影”的编码页，不能只剩一张宽表。

## step-09｜结构搜索证据与专项验证：总代价更低为什么仍不自动等于可交付

### 页面骨架
- 顶部放 GA/PSO 收敛图与读图口令。
- 中部放组合结构专项验证图、控制器表达式和控制效果曲线。
- 底部放三层边界判断显影链与一张判断卡。

### 模块清单
- 收敛图
- 收敛图读图表
- 组合结构专项验证图
- 组合控制器表达式卡
- 控制效果曲线
- 边界判断显影链
- 判断卡 `总代价更低为何仍不能直接交付`

### 静态承载内容
- 收敛图只服务于“结构选择证据”，不得被写成算法原理页。
- 组合结构控制器表达式必须完整出现：
  - `$u(s)=C_{fb}(s)(r(s)-\\psi(s))+F_r(s)r(s)-H_r(s)\\dot{\\psi}(s)$`
  - `$C_{fb}(s)=1.9727\\dfrac{47.0266s+1}{47.0266s}\\dfrac{20.6218s+1}{5.8952s+1}$`
  - `$F_r(s)=0\\cdot\\dfrac{0.9735s+1}{0.3286s+1}=0$`
  - `$H_r(s)=\\dfrac{0}{0.02s+1}=0$`
- 收束句：总代价更低、航迹误差更小，并不自动等于筛选线全部成立。

### 混合证据顺序
- 先收敛图与读图表 -> 再专项验证图 -> 再控制器表达式与控制效果曲线 -> 最后边界判断显影链和判断卡。

### 互动升级点
- 三层显影链依次写：
  1. 收敛图只说明搜索会把结果推向哪一类结构家族。
  2. 组合结构候选虽然总代价更低，但前馈与测速反馈最终收缩成零增益。
  3. 只要筛选线没有写成真正硬约束，优化器就会继续沿总代价允许的方向下降。
- 判断卡题面常显：为什么“总代价更低”与“工程可交付”不能直接画等号？

### 教师控制
- 教师控制显影链与判断卡发放；学生端默认不自主展开显影。

### 学生默认状态
- 图、公式和曲线常显；显影链与判断卡默认隐藏。

### 本页脱离讲稿后的自包含检查
- 学生只看本页即可知道专项验证的真正结论是“边界判断更清楚了”，而不是“组合结构已经可直接替代主方案”。

### 预览口径
- 一个“收敛证据 + 专项验证 + 边界判断”的综合页，但顺序必须先讲收敛图角色，再讲专项验证。
