BOPPPS 课案 | 单元 3-6：零点作用与动态改善实验——同一对象四版本比较
课型：实践主线课 | 总学时：90分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

B｜Bridge-in 场景导入（8min）
  形式：导入视频 + 问题追问
  内容描述：播放 `3-6-intro-video.mp4` 或展示封面漫画，让学生先产生“这些方案看起来差不多”的第一印象，再追问“同样都在加零点，为什么结果会分叉”。
  教师操作：
  - 播放 `3-6-intro-video.mp4` 或展示 `3-6-cover-comic.png`
  - 板书：`预测 -> 验证 -> 一句话解释`
  - 明确边界：本课不做完整补偿设计，不进入模块4选型整定

O｜Objective 课堂目标（4min）
  呈现方式：板书 + 页面显示
  目标描述：
  - 学完本节，我能在同一对象上比较基准、`PD`、测速反馈和简单超前四个版本的三域差异。
  - 学完本节，我能区分“显式增加零点”和“通过反馈改善阻尼”这两种不同口径。
  - 学完本节，我能写出一句完整判断：`零点位置 -> 根轨迹变化 -> 时域表现 -> 频域变化`。
  - 学完本节，我能识别右半平面零点带来的异常现象和工程风险。
  与全局框架的连接：本节承接 `3-5` 的理论判断链，把动态改善线做成统一对象实验；同时为 `3-7` 的稳态改善线留出清晰边界。

P₁｜Pre-assessment 前测（6min）
  形式：举手投票 + 平台快答
  测试内容：
  - 你会不会把测速反馈直接判成“也显式增加了零点”？
  - 你会不会把简单超前写成“更强的 `PD`”？
  - 你会不会把“更快”直接等于“更好”？
  根据结果的教学调整策略：
  - 若多数学生混淆测速反馈与显式零点，则在 P₂ 段 3 加重结构图辨认。
  - 若多数学生把超前写成更强的 `PD`，则在 P₂ 段 4 强调频带整形。
  - 若多数学生只写“更快”，则在 P₂ 段 6 加重“收益与代价同写”的要求。

P₂｜Participatory Learning 主体教学（62min）

- 段 1（6min）：统一对象与四版本框架
  - 教师讲授：固定对象 $G_p(s)=4/[s(s+0.8)]$，介绍四个学生必做版本与一个教师演示版本。
  - 组织形式：教师讲授 + 快速结构辨认。
  - 学生典型反应：会急于问“谁更好”。
  - 教师处理：要求先写结构差异，不先下结论。

- 段 2（10min）：第一轮预测（学生实践 8min）
  - 学生个体平台操作（8min）：
    - 只看结构图与零点位置信息；
    - 完成 `预测表`；
    - 写出每个版本的第一直觉。
  - 教师快评（2min）：
    - 只展示班级答案分布，不给标准答案。
  - 组织形式：学生个体操作 + 教师投屏汇总。

- 段 3（14min）：验证 A，基准 vs `PD`（学生实践 12min）
  - 学生个体平台操作（12min）：
    - 对照根轨迹、阶跃和 `Bode` 趋势；
    - 补写“为什么 `PD` 不能被说成继续加大增益”。
  - 教师点评（2min）：
    - 统一回收“结构改了，轨迹才会改”。
  - 组织形式：学生个体操作 + 教师投屏纠偏。

- 段 4（14min）：验证 B，`PD` / 测速反馈 / 简单超前（学生实践 12min）
  - 学生分组平台操作（12min）：
    - 完成三版本对照；
    - 补全 `四版本统一对照表`。
  - 教师点评（2min）：
    - 强调测速反馈与简单超前的不同解释口径。
  - 组织形式：同伴讨论 + 学生个体提交 + 教师点评。

- 段 5（8min）：教师演示右半平面零点（学生实践 6min）
  - 教师受控演示（2min）：
    - 播放教师锁定版本；
    - 只要求学生看三件事：反常初始趋势、额外相位滞后、工程风险。
  - 学生填写 `风险记录卡`（6min）。
  - 组织形式：教师演示 + 学生记录。

- 段 6（10min）：修正与一句话解释（学生实践 10min）
  - 学生个体平台操作（10min）：
    - 回看最初预测；
    - 修正 `预测表`；
    - 完成一句话解释。
  - 组织形式：学生个体操作。
  - 教师典型追问：
    - “你现在写出了结构差异吗？”
    - “你写出了收益，也写出了代价吗？”

P₃｜Post-assessment 后测（6min）
  形式：平台即时题目 + 口头追问
  测试内容：
  - 为什么测速反馈不能被写成“前向通道显式增加零点”？
  - 为什么简单超前不能被写成“更强的 `PD`”？
  - 为什么右半平面零点会让动态改善口径失效？
  反馈方式：平台显示正确率；教师只回收错误率最高的一题，要求学生回答时必须同时说出结构差异和三域后果。

S｜Summary 总结（4min）
  方式：教师总结 + 知识地图回顾
  核心要点：
  - 本课比较的是统一对象上的不同动态改善路径；
  - `PD`、测速反馈和简单超前都能改善动态，但解释口径不同；
  - 右半平面零点提醒我们：改善必须带着边界去判断；
  - 下一课 `3-7` 将切到稳态改善线，继续回答误差为什么还能继续变小。

学生实践训练时长统计：
- 第一轮预测：8min
- 验证 A：12min
- 验证 B：12min
- 风险记录卡：6min
- 修正与一句话解释：10min
合计：48min

课前布置：复习 `3-5` 中 `PD`、测速反馈、简单超前和非最小相的结构口径。
课后作业：整理本课 `预测表`、`四版本统一对照表` 和 `风险记录卡`，每份材料都补齐一句完整判断。
