# 3-6 封面漫画中文提示词

以哆啦A梦中的人物为原型，制作一张 4 格横向课堂导入漫画，比例 16:9，整体风格是“自动控制实验课里的并列对照小剧场”，画面轻松但有明确工程细节。核心情绪从“这些方案看起来差不多”逐步推进到“同样都在改善动态，为什么结果差这么多”。场景固定为同一间控制实验教室里的同一套透明对照实验台，四个并排小工作区分别对应：基准对象、`PD`、测速反馈、简单超前；侧边另有一个教师演示小屏只在第 4 格短暂出现，暗示右半平面零点风险。

## 第1格

场景：所有人围在同一套实验台前，四个小工作区看起来都只是“加了一点结构”，监控屏都刚亮起。  
角色动作 / 表情：大雄挠头，觉得这些方案看起来差不多，“感觉都差不多呀？”；小夫一脸自信，像是已经准备直接下结论。  
关键道具：并排四块小屏幕、统一对象实验台、写有“基准 / PD / 测速反馈 / 简单超前”的小标牌。  

## 第2格

场景：四个小工作区同时开始运行，屏幕上的根轨迹已经明显走出不同方向。  
角色动作 / 表情：静香认真指着其中两块屏幕比较，“轨迹走法已经分开了。”胖虎也开始收起“随便猜”的表情。  
关键道具：四块显示不同根轨迹弯折趋势的小屏、统一坐标格线、切换按钮。  

## 第3格

场景：同一实验台的下排屏幕同时显示阶跃响应和频域趋势，对照感更强。  
角色动作 / 表情：小夫露出意外表情，“原来收益和代价不是一起走的。”；大雄开始做记录。  
关键道具：阶跃响应曲线、频域趋势图、记录卡。  

## 第4格

场景：侧边教师演示小屏短暂切入右半平面零点版本，曲线一开始出现反常方向的抽动，四个学生都愣住了。  
角色动作 / 表情：哆啦A梦从旁边提醒大家先记风险，“同样叫零点，边界可不一样。”。  
关键道具：教师演示小屏、风险记录卡、统一实验台仍在背景里。
