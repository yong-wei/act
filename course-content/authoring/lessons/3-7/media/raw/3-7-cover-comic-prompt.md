# 3-7 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作四格漫画，需要使用箭头标注格子的阅读顺序。每一格是独立画面，共用同一页排版，格与格之间要有清晰边框或留白分隔。四格保持同一组人物形象和同一故事现场：哆啦A梦式教师角色、一位总想立刻调参数的学生、一位只盯“已经稳定”的学生、一位善于做对照记录的学生；场景固定在自动控制实验教室里的透明灌装生产线演示台，画面里只保留少量无字控制元素，例如目标液位线、实际液位线、误差灯条、型别切换卡、积分模块、PI 模块、滞后模块、几张无字响应曲线小卡。不要黑板公式墙，不要海洋船舶，不要赛博电影感，不要真人照片风，不要海报式整张大场景拼贴。

第1格：透明灌装线已经平稳运行，瓶子一个个停在目标液位线附近，但实际液位总是略低一点，误差灯条始终没有完全熄灭。那位只看“稳住了”的学生站在一旁觉得问题不大，另一位学生趴近玻璃罩认真盯着液位线，教师先不解释。关键道具是目标液位线、实际液位线、误差灯条、平稳传送带。台词：“明明已经稳住了，怎么还是差一点？”

第2格：教师把一个积分风格模块接到透明控制链上，型别切换卡从低级切到更高一级，瓶子的液位明显更贴近目标线，误差灯条缩短，低频区域出现柔和发亮的提示弧线。一个学生露出“终于更准了”的表情，另一个学生开始注意系统动作节奏有没有变。关键道具是积分模块、型别切换卡、液位更贴近参考线的小窗。台词：“想把这类误差真正压下去，往往得先改结构。”

第3格：PI 模块和滞后模块并排放在控制链旁边，左边方案让液位最终更准但响应显得慢一些，右边方案也能减小误差却保留一点拖后感，两张无字小响应曲线卡并排显示差异。三位学生不再只盯结果，而开始比较“谁更准、谁更慢、谁更保守”。关键道具是 PI 模块、滞后模块、两张对照响应曲线卡、节奏灯条。台词：“原来都在改善稳态，但代价根本不是一回事。”

第4格：四人把三条改进路径贴到一张小任务地图上，地图左侧是“已稳定但有残差”的基线，右侧分成“积分提高型别”“PI 改结构并重塑响应”“滞后重分配低频增益”三条路径，每条路径通向不同结果卡。那位最开始想直接调参数的学生终于明白不能把几种方案混成一个按钮。关键道具是任务地图、路径箭头、结果卡、同一条灌装线缩略图。台词：“关键不是记名字，而是看它到底消掉了哪一种误差。”
