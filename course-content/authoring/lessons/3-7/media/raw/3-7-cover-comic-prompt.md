# 3-7 讲义封面漫画提示词

请创作一张原创横向 16:9 四格课堂封面漫画，需要用箭头标明阅读顺序。整体风格是“自动控制课堂里的精度与代价小剧场”，画面明亮、清晰、偏工程教学可视化，不使用任何现成动画或漫画 IP 角色。四格中保持同一组原创人物形象一致：一位年轻教师、三位工科学生；场景固定为一间带透明工业沙盘的自动控制教室，沙盘中央是一条自动灌装数字孪生产线，透明瓶子沿传送带通过灌装嘴，周围悬浮无字液位曲线、误差灯条、型别切换卡和两种补偿模块外形。核心情绪从“明明已经稳住了，为什么还不够准”逐步推进到“原来积分、PI、滞后都在改善稳态，但代价并不一样”。不要黑板公式墙，不要海洋船舶场景，不要赛博战争电影感，不要真人写实照片风。

## 第1格

场景：自动灌装线已经稳定运行，透明瓶子一个接一个停在目标液位线附近，但每个瓶子的实际液位都略低一点，误差灯条始终没有完全熄灭。  
角色动作 / 表情：一名学生蹲下盯着液位线，满脸疑惑；另一名学生指着“已经稳定”的状态，觉得问题似乎不大；教师没有直接解释。  
关键道具：透明瓶子、目标液位参考线、实际液位线、误差灯条、平稳运行的传送带。  
台词：学生甲：“它都稳住了，怎么还是差一点？”

## 第2格

场景：教师把一个积分风格模块接入透明控制链，型别卡从低级切到更高一级，瓶子的液位开始更贴近目标线，误差灯条明显缩短。  
角色动作 / 表情：一位学生露出“终于更准了”的惊喜表情，另一位学生立刻把目光转向系统动作节奏。  
关键道具：积分模块、型别切换卡、液位更靠近参考线的无字小窗、低频区域发亮的弧形光带。  
台词：教师：“想更准，往往得先改系统对低频的态度。”

## 第3格

场景：`PI` 模块和滞后补偿模块同时出现在控制链旁边，两种方案都让液位更接近目标线，但一个版本收敛更慢，另一个版本带来更明显的拖后感。  
角色动作 / 表情：第三位学生先是高兴，随后发现两种方案虽然都更准，却不是“白拿收益”。  
关键道具：两种不同外形的补偿模块、两条对照的无字液位响应曲线、略有差别的节奏灯。  
台词：学生乙：“原来更准，不是按一下按钮就全都更好。”

## 第4格

场景：四格末尾收束成一张小型任务地图，左侧是“稳住了但有残差”的基线，右侧是积分、`PI`、滞后三条改进路径，各自连向不同的结果卡。  
角色动作 / 表情：三位学生把不同方案贴到“更准 / 更慢 / 更保守”几个任务卡旁边，终于不再把它们当成同一种东西。  
关键道具：任务标签卡、三条改进路径、同一条灌装线的缩略图、统一风格的透明界面。  
台词：学生丙：“原来关键不是记名字，是看谁在帮我消掉哪一种误差。”
