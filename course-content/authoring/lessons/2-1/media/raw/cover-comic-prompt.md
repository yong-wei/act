# 2-1 封面漫画中文提示词

请为《自动控制原理》单元 2-1《建模与变换语言——从真实对象到统一分析对象》设计一张横向 16:9 的四格漫画封面。整体风格亲切、明亮、适合大学工科课堂导入，色彩以蓝白为主，局部点缀橙色。必须使用简洁中文气泡文字，并用清晰箭头标出阅读顺序。第一格表现学生面对船舶航向控制问题，黑板上出现微分方程，气泡文字强调“真实系统先给你一条微分方程”；第二格表现系统连接一复杂就看不清，信号线和箭头开始变乱，气泡文字强调“只盯着微分方程，后面的连接和分析会越来越乱”；第三格表现拉氏变换把微分方程改写成传递函数，画面中有清晰的公式转化箭头，气泡文字强调“拉氏变换把对象翻译成可以反复调用的统一形式”；第四格表现传递函数与结构图拼成完整分析语言，出现简洁的方框图和船舶航向控制元素，气泡文字强调“从这里开始，系统就能被连接、比较和分析”。画面中可以出现课堂黑板、航向刻度盘、小型船舶轮廓、控制系统符号，但背景必须干净，不要大段说明文字，不要英文，不要海报式夸张表情。
