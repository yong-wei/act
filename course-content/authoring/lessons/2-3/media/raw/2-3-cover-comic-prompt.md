# 2-3 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作多格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 2-3《频率响应基础——从时域现象到 G(jω)》设计一张横向 16:9 的四格封面漫画。请在四格中保持角色形象一致，所有对白都使用简短中文，每格只放一句短台词。

第一格：学校礼堂后台，静香拿着红色节拍器慢慢摆动，自动跟拍云台稳稳跟住她；大雄在一旁惊喜地看着画面几乎不抖。静香台词：“慢一点，它就跟得很稳。”

第二格：胖虎突然拿着会疯狂闪烁的应援棒冲进画面，小夫还在一旁用小风扇制造快速抖动，云台却没有像追静香那样立刻乱转。大雄愣住，明显没想到系统会“挑对象”。大雄台词：“咦，它怎么不追这堆快闪？”

第三格：后台监视器上同时出现两种轨迹，一条平滑缓慢的波形被清楚记录，另一条密密麻麻的快速抖动只剩下矮矮一团。哆啦A梦指着监视器，大家第一次看见“慢变化被保留、快变化被压下去”。哆啦A梦台词：“不是它偷懒，是它在挑节奏。”

第四格：哆啦A梦把“慢节奏”“快节奏”“G(jω)”三个词写在小白板上，静香和大雄一起看向云台镜头。画面收束成“从奇怪现象进入频率语言”的结尾。大雄台词：“原来得先问，它对每种节奏会怎么回应。”
