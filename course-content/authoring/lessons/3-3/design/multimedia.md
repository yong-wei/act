## 2. 当前图片策略

- 封面图服务“为什么知道稳定区间还不够”的问题提出。
- 信息图服务正文结束前的主线收束，也供知识卡片复用。
- `pp-01` 用于概括“参数变化 → 根轨迹 → 动态解释”的方法链。
- `pp-02` 用于概括“普通根轨迹 → 广义根轨迹 → $0^\circ$/$180^\circ$ 根轨迹”的扩展关系。
- `pp-03` 把相角条件与幅值条件放回同一个复平面几何场景。
- `pp-04` 作为本讲完整法则的共用主例图，一图承接起点终点、实轴区段、渐近线、分离点和虚轴交点。
- `pp-05` 单独放大“向右数奇偶”的实轴判段动作。
- `pp-06` 单独呈现复极点附近的切线方向，服务起始角 / 终止角。
- `pp-07` 把时间常数参数转写为广义根轨迹的全过程做成一页图。
- `pp-08` 把根轨迹上的点位变化直接翻译为动态变化。

补充说明：

- `pp-01` 至 `pp-03`、`pp-05`、`pp-06` 走公式安全 SVG 渲染链路，避免浏览器直接暴露 `$...$`。
- `pp-04`、`pp-07`、`pp-08` 先由 `Octave` 生成根轨迹数据，再由 `Python` 统一排版，确保起点、分离点和虚轴附近曲线平滑。
- 当前 `pp` 图片已做一次批量 PNG 预览与人工核验，重点检查了公式、轨迹平滑度、文本框遮挡和出框问题。
