# 3-2 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作多格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 3-2《劳斯判据：从高阶系统稳定判定到参数可行域》设计一张横向 16:9 的四格封面漫画。请在四格中保持角色形象一致，所有对白都使用简短中文，每格只放一句短台词。

第一格：自动控制原理课堂上，哆啦A梦把一个带有参数滑块 `k` 的高阶系统演示台推到讲台中央，屏幕上显示四阶特征方程、复平面和绿色稳定区。大雄看着一长串系数发愁，静香和小夫凑近观察。大雄台词：“四阶方程这么长，难道真要一个个求根？”

第二格：大雄伸手把参数滑块往右推，屏幕上的一对共轭极点迅速向虚轴逼近，稳定区从绿色变成黄色警戒带，右侧的小窗开始出现振荡更明显的响应曲线。小夫瞪大眼睛盯着屏幕。小夫台词：“根还没算出来，边界已经开始发紧了。”

第三格：演示台继续推到边界位置，屏幕同时出现三块联动画面：复平面上一对极点贴近虚轴、时间响应开始长时间振荡、幅频曲线峰值明显抬高。静香意识到三种现象连在一起。静香台词：“同一个边界，极点、曲线和频率特性一起变了。”

第四格：哆啦A梦展开一张高亮“第一列”的劳斯表方法卡，旁边再翻出两张小卡片，分别写着“首位为 0”“全零行”“辅助方程”。大雄终于露出恍然大悟的表情，黑板右上角留出标题空间。哆啦A梦台词：“先守住稳定边界，再谈参数设计。”
