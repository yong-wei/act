# 2-2 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作多格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 2-2《时域响应基础——从响应曲线到动态性能指标》设计一张横向 16:9 的四格封面漫画。请在四格中保持角色形象一致，所有对白都使用简短中文，每格只放一句短台词。

第一格：哆啦A梦在社团活动室下达指令，让两台自动送点心滑轨车把铜锣烧送到桌子中央。大雄兴奋地盯着终点圆点，胖虎和小夫在旁边起哄。大雄台词：“一起出发，看谁先稳稳送到！”

第二格：左边那台滑轨车冲过终点，盘子晃得快要翻；右边那台滑轨车明显太慢，还差一小段才靠近目标。哆啦A梦皱眉看着两台车的差异，气氛瞬间从比赛变成翻车现场。哆啦A梦台词：“都在往终点走，可过程差太多了。”

第三格：墙上的显示屏出现两条对比鲜明的响应曲线，一条先冲过头再回落，另一条慢慢爬近目标。大雄趴在屏幕前，第一次把滑轨车的表现和曲线一一对上。大雄台词：“原来‘到了没’根本不够，还得看它怎么到。”

第四格：哆啦A梦拿笔圈住曲线上的几个关键位置，桌上的铜锣烧终于稳稳停在中心，所有人都围过来观察。画面收束成“从翻车到会读曲线”的结尾。哆啦A梦台词：“快不快、冲不冲、多久稳住，都藏在这条线上。”
