# 单元 2-2 讲义框架

## 适用范围

- 课次：`2-2`
- 标题：时域响应基础——从响应曲线到动态性能指标
- 目标：作为 `design/handout.md` 的结构母稿，先钉住主逻辑线、知识链、能力链、图表位与附录边界

## 范文文风感受提炼

只保留 `legacy/L-2a/design/handout.md` 的文风感受，不继承其具体结构和内容：

1. 先用一个具体工程情境把学生拉进问题，而不是一上来堆定义。
2. 叙述节奏应当平稳，先说“这节课要回答什么”，再逐层展开公式和判断语言。
3. 概念解释要尽量口语化，但关键公式和结论必须严谨落地。
4. 图、表、正文要互相分工，图负责把趋势看出来，表负责把关系压缩清楚。
5. 每个大段落结束时都要收一下，让学生知道“这一段学完后自己多会了什么”。

## 讲义主逻辑线

`为什么稳定还不够 -> 时域响应到底在看什么 -> 一阶系统先建立最基本的“快慢”语言 -> 二阶系统建立“快慢 + 振荡”语言 -> 四个动态性能指标把曲线变成可度量对象 -> 指标与 $\zeta$、$\omega_n$、极点位置连起来 -> 用例题完成计算与判断 -> 为 2-3、3-1、3-3、4-1 铺路`

这条主线要保证全篇始终围绕同一个核心问题：

> 给定一个稳定系统，我们如何从它的单位阶跃响应中判断“快不快、冲不冲、多久稳、为什么会这样”？

## 知识链

### A. 研究对象链

1. 时域分析研究的是输出 $c(t)$ 随时间变化的过程
2. 标准测试输入里，本课聚焦单位阶跃输入
3. 单位阶跃响应是后续动态性能指标的统一载体

### B. 一阶对象链

1. 标准一阶系统 $G(s)=\dfrac{K}{Ts+1}$
2. 单位阶跃响应推导
3. 时间常数 $T$ 的物理意义
4. $63.2\%$、$3T$、$4T$、$2.2T$ 这些工程估计量

### C. 二阶对象链

1. 标准二阶系统
2. $\zeta$、$\omega_n$、$\omega_d$ 的定义和角色分工
3. 无阻尼、欠阻尼、临界阻尼、过阻尼四类响应
4. 指数包络与振荡项共同决定曲线

### D. 指标语言链

1. 上升时间 $t_r$
2. 峰值时间 $t_p$
3. 超调量 $M_p$
4. 调节时间 $t_s$
5. 四指标的工程意义和适用条件

### E. 参数-现象-几何链

1. $\zeta$ 改变振荡程度和超调
2. $\omega_n$ 改变整体时间尺度
3. 极点位置改变响应形态
4. 时域指标最终要回到复平面语言，为模块3做准备

## 能力链

### 课内必须建立的能力

1. 看到传递函数后，能判断本课是在研究一阶对象还是二阶对象。
2. 能从标准一阶系统写出单位阶跃响应，并解释时间常数的意义。
3. 能识别标准二阶系统中的 $\zeta$、$\omega_n$、$\omega_d$，知道它们分别控制什么。
4. 能根据响应曲线读出并解释 $t_r$、$t_p$、$M_p$、$t_s$。
5. 能根据 $\zeta$、$\omega_n$ 的变化，预测响应曲线的大致变化方向。
6. 能把“曲线现象”翻译成“参数变化”和“极点变化”的语言。

### 放到附录或后续课程的能力

1. 高阶系统的主导极点近似
2. 卷积与一般输入的系统展开
3. 稳态误差正式理论
4. 控制器改善机理

## 2-2 handout 的建议重构方向

当前 `design/handout.md` 已经具备完整正文，但若按这份框架继续优化，建议重点收敛三件事：

1. 让“第 6 章 参数、指标与极点位置的三重对应”更突出，因为这是本节连接模块3的关键桥。
2. 例题部分要固定成“思路 -> 计算 -> 工程解释 -> 脚本验证”的统一模板，强化能力链。
3. 附录应显式承接较长推导和验证脚本，避免正文在公式细节上过度拖长。
