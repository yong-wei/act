## 文档职责

- 本文件是 `5-5` 作者态互动页面蓝图，负责把讲义中的显式控制律、学习策略、强化学习最小闭环、进入条件、航向控制 RL 路线、安全外壳、部署验证和四路线评价转化为学生脱离讲稿也能独立阅读的页面内容。
- 本文件与 `5-5-interactive-contract.yaml` 共同构成互动页面双轨真源；人读稿负责页面内容、顺序和学生理解口径，机读契约负责运行时结构。
- `sequence.json` 已按本页步骤归属同步校准，作为知识卡片进入互动步骤的顺序依据。

## 表述规则

- 每页必须回答四件事：对象是什么、正在判断什么、关键证据在哪里、结论怎样回到“前沿方法不取消控制目标、安全验证和工程责任”。
- 页面顺序服从讲义顺序。文字定义、公式、表格和案例任务先出现，结构图、训练曲线和评价图放在对应证据之后。
- 逐步显影只隐藏分析步骤，不隐藏对象、题面、已知条件、公式、图注和曲线读图口令。
- 本课不展开 RL 算法推导和训练技巧教学；所有互动都回到进入条件、收益代价、安全边界、部署验证和方法路线判断。
- 当前设计以现有讲义为真源：复杂边缘场景中 `RL直接` 明显弱于 PID，`RL调度PID` 是更合理的工程入口。

## step-12｜Nomoto 航向环境的状态与动作设计

### 页面骨架

### 静态承载内容

- 公式：$T\dot r+r=K\delta+d_r$，$\dot\psi=r$。

- 符号说明：$r$ 偏航角速度；$\delta$ 舵角；$T$ 响应时间常数；$K$ 舵效增益；$d_r$ 等效偏航扰动；$\hat d_{r,k}$ 扰动估计或分档信息。

- 元素出现顺序：奖励设计目标 -> 奖励总式 -> 符号说明 -> 显影链 -> 收束句。
- 常显公式：$r_k=-w_e e_{\psi,k}^2-w_r r_k^2-w_\delta \delta_k^2-w_{\Delta\delta}(\delta_k-\delta_{k-1})^2-w_s I_{\mathrm{safety},k}+r_{\mathrm{settle},k}$。
- 符号说明：$w_e$ 惩罚航向误差；$w_r$ 惩罚过大偏航角速度；$w_\delta$ 惩罚大舵角；$w_{\Delta\delta}$ 惩罚频繁打舵；$I_{\mathrm{safety},k}$ 记录安全边界或接管事件；$r_{\mathrm{settle},k}$ 奖励稳定保持。
### 显影链
- 显影 1：误差项和角速度项约束“准”和“稳”，防止策略只追求到达目标而忽略转动过程。
- 显影 2：舵角项和舵角变化项约束执行器代价，防止策略用大舵角或高频动作换取短时误差下降。
- 显影 3：安全项把越界、接管或不可信状态写成训练惩罚，避免训练回报掩盖危险行为。
- 显影 4：Q-learning 更新式 $Q(s_k,a_k)\leftarrow Q(s_k,a_k)+\alpha\left[r_k+\gamma\max_a Q(s_{k+1},a)-Q(s_k,a_k)\right]$，只说明离散状态动作下“当前估计向即时回报和未来最优估计修正”的含义，不展开算法技巧。
- 显影 5：收束句“奖励设计不是算法装饰，而是工程目标、执行器约束和安全责任进入策略学习的入口。”

## step-15｜三类航向 RL 策略训练与评价

### 页面骨架
- 顶部说明：“三类 RL 路线必须在同一航向边缘场景中训练并与 PID 基准比较，不能只看训练回报。”
- 正文先给边缘场景任务，再进入三类航向策略训练面板；面板按三个标签分别训练 `RL直接`、`RL安全外壳` 和 `RL调度PID`。
### 静态承载内容
- 元素出现顺序：边缘场景任务说明 -> 三类训练标签 -> 关键参数选择区 -> 训练动态回报曲线 -> 停止后的航向响应与舵角输出对比 -> 指标表 -> 提交结果 -> 路线判定表 -> 边界结论。
- 边缘场景任务说明：“评价场景包含目标航向变化、持续侧风或横流、反向扰动、短时脉冲、船体时间常数增大和舵效下降。所有标签都必须与同一 PID 基准比较。”
- 标签 1：`RL直接`。策略直接输出离散舵角增量或舵角指令；关键参数供学生选择：训练轮数档位、探索率衰减速度、动作步长、误差惩罚权重、舵角变化惩罚权重。
- 标签 2：`RL安全外壳`。底层策略先给出动作建议，再经过舵角限幅、舵速限制、误差放大检查和 PID 退化接管；关键参数供学生选择：安全误差阈值、角速度阈值、舵速阈值、安全惩罚权重、退化接管灵敏度。
- 标签 3：`RL调度PID`。策略不直接控舵，只在保守、常规、抗扰、快速四组 PID 参数档位中选择；关键参数供学生选择：参数档位集合、切换惩罚权重、抗扰档位偏置、快速档位使用限制、误差区间分档。
- 每个标签的面板都包含三块图形：训练动态回报曲线、航向响应对比、舵角输出对比。训练中只动态刷新回报曲线；点击停止训练后，用最新模型在边缘场景中生成航向响应和舵角输出，并与 PID 基准曲线并列显示。
- 指标表按当前标签动态更新，至少包含训练类型、RMS 航向误差、最大超调、调节时间、平均舵角、平均舵速、安全退化次数和学生选定的关键参数。
- 默认基线可显示讲义中的当前静态指标作为参考：PID RMS误差 $4.43^\circ$、RL直接 RMS误差 $30.62^\circ$、RL安全外壳 RMS误差 $6.94^\circ$、RL调度PID RMS误差 $4.20^\circ$；真实训练停止后，以本次训练计算值覆盖对应 RL 行，PID 行保持同一基准。
- 路线判定表常显本页评价口径：RMS 航向误差是主要排名指标，最大超调和调节时间检查闭环响应质量，平均舵角与平均舵速检查执行代价，安全退化次数说明安全外壳或退化接管是否频繁介入。
- 边界结论：“同一边缘场景下，训练回报只能说明策略在训练目标上改善；是否适合进入控制系统，还必须同时看闭环误差、舵角代价、安全退化和与 PID 基准的对照。直接 RL 适合说明策略学习能力，安全外壳和 PID 调度更接近工程入口。”

## step-17｜总结：策略学习的收益、代价与边界

### 页面骨架
- 顶部显示课程信息图 `5-5-info.png`，随后给主要内容、局限、重点难点、拓展思考和课堂表现统计。
### 静态承载内容

- 主要内容：显式控制律优势来自结构清楚和边界可分析；学习策略优势来自复杂场景中的样本化动作形成；RL 进入控制问题前必须检查任务、样本、回报、验证和监控；航向控制中更稳妥入口是参考生成、参数调度或扰动补偿；前沿方法扩大可处理任务范围，也提高验证、解释和接管责任。
