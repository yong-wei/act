# BOPPPS 课案 | 单元 5-5：从显式控制器到策略学习

**课型**：理论
**总学时**：90分钟
**知识类型**：[X] 跨域型
**核心问题**：当显式控制器结构难以预先写出时，如何判断强化学习是否有进入控制问题的依据，并说明它新增的样本、解释、安全和部署责任。

## B｜Bridge-in 场景导入（8min）

**形式**：导入视频 + 工程判断题。

播放 15 秒导入视频：显式控制律卡片面对越来越复杂的航行任务，策略学习路径出现，同时样本代价、可解释性、安全验证和部署风险同步点亮。

教师提出问题：一艘自主船在静水中靠 PID 能保持航向，但遇到侧风、横流、对象参数漂移和传感器噪声时，需要频繁重新整定。此时应直接让强化学习接管舵机，还是先判断策略学习能承担哪一层职责？

**学生可能反应**：容易把问题理解成“经典控制过时，RL 更先进”。
**教师处理**：要求学生先写出一个仍必须由显式结构保留的责任，再写出一个可能交给策略学习的局部职责。

## O｜Objective 课堂目标（5min）

**呈现方式**：平台展示 + 板书压缩。

完成本课后，学生应能够：

1. 区分显式控制律与学习策略的动作来源和验证方式。
2. 用五项进入条件判断强化学习是否适合进入控制任务。
3. 解释状态、动作、回报和策略怎样构成最小策略学习闭环。
4. 按航向控制任务说明 RL 的环境、状态、动作、奖励、安全保护和验证路线。
5. 比较 PID、直接控舵 RL、安全外壳 RL 和 RL 调度 PID 的收益与风险。

教师板书一句话：前沿方法不取消责任，反而提高验证责任。

## P1｜Pre-assessment 前测（7min）

**形式**：平台投票 + 口头追问。

前测题 1：某系统已有可靠 PID 控制器，但任务场景中动作选择条件变多。引入强化学习前最先检查什么？

- A. 神经网络层数是否足够。
- B. 显式结构是否真的难以覆盖动作选择空间，以及样本、安全和验证条件是否成立。
- C. 训练回报是否能超过 PID。

预期答案为 B。若多数学生选 A 或 C，主体教学中需加强进入条件与验证责任。

前测题 2：训练回报高能否直接证明控制策略可以部署？

预期答案：不能。还需独立测试、压力测试、故障注入、安全外壳、部署监控和接管机制。

## P2｜Participatory Learning 主体教学（55min）

### 1. 显式控制器与学习策略的责任差异（9min）

**组织形式**：教师讲授 + 图像读解。

教师从 $u(t)=C(e(t),x(t),p)$ 出发，说明显式控制律的价值来自结构可读、边界可查、责任可追踪。随后展示“显式控制器与学习策略的责任差异”图，要求学生读出两类证据来源：结构证明与样本验证。

**典型误判**：把学习策略理解为没有控制器。
**教师处理**：强调策略本身仍是动作生成机制，目标、约束、安全边界和接管逻辑仍需显式写出。

### 2. 强化学习的最小概念与小仿真（10min）

**组织形式**：板书公式 + 仿真图读解。

教师板书状态、动作、回报、策略和长期回报：

$$
J(\pi)=\mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty}\gamma^k r_k\right]
$$

展示横向误差修正仿真，让学生比较随机动作、显式比例修正和学习策略。讨论重点是：学习策略可以从回报中形成状态-动作关系，但简单误差修正中显式控制器已经足够。

### 3. 五项进入条件与风险矩阵（10min）

**组织形式**：全班投票 + 条件表讲解。

教师展示五项条件：任务、样本、回报、验证、监控。学生对一个“固定仓库移动平台希望 RL 替代 MPC”的案例投票：适合进入、需要补证据、暂不进入。

**收束**：若固定结构已可靠，整体替代通常不是合理入口；更合理的是局部代价估计、异常辅助或参数调度。

### 4. 航向控制 RL 技术路线（12min）

**组织形式**：板书路线 + 同伴问答。

教师按“结构、环境、状态、动作、奖励、训练、泛化、安全、部署、评价”十步展开。重点讲三种进入结构：直接控舵、参考航向生成、PID 参数调度或补偿调整。

学生任务：判断哪一种最适合作为工程起步路线，并说明理由。

预期答案：参考航向生成、参数调度或扰动补偿更适合作为起步；直接控舵验证难度最高。

### 5. 航向控制训练与评价图读解（12min）

**组织形式**：分组读图 + 教师点评。

先展示边缘场景时间线，让学生读出目标变化、侧风/横流、反向扰动、短时脉冲、时间常数增大和舵效下降。再展示四种方法评价图和指标表。

每组解释一条路线：

- PID：可解释、稳定，但对复杂边缘场景适应有限。
- RL直接：最终回到目标附近，但中段超调和舵角使用过大。
- RL安全外壳：能拦截危险动作，但安全退化频繁。
- RL调度PID：保留 PID 主结构，同时让策略选择参数档位。

教师追问：为什么不能只看 RMS 误差最小？

预期回答：还要看最大超调、调节时间、平均舵角、平均舵速、安全退化、训练外工况和部署边界。

### 6. 工程入口收束（2min）

**组织形式**：教师板书收束。

教师把 RL 的合理起步压缩为：参考生成、参数调度、扰动补偿和异常辅助；若要直接控舵，必须显著加强训练覆盖、动作解释、安全退化记录和独立验证。

## P3｜Post-assessment 后测（10min）

**形式**：平台短答 + 即时反馈。

后测题 1：某 RL 直接控舵策略在训练中回报很高，但独立评价中最大超调达到 $58.04^\circ$，平均舵速达到 $2.90^\circ/\mathrm{s}$。这说明什么？

参考答案：训练回报不能替代闭环评价；直接控舵路线可能存在过激动作和边界风险，需要安全外壳、训练覆盖补强和独立验证。

后测题 2：一艘船的传统自动舵在强扰动下需要频繁重整定。请写出一个受限 RL 进入方案。

参考答案：RL 可先做 PID 参数调度、参考航向修正或扰动补偿；状态包含航向误差、偏航角速度、上一时刻舵角和扰动估计；奖励惩罚误差、大舵角、舵角变化率和安全退化；输出受舵角限幅、舵速约束和传统自动舵接管保护；部署前完成参数随机化仿真、历史数据回放、硬件在环和受限水域观察模式。

## S｜Summary 总结（5min）

**方式**：板书总线 + 学生复述。

核心要点：

1. 显式控制律的优势来自结构清楚、边界可分析。
2. 学习策略的优势来自复杂场景中的样本化动作形成。
3. 强化学习进入控制问题前必须检查任务、样本、回报、验证和监控条件。
4. 航向控制中更稳妥的入口是参考生成、参数调度或扰动补偿，而不是直接取消控制器。
5. 前沿方法扩大了可处理任务范围，也提高了验证、解释和接管责任。

收束句：更聪明的方法并不自动带来更安全的系统，证据链必须比方法名更清楚。
