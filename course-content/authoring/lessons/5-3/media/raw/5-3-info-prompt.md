# 5-3 小结信息图提示词

生成一张横向 16:9 中文教学信息图，用于《自动控制原理》单元“5-3 从单回路控制到复杂自主系统链路：MASS 的感知、估计、规划与控制协同”的讲义小结。画面主题为“先看系统链路，再谈控制位置”，风格应清晰、工程化、适合课程讲义，不使用暗黑、赛博、战争或炫技视觉。

画面中央是一条从左到右的 MASS 链路：感知、估计、规划、控制、执行、监督。每个环节用独立模块表示，模块之间用箭头连接。控制模块使用更醒目的蓝色描边，但不能让它看起来支配整张图；它应处在链路中部偏后位置，表明控制是关键环节，同时依赖上游信息和下游执行。

左侧用两个小型证据框表示上游输入质量：传感器噪声、测量延迟。中部用一个路径参考框表示规划参考可实现性：平滑路径、最小转弯半径、舵角余量。右侧用一个执行约束框表示物理边界：舵角限幅、舵速限制、降级接管。底部用一条总结带写出短句：“状态是否可信、参考是否可执行、运动是否稳定可降级”。

可见中文文字只保留以下短标签：感知、估计、规划、控制、执行、监督、状态是否可信、参考是否可执行、运动是否稳定可降级。不要放长段文字，不要放公式，不要使用真实船舶品牌、军用装备、战斗场景或复杂法规条文。

输出应有足够留白，文字清晰，箭头方向准确，颜色不超过四类主色。整体视觉应像高质量课程总结图，而不是宣传海报。
