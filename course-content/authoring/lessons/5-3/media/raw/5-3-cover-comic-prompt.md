# 5-3 封面漫画提示词

以哆啦A梦中的人物为原型，绘制 4 格中文教学漫画，主题为“从单回路控制到 MASS 复杂自主系统链路”。画面保持温暖、清晰、课程漫画风格，人物表情自然，链路卡片和船舶场景可读，整体适合自动控制原理讲义封面。不要出现军武宣传、海战、赛博朋克、暗黑风格或真实品牌标识，不要把 MASS 画成炫酷装备展示。

第1格：大雄看着一张熟悉的单回路控制框图，框图只有“参考、控制器、对象、反馈”几个块。旁边的小型自主船模型正在水槽中航行。台词：大雄说“有了控制器，船是不是就能自己完成任务？”

第2格：哆啦A梦把框图向两侧拉开，出现“感知、估计、规划、控制、执行”五张卡片，每张卡片之间用箭头连接。台词：哆啦A梦说“真实自主系统是一整条链路。”

第3格：静香在链路图前指向“估计”和“规划”两张卡片，屏幕上显示前方目标船短时遮挡，规划路径随之变急。台词：静香说“偏差可能从上游信息开始传播。”

第4格：胖虎和小夫检查舵角限幅表，哆啦A梦把“控制负责什么 / 控制依赖什么 / 控制不能独自保证什么”三列放在黑板上。台词：哆啦A梦说“先看系统链路，再谈控制位置。”
