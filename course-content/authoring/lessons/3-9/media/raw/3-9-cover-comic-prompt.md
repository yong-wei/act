# 3-9 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作四格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 3-9《稳定—动态—稳态综合映射实验》设计讲义首页封面漫画。每一格是独立画面，共用同一页排版，格与格之间要有清晰边框或留白分隔。四格中保持同一组人物形象一致，所有对白都使用简短中文，不要英文气泡，不要长段旁白，不要大块公式堆砌。

第1格：自动控制实验教室里，哆啦A梦把一套船舶航向控制数字孪生实验台推到桌面中央，海面沙盘上的基准版本刚完成一次转向，船体有明显超调，末端还留着一点残差。大雄皱着眉记录曲线，静香在看无字阶跃响应小窗，小夫已经有点忍不住想直接换方案。关键道具是海面沙盘、基准版本标记灯、无字阶跃响应和无字根轨迹小窗。台词：“先别急着改，先看清它到底差在哪。”

第2格：积分版本切入，同一艘船的末端残差明显缩小，低频区域的提示色带亮起来，但回稳节奏也拖慢了些。静香露出“精度真的上去了”的表情，大雄同时注意到响应尾巴变长，小夫开始意识到改动不是只有好处。关键道具是低频色带、残差缩小的无字响应曲线、同一艘船的连续对照。台词：“它更准了，可怎么也更拖了？”

第3格：零点补强版本接着上场，船体动作更利落，起步更快，但中频附近的无字频域曲线和动态指标提示灯都变得更紧张。哆啦A梦指向中频穿越附近，大雄和小夫同时发现“更快”并不是白来的，静香开始把这条线记到“动态优先”卡片旁。关键道具是中频穿越提示、无字 Bode 小窗、动作更利落的船体姿态。台词：“这条线先救的是快，代价也会先露出来。”

第4格：最后一格把积分、零点补强和滞后版本缩成一张任务地图，哆啦A梦把三张任务卡排成“更快 / 更准 / 更稳”的顺序，同一实验台上几种版本分别贴到不同卡片旁。大雄、静香、小夫终于不再把这些改动混成一类，而是开始按任务分工去看它们。关键道具是四版本缩略图、任务标签卡、同一实验台上的对照面板。台词：“原来不是先挑名字，是先分配谁来承担任务。”
