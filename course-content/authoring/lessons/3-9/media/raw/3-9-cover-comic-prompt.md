# 3-9 讲义封面漫画提示词

请创作一张原创横向 16:9 四格课堂封面漫画，需要用箭头标明阅读顺序。整体风格是“模块3出口综合映射实验小剧场”，画面轻松但有明确工程细节，不使用任何现成动画或漫画 IP 角色。四格中保持同一组原创人物形象一致：一位教师、三位学生；场景固定为一间自动控制实验教室，中央是一套船舶航向控制数字孪生实验台，同一艘远洋船在透明海面沙盘上反复演示基准、积分、自选补强和教师演示滞后四个版本。透明悬浮屏显示无字根轨迹、无字阶跃响应、无字频域曲线和任务标签卡。核心情绪从“这些改动好像都在变好”逐步推进到“原来不同机制线优先解决的问题并不一样”。不要拍成控制器广告，不要稳定裕度专题海报，不要大段公式堆叠，不要真人写实照片风。

## 第1格

场景：同一艘船的基准版本正在修正航向，船体有明显超调和一点稳态残差，实验台所有人先看到“问题长什么样”。  
角色动作 / 表情：一名学生皱着眉做记录，另一名学生已经忍不住想直接换方案，教师让大家先把基线看完整。  
关键道具：海面数字沙盘、基准版本标记灯、无字根轨迹和无字响应小窗。  
台词：学生甲：“先别改太快，先看清它到底差在哪。”

## 第2格

场景：积分版本切入，低频区域的色带明显亮起来，稳态残差缩小了，但船体回稳节奏变得更拖一点。  
角色动作 / 表情：一位学生露出“精度真的上去了”的兴奋表情，另一位学生同时注意到节奏变慢。  
关键道具：低频亮起的透明色带、残差缩小的无字响应曲线、同一艘船保持不变。  
台词：学生乙：“它更准了，可节奏也跟着变了。”

## 第3格

场景：自选补强版本默认采用零点线补强，同一艘船的动作更利落，响应更快，但中频和高频相关的曲线变化更明显。  
角色动作 / 表情：第三位学生惊讶地发现“更快”不是白来的，教师点向频域屏幕上变化更剧烈的区域。  
关键道具：更利落的转向姿态、中频穿越位置变化、明显不同的根轨迹走向。  
台词：教师：“这条线先救的是动态，代价也会先露出来。”

## 第4格

场景：教师演示滞后版本切入，同样改善了残差，但动作明显更保守；四格末尾的画面把四个版本缩成一张任务地图。  
角色动作 / 表情：三位学生把四个版本贴到“更快 / 更准 / 更稳”三类任务卡旁边，终于不再把它们混成一类。  
关键道具：四版本缩略图、任务标签卡、同一实验台和同一艘船的连续对照。  
台词：学生丙：“原来不是先挑名字，是先分配谁来承担任务。”
