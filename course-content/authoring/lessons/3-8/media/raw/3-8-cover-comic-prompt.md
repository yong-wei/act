# 3-8 讲义封面漫画提示词

请创作一张原创横向 16:9 四格课堂封面漫画，需要用箭头标明阅读顺序。整体风格是“自动控制课堂里的频域翻译器小剧场”，画面明亮、清晰、偏工程教学可视化，不使用任何现成动画或漫画 IP 角色。四格中保持同一组原创人物形象一致：一位年轻教师、三位工科学生；场景固定为一间带透明数字沙盘的自动控制教室，沙盘中央是一艘在蓝色海面上航行的船舶数字孪生模型，周围有透明悬浮屏显示无字 `Nyquist` 轨迹、`Bode` 曲线、三频段色带和阶跃响应。核心情绪从“结构一变，结果也变了，可是看不懂规律”逐步推进到“原来频域是在给结构变化做统一翻译”。不要黑板公式墙，不要手工作图教学，不要赛博战争电影感，不要真人写实照片风。

## 第1格

场景：透明海面沙盘上，同一艘船连续切换三种结构模块，船体的摆动、回稳速度和稳态误差都在变化，但学生们还没有抓到规律。  
角色动作 / 表情：一名学生皱眉盯着船尾摆动，另一名学生正在快速翻记录卡，教师没有直接给答案。  
关键道具：海面数字沙盘、三种不同颜色的结构模块、同一艘船的多条无字响应轨迹。  
台词：学生甲：“明明只改了一点结构，怎么后果全变了？”

## 第2格

场景：透明悬浮屏放大成主画面，无字 `Nyquist` 轨迹正逼近一个发红光的危险点，整间教室的注意力都被那条轨迹吸住。  
角色动作 / 表情：教师抬手示意大家先盯住危险点，一位学生下意识往前探身，另一个学生露出“终于抓到关键”的表情。  
关键道具：发光危险点、逼近又回转的轨迹、统一风格的透明曲线屏。  
台词：教师：“先别急着背结论，先看它离危险还有多远。”

## 第3格

场景：另一块透明大屏展开成低频、中频、高频三条发光色带，像三段不同任务航道，旁边同步挂着无字 `Bode` 曲线和无字阶跃响应。  
角色动作 / 表情：三位学生分头指向不同频段，开始意识到“快、稳、准”并不是同一个按钮。  
关键道具：低中高三段色带、无字穿越点、无字超调/回稳小图、同一艘船的缩略图。  
台词：学生乙：“原来不同频段，各自在承担不同任务。”

## 第4格

场景：画面收束成左右双屏，左侧是船舶航向控制，右侧是船载稳定平台；两边都显示无字频域图和无字响应图，但侧重点明显不同。  
角色动作 / 表情：学生们把前几格的疑惑串起来，教师只是轻轻点向两边不同的重点区域。  
关键道具：双屏对照框、两种工程对象的小模型、同风格透明曲线界面。  
台词：学生丙：“原来频域不是新章节，是把后果一次看清的翻译器。”
