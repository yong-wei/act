# 3-8 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作四格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 3-8《频域判别与跨域综合语言》设计讲义首页封面漫画。每一格是独立画面，共用同一页排版，格与格之间要有清晰边框或留白分隔。四格中保持同一组人物形象一致，所有对白都使用简短中文，不要英文气泡，不要长段旁白，不要大块公式堆砌。

第1格：自动控制实验教室里，哆啦A梦把一套船舶数字孪生演示台推到桌面中央，同一艘船正在透明海面沙盘上连续切换三种结构版本，摆动幅度、回稳速度和稳态残差都不一样。大雄趴在台边盯着船尾，静香在记录板上比对三条无字响应小曲线，小夫已经开始有点着急。关键道具是透明海面沙盘、三种结构模块标记灯、三条无字响应小窗。台词：“明明只改一点结构，怎么后果全变了？”

第2格：另一块透明屏被放大成主画面，一条无字 Nyquist 轨迹正逼近一个发红光的危险点。哆啦A梦神情认真地指向危险点，大雄下意识前倾，小夫和静香都盯住那条回转的轨迹，气氛一下变紧。关键道具是发光危险点、无字 Nyquist 轨迹、透明悬浮曲线屏。台词：“先别急着下结论，先看它离危险还有多远。”

第3格：画面切到另一块独立分镜屏，上面展开低频、中频、高频三条发光色带，旁边并排放着无字 Bode 曲线和无字阶跃响应小图。静香指向低频色带，小夫指向中频穿越附近，大雄发现不同频段对应的任务根本不一样。关键道具是三频段色带、无字 Bode 曲线、无字阶跃响应缩略图。台词：“原来不同频段，各自在承担不同任务。”

第4格：最后一格收束为左右双屏对照，左边是船舶航向控制，右边是船载稳定平台，两边都显示无字频域图和无字响应图，但关注重点明显不同。哆啦A梦轻轻点向两边不同的重点区域，大雄、静香、小夫终于把前面三格串成一条线。关键道具是双屏对照框、两种工程对象的小模型、同风格透明曲线界面。台词：“原来频域不是新章节，是把后果一次看清的翻译器。”
