# 单元 3-8 | 教师版课堂讲义

- **标题**：频域判别与跨域综合语言
- **学时**：90 分钟
- **课型**：理论主线收束课
- **课堂主线**：围绕同一条判断链推进：`结构变化 -> 频域指纹 -> Nyquist / Bode 判稳统一 -> 三频段分工 -> 工程案例读回 -> 3-9 综合映射与模块 4 入口`。
- **上一课衔接语**：`3-7` 已经把“低频收益 / 中频代价”的第一层逻辑立住；今天要把这件事完整翻译成频域判断语言。
- **下一课铺垫语**：今天先统一翻译和判稳，下一课 `3-9` 再把这些语言用于同一对象的多版本比较，形成模块 3 的出口地图。

---

## 一、90 分钟课堂时间分配

| 环节 | 时间 | 目标 |
|------|------|------|
| 开场桥接 | 8 分钟 | 把 `3-5 / 3-7` 两条结构变化线收束成“频域为什么看起来不同” |
| 主线一：四类结构变化的频域指纹 | 22 分钟 | 讲清增益、零点、积分/滞后、非最小相为何改写不同频带 |
| 主线二：Nyquist 判稳统一链 | 16 分钟 | 从 $F(s)=1+L(s)$ 到 `P -> N -> Z` 的固定判断顺序 |
| 主线三：Bode 判稳与稳定裕度 | 14 分钟 | 压实截止频率、相角裕度、增益裕度与同一临界边界的关系 |
| 主线四：三频段分工与工程案例 | 22 分钟 | 把频域量读回精度、速度、超调、谐振峰值和高频代价 |
| 后测与收束 | 8 分钟 | 检查学生是否会看频带、看临界点、看收益与代价 |

## 二、课堂流程

### 1. 开场桥接（0-8 分钟）

**教师要讲的关键话**

- “`3-5` 回答的是零点为什么让动态更积极，`3-7` 回答的是积分与滞后为什么能让系统更准。”
- “今天不把频域当成新章节，而是把前面所有结构变化翻译成同一张判断图。”
- “如果你还只会说‘增益变大了’，那就还没有真正进入频域判断。”

**建议板书**

```text
3-5：零点线 -> 动态改善
3-7：低频补偿线 -> 稳态改善
3-8：统一翻译
结构变化 -> 频域指纹 -> 判稳 -> 性能读回
```

**教师提醒**

- 开场必须先让学生看到四类变化的不同“落点”，否则后面 Nyquist 与 Bode 容易重新退化成公式新章。

### 2. 主线一：四类结构变化的频域指纹（8-30 分钟）

**必须保留的核心内容**

- 增益提升：幅频整体上移，相位基本不变。
- 左半平面零点：中频附近带来相位提前和幅值抬升。
- 积分 / 滞后：优先强化低频，但会更早压缩中频余量。
- 右半平面零点：幅值可能变强，但相位代价更重，不可只看速度表象。

**课堂操作**

- 同屏放 `3-8-gain-effect.png`、`3-8-zero-effect.png`、`3-8-pole-effect.png`、`3-8-rhp-zero-effect.png`。
- 先不让学生说“更好 / 更坏”，只要求回答：
  - 哪一段频率先被改写？
  - 改写的是幅值、相位，还是两者一起？

**典型误判**

- 把积分补偿和增益提升都看成“整条曲线抬高”。
- 把右半平面零点的幅值抬升误当成“对象更快更好”。

**教师追问**

- “这条变化首先落在低频、中频还是高频？”
- “你现在看到的是收益，还是代价，还是两者同时出现？”

### 3. 主线二：Nyquist 判稳统一链（30-46 分钟）

**必须保留的核心内容**

- 幅角原理：
  $$
  \Delta \arg F(s)=2\pi(Z-P)
  $$
- 辅助函数：
  $$
  F(s)=1+L(s)
  $$
- 判稳出口：
  $$
  Z=P-N
  $$

**课堂操作**

- 先讲清为什么临界点是 $(-1,0)$，而不是把它当成死记点。
- 再用 `3-8-nyquist-quickcheck.png` 做四图快判，要求学生永远按下面顺序说：
  1. 开环右半平面极点数 $P$；
  2. 对临界点的包围数 $N$；
  3. 闭环右半平面极点数 $Z=P-N$。

**教师提醒**

- 本段最重要的不是图画得多漂亮，而是学生判断顺序固定。
- 任何学生先报“稳/不稳”而不先报 `P/N/Z`，都要打断并重来。

### 4. 主线三：Bode 判稳与稳定裕度（46-60 分钟）

**必须保留的核心内容**

- 截止频率：
  $$
  |L(j\omega_c)|=1
  $$
- 相角裕度：
  $$
  \gamma = 180^\circ + \angle L(j\omega_c)
  $$
- 相位穿越频率与增益裕度：
  $$
  \angle L(j\omega_\pi)=-180^\circ,\qquad G_m=\frac{1}{|L(j\omega_\pi)|}
  $$

**课堂操作**

- 用 `3-8-bode-example.png` 同时标出：
  - 截止频率线；
  - 相位穿越频率线；
  - PM 线；
  - GM 线。
- 固定一句课堂口令：
  - 开环读余量；
  - 闭环看带宽。

**典型误判**

- 把截止频率和带宽频率混为一谈。
- 把“相角裕度更大”直接理解成“所有性能都更好”。

**教师追问**

- “这个量是在开环图上读的，还是闭环图上读的？”
- “这是告诉你更快，还是告诉你更靠近临界边界？”

### 5. 主线四：三频段分工与工程案例（60-82 分钟）

**必须保留的核心内容**

- 三频段分工：
  - 低频：稳态精度、抗缓变扰动；
  - 中频：截止频率、相角裕度、超调风险；
  - 高频：噪声、执行器负担、鲁棒代价。
- 频域量到闭环后果的读回：
  - 带宽；
  - 相角裕度；
  - 谐振峰值；
  - 谐振频率。

**课堂操作**

- 先用 `3-8-three-band-overview.png` 把三频段任务固定下来。
- 再看两个 `2×2` 工程案例：
  - `3-8-heading-case.png`：航向控制中，超前校正主要改写中频，因此既加快又增大余量；
  - `3-8-platform-case.png`：稳定平台中，只靠降增益虽可增大余量，但代价是速度掉得太多，超前校正更能兼顾速度与平稳。

**教师收束句**

- “真正有效的校正，不是盲目把曲线整体推高或压低，而是定向改写最关键的那一段频率。”

### 6. 后测与收束（82-90 分钟）

**后测题建议**

1. Nyquist 图包围临界点一次、开环有一个右半平面极点，则闭环是否稳定？
2. 截止频率更大但相角裕度明显更小，应优先读成什么风险？
3. 想优先减小超调并降低谐振峰值，应优先关注哪一段频率的哪一类量？
4. 为什么非最小相对象不能只追求更大带宽？

**收束语**

- “频域不是把旧知识再讲一遍，而是把结构变化、稳定边界和闭环后果放进同一张工程判断地图。”
- “下一课 `3-9` 会检验学生能不能用这张地图比较同一对象的多个结构版本。”

## 三、建议板书

### 板书 1：统一判断链

```text
结构变化
  ↓
频域指纹（先看哪一段）
  ↓
Nyquist / Bode 判稳
  ↓
三频段分工
  ↓
闭环后果与工程判断
```

### 板书 2：Nyquist 固定顺序

```text
先数 P
再数 N
最后算 Z = P - N
```

### 板书 3：三频段分工

```text
低频：精度 / 抗扰
中频：速度 / 超调 / 余量
高频：噪声 / 执行器 / 代价
```

---

## 四、教师提醒

- 本课不能退化成“Nyquist 判据一节 + Bode 判稳一节”的并列复习稿。
- 任何时候都要先追问“先改写哪一段频率”，再谈结论。
- `Nyquist` 与 `Bode` 必须始终被讲成同一临界边界的两种表达。
- 工程案例只做判断链验证，不提前滑入模块 4 的参数整定与方案排序。
