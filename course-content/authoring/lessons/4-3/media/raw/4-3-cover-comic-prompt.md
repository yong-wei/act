# 4-3 讲义封面漫画提示词

请以哆啦A梦中的人物为原型。创作四格漫画，需要使用箭头标注格子的阅读顺序。为《自动控制原理》单元 4-3《初始方案落地实践：从对象分析到结构组合与首轮验证》设计讲义首页封面漫画。每一格是独立画面，共用同一页排版，格与格之间要有清晰边框或留白分隔。四格保持同一组人物形象和同一故事现场，人物身份必须固定且明确：哆啦A梦负责教师与评审引导，大雄负责先下结论、总想用一个控制器名字解决所有问题，静香负责把前两课留下的任务表达卡和单结构起步卡整理成输入，出木杉负责记录“结构骨架、参数方向、验证假设、明示代价”，哆啦美在涉及更复杂的抗扰通道或多物理分量时短暂出场，帮助指出第二条机制线。场景固定在自动控制实验教室里的方案评审台：左侧是客船航向控制数字沙盘，右侧是船舶横摇减摇鳍抗扰演示台，中间是一块可切换“单结构起步卡、复合结构骨架图、参数方向表、首版可验证方案卡”的透明界面。不要黑板公式墙，不要海报式大拼贴，不要赛博霓虹界面，不要真人照片风，不要复杂英文 UI。

第1格：评审台刚亮起，静香把 `4-1` 的任务表达卡和 `4-2` 的单结构起步卡并排摆在桌上，大雄却已经把一张写着“这次直接上 PID 就行”的大卡片举到前面。左侧客船对象显示低频保持改善了一些，但超调和调节时间仍不理想；右侧横摇减摇鳍对象显示谐振峰值还在明显抖动。出木杉在一旁记录“单结构已经抓住主矛盾，但还不够”。关键道具是两张前序卡片、被举高的“PID”名字卡、客船沙盘、横摇抗扰演示台、记录板。台词：“既然单结构不够，直接报个总答案不就行了吗？”

第2格：哆啦A梦没有直接认可“大雄版答案”，而是把透明界面切成“第一条机制线”和“第二条机制线”两层。客船一侧先亮起低频补偿线，再补一条中频整理线；横摇减摇鳍一侧则出现由位置、速度、加速度三类分量共同构造控制力矩的骨架。静香把两类任务卡贴到左右两边，出木杉开始把“频段型来源”和“通道型来源”写成两列。关键道具是双层机制线、客船复合骨架示意、横摇抗扰骨架示意、静香手中的任务卡。台词：“不是多加一个名字，而是把第二条机制线补到正确的位置。”

第3格：画面转到更难的抗扰通道解释。哆啦美短暂出场，拿着指示棒指向横摇减摇鳍一侧的扰动力矩支路，提醒“这里不是跟踪谁，而是要重写抗扰通道”；与此同时，客船一侧则把 `PI + 超前` 型的抽象骨架亮成两段不同颜色。大雄终于意识到两个案例虽然都在走向复合结构，但来源完全不同。出木杉把“频段型复合”和“通道型复合”写在记录板上。关键道具是扰动力矩支路线框图、双颜色复合骨架、哆啦美的指示棒、出木杉的记录板。台词：“原来复合结构不是默认答案，而且长出来的理由也不止一种。”

第4格：五人围着一张大号“首版可验证方案卡”，卡上清楚分成七栏：当前任务、结构骨架、参数方向、主要证据、预期改善、明示代价、失败后优先怀疑点。静香负责填“当前任务”和“主要证据”，大雄负责写“结构骨架”，出木杉负责补“参数方向、代价和怀疑点”，哆啦A梦在旁边点头，哆啦美把一张“先写验证假设再上机”的小提示卡贴到角落。关键道具是七栏方案卡、客船与横摇案例缩略图、记录板、小提示卡。台词：“会选结构还不够，得把方案骨架、方向和假设一起写出来。”
