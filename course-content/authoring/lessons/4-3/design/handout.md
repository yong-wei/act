# 单元 4-3 | 基于结构机理的初始方案形成：从选型判断到关键参数方向

- **层次**：模块4 理论主线 · 第三课
- **学时**：90分钟
- **知识类型**：[D] 设计型
- **前置**：已完成 `4-1` 的任务表达卡书写，能够区分硬约束、软目标与观察指标；已完成 `4-2` 的单结构首轮起步卡，能够说明首选结构、参数起步方向、预期收益与明示代价

## 一、引入：为什么 `4-2` 已经会选结构了，仍然不等于“会做方案”

到 `4-2` 结束时，我们已经能写出一张单结构首轮起步卡。例如：

- 当前最紧矛盾是什么；
- 首选单结构是什么；
- 第一个参数方向准备朝哪里起；
- 预期先改善什么；
- 这样做最可能透支什么代价。

这一步非常重要，因为它把“凭感觉喊控制器名字”推进到了“能讲出结构理由”。但它仍然没有解决设计课里真正最麻烦的那一跳：

> **单结构首轮起步卡，只说明了“先动哪条机制线”；它还没有说明，当这条机制线不够时，第二条机制为什么必须补进来，而且应当怎样补。**

这就是 `4-3` 的入口。它不再停留在“这类结构适合这个任务”的判断层，而要继续往前走三步：

1. 判断当前任务是否已经复杂到单结构无法同时照顾主要矛盾与次矛盾；
2. 若单结构不够，决定第二条机制线应补在哪里，是继续补低频、整理中频，还是沿通道加补偿；
3. 把结果写成一张**首版可验证方案卡**，供 `4-4` 做第一次验证，而不是假装自己已经完成最终优化。

所以，`4-2` 与 `4-3` 的关系，不是“上一课讲理由，这一课讲公式”；而是：

- `4-2` 负责回答：**先从哪类单结构起步，为什么**；
- `4-3` 负责回答：**单结构不够时，方案骨架怎样长出来，参数方向怎样写得可验证**。

### 1.1 先把两个错误压住

进入 `4-3` 之前，必须先压住两种最常见的错误。

**错误一：把复合结构当默认答案。**  
有些同学在 `4-2` 一写完“单结构起步卡”，下一句就自然变成“那最后还是上 `PID` 吧”。这其实等于把最关键的中间判断直接跳过了。复合结构只有在**单结构已经无法对准当前任务冲突**时才值得进入，而不是因为它“看起来更全”。

**错误二：把初始方案当最终答案。**  
有些同学会把几组参数一口气全填上，然后把这张纸当成“已经整定完”。这同样不对。`4-3` 的方案只能被称为**首版可验证方案**，因为它的价值不是“已经最优”，而是“第一次拿去验证时，能看出方向对不对，失败后该先怀疑哪里”。

因此，本课的最低目标不是“把参数算完”，而是把下面这句话真正写实：

> **我知道自己为什么要补第二条机制线，也知道第一次验证时应该先看到什么改善、又最该提防什么代价。**

### [AI融入点] 让 AI 帮你辨认“单结构已经不够”的证据

先不要让 AI 直接替你给方案。请你先独立完成下面两步：

1. 取出 `4-2` 的单结构起步卡，写下：若只沿这条结构继续推进，最可能先卡住的次矛盾是什么。
2. 再写一句：这个次矛盾更像低频问题、中频问题，还是通道问题。

然后把这两句交给 AI，只让它做一件事：检查你的“次矛盾分类”是否合理。你要求 AI 只回答下面三问：

- 你写的次矛盾，真的不是原来的主要矛盾换一种说法吗；
- 这个次矛盾主要落在哪一段频率行为；
- 若再补一条机制线，最可能补在低频、中频还是通道。

AI 在这里的角色是帮助你把矛盾说清，而不是替你跳过判断直接生成最终控制器。

## 二、什么时候必须从单结构走向复合结构

`4-3` 的第一件事，不是立刻写新控制器，而是判断：**单结构还能不能继续撑住当前任务。**

这件事至少要过三道判断。

### 2.1 第一问：主要矛盾改善以后，是否立刻暴露出新的次矛盾

单结构之所以先在 `4-2` 出现，是因为任何设计都应该先抓最紧矛盾。问题在于，很多任务并不是只有一个矛盾。例如：

- 只补低频以后，稳态误差和慢扰动问题缓和了，但超调、相位储备和调节时间仍然不够理想；
- 只整理中频以后，超调和动态品质改善了，但低频保持能力、恒值扰动抑制或累计偏差仍没有着落；
- 只做通道补偿以后，某条已测扰动的影响下降了，但闭环本体的保底能力并没有因此自动变强。

一旦出现这种“主矛盾刚压住，次矛盾立刻跳出来”的情形，就说明单结构的作用点已经太窄，必须考虑第二条机制线。

### 2.2 第二问：当前任务是不是天然跨两个频段

从频段语言看，单结构之所以会不够，通常不是因为它“没用”，而是因为它只集中作用在一个重点区域：

- `PI/滞后` 更偏向低频；
- `PD/超前` 更偏向中频；
- 前馈更偏向通道补偿。

如果任务本身就是“低频与中频同时拉扯”，那么只靠单结构往往会出现下面这类局面：

- 继续补低频，动态和储备会更吃紧；
- 继续整理中频，稳态精度和慢扰动抑制又没法站稳；
- 继续只补通道，闭环本体依然没回答“保底靠什么”。

因此，一道很有用的判断是：

> **当前问题，是不是已经不是“该先动哪一段”，而是“至少两段都要安排，而且顺序与主次要写清楚”。**

只要答案是“是”，复合结构骨架就不再是加分项，而是设计起步的必要步骤。

### 2.3 第三问：第一次验证前，你能不能写出可证伪的假设

还有一个常被忽视的标准：如果你的方案无法写出“第一次验证前应该先发生什么”，那它多半还不配叫方案。

所谓“可证伪的验证假设”，至少要包含三件事：

1. 这版方案主要准备先改善什么；
2. 这版方案最可能先透支什么代价；
3. 若第一次验证没有出现预期改善，你最先怀疑结构骨架，还是怀疑参数方向。

如果只靠单结构起步卡，你已经写不出这样的假设，那么说明它还不够承接 `4-4`。此时进入复合结构，不是为了显得复杂，而是为了让方案具备真正的验证入口。

### 2.4 一个最小判断表

表1. 单结构还能不能继续撑住的最小判断表

| 判断问题 | 若回答是“能” | 若回答是“不能” |
| --- | --- | --- |
| 当前最紧矛盾是否基本集中在单一频段或单一通道 | 先继续沿单结构推进 | 进入复合结构候选 |
| 主要矛盾改善后，是否没有立刻暴露新的硬约束冲突 | 单结构仍可作为第一版方案 | 说明至少还缺第二条机制线 |
| 只用当前单结构，能否写出明确的预期改善与预期代价 | 先保留单结构骨架 | 说明方案表达还不够 |
| 第一次验证失败后，能否明确优先怀疑方向 | 可直接进 `4-4` | 需先把结构骨架补完整 |

这张表的意义，是把“要不要进入复合结构”从经验直觉压成一个可以辩护的课堂动作。

## 三、什么叫“首版可验证方案卡”

当你决定单结构已经不够时，下一步并不是直接写一堆参数，而是先把方案压成一张结构化卡片。

这张卡片要解决的是：

- 方案的骨架是什么；
- 哪几个参数方向是优先变量；
- 主要证据来自哪里；
- 第一次验证期待看到什么；
- 如果失败，先怀疑哪里。

### 3.1 方案卡最少要写哪些字段

表2. 首版可验证方案卡模板

| 字段 | 应写内容 |
| --- | --- |
| 当前任务 | 对象是谁，当前要解决的主要问题是什么 |
| 结构骨架 | 反馈主结构由哪几条机制线组成 |
| 参数方向 | 第一轮先准备增强或减弱哪些作用 |
| 主要证据 | 为什么认为这些机制线值得放进来 |
| 预期改善 | 第一次验证前最希望先看到什么变化 |
| 明示代价 | 预期可能先透支什么边界 |
| 失败后优先怀疑点 | 若结果不对，先怀疑结构不足还是参数方向写反 |

要特别注意：这张卡里写的是**方向**，不是最终参数值。它的目标不是宣称“我已经会整定”，而是保证 `4-4` 有东西可验证、有风险可回收、有失败可解释。

### 3.2 为什么一定要把“代价”和“失败怀疑点”写进去

工程上最危险的方案，往往不是明显很差的方案，而是“只写收益、不写代价”的方案。因为这样的方案一上机，学生只会盯着自己最想看到的那条曲线，而忽略：

- 储备是不是被压得更紧了；
- 高频敏感性是不是变强了；
- 控制量是不是开始走得过猛；
- 原任务里没写出来的约束是不是被提前打破了。

同样，若不写“失败后优先怀疑点”，你在 `4-4` 看到异常时，就很容易把所有问题都归为“参数没调好”。这会把第一次失败诊断直接降格成机械试参。

因此，本课的方案卡必须强制同时写三类内容：

1. 我想先改善什么；
2. 我预期会牺牲什么；
3. 如果没改善，我优先怀疑哪里。

### 3.3 一条最重要的课堂提醒

> **初始方案不是最终答案。初始方案的价值，不在于“已经最好”，而在于“第一次验证就能暴露足够多的设计信息”。**

只有把这句话立住，`4-3` 才不会退回成“参数表填写课”或“校正公式推导课”。

## 四、主场景A：客船航向控制如何从单结构起步卡长成首版方案骨架

下面先只做本课最重要、也最稳的一件事：把主场景A的第一版方案骨架写出来。

### 4.1 先回收 `4-1` 与 `4-2` 已经确认的输入

`4-1` 已经给出了主场景A的任务表达：

- 当前对象是客船航向控制；
- 现有工作点虽然稳定，但超调偏大、调节时间偏长；
- 任务不只是“能跟踪”，而是“过程要进入可接受区域”；
- 相位储备不能再被一味压紧。

`4-2` 则已经给出了第一轮单结构起步判断：

- 主矛盾更像低频能力与慢扰动保持能力先站稳的问题；
- 因而首选单结构更偏 `PI/滞后`；
- 参数方向上，第一步先沿“增强低频能力”的方向起；
- 但这条结构线的代价也已经写清：它可能拖慢速度，并进一步挤压中频储备。

到这里，问题就变得非常具体了：

> **如果只沿 `PI/滞后` 继续走，虽然低频能力会被托起来，但动态品质、超调和调节时间怎么办？**

这就是 `4-3` 必须进入的地方。

### 4.2 为什么本案例里，单独“再补低频”已经不够

对客船航向控制来说，单独强化低频能力的确有意义，因为它回应了：

- 恒值航向跟踪精度；
- 慢扰动下的保持能力；
- 长时间累计偏差不要太大。

但它很难独自回答另外两件同样重要的事：

1. 当前超调已经偏大，乘客与船体对过程平顺性有明确要求；
2. 当前调节时间偏长，若只靠低频继续加力，动态过程未必会更利落，甚至可能更拖。

换句话说，本案例的任务已经不是“只要把低频补起来就行”，而是同时包含两条要求：

- 低频要站稳；
- 中频动态品质也必须被整理。

这正是一个典型的“跨两个频段”的设计问题。继续只沿单结构往前推，就会把次矛盾长期留空。于是，本案例进入复合结构，不是为了追求复杂，而是因为任务本身已经明确要求：

> **低频补偿与中频相位整理必须同时出现在第一版方案里。**

### 4.3 第一版结构骨架应该长什么样

若把这个判断写成最小复合结构骨架，可以先采用下面这种表达：

$$
C_0(s)=K\cdot\frac{1}{s}\cdot\frac{T_\ell s+1}{\alpha T_\ell s+1},
\qquad 0<\alpha<1
$$

这不是最终答案，而是一张结构骨架图。它只表达三件事：

1. $\dfrac{1}{s}$ 这一部分代表低频补偿线，负责把低频保持能力先托起来；
2. $\dfrac{T_\ell s+1}{\alpha T_\ell s+1}$ 这一部分代表中频相位整理线，负责给动态品质和储备留出整理空间；
3. 增益 $K$ 负责决定整体作用强度，但它不能被孤立理解，必须和前两条机制线一起看。

在模块4语境里，这个骨架最重要的不是“形式上像哪本书里的校正网络”，而是它把两条机制线明确写了出来：

- **第一条线**：低频能力不能丢；
- **第二条线**：只补低频不够，还必须同时整理中频动态品质。

这正是 `4-3` 相比 `4-2` 多走出的那一步。

### 4.4 参数方向应该怎么写，才不沦为口号

写到这一步，仍然不要急着给具体数值。本课只写**方向判断**。

表3. 主场景A的参数方向判断表

| 变量 | 第一轮方向判断 | 主要意图 | 需要警惕的代价 |
| --- | --- | --- | --- |
| 增益 $K$ | 适度增强，但不把它当唯一手段 | 让整体调节作用真正显现 | 若只靠加大 $K$，超调和储备可能先恶化 |
| 积分环节 | 保留，作为低频能力主承担者 | 压低长期偏差，增强慢扰动保持能力 | 可能拖慢动态并带来更大相位滞后 |
| 超前零极点比值 $\alpha$ | 取相位整理有效的方向，而不是趋近于 1 | 让中频阻尼与相位余量先被补出来 | 过于激进会带来高频敏感性上升 |
| 超前作用中心频段 | 靠近当前最需要整理的中频区域，而不是随意摆放 | 让主要改善真正落在超调和调节时间相关区域 | 若放错频段，可能“补了结构却没补到矛盾” |

这张表的本质，是把“参数方向”重新翻译成人能读懂的设计语言：

- 哪个变量先承担低频任务；
- 哪个变量先承担中频任务；
- 哪个方向是为了改善当前主要冲突；
- 哪个方向若走过头，会先透支哪条边界。

### 4.5 第一版方案卡应当怎样写

把前面几步压到一起，就能得到主场景A的第一版方案卡。

表4. 主场景A的首版可验证方案卡

| 字段 | 内容 |
| --- | --- |
| 当前任务 | 客船航向控制需要在保持低频跟踪与扰动抑制能力的同时，把超调和调节时间压进更可接受的区域 |
| 结构骨架 | “积分低频补偿 + 中频相位整理”的复合结构 |
| 参数方向 | 保留积分以托住低频能力，同时补入一条超前机制线整理中频动态品质；增益只作整体强度调节，不再单独承担全部任务 |
| 主要证据 | 只补低频无法同时回答超调偏大与调节时间偏长的问题；任务本身已经跨低频与中频两段 |
| 预期改善 | 低频保持能力不丢的前提下，超调应先下降，调节过程应先变得更利落 |
| 明示代价 | 若超前作用过猛或增益过高，高频敏感性与储备压力可能先暴露 |
| 失败后优先怀疑点 | 若低频精度改善了但超调没压下，优先怀疑中频整理线不够；若动态提起来了但低频保持变差，优先怀疑低频补偿线不足或两条线的配合失衡 |

请注意，这张卡仍然没有说“参数值是多少”。但它已经足够支撑第一次验证，因为它明确写出了：

- 方案的主骨架；
- 第一轮参数变量的主次；
- 成功时该先看到什么；
- 失败时该先怀疑哪里。

这就是 `4-3` 要交给 `4-4` 的真正输入。

### 4.6 第一次验证前，必须先把哪些假设写出来

在主场景A中，第一次验证前至少要写下下面三条假设：

1. 若方向正确，超调应先比单纯低频补偿方案更明显地下来；
2. 若方向正确，调节时间不应因低频补偿而继续大幅拖长；
3. 若方向正确，低频保持能力仍应保住，而不是因为一味追求中频改善而被削弱。

相应地，也要提前写出三条风险提醒：

1. 若只看到速度略快，但超调和储备更差，说明中频整理过激；
2. 若只看到低频误差改善，但过程更拖，说明方案仍停留在“只补低频”的旧路上；
3. 若主要现象完全不对应原任务矛盾，优先怀疑结构骨架就没有对准问题，而不是先怀疑数值算得不够精细。

到这里，`4-3` 的第一批核心正文就立住了：我们不是在“猜一个复杂控制器”，而是在把设计判断真正推进成一张可验证、可回收、可修正的首版方案卡。

---

## 五、本阶段小结

1. `4-3` 的任务不是把参数一步算完，而是把 `4-2` 的单结构起步卡推进成首版可验证方案卡。
2. 是否进入复合结构，取决于单结构能否继续撑住任务，而不是因为复合结构“看起来更全”。
3. 当任务同时跨低频与中频两段时，第一版方案必须把两条机制线明确写出来。
4. 对主场景A而言，最稳妥的第一版表达不是“默认上 `PID`”，而是明确写出“积分低频补偿 + 中频相位整理”的结构骨架及其参数方向。
5. 初始方案最重要的价值，在于让 `4-4` 的第一次验证真正有假设可检验、有失败可解释。
