## 文档职责

- 本文件是 `4-3` 作者态互动页面蓝图，负责把讲义中的对象、题面、公式链、表格、图后解释、例题显影和作答任务落成可直接呈现给学生的页面内容。
- 同目录 `interactive-contract.yaml` 是机读真源，两者必须在步骤顺序、标题、页面模板、互动类型、教师控制和学生默认状态上逐项对齐。
- 本课保持“结构工具箱优先”的讲义顺序：先把对象分析、结构分流和三类复合结构讲清，再进入客船案例、最小例题、实践工作区与边界案例。
- 页面蓝图 prose 只写学生真正会看到的内容与阅读顺序，不把实现门槛、埋点术语或审查口令写成页面正文。

## 表述规则

- 每一步都必须回答四件事：对象是什么、正在判断什么、关键证据在哪里、结论如何回接“第一版方案”主线。
- 图片、结构图、四联图和对照图一律服从讲义证据顺序，不得抢到公式、题面或判断语句之前。
- 例题页与显影页中，题面必须固定可见；可以隐藏的是求解步骤，而不是题面本身。
- 除前测 / 后测 / 专门题组页外，单页作答默认不超过两张卡；本课结构页与案例页均采用一页一任务的轻量作答。

## 逐步说明

### step-01｜回到地图：4-2 的起步卡如何长成 4-3 的第一版方案
- 页面骨架：上半区放“`4-2 -> 4-3 -> 4-4` 课程路径图”，中部放四张目标卡，不再放边界卡，也不再放作答区。
- 页面正文内容：标题句写“`4-2` 交来的是单结构起步卡，`4-3` 要把它推进成可运行的第一版方案”。目标卡依次写“对象分析”“结构分流”“参数方向”“首轮验证与问题清单”。
- 证据顺序：先看课程路径，再读本课四项目标，最后回到“第一版方案”主线。
- 互动升级点：本页不设学生作答，只承担路径定位与课程目标提示。
- 教师控制：四项控制均不适用。
- 学生默认状态：路径图与目标卡直接可见，无浏览锁。
- 本页脱离讲稿后的自包含检查：学生只看这一页，也能知道本课不是“再讲几个结构名”，而是把起步卡推进成第一版方案。
- 预览口径：学生预览进入本页时，应先看到路径与目标，而不是案例图或作答壳层。

### step-02｜对象分析四问：对象入口不是重抄模型
- 页面骨架：上半区放四张问题卡，下半区放一张完整的对象分析记录单。
- 页面正文内容：四张问题卡分别写“当前最紧矛盾在哪里”“原有单结构还能否继续推”“新机制应当补到哪里”“首轮验证先盯什么”。记录单四栏对应“主矛盾 / 硬约束 / 单结构继续推进最先失守处 / 首轮验证重点读数”。页尾收束句写“对象分析不是重抄模型，而是把模型重新写成设计入口”。
- 证据顺序：先读四问，再看记录单字段，最后读收束句。
- 互动升级点：学生只提交一张对象分析记录卡，要求写出当前对象的首轮入口判断。
- 教师控制：教师单独释放作答；浏览默认开放；参考答案教师切换。
- 学生默认状态：正文可读，记录单默认隐藏，释放后显示。
- 本页脱离讲稿后的自包含检查：学生应能凭本页知道“对象分析”具体要写哪四类判断。
- 预览口径：同页必须同时看到四问和记录单，不允许把记录单单独拆到别页。

### step-03｜结构分流：什么时候继续单结构，什么时候进入复合结构
- 页面骨架：上半区为表 1 原生表，下半区为一张单选判断卡和一句边界结论。
- 页面正文内容：表 1 保留三列“当前观察 / 更合适的起步方向 / 设计含义”，完整写出四类观察。边界结论固定写“复合结构意味着职责重分配：第二条机制线不是把第一条机制线推得更激进，而是接手另一段行为任务”。
- 证据顺序：先读表 1，再读三路分流解释，最后完成单选判断。
- 互动升级点：单选题题面直接写“当前观察最适合走哪一路：继续单结构、进入复合结构，还是反馈 + 前馈组合？”
- 教师控制：教师释放作答；浏览默认开放；参考答案教师切换。
- 学生默认状态：表格可见，作答卡默认隐藏。
- 本页脱离讲稿后的自包含检查：学生应能说清“为什么复合结构不是结构名更长”。
- 预览口径：表格必须位于判断卡之前，不得变成“先答题，后看依据”。

### step-04｜复合结构总览：三类常见写法不是公式堆长
- 页面骨架：整页只放一张原生公式表和一块职责总结卡，不附带作答壳层。

- 证据顺序：先读表达式，再读适用问题，最后读结构分工和总结句。
- 互动升级点：本页不安排作答，纯粹承担结构工具箱总览职责。
- 教师控制：四项控制均不适用。
- 学生默认状态：纯展示页。
- 本页脱离讲稿后的自包含检查：学生应能仅凭本页区分三类结构分别偏向解决什么问题。
- 预览口径：公式必须以原生 LaTeX 表现，不退化为图片或一段长文本。

### step-05｜结构 A：`PI + 超前`——低频托举与中频整理分工
- 页面骨架：上半区放对象与控制器公式卡、职责分工句与表 3；中部放 Rust/WASM 原生统一面板；下半区放一张半宽任务卡。
- 页面正文内容：对象卡写 `$P_1(s)=\dfrac{1}{(s+1)(0.4s+1)}$`，控制器卡写 `$C_1(s)=6\left(1+\dfrac{1}{1.8s}\right)\dfrac{0.9s+1}{0.18s+1}$`。正文解释句写“`PI` 环节负责提高低频增益，超前环节负责在截止频率附近补相位”。表 3 保留超调量、调节时间、稳态误差、相角裕度、截止频率五项结果与说明。图后读图口令写“先看稳态误差是否压到接近零，再看相角裕度是否被托住，最后判断速度提升是否伴随更强控制作用”。
- 证据顺序：完整公式与对象 -> 分工解释 -> 表 3 -> Rust/WASM 原生统一面板 -> 半宽任务卡。
- 互动升级点补充：统一面板必须同页显示控件区、实际控制器传函、校正前性能指标与当前性能指标；控件可调总增益、PI 等效极点频率、超前零点频率与超前极点频率，并显式约束 `0<\omega_z<\omega_p`。
- 互动升级点：任务卡标题写“谁负责低频，谁负责中频”，要求学生用一句话分别写出 `PI` 与超前的职责。
- 教师控制：教师释放作答；浏览默认开放；参考答案教师切换。
- 学生默认状态：正文和图表可见，任务卡默认隐藏。
- 本页脱离讲稿后的自包含检查：学生应能明白这里不是“加大增益”，而是低频与中频的分工重排。
- 预览口径：统一面板只能出现在对象、控制器和职责解释之后，不得退回静态四联图。

### step-06｜结构 B：`滞后 + 超前`——低频补偿与裕量回收并行
- 页面骨架：与 step-05 同构：对象与控制器公式卡、表 4、Rust/WASM 原生统一面板、半宽任务卡。
- 页面正文内容：对象卡写 `$P_2(s)=\dfrac{1}{(s+1)(0.5s+1)(0.1s+1)}$`，控制器卡写 `$C_2(s)=6\dfrac{5s+1}{20s+1}\dfrac{0.8s+1}{0.16s+1}$`。正文解释句写“滞后环节负责抬升低频增益，超前环节负责补回相位储备”。表 4 保留“超调量变为 `0%`、调节时间变为 `17.28 s`、相角裕度达到 `108.70°`、截止频率下降到 `1.52 rad/s`”等结果。图后读图口令写“先看低频误差是否被压低，再看相角裕度为何变得很高，最后确认速度为何明显下降”。
- 证据顺序：完整公式与对象 -> 分工解释 -> 表 4 -> Rust/WASM 原生统一面板 -> 半宽任务卡。
- 互动升级点补充：统一面板下方给出控件区、实际控制器传函、校正前性能指标与当前性能指标；控件可调总增益、滞后极点频率、滞后零点频率、超前零点频率和超前极点频率，并显式约束 `0<\omega_{p,\mathrm{lag}}<\omega_{z,\mathrm{lag}}<\omega_{z,\mathrm{lead}}<\omega_{p,\mathrm{lead}}`。
- 互动升级点：任务卡标题写“这一版为什么更稳健但更保守”，要求学生各写一句主要收益与主要代价。
- 教师控制：教师释放作答；浏览默认开放；参考答案教师切换。
- 学生默认状态：正文和图表可见，任务卡默认隐藏。
