## 文档职责

- 本文件是 `4-3` 作者态互动页面蓝图，只负责人读版页面设计。
- 同目录 `4-3-interactive-contract.yaml` 尚未按本版重写；需在本文件确认后再进入机读契约阶段。
- 本版以最新讲义 `4-3-handout.md` 为唯一内容真源。旧版“结构工具箱优先”的 14 步设计不再沿用。
- 新主线为：单结构候选缺口 -> 复合控制边界 -> 反馈主结构 -> 前馈通道 -> 实现层保护 -> 客船复合方案 -> 首轮验证记录。

## 表述规则

- 页面标题采用教科书式陈述标题，不使用问句或否定句。
- 步骤 1 固定为导入漫画，步骤 2 固定为本次课程目标，步骤 3 固定为前测。
- 后测与总结分开；总结页顶部必须放课程信息图。
- 例题、案例推导和公式链采用逐步显影；题面、对象、目标和已知条件常显。
- 图片、结构图和曲线图服从讲义证据顺序，不抢到公式、题面和判断语句之前。
- 有曲线对比的页面优先升级为参数观察面板；默认状态复现讲义静态图，并在图形下方放控件或观察记录提交区。

## 逐步页面设计

### step-01｜单结构候选走向工程复合方案
- 页面骨架：顶部显示导入漫画 `4-3-cover-comic.png`，右侧或下方放一段问题情境，不设置作答区。
- 静态承载内容：问题句写“单结构候选已经能改善一部分指标，但执行器限制、可测扰动、参考突变和积分饱和会让方案仍然不能直接运行。”
- 元素出现顺序：1. 导入漫画 -> 2. 单结构候选的工程缺口句 -> 3. 本课主问题“怎样把候选结构推进为可运行的复合控制初始方案”。
- 互动升级点：无作答；教师端可同步翻页。
- 教师控制：四项控制均不适用。
- 学生默认状态：全部内容可见。
- 自包含检查：学生不读讲义也能知道本课从“能改善曲线”进入“能工程运行”。

### step-02｜本次课程目标
- 页面骨架：五张目标卡，按“区分、写出、解释、形成、记录”排列。
- 静态承载内容：完成本次课程后，学习者能够区分狭义复合控制与广义复合控制；写出参考前馈和扰动前馈的基本表达；解释 Bode 主环路分析在复合控制中的边界；形成“反馈主结构 + 前馈通道 + 实现保护”的初始方案；用首轮验证记录说明收益、代价和下一轮优先项。
- 元素出现顺序：1. 页面标题 -> 2. 五张目标卡 -> 3. 目标与后测对应提示。
- 互动升级点：无作答。
- 教师控制：四项控制均不适用。
- 学生默认状态：全部内容可见。
- 自包含检查：目标只描述本次课程能力，不写单元边界管理。

### step-03｜前置基础读图与信号判断
- 页面骨架：前测标题卡 + 四道客观题。
- 静态承载内容：题目只检查前置能力：单位反馈开环函数识别、扰动加入点读图、相角裕度含义、执行器限幅含义。
- 元素出现顺序：1. 前测说明 -> 2. 单选题“`L(s)=C(s)G(s)` 表示哪条分析主环路” -> 3. 判断题“扰动加入点不同会改变扰动到输出通道” -> 4. 多选题“哪些量可从时域响应直接读取” -> 5. 排序题“先读对象通道、再读控制律、最后读验证指标”。
- 互动升级点：客观题组，每题单独提交；不出现本讲尚未讲解的前馈公式。
- 教师控制：页面加载即开放作答；参考答案教师切换。
- 学生默认状态：题组可见。
- 自包含检查：前测不考本讲新概念。

### step-04｜单结构候选留下的设计缺口
- 页面骨架：原生表 1 + 工程场景问题列表 + 双卡作答区。
- 静态承载内容：完整保留“滞后、PI、超前、超前-滞后、前馈”的已经改善方面、暴露缺口和进入 4-3 后的动作。
- 元素出现顺序：1. 表 1 -> 2. 五条工程场景问题 -> 3. 结论句“继续重复选结构已经没有足够增量” -> 4. 单选卡“哪类候选最适合作为反馈主结构起点” -> 5. 多选卡“哪些问题需要复合控制或工程保护”。
- 主要公式：无。
