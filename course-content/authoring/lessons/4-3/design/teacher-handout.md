# 单元 4-3 | 教师版课堂讲义

- **标题**：初始方案落地实践：从对象分析到结构组合与首轮验证
- **学时**：90 分钟
- **课型**：实践主线课
- **课堂主线**：围绕 `任务卡回收 -> 对象分析 -> 结构分流 -> 参数方向 -> 首轮验证 -> 问题清单` 推进，不再把失败分类学或故意失败剧本作为课堂骨架。
- **上一课衔接语**：`4-2` 已经写出单结构首轮起步卡；这一课继续回答“这张卡怎样真正长成第一版可运行方案”。
- **下一课铺垫语**：今天把首轮证据和问题清单整理出来，下一课 `4-4` 再据此做多目标权衡与优化。

---

## 一、90 分钟课堂时间分配

| 环节 | 时间 | 目标 |
| --- | --- | --- |
| 开场桥接 | 8 分钟 | 让学生意识到“会选结构”还不等于“会把方案真正落地” |
| 主线一：对象分析回收 | 12 分钟 | 把任务表达卡和单结构起步卡重新压回对象矛盾 |
| 主线二：结构分流判断 | 12 分钟 | 判断继续单结构、进入复合结构，还是引入前馈 |
| 主线三：参数方向表达 | 14 分钟 | 把方案写成“先改什么、预期改善什么、准备承担什么” |
| 主线四：客船案例验证 | 18 分钟 | 完成超前初始方案的参数方向和首轮验证 |
| 主线五：工作区实践 | 18 分钟 | 小组完成对象分析单、方案表达卡和问题清单 |
| 后测与收束 | 8 分钟 | 固化首轮验证读数逻辑和问题清单格式 |

## 二、课堂流程

### 1. 开场桥接（0-8 分钟）

**教师要讲的关键话**

- “结构选型只回答了‘先从哪类结构起步’，没有回答‘这版方案怎样真正落到对象上’。”
- “今天不比谁公式更长，只比谁能把对象矛盾、参数方向和首轮证据写清楚。”
- “首轮方案不是最终最优解，而是一份可继续推进的设计输入。”

**教师提醒**

- 开场必须压住“直接报 PID 或复合结构”的冲动。
- 不要把课堂推进成“再讲一遍控制器家族”。

### 2. 主线一：对象分析回收（8-20 分钟）

**必须保留的核心内容**

- 从 `4-1` 的任务表达卡和 `4-2` 的单结构起步卡继续，但立刻回到对象：
  - 当前最紧矛盾是什么；
  - 当前硬约束是什么；
  - 继续强化单结构会先碰到哪条边界；
  - 第一轮验证最值得盯哪组读数。

**课堂操作**

- 让学生先写“当前最紧矛盾”和“最担心先失守的约束”，再谈结构。
- 对“快、稳、准都重要”的回答，要求必须圈出一项当前最紧目标。

### 3. 主线二：结构分流判断（20-32 分钟）

**必须保留的核心内容**

- 单结构还能继续推时，先说明它还承担哪类任务。
- 当单结构一强化就明显透支边界时，应进入复合结构。
- 给定或扰动通道可测时，前馈可以进入候选，但反馈继续保底。

**教师追问**

- “若继续单结构，你准备拿哪一条证据证明它还值得继续？”
- “若补入第二机制线，这条新机制线究竟来接哪一段职责？”

### 4. 主线三：参数方向表达（32-46 分钟）

**必须保留的核心内容**

- 参数方向不是“把哪个参数调大”，而是：
  - 先改哪段行为；
  - 预期先改善什么；
  - 最可能先透支什么。

**板书模板**

```text
先改哪段行为
-> 预期先改善什么
-> 最可能先透支什么
-> 首轮先看哪组读数
```

**典型误判**

- 只报参数名，不报设计意图；
- 只讲收益，不讲代价；
- 把“参数方向”误写成最后整定结果。

### 5. 主线四：客船航向保持案例（46-64 分钟）

**固定案例结论**

- 对象已带积分特性，当前不急于继续补低频能力。
- 主矛盾落在中频动态品质和控制峰值边界。
- 因此首轮优先采用超前方案，而不是先堆成 `PI + 超前`。

**教师操作**

- 带学生走完阻尼要求、目标截止频率、超前量、零极点布置和总增益五步。
- 每一步都追问“这一参数方向准备换来什么，又准备承担什么”。
- 用表格读出调节时间、超调量、相角裕度和控制峰值的并行关系。

### 6. 主线五：工作区实践（64-82 分钟）

**学生必须完成的三份材料**

1. 对象分析记录单  
2. 初始方案表达卡  
3. 问题清单移交表

**建议工作顺序**

- 先写对象分析，再写结构分流；
- 再写参数方向；
- 最后用首轮读数整理问题清单。

**教师巡视重点**

- 学生是否真正写出“第二条机制线为何进入”，而不是只写结构名字；
- 学生是否把问题清单写成“已满足目标 / 已暴露代价 / 下一轮优先调整项”。

### 7. 后测与收束（82-90 分钟）

**后测题建议**

1. 什么时候单结构不宜继续强化，而应改为复合结构？
2. 参数方向表达至少要写哪三句话？
3. 为什么首轮验证不能只报一个最漂亮的指标？
4. 问题清单为什么是 `4-4` 的必要输入？

**收束语**

- “这一课的产物不是最后参数，而是一套可以继续推进的设计输入。”
- “只要对象分析、参数方向和问题清单写清楚，下一轮优化就有了可靠入口。”

### 板书 1：实践主线

```text

   ↓

   ↓

```

```text
已满足目标

```

---

## 四、教师提醒

- 这是一节“把方案做出来”的实践课，不是失败术语课。
- 任何结构组合都必须绑定对象矛盾和参数方向，不能只写公式。
- 首轮验证必须同时读时域、频域和控制量边界，不能只报一个最好看的指标。
- 工作区结果必须最终落成“对象分析单 + 方案表达卡 + 问题清单”三份材料。
