# 单元 3-5 讲义设计框架

## 1. 单元定位

- 课次：`3-5（理论）`
- 主题：零点引入与动态改善
- 主线问题：只沿既有根轨迹调增益，为什么很快不够？如果想继续改善动态过程，为什么必须关注零点而不是只盯着控制器名称？
- 承接关系：承接 `3-4` 已建立的“既有轨迹上的读图与参数窗口判断”，转入“改变轨迹结构本身”的第一课。
- 后续铺垫：为 `3-6` 的统一对象对比实验提供理论骨架，为 `3-7` 的稳态改善线建立清晰边界。

## 2. 讲义主线

按“同一对象四种结构变化”的单一逻辑链组织，不按 `PD / 测速反馈 / 超前` 三段并列展开。

1. 从 `3-4` 的边界回收：稳定窗口内继续调增益，为什么仍会遇到速度、振荡和裕量的矛盾。
2. 固定同一基准对象，先比较“无零点 / 纯增益继续增大 / 引入左半平面零点 / 引入右半平面零点”。
3. 用根轨迹语言解释：零点为什么会吸引闭环极点，为什么轨迹不再只是沿原路径平移。
4. 用时域语言解释：零点为什么常常带来更快、更稳的动态趋势，但不会免费改善一切。
5. 用控制器结构语言解释：`PD`、测速反馈、简单超前为什么同源，但副作用和适用边界不同。
6. 用频域语言收束：左半平面零点带来的相位提前、带宽变化，与右半平面零点带来的相位滞后和逆响应风险。
7. 课末明确边界：本课只讲“零点动态改善线”，不展开完整超前设计，不进入模块4的选型整定。

## 3. 章节骨架

### 一、开场：为什么只调增益很快不够
- 回收 `3-4` 的结论。
- 提出本课核心问题：怎样改变轨迹的走法，而不是只在原轨迹上选点。

### 二、同一对象的四种版本：零点到底改变了什么
- 固定统一基准对象。
- 建立“基准 / 纯增益 / 左半平面零点 / 右半平面零点”的首轮比较表。

### 三、零点对根轨迹的吸引作用
- 从相角条件解释零点为什么改变根轨迹。
- 讲清“纯增益调整 vs 零点引入”的本质差异。

### 四、为什么零点常常带来动态改善
- 把极点迁移翻译为响应速度、阻尼和超调变化。
- 说明“零点并不直接等于更大增益”。

### 五、三种常见实现：`PD`、测速反馈与简单超前
- 先讲同源性，再讲结构差异。
- 必须压实“测速反馈不在前向通道显式增加零点”。

### 六、频域视角与非最小相边界
- 左半平面零点的相位提前与带宽变化。
- 右半平面零点的逆响应、相位滞后与速度上限。

### 七、课末收束：动态改善线到此为止
- 归纳本课得到的判断语言。
- 铺垫 `3-6` 与 `3-7`。

### 附录
- 保留可选 MATLAB/Octave 复现脚本入口，不在正文堆砌计算细节。

## 4. 本课必须压实的三组对照

| 对照组 | 必答问题 | 讲义落点 |
| --- | --- | --- |
| `纯增益调整 vs 零点引入` | 为什么轨迹和动态变化不再只是原轨迹上的平移？ | 第三、四节 |
| `PD vs 测速反馈` | 为什么两者都可能减小超调，但结构副作用不同？ | 第五节 |
