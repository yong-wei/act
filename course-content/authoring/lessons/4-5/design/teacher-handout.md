# 单元 4-5 | 教师版课堂讲义

- **标题**：约束下的优化设计实践：参数约束翻译与带约束参数优化
- **学时**：90 分钟
- **课型**：实践主线课
- **课堂主轴**：围绕客船航向保持这一固定结构案例，让学生亲手完成“无约束候选复核 -> 硬约束翻译 -> `fmincon` 求解 -> 结果解释”的完整链条，真正理解为什么数值上更优的候选仍可能在工程上不可交付。

---

## 一、课堂总览

`4-4` 已经完成目标函数、参数向量、归一化基准和一版无约束候选的建立。本课不再重复优化建模本身，而是让学生看到上一课没有解决的问题究竟出在哪里。课堂必须把“候选解越界”作为真正入口，而不是把约束只写成求解器配置项。若这一点没有被学生直观看见，后面的罚函数和 `fmincon` 都会退化为机械算题。

课堂统一对象保持为

$$
P_h(s)=\frac{0.01715}{s(s+0.1)(s+2.14375)}
$$

控制器统一保持为超前结构

$$
C_h(s)=K\frac{Ts+1}{\alpha Ts+1}.
$$

整堂课围绕三类解展开：

1. `4-3` 起始方案；
2. `4-4` 无约束候选；
3. `4-5` 带约束可用解。

学生需要在统一证据下比较这三类解，最终形成一句完整判断：边界改变的不是“偏好有没有意义”，而是“偏好可以在哪个可行域内继续争取”。

## 三、课堂展开

### 1. 导入与问题钉住（0-8 分钟）

开场直接给出 `4-5-ship-heading-unconstrained-failure-compare.png`，不先回顾公式。先让学生看两条事实：

- 无约束候选把闭环输出压得更快；
- 控制量却冲到了远超执行边界的位置。

此处追问一句即可：“如果某组参数把时间指标压得更好，却同时把执行机构动作推爆，我们还能把它叫作优化结果吗？”这句话的作用是把“最优不等于可用”钉住。教师不要在这一段抢着解释罚函数，而要让学生先承认问题存在。

### 2. 越界证据复核（8-20 分钟）

课堂回到表 1 和表 2。要求学生分两步读：

第一步，只看自由目标项，指出无约束候选为什么看起来有吸引力；
第二步，回到工程复核表，指出它究竟在哪些地方失守。

这一段最需要教师盯住的误判有两个：

1. 学生只因为相角裕度仍大于 `45^\circ`，就误以为整体仍然可接受；
2. 学生把“控制能量变大”与“控制峰值越界”混成同一件事。

应明确说明：控制能量是总代价语言，控制峰值是执行机构硬边界，两者不能混写。课堂收束时，把三条真正要进入约束的量板书出来：

$$
M_p \le 20\%, \qquad \max |u(t)| \le 7, \qquad \phi_m \ge 45^\circ.
$$

### 3. 硬约束翻译（20-32 分钟）

这一段改成学生操作段。教师先给一句总原则：参数范围保证结果还属于当前结构，硬约束保证结果可以交付。然后让学生把三条边界分别写成求解器能够消费的不等式。

板书建议直接写成：

```text
overshoot - 20 <= 0
control_peak - 7 <= 0
45 - phase_margin <= 0
```

如果学生把 `1 <= K <= 6` 也写进 `nonlcon`，不要立刻说错，而是追问：“这条式子是在判断输出过程可不可交付，还是在说明当前搜索还停留在这个超前结构的解释区间里？”让他们自己区分。

### 4. 参数范围与约束分工（32-40 分钟）

本段不长，但一定要讲透。参数范围来自上一课：

$$
1 \le K \le 6,\qquad
4 \le T \le 15,\qquad
0.15 \le \alpha \le 0.85.
$$

教师需要明确说明：

- 这些上下界不是工程复核条件；
- 它们只负责把搜索留在当前结构的可解释区间；
- 真正决定“能否交付”的是输出过程读回来的边界。

这一段若讲得含糊，学生后面会把所有不等式都叫作“约束”，但不知道约束之间的职责差异。

### 5. `fmincon` 求解实现（40-56 分钟）

本段进入上机或代码对照。按讲义附录中的结构走五步即可：

1. 定义 `x0`、`lb`、`ub`；
2. 写目标函数；
3. 写 `nonlcon`；
4. 调用 `fmincon`；
5. 把 `x_star` 重新翻译回控制器参数。

这里教师要强调一句：`fmincon` 只是在消费我们已经写好的问题定义。若目标函数和边界写错，求解器只会更快地把错误做得很彻底。

对照代码时，重点不是每个 API 选项，而是让学生看清 `nonlcon` 里三条边界的来源与方向。

### 6. 结果比较与解释（56-72 分钟）

这一段用表 6、表 9 和 `4-5-ship-heading-constraint-closure-compare.png`。课堂讨论必须围绕三个对象：

1. 起始方案为什么仍值得保留作对照；
2. 无约束候选为什么不能直接推进；
3. 带约束可用解为什么虽然不再“最激进”，却更值得进入下一轮比较。

教师应把学生的描述收束到三句话：

- 无约束候选把速度收益建立在越界代价上；
- 带约束可用解牺牲了一部分自由目标收益；
- 这种牺牲换回了真正有工程意义的可用性与稳健性。

### 7. 权重与结构延伸（72-82 分钟）

这一段只做收束，不展开新专题。先用权重 `A/B/C` 的对比说明：在可行域固定之后，权重仍会重排收益分配，但不会再允许越界“假优”混进来。随后再点到同一主案例下的 PID 对照：结构一旦变化，最优点所在区间也会跟着变化。

这一段的唯一目的，是让学生接受下一课 `4-6` 的问题不是“再多调几组参数”，而是“固定结构优化的边界已经显露”。

### 8. 后测与收束（82-90 分钟）

后测问题保持短而准：

1. 为什么控制峰值越界不能靠再调小一点权重来搪塞过去？
2. 参数范围和输出侧硬约束分别回答什么问题？
3. 同一权重下，无约束最优和带约束最优为什么会分成两组不同参数？

若学生能回答出“可行域改变了最优点”，说明主链形成；若仍只会说“因为加了罚函数所以结果变了”，则说明他们只记住了工具，没有理解边界语言。

## 四、板书建议

### 板书 1：本课问题链

```text
无约束候选
↓
越界证据复核
↓
硬约束显性化
↓
fmincon / 罚函数
↓
可行解比较
```

### 板书 2：三条硬边界

```text
Mp <= 20%
umax <= 7
phase_margin >= 45 deg
```

### 板书 3：两类约束的职责

```text
参数范围：保证结构可解释
输出硬约束：保证结果可交付
```

## 五、课堂把握点

- 本课不重复 `4-4` 的目标函数建立过程，入口必须是越界证据。
- 不要把控制能量与控制峰值混成同一类指标。
- `nonlcon` 的教学价值在于把边界写成规则，而不在于 API 细节。
- 结果解释必须始终回到统一证据，而不是只读“最优参数”。
- PID 对照只服务 `4-6` 的边界预告，不在本课展开结构选型讨论。
