## 全局约定

**教师端右侧**：面向全班展示的内容 + 教学控制操作
**学生端右侧**：以教师端为信息基础，学生自主完成的个性化任务

**学生端"个性化"的定义**：
- 不基于历史数据做差异化推送
- "个性化"体现在：学生自己填写预测、自己操作仿真得到结果，系统将自己的输入与结果并排展示，形成"个人认知记录"
- 学生端操作完全独立于教师端操作，教师控制节奏（揭示/释放），学生自由探索内容

## 步骤 07｜四种响应家族：图示（8min）

**页面类型**：核心内容页，分步揭示 + 命名互动

### 教师端

```
四种响应家族

[占位：R-4 图2 四种极点配置+对应时域曲线，四图并排]
初始状态：曲线可见，标签遮住

家族 ①  过阻尼（Overdamped）
  极点位置：两个不同负实数极点
  曲线特征：单调上升，无超调，较慢达到稳态

家族 ②  欠阻尼（Underdamped）★ 工程最常见
  极点位置：一对共轭复数极点（实部为负）
  曲线特征：振荡衰减，有超调，较快接近稳态

家族 ③  临界阻尼（Critically Damped）
  极点位置：两个相同负实数极点（重极点）
  曲线特征：单调上升，无超调，是无超调中最快的

家族 ④  不稳定（Unstable）
  极点位置：实部为正的极点
  曲线特征：发散，不收敛到任何稳态值

教师口述：
  "这四种，工程中最常见的是哪种？——第②种。
   超调+衰减，这才是真实系统的常态。"

[学生命名实时汇总：标签云或列表，教师可高亮有趣的命名]
```

**教师控制**：「遮住所有标签（展示曲线）」→「揭示家族①」→「揭示②③④」→「高亮★工程最常见」→「展示命名汇总」

## 步骤 10｜三个性能指标：定义（10min）

**页面类型**：核心概念页，带标注图

### 教师端

```
三个性能指标（定义 + 工程含义）

[占位：R-3变体 带三个标注区域的船舶航向曲线]
[初始状态：三个标注区域以虚线框占位，标注内容遮住]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mₚ  超调量（Peak Overshoot）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
定义：响应峰值超出稳态值的百分比
      Mₚ = (y_max − y_∞) / y_∞ × 100%

船舶工程含义：
  船头冲过目标航向 → 需要反向修舵 → 增加能耗和时间

→ 完整推导将在单元 1-3 中给出

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
tₛ  调节时间（Settling Time）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
定义：响应进入 y_∞ ± 2% 范围内并保持不再离开的时刻

船舶工程含义：
  转向过程的总耗时 → tₛ 过大影响航线精度和任务效率

→ 完整推导将在单元 1-3 中给出

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
tᵣ  上升时间（Rise Time）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
定义：响应从稳态值的 10% 上升到 90% 所用的时间

船舶工程含义：
  舵角动作后多快有"动感" → tᵣ 小说明响应灵敏

基本矛盾：tᵣ ↓（更灵敏）通常导致 Mₚ ↑（更多超调）

[教师依次点击图上三个标注区域，高亮对应指标，同步推送学生端]
```

**教师控制**：「标注 Mₚ」→「标注 tₛ」→「标注 tᵣ」→「释放思考题：客船 vs 海巡船」→「随机抽答2-3人」

### 学生端

```
三个性能指标

[占位：R-3变体 同一带标注曲线图，当前高亮跟随教师]

指标速查卡（跟随教师讲解逐步显示）：

┌─────────────────────────────────────┐
│ Mₚ  超调量    Mₚ = (y_max−y_∞)/y_∞  │ ← [教师标注Mₚ后显示]
│ 单位：%                              │
├─────────────────────────────────────┤
│ tₛ  调节时间  进入 ±2% 并保持的时刻  │ ← [教师标注tₛ后显示]
│ 单位：s                              │
├─────────────────────────────────────┤
│ tᵣ  上升时间  10% → 90% 所用时间    │ ← [教师标注tᵣ后显示]
│ 单位：s                              │
└─────────────────────────────────────┘

思考题（教师释放后出现）：

假设你是船舶工程师：
```
