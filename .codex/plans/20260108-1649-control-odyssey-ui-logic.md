# Control Odyssey UI & Logic

## Goal
- 调整关卡选择交互、排行榜去重与提交逻辑、过关流程、面板显示与曲线全景展示，并更新设计文档

## Scope
- In-scope: 关卡选择页交互、排行榜去重、提交去重、防止重复关卡、配置页与游戏页面板调整、曲线全景、设计文档更新
- Out-of-scope: 新关卡/新玩法、数据库迁移、接口协议重构

## Steps
1) 修复成绩提交重复与排行榜按账号最高分去重
2) 调整关卡选择页交互与过关跳转逻辑；配置页显示控制器配置、游戏页移除配置面板
3) 曲线全景展示与数据采集优化
4) 更新 docs/Game_ControlOdyssey_Design.md 的实现现状与计划
5) 运行 lint/test/build 并记录结果

## Tests
- npm run lint
- npm run test
- npm run build

## Acceptance
- 关卡选择页点击仅选中，底部按钮进入配置页；左侧榜单随选中关卡更新
- 榜单同账号只显示最高分，单局只提交一次成绩
- 过关后进入下一关配置页（不再卡在第二关）
- 游戏页不显示控制器配置面板；曲线展示全程全景
- 设计文档已更新
