# Lesson 10 线下课堂资源

## Goal
- 基于两份 PPT 与统一框架，设计并落地 90 分钟线下课堂的静态/互动资源，注册为预置教案并可在互动学习页访问。

## Scope
- In-scope: 读取 PPT 与统一框架；在 `src/resources/interactive-learning/lesson-10` 新增资源；注册到资源与预置教案；更新 `docs/ProjectDescription.md`。
- Out-of-scope: 不改动其他课程结构，不做额外 UI 设计改版。

## Steps
1) 调研现有课程与统一框架：读取 `docs/Unified_Lesson_Framework.md`、提取两份 PPT 的结构要点、查看现有 interactive-learning 课程与预置教案注册方式。
2) 设计 lesson-10：按 90 分钟节奏编排静态与互动环节；如需新增互动组件则实现并接入资源注册与教案。
3) 集成与文档：将 lesson-10 注册为预置教案并确保互动学习页面可访问；更新 `docs/ProjectDescription.md`。
4) 测试与验收：运行 lint/test/build/test:integration；整理结果与变更说明。

## Tests
- `npm run lint`
- `npm run test`
- `npm run build`
- `npm run test:integration`

## Acceptance
- 课程在 `src/resources/interactive-learning/lesson-10` 存放，符合统一框架与 90 分钟安排。
- 资源注册与预置教案注册完成，互动学习页面可访问 lesson-10。
- 文档更新完成；全部测试通过。
