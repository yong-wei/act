# Lint Fix + Build

## Goal
- 修复当前 lint 警告并完成 build 验证

## Scope
- In-scope: 修复当前 `npm run lint` 提示的警告、运行 `npm run build`
- Out-of-scope: 新功能开发、非 lint 相关重构

## Steps
1) 定位并修复所有 lint 警告点
2) 复跑 `npm run lint` 确认无警告
3) 运行 `npm run build` 并记录结果

## Tests
- `npm run lint`
- `npm run build`

## Acceptance
- lint 无警告/错误
- build 成功完成
