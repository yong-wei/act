# Odyssey PD Investigation

## Goal
- 定位自动模式下 PD 控制量在正阶跃时反向变化的原因

## Scope
- In-scope items
  - Level 5（小惯性+纯延时）自动模式的控制量计算与显示路径
  - 控制器符号与曲线渲染方向的映射
- Out-of-scope items
  - 新增功能或重构其他关卡逻辑

## Steps
1) 定位控制奥德赛资源与 Level 5 自动模式的控制计算/显示代码
2) 分析 PD 控制计算与曲线显示方向，复现并定位原因
3) 给出结论与修复建议（如需改动则实施并验证）

## Tests
- 若涉及代码改动：npm run lint
- 若涉及控制逻辑：手动复现实验步骤截图/描述

## Acceptance
- 明确原因（仿真设置/显示方向/控制逻辑）并给出依据
- 如修复：自动模式与手动模式方向一致
