# Lesson 01 & Lesson 02 (Laplace) Offline Course Build

## Goal
- 将 lesson-02 原建模课迁移为 legacy，并按统一框架补齐 lesson-02（拉氏变换）与 lesson-01（反馈）90 分钟线下课程资源与预置教案。

## Scope
- 迁移现有 lesson-02 资源为 lesson-02-legacy（registry、preset、入口与知识卡片对齐）。
- 新建 lesson-02（拉氏变换）与 lesson-01（反馈）互动资源、预置教案、知识节点与互动学习入口。
- 更新资源注册表、系统资源 ID、知识点种子与文档说明。

## Steps
1) 迁移旧课为 lesson-02-legacy：重命名资源目录与 registryId/presetKey，修复知识卡片 ID 与知识图谱节点对齐。
2) 新建 lesson-02（拉氏变换）：新增互动组件、知识卡片、预置教案与互动学习页面入口。
3) 新建 lesson-01（反馈）：新增互动组件、知识卡片、预置教案与互动学习页面入口。
4) 更新知识图谱种子与 MDX 内容、系统资源 ID、首页精选课程入口。
5) 更新 docs/ProjectDescription.md，运行 lint/test/build/integration 测试并提交推送。

## Tests
- npm run lint
- npm run test
- npm run build
- npm run test:integration

## Acceptance
- lesson-02 旧课以 lesson-02-legacy 命名可用，新 lesson-02 为拉氏变换课。
- lesson-01 与 lesson-02 预置教案可克隆，知识卡片与 KnowledgeNode 绑定成功。
- 互动学习页面可访问新课入口并加载互动资源。
- 文档与测试结果更新完成。
