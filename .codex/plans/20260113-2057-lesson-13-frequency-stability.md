# Lesson 13 Frequency Stability

## Goal
- 以统一框架新增 lesson-13 频域幅相特性与稳定判据的 90 分钟线下课程，并在互动学习页面可访问。

## Scope
- In-scope: 新增 lesson-13 资源组件（知识卡片与互动环节）、资源注册、预置教案、互动学习页面入口、项目说明更新。
- Out-of-scope: 数据库 TeachingResource/KnowledgeNode 实际落库与线上内容发布。

## Steps
1) 设计 lesson-13 课程结构与知识卡片/互动组件，实现新组件与资源配置。
2) 更新资源注册与预置教案，替换 lesson-13 入口与互动学习页面展示。
3) 更新文档与进行测试/构建校验，整理提交并推送。

## Tests
- npm run lint
- npm run test
- npm run build
- npm run test:integration

## Acceptance
- lesson-13 预置教案按 BOPPPS 流程注册并可引用 registryId。
- 互动学习页面可访问 lesson-13 并展示知识卡片与互动环节。
- 文档更新，测试通过并提交推送。
