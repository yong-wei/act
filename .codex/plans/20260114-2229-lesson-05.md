# lesson-05 线下课堂资源

## Goal
- 基于指定PPT与统一框架，设计并落地lesson-05的90分钟线下课堂资源（含知识卡片与互动环节）并在互动学习页面可访问。

## Scope
- In-scope: 新增lesson-05课程结构、知识卡片与互动环节配置；知识卡片绑定到新增知识图谱节点；注册为预置教案；资源放入`src/resources/interactive-learning/lesson-05`。
- Out-of-scope: 改动其他课程内容或全局UI重构。

## Steps
1) 调研现有课程/框架与资源结构，确定BOPPPS与注册方式、知识图谱绑定格式。
2) 产出lesson-05课程资源与知识卡片/互动配置并放置到指定目录。
3) 注册预置教案、更新相关入口与文档说明，完成验收检查。

## Tests
- npm run lint
- npm run test
- npm run build

## Acceptance
- lesson-05在互动学习页面可访问且结构符合BOPPPS。
- 知识卡片数量为12-14，并绑定新增知识图谱节点。
- 资源与注册方式符合仓库规范，文档更新完成。
