# 自适应测评报告配图前端映射计划（仅规划）

## 1. 目标与约束

- 目标：为 `image/image.png` 中 3 个空白位提供可落地的前端界面映射，支撑报告表述：  
  “学习行为数据采集 → 协同过滤算法分析 → 动态推荐/现场生成 → 个性化能力训练”。
- 约束：本轮只做规划，不写业务代码；方案需优先复用现有页面与 API。

## 2. 空白位映射（推荐）

### 空位 A（左侧框：题库稳定性 / 经典题保持 / 评测标准统一）

- 推荐映射页面：`/assessment/adaptive-practice`
- 画面焦点：
  - 左侧“能力诊断”三维条（计算型/跨域型/设计型）
  - 薄弱知识点标签（`weakAreas`）
  - 推荐训练方向列表（`recommendedFocus`）
  - 右侧题干区域的“domains + difficulty”标识
- 对应能力证明点：
  - 经典题库（`PRESET_QUESTIONS`）可持续复用
  - 题目带统一结构字段（difficulty/domains/tags/options），可支撑标准化评测

### 空位 B（中间框：差异化生成 / AI 现场生成试题 / 满足个性需求）

- 推荐映射页面：`/assessment/adaptive-practice`
- 画面焦点：
  - “AI 即时生成题目”按钮
  - 生成后新题题干（带跨域标签）
  - 当前能力值 θ 与置信区间 CI
  - 提交反馈区“推荐补强方向”
- 对应能力证明点：
  - 支持按 `targetKnowledgeTags + difficultyTarget + domains` 生成题目
  - 实现“动态推荐 + 现场生成”的双路径差异化训练

### 空位 C（右侧框：结构型能力 / 评价常态化）

- 推荐映射页面：`/evaluation/prompt-assessment`（可叠加新建“能力追踪页”）
- 画面焦点：
  - 结构化提示词编辑器（控制对象/目标/约束/背景）
  - 质量仪表盘（完整性、精确性、结构化、可执行性）
  - 一致性报告（目标-行为对齐、收敛形态）
- 对应能力证明点：
  - AI 生成与结构化评价结合（评分 + 建议 + 一致性）
  - 已有后端支持历史化：`/api/evaluation/prompt-history/[userId]`
  - 已有能力轨迹：`/api/assessment/ability-report/[userId]`（可用于常态化趋势展示）

## 3. 配图产出策略（按报告可读性）

- 图 1（空位 A）：选“诊断 + 标准题卡片”同屏，强调“题库稳定性+标准化”。
- 图 2（空位 B）：选“点击 AI 即时生成后”的状态，强调“差异化与即时生成”。
- 图 3（空位 C）：选“质量仪表盘 + 一致性报告”双栏，强调“结构化评价常态化”。

- 风险：模板右侧标题当前写作“题库稳定性”，与内容“结构型能力/评价常态化”存在语义偏差。  
  处理：报告图建议将右侧栏标题改为“结构化评价”，不改亦可在图注解释。

  处理：加“演示数据锁定模式”或准备一组固定演示账号数据。
