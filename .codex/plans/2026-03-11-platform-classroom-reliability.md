# 课堂链路稳定性与运维可观测性实施计划

## 目标

- 打通学生从 `dashboard` / 通用“加入课堂”页面进入当前正在进行课程的链路，按课堂实际课程类型正确跳转。
- 为互动课程教师端补齐“结束课堂”能力，并允许教师后台停止进行中的课堂，减少遗留 `ACTIVE` 课堂。
- 将教师端与学生端的翻页状态解耦，消除教师页回跳；学生端若与教师不同步，提供显式提示与一键跳转。
- 提升 100+ 学生峰值场景下的可诊断性与服务器开销表现，优先复用现有服务与日志能力。
- 优化全站浅色模式的统一样式映射，不对单个精品课程做硬编码。
- 更新项目私有互动课程制作技能，使其纳入这次暴露出来的实现约束与验收闭环。

## 约束

- 优先复用现有 `/api/session`、`/api/session/join`、`/api/session/[sessionId]`、`/api/session/[sessionId]/state`，非必要不新增接口。
- 课程路由判断应由“会话所属教案/课程元数据”驱动，不能再在各入口页硬编码课程路径。
- 主题优化必须落在统一样式层，例如 `src/app/globals.css` 或共享主题 token，不允许为某个页面单独补浅色 patch。
- 需要保留现有 L-2a 与“柔性之海”的独立课堂入口与 demo 入口。

## 执行步骤

### 1. 统一课堂码加入与课程路由解析

- 复查 `src/app/api/session/join/route.ts`、`src/app/classroom/join/page.tsx`、`src/features/interactive/premium-classroom-quick-join.tsx`、`src/features/interactive/l2a-time-domain/entry-page.tsx`、`src/features/interactive/cruise-classroom/entry-page.tsx`。
- 复用 `plan` 信息，在服务端 join 返回值中补充可判定课程路由所需的最小元数据。
- 新增统一课程路由解析 helper，供 dashboard / 通用 join / 课程页 join 共用。
- 补测试覆盖“邮轮/L-2a/默认课堂”三类跳转。

验收：
- 输入同一课堂码，无论从 `dashboard`、`/classroom/join` 还是互动课程页加入，都落到同一正确学生页。

### 2. 补齐结束课堂控制

- 复用 `PATCH /api/session/[sessionId]` 的 `status: FINISHED` 能力，不新增结束接口。
- 为 L-2a、邮轮课程教师页接入统一“结束课堂”按钮，保证任意环节可操作。
- 在教师班级详情页为进行中的课堂补充“停止课堂”操作，而不是只能进入课堂。
- 复查结束后学生端显示、班级记录筛选与时长计算。

验收：
- 课堂结束后不再残留 `ACTIVE`。
- 教师可从课堂页或班级页两条路径结束课堂。

### 3. 重构教师/学生同步模型

- 教师端：
  - 轮询仅同步会话状态与附属信息，不再无条件用服务端 `currentItemId` 覆盖本地页码。
  - 翻页时引入“待确认步骤”机制，避免轮询回写旧页。
- 学生端：
  - 本地页码与教师目标页码分离。
  - 初次进入或显式点击时才跳转到教师页；若不同步则展示提示条与“一键跳转”按钮。
  - 保持 demo 模式自由切换。
- 优先把共享逻辑提炼为轻量 helper，避免 L-2a / 邮轮各自再复制一份。

验收：
- 教师连续翻页不再偶发回跳。
- 学生端手动留在旧页时，会出现不同步提示；点击后跳到教师页。

### 4. 高峰性能与日志

- 远端检查 `act-obe` 运行方式与日志入口，确认当前使用 Podman + systemd。
- 本地实现中减少不必要的高频轮询/重复状态写入。
- 复用现有日志接口与服务端日志输出，补课堂同步、join、状态轮询、结束课堂的最小诊断日志。
- 如现有日志不足，增加可控开关的结构化日志，便于下次授课后分析。

验收：
- 能说明主要请求热点与日志采集点。
- 关键链路出现异常时，可在本地或远端日志中定位 join / sync / finish 行为。

### 5. 浅色主题统一优化

- 审查 `src/app/globals.css` 的浅色桥接映射，补足交互课堂高频使用的文字、边框、渐变和强调色。
- 保证改动对全站统一生效，而不是只修某个精品课程页面。
- 补一个轻量回归测试，防止浅色文本重新退回低对比度。

验收：
- 浅色模式下互动学习关键页面文字与按钮具备足够对比度。

### 6. 更新项目私有技能

- 更新 `.codex/skills/interactive-lesson-implementation/SKILL.md` 与相关参考文档/笔记模板。
- 纳入这次暴露出的规则：
  - 入课链路必须复用统一课堂码解析。
  - 教师端必须具备结束课堂能力。
  - 学生端默认按“顶部提示 + 按需互动 + 不同步提醒”实现。
  - 实现完成后必须执行“设计稿差异核对 + 课堂运行链路核对”。

验收：
- 技能文档反映上述约束，并可通过现有校验脚本。

### 7. 验证与收尾

- 运行针对性脚本、`npm run lint`、`npm run test`、`npm run build`，必要时补充测试脚本。
- 更新 `docs/ProjectDescription.md`。
- 提交并推送当前分支。

## 当前已知根因

- `dashboard` 与 `/classroom/join` 目前是硬编码学生路由，未根据课堂所属课程类型分流。
- 教师端与学生端都在轮询后直接覆盖 `activeIndex`，教师翻页后容易被旧状态回写。
- 互动课程教师页尚未完整复用现有结束课堂流。
- 远端部署环境使用 Podman + systemd，而不是裸 `docker`，后续日志采集需要针对该链路设计。
