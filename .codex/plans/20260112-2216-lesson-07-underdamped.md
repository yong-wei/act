# Lesson 07 欠阻尼二阶系统互动课程

## Goal
- 基于 7.1 PPT 按统一框架新增 lesson-07，并以预置教案面向所有教师

## Scope
- In-scope: lesson-07 互动组件与页面、资源注册、预置教案、项目说明更新
- Out-of-scope: 新增仿真引擎或数据库迁移

## Steps
1) 设计 lesson-07 的 BOPPPS 流程、内容结构与组件清单
2) 实现 lesson-07 组件/manifest/页面与静态资源
3) 注册资源并新增预置教案，更新文档说明
4) 运行 lint/test/build 并提交推送

## Tests
- npm run lint
- npm run test
- npm run build

## Acceptance
- 课程结构与时长满足 90 分钟线下课堂
- 预置教案可被教师克隆
- 相关资源与注册完成，文档更新
