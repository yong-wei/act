# Step 7B：AI 生成式媒体规格

> 适用范围：位图、封面漫画、讲义信息图、导入视频、课程内容视频、课程音频播客及其提示词。

## 默认新增媒体

### 1. 讲义封面漫画

- 用于学生版讲义首页信息节之后、正文之前的注意力引入。
- 多媒体阶段默认交付 `[单元编号]-cover-comic-prompt.md`。
- `[单元编号]-cover-comic.png` 不属于媒体制作阶段必须生成的成品；由用户后续制作完成后，在审查阶段确认可用性。
- 封面漫画必须以情节驱动，而不是把讲义摘要拆成插图。
- 封面漫画默认就是**多格漫画**，不是单张海报、单幅概念图、整页大场景插画，也不是把多个场景松散拼在一张大图里。
- 默认按 **4 格或 6 格** 设计；除非用户明确要求其他格数，否则不要写成“单图中包含若干元素”的模糊描述。
- 优先级固定为：先有趣，再有情节张力，再有单元预告感，最后才是知识点传达。

### 2. 15 秒导入视频

- 用于课堂开场或互动课首页的情绪启动。
- 生成导入视频提示词时，默认显式调用 `seedance` 技能。
- 目标不是复述讲义，而是快速建立问题情境、唤起兴趣、形成“为什么要学这一节”的感受。
- 必须先判断最适合该单元核心问题的叙事机制，再决定主题与场景。
- 可选机制至少包括：
  - 冲突型：错误直觉被打脸。
  - 任务型：学生代入工程师。
  - 类比型：生活/具体场景映射抽象概念。
  - 工业型：真实设备、异常、风险。
  - AI/未来型：仅限确有前沿语义的单元。
- 不得为了系列统一而把所有单元套入同一母题，更不得默认回到船舶、海面或抽象工程空间。
- 多媒体阶段交付提示词，不直接生成 `[单元编号]-intro-video.mp4` 成品。
- `[单元编号]-intro-video.mp4` 由用户后续制作完成后，在审查阶段确认可用性。
- 生成完导入视频提示词后，若 `processed/[单元编号]-media.md` 的 `intro-video.mp4` 对应节仍为空，才额外压缩出 1 句导入视频文案；若该节已有内容，则不覆盖。
- 这句文案必须直接描述视频里看到了什么，例如“两个对象同时启动、一个超调一个平稳逼近”这类场景化句子；禁止写成“用导入情境引出……”“引出本课主题……”之类抽象总结。

### 3. 讲义信息图

- 用于学生版讲义正文结束、附录开始前的整页总结。
- 作用是把本单元的概念关系、关键结论、典型图形或辨识线索压缩成一张可复习的信息图。
- `[单元编号]-info.png` 不属于媒体制作阶段必须生成的成品；媒体制作阶段只登记内容要求与审查占位。

### 4. 课程级默认成套媒体

资源规划中必须显式保留待审查占位：

- `[单元编号]-slides.pdf`
- `[单元编号]-course.mp4`
- `[单元编号]-audio.m4a`

其中 `slides.pdf` 与 `audio.m4a` 不属于媒体制作阶段必须生成的成品；由用户后续制作完成后，在审查阶段确认可用性。

若某项不适合当前单元，需在 `multimedia.md` 中明确写出不采用原因，避免默认省略。

### 讲义封面漫画（位图特例，媒体阶段交提示词）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
资源 h-cover | 讲义封面漫画
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

存放：`raw/{单元编号}-cover-comic-prompt.md`
后续成品：`processed/{单元编号}-cover-comic.png`，由用户制作后进入审查阶段
引用于：handout.md 信息节后、正文前（媒体阶段默认先交提示词，不强制插图）

【中文定稿提示词】
{直接可投喂中文生图平台的完整提示词。必须是自然语言正文，不得只给设计约束清单。}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**封面漫画硬约束：**

- 固定开头必须是：
  - `请以哆啦A梦中的人物为原型。创作多格漫画，需要使用箭头标注格子的阅读顺序。`
- 固定开头之后，不再额外强调风格和配色。
- 后续正文必须直接进入**逐格描述**，不能只写整张图的总体氛围。每一格都要单独编号，并写清：
  - 本格场景
  - 角色动作 / 表情
  - 关键道具
  - 一句简短中文台词
- 提示词中必须明确出现 `第1格 / 第2格 / 第3格 / 第4格` 这类分格标记；若是 6 格，则继续写到 `第6格`。
- 必须明确要求“每一格是独立画面，共用同一页排版”，避免模型把提示词理解成单幅大图中的多个元素。
- 必须明确要求“格与格之间要有清晰边框或留白分隔”，不得生成无边界的大场景拼贴图。
- 若需要镜头关系，写成“第1格……；第2格……；第3格……”的顺序，不要写成一整段连续电影式描写。
- 所有对白必须使用简洁中文，不得出现英文气泡、长段旁白、讲义式摘要或大块公式堆砌。
- 场景不必局限于教室、船舶或课堂讲授位，只要足够具体、能稳定生成、能引出本课核心问题即可。
- 禁止使用以下模糊写法：
  - “画一张封面图，里面包含……”
  - “整体画面分成若干部分……”
  - “左边是……右边是……背景还有……”
  - 任何只描述整张图、不逐格拆开的写法

**逐格写法最小样例：**

```text
请以哆啦A梦中的人物为原型。创作四格漫画，需要使用箭头标注格子的阅读顺序。

第1格：码头黄昏，远处有一艘准备转向的船。大雄趴在栏杆上发愁，手里拿着一张画满轨迹的草稿纸。道具是草稿纸和望远镜。台词：“明明还稳定，怎么船头还是晃个不停？”

第2格：哆啦A梦指着一块悬浮小黑板，黑板上只有简洁的根轨迹线条和几个极点标记。哆啦A梦神情认真。道具是小黑板和记号笔。台词：“先别急着调参数，先看关键节点。”

第3格：小夫把增益旋钮拧大，屏幕上的轨迹更贴近目标，但旁边的波动也更明显。静香露出担心表情。道具是控制台、旋钮、响应曲线屏幕。台词：“跟踪更快了，可怎么感觉更悬了？”

第4格：哆啦A梦把根轨迹图、阶跃曲线和 Bode 图并排展示，几个人一起对照。道具是三张并排的小图卡。台词：“要把根轨迹、时域和频域放在一起看。”
```

**反例特征：**

- 只有“整体画面描述”，没有逐格编号。
- 明明写了“多格漫画”，正文却仍然只描述一张完整大图。
- 用“左侧 / 右侧 / 上方 / 下方”组织整张图，却没有把每一格当成独立画面。
- 没写每格台词，导致模型更容易生成海报式插画而不是漫画分镜。

### 15 秒导入视频（媒体阶段交提示词）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
资源 ic-intro-video | 15 秒课程导入视频
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
文件名：{单元编号}-intro-video-prompts.md
存放：`raw/{单元编号}-intro-video-prompts.md`
后续成品：`processed/{单元编号}-intro-video.mp4`，由用户制作后进入审查阶段
引用于：课堂开场 / interactive-page 首页导入区域

【输出内容】
1. Agent 模式视频生成提示词
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**即梦导入视频硬约束：**

- 默认使用中文提示词，不得只堆关键词。
- 默认只采用 `seedance` 的 Agent 模式生成，不再额外交付“分镜图生成提示词”或“图生视频提示词”。
- 一条视频默认遵循“0-3 秒钩子、3-12 秒展开、12-15 秒点题”，且只服务一个核心概念。
- 提示词正文必须写成**分段分镜描述**，按时间顺序写清 3-5 段镜头或情节推进；每段都要能独立看出“谁在做什么、场景如何变化、镜头如何承接”。
- 默认优先使用具体、可拍、可转场的场景，少用公式、板书和抽象悬浮空间。
- 必须明确写出已选定的**唯一风格**，并补一句“为什么该风格适合本课核心问题”；风格可以是电影级写实、2D 动画、3D 动画、木偶、黏土动画等，但不得把多个风格并列成“任选”。
- 题材应围绕当前单元的核心冲突自由选取，不得为了课程系列统一而强行限制在船舶、海洋、海面或驾驶台场景；若实验室、仓储、校园设备、工业产线、课堂演示台更合适，应优先使用这些场景。
- 提示词中必须写清关键动作链、镜头或转场安排、结尾点题方式、音效/配乐气质与必要的负面约束，但不要回到“四格图”“主体形态固定”“四张图保持一致”这类模板。
- 推荐结构为：风格与选择理由 -> 镜头 1（0-3 秒）-> 镜头 2（3-7 秒）-> 镜头 3（7-12 秒）-> 镜头 4（12-15 秒）-> 音效/配乐 -> 负面约束。
- 仅当 `processed/[单元编号]-media.md` 的导入视频节为空时，才从 Agent 模式提示词提炼 1 句主线描述写入，保留主角、动作、冲突和结果，不保留“点题”“引出”“说明本课”这类元话语；若该节已有人工内容，则保持原样。

**推荐写法样例：**

```text
## Agent 模式视频生成提示词

为《自动控制原理》单元“时域响应基础”设计一段 15 秒课程导入视频，采用高质量 2D 动画实验短片风格。选择这一风格的原因是：本节需要把“同样到达目标，但过程差别很大”的动态对比做得直观、轻快、易于学生立刻看懂，同时又保留工程判断的紧张感。

镜头 1（0-3 秒）：实验台上两台同型号小车同时接到到达目标位置的指令，镜头居中推进，先把“同题竞争”的局面立起来。

镜头 2（3-7 秒）：左侧小车冲过目标又回拉，右侧小车还在平稳逼近，镜头快速切换但保持同一空间关系，让观众第一眼看出“快不等于好”。

镜头 3（7-12 秒）：画面切到屏幕上的两条响应曲线，并和两台小车的真实运动做匹配剪辑，突出超调、回落和缓慢逼近的差异。

镜头 4（12-15 秒）：两台车最终都到达目标，画面收束到标题“时域响应基础——从响应曲线到动态性能指标”，留下“都到了，为什么表现还不一样”的问题。

音效/配乐：轻微电机声、计时器提示音、克制的电子节奏，不要热血鼓点。

负面约束：不要海面、船舶、驾驶台，不要大段公式板书，不要花哨科幻 UI，不要真人夸张表演。
```

## AI 工具选用建议

| 资源类型 | 推荐工具 | 说明 |
|----------|----------|------|
| 工程场景图、设备实物图、讲义封面漫画 | 即梦 / Midjourney / DALL-E | 位图，需中文定稿提示词 |
| 复杂原理示意图 | Stable Diffusion + ControlNet | 可控制构图 |
| 动态演示视频 | `seedance` | 课程视频与导入视频默认统一走 `seedance` Agent 模式 |
| 课程音频播客 | 语音 / 音频工具链 | 文案稳定后再导出音频 |
