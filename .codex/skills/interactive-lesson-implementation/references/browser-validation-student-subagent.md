# 学生端浏览器验收子代理规范

## 适用范围

本文件只给学生端浏览器验收子代理使用。主代理不需要读取本文件，只需在分派学生端角色时把本文件一并下发。

## 启动基线

- 浏览器验收默认基线是 `npm run startup`
- 若本地服务不是由该基线启动，先回报主代理，不要自行切换到不完整的 standalone 或 `npm run start`
- 若页面看起来“只加载一半”，先检查是否仍在等待 hydration 或静态资源未准备好

## 账号与浏览器前置处理

- 学生账号：`demo`
- 学生密码：`DemoStudent@Just2026!`
- 登录字段优先输入 `demo`，不要擅自改成邮箱
- 使用独立浏览器 profile，避免复用教师端会话
- 若浏览器弹出“保存密码”“弱密码”“密码已泄露”等提示，先关闭或拒绝，避免遮挡输入框和按钮

## 学生端主流程

1. 登录后停留在课程入口页，等待教师提供课堂码。
2. 通过课堂码加入课堂，确认进入的是真实课堂页而不是入口页。
3. 首次进入时确认页面与教师当前页对齐。
4. 教师后续翻页后，优先验证“当前页面与教师不同步，点击跳转”提示是否出现；这是预期行为，不要误报。
5. 逐页完成学生动作：
   - 单选题：选择并提交，等待教师端查看统计或显示答案
   - 文本题：输入并提交，确认页面状态正常
   - 实践页：按设计填写任务一、任务二、反思、后测等内容
   - 知识卡片页：打开“知识卡片”抽屉，检查 `详情 / 概览` 切换
   - AI 页：确认 AI 助手在当前页面内弹窗，不跳到独立 AI 页面
6. 教师结束课堂后，确认学生端回到成绩概览或课程结束后的预期状态。

## 必报缺陷

- 课堂码加入失败，或落到错误路由
- 不同步提示缺失、提示可见但无法跳转
- 提交后页面报错、卡死或状态异常
- “知识卡片”按钮缺失、抽屉空白、`详情 / 概览` 不可切换
- AI 助手跳转到外部页面，而不是页内弹窗
- 教师显示答案后学生端没有同步看到正确答案

## 回报格式

- 只汇报：页面编号、通过/失败、学生动作、异常现象、必要截图
- 若阻断来自浏览器保存密码/弱密码弹窗，要明确标记为“浏览器弹窗阻断”
