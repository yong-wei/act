# 多媒体审查

代码直出图采用两段式：
1. `media/raw/*.py` 生成到 `media/processed/*`
2. `media/processed/*` 再导出到 runtime

核对顺序：
- 文件名与 `multimedia.md` 一致
- 图中公式、箭头方向、节点连线、标注语义正确
- 中文字体可显示，避免部署后乱码
- 图与 handout 的文字描述一致；若为实践课，还要与 `boppps.md` / `interactive-page.md` 中的使用场景一致
- 控制系统曲线、频域图、根轨迹等确定性图像，必须能回溯到 `python3` + `control` 脚本
- 线框图必须来自真实绘图流程，不接受 ASCII 图、截图拼贴或字符草图充当正式产物
- 逐张检查成图质量：字符正确、标注无遮挡、无错误截断、图例不拥挤、箭头不误指、边缘留白充分
- 目标不是“能看个大概”，而是“已经达到规范清晰、可直接进入讲义/页面的出版级配图”

不要跳过 `media/processed` 直接把 raw 导出到 runtime。
