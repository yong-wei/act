# BOPPPS 覆盖审查

对照正文或实践任务，逐项核查：
- Bridge-in 是否正确引出本课问题
- Objective 是否覆盖本课主任务与关键公式
- Pre-assessment 是否与本课前置知识匹配
- Participatory Learning 是否覆盖正文主线，且顺序一致
- Post-assessment 与 Summary 是否真正回收目标
- 各阶段中的事实、案例、工程结论是否与正文一致
- 各阶段中的因果解释与教学判断是否科学合理，而不是只“像是顺”

出现以下情况必须修正：
- 正文主例题或核心任务未进入 P2
- 阶段中的事实、公式、工程判断与正文不一致
- BOPPPS 说要练习梅森公式，但正文没有对应支撑内容
- BOPPPS 引用了外部事件、人物、案例却没有证据支撑
- BOPPPS 把条件性结论说成绝对规律
