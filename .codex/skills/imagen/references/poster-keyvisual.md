# Poster And Key Visual Reference

Use for posters, course covers, event visuals, hero images, campaign graphics, and strong first-screen assets.

## Prompt Structure

1. Define the central object or scene.
2. Define visual hierarchy: title area, focal object, secondary details, open space.
3. Define camera, lighting, material, and atmosphere.
4. Define exact visible text, if any.
5. Define output surface: web hero, print poster, slide cover, social image.

## Quality Rules

- Do not make a text-heavy flyer unless the user asks for one.
- The first visual signal should be the topic, object, place, or offer.
- Use a real or generated visual scene as the main carrier, not abstract gradients.
- Keep title text short and large; put any details in small secondary type.
- Avoid generic bokeh, orbs, stock-photo blur, or decorative filler.

## Prompt Skeleton

```text
Create a high-end [language] key visual for [topic/event/course].
Canvas: [ratio and target surface].
Focal scene: [central object/action/environment].
Composition: [foreground/midground/background, open title space].
Visible text: [exact text or none].
Style: [photoreal/cinematic/editorial/illustrative], [lighting], [palette], [materials].
Negative constraints: no extra text, no logos unless provided, no watermarks, no generic gradient background.
```
