## Why

教师班级页可查看多次持久化诊断报告，并对当前与上一份做有限的发现项比较，但报告正文没有稳定、可审计的数值指标合同，无法可靠展示班级学情随历次报告的变化（Issue #1963）。趋势若从自然语言摘要解析或页面打开时实时计算，则既不可复现也不可审计。

## What Changes

- 新增班级级「报告演变板块」：以教师主动生成的不可变报告快照为时间点（非自然日窗口），展示「本次相对上次关键差值 + 可切换单指标趋势图 + 最近 6 次快照明细」三层结构。
- 为新生成的班级诊断报告保存版本化、隐私安全的结构化指标快照：七维能力均值/置信度/纳入与缺失人数、作业与测评均值及分母、风险分布、薄弱知识点身份与覆盖人数、各指标可用性状态；缺失维度保留不可用态不补零。
- 指标由服务端在生成任务固定的 `evidenceCutoff` 内确定性计算并冻结，与报告在同一成功持久化边界写入；AI 只写诊断文字，不生成或修改指标。
- 可比性规则：相邻快照仅在报告范围、班级成员集合身份、证据覆盖口径、指标 schema 与计算版本一致时连成趋势；不一致时趋势断开并说明原因；旧报告无快照时显示「历史指标不可用」，不重算。
- 仅进入交互式教师页面；不进入教师交付版、打印页、学生安全版或 PDF。

## Capabilities

### New Capabilities

- `teacher-diagnosis-report-evolution`: 班级诊断报告指标快照的读取合同与演变板块（三层结构、可比性断连、旧报告降级、教师页面独占范围）。

### Modified Capabilities

- `teacher-diagnosis-generation-governance`: 班级报告生成成功持久化边界新增确定性指标快照冻结要求（schema 版本、计算版本、证据截止、成员集合身份、不补零、AI 不可写指标）。

### Removed Capabilities

（无）

## Impact

- 代码：`prisma/schema.prisma`（新指标快照模型 + 迁移）、`src/lib/diagnosis-persistence.ts`（同边界快照写入）、指标计算纯函数（新）、班级页历史 UI（`src/features/teacher/teacher-diagnosis-report-history.tsx` 及投影）、相关 API 路由。
- 数据：新表历史行为空（旧报告显示「历史指标不可用」），无回填、不重算旧报告。
- 验证：指标物化与确定性、不可变性、可比性断连、旧报告降级、授权（教师班级范围）、交互与打印范围回归测试；迁移与兼容读取验证。
- 非目标：学生级趋势、按日/周/月实时重算、趋势自动判断教学成效、从报告文字反推指标、学生画像目录与教师干预工作流。
