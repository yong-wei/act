# 实现微尺度水体光学与分级反射 — 设计

基线：`37a988f5928d73c2af7eabad57284a771c9d3519`。共同依据与上游来源：[研究报告](../../../docs/research/2026-09-17-marine-environment.md)。所有性能/误差数值为待验证目标。

## 技术先决条件

使用 `implement-bandlimited-marine-ocean` 的几何/采样与 `unify-marine-sky-lighting` 的共享辐射。

## 决策

水为非金属介质，Fresnel-Schlick 与 GGX 高光采用一致世界法线和视线。2–3 层微尺度斜率/法线按风向运动；纹理采样按距离和屏幕 footprint 过滤，必要时用法线方差补偿粗糙度。法线细节不参与船体运动。

深水默认 opaque、上表面单面；不以 alpha 近似吸收。浅水布局才申请颜色/深度资源，区分场景深度、水层厚度与作者态地形水深；用路径长度衰减，正确处理深度边缘、天空和自身反馈。

默认环境反射来自同源 PMREM。高档近景/较平缓水面可启用平均水面平面反射；半线性分辨率只减少像素，不保证减少顶点提交。使用对象白名单和船模简化 LOD，排除水自身、UI、教学线和大多数粒子；按运动误差刷新，浪大时降低该近似权重。SSR 非默认且不作为交付必需。

自然白浪来自压缩/Jacobian、海况阈值和纹理调制。仅中高档/支持格式时启用有界 ping-pong 累积，建议 20–30 Hz 起测；低档可用简化即时泡沫。泡沫受光且改变粗糙度，不是 additive 自发光。为下一项船体尾流提供同一泡沫/局部法线输入，不在本项实现船体发射规则。

所有额外 pass 按消费者和效果开关懒创建，未启用反射/浅水时不得持续渲染空目标。沿用当前 post 架构，一次输出变换；不默认加体积云、全屏 SSR 或折射通道。

## 验证

固定时钟捕获顺光/逆光/掠射/顶视及运动视频；验证远海无严重闪烁、泡沫无夜间发光、反射无递归和 UI 泄漏。开关逐项记录增量 CPU/GPU/RT 预算，不以空场 demo 帧率作依据。
