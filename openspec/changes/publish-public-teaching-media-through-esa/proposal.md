## Why

课程音视频、插图、PDF、教材插图和信息图目前由 OSS 直连或应用转发提供，相同公开教学内容缺少共享边缘缓存。用户已明确决定信息图无需用户登录鉴权，并授权配置阿里云分发、完成测试后直接切换。

## What Changes

- 从生产当前 Runtime 的不可变清单选取浏览器可读的教学媒体，并校验信息图审核、内容哈希和发布身份。
- 将公开媒体副本发布到 `act-course-models/teaching-media/sha256/<digest>/asset.<ext>`，复用已工作的 `static.adapt-learn.online`、私有 OSS 回源身份和证书。
- 扩展 ESA 专用读取策略及媒体缓存规则，仅覆盖新增公开媒体前缀；资源发布身份与 ESA 读取身份保持分离。
- 在完整发布及测试通过后，通过受控的分发索引使现有媒体入口重定向到 ESA；未发布的内容继续使用既有读取方式。
- 信息图媒体入口允许匿名读取，继续执行审核、版本引用及图谱/教学投影一致性校验；节点详情、知识图谱、用户及学习数据 API 保留既有权限。
- 保留固定课堂版本的媒体身份、原有读取回退，以及可以撤销 ESA 分发索引的恢复路径。

## Capabilities

### New Capabilities

- `public-teaching-media-delivery`: 公开媒体资格清单、不可变复制发布、ESA 分发索引、回退和生产验收。

### Modified Capabilities

- `private-runtime-media-delivery`: 经过完整公开分发验证的精确媒体对象可优先使用 ESA，其他对象保持短时 OSS 签名或既有本地回退。
- `authority-card-infograph-inspector`: 已审核且身份匹配的信息图图片可匿名读取，媒体用户鉴权与内容发布资格相互独立。

## Impact

影响课程媒体、讲义与教材资产读取入口、两类信息图媒体入口、公开媒体发布脚本、阿里云只读策略与 ESA 缓存、应用发布配置和运维说明。生产应用从本轮冻结的 `origin/main` 基线 `237d17bdb373d4929cf4523430cd2a7d5e2656bc` 实施并发布。

本次不激活或回滚课程 Runtime，不修改图谱、教学投影、资源绑定、课堂记录或数据库，不发布治理清单、检索索引、原始答案或学习数据，不修改其他产品的 ESA 记录，不替换云凭据。
