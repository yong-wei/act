## Context

开始捕获时生产应用为 `0.7.30`，代码基线为 `237d17bdb373d4929cf4523430cd2a7d5e2656bc`，Runtime 为 `runtime-b24b84a4ddea4d450ce813a87757298855c5476f26e9e79a782c752`。发布前再次核验，生产应用已更新至 `0.7.31`（`bf815b58b8196f2ca4c0769c2db3f071baa34056`），Runtime 身份不变。本轮应用以该新 main 修订为基线，分配 `0.7.32`，保持生产 cutover 模式与全部选择器。媒体 API 从活动或课堂固定清单中获取对象身份后签发 OSS 地址；讲义、教材插图和部分信息图由应用读取文件后返回。信息图的两个专用入口继承知识图谱登录检查。

阿里云控制台已核验 `static.adapt-learn.online` 使用私有 `act-course-models` OSS 回源与有效证书。其专用只读策略原为 `model-releases/*`，本轮已以完整多行 JSON 增加 `teaching-media/*`，保存为 v3。参见 proposal.md 的授权范围。

## Goals / Non-Goals

**Goals:** 将已允许浏览器读取的固定教学媒体通过 ESA 缓存提供；信息图图片无需登录；课堂固定版本、资源引用与内容哈希保持一致；未发布的新内容自动使用原读取路径。

**Non-Goals:** 不切换 Runtime、图谱或教学投影，不发布内部索引、治理文件、用户及学习数据；不修改模型与 OC 产品的分发身份或对象；不变更云凭据。

## Decisions

1. **复用已有浏览器分发 Bucket 和域名，增加独立前缀。** 使用 `act-course-models/teaching-media/sha256/<sha256>/asset.<ext>`，避免新增域名、证书和凭据。此 Bucket 只放批准公开的分发副本；`act-course-assets` 继续作为内部 Runtime 来源。
2. **以当前生产清单确定分母。** 捕获完整 v2 manifest、学习内容清单和既有信息图资源清单；候选限于课内音视频、图片、PDF、教材 assets 图片及已接受信息图。Authority 信息图的 available 状态和 SHA 必须与 v2 学习内容清单相符；孤立、缺失或摘要不符的条目不进入公开分发。
3. **OSS 服务端复制，采用不可覆盖对象键。** 发布器从捕获清单推导源 Blob 和目标键，设置正确 Content-Type、不可变缓存元数据和私有 ACL。复制前后核验对象大小与身份，完整集合验证通过后才产生终止索引；代表性每类对象从 ESA 全量下载核对 SHA。
4. **应用通过小型本地分发索引读取资格。** 索引位于现有只读宿主机状态挂载内 `public-teaching-media/current.json`，包含源 Runtime 身份、完整公开对象集合和验证完成状态。索引由受控发布操作原子写入；应用根据本地文件身份刷新缓存，缺失、损坏或不合格时使用原读取链路。索引不写进 OSS 公共目录，也不改 Runtime 指针。
5. **路径与摘要分别适配已有入口。** 普通 `/course-runtime` 路径只在索引 Runtime 身份与活动回执一致时重定向；媒体和课堂 Blob 入口以已验证的精确 SHA 查找已发布对象。不同课堂 release 和未发布的新摘要继续走既有固定版本读取，不能以同路径旧图代替新字节。
6. **仅移除信息图图片入口的登录检查。** 两个图片入口继续经过现有 Authority/Teaching、审核、摘要、locale 和版本引用校验；可用图片优先重定向至 ESA，未进入分发索引的已接受图片作为应用公开读取回退。知识图谱和节点详情 API 的会话/角色检查保持原实现。
7. **先验证再切换。** 云端发布完成后验证 HTTPS、MIME、Range、CORS、缓存命中及每类对象完整哈希；代码执行直接回归、相关测试、类型检查和 lint。发布新的应用版本后，最后启用经过验证的分发索引并验证真实页面、匿名信息图和固定课堂媒体。
8. **应用发布保持数据服务与选择器。** 现有 remote-deploy 的 app-only 事务仍含数据库导入与知识 seed，违反本轮不修改数据面的边界。采用现有 `--runtime-cutover-app-only` 容器替换路径，跳过数据库写入，直接装载本次已验证镜像；systemd 只更新配置而不再次重启整套服务。部署后核对数据库、Redis 容器身份及全部选择器。

## Risks / Trade-offs

- [发布或复制中断] → 内容哈希键与不可覆盖写入支持精确重试；终止索引生成前保持原生产读取。
- [缓存命中新版本错误] → 对象 URL 绑定 SHA；普通路径匹配活动 Runtime 身份；版本引用仍由既有资源合同校验。
- [公开了内部内容] → 路径、媒体类型及信息图发布资格共同限定集合；索引与 Runtime manifest 保留内部，不从扩展名推断任意对象可公开。
- [ESA 或对象不可用] → 保留原入口和索引停用开关；发布前完整 HEAD 与每类正文校验，页面端保留现有错误处理。
- [编辑器破坏换行] → 文件使用 apply_patch；控制台策略和 Cloud Shell 使用多行粘贴，并通过复制回读、JSON 解析和 Python 编译验证。

## Migration Plan

完成公开集合捕获与发布测试；保存云策略和缓存规则证据；验证并发布 `0.7.32` 应用；原子启用分发索引；核验媒体、教材和匿名信息图入口及浏览器行为。恢复时停用分发索引以回到原读取链路，保留不可变公开对象，不触碰生产 Runtime 与图谱选择器。批量发布由本机 CLI 环境调用官方 OSS SDK，Cloud Shell 只承担本机发布身份无权执行的有限 RAM 管理配置。
