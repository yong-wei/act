## Context

AI 工坊 `/ai` 已有受治理实验集合，但当前装配器只读取 `SimulationLog` 与 `ArenaSubmission`。控制工作台和场景追踪已通过 `/api/simulation/runs` 写入标准 `SimulationRun`/`SimulationTrace`，这些运行因此不会进入实验档案。奥德赛完成流程还会同时保留仿真日志与 Arena 提交，当前投影没有利用桥接身份去重；所有非伦理日志也被统一标为 PID 调参。实验条目本身没有导航字段，学生只能看到不可打开的历史卡片。

本变更必须保持当前学生隔离、预览/正式结果边界和 AI 工坊读取无副作用的约束，并与当前路径任务导航变更兼容。

## Goals / Non-Goals

**Goals:**

- 让当前学生已完成且具备展示资格的标准 `SimulationRun` 出现在实验档案中。
- 让仿真、奥德赛和 Arena 条目保留正确来源类型、结果权威性、稳定身份和可达导航。
- 合并同一学习活动的标准运行、兼容日志和 Arena 桥接记录，避免重复条目与重复总数。
- 保留对历史未桥接日志的兼容读取，并以安全摘要替代原始轨迹和载荷。

**Non-Goals:**

- 不新增或改写 `LearningFact`、个人画像、官方成绩、排行榜或普通奥德赛解锁。
- 不把预览运行升级为正式评测，也不通过时间或标题猜测来源身份。
- 不在本变更中重做仿真详情页面；只补足已有入口的稳定导航，必要时复用现有复盘页面。

## Decisions

### 1. Canonical-first source assembly

实验装配器先读取当前学生拥有且已完成的 `SimulationRun`，使用其 `runKind`、`sourceDomain`、任务规格快照和摘要生成学生安全条目。`SimulationTrace` 只用于读取已允许的摘要或复现入口，不把高频样本序列传给客户端。旧 `SimulationLog` 和 `ArenaSubmission` 作为兼容或来源专属补充读取，但不能覆盖标准运行的权威来源。

### 2. Resolve identity before projection

在生成条目前先解析跨来源活动身份：优先使用标准运行身份；对奥德赛使用已有的 `odysseyRunId`、`odysseySubmissionId` 或 Arena artifact 中的稳定桥接引用；未桥接的历史记录使用其自身持久化身份。去重不能依赖标题、分数或相邻时间窗口。无法证明属于同一活动的记录继续分开显示。

### 3. Source-specific navigation

条目必须包含与来源相匹配的导航目标：Arena 提交回到经授权的挑战详情，控制工作台或场景运行回到能恢复该实验上下文的工作台/仿真入口，奥德赛记录回到对应关卡或复盘入口。目标由服务端从已验证的任务、资源和发布上下文生成；没有可验证目标时显示受限状态并提供集合级恢复行动，不生成死链。

### 4. Derive type and authority from source contract

实验类型由标准运行的场景/运行类型或旧来源的明确控制模式决定，不能把所有非伦理记录默认标为 PID。正式性必须由来源合同决定；无效或未完成记录不得显示为正式分数。

### 5. Preserve bounded student-safe projection

扩展 `AiExperimentItem` 时只增加稳定身份、来源类型、结果权威性和导航所需字段；参数继续使用白名单，摘要继续限制长度和字段。所有查询都使用当前认证学生的服务端身份，并保持确定性排序、分页上限和无写入副作用。

## Risks / Trade-offs

- [Risk] 新旧来源对同一次活动的引用不完整。-> 只在已有稳定桥接引用成立时合并；不可证明关联的记录继续分开。
- [Risk] 旧记录缺少可恢复的详情上下文。-> 使用经过验证的来源入口或集合级恢复行动，不伪造带运行参数的深链。
- [Risk] 读取标准运行增加 `/ai` 查询负担。-> 并行读取、只选择必要字段、限制条目数量，并保留局部不可用状态。
- [Risk] 合并后历史总数变化。-> 总数按去重后的可展示活动计算，并在测试中固定同一活动只计一次。

## Migration Plan

1. 扩展实验条目契约与服务端来源投影，补充标准运行、来源类型和导航字段。
2. 实现跨来源身份解析与兼容记录去重，保留旧来源的回退路径。
3. 将实验档案卡片改为可访问导航元素，并校验来源和结果权威性文案。
4. 运行服务端单元、组件/路由测试、相关类型检查、OpenSpec strict validation 与 `git diff --check`。
5. 在稳定且干净的行为 checkpoint 捕获 `/ai` 1440px/320px 证据，并验证点击导航和无横向溢出。

回滚方式为代码回滚；本变更不要求数据库迁移或历史数据改写。

## Open Questions

无。若后续新增实验来源，必须先建立该来源的身份、权威性和导航合同，再加入集合白名单。
