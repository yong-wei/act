## Context

本轮分支 `codex/graph-path-redesign`，基线 `f455748e1d`。基线已包含 r6 工程图谱（#2058）、统一资源查看器（#2044）、路径节点运行时资源校验（#2055）及控灵图谱消费（#2047）。#2046 在独立工作树实施，#2059 的提案状态与实际发布数据需要再次核对。

浏览器基线使用本分支 `http://localhost:3002`、受管本地学生测试账号。1280×720 下领域入口与稳定性领域均偏向右侧，后者 35 个对象、3 条关系；3D 初始画面没有可读节点文字。截图保存在 `.tmp/graph-path-redesign/`，不包含认证状态。

## Goals / Non-Goals

目标：图谱名称、类型、关系方向与资源信息真实可读；2D/3D 均可浏览、聚焦、选择和返回；路径按已发布先后修约束排列实际绑定且可打开的资源。

非目标：重建全部上游知识内容、变更历史学习事实、增加第二套规划器、迁移数据库或执行生产发布。

## Decisions

1. 用户已明确授权重构渲染引擎。以真实可读性、交互稳定性和性能选择活动图谱的渲染方案；旧 Force Graph 的复用约束不再是本轮限制。优先复用可靠的几何与资源能力，若旧引擎耦合持续制造问题则替换活动渲染层。节点、标签、碰撞与 fit 必须使用一致的几何，尺寸变化后重新计算可用范围。
2. 领域入口使用克制的颜色、清楚的名称与轻量边界；取消占据大面积且不承载信息的高光装饰。知识节点突出类型和选择状态，资源标记作为辅助信息。
3. 连线以语义分组与明确方向呈现。仅有真实先后修边才表达学习顺序，不以排布位置或工程关联猜测先修关系。聚焦时突出相关子图，背景关系降低对比度。
4. 屏幕标签在 2D/3D 保持可读字号，采用有界碰撞选择；所选和悬停对象优先。缩放、旋转及调整窗口不应使全部标签消失。完整名称仍可从搜索、目录和详情获取。
5. 路径以 `planLearningPath` 为生产入口。候选必须拥有明确资源身份与可启动目标；教材容器可解析为可学习单元，不能用不存在的入口假装全资源覆盖。未具备资源的先修知识显式说明，不静默跳过。
6. 复用 #2046 已提交且可验证的实现，之后处理与本轮目标相关的缺口；#2059 的采用、发布和实际排序应一起验证，不能仅凭独立 planner 单测宣称生产路径生效。

## Accepted Rendering Decision

2026-09-08，独立 decision-advisor 选择活动图谱专用渲染层：复用现有 ForceGraph/Three 的底层交互能力，替换五千余行旧 wrapper 的布局、相机和标签状态。`ActiveAuthorityRuntimeView` 改接专用入口；共享 `KnowledgeGraphRuntimeCanvas` 及 legacy 路径不改职责。

共享模型负责节点身份、类型颜色、几何、标签内容与关系方向。2D/3D 使用围绕世界原点的确定性初始布局，并允许 3D 有限深度展开；相机只因初次进入、视口变化或显式 fit 更新。标签有数量上限并统一批次投影，hover 不得重新启动布局。清理组件时释放动画、事件和 Three 对象。

不选择继续逐点修补旧 wrapper；不自制命中、拖动、缩放和轨道控制。验收重点是全图 bounds、非空标签、跨维度身份、操作后的相机保持以及大域标签预算。

## Accepted Path Decision

2026-09-08，独立 decision-advisor 选择统一投影资源合同，区分可引用与可推荐。为全部已发布资源类型提供受控引用入口，入口绑定不透明 resourceId 和不可变 projection/snapshot 身份，服务端解析真实内容。已有课程、教材、仿真和 viewer 继续提供实际展示能力。容器及缺内容资源可显示元数据和限制，但不能冒充可执行学习单元。

推荐仅消费真实 canonical bindings，并要求学生可访问、存在可执行内容/后端。新增 `published-contract` 资格来源承载已发布工件的机器可验证事实，不能伪装为人工审核，也不生成没有依据的能力、掌握或证据数据。手工覆盖与教师裁决仍保留原审核语义。未绑定资源不猜测知识覆盖。

先修在资格过滤、当前请求排序之后解析：每个未满足的前驱 canonical 是一组可替代资源，从中选择一个合适代表；同一代表可覆盖多个前驱。结果写入请求级派生 registry，供 repair、assembly、解释共同消费。工程直接 prerequisite 保留来源，取消 #2059 原方案的教学层转写与指针切换。具体顺序验收以该 change 更新后的 tasks/spec 为准。

#2046 当前 WIP 的旧族 mapper 不足以覆盖新运行数据；其稳定成果按统一合同吸收，不整体复制未验证工作区。已有精确身份、混合资源策略与相关测试可以复用，逐族硬编码与全局可变 canonical 桥不进入最终设计。

实施细节：路径入口使用现有 `AdaptivePathJourneyControlFromRoute`、完成请求和返回上下文合同。普通阅读只能产生显式阅读/完成行为，不能声明测验得分或能力掌握；仿真、Arena 等仍由实际任务后端报告完成。教材参考条目缺少真实单元时只展示引用，不猜测页码。

旧 goal 的 aliases 若需连接 canonical，只采用已有知识卡 resourceId 与发布 bindings 等精确对应；禁止名称相似度或全局可变映射。先修解析从本次请求的目标 canonical 开始，不能因为一份资源同时覆盖许多其他概念，就把整个课程的依赖都加入该次路径。

候选合并按可证明的资源身份去重，不能按标题或 href 合并不同资源。已存在的资源节点和完成引用若有精确身份对应，应保持或记录该对应；历史路径不改写。绑定 ID 属于出处信息，不能混入 canonical 知识覆盖集合。

候选集合构建只读取已验证的发布索引和必要轻量内容，不为每次路径请求逐一读取、哈希上千张图片。对入选资源沿用 #2055 的运行时绑定/读取校验，在实际打开时再次校验内容。任何缓存都绑定具体 projection/snapshot 身份；当前指针变化后不能继续使用旧候选。

## Resource Features and Recommendation

2026-09-08 用户补充要求：资源摘要、类型、知识覆盖、难度与学生选择情况进入索引/特征库；规划结合画像、需求和现有三种路径导向，采用协同过滤或其他适合实际数据的算法。

- 静态特征以发布资源身份和 projection/snapshot 为键，包含有来源的摘要、原始资源族、canonical bindings、难度/认知负荷、时间估计、引用与执行资格。难度或时间没有来源时明确为未知或策略估计，不能伪装为实测值。
- 摘要在索引构建或资源版本变化时提取，规划读取索引，不再逐次读取卡片、教材全文或媒体字节。全文与内容哈希校验放在索引更新和实际资源打开阶段；生成期验证不得冒充新鲜全文读取。
- 学习行为特征来自真实选择、采用、完成或反馈记录。个人历史作为当前学生的私有覆盖层；群体统计按独立学习者计算、抑制小样本，不向客户端提供其他学生标识或原始记录。
- 复用现有三种路径导向及画像排序能力，为不同导向设置相应的内容相关性、难度、资源偏好、实践/验证与时间权重。历史稀疏时使用内容与规则排序；若使用协同过滤，必须有真实、足够的资源共选/交互样本，并保留来源与降级状态，不能把零数据当作热度。
- 图谱先修、权限、可执行性和预算是硬约束，协同或特征得分不能覆盖这些条件。最终选择和先修代表使用同一请求排序，避免后处理反转策略。
- 基础资源索引与变化更快的行为统计分开更新。索引版本变化必须使候选缓存失效；重复规划应复用对应索引。生产请求路径增加“未读取全文”的回归断言，并检查新发布或新选择后特征能更新。

原 #2055 的运行时身份和 manifest 校验继续复用；其每次生成读取对象正文的策略按本次用户要求改为索引/发布验证依据，实际打开仍做内容完整性校验。既有计划不得误标为已经执行了本次没有发生的读取。

用户进一步要求属性可随学生互动调整。保留作者/内容给出的基础属性，另存观测难度、时间估计等派生值及样本量、置信度、计算版本与证据水位。仅采用能与资源版本准确关联的有效作答、完成、用时、重试或反馈；点击/打开只是使用信号，计划选择也不能当作每个资源的作答结果。样本不足保留原估计，统计需能重算和回退，幂等重放不增加样本。画像用于判断个人适配度，不能把低基础群体的失败直接当作资源对所有人都更难。动态属性影响三种导向的排序，但不改写知识绑定、先修事实或教师硬约束。

资源内容版本与全局索引版本分别管理。当前候选和持久化必须匹配当前 index/projection/snapshot；互动统计按资源内容及绑定摘要版本归属。一次全局发布若没有改变该资源的内容和知识绑定，可以继续使用该资源的历史互动；内容或绑定变化则不继承旧样本，避免无关发布清空全库校准。结果型观察同时通过可信来源锚点与画像用途治理门禁，自报难度仅用于资源适配。

先修代表优先选择针对该前置概念的资源，再按本次请求的排序决胜；覆盖整门课程的步骤不能仅因同时命中最终目标而替代聚焦的前置资源。同一资源同时覆盖前驱和目标时仍继续追溯更早先修。目标已满足后的补充资源优先增加不同学习方式，避免用同类重复步骤填满预算。

音视频直接在统一资源页播放发布记录对应的文件，复用现有 runtime 媒体服务和发布版本参数，避免把某一媒体引用替换成课程总览。
