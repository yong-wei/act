## Why

Textbooks and reference resources are numerous and valuable, but they must enter the platform at the right grain. Sections can be path-plannable when reviewed; chunks, figures, captions, and search documents are usually citation or embedded support. Current audit output shows large long-form deficits, especially search-document rows and authoring-derived figure/caption resources.

This batch closes long-form textbook/reference semantics by reviewing sections, parent-child links, citation anchors, graph/K/A/Q fit, and path roles without promoting raw chunks into paths.

## What Changes

- Process remaining helper workqueues for textbook sections, reference sections, textbook/reference search documents, figures, captions, image descriptions, equations, tables, and related citation targets.
- Review section-level resources for path-planning eligibility and prerequisite position.
- Classify chunks, figures, captions, and search documents as supporting-citation, embedded-asset, parent-section evidence, or excluded-with-rationale unless independently reviewed as PlanningUnits.
- Preserve citation links that can jump to section anchors, figure anchors, or time/page anchors where available.

## Impact

- Improves RAG/Konling citation accuracy and path rationale support.
- Adds path-plannable long-form sections only where section-level review confirms instructional value and launch/citation targets.
- Does not process runtime lesson resources or assessment checkpoint items.
- Does not block Yang Fan fixture completion; fixture data should remain scoped to fixture-owned governed resources.
