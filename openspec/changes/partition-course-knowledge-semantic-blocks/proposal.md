## Why

Future governance children must own exact, non-overlapping review material. The dated prototype is evidence only and identity ownership can still move cross-block endpoints. Partitioning must consume frozen identity-component and domain-candidate manifests.

## What Changes

- Exclude course/module and navigation pollution, then assign every indivisible identity equivalence component to exactly one semantic owner block using identity semantics, normalized text, and relation connectivity.
- Target 40–80 equivalence components in a dedicated `candidate_concept_count`; pending split counts once and documented indivisibility/connectivity exceptions are allowed.
- Freeze exact item IDs, owner block, endpoint blocks, dependencies, and source digests for every block record.
- Prohibit splitting identity components and prohibit final concept, domain, relation, or resource decisions.

## Capabilities

### New Capabilities

- `knowledge-semantic-block-manifest`: defines exhaustive owner-shard assignment and exact digest-bound semantic block records.

### Modified Capabilities

- None.

## Impact

- Produces the ownership substrate for all cross-block review queues.
- Replaces no production graph and does not create future content-block OpenSpec changes.
## ADR 0045 Boundary

Migration exact items contain only reviewed active legacy mappings and current course/resource/progress/note or incomplete-path references. Historical facts, events, completed paths, and learner-derived state do not enter semantic blocks.
