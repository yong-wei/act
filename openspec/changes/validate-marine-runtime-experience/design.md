# 真实运行验收设计

## 已确认问题

MarinePerformanceEvidenceProbe使用document.querySelector('canvas')，与页面多图表可能冲突；其rAF探针不等于真实GPU耗时。代码gpuTimerAvailable恒false，仅检测扩展存在。delta>=1000ms被跳过，不能据此证明无严重前台卡顿。实际governor仍按旧整档策略，后台/预热保护只出现在探针中。

055 DestroyerModelScene在普通浏览器每帧执行Box3.setFromObject、屏幕包围盒测试和skinnedBindingsIntact；首先门控此类QA成本，并测量是否为CPU热点。资源台账不是实际泄漏测试。

## 实现与测量

复用R3F gl/canvas引用、已有探针与采集脚本；明确rAF间隔、实际render提交/完成、CPU耗时和GPUtimer各自口径。可用EXT_disjoint_timer_query_webgl2时异步轮询GPU时间并丢弃disjoint，不能gl.finish或同步读回；不可用就注明，不阻止其他实际测量。

前台严重长帧全部计数并保留时长，后台挂起单独排除；start重置时间基准。样本窗固定预热后60s，切换模型/镜头/档位时切分窗口，不能给混合负载贴一个最终状态标签。记录实际drawing buffer、DPR、设备/GPU、浏览器、活跃船包/LOD、镜头、海况、布局和开启pass。

实际governor需要预热/后台保护、冷却和可见作用的降级；优先减少附加pass、透明效果和像素负载，保持基础波面/姿态所有权/数值输出不变。每档开关必须减少真实工作量，不以degradation.ts描述数组代替消费接线。

QA观察只有显式开启时才遍历大模型；稳定骨骼结构和包围盒可在加载/LOD改变时缓存，不默认每帧完整扫描。测量材料/几何/纹理/RT及effect分配和释放，区分共享缓存与真实泄漏，避免把仍在用的共享资源释放掉。

## 实际交付

从当前基线即可开始，不等待所有补完。先完成055原镜头及邮轮/平台的真实运行；覆盖七路由和有效课程嵌入入口的冷启动、运行、暂停恢复、重置、相机、预设和质量切换。各新效果自身承担动态验收，本项负责集成路径和采集可靠性，不是最终“大门”取代各项责任。

桌面目标实际1920×1080/DPR1、60fps和p95约18.2ms；移动目标30fps并注明实际像素。目标不等于通过值。至少保留一台真实桌面GPU与一台真实移动设备的结果；声称普通集显达标时必须有对应设备，不能以高配开发机代替。尚无设备的矩阵项保留未完成/具体阻塞，不伪造。

十次预设切换、至少三轮路由进入退出，检查资源稳态；记录默认模式及各效果开关的真实增量。短视频包含波光、泡沫寿命、船水接触和不同船型数值运动。发现有界集成问题就在本项修复；跨其他补完范围的缺项明确归属，不重复建框架。
