## Context

路径执行已持久化检查点和偏离事实，但学生在检查点失败或跳过当前节点后只能重试或继续，无法查看基于这些事实形成的后续调整建议。现有规划器已经具备受治理资源、先修关系、学习缺口和路径可视化输入；本次不引入新规划策略或写模型。

## Goals / Non-Goals

**Goals:**

- 对可信检查点失败与路径偏离生成确定性的、仅面向未完成节点的候选纠偏方案。
- 使学生能查看触发原因、原路径与候选方案的节点差异、既有依据、预计影响和无法生成原因。
- 确保候选方案读取与展示不改写路径执行状态。

**Non-Goals:**

- 不持久化学生确认、拒绝或稍后处理的决策。
- 不自动替换当前路径，不引入并发写保护或效果回写。
- 不扩展通用规划器策略、Canonical 投影、学习事实迁移或教师诊断。

## Decisions

### 使用显式候选投影而非自动重规划

路径旅程从已持久化的检查点失败或偏离记录生成候选投影，并保持原始路径不变。自动应用会混淆“建议”和“已执行”的路径事实，且需要 P2 的持久化决策与并发边界。

备选方案是在偏离写入时直接重写路径；拒绝，因为学生无法审阅差异，也会损害已有路径和证据链。

### 只消费受治理的现有路径与资源事实

候选节点仅来自路径的未完成部分和当前可用、受治理的资源/先修关系。输入不足时返回学生可读的不可生成原因，不生成补救内容或不受治理资源。

备选方案是使用自由文本或临时资源填补空缺；拒绝，因为这不能形成可验证的个性化教学证据。

### 将候选展示接入失败与偏离后的下一步状态

旅程合同在存在候选方案时提供“查看纠偏方案”的动作，页面按同一合同渲染方案及差异。这样避免客户端从节点顺序或局部错误信息猜测是否可纠偏。

## Risks / Trade-offs

- [历史路径缺少可用执行事实] → 返回不可生成原因，不从缺失字段推断调整。
- [资源或先修信息不足] → 明确标记限制，保留原路径。
- [候选与原路径差异不明显] → 返回不可生成原因而非把同一路径包装为纠偏。
- [候选仅为读取时投影] → P2 前不展示“已确认”或“已应用”状态。
