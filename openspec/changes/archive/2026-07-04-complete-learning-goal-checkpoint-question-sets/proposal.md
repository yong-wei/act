## Why

The current K/A/Q foundation bank is a useful seed, but it is not enough to support complete adaptive paths for all path-ready LearningGoals. A path that contains only one or two assessment items, or uses generated/template items as if they were reviewed checkpoints, cannot give reliable readiness, remediation, or completion evidence.

The nine current path-ready LearningGoals need minimum reviewed item sets across precheck, practice, checkpoint, and remediation stages. These sets should reuse existing static and imported questions where they fit, rewrite or deprecate unsuitable items, and add new reviewed questions only where coverage is insufficient.

## What Changes

- Define minimum reviewed question-set requirements for every current path-ready LearningGoal.
- Build or register reviewed item sets for precheck, practice, checkpoint, readiness, and remediation stages.
- Require semantic review and path eligibility before items count toward minimum coverage.
- Emit a LearningGoal-by-stage assessment coverage matrix.
- Block high-confidence path generation or checkpoint claims when minimum coverage is incomplete.

## Impact

- Depends on the unified catalog and semantic review workflow.
- Extends assessment item catalog, LearningGoal package, and path planning contracts.
- Focuses on content and data completeness rather than engine switchover.
