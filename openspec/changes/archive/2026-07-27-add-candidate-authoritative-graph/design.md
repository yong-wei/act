## Context

旧画布 DTO 把所有对象压缩为 `THEORY` 并仅支持三类关系。候选图谱需要表达 ActKG 原始类型和谓词，但迁移期仍需让用户显式查看旧图。

## Goals / Non-Goals

**Goals:**

- 提供独立 V2 API 和异质候选图谱体验。
- 让所有既有图谱用户默认查看首个局部 Release。
- 清晰表达覆盖范围、治理等级和角色化详情。

**Non-Goals:**

- 不混合新旧节点，不补齐候选缺口。
- 不让页面版本选择改变生产权威。
- 不迁移控灵或其他消费者。

## Decisions

1. 前端切换直接选择旧 API 或 V2 API，两个响应不能在客户端转换、并集或 fallback；候选 UI/API 完成后保持公开激活门禁关闭，直到候选控灵验收通过。
2. 一级导航按 `canonical_type`；当前类型使用中文词表，未知合法类型显示上游原文和通用样式。
3. 类型中心视图保留中心类型的一跳异质对象，以弱视觉保持跨类型关系。
4. 谓词按原始 relation type 映射中文名称、方向、线型和说明，不建立旧三类关系或推测语义族。当前登记固定为：`association`“关联”、`represented_by`“表示为”、`applies_to`“适用于”、`derived_from`“推导自”、`used_to_analyze`“用于分析”、`is_a`“属于”。
5. Gold 显示“核心”，Silver 显示“扩展”；默认扩展视图包含两者，核心视图只含 Gold。
6. 详情按学生、教师、管理员分层；管理员审计字段不向普通用户暴露。

## Risks / Trade-offs

- [局部 Release 被误解为完整课程] → 页面常显 Release 名称、覆盖说明和教学语义状态。
- [未知类型视觉有限] → 通用只读样式保证不丢数据，专属适配在真实类型出现后补充。
- [迁移期双入口认知成本] → 明确标记“新版候选/旧版”，不提供自动跨图跳转。

## Migration Plan

先对 V2 API 做合同测试，再完成受激活门禁保护的候选画布、详情和切换。本变更保持普通用户候选入口关闭；候选控灵完成只读验收后由下一变更公开并设为默认。
