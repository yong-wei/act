## Why

The unified UI series will touch shell, navigation, route metadata, visual tokens, floating dock, and representative routes across student, teacher, admin, and report surfaces. Without local governance gates, the project can appear visually migrated while still retaining page-local navigation, unowned legacy shells, missing mobile evidence, stale screenshot metadata, or new React Doctor error-level findings.

## What Changes

- Harden local commercial UI governance for canonical archetype route ledger coverage and owning-change metadata.
- Enforce legacy shell retirement or temporary exception metadata.
- Require structured visual evidence for representative routes, themes, viewports, navigation states, dock behavior, and first-viewport task visibility.
- Keep validation local only; do not add GitHub Actions due current quota constraints.
- Include React Doctor error-only local checks as a quality gate for migrated UI surfaces.
