## Design

Long-form resources should enter planning at the right grain:

- book/container resources provide provenance and authority;
- chapters and sections can become PlanningUnits if reviewed;
- paragraphs, figures, equations, tables, descriptions, transcripts, and time segments normally remain supporting citations or embedded assets;
- selected exercises inside references or textbooks may become checkpoint/practice resources if reviewed as assessment items.

## Semantic Review

For every helper-discovered long-form resource in scope, agents must classify the resource and then manually determine required fields at the right grain:

- graph nodes covered;
- LearningGoal fit;
- prerequisite position;
- cognitive load and estimated time;
- suitable path stage;
- whether the section is primary instruction, enrichment, remediation, reference, or checkpoint support;
- citation target and deep-link behavior;
- source hash/version and review state.

## Planner Consumption

The planner should be able to select reviewed textbook/reference sections as learning resources, while still using lower-level chunks for rationale, explanation, and Konling citations.

## Acceptance Shape

The helper should show that all in-scope long-form resources are accounted for as path-plannable sections/exercises, supporting citations, embedded assets, evidence-producing items, or excluded resources with rationale. The before/after evidence must include denominator counts by source family and grain, unaccounted counts, invalid promotion counts, unreviewed semantic counts, and remaining blocker counts.
