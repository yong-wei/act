# 实现带限多尺度海面与稳定近场采样 — 设计

基线：`37a988f5928d73c2af7eabad57284a771c9d3519`。共同依据与上游来源：[研究报告](../../../docs/research/2026-09-17-marine-environment.md)。所有性能/误差数值为待验证目标。

## 技术先决条件

使用统一运行契约 `unify-marine-scene-runtime` 的帧输入与原点定义；此处是设计先决条件，不是 GitHub 已登记依赖状态。

## 决策

用有种子的 4–8 个尺度合理的基础低频分量作为起点，所有档位保持相同基础波参数。世界坐标相位与浮动原点正确换算，禁止波形随船平移。

围绕船体交互区域维持误差受控的精细曲面，外围按距离/投影大小降低细分。可采用 clipmap 环带；自由相机远离船时，保留船体接触域的覆盖。总体网格受预算控制，不把整个 60 km 平面升到 1024²。

每级按网格间距衰减不能表达的频带，LOD 边界同时过渡位移和法线，处理 T-junction、裂缝和闪烁。约 8 个间隔/最短几何波长仅作初始设计值，最后按振幅/曲率的实际误差裁决。

Gerstner 完整参数曲面偏导叉积用于法线；水平位移的反解必须与 CPU 查询一致。船体展示性响应采用质量不变的基础采样，精细交互网格负责逼近它；贴水线等需要可见曲面高度时，共享服务提供相应结果。近场建议 0.05 m 误差目标，不要求整条远海无限范围都用该密度。

微法线在下一项光学中完善，本项提供明确频段和采样接口。CPU 采样预分配、批量执行，不在每个点新建 Map 或 Vector3。几何/材质寿命与 React 重渲染解耦。

## 验证

使用独立数学参照和实际 GPU 顶点/离屏采样，覆盖水平位移、非顶点点位、原点移动、LOD 接缝、自由相机和海况范围；不能只比较两份调用同一 helper 的代码。
