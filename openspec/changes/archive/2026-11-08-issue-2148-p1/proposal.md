# Proposal: issue-2148-p1 — 学生辨识/预测验证/科学评价内核（阶段 A）

- Issue: #2148（P1，父项 #2146；物理 #2153 ✅、运行 #2147 核心链 ✅、教学合同 #2149 阶段 A ✅）
- 类型: 学生模型与评价计算内核（多阶段；本 change 覆盖阶段 A——Rust 内核 + 核心算法）

## Why

七船新任务需要统一的辨识、预测验证与评价能力——学生从真实物理仿真建立局部模型，经过独立验证后用于控制设计与对照。这需要一套与 TruthPlant 并行但不驱动它的 StudentModel 计算内核。

## What Changes（阶段 A）

1. **`sixdof/student_model.rs`**：学生模型工件结构（模型族/结构/系数/工作点/训练runIDs/验证runIDs/版本hash）+ 三种比较模式：
   - A·船体模型验证（同一执行器输入，物理回放 vs 学生独立预测）
   - B·命令到输出验证（真值含执行器，学生侧串联辨识执行器）
   - C·独立闭环对照（同参考同参数，两侧各自闭环）
2. **辨识算法**：
   - Nomoto 一阶/二阶（输出误差最小二乘，多初值有界优化）
   - FOPDT 航速（K·exp(-Ls)/(Ts+1)，ZOH 离散化）
   - 二阶横摇振子（含执行器通道）
3. **评价指标**（§4 固定定义）：
   - RMSE / FIT（可负、分母近零→不适用）
   - 阶跃超调（相对 Δy=yref−y0，支持负阶跃）
   - 调节时间（从参考事件计、最短保持窗、不足→不收敛）
   - 残差均值/RMS/与输入相关性
4. **角度处理**：正确 unwrap/wrap（179° vs −179° = 2° 而非 358°）

## Impact

- 新增 `rust/control-engine/src/sixdof/student_model.rs` + 测试。
- 纯 Rust 内核（WASM 可调），不接线前端（随 #2152 证据报告接入）。

## Non-Goals

- 不实现前端 UI（比较页面布局）
- 不实现 DP 3×3 / 挖泥横移辨识（阶段 B）
- 不修改评分语义（#2149 教学合同已定）
- 不替代 TruthPlant（StudentModel 仅预测，不驱动 3D/物理）
