## Context

前三项变更分别提供 v2 教材结构、文件型混合检索和统一阅读器。本变更是系列唯一的生产切换点。当前 Source Pack 会在每次上下文构建时读取全部教材 search-document，并只把候选标题和引用摘要放入提示词；控灵可见正文仍可能包含内部 citation ID，旧阅读链接则绑定物理 chunk/section 文件。

现有平台已经具备服务器页面上下文、页面工具合同、AgentToolRun、CitationAddress、CitationChip、共享控灵渲染和开发/生产诊断隔离。本变更扩展这些边界，不建立第二套聊天、权限或引用系统。

## Goals / Non-Goals

**Goals:**

- 将教材 RAG 作为共享只读工具按页面合同暴露，并复用各页面既有上下文。
- 把召回正文和精确结构单元交给回答模型，同时保持引用身份由服务器控制。
- 统一教材内容和学习证据的可见编号、验证、失败提示和导航。
- 在不阻塞首轮流式体验的前提下允许外部检索后台补强并刷新同一消息。
- 一次性删除旧教材运行态格式、读取器和过渡产物。

**Non-Goals:**

- 不新增知识图谱选中节点专用查询逻辑。
- 不要求每条控灵消息都检索教材。
- 不回填历史消息、旧教材 URL 或旧引用映射。
- 不在生产服务器生成教材索引。
- 不接入视觉图片索引。

## Decisions

### 教材检索是共享只读工具

工具注册表增加只读教材检索能力。需要课程知识支撑的页面合同可以暴露该工具，工具集在一轮开始后保持不变；模型依据用户问题和已注入的页面上下文决定是否调用。工具输入不能扩大服务器权限或携带学习者私有数据到外部嵌入/重排服务。

### Source Pack 只交接少量正文

工具调用混合检索后，把窗口拆回 owning units，按结构单元去重，并执行可见性、直接支撑和来源优先级裁决。模型收到少量窗口正文、所属结构单元、引用编号和限制状态；全量索引与教材不进入提示词。

直接、完整支撑是首要门槛。合格来源中依次优先胡寿松第八版、刘胜版和英文教材；第七版、习题解析和控制百科只在约定用途内补充。现有图谱绑定、名称、说明和关系只作为候选扩展或排序信号，不能替代正文支持。

### 引用表由服务器预分配

服务器在回答生成前对教材内容和学习证据去重并分配统一 `[1]`、`[2]` 序列。提示词只提供这些编号及其正文/证据摘要，模型不能创建 URL 或新编号。最终显示链接由 CitationAddress 和统一阅读器路由生成。

### 引用修复只有一次映射调用

首轮后先接受已知编号、完整已知 ID 和唯一标题匹配三类确定性规范化。剩余未知标记连同原问题、冻结的服务器上下文、已分配引用表和原回答传给一次修复调用；修复只返回映射，不重写正文或引入新来源。仍失败的标记和链接从生产正文删除，引用区显示安全核验状态。

### 软超时保持同一消息

外部向量与重排合计约 2 秒仍未完成时，工具返回词面/本地融合候选和 `optimizationPending`，控灵开始正常流式回答，UI 显示“正在后台优化响应”。原请求的数据流保持到实验 P95 上限，等待外部结果。

后台结果以结构单元标识与首轮实际证据集合确定性比较。首选来源或已用引用集合变化时，用冻结问题和最终证据重新生成消息修订，并通过同一消息 replacement 事件替换正文、引用和最终状态；结果等价时只结束进行中状态。

### 最终切换采用停服部署

本地对七套来源执行全量导出、结构检查、检索基准、引用和阅读器端到端验证。生产切换时停止应用，同步新版 runtime 和索引，部署匹配应用后执行冒烟验证。失败时保持停服，现场修复并重新本地验证后继续上线，不恢复旧格式。

## Risks / Trade-offs

- [模型未调用教材工具] → 页面合同只决定可用性，真实概念问答加入工具调用回归；不以无条件预检索掩盖模型行为。
- [后台等待使流连接变长] → 上限取实测 P95；断开时保留已完成的基础回答，不创建孤立第二条消息。
- [二次生成造成内容跳动] → 只有实际使用的证据集合或首选来源改变才替换，等价结果只清除状态。
- [引用修复仍失败] → 删除内部标记和无效链接，保留正文并显示“部分引用未能核验”或“引用未能核验”。
- [破坏性运行态切换失败] → 上线前全量本地验收；生产保持停服修复，不引入长期双格式回退。

## Migration Plan

1. 在集成环境消费 v2 runtime、混合索引和统一阅读器。
2. 迁移 Source Pack 适配器、CitationAddress 和全部教材消费者。
3. 完成教材工具、引用编号、修复、软超时和消息修订测试。
4. 删除旧 `sections/chunks/search-documents/citation-map` 读取器、测试夹具和过渡产物。
5. 对七套来源执行全量本地验收与应用构建。
6. 短暂停服同步 runtime 和应用，启动后验证已知失败问题、引用跳转和普通非教材问答。
