## Context

第一阶段已把候选路径的聚合推荐依据持久化，第二阶段把该依据投影为活动节点的历史选择说明。现有学习者状态服务同时保留目标作用域筛选后的 `LearningFact`、官方 Arena 结果和目标级 `supportingEvidenceRefs`，但路径规划合同只消费分数、置信度和数量，因此 UI 无法展示可核验的事件。证据时间线已经定义了学生可见的来源分类和回跳策略，第三阶段应复用该语义，而不是建立另一套学习记录。

本变更涉及学习者状态、规划器、路径持久化和 UI。事件引用必须由服务端生成，且只能来自已证明参与目标能力判断的受治理记录。

## Goals / Non-Goals

**Goals:**

- 为每个能力判断生成有限数量、无内部标识的学生安全事件引用。
- 让候选路径和活动节点说明事件如何影响判断及资源选择。
- 复用证据时间线的来源分类和安全回跳规则。
- 在证据不足、冷启动、旧数据或无法建立事件关联时明确 fail closed。
- 保证事件引用随候选路径和已选节点持久化，不受后续执行状态改变影响。

**Non-Goals:**

- 不改变路径评分、资源排序、候选路径数量或节点执行状态机。
- 不新建学习记录查询、时间线页面、Prisma 模型或数据回填。
- 不展示原始答案、原始对话、内部数据库 ID、sourceLogId、sourceEventId、reason code、fingerprint、原始 evidence JSON 或模型提示词。
- 不为聚合快照、特征缓存或无法关联到具体事件的依据伪造历史事件。

## Decisions

### 在学习者状态的目标切片中生成安全事件投影

服务端在构建控制校正目标切片时，将目标能力已经采用的 `supportingEvidenceRefs` 与同一批目标作用域记录关联。只有能够匹配到具体 `LearningFact` 或合格官方 Arena 提交的引用才生成学生投影。每条投影只保留稳定来源枚举、发生时间、学生摘要和安全入口。

选择该位置是因为它同时掌握目标作用域、证据使用关系和角色权限。若在 UI 查询最近时间线，会把未参与规划的记录误标为依据；若在规划器中重新查询数据库，会破坏规划器的纯函数边界。

### 抽取并复用证据时间线的学生来源投影

证据时间线导出一个最小、纯函数式的学生记录投影入口，统一来源分类与回跳规则。学习者状态服务仅补充“该记录影响哪个能力目标”的上下文，不复制路由判断。

替代方案是在路径模块中维护独立映射。该方案会使 Arena 正式/预览、工作台和自适应练习的入口规则逐渐分叉，因此不采用。

### 事件引用随 deficit 和 provenance 流动

能力目标的安全事件投影进入规划器的目标级证据合同；`inferDeficits` 将相关引用附到 deficit，`buildAdaptivePathRecommendationProvenance` 再按候选路径覆盖的目标写入 entry。低置信度判断不把事件宣称为具体资源选择依据，但可展示这些事件仅用于说明证据局限。

每个目标最多保留三条、按发生时间倒序去重，避免持久化载荷和 UI 过载。候选路径被采纳后，第二阶段既有 `selectionBasis` 投影会携带同一组安全引用，因此不需要再次查询当前画像。

### 缺少可核验引用时明确降级

聚合画像、特征缓存、受限 AI 证据或无法匹配记录 ID 的引用不生成事件卡片。推荐依据增加“尚无可核验的事件级记录”限制；UI 保留查看完整学习记录入口，但不暗示该页面所有记录都参与了当前推荐。

## Risks / Trade-offs

- [历史数据只有聚合快照，无法恢复事件] → 保留聚合解释并显示事件级证据缺失，不反推或伪造。
- [同一事件支持多个能力目标，造成重复] → 在每个目标内去重并限制三条；跨目标重复保留，因为其影响关系不同。
- [来源分类与现有时间线发生偏差] → 复用同一纯函数投影入口，并为来源与链接增加单元测试。
- [旧候选路径缺少新字段] → 所有读取合同保持可选字段，旧数据继续展示现有聚合解释。
- [事件摘要暴露敏感内容] → 摘要由来源枚举和结果状态模板生成，不读取答案、对话或原始 payload。

## Migration Plan

该变更仅扩展 JSON 合同，无数据库迁移。部署后新生成路径包含事件引用，旧路径继续走兼容降级。回滚时旧代码会忽略新增 JSON 字段。

## Open Questions

无。事件来源范围、上限、隐私字段和降级语义均由本变更固定。
