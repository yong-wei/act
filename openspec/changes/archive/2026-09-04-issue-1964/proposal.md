# 提案：增强班级学生学情检索并连接诊断报告入口

## Why

教师班级页的"班级学生"表已展示累计画像等级、达成指数、证据状态、风险、趋势与证据截止时间，但缺少按姓名/学号的查找与按风险、趋势、证据缺失、画像可用性的筛选；学情诊断报告区域也没有定位到当前学生学情的入口，教师在报告快照与当前累计画像之间没有明确的查看路径。

## What Changes

- 现有"班级学生"表增加姓名/学号搜索、风险状态筛选、最后趋势筛选、证据缺失筛选、画像不可用筛选，全部支持组合使用，并提供一键清除与命中人数。
- 学生表默认按学号或姓名稳定排序，不默认按风险或综合分排序，不建立隐含学生排名。
- 搜索或筛选无命中时显示明确的空状态（与"班级暂无学生"区分）。
- 学情诊断报告历史区域新增"查看当前学生学情"入口，锚点定位到现有学生表，不复制名单、不触发第二次逐生画像读取。
- 学生表明确标注数据口径为"当前累计画像"，与历史诊断报告快照相区分，并继续显示各学生证据截止时间。
- 学生详情继续复用既有授权路由；不新增第二套学生表、画像详情页或逐生数据请求。

## Capabilities

### New Capabilities

- `teacher-class-student-roster`: 教师班级页现有班级学生表的检索、组合筛选、稳定排序、命中反馈与空状态契约，以及诊断报告区域到该表的定位入口。

### Modified Capabilities

（无——既有 `teacher-evidence-governance` 与 `role-based-learning-diagnosis` 的需求不变，本变更只消费其既有批量投影。）

## Impact

- `src/app/teacher/classes/[classId]/page.tsx`：学生表区域新增筛选状态、派生过滤排序与筛选 UI；学生表标题区新增数据口径标注。
- `src/features/teacher/teacher-diagnosis-report-history.tsx`：header 新增可选"查看当前学生学情"入口 prop。
- 新增 `src/features/teacher/class-student-roster.tsx`（或同目录纯函数模块）：过滤、排序、命中计数纯逻辑，供页面复用与单测。
- 新增回归测试：搜索、组合筛选、稳定排序、空状态、报告区域入口定位、移动端表格/卡片 `data-label` 保留、详情链接仍走既有授权路由。
- 不改动教师交付版、打印页、学生安全版与 PDF 链路；不改动授权 API 与数据模型。
