# Proposal: issue-2151-p2 — 完善图形能力失败处理，并让任务、曲线和提交便于对照

- Issue: #2151（P2，系列总览 #2146）
- 类型: 学生体验与失败路径治理

## Why

现网在部分客户端（含云端 Chrome）出现海面场景图形初始化失败（`Cannot read properties of null (reading 'getSupportedExtensions')`）：界面保留开始按钮与教学面板、原始异常直接透出、缺少恢复路径；开始按钮与真实引擎状态脱节（按钮显示运行而仿真时间为 0）。同时多面板独立滚动使任务、曲线、提交难以并读，部分控件可访问名称（"参数一/参数二"）与内部标识（`ai_data`、`engineering-target`）对学生不可理解。

## What Changes

1. **运行前置能力三态报告**：进入实验前区分"模型准备（WASM）—图形准备（渲染器）—可以运行"，页面出现不再等同引擎就绪。
2. **图形失败的学生可理解路径**：失败原因分类（环境不支持/设备丢失/初始化缺陷）、支持环境说明、可操作恢复建议；原始异常收进诊断折叠，不再作为唯一提示。
3. **运行状态一致性**：开始/暂停按钮、仿真时钟、采样计数、提交校验与真实引擎状态同源；引擎未就绪不能开始；零采样不得被认作成功运行；失败恢复后只产生新运行。
4. **失败保留进度**：图形失败或上下文丢失不清空已完成步骤与草稿。
5. **图形不可用时的明确边界**：本版不把数值循环从三维场景中解耦（该解耦属 #2147 运行接通范围）；图形不可用时明确停止、保留进度并提示更换支持环境，不新增第二套物理内核或二维降级内核。
6. **布局与可读性**：失败提示不遮挡关键按钮；当前任务目标、可操作变量、关键曲线、提交区域在 1366×768 常见视口可稳定定位；修正"参数一/参数二"类可访问名称与单位不一致（节 vs m/s）；学生视图隐藏调用账本字段与工程任务标识（移入教师/诊断信息）。

## Impact

- 代码：`src/resources/simulations/scene/marine-canvas.tsx`（失败 UI/三态）、新增 `simulation-capability` 模块（WASM+图形探测）、七船共享面板与开始门控、抽查控件命名与单位文案。
- 不影响：数值内核（Rust/WASM）、七船任务定义、评分与回传协议。
- 风险：能力探测误报（以真实上下文创建探测 + 显式 `?graphics=` 覆盖保留）；布局微调回归（限共享面板最小面）。

## Non-Goals

- 不做数值仿真与三维渲染的运行解耦（#2147 范围）。
- 不新增三维美术资产、不全面重做 UI。
- 不宣称修复移动端问题（未验证）；不把云端环境现象写成全站故障。
- 不对生产施加并发负载测试。
