## Why

The pilot can establish that a manifest course no longer needs a private classroom authority, but the remaining runtime-first catalog still contains title-to-private-route bridges, aliases, and legacy renderer consumers. Keeping those paths as permanent redirects preserves two session identities and two rendering contracts, making drift inevitable.

## What Changes

- Freeze a denominator and qualified pilot receipt, then migrate the remaining eligible title/route bridge callers to canonical identity, shared classroom session use cases, bundle binding, and registered manifest plugins in batches.
- Delete each retired private course route after its callers and browser entries reach zero; retired paths return the repository's explicit not-found behavior and are not kept as permanent redirects.
- Remove obsolete title-to-route aliases and old renderer calls only when the canonical identity registry and plugin/resource contracts prove they are no longer needed.
- Keep canonical identity aliases that are still required for bounded ingress as explicitly classified migration inputs; they must not resolve classroom identity by mutable plan title.
- Retain the lowercase lesson-engine `resource-renderer` as the current mainline. Remove uppercase `ResourceRenderer.tsx` only after a consumer inventory proves zero remaining consumers and the legacy renderer retirement gate passes.

## Capabilities

### New Capabilities

- `private-course-session-route-retirement`: Defines denominator-closed route/alias/renderer retirement, batch gates, no-redirect behavior, and final private-bridge zero conditions.

### Modified Capabilities

None. `legacy-interactive-lesson-retirement`, `interactive-lesson-identity-resolution`, `interactive-course-standard-module-migration`, `course-data-quality-gates`, and resource-renderer contracts remain authoritative.

## Impact

- Denominator: every runtime-first course family and private entry/student/teacher/waiting route, title alias, route bridge, direct `/api/session` producer, old manifest renderer call, and uppercase `ResourceRenderer` consumer. The baseline observation is 32 runtime-first families and approximately 96 private route surfaces; the exact list, aliases, and consumers must be frozen before the first batch.
- Depends on the qualified `migrate-one-manifest-course-to-shared-classroom-shell` pilot and its browser/behavior receipt, plus the upstream bundle, application-service, live/evidence, and plugin contracts transitively.
- Affected route inventory/tests, `src/lib/interactive-lesson-identity.ts`, manifest runtime registries, shared classroom shell callers, and `src/features/lesson-engine/{resource-renderer.tsx,ResourceRenderer.tsx}`. It does not change unrelated UI selection/style work.

## Scope and Evidence

- **Characterization:** reconcile route filesystem entries, route aliases, identity registry aliases, plan-title fallbacks, session producers, manifest switch/import consumers, and renderer consumers against browser-visible links and tests.
- **Migration and deletion:** process only qualified batches; migrate callers, run zero-consumer and browser gates, delete the old route/bridge in the same change, and record a recoverable removal receipt. No permanent redirect and no deletion of uppercase renderer before consumer zero.
- **Verification:** run route/identity drift and no-redirect tests, private-producer inventory, manifest/module gates, renderer consumer scan, affected browser journeys, domain tests, typecheck/lint, and strict OpenSpec validation after every batch and at final zero.
- **Browser acceptance:** canonical course links load for teacher/student, retired private links are not exposed or redirected, title changes do not change identity, refresh/reconnect preserves the session, and optional media/knowledge-card failures remain soft.
- **Ledger:** retain a batch ledger with denominator, pilot qualification, owner, old path, replacement, consumer count, deletion condition, browser evidence, and removal receipt. This proposal does not claim completion, deployment, or production activation.
