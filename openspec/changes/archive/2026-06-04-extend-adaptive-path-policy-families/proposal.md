## Why

The future control-correction baseline will persist path rounds and connect execution to evidence, but the teaching-assistant report requires students to see multiple distinct path styles. If all paths are produced by one scoring policy, the UI may show three routes that are only minor reorderings.

## What Changes

- Extend adaptive path planning with registered policy families for foundation remediation, simulation-driven learning, sprint correction, and teacher-assigned variants.
- Require path diversity metrics and overlap thresholds when multiple alternatives are shown together.
- Preserve existing control-correction path behavior as one compatible policy family.

## Capabilities

### Modified Capabilities

- `adaptive-learning-path-planning`

## Impact

- Builds on future ResourceNode seed graphs and persisted path rounds.
- Supports whole-course teaching assistant paths after goal-slice registration.
- Does not create new ResourceNode content or student UI surfaces by itself.
