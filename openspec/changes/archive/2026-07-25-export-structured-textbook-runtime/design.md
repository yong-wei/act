## Context

教材作者态由 Mathpix 转换后的章节 Markdown 和本地图片组成。当前导出器只识别主要标题，随后按字符长度生成 section/chunk/search-document；这种结构适合粗粒度检索，却不能稳定表示教材中的多级编号、公式、插图和表格，也无法同时满足重叠检索与精确引用。

本变更只生成未接入生产的 v2 测试运行态。生产消费者和旧格式删除由系列最终集成变更负责。

## Goals / Non-Goals

**Goals:**

- 从七套作者态来源确定性生成可寻址的最小结构单元和片段锚点。
- 将权威引用单元与可重叠检索窗口分离。
- 对结构异常执行自动检测、模型分散审核、人工归因和可重复再导出。
- 使正文或标题小改动不会无故改变已有自然编号单元的稳定路径。

**Non-Goals:**

- 不让模型生成正式层级或正文。
- 不建立旧 section/chunk 到新单元的映射。
- 不在本变更中切换生产读取器、控灵或引用路由。
- 不修改知识图谱节点或历史学习事实。

## Decisions

### 作者态保持章节 Markdown

作者态继续以现有章节文件为真源，不为运行态路由物理拆分。只有异常审核确认源文件编号、标题或边界缺损时才修改作者态，并保留普通代码审查可见的差异。

### 通用解析规则加每本教材声明式配置

解析器先应用 Markdown 标题、中文数字编号、阿拉伯数字编号、括号编号和教材常见公式/图表编号规则，再由每本教材配置声明例外、跳级许可和不可拆分区域。无法唯一确定父子关系时导出失败，不用猜测结果继续运行。

### 结构标识来自版本与路径

有自然编号的单元使用规范化编号；无编号单元使用父级内确定性序号。标识包含 `bookId`、版本和父子路径，不直接使用标题文本或正文哈希。公式、插图和表格使用所属单元内的自然编号或确定性序号作为片段锚点。

### 检索窗口引用结构单元

每个结构单元正文只存储一次。检索窗口可组合当前单元、必要祖先标题和相邻内容，并为窗口中的每段内容保留 owning unit id。窗口不拥有独立引用地址，父级也不复制全部后代正文。

### 校订采用异常驱动闭环

先导出，再检测空单元、极端长度、编号跳跃、层级突变、正文挂错和未识别自然编号。每章抽查最深层单元、边界、编号序列以及最大/最小单元。模型只报告疑点；确认源缺损时修作者态，确认规则缺口时修解析器并重新导出。

## Risks / Trade-offs

- [无编号单元前插会改变后续确定性序号] → 教材变化很少；结构调整时由引用与路由测试明确暴露变化，不维护永久映射表。
- [教材编号风格不一致] → 通过每本教材配置和失败关闭处理，不把例外写成全局猜测。
- [临时 v2 产物与旧生产运行态并存] → v2 使用明确测试目录且不接入生产；最终集成任务必须删除过渡产物。

## Migration Plan

1. 为七套来源建立解析配置和结构异常基线。
2. 生成 v2 测试运行态并完成逐章采样校订。
3. 冻结结构合同供检索与阅读器变更消费。
4. 保持生产旧格式不变，直到最终集成变更一次性切换。

## Open Questions

无。教材特有解析例外在实现阶段由异常证据决定，不改变上述合同。
