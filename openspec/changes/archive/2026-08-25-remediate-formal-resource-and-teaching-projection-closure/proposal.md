## Why

The formal-resource and teaching-projection specifications already require real atomic bindings and complete relation governance, but the current implementation stops at builders, caller-supplied hashes, and synthetic fixtures. No captured release has yet processed the actual textbooks, handouts, cards, infographs, media, exercises, simulations, and launchers into a complete formal resource envelope and Teaching Projection, so the coordinated cutover cannot truthfully consume those artifacts.

## What Changes

- Remediate the existing formal-resource workflow under the exact shared coordination allocation required by the downstream cutover: close the captured Authority and declared resource denominator with real source evidence, actual semantic atoms, Canonical bindings, launch anchors, final dispositions, and immutable processing receipts. Framework APIs, fixtures, hand-authored hashes, and synthetic qualification data cannot satisfy completion.
- Import `intro-video` production truth from the matching local Videos source projects, binding source revision, composition/design records, script/cue/timeline identities, final-media hash, and ACT runtime target. A verified production script remains authoritative and cannot be overwritten by ASR.
- Process course video, audio, and podcast material without authoritative scripts through a frozen, locally served Fun-ASR-Nano pipeline after the downloaded LM Studio model and runtime are identified and qualified. For each item, derive a deterministic hotword list from the exact frozen handout or lecture source used to create that media, and bind the source paragraphs, extraction rules, weights, model/runtime identity, transcript, semantic segmentation, time alignment, and output hashes in the receipt.
- Qualify hotword-assisted ASR on representative real control-theory media through a pre-registered calibration and blind-holdout protocol, including terminology recall, substitutions, deletions, false insertions, and timestamp validity. Thresholds and the exact pipeline identity must be sealed before holdout results are opened. Hotwords are hints only and cannot override acoustic evidence; any source, hotword, model, runtime, configuration, segmentation, or alignment drift invalidates derived media atoms.
- Materialize real semantic-paragraph atoms for textbooks, handouts, lectures, cards, infographs, and media; real question/task atoms for exercises; and governed task/launch anchors for simulations and interactive resources. A Canonical node may have no resource, but every included teaching resource must have at least one valid bound atom and other atoms may be evidenced as non-teaching. A technical failure in a production-active baseline resource blocks remediation completion unless the course owner explicitly retires it; a failed new resource remains explicitly excluded and development-only.
- Make resource processing incremental by reusing a prior result only when the complete source, atom, Canonical revision, role, scope, processor/model/hotword, anchor, and launcher identity is unchanged. Ordinary same-schema content updates reuse this workflow; schema or consumer-contract changes require a separate adaptation change.
- Complete all containment, prerequisite, and pedagogical-association decisions for the captured active-domain scope, activate evidence-qualified relations in the candidate, and preserve low-confidence or problematic relations in immutable repository review packs for the course owner. There is no runtime reviewer role or project-service review UI.
- Generate and validate the actual complete Teaching Projection, domain fragments, consumer projections, and formal resource envelope from sealed inputs and computed ledgers. Completion requires zero unresolved relation items and real materialized hashes; it cannot be asserted by a caller.
- Produce one qualified, non-selectable remediation candidate and its audit package under the same immutable coordination allocation that `coordinate-latest-authority-and-active-oss-cutover` must consume; a second allocation is forbidden. This change does not deploy artifacts, modify production selectors, activate a graph, or authorize production release.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `formal-runtime-atomic-resource-binding`: Requires source-backed execution over the real release denominator, materialized atoms and bindings, complete incremental invalidation identity, and evidence that cannot be replaced by framework or fixture existence.
- `media-source-manifest-ingestion`: Adds authoritative Videos-source import and qualified Fun-ASR-Nano processing with handout-derived hotword manifests, real-course evaluation, and drift-bound receipts.
- `act-canonical-teaching-relation-governance`: Requires actual candidate-to-decision-to-disposition execution for all three relation families, computed zero-unresolved closure, candidate activation of qualified relations, and immutable review packs for excluded problems.
- `act-teaching-projection`: Requires a real complete Teaching Projection and formal-resource envelope computed from the exact captured Authority, resource denominator, and sealed relation ledgers rather than caller-supplied completion claims or hashes.

## Impact

- Affects formal resource inventory and binding tools, media-source ingestion and local ASR integration, textbook and handout segmentation, card/infograph projection, exercise and simulation resource analysis, Teaching Projection builders, relation-governance review artifacts, incremental caches, validators, and release evidence.
- Reads authoritative media-production inputs from the local Videos projects and the execution-time LM Studio model installation, but copies only governed runtime inputs and immutable provenance needed by ACT; ignored outputs, dirty workspace state, model assumptions, or unstated external files cannot become release authority.
- Requires actual course-owner review during repository execution for exception packs and relation decisions. It does not add users, roles, review services, or production runtime workflows.
- Supplies the currently missing real artifacts to `coordinate-latest-authority-and-active-oss-cutover`; candidate selection, OSS publication, production activation, and rollback remain under that separate change and explicit authorization.
