## Why

Two earlier migration changes were archived with passing tests while static coordinates, zero-tick force behavior, full-domain payloads, prose-only Formula labels, a disabled language switch and a visible node directory remained. A final independent acceptance boundary is required so the third remediation cannot declare completion from component names, source-string assertions or synthetic fixtures.

## What Changes

- Establish one exact-current-revision acceptance manifest covering all fifteen domains, all three navigation levels, 2D/3D force behavior, default labels, governed formulas, bilingual switching, dedicated filters, accessibility, performance and absence of the visible node directory.
- Require real browser evidence for student, teacher and administrator roles on desktop and mobile, with interaction traces for domain entry, concept selection, one-hop expansion, relation filtering, language switching, drag/pin/unpin/reflow, camera restoration and inspector focus return.
- Measure request counts/bytes, domain usable time, main-thread blocking, force-settle time, frame budget, visible node/label counts and KaTeX render counts against explicit thresholds; failures block completion rather than becoming advisory notes.
- Add structural gates proving every root entry has bounded follow-on shards, no ordinary request returns a complete domain graph, all Formula labels have governed presentation, and every locale surface remains identity-consistent.
- Require an independent final review of the exact evidence revision and forbid checking migration tasks complete until every acceptance row passes without exception, fallback or manual reinterpretation.

## Capabilities

### New Capabilities

- `active-authority-graph-migration-acceptance`: Defines immutable evidence, performance budgets and no-regression release gates for the completed active graph migration.

### Modified Capabilities

- `commercial-ui-governance-gates`: Add exact-revision browser and accessibility gates for the active graph hierarchy and controls.
- `active-authority-legacy-force-runtime`: Make behavioral force parity evidence mandatory before migration completion.
- `active-authority-semantic-graph-presentation`: Require complete real-data coverage of hierarchy, formulas and progressive disclosure.
- `authority-locale-readiness-and-switching`: Require real bilingual switching evidence across every graph surface.

## Impact

- Adds graph-specific evidence manifests, performance probes, browser scenarios, structural validators and release gates; updates no production selector itself.
- Depends on all preceding executable changes in the series and is the only change allowed to declare the third migration complete.
- Does not permit waivers for current failures, fixture-only substitution, source-code substring evidence, hidden manual steps or partial domain coverage.
