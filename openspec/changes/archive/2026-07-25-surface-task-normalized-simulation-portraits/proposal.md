## Why

仿真任务证据即使完成治理，也不能由点击数量、低层过程或重复事实直接抬高画像。学生与教师需要看到基于当前可完成任务的累计仿真达成，以及可核验的完成任务构成；否则“仿真验证与证据”维度仍不可解释、不可比较。

## What Changes

- 消费前置变更 `govern-simulation-task-attainment-evidence` 的零画像权重任务证据和当前只读任务目录，将第七维“仿真验证与证据”计算为已满分完成任务数除以平台当前已发布、学生可完成任务总数。该全局目录是所有学生的同一分母；任务等权，部分进度、低层过程、重复产物与旧 `param_change` 不增加该维度分子。
- 在既有累计 learner portrait 物化器中按学生增量更新该维度：新任务证据仅重算该学生的任务投影；目录变更以目录摘要作为新输入，更新所有已有仿真任务投影学生的分母/聚合，不重放原始产物或全量重建事实。
- 将历史候选的应用、直接“更新画像”操作与实时事件纳入同一单学生物化路径；批处理仅并行不同学生，不把一名学生的多条事实合并为不同的计算语义。
- 向学生和有权教师返回“已满分完成任务 / 当前相关任务”及按奥德赛、Arena、控制工作台、虚拟仿真分组的任务构成；现有个人与班级画像继续以当前成员的个人事实投影聚合，不赋予班级独立事实或时间归属。
- 仅显示可用的累计任务达成与二元任务组成；没有满分完成任务时保持明确无证据状态，不以零分、过程进度或近期窗口替代累计结论。

## Capabilities

### New Capabilities

- `simulation-task-attainment-portrait-projection`: 定义任务归一化的仿真画像计算、增量物化、历史候选应用和任务组成输出。

### Modified Capabilities

- `adaptive-learner-state-service`: 将任务归一化的仿真维度作为 portrait v2 第七维的受治理累计输出，并向授权学生消费端提供任务组成。
- `cumulative-learner-attainment-backfill`: 以单学生、可恢复的累计物化路径处理合格历史任务候选与目录变动后的受影响画像。
- `teacher-evidence-governance`: 向授权教师的个人与班级累计画像返回任务达成分子、分母与分组组成，且只以当前成员的个人投影聚合。

## Impact

- 影响 portrait v2 的 `simulationValidationEvidence` 维度、任务证据消费、单学生物化队列、累计班级聚合和既有学生/教师画像 API 与页面。
- 依赖 `govern-simulation-task-attainment-evidence` 的任务目录、受治理上下文和历史 dry-run；不新增任务目录表、独立事实表、班级事实、通用撤销流程、Arena 评分器或 Rust/WASM 改动。
- 不重新设计画像页面，不修改其他六个维度的评分，也不以近期窗口覆盖累计任务达成。
