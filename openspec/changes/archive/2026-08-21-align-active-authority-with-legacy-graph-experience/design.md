## Context

新版 `/knowledge` 通过独立 Authority API 和分片状态机读取当前激活的工程图谱、领域目录及教学投影。旧版路径已经具备稳定画布、根节点多行标签、浮动检查器、资源启动和 KaTeX 渲染；新版另建了简化 SVG 组件，因而出现固定截断、节点内类型文字、侧栏触发布局缩窄、资源缺失和公式纯文本等偏差。

已有规范已经确定一级入口不画线、二级教学关系默认可见、工程关系按族筛选、详情内容身份绑定且新版/旧版数据不可混合。本变更修复的是呈现与交互适配，不重新定义 Authority 或 Teaching Projection 真相。

## Goals / Non-Goals

**Goals:**

- 让新版和旧版遵循同一套主要画布、节点、关系筛选和检查器交互合同。
- 保留新版的独立 API、分片、身份相关性、失败关闭和渐进加载。
- 确保根入口完整可读、二级教学关系真实可见、工程关系可按需筛选。
- 在稳定悬浮检查器中统一呈现关系、知识内容、系统资源入口和 LaTeX 数学表达。
- 用桌面、移动端、键盘和视觉证据证明实现不再依赖截图中的简化网格形态。

**Non-Goals:**

- 不把旧版节点、关系或 API 数据转换成新版数据。
- 不修改 Authority、Teaching Projection、领域成员或资源绑定真相。
- 不为缺失教学关系补造边，不从名称或空间距离推断关系。
- 不在检查器中复制课程、仿真、Arena 或其他功能的运行逻辑。
- 不在本变更中制作或补齐中英文翻译。

## Decisions

### 1. 共享呈现合同和可复用原语，不复用旧版数据容器

抽取或复用画布视口、节点标签、关系视觉语法、稳定检查器、焦点管理和资源启动等呈现原语。新版继续把 Authority 分片转换为自己的 view model，再交给这些原语；旧版继续使用原合同。

直接把新版数据塞入旧版 `KnowledgeGraphSystem` 被拒绝，因为它会重新引入旧 DTO、三类关系压缩和数据状态混合。继续维护两套相似 UI 被拒绝，因为当前偏差正来自独立实现。

### 2. 一级入口与普通知识节点使用不同标签合同

一级圆形入口测量完整领域名称和摘要，按可用直径折行至受限行数，并在既有最小/最大半径内扩大碰撞半径。其空间 packing 使用最终半径，不允许文本越过相邻入口。

普通知识节点保持 Legacy 式紧凑类型形状；名称在形状下方使用可换行的外部标签，节点本体不再显示类型文字。类型通过形状、颜色、图例和可访问名称表达，视觉上不重复占位。

### 3. 二级画布以教学关系为初始骨架，工程关系为附加筛选层

领域默认分片声明非空教学关系时，客户端必须同时物化两端节点并绘制可见边；端点丢失、身份漂移或几何缺失视为失败，不得降级为孤立节点网格。教学覆盖确实为空时，仍显示可选对象及明确空状态。

结构、推导与表示、应用与分析、关联等工程关系族通过共享筛选控件按需请求并叠加。筛选只改变可见性和缺失分片加载，不改变关系层、谓词、方向、端点、当前选择或既有坐标。

### 4. 检查器覆盖画布而不参与图布局

桌面使用固定或绝对定位的悬浮检查器，移动端使用聚焦受控的抽屉/面板。打开、更新和关闭检查器不得改变画布网格列、坐标、缩放、平移或关系筛选；关闭后焦点返回触发节点或画布。

检查器按“语义身份与说明 → 知识卡/信息图与系统资源 → 教学及工程关系邻居 → 来源与角色允许的状态”组织。关系邻居可触发现有跨域导航和渐进加载，异步旧响应不得覆盖新选择。

### 5. 详情分片投影安全资源启动描述符

服务端按选中 Authority 身份和当前角色解析已治理资源绑定，并返回有界的显示名称、绑定角色、资源类型、可用状态及不含内部路径的启动描述符。客户端只把描述符交给已有 route、registry 或 feature-owned launcher，不拼接 URL，也不使用 Canonical ID 猜测入口。

知识卡、信息图和资源绑定必须与详情分片的 Authority/Projection 身份一致；可选学习内容漂移只隐藏对应内容，不隐藏基础语义详情。资源缺失以作用域状态表示，不解释为 Authority 节点缺失。

### 6. 只把受审数学字段交给现有 LaTeX 渲染链路

Formula 对象的数学表达和知识卡中已声明的数学片段使用现有 KaTeX/Markdown 数学组件渲染。普通说明文本始终作为文本或受控 Markdown 处理，不把任意字符串猜测为 TeX；渲染失败显示中文受控状态且不回显内部源值。

### 7. 产品名称与内部身份分离

普通切换控件只显示“新版”和“旧版”。内部测试标记、API 路径和日志可以继续使用 Authority/Legacy，但这些称号不得出现在普通可见文本、辅助名称或错误回退中。管理员候选诊断入口保持独立受控，不并入该二选一产品称号。

## Risks / Trade-offs

- [共享 UI 原语可能意外耦合两套数据模型] → 只共享无业务真相的呈现合同，保留独立适配器和合同测试，禁止旧 DTO 进入新版状态。
- [长标签扩大入口后造成窄屏拥挤] → 使用测量后的有界半径、确定性重新 packing 和移动端视口测试，不允许无界放大。
- [教学关系存在但端点未进入默认节点预算] → 服务器和客户端合同共同保证默认教学边的端点物化，并用真实边几何验收。
- [悬浮检查器遮挡画布控制] → 复用现有 workspace inset 和移动端 sheet 规则，验证关闭、返回、缩放和筛选控件始终可达。
- [资源启动扩大授权面] → 服务端按角色投影，客户端只调用既有受权 launcher；不返回本机路径、未审 URL 或业务内部状态。
- [KaTeX 处理不可信内容] → 只渲染已声明数学字段和受控 Markdown 数学节点，错误失败关闭。

## Migration Plan

1. 先建立共享呈现合同和测试夹具，在不改变旧版行为的情况下接入新版适配器。
2. 迁移新版根入口、二级节点与关系筛选，验证教学边端点和稳定画布状态。
3. 扩展详情分片与悬浮检查器，再接入资源 launcher 和 LaTeX 内容。
4. 完成三角色、桌面/移动端、明暗主题、键盘焦点和真实分片浏览器验收。
5. 回滚时恢复新版呈现适配器；Authority、Teaching Projection、资源绑定和旧版路径均无需迁移或回写。

## Open Questions

无。资源采用现有平台入口启动；翻译完整性和中英文切换由后续依赖变更处理。
