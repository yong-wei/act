# 作业批改视觉证据与反馈质量改进任务

## 最终目标

在不破坏已验收的“教师发布作业—学生按题提交—截止后 AI/人工批改—教师确认—逐份发布—补交增量”闭环的前提下，建立可审计的视觉证据链，使含手绘图、图表或截图的作业能够被可靠识别、受控评分和教师复核；同时将评分结果逐步扩展为可定位的批注与 PDF 审阅材料。

本变更的交付不是宣称模型已达到人工评分水平，而是证明：视觉信息是否进入评分证据、由何种受控处理生成、缺失时系统如何拒绝自动结论，以及质量改善如何通过独立实验验证。

## 固定边界

- 复用既有作业、提交、批改批次、证据、教师审核、确认与发布模型，不建立平行作业或评分系统。
- 已完成的作业闭环继续保持：截止前不得批改；AI 草稿不能自动向学生发布；教师确认和逐份发布仍是唯一结果发布门禁。
- 答题记录仅用于本地人工分数对比，禁止进入 ZIP、Git、日志、外部 Provider 或模型上下文。
- 原始 Word、PDF、图片和身份信息不得以“调试方便”为由写入前端、日志、报告或未确认的数据集。
- 所有外部视觉/转换/评分调用都必须沿用脱敏、最小化投影、策略冻结、可删除与 fail-closed 约束；未获批准的旁路模型不得调用。
- 40 份 T2 实验的隐藏集保持密封；调优、诊断和回归不得消耗隐藏集。
- UI 文案面向教师和学生，禁止展示内部字段、模型术语、数据表名或样例账号标识。
