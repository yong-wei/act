## Context

既有作业闭环已把每题提交固定为 `SubmissionAttempt`、`AnswerEvidence`、`GradingRun` 和作业级确认/发布结果。文本及独立图片附件可以被转换为 Markdown 证据块，但 Word 内嵌图片只用于完整性检查，未作为评分模型的视觉输入；渲染 PDF 也仅作为派生审阅材料保存。40 份 T2 实验中，T2-3 等含视觉内容的作业是人工与 AI 差异的高风险集合。

本设计必须保留既有脱敏、外部处理策略、Provider 删除、快照、补交向量和教师确认门禁。答题记录仍只在本地作为人工分数基准，禁止进入任何视觉或评分 Provider。

## Goals / Non-Goals

**Goals:**

- 将视觉信息构造成题目级、可审计、可定位、带局限性的证据，而不是把原文件直接暴露给评分模型。
- 对视觉证据缺失、冲突、低置信度或无法归题的情况 fail-closed，转教师复核。
- 用冻结对照实验验证候选证据链对 T2-3 和视觉样本的影响，隐藏集只在预设门槛满足后使用一次。
- 让教师看到一键批改可用性与视觉复核原因，并将确认后的结果逐步映射为 PDF 审阅材料。

**Non-Goals:**

- 不修改 Qwen 的基本评分哲学、自动改变人工分数，或承诺达到人工评分准确率。
- 不将原始 Word、PDF 或图像直接提供给学生端、日志或未获批准的外部服务。
- 不改变已发布作业的截止、确认、发布、补交或历史结果语义。
- 不在本变更中解封、重置或重复消费隐藏集。

## Decisions

### 1. 证据而非文件是评分边界

新增版本化 `VisualEvidence` 投影，而不是让 Qwen 直接读取 Word/PDF。每条视觉证据包含源资产/规范 PDF 的校验和、页码或区域、题目归属、描述、置信度、处理器版本、策略快照、局限性与生成时间。评分输入只消费通过完整性检查的文本证据块和视觉描述块。

直接上传整份文件给评分模型会扩大外发范围，且无法保证题目归属、定位与删除审计；仅保存图片描述而不保留来源锚点则不能支持教师复核，因此均不采用。

### 2. 规范 PDF 是审阅载体，不是视觉理解的替代

Word 与 PDF 都产出不可变的规范 PDF 表示，Word 继续复用现有双表示和页面映射。视觉处理从规范 PDF 页面、Word 内嵌图片或独立图片附件生成证据；每个来源都需和页码/区域及题目锚点对应。

仅把 Word 转成 PDF但仍只抽取文字不能解决手绘图问题；保留多套不等价的 Word/PDF 表示又会使批注和实验无法重现，因此采用单一审阅 PDF 与来源证据的组合。

### 3. 视觉归属失败时 fail-closed

题目归属由显式题号、段落/页面锚点、附件嵌入位置和已验证的转换元数据共同确定。无法唯一归属、与文本证据冲突、描述低置信度或转换失败时，视觉证据状态为 `REVIEW_REQUIRED`；自动 AI 批改不产生可确认的题目结论，控制台提供重试或人工批改入口。

按最近题目或页面猜测归属会造成跨题误评分；生成泛化描述后继续评分会掩盖不确定性，均不采用。

### 4. 外部多模态处理由策略驱动

视觉处理器实现为受控适配器。仅当课堂范围、脱敏确认、最小数据类别、保留期限、删除定位符与策略版本齐备时，才允许调用已批准 Provider；否则使用本地处理或返回 `REVIEW_REQUIRED`。输出必须带模型、策略和删除审计，禁止把原始作答或身份映射写入日志。

现在不预先绑定具体旁路模型。先完成阶段 0 的证据诊断和阶段 1 的策略接口，再由负责人选择能够满足合规约束的 Provider。

### 5. 对照实验先于隐藏验收

对照组和候选组共享匿名样本、量规、人工基准、随机种子与评分模型，只改变证据版本。调优集运行三次，分层报告总体、视觉样本与 T2-3；视觉描述另行盲审。门槛冻结后才可解封一次隐藏集。

单次模型结果、总体平均分或手工截图都不能说明视觉链路有效，因此不作为验收依据。

### 6. PDF 批注仅从教师确认版本派生

评分总评、分段评语和证据锚点分别版本化。教师确认后，系统用规范 PDF 和确认快照生成审阅 PDF；精确区域不可用时按块、页的顺序退化并标明原因。学生结果包只引用发布后的确认内容，排除视觉处理内部描述、AI 草稿和教师历史。

对 Word 作业，规范 PDF 是转换成功后冻结的唯一审阅底稿。Markdown 保存教师确认的批注内容和语义锚点，不承担重新排版作业正文的职责；最终交付固定为在规范 PDF 上附加页内批注或汇总批注页的 `REVIEWED_PDF`。转换 PDF 缺失或校验不完整时，派生流程阻断，不以带批注 Word 或 Markdown 降级交付。

从 AI 草稿直接生成学生可见批注会绕过教师门禁；重新解析原文档生成位置会破坏可复现性，因此不采用。

## Risks / Trade-offs

- [视觉描述幻觉或误归属] → 保存来源锚点、置信度和局限性；失败时转人工，教师盲审验证描述质量。
- [Word/PDF 版式与页码漂移] → 冻结规范 PDF 校验和；批注只指向该版本并受控退化。
- [外部模型扩大数据暴露] → 策略冻结、最小化投影、删除定位符和审计缺一不可；没有批准策略即阻断。
- [视觉链路提高耗时和成本] → 仅对检测到的视觉资产执行，缓存按资产与处理器版本幂等，实验分别报告成本与成功率。
- [隐藏集被误用] → 数据集状态机拒绝诊断/调优路径读取隐藏集，并记录任何尝试。
- [新增状态使教师困惑] → 控制台只展示中文业务状态、可执行下一步和诊断码，不展示内部 Provider 或样例信息。

## Migration Plan

1. 先增加只读诊断和视觉证据数据契约，不改变当前批改选择条件。
2. 在调优集上回填/生成候选视觉证据，完成对照实验和教师盲审。
3. 策略、质量门槛和教师确认完备后，将 `REVIEW_REQUIRED` 接入正式控制台；保持原路径对无视觉资产作业不变。
4. 先提供教师审阅 PDF，再在既有发布包中引用教师确认后的批注投影。
5. 回滚时停止候选视觉处理并保留已生成审计记录；既有文本证据、人工批改、确认与发布继续运行，已发布包不重写。

## Open Questions

- 旁路多模态 Provider、模型、保留期限与删除 API 由谁批准，何时可配置？
- 视觉描述的最低置信度、盲审合格率和 T2-3 质量阈值由谁冻结？
- PDF 中手绘图的区域检测能否可靠落到题目锚点；不可靠时是否仅允许页级批注？
- “一键批改不可见”发生在正式作业控制台、实验室页面还是历史入口，是否能提供对应作业和时间窗口？
