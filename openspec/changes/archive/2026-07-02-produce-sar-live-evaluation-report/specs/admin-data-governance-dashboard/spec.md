## ADDED Requirements

### Requirement: Admin governance can review SAR live evaluation evidence
The admin data governance dashboard or linked governance report SHALL expose SAR live evaluation evidence when available.

#### Scenario: Evaluation report exists
- **WHEN** an administrator opens SAR evaluation evidence
- **THEN** the surface SHALL show report freshness, query count, baseline comparison summary, verified citation rate, privacy rejection count, multi-hop hit summary, feedback or structured test record count, and known limitations
- **AND** it SHALL preserve the distinction between SAR-assisted candidates and verified citations.
