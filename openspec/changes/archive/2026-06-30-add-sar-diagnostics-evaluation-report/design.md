## Design

Diagnostics should expose bounded, privacy-safe summaries of SAR projections and queries. The first implementation can be an admin data governance route or API payload backed by deterministic fixtures and serialized traces.

## Metrics

- SAR event count, entity count, and relation count.
- Counts by source type, privacy scope, and authority level.
- Events with citation target refs and events with verified citation outcomes from downstream citation layers.
- Query count, average hop count, privacy rejection count, limitation count.
- Source Pack handoff count and verified citation rate.
- Path planner SAR candidate adoption and rejection counts.

## Demo Fixture

The control-correction fixture should demonstrate frequency response/stability margin, controller correction, simulation validation, Arena official evaluation, learner evidence limitation, and verified citation handoff.

## Privacy

Admin diagnostics can show governance details, but raw private evidence, hidden Arena internals, and raw learner submissions remain unavailable.
