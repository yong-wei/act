## Design

This change should prioritize resources that are already natural path nodes:

- interactive lesson steps and runtime lesson planning units;
- knowledge cards and infographs;
- registered TeachingResource records;
- simulations and control workbench entries;
- quizzes, checkpoints, and platform-managed exercises;
- Arena preview or terminal-validation resources where official-scoring boundaries are preserved.

## Completion Method

Implementation agents must start by running the helper and enumerating every helper-discovered in-scope core resource. For each resource in scope, the agent should manually review:

- source identity and source hash;
- graph node mappings;
- LearningGoal fit;
- capability or quality contribution;
- prerequisite and successor relation;
- path stage and remediation role;
- route target and launch behavior;
- evidence contract and instrumentation;
- citation or source authority;
- privacy and teacher policy;
- review state.

SAR and RAG may be used to explore likely relations, but accepted metadata must be human-reviewed.

## Acceptance Shape

The helper should show that all in-scope core-resource findings are resolved, classified, or converted into reviewed limitation/exclusion states. The before/after evidence must include denominator counts by resource family, unaccounted counts, invalid promotion counts, unreviewed semantic counts, and remaining blocker counts. Path generation for all currently registered LearningGoals should have access to multiple governed core resource types where content exists.
