## Why

Persisted path execution is not enough unless it feeds the governed evidence and feature-cache layer. The report's closed loop depends on path adoption, node completion, simulation failure, Arena validation, and Konling intervention outcomes becoming visible to learner state, recommendations, and reports without raw table scans or overstated confidence.

## What Changes

- Materialize path execution, deviation, and intervention activity into governed evidence or feature-cache inputs.
- Refresh affected student evidence feature cache entries after path-related evidence changes.
- Expose adoption, completion, failure, fallback, and intervention outcome features with coverage and confidence metadata.
- Preserve user isolation and shared adaptive-learning evaluation envelopes.

## Capabilities

### Modified Capabilities

- `student-evidence-feature-cache`
- `evidence-driven-personalization`
- `adaptive-learning-governance-contracts`

## Impact

- Converts path activity into measurable evidence for learner state and reports.
- Does not expose raw execution payloads to normal student or teacher surfaces.
- Requires idempotent refresh behavior to avoid double-counting retries.
