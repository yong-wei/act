## Context

见 proposal.md。当前前后端已通过同一 Rust/WASM 内核步进，但关卡推进与指标累计分别维护。普通成绩直接落入 SimulationLog 后发积分；Arena 重放使用持久化快照。StudentProfile 存储积分及 JSON 进度，已有事务与运行租约不等于账户级串行化。

## Goals / Non-Goals

**Goals:**
- 在现有 JSON 运行载荷和服务端 action 边界内补足验证、重试与一致性。
- 保留手动输入、自动给定偏移及现有可达的运行中调参；不以禁用玩法代替重放。
- 保持固定 dt 和既有评分权重；优化前后用相同夹具比较。

**Non-Goals:**
- 不引入数据库迁移、外部依赖、通用仿真框架或新的服务部署。
- 不证明真人操作，不禁止用户重复完成同一关卡；运行验证只证明提交的输入能够合法通关。
- 不回算或删除历史成绩。

## Decisions

### 1. 最小输入记录与服务端权威结果

用版本化、有长度上限的固定步长输入记录描述运行：初始配置、参数/按键变化对应的步号和最终步数。记录输入而不信任客户端输出；避免每步重复整份控制器配置。服务端严格校验关卡、等级、模式、有限数值、参数范围、变化顺序与最大步数；由数据库控制器权限决定合法配置。

游戏复核复用 Rust 步进和共享的纯关卡/指标逻辑。普通模式可重放手动操作；Arena 沿用现有官方资格与服务端重放边界，不因普通模式新增记录就开放手动官方提交。已完成旧记录允许幂等读取；未验证旧记录不得获得新增奖励。验证和写入必须使用同一份持久化输入身份，重试不得替换输入。

部署前已经持久化完整 v1 配置快照、尚未落库 Arena 提交的 AUTO 运行保留原官方恢复路径：只读取原快照，核验其关卡与 Arena task 配对及既有官方资格，再由服务端配置重放恢复 Arena 提交。该兼容路径不要求补造输入轨迹，也不补发普通积分、推进普通进度或新增普通完成证据；已经发出的历史奖励保持原值。新运行、普通旧运行以及旧 MANUAL 官方运行不能借用这一例外，重试请求不能伪造旧快照或替换其输入。

不采用只限制客户端 score 上限的方案：它仍不能证明通关。也不采用只用最终参数重放的方案：它无法保留手动和动态调参的实际过程。

### 2. 账户更新串行化并在锁内读取最新值

所有奥德赛积分、购买、升级与奖励路径使用一致的数据库事务保护，采用仓库已有 PostgreSQL 事务锁方式或可序列化事务及有限重试。核验余额和拥有状态后才扣款；通关事务只更新确需改变的进度与积分，不写回无关的旧控制器 JSON。缺失账户的初始化也必须与这些操作一致。

运行级租约继续防止同一运行重复奖励，账户级保护处理不同运行和商店操作的竞争。服务端重放在数据库短事务之外执行。

### 3. 统一运行判定，终局立即停止

提取奥德赛专用的纯关卡推进与指标累计代码，供画布和服务端使用；不在 TypeScript 新增物理积分器。统一碰撞与终点先后顺序，终局回调返回 false，并只提交一次最终指标与输入记录。

### 4. 延迟修正和固定模型复用

Rust 延迟队列保持恰好 N 个历史输入。用 0、1、2 个采样周期及现有关卡测试验证；单独记录延迟关卡数值变化，不随意修改关卡阈值掩盖差异。

在 Rust 内以模型系数、系数顺序与 dt 等实际影响离散化的字段复用离散结果，保持缓存有界。优先减少重复矩阵运算；除非验证表明必要，不新增 batch API 或 worker 架构。生成物只由现有构建脚本产生。

### 5. 渲染和查询优化

固定步长记录遥测，面板低频同步、终局强制同步；组件只订阅所需字段，静止示波器不持续扫描绘制，尺寸变化触发重绘。保持原布局与交互。

排行榜在数据库按用户最佳成绩聚合后限量，固定同分顺序；个人最佳按关卡/等级聚合，不拉取全部日志 JSON。查询范围保持 GAME，兼容旧 missionId 与载荷 levelId，参数使用安全绑定。

## Risks / Trade-offs

- 输入记录增加请求体和重放成本 → 变化点压缩、严格数量与步数上限；失败不得产生奖励。
- 延迟修正改变带延迟关卡响应 → Rust 与关卡回归报告明确列出差异，保留无延迟标定。
- 历史中断运行材料不足 → 保留记录，不重新发奖，提供重新运行提示。
- 性能数值受机器影响 → 同机同夹具前后对比，不把本地数据视为生产容量。
- 数据库测试环境可能不可用 → 不接触生产数据库，明确区分 mock 回归和真实数据库验证。

## Migration Plan

不执行数据迁移。正常应用及 WASM 构建必须来自同一代码修订；本任务只完成本地实现与验证，发布另行授权。回滚依赖原有发布流程，不由本任务操作生产。
