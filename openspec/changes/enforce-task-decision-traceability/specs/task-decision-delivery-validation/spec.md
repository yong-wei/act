## ADDED Requirements

### Requirement: 本地提交校验任务清单
本地提交校验 SHALL 对暂存区改动执行任务清单结构验证，并要求每个受管实施文件由恰好一个有效任务清单的实施范围覆盖。纯文档、OpenSpec 和 Grill 决策记录改动不得仅因缺少实施范围而失败。

#### Scenario: 暂存的实现文件有有效覆盖
- **WHEN** 暂存区中的受管实施文件位于一个有效任务清单的唯一实施范围内
- **THEN** 本地提交校验通过

#### Scenario: 暂存的实现文件没有清单覆盖
- **WHEN** 暂存区中的受管实施文件不位于任何有效任务清单的实施范围内
- **THEN** 本地提交校验失败并列出未覆盖文件

#### Scenario: 暂存的清单无效
- **WHEN** 暂存区包含缺失必填字段或规划真源不符合合同的任务清单
- **THEN** 本地提交校验失败并指出对应清单和合同错误

### Requirement: PR 校验完整变更范围
PR 校验 SHALL 从目标基线与 `HEAD` 的 merge-base 计算完整差异，并按同一任务清单合同验证全部受管实施文件。该校验不得要求决策记录与实施文件处于同一个 Git 提交。

#### Scenario: 决策记录先于实现提交
- **WHEN** 任务清单和决策记录已在较早提交中加入，而受管实施文件在同一 PR 的后续提交中加入
- **THEN** PR 校验将两者纳入同一完整差异并通过

#### Scenario: PR 出现跨任务范围冲突
- **WHEN** 同一受管实施文件被两个有效任务清单的实施范围覆盖
- **THEN** PR 校验失败并列出冲突文件与任务标识

### Requirement: PR 自动执行交付校验
项目 SHALL 在 `pull_request` 事件中执行轻量任务决策交付校验，而不扩大现有发布型 CI 的触发范围。

#### Scenario: 打开包含实施改动的 PR
- **WHEN** 向仓库打开或更新 PR
- **THEN** GitHub Actions 以 PR 目标分支为基线执行任务决策交付校验
