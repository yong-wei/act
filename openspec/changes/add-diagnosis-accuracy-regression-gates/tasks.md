## 2. 指标与评测 runner

- [x] 2.1 实现节点级指标计算（precision/recall/F1、宏/微平均、完全匹配率、首要弱点命中率、健康假阳性率）与单测（已知输入的精确值断言）
- [x] 2.2 治理指标重放：复用生产语言门、证据引用门、归因门与校准门函数计算中文合规率、引用有效率、归因有效率与数值主张支持率的可计算子集
- [x] 2.3 实现 runner：统一 run ID、`artifacts/diagnosis-benchmark/<runId>/` 输出布局（manifest/summary/JSON+CSV 明细）、版本边界记录、阈值常量表与失败明细（场景、运行编号、预期真值、实际输出）
