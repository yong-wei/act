## MODIFIED Requirements

### Requirement: 新归因使用当前激活的精确选项级证据

系统 SHALL 在创建新的错误答案归因时，使用当前激活目录中与题目 ID、不可变内容哈希、题目审核哈希和学生实际选择精确匹配的唯一有效记录。系统 MUST 保持已持久化归因不可变；目录升级不得重算、回填或覆盖历史答案证据。

#### Scenario: 新答案命中 v2 记录

- **WHEN** 新错误答案与唯一有效的 v2 选项归因精确匹配
- **THEN** 系统使用 v2 记录创建归因

#### Scenario: 历史答案已有归因

- **WHEN** 答案已经具有受支持版本的持久化归因
- **THEN** 系统返回最早的历史归因
- **AND** 不因 v2 目录新增记录重新解释该答案
