## MODIFIED Requirements

### Requirement: 合格 v2 错误选项具有唯一且当前的归因

系统 SHALL 为 v2 固定分母中每道题的每个错误选项维护一条归因记录。每条记录 MUST 绑定 `catalogItemId`、当前内容哈希、题目审核哈希和错误选项键，并且恰有一个已登记学习目标、一个 active 规范知识节点、一个受控错因标签和非空归因版本。正确选项不得具有归因；同题错误选项不得复用错因、证据摘要或逐选项审核哈希。

#### Scenario: 当前错误选项有 v2 审核归因

- **WHEN** 错误答案与 v2 目录中的题目 ID、内容哈希、题目审核哈希及选项键精确匹配
- **THEN** 系统将该唯一记录作为新归因证据

#### Scenario: v2 记录缺失或漂移

- **WHEN** 当前错误选项没有唯一有效记录，或内容及审核来源发生漂移
- **THEN** 系统返回受控 `UNCERTAIN`
- **AND** 不得使用 v1 邻近记录、题目级语义、关键词或默认节点补全
