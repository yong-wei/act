## Why

对比页 WebGPU 当前每半秒更新波场，反复读回 GPU、重建 CPU 网格并执行参考校验，且场景和光学与 WebGL 分开维护，不能作为公平的后端对照。用户已授权迁移对比页 WebGL 入口，以共享实现实现完整功能对齐。

## What Changes

- 对比页统一为 Three.js 节点材质和共同场景，显式选择原生 WebGPU 或 WebGL2 后端。
- 波场结果常驻 GPU；共享波谱、IFFT 数学、材质、时间、船体查询、光学参数和验收，不维护两份效果实现。
- 复用现有泡沫历史、船体模型、时钟和 CPU 查询。移除 WebGPU 专有的简化场景及半秒更新限制。
- 数值读回和 CPU 参考计算只由显式 QA 调用；正常帧循环不整场读回。船体接触允许低频三点 GPU 异步采样。
- 保留真实后端身份、错误与功能状态，设备不支持时不静默回退。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `marine-spectral-evaluation`：双后端对比共用场景与光学，并以 GPU 常驻数据连续更新。

## Impact

仅迁移 `/simulations/fft-ocean-comparison` 及其专用适配、测试。现有正式仿真路由、生产默认后端和发布配置不变。无新依赖；允许浮点和抗锯齿导致的微小差异，不承诺逐像素相等。用户于2026-09-29授权提交、推送；不部署。

## 追加范围：船行波与泡沫生命周期

用户授权在对照页增加移动压力驱动的位移船行波、表面破碎触发的持久泡沫场（漂移、扩散、消散），默认战术视角和圆周航行。复用共享 GPU FFT、材质和既有时钟/相机预设；不迁移正式船舶路由，不宣称三维卷浪或工程级船体 CFD。
