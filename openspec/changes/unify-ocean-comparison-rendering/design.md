## Context

现有 WebGL 路线使用 GLSL ShaderMaterial 和离屏纹理 FFT，WebGPU 路线逐轮分配计算资源、读回四组缓冲、CPU 参考校验和重建网格。两侧船体、反射及泡沫消费并不同源。安装的 Three.js 提供 WebGPURenderer 的原生 WebGPU / forceWebGL WebGL2 后端及共同 TSL 节点编译。

## Goals / Non-Goals

目标：相同输入和时间下，两个 API 的同算法路线使用相同场景、网格、材质和交互，实际波场常驻 GPU；显式 QA 才读回。

当前非目标：跨硬件性能结论、逐像素确定性、升级依赖、改变正式船舶动力学模型或生产部署。正式路由迁移与自动硬件选路已由后续授权纳入。

## Decisions

1. 对比页只保留一个客户端和场景。复用 ComparisonQueries、ComparisonVessel、MarineFrameProvider 和 FoamHistoryField。
2. 采用共同节点材质，移植当前 GGX/Fresnel、微法线脚印过滤、泡沫历史、浅水吸收和反射消费。底层 API 差异交由 Three.js 后端处理；不复制两份 GLSL/WGSL 光学。
3. 共享 FFT 节点数学和逐阶段调度。第一版以 GPU 离屏 pass 执行演化、位反转、蝶形和位移生成，两后端均执行真实 GPU 计算，无 CPU 中转。WebGPU 暂不额外维护第二套 compute FFT；未来优化须以同源数值验收证明收益。
4. 数据适配负责显式后端创建、目标纹理与异步读回。常规帧不整场读回或重建 CPU 网格；后续授权的船体三点接触采样可低频异步读回，资源持久复用。
5. 光学开关按真实资源和消费者报告。反射隐藏水面、保留船体；浅水只渲染底面。WebGPU 不可用时显示明确失败，不静默使用 WebGL。
6. 保留既有视觉基线，以固定时间截图、实际 GPU 读回、接触查询和光学开关验证迁移；更新仅依赖旧源码字符串的测试，不能靠测试文本掩盖功能缺失。
7. 实际 GPU 接触读回揭示旧 FFT 网格的 N−1 间隔与周期 N 样本错位，以及解析曲面与可见三角面混用。新网格使用 N 间隔和 texel 中心，主线程与 Worker 复用独立的三角面插值函数；解析 DFT 查询保留用于数值参照。Gerstner 查询消除重复水位叠加，并与同场景岸线衰减一致。两种 API 共用这些修复。

## Risks / Trade-offs

- 节点编译后不同后端纹理坐标约定不同：用已知频谱、多个时刻和 DPR=1/2 的实际读回验证。
- WebGL 入口迁移可能改变色彩或环境采样：使用同一天空资产、颜色、曝光和参数，进行旧画面与新路线对照。
- 首次编译耗时：初始化时准备资源，运行时复用；报告首帧和稳态分别测量。
- 暂用离屏 FFT 而非专用 compute 优化：先实现正确、共享、无读回的连续路线，不预先承诺 WebGPU 快于 WebGL。

## Migration Plan

初始阶段对比页先切至共享入口；后续授权阶段七船正式路由共同接入。保留本次开始时的工作区快照作为迁移视觉和差异依据，不覆盖既有未提交修改。验收失败时继续修复，不能把缺失功能改标为已实现。

## 后续视觉校准（2026-09-29）

用户反馈显示器问题修复后 FFT 波浪过大、浪尖白斑不自然，授权修正 FFT 尺度和白沫表现。

- 默认 ss4 的有效波高从 6.5m 调为 2m，保留跨分辨率归一化。6.5m 是旧外观匹配目标，不能代表中等海况；2m 是本实验选择的代表值，不是风速唯一决定的实海预测。
- 删除为了突出船尺度波峰加入的 36m 频带增益；保留既有 Phillips 谱、方向扩散和网格带限。
- 两种 API 仍共用同一材质：中心差分法线消除半格偏移；GGX 直射贡献补上入射余弦；FFT 白沫由较强压缩驱动，缩小纹理尺度、降低覆盖和亮度。保留现有岸边泡沫历史。
- FFT 白沫仍是带限网格的视觉近似，没有新增破碎水体、喷溅或 FFT 白沫历史模拟。不能将压缩阈值解释为真实破碎判据。
- Gerstner 几何参数保持原值，两算法暂不宣称等有效波高；同算法跨 API 的输入、波场和光学保持同源。
- 验收：ss4 在多个时刻 Hs=2m±2%；128/256/512 归一化及独立 DFT 回归通过；两种 API 的固定时间截图、接触误差及 DPR=1/2 回归通过。

参考：[Met Office 海况分级](https://weather.metoffice.gov.uk/guides/coast-and-sea)、[Tessendorf 海洋渲染讲义](https://people.computing.clemson.edu/~jtessen/reports/papers_files/coursenotes2002.pdf)。

## 圆周航行、船行波与持久泡沫（后续授权）

1. 对照页船舶采用半径300m、航速12m/s的规定圆轨迹；这是检验轨迹，不增加 TypeScript 船舶动力学积分器。复用 tactical 相机预设并随船移动，可切为自由观察。
2. GPU 以移动椭圆高斯压力驱动线性深水重力波：每个频率箱满足 eta'' + g|k|eta = -|k|p/rho，以固定1/60秒和分段常力解析更新谱状态；共享现有二维逆FFT输出实际高度。全局弱阻尼限制周期域历史回绕，不模拟岸线反射和船体浸没边界。
3. 船行波加到同一个海面几何和法线上；不绘制凯文臂贴片。保留世界空间的波和泡沫历史，转弯不会旋转旧尾流。
4. 泡沫为GPU双缓冲持久场：压缩/陡度触发破碎，船艉湍流补充源，半拉格朗日漂移、扩散、指数衰减；新生泡沫与残留泡沫用不同寿命。按固定步更新，暂停冻结，重置/倒放重建，前跳分批重放；正常帧不整场读回。
5. 共享相同节点波面供材质和破碎检测。船体低频异步采样可见三角面三点，含船行波；避免为CPU另造一份动态谱求解器。波浪纯数值QA保留独立DFT参照。
6. 验收覆盖双API、零源/非零源、真实位移、源停止后的传播和泡沫消散、固定时间重放、暂停、重置、船体三点、圆轨迹和默认相机。声明本机硬件范围和表面破碎近似，不能称为完整三维流体。

本节取代初版对照页 CPU 泡沫历史及仅背景波的 Worker 接触查询；正式路由与独立 DFT/Worker 工具保留。三点查询只报告端到端延迟，compute/queue/transfer 子项未独立测量时为 null。泡沫沿用既有26秒半衰期，新增短寿命通道表示刚产生的白沫；固定1/60秒更新船行波，每4个固定步更新一次泡沫，避免显示帧率改变沉积量。远跳分帧补算，单帧最多120步；暂停时复用已算纹理，不重复FFT。

船行波参考：[时间变化压力源的波浪解](https://arxiv.org/abs/1511.02610)、[船波频谱与线性波模型](https://arxiv.org/abs/1604.05812)。泡沫采用压缩与坡度触发的表面近似及持续输运，不声称依据阈值即可精确预测真实浪花破碎。

## 正式仿真接入决策

- 将对比页渲染器与水面宿主下沉为共享资源，对比页保留测试场景适配。正式场景不反向依赖app目录。
- 七船统一Canvas与FFT水面，按实际船位、场景航向、速度驱动压力源。海面状态在世界坐标保持，船型尺寸、海况、岸线与预设作为输入。
- 后端选择检查原生adapter、所需纹理能力及初始化；不根据品牌猜测性能。自动模式失败使用新canvas重建WebGL；显式诊断模式保留真实失败。
- 环境和后处理迁入兼容节点渲染器的共享路径；不得通过删除既有能力实现后端兼容。船体和教学线采样统一实际FFT曲面，报告异步样本年龄。
- 测试覆盖七船自动路线、强制WebGL、无WebGPU/初始化失败回退、重置、运动、预设与质量档位；复用对比页数学和泡沫测试。

### 正式接入的实现边界

背景FFT使用256²交互网格，自然泡沫场512²；本轮增加的局部船行波与洗流见后节，光学档位改变不重建这些场。压力尺寸按船型输入，速度取数值模型的真实速度，暂停停止新船行源。钻井平台八个推进器按实际锚点、方位、可用状态和功率发射洗流。

近场随船按网格步长平移，位移相位锚定世界坐标；边缘100m渐变至同材质远场。远场保留光学微波，不承诺远处几何浪与近场同精度。泡沫区域超过四分之一域后按像素对齐移动，回溯旧世界位置采样，新区域填零。环境或海况配置变化重建对应场景资源与历史；质量切换保持历史。

贴水查询采用场景内有界异步缓存，直接读实际合成曲面，复用探针资源；缓存包含样本时刻，最多保留512点与128个待采点，逐批最多8点。近邻短距离以所读坡度补偿，过期样本不继续作为有效接触数据。它属于显示接触近似，不向Rust/WASM动力学反馈新水动力。

自动模式在独立canvas上验证原生设备初始化，失败后正式canvas使用WebGL；运行中的设备丢失使用新canvas回退，仿真控制状态由外层保留。显式诊断选择WebGPU时仍报告失败，不能把WebGL标成原生成功。本轮不采用品牌白名单或宣称自动模式完成性能竞速选优。

### 海面边界与生产压缩回归修复

近场和远场共同以 y=-1 为平均海平面，远场片元在近场2048m方形范围内剔除，仅填充外部区域。近场边缘原有100m位移渐变保持不变，避免远场整平面截住负浪高。远场判定复用世界原点，不随相机投影变化。

055与981不再用粗略局部矩形剔除水面。旧框没有跟随真实船壳的尖艏、轮廓或模型缩放，可能把船外水面裁空；由实际模型深度遮挡水面，保留开放月池与船外海水。共享材质保留已有可选排除接口供旧消费者使用，但七个正式船型不再传入此类框。

后端身份及纹理读回方向使用Three.js的isWebGPUBackend/isWebGLBackend标志，不依赖会被生产压缩改名的constructor.name。独立浏览器回归将真实渲染器、水面和FFT数据管道压缩后运行，检查初始化、读回误差及远场对负浪高的遮挡。

### 微法线规则纹路修正（2026-10-01）

固定时间、同一低视角的归因对照显示，关闭额外微法线后密集交叉纹路消失；关闭直射高光后纹路仍然存在。主因是有限组正弦微波产生的空间周期，并非FFT主波场的网格裁剪。

共享材质保留原细节尺度、方向、质量分级和像素足迹过滤，将周期正弦扰动替换为Three.js MaterialX的连续二维Perlin噪声。横向取样密度也参与尺度过滤；被滤除的分量跳过噪声计算。细节在世界坐标中输运，暂停和固定时间重放可复现。

GGX与环境反射共用按像素内法线变化补偿的粗糙度，降低低粗糙度高光的闪点。该层仍是视觉微法线近似；不改变FFT位移、浪高、船行波、泡沫历史、船体接触或数值动力学。本次目标是减少截图中的规则纹路，未声明与未提供材质设置的Blender预览逐像素一致。

### 船体波、洗流与泡沫

- 移动压力仍采用 GPU 固定步线性深水模型。将单一宽高斯源改为有船长、船宽及航速尺度的艏/艉压力分布，取消正常航速范围内4m/s即饱和的振幅门控；其参数属于显示校准，不冒充实船CFD或推力测量。
- 船周采用局部细波场，并细化实际可见网格。背景2048m FFT保持既有波高与独立DFT口径；两个API共用插值、局部波位移、世界坐标相位与贴水查询。局部边界吸收和几何过渡防止周期回绕及叠面截住波谷；不能只增加纹理精度却保留不能表示该波长的几何。
- 现有推进器节点提供世界位置与轴向；055改为直接由公共出流入口读取已显示节点并移除无消费者的ref，其余船按已声明动画/节点接口解析，981保留既有方位、可用性和功率读取并合并当前模型锚点。桨径按挂载时几何估算，浸深读取节点相对平均水线的位置；这些显示值不作为实船测量。缺少真实转速/推力时按已有运动状态估计，不把演示clip速率当作真实RPM。
- 船体波依据船体运动产生，推进器洗流依据推进活动产生；有推力的零平移平台保留局部洗流，无平移时不伪造远场航行波。所有状态只读，不增加或改变数值船舶动力学。
- 自然破碎泡沫保留现有世界历史，桨流与船行波破碎使用局部细场。减少固定船艉高斯涂层，调整源强、输运、覆盖和衰减以呈现局部新生白沫及后方稀疏历史。转弯不旋转旧场，暂停/重置/倒放沿用共有时钟合同。

局部域为768m、512²，格距1.5m，生成波长下限8m；整个局部波域的可见格距为2m，384–512m区域过渡至背景格距。粗细边界增加共享边顶点，以单一网格连接；背景纹理周期四点插值，局部纹理同源四点插值。显示与贴水探针复用该网格。所有场景的网格原点跟随局部波域，背景相位仍锚定世界；对比页远场孔洞中心同步该原点。

艏/艉压力中心位于船长的+0.42/-0.40处，权重0.9/0.65；长向标准差为0.035L并限制于2–9m，横向为0.23B并限制于1.3–6m。压力水头为0.10U²/(2g)，上限1.5m。深水色散由ω²=g|k|产生发散波与横波，其几何和强弱随运动变化；这里的系数是视觉校准。局部原点按48m移动，对高度和速度频谱施加同一世界相位平移。每个模拟秒在256–384m边缘同时吸收高度与速度，再正向变换回频域，减少周期回绕；无波历史时跳过船波变换。

自然破碎源只读背景位移并保留既有岸线衰减。自然密度、洗流密度、船波破碎密度分别使用26/8/12s半衰期，新生层另用1.8/1.2/1.6s半衰期。洗流使用逐桨方向、活动、几何直径与浸深产生局部输运和源；深水表面混合的衰减为显示估计，不能等同于真实气泡上升。自然及船波破碎覆盖使用噪声斑块与新生层；局部洗流的斑驳调制范围为0.35–1并乘以已有密度，让新生层消退后仍能看到残留。密度为零时洗流覆盖仍为零，不设置整片海面的最低白色覆盖。不同域的诊断质量、质心按像素面积合并。

贴水查询每批至多8点，仍在同一实际三角面上渲染。8个像素共用一次异步读回；拷贝已提交到独立缓冲后释放海面更新锁，避免等待GPU导致海面停更。结果携带命令提交时的采样时间，缓存和对比页使用该时间。诊断船姿与该帧实际消费的接触样本一起观测，不混用随后到达的新样本。

- 大贴图转码与新模型发布由3DModels负责，本轮ACT不改上游GLB/PNG字节；现有材质和模型的预热在当前渲染器中进行，不能通过创建常驻额外图形设备来换取复访速度。

### 验收

双API核验实际位移、直航发散波/横波、0/低/中/高航速、船艉不同推进器位置、981零速推力、源停止后的历史、固定步重放及窗口移动；低视角扫过反光带检查白沫和波面。延迟及失败LOD请求必须证明当前船体保持可见；首次请求以LOD2优先、正常运行不整场读回。采集首屏、候选准备与稳态成本，不宣称未测硬件或生产收益。

## 已发布代理接线（2026-10-02）

用户通知解除上游等待。七船采用新运行包的`ship-proxy`与`act-propulsion-anchors/1`接口：同一版本的角色、摘要、贴图和独立锚点一起接收。代理只展示静态识别外形，无精细动画；按包声明的总长、坐标矩阵及水线挂载，不能因代理AABB不同而重新居中或缩放。独立锚点作为版本绑定的小型接口进入应用，代理期间按既有遥测映射方位；正式LOD出现后消费实际节点，同一推进器保持稳定标识与名义桨径出处。

首次显示本船代理，后台准备LOD2，再直接准备当前所需目标档。准备或下载失败保留已有模型，低档不可用时允许直接准备目标档。生产允许Origin使用ESA优先地址及同源回退；开发Origin用同源包。已消费模型保持同一地址，不因准备阶段结束切域重复下载。新的版本化消费闭包统一发布到私有OSS；不可变对象以摘要核验，同长度不等于同内容，禁止覆盖既有异内容对象。ESA验收覆盖代理、三档GLB、接口、清单及相对贴图的MIME、CORS和字节身份。对象发布与应用镜像部署分别记录。


### 动画状态所有权与恢复

下载错误边界按URL重建，动画状态必须归外层模型包会话所有；包身份或显式实验重置才建立新会话。循环累计时间、实时桨相位、达标状态及独立演示的播放和剩余停留时间跨LOD保存。恢复动作先以相对目标mixer当前时钟的绝对调度时刻、单位速率重建进度，再恢复原暂停和速率；不能假设目标时钟为零，或认为Action.reset会清除已缓存的零速率。直接浏览器回归检查暂停后的稳定螺旋桨朝向，不把原始量化四元数的长度误差当作方向跳变。

## 按船型配置的长尾迹与船侧泡沫（2026-10-03）

七船以同一视觉参数结构配置：洗流与气泡半衰期、扩散系数、源强、弱散射强度、历史范围及水线形态。它们是依据实拍的显示校准，尚非实船测量或三维气泡动力学。尺寸、船位、航向与推进活动继续消费原只读输入。

保留768m/512²船行波和精细洗流，以及2048m/512²自然泡沫。增加独立512²长尾迹双缓冲，按船型采用数公里范围，保存残留洗流、弱气泡、破碎/船侧白沫及船侧诊断通道。额外纹理预算为8MiB；每四个固定步更新，正常帧不读回。长历史按像素对齐平移，域外填零；精细与长历史在精细边缘清除之前平滑混合，避免叠加增亮。微气泡只提供有界、随原水色和光照变化的弱散射，不作为长期白色覆盖。

艏肩及船侧源沿可配置的收艏/收艉水线带生成，强度取航速Froude尺度与已有海浪陡度的显示近似；平静水面静止、无推进活动时没有船源。平台按分离的立柱水线带处理，不沿整平台包围框画白边，也不裁掉开口水面。源使用可解析的带宽，并在粗场降低峰值以保持注入量的量级。历史留在世界空间，停止源后继续输运/扩散/衰减，暂停冻结、重置/倒放重建。
