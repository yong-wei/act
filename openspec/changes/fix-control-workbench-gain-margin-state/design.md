## Context

控制分析内核以可空的 `gainMarginDb` 和 `phaseCrossoverRadPerSec` 返回频域计算结果。没有在当前采样区间内找到 `-180°` 交叉时，这两个值均为 `null`；该结果不能证明整个正频率轴不存在有限交叉。图表层不得把该可空值直接解释为无穷增益裕度。

## Goals / Non-Goals

**Goals:**

- 在已有频率响应数据时，区分有限相位交叉和当前范围内未观测到相位交叉。
- 保留 `--` 作为频率响应未生成或不可用时的展示。
- 让性能指标卡和频域图表元信息使用同一判定。

**Non-Goals:**

- 不修改稳定裕度计算公式或从有限采样曲线反推无穷增益裕度。
- 不改变根轨迹、时域指标或控制器设计流程。

## Decisions

- 在 Rust 内核中随指标序列化 `phaseCrossoverStatus`；`finite` 表示已计算出交叉频率，`notObservedInFrequencyRange` 表示当前请求区间没有观测到交叉。
- 图表展示层仅消费内核状态：有限交叉显示数值，范围内未观测到交叉显示明确提示，空频率响应保持 `--`。
- 复用单一格式化路径供指标卡与 Bode/Nyquist 元信息使用，避免两处再次产生不一致。

## Risks / Trade-offs

- [真实交叉位于请求范围外] → 输出 `notObservedInFrequencyRange`，避免前端产生无穷裕度结论。
- [频率曲线为空但指标被外部构造] → 仅显示 `--`，避免未经证据的稳定裕度结论。
