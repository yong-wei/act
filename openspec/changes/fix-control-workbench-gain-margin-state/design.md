## Context

控制分析内核以可空的 `gainMarginDb` 和 `phaseCrossoverRadPerSec` 返回频域计算结果。控制工作台的默认请求包含幅频和相频数据；在相频曲线没有穿越 `-180°` 时，两个值均为 `null`。现有图表层将该状态格式化为 `--`，但多表征联动层已把同一状态识别为无穷增益裕度。

## Goals / Non-Goals

**Goals:**

- 在已有频率响应数据时，将“无有限相位交叉”显示为 `GM ∞` 和“无相位交叉”。
- 保留 `--` 作为频率响应未生成或不可用时的展示。
- 让性能指标卡和频域图表元信息使用同一判定。

**Non-Goals:**

- 不修改 Rust/WASM 的稳定裕度计算公式或传输数据结构。
- 不改变根轨迹、时域指标或控制器设计流程。
- 不把无穷增益裕度改为任意有限数值。

## Decisions

- 在图表展示层从完整 `ControlAnalysisResult` 推导状态，而不把 `null` 直接改为 `Number.POSITIVE_INFINITY`。`null` 仍是内核的可空结果，只有同时存在有效幅频和相频曲线、且相位交叉频率为空时，才具有“无有限相位交叉”的控制学语义。
- 将展示分为有限值、无穷增益裕度和不可用三种状态。这样既与默认工作台的结果一致，也不会把未请求频域输出或空数据错误标为无穷大。
- 复用单一格式化路径供指标卡与 Bode/Nyquist 元信息使用，避免两处再次产生不一致。

## Risks / Trade-offs

- [频率曲线为空但指标被外部构造] → 仅显示 `--`，避免未经证据的无穷裕度结论。
- [展示逻辑依赖曲线存在性] → 为有限、无相位交叉和不可用三种输入分别增加图表单元测试。
