## Why

Runtime lesson modules, lesson steps, media, slides, audio/video, and handouts are the largest practical source of path-plannable course resources. Current audit output still shows many runtime items missing graph bindings, capability targets, path profiles, or reviewed dispositions. Without completing this family, path options will continue to collapse into a small repeated set.

This batch completes runtime teaching resources by reviewing launch targets, parent lesson context, graph/K/A/Q fit, evidence behavior, and whether each item is an independent PlanningUnit or only supporting material.

## What Changes

- Process remaining helper workqueues for runtime lesson steps, runtime lesson modules, runtime lesson media, slides, audio/video, PDFs, and handouts.
- Review every in-scope item against its runtime manifest, parent lesson, route target, source asset, graph context, LearningGoal K/A/Q objectives, path stage, evidence contract, and privacy/access policy.
- Promote only independently executable, reviewed PlanningUnits to path-plannable status.
- Classify fragments, media assets, and modules without independent launch/evidence contracts as supporting-citation, embedded-asset, evidence-producing, or excluded-with-rationale.

## Impact

- Should materially increase usable path resources for all nine LearningGoals.
- Preserves runtime-first source-of-record ownership; no raw media or authoring truth is copied into planner metadata.
- Does not process long-form textbook/reference resources or assessment checkpoint items.
- Does not block Yang Fan fixture completion; fixture data should remain scoped to fixture-owned governed resources.
