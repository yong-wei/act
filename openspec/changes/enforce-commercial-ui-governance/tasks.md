## 1. Governance Contract

- [ ] 1.1 Define advisory and blocking governance modes with explicit migration allowlists.
- [ ] 1.2 Define source checks for approved token use, page-local palette detection, and unregistered gradients/status colors.
- [ ] 1.3 Define shell and route inventory checks for platform and commercial workspace shells.
- [ ] 1.4 Define navigation coverage checks for student intent groups, core destinations, aliases, profile, and cockpit semantics.
- [ ] 1.5 Define interactive module chrome checks for migrated course manifests.
- [ ] 1.6 Define the default visual acceptance matrix for login/auth, homepage, Interactive Learning, Arena, adaptive learning, profile, Control Workbench, course runtime, teacher analytics, and admin governance.
- [ ] 1.7 Define accessibility and text-fit gates for contrast, visible focus, keyboard reachability, reduced motion, button wrapping, and 320px mobile overlap.

## 2. Enforcement

- [ ] 2.1 Implement advisory reporting with allowlisted legacy debt tied to migration issues.
- [ ] 2.2 Promote checks to blocking mode after related entry and workspace migrations complete.
- [ ] 2.3 Update PR/review checklist requirements for screenshots, visual hierarchy, first-viewport usefulness, and responsive text fit.
- [ ] 2.4 Require affected-route evidence for commercial UI PRs rather than accepting generic screenshots.

## 3. Validation

- [ ] 3.1 Add positive and negative fixtures for token, shell, navigation, status, and module-chrome checks.
- [ ] 3.2 Verify advisory mode reports existing legacy debt without blocking unrelated work.
- [ ] 3.3 Verify blocking mode fails a newly introduced unregistered palette, shell, or module chrome.
- [ ] 3.4 Verify the visual acceptance matrix and accessibility/text-fit checklist fail when required evidence is missing.
- [ ] 3.5 Validate with `rtk proxy openspec validate enforce-commercial-ui-governance --strict`.
