## Context

AI 工坊的任务集合由服务端读取当前学生的已采用学习路径，并把未完成节点转换为任务项。当前 `pathTaskItems()` 为所有路径节点生成只包含 `pathId` 的 `/assessment/adaptive-practice` 地址；路径的 `goalId`、节点 ID 和 `path-execution` 意图没有进入导航。

自适应学习中心只有在存在有效目标时才加载路径上下文。路径执行工作区还需要明确的路径意图和路径 ID；节点详情则依赖节点 ID。因而从 AI 工坊点击任务后，页面无法恢复该任务，学生会落入空的或通用的入口，任务卡片没有形成真实学习行动。

## Goals / Non-Goals

**Goals:**

- 使每个已采用路径任务的导航目标能够唯一恢复目标、路径、节点和路径执行意图。
- 让当前节点可直接继续，未解锁节点可进入真实的锁定说明与下一步行动。
- 在服务端加载路径执行数据时验证当前学生对路径和节点的归属及可执行状态。
- 对缺失或失效的路径上下文呈现诚实的恢复状态，并覆盖真实浏览器导航。

**Non-Goals:**

- 不改变学习路径规划、节点排序、解锁规则或完成推进规则。
- 不允许客户端 URL 参数绕过服务端的学生归属、路径状态或节点 readiness 校验。
- 不把锁定节点改为可执行节点，也不允许从 AI 工坊重新选择任意路径替代当前任务。
- 不新增数据库表或迁移；路径和节点身份沿用现有持久化模型。

## Decisions

### 1. 服务端生成完整的路径任务导航

`readAdoptedPath()` 读取 `goalId`、路径状态、节点有序列表和当前节点。`pathTaskItems()` 为每个未完成节点生成带 `goal`、`pathId`、`nodeId`、`intent=path-execution` 的 URL，并对每个参数进行 URL 编码。任务项中的导航描述只来自服务端已采用路径，不接受客户端补写。

当路径缺少有效目标或节点不能被服务端确认时，不生成看似可执行的通用地址；集合应保留受治理的不可用或恢复语义，由 AI 工坊显示对应限制和行动。

备选方案是继续只传 `pathId`，由目标页猜测目标和当前节点。该方案在多个目标或节点状态并存时不具确定性，也会再次把任务卡片降级为通用入口，因此不采用。

### 2. 路径执行页重新确认上下文

自适应学习中心接收导航参数后，先按当前登录学生读取 Learner State，再按 `pathId` 加载路径执行轮次；服务端返回的数据必须确认路径属于该学生、处于允许读取的状态，且 `nodeId` 属于该路径。客户端参数只用于定位请求，不授予权限。

若指定节点不是当前可执行节点，页面显示该节点真实的锁定或等待状态；若路径、目标或节点不存在，页面进入现有的 truthful recovery state，提供返回路径中心、生成路径或重新加载等真实行动，不静默进入通用练习。

### 3. 当前节点与指定节点分别验证

任务卡片对当前节点和未解锁节点都保留节点身份。当前节点的主行动恢复指定节点执行态；未解锁节点进入同一路径执行工作区以展示锁定条件，但不得启动练习。页面不得用 URL 中的标题或数组位置推断节点完成状态。

### 4. 验收覆盖链接契约和真实导航

服务端单元测试验证完整 URL、参数编码、目标缺失时的限制状态及当前/锁定节点差异。路由测试验证有效路径执行上下文、错误上下文和归属校验。Playwright 在登录学生场景中从 `/ai` 点击当前任务，断言最终页面保留目标、路径、节点和执行意图，并覆盖 1440px 与 320px 的布局和可达行动。

## Risks / Trade-offs

- [旧路径缺少 `goalId`] -> 不伪造目标；显示恢复状态并提供回到路径中心或重新生成路径的行动。
- [节点已在其他请求中推进] -> 页面以服务端最新 readiness 和执行记录为准，展示锁定、已完成或重新定位状态，不信任过期 URL。
- [URL 过长或参数被手工修改] -> 使用标准编码和服务端白名单解析；非法或越权上下文进入 fail-closed 恢复状态。
- [浏览器服务使用旧代码] -> 证据脚本在捕获前确认运行态 revision 与工作区 checkpoint 一致，并在漂移时失败。

## Migration Plan

不需要数据库迁移。部署新投影逻辑后，新生成的路径任务使用完整导航；旧页面书签或旧任务 URL 仍通过现有恢复状态处理，不会获得额外权限。回滚时新增查询参数会被忽略或按无效上下文处理，不修改路径数据。

## Open Questions

无。未解锁节点的产品规则由本变更确定为“可查看真实锁定原因，不可直接开始”，与现有路径中心的锁定节点规则一致。
