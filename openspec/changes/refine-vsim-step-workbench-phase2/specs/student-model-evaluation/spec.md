## ADDED Requirements

### Requirement: 四船（055 / LNG / 雪龙 2 / 天鲸号）评估指引、级联依赖与方案锁定一致闭合

共用评估工作台与各船课程控制台在 055 驱逐舰、LNG 运输船、雪龙 2 破冰船与天鲸号绞吸挖泥船的各教学步序中 MUST 保持一致的通道映射、级联伺服前置引导与控制器/方案参数锁定语义，防止学生在未冻结前置模型前误入无法通过验收的运行或在不同步序间遗漏必填校验。

#### Scenario: 级联模型、双通道联合模型与风流方案对比闭合校验
- **WHEN** 学生在 055 第 9–19 步选择控制模型或在第 10 步预测、在 LNG 第 16 步完成风流干扰靠泊对比、在雪龙 2 选择开水/冰区模型、或在天鲸号第 15/19 步引用前期方案
- **THEN** 缺省前置冻结模型时控制台 MUST 原位指明前置冻结步序与对应模型通道
- **AND** 055 驱逐舰运行步（非分析/非报告步）缺失 `prediction` 与 LNG 第 16 步提交两套完全相同参数运行时，系统校验 MUST 拦截并指出具体缺口。
