## Purpose

为受治理的常规练习错误选项提供可审计的唯一错因证据，使微辅导只基于当前、审核通过且内容匹配的归因开展。

## ADDED Requirements

### Requirement: 合格 practice 错误选项具有唯一且当前的归因

系统 SHALL 为固定 v1 分母中每道合格 practice 题的每个错误选项维护一条归因记录。每条记录 MUST 绑定 `catalogItemId`、当前内容哈希和错误选项键，并且恰有一个已登记学习目标、一个 active 规范知识节点、一个受控错因标签和非空归因版本。

#### Scenario: 当前错误选项有审核归因

- **WHEN** 合格 practice 题的错误选项与归因目录中的题目 ID、内容哈希及选项键精确匹配
- **THEN** 系统将该唯一记录作为该选项的归因证据
- **AND** 覆盖审计不因该选项产生 `ATTRIBUTION_UNCERTAIN`

#### Scenario: 正确选项不被归因

- **WHEN** 目录记录指向合格 practice 题的正确选项
- **THEN** 系统拒绝该记录
- **AND** 不得将正确作答转换为微辅导归因

#### Scenario: 内容或审核状态发生漂移

- **WHEN** 归因记录的内容哈希不等于当前目录项，或关联题目不再是当前审核通过的合格 practice 题
- **THEN** 系统不使用该记录
- **AND** 覆盖审计及运行时均以受控不可用状态处理该错误选项

### Requirement: 归因记录保留受治理的审核证据

每条归因记录 SHALL 保存证据摘要、限制说明和目录版本，且这些字段 MUST 为不包含题干、选项文本、正确答案或学生数据的受治理说明。目录加载 SHALL 拒绝重复的题目 ID、内容哈希与选项键组合。

#### Scenario: 重复选项归因

- **WHEN** 同一题目 ID、内容哈希和错误选项键出现多条归因记录
- **THEN** 系统将该选项视为归因不确定
- **AND** 不得依据任意一条记录继续编排微辅导

#### Scenario: 归因证据缺失

- **WHEN** 归因记录缺少证据摘要、限制说明或目录版本
- **THEN** 系统拒绝该记录
- **AND** 不得以题目级元数据、关键词或默认知识节点补全该记录
