# Proposal: issue-2156-p1 — 统一可复现风浪流、真实观测链和现实因素分级开关

- Issue: #2156（P1，父项 #2146；物理基座 #2153 已闭环）
- 类型: 物理环境与观测链能力（多阶段交付；本 change 覆盖阶段 A：内核模块 + 因素开关 + 种子体系 + 首批算例）

## Why

#2153 落地的六自由度 TruthPlant 当前环境场为 T 级等效（恒流 1.2 m/s + 正弦波浪）。#2156 要求七船长期保留**真实风浪流机制与真实观测链**：教学步骤只改因素开关与操作权限，不删机制；测量经传感器（采样/噪声/偏置/量化/时延/故障）影响反馈，噪声不得只"给图表撒点"。

## What Changes（阶段 A 内核交付）

1. **波场模块 `sixdof/wave.rs`**：带种子 JONSWAP（γ=3.3、σ 前 .07/后 .09、ω .2–2.5、128 等能频段、7 方向 cos² 归一、离散后 Σa²/2=Hs²/16）；水深进入色散/相位/轨道速度（默认 200m，浅水 40/20m 预置）；波面/轨道速度/一阶力共用同一场；二阶 QTF 未就绪显式标 `not_ready`（不伪造慢漂）。
2. **风模块 `sixdof/wind.rs`**：Fujiwara 2005 分量风载（X/Y/N/K，按水上投影，T 级系数）；相对风=真风转船体系−船体运动−ω×安装点；阵风二维 OU（物理时钟 20Hz，τ=10s）；FROM 真北顺时针语义；消融开关语义（`wind_force_enabled=false` 气动归零、模块保留；enabled+真风 0 仍有航行相对气流；关风不删水动力）。
3. **传感器链 `sixdof/sensor.rs`**：N1 九传感器表（航向陀螺 10Hz/转艏率 20/GNSS 5/计程仪 5/IMU 50×2/编码器 50/风 2/桨轴 20）——安装点量测→离散采样→白噪→偏置 OU（按采样 dt 精确离散）→量化→时延队列→(timeStamp, arriveTime, quality)；N0（无误差保留 API）/N2（×2）；F1 航向偏置斜坡/F2 GNSS 缺失（不填 0）/F3 推进扭矩归零（轴系惯性续走）/F4 吊舱角度冻结；风低风速方向 quality 未定义。
4. **流场语义**：恒定水平流空间均匀时间恒定（W 表 C1/C2），局部来流统一取自同一流场；对水/对地速度分开输出；不加同义流扰动力（#2153 合同延续）；空间剪切不开放（接口保留，未验证不混入）。
5. **种子体系**：训练 seed 20261106、验证 17/29/43；风/波/各传感器/各故障独立子流稳定派生；关噪声不改波浪序列；30/60/120fps 与 1/8 倍速同输入同结果（随机时钟=物理时钟）。
6. **plant 集成**：`EnvironmentField`（T 级等效）升级为 `EnvironmentState`（真实场：wind/wave/current 分量 + 三级开关），sixdof_runtime 的 disturbance 布尔映射为 E1 组合工况（W1+V1+C1）供在线行为延续。

## Impact

- 代码：`rust/control-engine/src/sixdof/` 新增 wave/wind/sensor 三模块 + plant 环境集成 + runtime 工况映射；测试新增三套算例。
- QTF 二阶、Smogeli 通气、剪切流、真实估计器（Fossen-Strand 观测器）为阶段 B（各船专项/#2157/#2148 联动），首版不开放并显式标注。

## Non-Goals

- 不伪造二阶慢漂/通气/剪切（未验证不开放）。
- 不把传感器数值宣称为实船仪器规格（T 级课程设计）。
- 不实现完整估计器（观测器模板随 #2148）。
- 不动前端页面布局（可见性 UI 随 #2147 接线）。
