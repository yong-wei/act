# 作业批改视觉证据与反馈质量改进交接

## 1. 目标与范围

本后续变更处理正式作业批改的质量和可解释性问题，重点是手绘图、图表、截图及其转换后的证据缺失。它建立在已完成的作业闭环之上，不重新实现作业发布、按题提交、截止门禁、AI/人工批改、教师确认、逐份发布或补交版本隔离。

目标是让视觉信息以受控、可定位、可审计的方式进入评分证据，并逐步产出教师可审核的 PDF 批注。当前不承诺改变 Qwen 的评分方式，也不以流程闭环通过代替评分质量通过。

## 2. 已完成基线

- OpenSpec 变更 `add-assignment-ai-grading-loop` 已完成全部阶段并通过真实教师、学生账户的闭环验收：AI 与人工批改、教师确认、逐份发布、学生受控读取和补交增量均已验证。
- 教师批改控制台已支持“全选待批改学生／取消全选”；它只操作当前仍具备 AI 批改资格的学生。
- 作业级人工快照使用完整且稳定的 attempt-vector；补交后不会复用旧操作或覆盖已确认、已发布结果。
- 当前闭环保证流程、权限、审计和发布隔离正确；它不证明任何模型在人工评分基准上的准确率达标。

## 3. 40 份 T2 实验事实

- 正式实验数据由 40 个匿名样本组成，每个样本有 `T2-1`、`T2-2`、`T2-3`、`O2` 四题；人工答题记录仅用于本地对比分数，不进入 Provider、ZIP、Git 或模型上下文。
- 实验配置为每题三次独立运行；理论规模为 40 × 4 × 3 = 480 次，其中调优集 28 个样本对应 336 次执行，12 个隐藏样本保持密封。
- 已记录的 T2-3 问题包括人工基准与量规可能不一致，以及视觉证据波动；这只能说明存在待诊断风险，不能直接证明 Qwen 是唯一根因。
- 会议反馈表明，AI 多次评分方差较小，而与人工分数差异较大的案例集中于含手绘图的作业。因此后续优先验证视觉证据是否丢失、失真或未被评分模型消费。

## 4. 当前技术事实

### 4.1 Word 与 PDF

- 当前 Word 批改不是将原始 Word 直接交给评分模型。`.doc` 先规范化为 `.docx`；系统解析正文、公式和内嵌图关系，并由 LibreOffice 渲染 PDF、映射页面与证据块。
- 转换结果保存为规范 Markdown、证据块和可选的渲染 PDF。评分提示词使用题目、冻结量规和 `AnswerEvidence` 证据块，不使用原始 Word 或渲染 PDF 文件。
- Word 内嵌图片会被提取并参与完整性检查，但当前主批改链路不会将其作为视觉输入直接传给 Qwen。纯扫描式 Word 因没有可提取文本或公式而应被阻断或转教师复核。

### 4.2 独立图片附件

- 单独上传的 PNG/JPEG 由受控转换链路处理；在策略允许时，Mathpix 将图片转换为 Markdown、文本块、页码和边界框，再并入题目证据。
- 当前评分模型主链路读取的是转换后的 Markdown 和证据块，而不是原始图片。因此图片转换失败、描述不足或图形语义无法文本化时，会直接影响评分依据。

### 4.3 批改痕迹与界面

- 当前已具备评分、教师审核、确认、发布和部分文本反馈链路；完整的“分段评语—证据位置—PDF 页内批注”尚未形成正式交付。
- 会议中“一键批改不可见”尚未绑定到具体页面、作业状态和日志证据。正式作业控制台已有批改入口；后续必须区分它与实验室或历史页面的显示问题。
- 教师与学生可见界面仍需审查并清理内部字段、样例账号和非业务化术语。

## 5. 已确认的业务决策

- 视觉证据不足时，优先标记待复核或转人工，而不是生成看似确定的 AI 结论。
- Word 与 PDF 应收敛到同一份规范 PDF 审阅表示；但“转为 PDF”本身不解决问题，必须保证视觉信息及其定位进入受控证据链。
- 旁路多模态模型只能在外部处理策略、脱敏投影、保留期限、删除机制和审计字段齐备后启用；其输出是带来源与置信度的证据，不是不可质疑的事实。
- 评分结果的实现顺序固定为：分数、文本化总评、分段评语、证据位置批注、PDF 页内批注。
- 模型质量实验和正式作业发布仍由教师确认门禁隔开；AI 结果不得自动发布给学生。

## 6. 禁止事项

- 不得把人工答题记录、学生身份信息、原始作答内容、本地路径或 API 凭据写入实验报告、调试日志、前端或外部 Provider。
- 不得为方便演示而解封隐藏集、改写历史实验结果、忽略失败样本，或用截图替代可复现的指标与链路证据。
- 不得仅调整 Qwen 提示词或模型参数就宣称解决手绘图问题；必须先确认视觉信息是否已进入评分证据。
- 不得将视觉描述、AI 草稿、内部模型信息或教师修改历史直接暴露给学生。
- 不得因为新增视觉链路而改变截止时间、补交、确认和发布的既有语义。

## 7. 风险与待决问题

- 手绘图的识别可能产生幻觉、遗漏、错误归属或页码定位偏差；这些必须作为可见局限性进入教师复核，而非被静默吞掉。
- 使用外部多模态模型将新增数据治理、调用成本、删除确认与失败重试要求；具体 Provider 和模型尚未选定。
- T2-3 的误差可能还包含人工基准、量规或公式转换因素。视觉链路是高优先级假设，不是已证实的唯一原因。
- 完整 PDF 批注依赖稳定的题目、块、页和区域锚点；无法精确映射时只能受控退化到块或页级。
- 隐藏集尚未作为本变更的质量验收输入使用；任何执行前必须冻结候选方案与通过阈值。

## 8. 建议的启动顺序

1. 执行 `tasks.md` 阶段 0：完成匿名化的 T2-3 证据链诊断和视觉样本分类。
2. 由负责人根据诊断确认视觉证据契约与旁路模型策略，再进入阶段 1。
3. 仅在调优集完成对照实验并满足预先冻结的阈值后，考虑一次隐藏集验收。
4. 视觉证据链稳定后，再推进一键批改显示诊断、界面治理与 PDF 批注。

## 25. 一键批改链路与 v15 前置调整（2026-08-20）

- 已确认“一键批改”指教师只需一次操作，而不是限制后台只能调用一个模型。现有职责分离应保留：后端以确定性工具完成 Word→Markdown、Word→规范 PDF、PDF 页渲染；视觉模型基于页图生成可盲审的描述、位置与局限性；评分模型基于题目、量规、Markdown 与视觉描述生成评分草稿；后端再生成供教师确认的 PDF 批注。任何环节均不需要人工逐页映射。
