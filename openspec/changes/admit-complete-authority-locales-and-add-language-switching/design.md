## Context

当前 Authority 中文标签解析器绑定 `zh-CN` 术语组件，但缺少首选中文行时仍可回退到发布 `display_name`；该字段可能为英文，所以现有“可解析”不等于“完整中文”。现行 snapshot-bound overlay 可修复个别历史记录，但用户已经明确翻译作者权属于图谱项目，本项目不得用本地补丁替代新版完整翻译。

未来图谱发布将提供中文和英文。本项目需要提前定义可验证的语言就绪合同及 UI 切换边界，同时继续遵守不可变发布、精确身份、候选与生产分离和不自动追随 latest 的规则。

## Goals / Non-Goals

**Goals:**

- 只接收图谱发布中身份绑定、覆盖完整且通过安全校验的中文显示内容。
- 为同一发布建立可选英文完整性资格，不允许部分字段跨语言回退。
- 让新版图谱默认中文，并在双语就绪后无状态污染地切换到英文。
- 让所有 Authority 来源的领域、节点、类型、关系、说明、别名和可读来源使用同一 locale。
- 让 ACT 自有的图谱控件、筛选、图例、空状态、错误和无障碍提示使用同一 locale 的完整界面词表。
- 保留当前已激活发布，直到未来精确版本通过独立候选、资格和激活流程。

**Non-Goals:**

- 不在 ACT 仓库编写、修订或机器翻译 Authority 文本。
- 不把历史 v0.18/v0.22 本地 overlay 认定为新版完整语言发布。
- 不自动下载或激活图谱项目的未来版本。
- 不要求所有 ACT 自有课程资源立即翻译；缺少所选语言的可选本地内容不得混入另一语言。
- 不改变 Canonical ID、关系、Teaching Projection、资源绑定或学习状态。

## Decisions

### 1. 使用发布随附的不可变语言就绪清单

图谱发布提供版本化 locale manifest，绑定 Aggregate/Component Manifest、Authority snapshot/release、语言组件标识与摘要。清单列出适用 locale、各必需语义类别的确定性分母摘要和完整性结论；ACT 重新计算并生成自己的接收 receipt，不能只信布尔声明。

分母至少覆盖活动领域目录、可展示对象名称与说明、类型词、关系词与方向说明、批准别名及用户可读来源文本。可选知识媒体单独声明语言可用性，不通过缺失媒体阻断基础 Authority 语言资格。

### 2. 中文完整性是新版发布接收门禁，英文是独立可选能力

任何准备进入新版产品的未来 Authority 发布必须通过 `zh-CN` 全分母验证；缺失、重复、不安全、身份漂移或跨发布内容使候选不具备产品资格。现有生产发布可继续服务到明确切换，不因新门禁被后台隐式替换或停用。

`en` 使用相同分母和安全标准独立验证。只有同一 Authority envelope 的 `zh-CN` 与 `en` 都通过时才声明双语就绪；英文失败不否定已合格中文，但必须保持英文选项不可用。

### 3. 完整语言发布不得使用 ACT 本地翻译覆盖补足分母

资格计算只接受发布 manifest 声明并被 admission 绑定的语言组件。历史 snapshot overlay 和 Formula record pin 可以继续解释既有发布，但不得计入未来 complete-locale 分子，也不得把本地补丁写回或伪装成图谱发布内容。

该边界选择等待上游正式发布，而不是获得更快的本地中文覆盖，以保持图谱项目作为标签、说明和工程语义的唯一编辑权威。

### 4. locale 在服务端解析并进入分片缓存身份

客户端只可请求当前活动发布声明的 locale；服务端仍自行解析 Authority identity，并根据 locale 返回该身份下唯一的显示投影。root、domain、family、neighborhood、detail、search 和媒体元数据的 cache key 与 envelope 都包含 locale profile identity，跨 locale 响应不得合并。

语言中立数学表达必须由上游清单显式标记或由受信 Formula 类型合同确定，不能通过字符形态猜测。其周围的名称、说明和无障碍文本仍按 locale 验证。

### 5. 语言切换是本地呈现状态，不是发布或学习状态

新版图谱显示“中文 / English”控件并默认 `zh-CN`。切换时保留活动领域、节点选择、关系族、已加载逻辑分片、坐标、缩放、平移和检查器阅读位置，只重新解析或请求对应 locale 的显示投影。

未双语就绪时，英文选项保持不可选并给出中文原因；不得先切换再用中文或英文逐字段补洞。切换不写用户画像、学习事实、selector 或服务器 graph mode。

### 6. ACT 只翻译产品界面词表，不翻译 Authority 语义内容

按钮、筛选、图例、载入/空/错误状态、焦点说明和其他固定产品文案由 ACT 的版本化图谱界面词表提供。英文可用性要求该词表在所有登记 key 上同时具有中文和英文，并通过缺项与未知 key 门禁；该词表不能包含或覆盖领域名、对象名、关系语义、概念说明或来源内容。

### 7. 可选 ACT 内容按自身语言声明呈现

知识卡、信息图、资源标题或其他 ACT 自有内容若没有当前选择语言，则整体省略该可选块或显示当前语言不可用状态；不得把另一语言正文插入已选择语言的 Authority 详情。资源启动本身仍可用，且其身份和绑定不因语言改变。

### 8. 未来实际发布仍需独立接入与激活变更

本变更只实现通用接收、验证和切换能力。图谱项目完成新版语言发布后，ACT 必须另行提出精确版本的候选导入、资格验证和生产激活；本系列不预填未知 release ID、哈希、计数或上线授权。

## Risks / Trade-offs

- [完整分母定义遗漏某个产品表面] → 由静态表面清单、DTO 字段审计和浏览器 DOM/ARIA 扫描共同验证，未知字段使资格失败。
- [当前发布无法通过新门禁] → 门禁仅作用于未来候选资格，现有生产保持不变，直到经授权切换。
- [英文切换导致重复加载和缓存膨胀] → 逻辑对象缓存与 locale 显示缓存分离，按活动发布和两个受支持 locale 有界存储。
- [语言中立公式被误当英文缺口] → 只接受明确 Formula/manifest 分类，普通文本不自动豁免。
- [可选本地内容在英文模式下缺失] → 以块级语言状态诚实省略，不混入中文正文，也不阻断图谱关系探索和资源启动。
- [固定图谱控件仍为中文而语义内容已切换英文] → 将完整 ACT 图谱界面词表加入英文就绪门禁，并对 DOM/ARIA/tooltip 做选定语言扫描。
- [上游 manifest 结构尚未发布] → 本地实现以版本化 schema 和 fixture 固定合同；真实版本接入必须重新核对并可通过独立 change 扩展，不猜测实际 ID。

## Migration Plan

1. 定义 locale manifest、ACT qualification receipt 和安全投影 schema，并用完整/缺失/重复/漂移 fixture 验证。
2. 扩展服务端 locale resolver、分片 envelope 和缓存隔离，同时保持当前 `zh-CN` 默认路径兼容。
3. 建立 ACT 图谱界面中英文词表及完整性门禁，在依赖变更稳定的新版画布上接入语言控件和状态保持测试；英文未就绪 fixture 必须不可选择。
4. 运行 API、客户端、无障碍、DOM 混合语言扫描、typecheck 和构建验证。
5. 等待图谱项目正式发布后，以新的精确版本 OpenSpec 执行候选导入、资格和生产切换。
6. 回滚只移除 locale 能力与控件；不修改当前 Authority selector 或任何发布内容。
