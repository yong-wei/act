## Why

现网七船虚拟仿真在评估接入、步骤引导、多模态交互与提交校验上存在四类影响教学体验的核心缺陷：共用评估工作台未按船型和步骤裁剪且无运行记录时回退显示无关「舵角通道」和「冻结的舵机模型」、空列表旁缺少前置冻结提示；步骤「本步目标」与「本步要看」大量同源重复且充斥名词缩写，控制面板与评估面板在非对应步骤暴露无关控件；除 055 外的六船第 19 步统一硬注入空白手绘板而缺少带标准工程坐标系的预测/分析双向多模态体验；集装箱船、邮轮、981 平台及 LNG 船漏接 `prediction` 提交校验及部分第 16–19 步控制项。本变更作为两期重构的第一期（Phase 1），旨在根治七船共用评估底座与前后端漏接控件，重构带工程坐标系的多模态手绘与三段论结构化表单框架，并率先完成集装箱船、邮轮、981 半潜平台 60 步的全量教学与交互升级。

## What Changes

- **全七船共用评估工作台按船型与步序重构（`VesselModelWorkbench` / `DpModelWorkbench` / `VesselCourseEvidencePanel`）**：
  - 引入船型—步序策略真源（`vessel-workbench-policy.ts`），显式传入 `courseKey` 与 `stepSequence`，根除无运行记录时邮轮/雪龙 2/天鲸回退显示舵角通道，以及集装箱/LNG/天鲸空态误显「冻结的舵机模型」的缺陷。
  - 将辨识冻结与独立对照按步骤彻底拆开（独立验证步隐藏“辨识并冻结模型”按钮，非辨识/验证步仅保留对应评价与物理诊断卡）；雪龙 2 级联验证明确展示「冻结的吊舱伺服模型」；邮轮第 2 步自由衰减隐藏第 3 步 `freeDecayRunId` 引用框，第 3 步显式提供自由衰减预览。
  - 在空运行列表、空学生模型列表及空伺服模型列表旁直接说明前置步骤与待冻结模型类型，坚持“辨识失败绝不替换默认参数”。
  - 统一七船评估区接入（补齐天鲸号轮次切换/新建/导览锁定；移除 055 旧版冗余报告列表；修复集装箱船错用航向/横摇评估卡与双栏重复天平）。
- **步骤简报、控制收敛与多样化“预估—采集—解释”三段论底座**：
  - 将任务简报拆分为独立清晰的「本步目标（动词态+理解要点）」「操作步骤（编号指引）」「本步重点观察（物理量与现象）」与「本步工况（自然语言去内部代码）」四段式结构。
  - 重构 `StepWorkbenchSpec` 与结构化三段论组件（`StepPredictionStage` / `StepObservationStage` / `StepInterpretationStage`）：运行前预测支持单选、多工况排序、数值靶标与坐标系预测草图并放入 `controls` 之前；运行中/后读数支持通道配对、单步结构化指标、多工况对照槽表（按工况自动关联运行记录与曲线一键读取/拾取）与工件绑定；因果解释提供分步写作指引与核对清单。全部通过扁平 `Record<string, string>` + 摘要合成兼容现有 IndexedDB、`stepDrafts`、CAS `act.vessel-step-work.v1`、教师端复核及 iLab-X 账本。
- **带工程坐标系的多模态 `SketchPad` 与识图 API 升级**：
  - **BREAKING（行为变更）**：移除“非 055 六船第 19 步强制通用手绘板”的硬编码注入，改为按船型教学节点精确挂载 **运行前预测手绘**（识图后提供苏格拉底防剧透反馈，并在运行完成后支持叠加实船实测曲线与手绘靶标比对）或 **模型分析手绘**（识图后叠加 `StudentModel` 解析特征）。
  - 为 `SketchPad` 增加 6 套带刻度、单位与物理临界标记（如 `t=20s`、`t=180s`、`1.0x`、井口 `1.0m/1.5m/2.5m` 警戒圈）的 SVG 工程坐标系底板、撤销上一笔与双色笔触，上传视觉模型仅合成“底图坐标系 + 学生笔迹”，严禁污染第三方参考/实测曲线覆盖层。
- **三大核心船（集装箱船 / 邮轮 / 981 平台）60 步全量重构 + 全船漏接校验/控件补齐**：
  - 逐一重写集装箱船、邮轮、981 平台各 20 步（共 60 步）的目标、操作步骤、观察重点、纯中文工况、按步收敛/锁定控制面板及三段论表单。
  - 一并修复集装箱船（步 7–8 单模型 PI 免强选 3 模、步 17–18 补回 `filterTauS`、步 19 锁定冻结方案）、邮轮（`CruiseRollDesign` 传入真实 `notch`、步 18–19 锁定联合参数）、981 平台（步 4/5 移除多余模型框、步 11 锁定步 10 控制器、步 19 同步 `powerBudgetMw` 并锁定）、LNG 船（步 16 补回静水方案引用、评估按步收口）以及 4 船缺少 `answers.prediction` 提交校验的问题。
- **明确非目标（Phase 2 承接）**：
  - 055 驱逐舰、LNG 船、雪龙 2、天鲸号其余 80 步的完整文案重写与全步进精细控制/表单改造留待 Phase 2 实施；不重建 Rust/WASM 二进制，不修改 Prisma 数据库表结构。

### Modified Capabilities
- `student-model-evaluation`: 增加共用学生模型评估工作台对 `courseKey` 与 `stepSequence` 的感知要求、七船合法通道/结构/对照模式边界、仅 055 与雪龙 2 显示对应伺服选择器、空运行不回退舵角通道、空列表前置步骤引导及辨识与独立验证按步分离约束。

- **受影响代码**：`src/features/ilab/sketch-plots.ts`、`src/features/ilab/sketch-recognition.ts`、`src/app/api/simulations/sketch-review/route.ts`、`src/resources/simulations/experiments/` 与 `src/resources/simulations/simulations/` 下共用评估工作台、曲线组件、多模态手绘板、三段论表单、步骤规约与核心三船/跨船控制及仿真页面。
- **兼容性边界**：仅扩展前端 `VesselStep` 可选字段并维持 `answers: Record<string, string>` 扁平契约，与 `src/features/ilab/course-attempt-validation.ts`、`stepDrafts`、CAS 工件、教师复核及 iLab-X 回传完全向后兼容。
