# Change: Integrate diagnosis outcomes and make report delivery print-only

## Why

教师班级诊断已经区分“未接入”和“无结果”，但原有受治理输入没有读取作业与班级测验的合格结果；诊断报告交付页同时提供打印和直接导出 PDF，当前产品只需要保留打印。

## What changes

- 将审核通过的作业结果与带班级绑定的测验会话冻结到班级诊断输入。
- 将两类结果加入模型工具审计、持久化引用校验与报告覆盖摘要。
- 教师与学生安全交付版均移除 PDF 导出入口和其前端请求，只保留浏览器打印。
- 教师报告级处置始终提供现有备课工作台入口，避免班级报告未映射知识节点时没有备课跳转。

## Non-goals

- 新增作业或测验的编排、发布界面。
- 向模型、报告或页面公开原始作答、选项、附件、评语或学生身份。
- 删除既有 PDF 产物、历史导出审计或已发布的服务端 PDF 接口。
