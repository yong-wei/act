## Context

作业提交具备冻结班级归属、版本与审核状态。自适应测验会话本身可能是个人练习，只有含 `diagnosis-class-assessment-session.v1` 元数据且内容摘要可核验的会话才属于班级测验。诊断生成必须冻结输入，并在报告持久化时重新验证证据范围。

教师和学生报告复用同一个交付视图。PDF 下载是可选参数，教师模式不应渲染或调用它；学生安全模式继续使用现有 PDF 入口。

## Decisions

1. 作业只读取 `REVIEWED`、存在审核总分、冻结班级一致且版本发布时间和审核时间均不晚于证据截止的提交。
2. 测验只读取具有有效班级标识和题目内容摘要的会话；普通自适应练习不作为班级测验结果。
3. 冻结输入只保存来源 ID、学生 ID、版本摘要、聚合分数和时间。原始作答、正确答案、附件、评语不进入模型提示或报告。
4. 作业和测验覆盖人数由服务端根据冻结输入计算并覆盖模型输出，避免模型编造覆盖统计。
5. `DiagnosisReportDeliveryView` 的 PDF 入口只在学生安全模式且传入 PDF 地址时出现；教师页面不再传入该地址，打印维持不变。

## Verification

- 预检覆盖作业与测验的输入摘要、变化检测以及原始答案隔离。
- 持久化覆盖两类引用在班级、成员和证据截止时刻上的再校验。
- 教师历史页覆盖 100/100 的作业和测验投影。
- 教师交付视图断言保留“打印”且不包含“导出 PDF”；学生安全视图仍可显示 PDF 入口。
