## Context

现有 `/textbook-citations/[...targetPath]` 页面直接解析物理 runtime 路径并显示单个 Markdown 文件。它没有全书章节树，URL 与旧 section/chunk 文件绑定，也不能稳定定位教材内部的公式、插图或表格。新版结构运行态已经提供书籍、版本、层级单元和片段锚点，可作为统一阅读边界。

本变更实现阅读器和路由，但控灵引用切换由最终集成变更负责。

## Goals / Non-Goals

**Goals:**

- 为全部运行态教材提供同一套双栏层级阅读体验。
- 让同一稳定 URL 同时支持应用内弹窗、刷新、直接访问和分享。
- 精确定位结构单元及其公式、插图或表格锚点。
- 在服务端执行登录和课程访问权限检查。

**Non-Goals:**

- 不提供旧 section/chunk 路由重定向。
- 不建立全文搜索、批注、书签或教材编辑器。
- 不显示检索窗口、嵌入文本或机器辅助描述为普通教材正文。
- 不在本变更中修改控灵引用协议。

## Decisions

### 稳定 URL 使用语义结构路径

公开地址采用 `/textbooks/{bookId}/{edition}/{...unitPath}`，片段锚点使用 URL fragment。服务器只从新版 runtime 索引解析书籍、版本、单元和片段，不接受任意文件系统路径。

### 同一路由支持模态和独立页面

Next.js 拦截式/并行路由在平台内点击引用时打开可关闭模态；浏览器地址同步为教材 URL。关闭模态恢复来源页面与地址。直接访问或刷新相同 URL 时由普通页面路由渲染全页双栏阅读器。

### 导航与正文共用服务器投影

服务器读取章节树和当前单元，输出最小权限内的阅读投影。左侧导航按层级展开并保持当前路径，右侧使用受控 Markdown/媒体渲染器显示单元正文。片段锚点在渲染后聚焦并滚动到可见区域。

### 权限在正文读取前执行

访问者必须登录并通过现有课程访问边界。客户端不能通过猜测 URL 读取未授权正文；失败时返回受控的登录、禁止或不存在状态，不泄露物理路径。

## Risks / Trade-offs

- [拦截式路由关闭后恢复错误页面] → 使用框架路由历史和来源 URL 合同测试覆盖直接访问、应用内打开与刷新。
- [大型章节树增加首屏负担] → 只加载轻量树元数据和当前单元正文，其他正文按导航请求读取。
- [片段锚点缺失] → 保持当前结构单元可读，并将片段定位标为受限；不跳转到猜测位置。
- [旧链接失效] → 本系列明确不承担旧映射；最终切换前完成所有平台消费者迁移。

## Migration Plan

1. 使用 v2 测试运行态实现服务器解析器和权限边界。
2. 构建共享双栏阅读组件、独立页面和拦截式模态路由。
3. 覆盖章节导航、片段定位、关闭恢复、直接访问和未授权访问测试。
4. 保持现有控灵链接不变，等待最终集成变更原子切换。
