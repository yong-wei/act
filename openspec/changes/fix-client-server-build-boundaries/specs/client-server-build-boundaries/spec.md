## Purpose

确保浏览器可达的教学、作业与图谱页面只依赖可在浏览器执行的模块，使生产构建不会因 Node 专用运行时导入而失败，同时保持服务端的数据完整性与页面行为。

## ADDED Requirements

### Requirement: 浏览器模块与 Node 运行时边界

系统 SHALL 将浏览器可达模块所需的契约、筛选和展示逻辑与 Node 专用的加密、文件系统及路径解析逻辑隔离。

#### Scenario: 学生作业页面构建

- **WHEN** 生产构建打包学生作业工作区或作答编辑器
- **THEN** 其导入链不得包含 `node:crypto`
- **AND** 原有的文件类型与大小校验保持可用

#### Scenario: 互动课程图谱抽屉构建

- **WHEN** 生产构建打包互动课程的学生或教师页面
- **THEN** 其导入链不得包含 `node:fs` 或 `node:path`
- **AND** 课程包范围与知识抽屉条目仍按既有运行态数据生成

### Requirement: 服务端完整性行为保持

系统 MUST 在服务端继续生成不透明对象键、提交散列、题目快照及目录选择签名，并使用现有的完整性校验语义拒绝篡改数据。

#### Scenario: 服务端处理受保护的作业数据

- **WHEN** 服务端创建、读取或验证提交对象与题目快照
- **THEN** 它继续使用加密散列和签名校验
- **AND** 完整性校验失败仍返回既有领域错误

### Requirement: 生产构建门禁

系统 SHALL 允许受影响页面通过默认与 Webpack 生产构建门禁。

#### Scenario: 执行生产构建

- **WHEN** 在依赖和生成产物齐备的工作树执行默认构建或 Webpack 构建
- **THEN** 构建不会因浏览器包解析 Node 专用模块或 App Route 非法导出而失败
