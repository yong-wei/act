## Context

2026-09-09 生产应用为 e1c25fff，活动 Authority 仍为 r4/e2d8b92f，英文登记已为 r6/b7c6992d。生产领域教学层仅 11 核心、7 关系；本地已完成 376 核心、374 关系及后继资源绑定。时域概览 153 点被点击逻辑裁为 24 点，首帧遮罩要求完整概览而无法关闭。详情的 missing 富文本对象遮蔽已有名称、说明。

实施工作树为 act-resource。主工作树并发工作不纳入本次修改。既有本地资源和教学成果必须进入候选输入，不能用旧生产材料重建后覆盖它们。

## Goals / Non-Goals

**Goals:** 固定已显示布局、可靠浏览详情、完整课程先后修和一次完整一致的生产交付；通过机制阻止再次部分更新。

**Non-Goals:** 不修改上游工程事实，不根据名称制造 canonical 等价，不把非课程工程知识强制编入课程，不以跳过资格或身份校验恢复显示。

## Decisions

1. **完整视图会话。** Active 工作区持有按 Authority/catalog、领域、维度分组的坐标及相机。保存所有已初始化节点而非仅拖拽 pin。筛选隐藏不清除坐标，新增邻域只安置新点，切回领域恢复原会话。拓扑/展示变化不得隐式 fit；首次进入、首次切换维度、显式适配或重新布局例外。
2. **独立详情状态。** selectedNodeId、inspectorOpen、邻域披露不共用关闭动作。详情头部同步显示名称；富文本 missing 使用同语言纯文本。节点详情及邻域分别加载，过期请求不能覆盖后续选择。原图在增量加载期间保持可见。
3. **筛选反映实际关系。** 一个默认启用的先后修入口控制教学 PREREQUISITE 与工程 prerequisite；相同语义去重展示但保留来源。点击一跳邻域显式披露其发布关系，筛选控件同步状态；不因未打开的全域族过滤而丢边。包含/关联不冒充先后修。
4. **真正三维布局。** 使用已有三维力布局依赖初始化球体/体积种子和三维碰撞；初始计算后固定所有坐标，节点拖动不引发其他节点重排。取消 pin 仅更改 pin 意图，重新布局由显式动作触发。
5. **课程作者决策。** 完整课程蓝图及各单元知识清单构成分母，讲义提供细化证据。作者逐项判断 Authority 映射、课程出现位置、必要或推荐前置、证据与理由。既有绑定是证据之一，不再决定入选资格。保留既有有效关系，替换无证据的自动扩展。生成器检查完整映射、证据、端点、孤立点和 REQUIRED DAG，不自动补连通边。
6. **全站停靠位置。** 在共享控灵 Dock 中使用 Pointer Events 区分点击与拖拽，超过阈值后禁止触发点击；位置跨页面和刷新保存，视口变化后限制在安全区域，提供键盘可操作的恢复默认入口。
7. **完整候选输入及一次验证。** 既有 r6 Authority、完整教学层、课程资源、分片、双语资格、资源索引与兼容性证据共同生成候选。最终文案变更后重建 locale digest。发布器检查完整成果集合及组合身份；禁止应用携带新登记而继续选择旧图谱。应用/Runtime SHA 可以不同，但必须由已验证兼容性证据连接。
8. **生产操作授权。** 用户已明确要求全部已完成的本地教学投影、资源绑定及依赖进入生产。采用现有部署和协调激活流程，先准备不可选候选，再切换兼容应用及数据组合，并核验真实产品路径；保留完整前任用于回滚。
9. **2026-09-09 Authority 缺口裁决。** 完整课程清单仍保留模块 1—5；r6 缺少 MPC、数据驱动控制和强化学习等对象。用户选择先交付现有 Authority 范围，明确保留缺口，不宣称全课覆盖完成。缺失映射记录为 authority-gap，不能使用相近概念伪造映射；本次不扩展 ActKG。

## Risks / Trade-offs

- 课程同名概念有不同来源和定义：逐项记录选择依据，未解决映射阻断对应候选，不猜测。
- 新图谱含更多关系：增量布局固定旧点，真实浏览器验证重叠、帧率、触摸与标签，不只依赖模拟引擎测试。
- 主树仍有并发修改：冻结本次发布输入，发布后新增提交不自动进入候选；对已有本地成果分别记录来源，禁止静默遗漏。
- 旧资格工件与新文案/拓扑不兼容：最终重新生成资格和组合，不原地改写历史 hash。

## Migration Plan

先建立回归并修复 Active 与 Dock，再完成课程作者决策及生成。校验全套候选后执行现有发布流程，逐一复核英文、领域、详情、资源、先后修及活动指针。失败时按既有事务恢复完整前任；不回退单个 selector 形成另一混合组合。
