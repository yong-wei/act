# syllabus-refactor

保留学时、已学知识边界、评分结构、开放题连续演进和人工接受的重要教学取舍。已授权修订直接回写相应蓝图；未决定方案标为草案。资源不强行凑齐，修改必须服务学生能力和可验证的教学目标。

## 按任务读取

- 整课结构：读取 `course-content/syllabus-refactor/blueprint.md`、相关 decisions 与 [课程质量透镜](references/course-quality-lens.md)。
- 模块/课次调整：读取对应 module 与 [工作流程](references/authoring-workflow.md#working-flow) 的相关层级。
- 作业边界：读取 `course-content/syllabus-refactor/homework-framework.md` 和 [作业重构入口](references/authoring-workflow.md#作业题目重构入口)。
- 资源选择：读取 [source-map.md](references/source-map.md)，按候选资源类型加载相关索引。
- 不把单课问题自动扩展为整门课程重构，不要求每次读取所有笔记。

已有未变化的证据可复用。只为会改变目标、授权或重要教学含义的缺失信息提问；普通可逆实现与表达选择自主完成。当前用户明确指令优先于技能建议，项目安全和数据约束继续有效。
