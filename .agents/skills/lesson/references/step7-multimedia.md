# Step 7：多模态资源设计规格

> 目标：扫描讲义和互动课设计文档，识别所有需要媒体支撑的位置，按资源类型和用途输出制作规格，并在完成后将引用路径回写到对应文档中。

---

## 资源分类体系

### 维度一：用途

| 前缀 | 用途 | 引用目标文档 |
|------|------|-------------|
| `h`  | 讲义专用 | `design/handout.md` |
| `ic` | 互动课专用 | `design/interactive-page.md` |
| `sh` | 讲义与互动课共用 | 两处均引用 |
| `cd` | 卡片专用 | `authoring/knowledge/cards/nodes/<node_id>.md` |

> **跨媒介复用原则**：讲义、互动课、知识卡片可复用同一媒体文件。`sh` 前缀表示讲义+互动课共用；若卡片也复用讲义图像，不新建文件，只在 `card-media-plan.md` 的"可复用自"列注明。

### 维度二：生成方式

| 类型 | 判断标准 | 输出内容 |
|------|----------|----------|
| **代码直出图** | 响应曲线、根轨迹、Bode图、各类参数曲线、框图、信号流图等可矢量化绘制的图形 | 图片内容描述 + Python/matplotlib 示例代码 |
| **位图（AI生成）** | 原理示意图、工程场景图、实物/设备图等无法代码直出的图像 | 中文场景描述 + 英文生图提示词 |
| **互动前端绘制** | 互动课中需要随参数变化实时更新的图表（有交互价值） | 前端绘制需求描述（不产生媒体文件） |
| **视频** | 仅出现在互动课中，用于动态演示 | 英文生成提示词（Sora）|

> **互动课静态图判断规则**：若某图在互动课中无需随参数动态变化，按"代码直出图"或"位图"处理，不另起前端绘制需求。

---

## 文件命名规则

```
{用途前缀}-{两位序号}-{简短描述}.{ext}

示例：
  h-01-step-response-family.py        ← 讲义用，代码直出，Python 源文件（→ raw/）
  h-01-step-response-family.svg       ← 对应产出图（→ processed/）
  h-02-ship-bridge-scene.png          ← 讲义用位图（原始 → raw/，处理后 → processed/）
  ic-03-bode-plot-static.py           ← 互动课用静态图，代码直出
  sh-04-second-order-block-diagram.py ← 讲义与互动课共用框图
```

存储路径：`course-content/authoring/lessons/<unit>/media/`
- `raw/`：Python 源文件、AI 生成原始图、录屏母版等
- `processed/`：产出的 .svg/.png，裁剪/压缩后可上线的版本

互动前端绘制需求**不产生媒体文件**，只在 `design/interactive-page.md` 对应步骤中描述。

## 工作流

### 1. 扫描阶段

**同时**读取以下三类文档，识别所有媒体插入点：
- `design/handout.md`（讲义）
- `design/interactive-page.md`（互动课设计）
- `authoring/knowledge/cards/lessons/<unit>/`下各节点卡片（若 Step 4 已登记 `card-media-plan.md`，直接读取）

扫描结果输出为统一资源总表，与用户确认优先级。**同一图像在多处引用时只列一行，"引用于"列注明所有引用位置**：

```
| 编号 | 用途前缀 | 简短描述 | 生成方式 | 引用于 | 优先级 |
|------|----------|----------|----------|--------|--------|
| 01   | sh       | ...      | 代码直出 | handout §2.1 / 卡片：复平面可行域首页 | P1 |
| 02   | h        | ...      | 代码直出 | handout §4例题1 | P1 |
| 03   | cd       | ...      | 代码直出 | 卡片：设计可行域首页（无讲义复用） | P2 |
| ...  |          |          |          |        |        |
```

### 2. 逐项生成阶段

用户确认优先级后，按序逐项输出完整制作规格（见下方格式）。

### 3. 回写阶段

所有资源规格输出完毕后，将引用路径插入对应文档的对应位置：
- 格式：`![图注](../media/processed/{文件名})`（Markdown 图片引用）
- 互动前端绘制需求：在 interactive-page.md 对应步骤的「资源」栏补充 `[前端绘制]` 标注

## AI工具选用指南

| 资源类型 | 推荐工具 | 说明 |
|----------|----------|------|
| 响应曲线、Bode图、根轨迹、参数曲线 | Python + matplotlib | 代码直出，矢量 SVG |
| 框图、信号流图 | Python + matplotlib / tikzplotlib | 可矢量化 |
| 工程场景图、设备实物图 | Midjourney / DALL-E | 位图，需提示词 |
| 原理示意图（复杂） | Stable Diffusion + ControlNet | 可控制构图 |
| 动态演示视频 | Sora | 互动课专用 |
| 实时交互图表 | Recharts / Canvas / D3 | 前端绘制，无媒体文件 |
