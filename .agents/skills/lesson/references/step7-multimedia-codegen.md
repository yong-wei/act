# Step 7A：代码直出媒体规格

> 适用范围：`Octave` 生成的控制图、`tikz-control-draw` 线框图、互动前端绘制需求。

## 适用资源类型

- 时域响应、频域响应、根轨迹、Bode/Nyquist、极点零点、稳定域、参数扫描图
- 方框图、信号流图、电路图、机械结构图
- 互动课中需要随参数实时更新的图表或工作区

## 输出格式

### 代码直出图（控制仿真/计算类）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
资源 {用途前缀}-{序号} | {简短描述}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
文件名：`generate_design_data.m` / `generated-data/{单元编号}-design-data.json` / `render_figures.py` / `processed/{单元编号}-{资源名}.png`
存放：`raw/generate_design_data.m` → `raw/generated-data/{单元编号}-design-data.json` → `raw/render_figures.py` → `processed/{单元编号}-{资源名}.png`
引用于：{文档名} § {章节/步骤}

【图片内容描述】
{说明图片要呈现的内容、坐标轴、曲线含义、标注要求等}

【实现约定】
- `Octave` 脚本负责建模、调用 control 包原生函数并导出 JSON 数据
- `Python/matplotlib` 脚本负责统一排版、字体、线型、网格、留白、摘要框和导出 PNG
- 默认直接从 `templates/octave-design-data-template.m.tpl` 与 `templates/matplotlib-render-template.py.tpl` 复制脚手架
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**硬约束：**

- 时域响应、频域响应、根轨迹、Nyquist/Bode、极点零点、稳定域、参数扫描等控制系统图，默认必须使用 `Octave` 完成计算、仿真与出图。
- 数值图像的最终成图不再直接由 `Octave` / `gnuplot` 输出；统一采用“`Octave` 导出数据 + `Python/matplotlib` 最终排版”的两段式流程。
- 默认字体、线型、网格、颜色、留白和摘要框风格必须与 3-6 单元保持同一套基线，不得为单个课次单独发明新的图面语言。
- 默认优先使用 `Octave` / control 包的原生高层函数完成出图和核验，例如 `step()`、`bode()`、`nyquist()`、`rlocus()`、`lsim()`、`margin()`；除非原生函数确实无法覆盖，否则不得手写底层数值积分、频率扫描或同类替代函数。
- 不得为阶跃响应、频率响应或性能指标等基础能力自造底层数值计算函数。
- 若讲义、互动课或信息图引用同一张控制图，优先复用同一产物，不要重复出图。
- 讲义正文或附录若提供参考代码，默认也应与这里保持一致，统一使用 MATLAB/Octave 形式的 `.m` 文件。
- 默认模板位置：
  - `templates/octave-design-data-template.m.tpl`
  - `templates/matplotlib-render-template.py.tpl`
- 数值图的多子图布局应按图数自适应，不固定成单一 `2x2` 模板。
- 若只有 2 幅图，默认左右并排展示，不额外添加说明文本块。
- 若有 3 幅图，可沿用 3-6 单元常用的 `2x2` 教学图布局：前三格放图，右下角放摘要说明文本块。
- 若图数更多，再按教学逻辑扩展布局，但仍要保持与 `3-6` 单元一致的字体、线型、网格、留白和摘要框风格。

### 根轨迹图专项规范

- 根轨迹数据默认优先由 `Octave` / control 包原生 `rlocus()` 生成并核验，不手搓整套扫描逻辑替代其主流程。
- 若为了统一到 `Python/matplotlib` 版式而自行导出各增益点闭环极点矩阵，必须调用 `.agents/skills/lesson/scripts/root_locus_branch_match.py` 做分支匹配与审计，禁止在课次目录里临时重写根轨迹分支整理逻辑。
- 根轨迹脚本的输入输出格式、视图配置和审计项见 `references/root-locus-branch-match.md`；独立根轨迹图、局部放大图、以及多联/四联图中的根轨迹子图都必须使用这套脚本。
- 对交汇、分叉、回折、离开实轴、接近渐近线等关键区间，必须做自适应增益加密；不允许因采样太疏造成共轭分支在理论交汇点附近错开，或把本应平滑连续的轨迹画成折线误连。
- 每张根轨迹图必须显式检查：开环极点/零点是否全部标出，闭环分支数是否等于开环极点数，共轭分支是否保持对称，远端快速极点附近是否因增益上限不足而丢失终端轨迹。
- 若图中需要展示“全范围根轨迹”以说明快速极点或远端渐近行为，默认优先采用 `rlocus(P)` 自动给出的增益范围生成源数据，不要为了方便排版而先在人为较小的 `K` 上限处截断；视窗范围可以单独收窄，但源数据应完整。
- 根轨迹图中的文本、增益标注、阻尼比线、自然频率线必须避让主轨迹与极点/零点标记；出现遮挡、压线、误指或文字重叠，视为未完成。

### 跨域 `2×2` 图专项规范

- 基本跨域四联图默认顺序固定为：时域响应、根轨迹、幅频图、相频/裕度图。
- 四个子图标题只写基本标题，例如“闭环阶跃响应”“根轨迹”“Bode 幅频特性”“相频特性与裕度”；不写“左上/右上/左下/右下”等方位词。
- 默认版式可采用规则 `2×2` 布局；但若根轨迹存在明显尺度差异，允许改用案例 B 特例布局：左上放时域响应，右上用上下窄图压缩放置幅频图与相频/裕度图，左下放全范围根轨迹，右下放关键区域根轨迹。
- 采用案例 B 特例布局时，正文或说明框必须明确区分“全范围根轨迹”与“关键区域根轨迹”的教学目的，避免学生误以为两图展示的是不同系统。
- 若讲义、互动页或信息图复用同一组跨域图，必须保持子图顺序、标题命名和根轨迹范围定义一致，不得在不同载体中各改一套口径。若其中任一子图是根轨迹，则各子图必须共用同一份 `root_locus_branch_match.py` 输出的匹配后 CSV，只通过视图范围区分全图与局部图。

## 代码直出媒体的额外提醒

- 若互动课中的图只是静态展示，优先沿用讲义已验证产物，不另起前端绘制。
- 若互动课中的图来自 handout 曲线图，则默认不视为“只是静态展示”；应优先设计为可调参数的互动图，并保证默认状态与静态图完全对齐。
- 每张导出图都必须检查坐标轴、图例、文字、箭头与留白，避免“内容对但版式拥挤”的半成品。
- 若信息图中需要嵌入控制图、结构图或参数图，仍按本文件对应类型分别制作，不要把信息图当成豁免区。
