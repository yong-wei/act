# Step 5：BOPPPS 课案设计规格

> 目标：将讲义内容转化为完整课堂教学方案，明确时间分配、互动形式，以及平台操作、AI工具、课堂活动等讲义之外的教学设计。教案是讲义的课堂展开版，不另起炉灶。

## 输出格式

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
BOPPPS 课案 | 单元[编号]：[标题]
课型：[理论/实践] | 总学时：[X]h
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

B｜Bridge-in 场景导入（[X]min）
  形式：[视频导入/问题抛出/演示实验/故事引入]
  内容描述：[具体设计，连接工程场景]
  教师操作：[具体行动步骤]

O｜Objective 课堂目标（[X]min）
  呈现方式：[PPT展示/板书/平台显示]
  目标描述：[用学生视角描述"学完本节，我能..."]
  与全局框架的连接：[今天学什么，在地图的哪里]

P₁｜Pre-assessment 前测（[X]min）
  形式：[平台自适应题目/口头提问/举手投票/同伴讨论]
  测试内容：[前置知识的1-2个关键点]
  根据结果的教学调整策略：[如果大部分学生不会X，则...]

P₂｜Participatory Learning 主体教学（[X]min）
  【按[C/X/D]定制——见下方各类型模板】

P₃｜Post-assessment 后测（[X]min）
  形式：[平台即时题目/随堂小测/出口问题]
  测试内容：[本节1-2个核心知识点]
  反馈方式：[即时平台反馈/教师点评/同伴互评]

S｜Summary 总结（[X]min）
  方式：[教师总结/学生复述/思维导图/框架地图回顾]
  核心要点：[3-5条，对应讲义小结]
  下节预告：[一句话连接下一课]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
课前布置：[预习要求/平台预操作]
课后作业：[作业类型和要求，优先平台自适应题库]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

## P₂ 按知识类型定制模板

### [C] 计算型

```
- 概念讲授段（[X]min）：关键概念和推导
- 例题演算段（[X]min）：教师示例 + 学生练习
- 平台验证段（[X]min）：用平台验证计算结果
```

### [X] 跨域型

```
- 概念引入段（[X]min）：跨域关系的直觉建立
- 平台联动演示段（[X]min）："一动全动"可视化
- 定量关系推导段（[X]min）：公式和适用范围
- 学生自主探索段（[X]min）：给定任务，平台操作
```

### [D] 设计型

```
- 工程任务发布段（[X]min）：问题背景 + 约束条件
- 设计探索段（[X]min）：学生尝试，AI介入
- 方案讨论段（[X]min）：多方案比较，决策逻辑
- 教师总结段（[X]min）：工程判断要点
```

---

## AI工具融入时机标注

在P₂中，明确标注AI工具介入点（对应讲义中的`[AI融入点]`）：
- 何时让学生先自主预测
- 何时打开AI对话（工具调用）
- 何时让学生对比AI输出与自己预测
- 何时组织反思讨论
