# Step 7B：AI 生成式媒体规格

> 适用范围：位图、封面图、讲义信息图、导入视频、课程内容视频、课程音频播客及其提示词。

## 默认新增媒体

## 与 `imagen` 技能的关系

本文件负责课程媒体中的 AI 生成式规格。遇到下列情况时，允许并建议调用 `imagen` 技能直接生成成品图像：

- 讲义导入需要具体场景图，普通响应曲线或结构图不能建立问题情境；
- 需要具体对象、实物设备、工业现场、实验台、控制对象外观等图像；
- 需要用类比图解释抽象概念，例如水箱、弹簧、仪表、通道、地图、阀门、平台、航向等；
- 框图或机制图中需要嵌入具象对象，使抽象信号关系更易理解；
- 代码直出图、Octave 曲线、TikZ 线框图无法表达所需视觉信息。

调用 `imagen` 时，仍要遵守本课程媒体命名和讲义严谨性要求：图片和提示词同时保存，成品文件名带单元前缀；正文必须解释图像承担的概念任务和工程边界。生成式图片不得替代数值验证图或真实计算结果。

### 1. 讲义封面图

- 用于学生版讲义首页、正文之前的注意力引入。
- 在 handout.md 文稿定稿后，调用 `.agents/skills/imagen` 技能一次性成图——图文合并在同一次生成中完成。其他代理调用时使用 `codex exec` 方式。
- 生成流程：文稿最终确认 → 构造图像提示词 → imagen 一次性生成带文字的完整封面图 → 回写 `media/processed/` → 导出正式 PDF。
- 风格：16:9 横向画幅，写实工程摄影质感，低饱和度深色调。不卡通、不抽象、不过度风格化。
- 图像内容：工程现场感——真实的设备、控制室、海面、仪表盘——构图和光影让读者感受到”这个场景正在被控制问题所困扰”。章节标题和一句核心引文作为图像的组成部分在同一次生成中完成。
- 优先级固定为：先工程语境准确，再视觉吸引力，再知识点暗示。

### 2. 15 秒导入视频

- 用于课堂开场或互动课首页的情绪启动。
- 生成导入视频提示词时，默认显式调用 `seedance` 技能。
- 目标不是复述讲义，而是快速建立问题情境、唤起兴趣、形成“为什么要学这一节”的感受。
- 必须先判断最适合该单元核心问题的叙事机制，再决定主题与场景。
- 可选机制至少包括：
  - 冲突型：错误直觉被打脸。
  - 任务型：学生代入工程师。
  - 类比型：生活/具体场景映射抽象概念。
  - 工业型：真实设备、异常、风险。
  - AI/未来型：仅限确有前沿语义的单元。
- 不得为了系列统一而把所有单元套入同一母题，更不得默认回到船舶、海面或抽象工程空间。
- 多媒体阶段交付提示词，不直接生成 `[单元编号]-intro-video.mp4` 成品。
- `[单元编号]-intro-video.mp4` 由用户后续制作完成后，在审查阶段确认可用性。
- 生成完导入视频提示词后，若 `processed/[单元编号]-media.md` 的 `intro-video.mp4` 对应节仍为空，才额外压缩出 1 句导入视频文案；若该节已有内容，则不覆盖。
- 这句文案必须直接描述视频里看到了什么，例如“两个对象同时启动、一个超调一个平稳逼近”这类场景化句子；禁止写成“用导入情境引出……”“引出本课主题……”之类抽象总结。

### 3. 讲义信息图

- 用于学生版讲义正文结束、附录开始前的整页总结。
- 作用是把本单元的概念关系、关键结论、典型图形或辨识线索压缩成一张可复习的信息图。
- `[单元编号]-info.png` 不属于媒体制作阶段必须生成的成品；媒体制作阶段只登记内容要求与审查占位。

### 4. 课程级默认成套媒体

资源规划中必须显式保留待审查占位：

- `[单元编号]-slides.pdf`
- `[单元编号]-course.mp4`
- `[单元编号]-audio.m4a`

其中 `slides.pdf` 与 `audio.m4a` 不属于媒体制作阶段必须生成的成品；由用户后续制作完成后，在审查阶段确认可用性。

若某项不适合当前单元，需在 `multimedia.md` 中明确写出不采用原因，避免默认省略。

### 讲义封面图（位图特例，文稿定稿后一次性成图）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
资源 h-cover | 讲义封面图

文件名：{单元编号}-cover-comic.png
存放：processed/{单元编号}-cover-comic.png
生成方式：handout.md 文稿定稿后，调用 `.agents/skills/imagen` 一次性生成
引用于：handout.md 首页、正文前
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**封面图制作规范：**

- 在文稿定稿后一次性成图，图文合并在同一次生成中完成。不采用后期叠加文字方案。
- 调用 `.agents/skills/imagen` 技能。Codex 原生环境直接 invoke；其他代理通过 `codex exec` 调用。
- 风格参数：16:9 横向画幅，写实工程摄影质感，低饱和度深色调。不卡通、不抽象。
- 图像内容：工程现场感——每一张图像锚定该章的工程语境（以船舶为主线，在相关领域自然扩展）。构图和光影让读者感受到”这个场景正在被控制问题所困扰”。
- 章节标题和一句核心引文作为图像的组成部分在同一次生成中完成。

**提示词示例（1-1）：**

```text
Engineering photograph, 16:9 landscape. View from a ship's bridge looking forward over the bow toward a restless sea. The helm instruments in the foreground show a heading deviation of several degrees. The lighting is overcast, late afternoon, low saturation, deep navy and steel tones. At the lower portion of the image, overlaid directly on the photograph in a clean sans-serif typeface: the chapter title “单元 1-1 | 看见整门课：从反馈思想到控制全景” and below it in smaller text “当环境不断变化时，怎样让一个真实系统持续朝着期望状态工作？”. The text should be white or light gray, placed over the darker area of the image for readability. National Geographic engineering feature editorial style.
```

**提示词要素：**
- 工程场景的具体描述（对象、环境、光线、色调）
- 章节标题和引文的文字内容（英文拼写中文）
- 文字的排版位置和颜色（确保可读性）
- 整体风格参照（National Geographic engineering feature editorial style）

```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**即梦导入视频硬约束：**

- 默认使用中文提示词，不得只堆关键词。
- 默认只采用 `seedance` 的 Agent 模式生成，不再额外交付“分镜图生成提示词”或“图生视频提示词”。
- 一条视频默认遵循“0-3 秒钩子、3-12 秒展开、12-15 秒点题”，且只服务一个核心概念。
- 提示词正文必须写成**分段分镜描述**，按时间顺序写清 3-5 段镜头或情节推进；每段都要能独立看出“谁在做什么、场景如何变化、镜头如何承接”。
- 默认优先使用具体、可拍、可转场的场景，少用公式、板书和抽象悬浮空间。
- 必须明确写出已选定的**唯一风格**，并补一句“为什么该风格适合本课核心问题”；风格可以是电影级写实、2D 动画、3D 动画、木偶、黏土动画等，但不得把多个风格并列成“任选”。
- 题材应围绕当前单元的核心冲突自由选取，不得为了课程系列统一而强行限制在船舶、海洋、海面或驾驶台场景；若实验室、仓储、校园设备、工业产线、课堂演示台更合适，应优先使用这些场景。
- 提示词中必须写清关键动作链、镜头或转场安排、结尾点题方式、音效/配乐气质与必要的负面约束，但不要回到“四格图”“主体形态固定”“四张图保持一致”这类模板。
- 推荐结构为：风格与选择理由 -> 镜头 1（0-3 秒）-> 镜头 2（3-7 秒）-> 镜头 3（7-12 秒）-> 镜头 4（12-15 秒）-> 音效/配乐 -> 负面约束。
- 仅当 `processed/[单元编号]-media.md` 的导入视频节为空时，才从 Agent 模式提示词提炼 1 句主线描述写入，保留主角、动作、冲突和结果，不保留“点题”“引出”“说明本课”这类元话语；若该节已有人工内容，则保持原样。

**推荐写法样例：**

```text
## Agent 模式视频生成提示词

为《自动控制原理》单元“时域响应基础”设计一段 15 秒课程导入视频，采用高质量 2D 动画实验短片风格。选择这一风格的原因是：本节需要把“同样到达目标，但过程差别很大”的动态对比做得直观、轻快、易于学生立刻看懂，同时又保留工程判断的紧张感。

镜头 1（0-3 秒）：实验台上两台同型号小车同时接到到达目标位置的指令，镜头居中推进，先把“同题竞争”的局面立起来。

镜头 2（3-7 秒）：左侧小车冲过目标又回拉，右侧小车还在平稳逼近，镜头快速切换但保持同一空间关系，让观众第一眼看出“快不等于好”。

镜头 3（7-12 秒）：画面切到屏幕上的两条响应曲线，并和两台小车的真实运动做匹配剪辑，突出超调、回落和缓慢逼近的差异。

镜头 4（12-15 秒）：两台车最终都到达目标，画面收束到标题“时域响应基础——从响应曲线到动态性能指标”，留下“都到了，为什么表现还不一样”的问题。

音效/配乐：轻微电机声、计时器提示音、克制的电子节奏，不要热血鼓点。

负面约束：不要海面、船舶、驾驶台，不要大段公式板书，不要花哨科幻 UI，不要真人夸张表演。
```

## AI 工具选用建议

| 资源类型 | 推荐工具 | 说明 |
|----------|----------|------|
| 工程场景图、设备实物图、类比解释图、具象对象嵌入图 | `imagen` | GPT Image 2 位图；适合生成代码直出和 TikZ 难以表达的阅读体验增强图 |
| 讲义封面图 | `imagen` | 位图，文稿定稿后一次性成图，图文合并在同一次生成中完成 |
| 复杂原理示意图 | Stable Diffusion + ControlNet | 可控制构图 |
| 动态演示视频 | `seedance` | 课程视频与导入视频默认统一走 `seedance` Agent 模式 |
| 课程音频播客 | 语音 / 音频工具链 | 文案稳定后再导出音频 |
