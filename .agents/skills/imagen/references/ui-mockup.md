# UI Mockup Reference

Use for app screens, dashboards, website visuals, admin panels, mobile screens, and interface concept images.

## Prompt Structure

1. Product type and user context.
2. Device or surface: desktop, mobile, tablet, kiosk, browser window, app panel.
3. Layout: navigation, content regions, controls, charts, tables, status panels.
4. Visual system: density, color, typography, spacing, icon style.
5. Text contract: exact visible labels or placeholder policy.

## Quality Rules

- Use realistic UI hierarchy and spacing.
- Operational tools should be dense but organized, not marketing-style.
- Avoid unreadable fake text; request short real labels or neutral placeholders.
- Use icons for toolbar actions when appropriate.
- Do not show impossible charts, impossible controls, or decorative panels that do not serve the workflow.

## Prompt Skeleton

```text
Create a polished [desktop/mobile] UI mockup for [product/task].
Canvas: [ratio].
Layout: [nav/sidebar/header/content regions].
Key components: [tables, charts, forms, cards, controls].
Visible text: [exact labels or short placeholders].
Style: [density, palette, typography, icon style].
Negative constraints: no lorem ipsum paragraphs, no fake brand logos, no overlapping text, no decorative filler.
```
