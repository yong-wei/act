# Icon And Symbol Reference

Use for icons, symbolic marks, badge-like assets, simple logos, pictograms, and small visual tokens.

## Prompt Structure

1. Symbol meaning and target use.
2. Shape language: geometric, line icon, filled icon, badge, monoline, isometric, or flat.
3. Required elements and forbidden elements.
4. Background and transparency expectations.
5. Color and stroke rules.

## Quality Rules

- Keep the silhouette recognizable at small size.
- Use one central idea, not a collage.
- Avoid text inside the mark unless the user provides exact initials or label.
- Do not claim final trademark/logo uniqueness.
- Prefer simple shapes and strong contrast.

## Prompt Skeleton

```text
Create a [style] icon for [meaning/use].
Canvas: square.
Core symbol: [one central object or combination].
Shape rules: [stroke/fill/corner/geometry].
Colors: [palette].
Background: [transparent/simple solid].
Negative constraints: no small text, no excessive detail, no trademarked logo, no watermarks.
```
