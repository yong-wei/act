# Product And Object Reference

Use for product shots, object renders, devices, packaging, tools, vehicles, materials, and object-centered assets.

## Prompt Structure

1. Object identity and exact features.
2. Viewpoint: front, three-quarter, top-down, exploded, cutaway, macro, or in-use.
3. Material and surface behavior.
4. Environment and scale cues.
5. Any labels, callouts, or comparison panels.

## Quality Rules

- Make the object inspectable: avoid dark, cropped, blurred, or purely atmospheric views.
- Do not invent brand names, logos, ports, controls, or claims.
- Use realistic shadows and contact surfaces.
- For technical objects, include one small detail inset only if it helps inspection.
- For packaging, keep text minimal unless copy is provided.

## Prompt Skeleton

```text
Create a high-quality image of [object/product].
Canvas: [ratio].
View: [camera angle], [distance], [object orientation].
Required features: [list].
Materials and lighting: [surface, reflections, light setup].
Environment: [background and scale cues].
Visible text: [exact labels or none].
Negative constraints: no invented logo, no unreadable fake text, no extra components, no watermarks.
```
