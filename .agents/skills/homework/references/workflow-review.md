# 题目检查/更新工作流

## 触发条件

用户要求检查或更新已有题目，例如：
- "检查T2-3"
- "T1-2的图片有问题"
- "更新T3-1题面"
- "T2系列所有题目的公式格式有误"

## 检查范围确认

在开始检查前，先向用户确认：
- 需要检查的具体题号（一道或多道）
- 是否有特别关注的方面（图片、公式、逻辑），还是全维度检查

## 检查维度

### 1. 图片充分性检查（新增）

**先于图片质量检查，判断题面和答案是否应有图片但缺少图片。**

#### 题面图片充分性

| 检查项 | 说明 |
|--------|------|
| 是否以文字描述代替曲线图片 | 若题面出现"t=N s 时约为..."、"峰值约为..."、"振荡幅值..."等文字描述曲线数据，**必须补充实际图片** |
| 是否涉及图形认知但无图 | 若题目要求学生分析/观察/描述响应曲线、极点图、Bode 图、奈奎斯特图、根轨迹等，必须有对应图片 |
| 文图一致性 | 题面文字描述的形态特征（如"单调收敛""先快后慢"）必须与图片中可见的形态严格对应 |

#### 答案图片充分性

| 检查项 | 说明 |
|--------|------|
| 草图类题目无参考草图 | 若题目要求学生"画草图"，标准答案必须附对应的参考草图（代码生成） |
| 多情形对比题无对比图 | 若答案描述了多种典型情形（如五种极点配置），必须附对比示意图 |
| 答案描述了图形但无图 | 若答案中出现"响应呈衰减振荡"、"包络线不断扩张"等图形化描述，必须配图 |

发现题面或答案存在图片充分性问题时，在汇报中标注"需要补充图片"，并在用户确认后用 Python (matplotlib) 生成对应图片，更新 `final-package.md` 及已汇编的发布文件。

### 2. 图片质量检查

检查 `selected/assets/` 和 `final/` 中所有已有图片：

| 检查项 | 说明 |
|--------|------|
| 内容正确性 | 图表数据是否与题面描述一致（如极点位置、曲线形状、系统结构） |
| 字体可读性 | 坐标轴标签、图例、标题字号是否足够大（建议 ≥ 10pt） |
| 坐标轴完整性 | 是否有坐标轴标签、单位、刻度 |
| 显示完整性 | 图形是否被截断，边距是否合理 |
| 引用有效性 | `stem.md` 和 `final-package.md` 中的图片相对路径是否能正常引用 |

### 3. 公式格式检查

扫描 `selected/stem.md` 和 `final/final-package.md` 中所有公式：

| 检查项 | 正确格式 | 常见错误示例 |
|--------|---------|------------|
| 行内公式 | `$G(s)$` | `G(s)`（未包裹）、`\(G(s)\)`（LaTeX 格式）|
| 行间公式 | `$$G(s) = \frac{K}{s+1}$$` | 单 `$` 包裹、直接裸写 |
| 分数 | `\frac{a}{b}` | `a/b`（在数学上下文中） |

### 4. 逻辑检查

| 检查项 | 说明 |
|--------|------|
| 题面自包含 | 题面是否引用了项目文件、讲义或外部内容 |
| 评分标准可判分 | 是否有"酌情给分"等模糊表述 |
| 答案覆盖度 | 标准答案是否覆盖题面所有子问 |
| 一致性记录完整 | `final-package.md` 中是否有一致性判定记录 |

## 汇报格式

检查完成后，向用户汇报发现的问题，**不要直接修改，等待用户确认**：

```
## 题目检查报告：T2-3

### 图片充分性问题
- 题面：题目要求分析四条响应曲线，但仅有文字数值描述，缺少实际曲线图 → 需补充生成 matplotlib 图片
- 答案：题目要求学生"画草图"，但标准答案无参考草图 → 需补充答案配图

### 图片质量问题
- step-response.png：坐标轴缺少单位标注（时间轴应为秒 s）
- bode-plot.png：相位图 Y 轴标签字体过小（约 7pt）

### 公式格式问题
- 题面第 3 行："G(s) = K/(s+a)" 未用 $ 包裹
- 评分标准第 2 步：矩阵符号用了 \( \) 格式

### 逻辑问题
- 无

---
共发现 5 处问题（含 2 处图片充分性）。确认修改后我将更新源文件。
```

## 修改流程

用户确认（"可以修改"/"全部修改"/"只修改图片问题"等）后：

### 修改源文件

1. 修改 `.tmp/homework-problem-authoring/<QUESTION_ID>/selected/stem.md`（题面文件）
2. 如有图片问题，修改对应的 `gen_<name>.py` 生成脚本并重新生成图片
3. 修改 `.tmp/homework-problem-authoring/<QUESTION_ID>/final/final-package.md`

### 同步已汇编作业

如果该题已汇编入 `course-content/authoring/shared/homework-problems/T{n}.md`：

1. 更新 `T{n}.md` 中对应题目的题面内容（图片引用路径也同步更新）
2. 更新 `T{n}S.md` 中对应题目的完整内容
3. 将修改后的图片复制到 `assets/T{n}/` 目录
4. 重新生成 `T{n}.docx` 和 `T{n}S.docx`

### 修改完成报告

向用户汇报：
- 修改了哪些文件
- 重新生成了哪些图片
- 是否同步更新了作业文档

## 注意事项

- **先汇报，后修改**：不得在用户确认前直接写入文件
- **修改范围与用户确认一致**：如用户说"只修改公式格式"，不要顺带改其他内容
- **图片重新生成后需目视验证**：运行生成脚本后，检查生成的图片是否解决了原问题
