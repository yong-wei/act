# 代码直出 / SVG 绘制资源规则

## 适用范围

本规则只适用于以下资源：
- matplotlib / p5 / d3 / Python / TS 可直接生成的图
- 页面内可直接用 SVG 绘制的结构图、知识地图、框图、示意图
- 不依赖外部摄影、录屏、人工美术资产的教学图

不适用于：
- 视频录屏
- 实拍图片
- 复杂插画
- 需要外部设计软件手工制作的海报式图片

## 目录约定

### 设计源

原始脚本、参数草稿、辅助模块统一放在：

`course-content/authoring/lessons/<lesson>/media/raw/`

### 运行时产物

页面实际读取的产物统一放在：

`course-content/runtime/lessons/<lesson>/media/`

### 批量生成脚本

建议在仓库根目录新增：

`scripts/generate_<lesson>_runtime_media.py`

职责：
- 统一调用原始脚本
- 统一传递 `--output`
- 统一创建输出目录
- 统一处理 matplotlib 配置目录或环境变量

## 制作流程

1. 从 `multimedia.md` 识别出标注为"代码直出"与"前端绘制"的资源。
2. 为每个代码直出脚本补齐 `--output <path>` 参数。
3. 对共享配置抽公共模块，不在 5 个脚本里重复散写。
4. 先生成到 `course-content/runtime/...`，再接课程页面。
5. 页面接入后，必须验证：
   - 文件存在
   - 页面可读
   - 中文显示正常
   - SVG 或结构图无错位

## 字体规则

### 原则

代码直出图只要包含中文，必须显式配置系统中文字体，不能依赖 matplotlib 默认字体链。

推荐做法：
- 在 `raw/` 目录下新增共享字体辅助模块
- 统一调用类似 `configure_matplotlib_for_cjk()` 的函数
- 明确设置：
  - `rcParams['font.family']`
  - `rcParams['axes.unicode_minus'] = False`
  - `rcParams['svg.fonttype'] = 'path'`

### 为什么必须这样做

如果不显式设置系统 CJK 字体：
- 生成时可能退回到默认西文字体
- SVG 虽然生成成功，但浏览器端中文不显示或显示成方块
- 不同机器上的显示结果会不一致

如果不把 SVG 字体转成 path：
- 浏览器仍然依赖本机字体
- 页面部署到别的设备后可能再次缺字

## 前端 SVG 绘制规则

前端绘制图必须：
- 先按语义拆成几何元素：方块、箭头、回路线、标签
- 不要只凭感觉摆坐标；关键组件位置要有相对关系
- 布局改动后至少做一次截图核对

对于反馈框图、知识地图、结构示意图，重点检查：
- 底部回路线是否与节点对齐
- 标签是否压线或漂移
- `viewBox` 是否足以容纳全部元素
- 移动端缩放后是否仍可读

## 本次已固化的问题与解法

### 问题 1：运行时 SVG 中文文本不显示

出现位置：
- L-2b 的第 7、8、10、11、14 页相关示意图

根因：
- 绘图脚本未显式配置系统中文字体
- 生成时虽然有 SVG，但仍使用了不稳定的默认字体链

解决方案：
- 新增共享字体模块，例如 `matplotlib_font.py`
- 脚本启动后第一时间调用 `configure_matplotlib_for_cjk()`
- 使用系统 CJK 字体
- 设置 `svg.fonttype = 'path'`

验证方法：
- 检查运行时 SVG 中不应残留普通 `<text>` 依赖
- 浏览器实际打开课程页，确认中文文字可见

### 问题 2：系统字体不包含个别符号，重新生成时报缺字警告

本次遇到的字符：
- `✓`
- 下标 `₁ / ₂`

根因：
- 选定系统中文字体能覆盖中文，但不保证覆盖所有特殊 Unicode 符号

解决方案：
- 优先把教学上非必须的特殊字符改写为兼容文本
- 例如：
  - `✓ 理想工作区` → `理想工作区`
  - `p₁ / p₂` → `p1 / p2`

规则：
- 除非教学含义强依赖该字符，否则优先改成兼容写法

### 问题 3：前端 SVG 结构图布局错位

出现位置：
- L-2b 第 6 页反馈框图

根因：
- 回路线、传感器框和 `viewBox` 参数没有联调
- 只看代码没有做截图核对

解决方案：
- 调整 `viewBox`
- 重排底部传感器框坐标
- 重新拉直反馈回路线
- 用截图对照确认而不是只看 DOM

规则：
- 前端 SVG 结构图改动后，至少要做一次截图级核查
