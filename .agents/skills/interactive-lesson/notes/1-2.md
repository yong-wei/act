## 3D 与交互图形合同

- 第 9 步 `magnitude-surface` 必须通过 manifest runtime 的 `compute.panel` + `static-surface-3d` 渲染。
- 浏览器或静态渲染验收 DOM 必须包含：`data-static-surface-3d-panel="magnitude-surface"`。
- 第 9 步曲面数据合同：`49x49` regular grid，`x=[-4,2]`，`y=[-3,3]`，`dx=dy=0.125`；极点标记为 `s=0` 与 `s=-B/J=-2`，标记高度高于截顶峰值。
- 第 9 步 WebGL 呈现需接近 MATLAB 读图方式：jet-like 色带、曲面网格线、底面坐标网格、三维坐标框和以曲面中心为目标的默认视角。
- 第 9 步 fallback 图片为：`/course-runtime/lessons/1-2/media/1-2-fig-08-magnitude-surface.png`。
- 第 10 步 `drag-pole-panel` 必须通过共享 `interactive-figure` 渲染，DOM 标记为 `data-interactive-figure-panel="drag_pole_s_plane"`。
- 第 11 步 `ship-simulation` 必须通过共享 `interactive-figure` 渲染，DOM 标记为 `data-interactive-figure-panel="three_ships_case"`。
- 第 10、11 步不得在 1-2 私有页面中绕过 manifest runtime，也不得降级为纯静态截图。
- `activity.panel` 等 activity runtime modules 不得在静态内容流中渲染成“互动任务”占位；活动入口由学生/教师 activity renderer 承接。
- 图片标题不得使用 module id、block key、panel id 或 spec key；合法英文标题如 `Root-Locus` 必须保留，不得被泛化清洗。
- `content.reveal` 的层级对象可能使用 `content` 字段承载正文，renderer 必须识别，避免 p12 类空白 reveal 模块。
