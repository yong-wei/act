# interactive-lesson

正式页面读取 runtime；内容变更先修作者态和导出链，不手写第二份 runtime 真源。保留师生身份隔离、作答持久、隐藏式 AI 上下文、标准组件和 Rust/WASM 仿真边界。完整交付运行相应严格契约与浏览器验证；局部修复更新受影响证据，不伪造完整或独立审查。子代理仅在已授权时调用。

## 按任务读取

- 局部修复：读取目标实现、对应设计/契约与直接相关测试，不先做整课全量验收。
- 新建完整课程：读取 [实现工作流](references/authoring-workflow.md#工作流)。
- 媒体与路径：读取 [media-and-path-rules.md](references/media-and-path-rules.md)；代码媒体另读 [runtime-code-generated-media.md](references/runtime-code-generated-media.md)。
- 设计核对与记录：读取 [verification-and-note-update.md](references/verification-and-note-update.md)。
- 完整双角色验收：读取 [closed-loop-browser-validation.md](references/closed-loop-browser-validation.md)，按实际角色加载细则。
- 入口/媒体索引：读取 [runtime-entry-page-pattern.md](references/runtime-entry-page-pattern.md) 或 [runtime-media-index-contract.md](references/runtime-media-index-contract.md)。
- AI 上下文变化：读取 [AI 上下文约束](references/authoring-workflow.md#ai助手上下文配置强制设计原则)。

已有未变化的证据可复用。只为会改变目标、授权或重要教学含义的缺失信息提问；普通可逆实现与表达选择自主完成。当前用户明确指令优先于技能建议，项目安全和数据约束继续有效。
