# 现有界面改进

先检查目标页面、已有组件和设计约定，识别具体的阅读、布局或交互问题。围绕本次目标修改，保留业务功能、数据含义、品牌与导航一致性。

优先复用现有字体、图标和组件。允许列表、表格、留白和重复布局，只要符合内容。新资产或动效应解决实际问题；不为展示风格引入新依赖或重做无关页面。

真实日期、指标、评价和人物信息保持来源内容。演示数据应明确标注，不能随机化日期或编造社会证明使页面显得真实。

使用实际页面核验受影响的布局、关键操作与响应式状态；通过后不重复做全站审计。
