# 叙事网页与动效

根据页面目标和已有品牌选择构图。AIDA 适用于转化页面，不强加到课堂、表格或工具界面。标题保持可读、导航与主要操作可见；网格留白可以服务视觉层次。

动画应表达反馈、层次或状态变化。复用已有动效库；只有实际需要复杂时间线时使用 GSAP。实现清理、键盘操作和 reduced-motion 回退；避免动画阻塞正文读取。

不模拟 Python 执行或用随机结果决定产品设计。用户要求随机探索时才真实执行并记录种子；常规设计直接说明有意义的设计选择。不要强制输出 design_plan，也不要为了差异化替换现有字体、图标或依赖。
