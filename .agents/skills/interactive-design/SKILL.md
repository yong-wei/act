# interactive-design

人读设计经明确接受后才进入机读契约；接受可从当前会话复用，已批准契约的明确修复不逐文件再确认。保留讲义顺序、自包含正文、题面/答案角色投影、教师控制、真实内容源、sequence/card_order 与 manifest 一致性。不得伪造接受记录或绕过严格导出审查。

## 按任务读取

- 页面内容与教学顺序：读取 [设计原则](references/authoring-workflow.md#核心原则)。
- 例题与推导显影：读取 [worked-example-modules.md](references/worked-example-modules.md)。
- 曲线互动：读取 [curve-interaction-panels.md](references/curve-interaction-panels.md)。
- 模板、页面顺序与活动字段：读取 [page-sequence-and-activity-controls.md](references/page-sequence-and-activity-controls.md)。
- 新建完整设计或输出契约：读取 [设计流程](references/authoring-workflow.md#设计流程) 与输出要求；局部修订只读取对应契约和直接影响项。

已有未变化的证据可复用。只为会改变目标、授权或重要教学含义的缺失信息提问；普通可逆实现与表达选择自主完成。当前用户明确指令优先于技能建议，项目安全和数据约束继续有效。
