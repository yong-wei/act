# refine

表达自然不等于省略科学前提。发现内容错误时区分文风修改与事实修订，给出证据；不为了词表替换“稳定、闭环、鲁棒性”等专业概念。

## 按任务读取

- 先确定目标讲义与指定范围，保留术语、符号、例题条件、结论和交叉引用。
- 按 `course-content/AGENTS.override.md` 的读者与表达要求修订。局部改写直接处理，不固定执行多轮重写。
- 遇到特定搭配或文风问题时查 [表达规则与范例](references/authoring-workflow.md#润色规则) 和附录；不默认读取全部示例。
- 只修改授权的讲义；导出、知识同步或教学结构变更分别按其流程和授权处理。

已有未变化的证据可复用。只为会改变目标、授权或重要教学含义的缺失信息提问；普通可逆实现与表达选择自主完成。当前用户明确指令优先于技能建议，项目安全和数据约束继续有效。
