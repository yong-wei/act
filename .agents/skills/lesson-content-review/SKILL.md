# lesson-content-review

保留事实来源、数值验证、设计接受、实现接受、内容时效和三层契约一致性门禁。接受文件必须来自真实验证，局部检查不能声称整课通过。已有人工 media 文档不可由导出覆盖。用户只要求审查时报告；明确要求回修时在本次范围内完成。

## 按任务读取

- 指定公式、段落或图片：只审该对象与直接依赖，结论限定范围。
- 正文科学正确性：读取 [correctness-review.md](references/correctness-review.md)。
- BOPPPS 覆盖：读取 [boppps-coverage-review.md](references/boppps-coverage-review.md)。
- 互动实现：读取 [interactive-implementation-review.md](references/interactive-implementation-review.md)。
- 知识卡与媒体：分别读取 [knowledge-card-review.md](references/knowledge-card-review.md) 或 [multimedia-review.md](references/multimedia-review.md)。
- 整课放行与 runtime 导出：读取 [完整审查流程](references/authoring-workflow.md#workflow) 和 [runtime-output-contract.md](references/runtime-output-contract.md)。

已有未变化的证据可复用。只为会改变目标、授权或重要教学含义的缺失信息提问；普通可逆实现与表达选择自主完成。当前用户明确指令优先于技能建议，项目安全和数据约束继续有效。
