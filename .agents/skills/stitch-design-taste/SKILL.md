# Stitch 设计约定

从用户 brief、已有界面和品牌中提取颜色、字体、间距、组件和状态规则，写入任务指定的 DESIGN.md。只记录会改变实现选择的约定，并区分硬约束、建议与示例。

不把个人风格模板扩展为通用禁令；不强制持续动效、非对称布局或背景图。既有设计保留可复用部分，明确实际需要调整的组件。

提供代表性组件与交互状态说明；截图或工具不可用时说明证据限制，不声称已在 Stitch 中执行。附带的 DESIGN.md 仅作示例，不覆盖项目真源。
