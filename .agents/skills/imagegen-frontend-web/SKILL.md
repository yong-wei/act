# 网页视觉参考

根据用户要求的页面、区块和风格生成清晰可读的参考图。图数服从指定数量与实际设计需求；未指定时使用足以表达方向的最小图集，不自动增加六至八个区块。

跨图保持字体、颜色、间距、组件与品牌一致。需要精读局部时生成细节图；用户要求完整逐区参考时覆盖全部指定区块。已有图像的编辑使用当前图片编辑工具。

优先明确主要内容、视觉层次和操作。不要加入虚构指标、客户评价或未经授权的产品功能。图片文字是设计参考，实现时应回到真实内容。交付图片及有用的设计说明，不强制输出逐步广播。
