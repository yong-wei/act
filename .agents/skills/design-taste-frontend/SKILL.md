# 前端视觉设计

先从用户目标、内容密度、已有品牌与目标设备确定方向。已有项目复用其设计系统；新页面用清晰的字体层级、间距、色彩和图像关系形成一致视觉。

选择适合内容的布局，不预设 hero、bento 或固定章节数量。课堂页面以阅读、作答与教师控制为主；营销页面可采用叙事构图。中文排版按实际字符与设备宽度检查，英文词数限制不能直接套用。

图像只在需要视觉资产或概念探索时生成。已有合适资产直接复用。动效需要具体作用，使用已有依赖并提供 reduced-motion、可访问名称、键盘操作及错误/空状态。

检查目标页面在代表性宽度的可读性和操作结果；不要为追求“高级感”更换整个组件库、禁用既有字体或堆叠特效。
