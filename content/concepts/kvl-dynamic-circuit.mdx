# KVL 与动态电路

一句话：回路电压升 = 电压降，遇到 L/C 就变成微分方程。

## 核心公式

- **KVL**：$$\sum u = 0$$
- 电感：$$u_L = L\frac{di}{dt}$$
- 电容：$$u_C = \frac{q}{C},\quad i = \frac{dq}{dt}$$

## 典型 RLC 回路

$$L\frac{di}{dt} + Ri + \frac{1}{C}\int i\,dt = u(t)$$

## 机电类比（超好记）

- 电感 **L** ↔ 质量 **m**
- 电阻 **R** ↔ 阻尼 **f**
- 电容 **C** ↔ 弹簧 **k**

## 小结

动态元件 = **能量存储**，所以方程一定带“时间变化”。
